【原著剧情锚点总览：主线时间线导航】

> 本文件是「主线」的骨架。每个阶段对应一段原著剧情窗口，玩家可卷入原著事件，也可完全偏离走原创线。所有日期为原著公开时间线（可参考重写，非照搬）。

== 阶段 0：旧约·前日谭（1月-7月）==
- 原石拯救篇：1月18日，未在学园都市接受能力开发的原石能力者事件。
- 美琴过去篇：2月20日，御坂美琴初获"超电磁炮"名号的回忆（回忆窗1·名号之重）。
- 美琴一年级篇：美琴一年级学年（回忆窗2·名门之暗）——常盘台三大派阀（沙/水镜/支仓）为「永代姬君」之位抗争，Mongolfiere社与安提基特拉社幕后搅局，沙淡扇为养姐武林夜宵向常盘台复仇（超炮漫画第17-21卷最终章改编）。
- 幻想御手篇：5月-6月，Level Upper / 幻想御手 空中电波能力增幅网络，初春饰利卷入。
- 无能力者（Skill-Out）：Lv0 结社与武装无能力集团的活动。

== 阶段 1：旧约·禁书降临篇（7月-8月中旬）==
- 禁书目录篇（7月20日）：上条当麻遭遇蓝色修女茵蒂克丝，卷入英国清教与罗马正教的魔道书追猎，揭开 Index 体内魔法书（约翰之书/法之书）的秘密。
- 学习装置篇：取得学习装置，深入了解超能力开发与个人现实。
- 乱雑開放篇（8月上旬）：能力者集体暴走（Poltergeist）与 Capacity Down 抑制装置，木原系研究者泰瑞丝缇娜的幼童实验阴谋，8月10日收束。
- 能力者与魔法师的首次正面碰撞，确立"科学×魔法"的交错舞台。

== 阶段 2：旧约·绝对能力者进化篇（8月中旬-8月底）==
- 绝对能力者进化计划：一方通行为实现 Level 6 而猎杀御坂妹妹，御坂美琴拼死阻止。
- 上条当麻只手粉碎计划，一方通行首次遭遇"无法计算的异能"。
- Last Order（最后之作）登场，一方通路从杀戮者转向守护者。
- 静默派对篇（8月22日-27日）：科学结社STUDY以人工生命体双胞胎姐妹与两万驱动铠密谋"革命"，学究会公开实验未遂；美琴+布束砥信+风纪委员群像死守（主线事件·静默派对）。
- 8月31日：一方通行脑损伤事件（被切断部分生理机能，需电子辅助）。

== 阶段 3：旧约·天使坠落篇（8月底-9月）==
- 天使坠落事件：8月31日深夜至9月，学园都市卷入世界范围的身份互换术式。
- 玩家身边的角色可能被换了灵魂/身份，日常陷入荒诞错乱。
- 上条当麻追查并解除天使坠落，揭示世界真相的一角。
- 死灵术师篇（9月1日-9月8日，与本篇时间带内共存）：一方通行住院期，DA猎杀死灵术师艾丝特·罗森塔尔，妹达10046号遭绑架，罗森塔尔家400年“神之棺”阴谋浮出。
- 神之饮物篇（9月9日-9月14日，死灵术师篇后、大霸星祭前，嵌套共存）：一方通行静养期撞上从天而降的姬戏茉离，暗部组织Full Course以“神之饮物”之名把暴走能力者当体晶原料榨取，豪华客船“食之宴”终局——恶党以恶制恶的守护战（详见主线事件·神之饮物）。

== 阶段 4：旧约·大霸星祭 / 使徒十字篇（9月中-9月底）==
- 大霸星祭：学园都市秋季运动会，超能力者对决的盛大祭典，暗部势力暗流涌动。
- 恩底弥翁篇（剧场版）：天空城恩底弥翁的音乐与科技阴谋。
- 使徒十字篇（9月底）：罗马正教试图以使徒十字圣器支配学园都市，各国魔法侧暗战。
- 天赋梦路篇（9月底-10月初）：梦境卡牌「印第安扑克」黑市流通，S级梦境「天赋梦路」，操齿凉子的"制造灵魂"改造人实验，食蜂操祈追查卡牌来源。
- 亚得里亚海女王篇（9月下旬，使徒十字篇后、意大利境外）：上条的北意大利"幸运之旅"撞上罗马正教灭口案——巨大陆军战舰"亚得里亚海的女王"炮口对准水都，天草式接应，雅妮丝修女一队获救（详见主线事件·亚得里亚海女王）。
- 0930事件（9月30日单日，大霸星祭季终幕、暗部大战导火索）：神之右席前方のヴェント入侵、天罚术式全城昏睡，木原数多同日猎杀一方通行——黑翼觉醒、上条为护最后之作失忆，学园都市最黑的一天（详见主线事件·0930事件）。

== 阶段 5：旧约→新约·第三次世界大战篇（10月-11月）==
- C文书篇（10月1日-8日，0930余波中、暗部大战前夜）：罗马正教以灵装C文书书写"神的旨意"遥控全球反科学示威，上条与土御门赴法国阿维尼翁断其源头（详见主线事件·C文书）。
- 暗部大战（10月9日独立纪念日，Battle Royale）：学园都市暗部四大组织全面内战，垣根帝督叛乱、BLOCK勾结五千佣兵图谋刺杀亚雷斯塔，暗部管理体制事实解体。
- 越狱篇（10月10日-15日）：第二少年院脱狱试用赛被真犯人利用，春暖嬉美（宿有天使型竜的整体论能力者）胁迫初春公开能力开发技术。
- 圣人袭来篇（10月11日-17日，暗部大战余波中、三战前夜）：神之右席後方のアックア携左方之地遗骸下战书、踏浪入侵猎杀上条右手，五和护卫、神裂圣人参战（详见主线事件·圣人袭来）。
- 第三次世界大战：科学侧（学园都市）与魔法侧（俄罗斯成教等）的全面冲突。
- 上条当麻的"右手"（幻想杀手）与"左手"（龙王的叹息）觉醒，成为扭转战局的关键。
- 一方通行、滨面仕上等卷入世界规模的战斗。
- 神之右席（右方之火）暗中推动"拯救世界"的极端计划。

== 阶段 6：新约·格雷姆林 / 魔神篇（11月-12月）==
- 格雷姆林组织与魔神欧提努斯登场，挑战世界法则的"魔神"概念浮出水面。
- 人工天界计划、位相篡改，科学侧与魔法侧被迫联手。
- 上条当麻对魔神，赌上"能否保护所有人"的信念之战。

== 阶段 6.5：新约·蜜蚁爱愉篇（12月上旬，魔神之战余波）==
- "蜂与蚁"的悲剧：蜜蚁爱愉（Level 3「心理穿孔」，被《资质排行》砍掉的另一名女王候补）以 Five_Over OS 向食蜂操祈复仇，三秒击倒食蜂；上条当麻介入对峙，败于幻想杀手与劝救，送入少年院。

== 阶段 7：新约终章·科隆尊篇（12月中旬）==
- 科隆尊降临：更上层的魔法存在（艾华斯/科隆尊）揭开魔法侧最本源的力量与真相。
- 玩家的选择开始决定世界的走向（可完全偏离原著结局）。

== 使用说明 ==
- 每个阶段是"主线窗口"，AI 通过 主线进度.当前阶段 判断玩家所处剧情位置。
- 玩家可自愿卷入阶段事件，也可跳过、偏离，走完全原创的主线线。
- 出场原著角色对玩家保持开放互动，关系随剧情推进。
- 详细事件、敌人、地点见 主线/ 与 支线/ 各逐事件文件。
