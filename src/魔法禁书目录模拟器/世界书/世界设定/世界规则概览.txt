【世界规则概览：魔法禁书目录模拟器】

== 世界观铁律 ==
1. 科学与魔法彼此对立又相互交织。科学侧以超能力（AIM扩散力场、个人现实）为根基，魔法侧以魔力与偶像崇拜理论为根基。原著设定中二者互斥：能力者经学园都市开发后体内形成 AIM 扩散力场，与魔法所需魔力不相容，强行施展魔法会严重伤身；魔法师则因无个人现实才能而无法使用超能力。本作尊重此设定作为世界基础，但玩家作为主角享有「主角光环豁免」——可像原石（天生能力者）、特殊体质者（如上条当麻）那样兼用两体系；豁免代价以搞笑受挫、出糗、体力透支等热血喜剧方式呈现，不判死亡、不设数值惩罚。
2. 超能力等级：Level 0（无能力者）至 Level 5（超能力者）为常规上限，Level 6（绝对能力者）为传说中的禁忌目标。本作开放 Level 6 开局，玩家可凭主角光环与成长剧情逐步触及绝对能力者领域。
3. 魔法境界：魔法师 → 圣人（拥有天使级力量的一部分，肉体已非人类）→ 魔神（超越人智、可篡改世界法则的存在）。本作开放魔神级开局，但魔神级力量伴随世界观冲击，建议用在关键剧情或作为成长终点。

== 玩家能力与都市传说规则 ==
1. 适用范围：玩家开局等级为 Level 2 及以上时适用；Level 0-1 开局本规则不生效（无能力者本就不起眼）。玩家的能力与等级不在学园都市官方档案中（测定数据异常/登记缺失，官方当作仪器故障或误差处理），坊间以"都市传说"形式流传，版本走样、真假掺半。
2. 七人排名永不变动：原著 Level 5 七人的位次与剧情不因玩家改变；玩家不属于排名序列。
3. 知情三层（推进时同步更新 NPC关系.认知 字段）：
   - 传说层（默认，认知=陌生）：NPC 只听过模糊传闻，不知真名真貌；玩家未出手前，NPC 不得虚构玩家的具体能力细节，传闻只许模糊走样。
   - 调查层（认知=知道名字/知道身份；"知道阵营"在本层后期获知）：暗部组织、Level 5 级人物、风纪委员可循线索调查，获知代号或外貌，真实能力仍不明。
   - 亲历层（认知=知道能力/知道秘密）：亲眼目睹、正面交手、或被精神系能力直接接触（如心理掌握读心）后，知晓真实能力与等级。
4. 单向性与例外：进入亲历层后永久知晓，不因时间流逝回退；除非剧情明确处理记忆消除（如心理掌握抹除在场者记忆），被消除记忆者按对应层重新归零。
5. 泄露机制：玩家当众使用能力→传闻自动升级（扭曲加重、波及扩大）；在原著大事件现场出手→相关势力进入调查层；玩家主动公开身份→相关 NPC 直接进入亲历层。
6. 写作要求：NPC 言行必须与 认知 字段一致——未达知情层者不得在言行中表现出知道玩家真实能力；已知情者言行应体现相应认知。科学侧按上述都市传说模板处理；魔神/圣人级开局不套用学园都市模板，改为"魔法侧势力隐约察觉异常波动、流传神秘存在的传闻"。
4. 学园都市：位于东京西部，通过装置将全国八成超能力者集中于此，分 23 个学区。超能力开发仰赖身体成长与『个人现实』的构建，成熟期约 15-16 岁（故角色多为学生）。
5. 魔法阵营林立：英国清教、罗马正教、俄罗斯成教、天草式十字凄教、神之右席、格雷姆林、真·格雷姆林、黄金黎明、科学结社等。英格兰清教拥有禁书目录（Index），是魔法侧的守护组织之一。
6. 现实世界背地里由魔法师与科学组织博弈数百年，表面上则是现代都市日常。玩家可沉浸在学园都市的校园日常，也可卷入足以改变世界的大事件。

== 本作风格基调 ==
- 日常与战斗穿插：轻松搞笑的校园/日常为主，关键时刻（主线事件、强敌登场）切换为热血认真。
- 氛围轻松，减少死亡压迫感：世界观中有强敌与冲突，但不强制"九死一生"。允许玩家搞笑化解、吐槽整活、靠光环保住局面。
- 人物不冷漠：所有角色（含反派）都以有血有肉、有幽默感的方式呈现。
- 失败与挫折：不设风险值，不判定死亡。失败只带来出糗、受挫或搞笑（被抓包、被反杀出丑、任务搞砸等），玩家随时可继续冒险，靠主角光环与剧情推动翻盘。

== 能力与魔法结算 ==
- 能力者使用超能力、魔法师施展术式，均围绕 能力档案 展开，体现成长与变化。
- 跨体系（能力者用魔法/魔法师用超能力）按原著互斥规则：普通能力者强行施法会受身体反噬、魔法师用超能力无效。玩家享有主角光环豁免，可兼用两体系，代价以搞笑受挫、出糗、体力透支呈现，不判死亡、不设数值惩罚。
- 主线推进由原著剧情锚点（阶段0-7）引导，玩家可偏离原著走原创线。
- 任务追踪 记录当前主线/支线目标，NPC关系 记录玩家与各角色的羁绊与好感度。

== 世界线 ==
- 正史时间线（原著剧情）作为可选锚点存在，玩家可以选择卷入或完全偏离。
- 玩家拥有自主性：可以在学园都市过日常、接支线委托、探索魔法侧秘密，或冲击世界级大事件。
- 所有原著角色作为独立人物（每角色一文件）存在，与玩家的关系随互动推进。
