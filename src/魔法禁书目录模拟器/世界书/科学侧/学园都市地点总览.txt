【地点：学园都市地点总览】

> 学园都市位于东京西部（含埼玉、神奈川部分），圆形城市，约 230 万人口，学生占 80%。科技领先外域 20-30 年，由统括理事会统辖，风纪委员与警备员维持治安。无能力者（Level 0）占学生总数 60%。本文件聚焦玩家日常可涉足的地点。

== 第7学区（玩家核心活动区）==
- 类型：学生生活密集区
- 位置：学园都市中心偏南
- 外观：普通的学生街道、便利店、宿舍楼夹杂着高科技研究所
- 功能：高中生与初中生集中生活、上学、打工；风纪委员 177 支部设于此
- 常驻角色：上条当麻（学生宿舍）、白井黑子与初春饰利（177 支部）、常盘台众人（学舍之园相邻）
- 对玩家的意义：默认落脚点与日常舞台，支线委托、校园日常、街头冲突多发生于此

== 学舍之园（常盘台中学等名门聚集地）==
- 类型：女子名校复合学区
- 位置：第7学区内的高级区域
- 外观：哥特式与近代校园建筑混合，整洁优雅
- 功能：常盘台中学、栅川中学等名校集中地，培养顶尖能力者
- 常驻角色：御坂美琴、食蜂操祈、白井黑子（常盘台）；初春饰利、佐天泪子（栅川）
- 对玩家的意义：若选科学侧名校开局或接触御坂美琴线，此地为核心场景

== 没有窗户的大楼（亚雷斯塔居所）==
- 类型：统括理事长官邸/神秘核心
- 位置：第7学区深处
- 外观：一栋完全没有窗户的巨大建筑，内部充满红色液体容器
- 功能：亚雷斯塔·克劳利倒立栖身之处，学园都市真正的决策核心
- 常驻角色：亚雷斯塔·克劳利（幕后）；冥土追魂医生偶尔出入
- 对玩家的意义：极高阶段才会触及；普通人完全不知其内情，是都市最大秘密之一

== 冥土追魂医院（第七学区）==
- 类型：综合医院
- 位置：第7学区
- 外观：现代化医疗大楼，设备远超外域
- 功能：学园都市顶尖医疗中心，救过亚雷斯塔与众多重伤者
- 常驻角色：冥土追魂医生
- 对玩家的意义：受伤后的兜底治疗点；一方通行 8月31日事件后曾在此治疗

== 绝对能力者进化计划实验场 ==
- 类型：废弃/半废弃实验设施
- 位置：第7学区及周边铁道调车场区域
- 外观：夜晚的钢铁调车场，带实验记录设备
- 功能：一方通行猎杀御坂妹妹的实验场所
- 常驻角色：一方通行、御坂妹妹（20000 体的实验体）、御坂美琴（阻止方）、上条当麻（介入方）
- 对玩家的意义：阶段2主线核心场景；介入或阻止计划的关键地点

== 风纪委员177支部 ==
- 类型：治安值班站点
- 位置：第7学区商业街附近
- 外观：不起眼的办公楼，挂着 Judgement 标志
- 功能：风纪委员日常执勤、案件登记、巡逻出发点
- 常驻角色：白井黑子、初春饰利、固法美伟
- 对玩家的意义：日常线与支线委托的常见交接点；卷入街头事件会来这里

== 第10学区（研究/墓地/监狱）==
- 类型：地价最低的功能区
- 位置：学园都市边缘
- 外观：冷清的实验设施、墓碑群与高墙监狱
- 功能：危险研究设施、墓地、学园都市监狱
- 常驻角色：各路研究员、囚犯
- 对玩家的意义：暗部线、危险实验、追查真相时的高危地点

== 第11学区（陆路大门）==
- 类型：运输与物资枢纽
- 位置：学园都市陆路出入口
- 外观：巨大的仓库群与检查站
- 功能：物资进出与佣兵潜入的通道
- 常驻角色：警备员、Block 佣兵（攻门事件）
- 对玩家的意义：涉及外部势力渗透支线的关口

== 第15学区（繁华区）==
- 类型：商业娱乐中心
- 位置：学园都市地价最高处
- 外观：霓虹灯、电视台、大型商场
- 功能：购物、娱乐、吃穿用度的繁华区
- 常驻角色：各色学生与市民
- 对玩家的意义：日常放松、约会、消费场景

== 第18学区（能力开发学校）==
- 类型：能力开发专门区
- 位置：学园都市偏北
- 外观：多所能力开发名校集中
- 功能：长点上机学园、雾之丘女子学院等所在地
- 常驻角色：垣根帝督（未元物质）等
- 对玩家的意义：科学侧进阶能力开发线与 Lv5 冲突相关场景

== 第22学区（地下避难所）==
- 类型：地下 VIP 设施
- 位置：学园都市地表最小区域
- 外观：地表风力发电，地下十层
- 功能：地下避难所「避暑地」
- 常驻角色：无固定常驻
- 对玩家的意义：大事件时的避难或秘密地点

== 第23学区（航天与宇宙开发）==
- 类型：航天枢纽
- 位置：学园都市最外圈
- 外观：机场、航天发射场、战斗机
- 功能：航空航天、宇宙开发；树状图设计者通信中心旧址
- 常驻角色：航天相关人员
- 对玩家的意义：科技高端线、宇宙相关主线（恩底弥翁/树状图设计者）的入口

== 虚数学区·五行机关 ==
- 类型：与学园都市同相位的存在
- 位置：AIM 扩散力场的集合体所在
- 外观：常人不可见；特定条件下显现科学天使风斩冰华
- 功能：AIM 扩散力场的本体，真正目的是建立使魔法侧不攻自破的人工天界
- 常驻角色：风斩冰华（科学天使）
- 对玩家的意义：极高阶段真相揭示时才会触及；普通人完全无知

== 树状图设计者（残骸）==
- 类型：轨道超级计算机
- 位置：同步轨道卫星「织女星一号」
- 外观：7月28日被 Index「龙王的叹息」击毁，现仅余残骸
- 功能：曾精准预测天气与能力进化实验；击毁后相关数据散落
- 常驻角色：无
- 对玩家的意义：阶段1后的背景设定；残骸与数据可作为支线道具
