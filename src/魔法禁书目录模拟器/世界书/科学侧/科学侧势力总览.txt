【势力：科学侧势力总览】

== 统括理事会 ==
- 定位：学园都市的最高决策机构科技中枢，统管都市所幕后走向
- 成员/代表人物：会长亚雷斯塔·克劳利（长期栖身于没有窗户的大楼的黑袍神秘人）
- 目标理念：控制学园都市，把超能力者当作「科学武器」与对抗魔法侧的棋子
- 与玩家的关系：玩家若只是普通学生通常不直接接触；若玩家挑战都市规则或惊动高层，会被纳入观察名单
- 与其它势力关系：与英国清教暗中博弈，与罗马正教冲突
- 在主线中的角色：多次作为幕后黑手推动事件，影响玩家走向（可被玩家介入或暗中搅局）

== 风纪委员（Judgement） ==
- 定位：学园都市学生自治的治安组织，维护课余秩序
- 成员/代表人物：白井黑子、初春饰利、固法美伟等
- 目标理念：用能力与规则维持学园秩序，制止街头暴力
- 与玩家的关系：玩家若在街头惹事或卷入冲突，可能与风纪委员打交道
- 与其它势力关系：与警备员配合，与暗部对立
- 在主线中的角色：日常线的关键组织，可成为玩家的朋友或约束

== 警备员（Anti-Skill）==
- 定位：教职员组成的武装治安部队，处理学生对付不来的事态
- 成员/代表人物：黄泉川爱穗、铁装缀里等
- 目标理念：保护学生、镇压危险事态
- 与玩家的关系：处理过当事件时保护玩家，也可能成为背景板
- 与其它势力关系：与风纪委员协作，与暗部对抗
- 在主线中的角色：冲突现场的武力执法者

== 暗部（Group 等组织）==
- 定位：学园都市的地下行动组织，处理见不得光的脏活
- 成员/代表人物：一方通行、土御门元春、结标淡希等（依事件而定）
- 目标理念：替统括理事会干见不得光的任务，必要时抹除阻碍
- 与玩家的关系：若玩家牵扯进都市机密，可能被拉拢、利用或清除
- 与其它势力关系：与风纪委员/警备员对立，受统括理事会指派
- 在主线中的角色：悬疑与冲突的主要来源

== 武装无能力集团（Skill-Out）==
- 定位：无法使用能力的 Level 0 学生组成的街头组织
- 成员/代表人物：驹场利德、滨面仕上（早期）等
- 目标理念：在能力至上的学园求生存，找回 Level 0 的尊严
- 与玩家的关系：玩家可与之结盟、对抗或日常互动
- 与其它势力关系：与风纪委员/高能力者对立
- 在主线中的角色：揭示学园都市「无能力者被轻视」的现实面
