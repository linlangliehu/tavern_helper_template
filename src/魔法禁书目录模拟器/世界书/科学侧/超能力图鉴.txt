【超能力图鉴：魔法禁书目录模拟器】

> 本作科学侧超能力归档。按 Level 等级与能力者分列原著标志性能力与效果，供科学侧玩家与 NPC 战斗演绎参考。
> 科学侧能力源于「个人现实」——通过药物+催眠在脑内构建对现实的改写，能力等级与大脑运算量挂钩。所有能力者无意识放出「AIM扩散力场」（与魔法师魔力互斥，玩家主角光环豁免）。
> 本作无风险值、无反噬、无解密——能力失控以「失灵/出糗/扰民/被举报」等喜剧性后果呈现，不致死不收场。

== Level 5 超能力者（学园都市最强七人，单独对抗一支军队级） ==

- 类型：超能力者（Level 5）
- 持有者：学园都市排名前七的能力者
- 效果：学园都市金字塔顶端，仅七人。每人能力独特且具军队战术价值
- 用处：高阶段主线核心战力；学园都市"科学武器"与对抗魔法侧的棋子

== 矢量操作（一方通行·第1位） ==
- 类型：矢量系超能力
- 持有者：一方通行（Accelerator）
- 效果：通过对自身观测现象的逆运算，控制一切矢量（力、速度、动能等有方向的量）
  · 反射：接触身体的矢量自动改向，只接收重力/气压/光/氧气/热/声等最低限度所需，其余全反射，无意识自动判别"有害"并反射
  · 重力反转：飞行/悬浮
  · 气流操作：制造风暴、超音速移动、压缩空气达万度等离子体球
  · 力量倍增：出拳动能全指向对手；鞋跟冲击波溅石如子弹；夺取地球自转5分钟能量发射大楼2公里（"地球自转炮"）
  · 生物电操作：感知/操控他人生物电，重新调整最后之作人格
  · 羽翼形态：黑翼（破坏力绝大/可扩百米/土石海啸）、白翼（"守护"心境/可抵大陆级天使之力/冲上千米高空）、白金翼（连御坂网络+恶魔，抗衡圣守护天使爱华斯）
- 限制/副作用：需保持"反射"常开（否则可被物理攻击）；木原数多可在反射瞬间改变力方向使其反射回自身；未元物质等"未知矢量"反射难发挥（喜剧化：遇到搞不懂的力，反射打脸反噬自己）
- 用处：Level 5 第一位，学园都市最强；暗部 Group 核心

== 未元物质（垣根帝督·第2位） ==
- 类型：创造系超能力
- 持有者：垣根帝督（ Kakine Teitoku）
- 效果：创造世界上"从一开始就不存在"的物质，更改已存在物质的法则
  · 未元白翼：背展六片白翼可延20米+，飞行/防御/打击/斩击/烈风/冲击波/光攻击；反弹原子崩坏、超电磁炮也击不穿；缝隙使物质法则改变（阳光→死亡射线）
  · 未元矢量：创造不可能存在的矢量，注入光线/风等攻击，破解法寥寥
  · 无限增殖：建构人体细胞，复原肉体/制造内脏/分裂个体量产"未元物质"，分割多少块就多少意志，会合时意识整合
  · 未元冲击波：猛烈鼓动白翼形成巨大冲击波
- 限制/副作用：能力对魔法攻击效果不明（喜剧化：搞魔法撞墙一脸懵）
- 用处：Level 5 第二位；暗部 School 首领

== 超电磁炮（御坂美琴·第3位） ==
- 类型：发电系超能力
- 持有者：御坂美琴（Misaka Mikoto）
- 效果：发电系能力最高者
  · 超电磁炮：游戏币经电磁力以3倍音速射出，攻击贯穿力极高、弹道物体全毁、可在楼房开2米洞，与空气摩擦熔化硬币射程约50米
  · 雷击之枪：投掷高压电流枪，最大10亿伏特
  · 落雷召唤：从天上召唤真正的落雷
  · 砂铁散布/砂铁之剑：操纵地下铁砂形成锋利之剑、铁砂海啸/龙卷风
  · 磁力操控：移动含铁物质组盾、在钢筋建筑行走、用混凝土抵爆炸
  · 电磁波电子操作：操纵电子仪器（自称最强黑客）、检测心电图
  · AIM雷达：不自觉放出AIM扩散力场感知微弱电磁波
  · 电流涡旋发热、电磁力漂浮
  · 对电击有抗性、可扭曲麦野原子崩坏、可防御食蜂洗脑
- 限制/副作用：长时间使用会"电池耗尽"瘫倒（喜剧化：战斗中突然没电蹲地上哭）
- 用处：Level 5 第三位；常盘台中学超电磁炮；主线玩家最常接触的 Level 5

== 原子崩坏（麦野沉利·第4位） ==
- 类型：电磁系超能力
- 持有者：麦野沉利（Mugino Shizuri）
- 效果：本质"粒机波形高速炮"——强制操纵介于波与粒子之间"暧昧状况电子"
  · 攻击：发射电子射线，连同遮蔽物和对方身体一起贯穿
  · 防御：暧昧电子撞击物体时因无法决定呈现粒子/波形反应而"滞留"，形成拟似障壁护盾
  · 电磁系：可与御坂美琴能力互相干扰，扭曲对方攻击、护盾摧毁已发射超电磁炮
- 限制/副作用：单论破坏力在第三位之上，但难以控制准星故排第四；全力使用自身身体因反作用力粉碎；御坂电磁干扰可引爆失控；依赖泷壶理后辅助瞄准（喜剧化：准星翻车轰错人）
- 用处：Level 5 第四位；暗部 Item 女王

== 心理掌握（食蜂操祈·第5位） ==
- 类型：精神系超能力
- 持有者：食蜂操祈（Shokuhou Misaki）
- 效果：精神操控系最强，与同系统能力者有根本性差距；本质以液体/人类体液为切入点操控大脑
  · 九大具体表现：行为控制（像木偶操控他人含自杀）、人格操作（改性格）、记忆篡改、强制读心、强制自白、呆然自失、认知操作、记忆抽取（对无生命物品）、行为退化
  · 精密操纵≤10-14人并随时切换；单纯赋予指令可操控约三位数人
  · 念话（远距离）、思考消除、意志增幅、思考重现、感情移植——一手包办所有精神现象，如瑞士刀般万能
  · 可用能力封锁同类型能力者入侵
- 限制/副作用：无法通过被操纵者大脑使用其能力；需要电视遥控器细分能力否则把握不了；惧怕难以忍受的精神攻击（喜剧化：遥控器没电能力乱串）
- 用处：Level 5 第五位；常盘台中学最大派阀女王大人

== 蓝花悦（第6位） ==
- 类型：不明
- 持有者：蓝花悦（Aihana Etsu）
- 效果：学园都市第六位超能力者，一切详细信息均不明（性别、能力皆未公开），大霸星祭委员会始终联系不到
- 限制/副作用：正体不明，可玩家化或作为神秘存在处理
- 用处：Level 5 第六位；神秘存在

== 念动炮弹（削板军霸·第7位） ==
- 类型：念动系（原石能力，正体不明）
- 持有者：削板军霸（Sogiita Gunha）
- 效果：世界最大"原石"（Gemstone，天然超能力者，非开发产生）。能力正体不明，学园都市科学家及本人都无法解释原理（每次自己编一套不成立的解释）
  · 念动炮弹（Attack Crash，自称）：不可视之力将相距10米以上对手殴飞，通称"强拳"
  · 二倍音速移动、弹开子弹、自动止血与接回断骨
  · 随手拍落强制进化至5.1的御坂美琴雷击
  · AIM场混乱不可观察，似乎是将心中"骨气（根性）"具象化
- 限制/副作用：潜力无法挖掘故排第七（喜剧化：自己都搞不清能力，打完自己懵）
- 用处：Level 5 第七位；纯战斗能力在 Level 5 中属前列

== Level 4 大能力者（军队战术价值级） ==

- 类型：大能力者（Level 4）
- 持有者：具军队战术价值的高能力者
- 效果：单独行动可影响战术走向，是学园都市中坚战力
- 用处：中高阶段主线与支线核心战力；暗部组织主力

== 坐标移动（结标淡希·Level 4） ==
- 类型：空间系超能力
- 持有者：结标淡希（Musujime Awaki）
- 效果：空间移动升级版。无需触摸，仅凭意念或注视即可将物体从A点传至B点，可同时转移多目标
  · 极限：重量4520公斤（4.5吨）、距离超800米（白井黑子的10倍+）
  · 用军用手电筒作瞄准基准点
  · 可视为白井黑子的加强版
- 限制/副作用：移动超1000公斤损害健康；对移动自身有极大恐惧（两年前测验失误脚埋进墙受重伤），自我移动超4次胃翻呕吐精神错乱，自我转移有2-3秒延迟（喜剧化：自传送吐一地）
- 用处：暗部 Group 成员；"带路人"都市传说正体

== 空间移动（白井黑子·Level 4） ==
- 类型：空间系超能力
- 持有者：白井黑子（Shirai Kuroko）
- 效果：将皮肤接触物（含自己）以无视三次元空间规则瞬间送至远方
  · 极限：距离81.5米、质量130.7公斤
  · 规则"被移动物挤开目标位置物体"与材质无关——理论上可用纸切钻石
  · 战斗用大腿枪套金属箭矢空间传送进敌武器/身体（避开要害）
  · 自身连续移动每80米1秒延迟，时速约288公里
- 限制/副作用：只能移动触摸到的东西，无法把远处物体移到手边；接近极限距离精确度必降（喜剧化：传送误差卡墙里）
- 用处：常盘台中学风纪委员；御坂美琴学妹兼室友

== 能力追踪（泷壶理后·Level 4） ==
- 类型：AIM 感知系超能力
- 持有者：泷壶理后（Takitsubo Rikou）
- 效果：感应他人AIM扩散力场
  · 可凭记忆的AIM场搜寻并锁定能力者位置，即使对方逃到太阳系外也能搜寻捕捉
  · 可干涉他人能力（如使垣根帝督主副能力互换）
- 限制/副作用：1次发动只能锁定1人、结果需十数秒；体力消耗大难连发；对非能力者（魔法师）完全无效；发动慢、防御力低（喜剧化：刚锁定好对方已经跑没影）
- 用处：暗部 Item 成员；被认为最可能成为"第八人"Level 5

== Level 0-3 代表能力 ==

- 类型：无能力者至强能力者
- 持有者：学园都市普通学生
- 效果：占学园都市学生绝大多数，能力微弱或可日常生活活用
- 用处：日常线与成长线主角群；玩家常见出身

== 幻想杀手（上条当麻·Level 0） ==
- 类型：异能消除（与生俱来，非开发所得）
- 持有者：上条当麻（Kamijou Touma）
- 效果：右手（手腕到指尖）触碰即消除一切异能（超能力+魔法+神迹+地脉龙脉），不论善恶好坏
  · 区画分割的异能（如龙王叹息、亚得里亚海女王）无法一次消除
  · 天罚术式/空间移动等以"上条当麻"为对象的异能，右手在效果范围内无需接触也可消除
  · 无法被检测故测为Level 0
- 限制/副作用：无意识消除"神明庇佑""命运红线"等微弱异能，导致不幸缠身（口头禅"不幸啊"）；右手内潜藏"龙王的叹息"等真相（剧透按阶段揭露）（喜剧化：消除好运导致倒霉体质，但也是解救被卷入事件之人的"避雷针"）
- 用处：主线主角能力；魔法与科学两侧共同的钥匙

== 缺陷电力（御坂妹妹·Level 2-3） ==
- 类型：发电系超能力
- 持有者：御坂妹妹（约20000体克隆人）
- 效果：电击能力，御坂美琴能力克隆体，能力等级2-3
  · 共享御坂网络情报与计算资源，可支持一方通行演算
  · 御坂妹妹间共享情感与发言
- 限制/副作用：单体能力微弱，强在数量与网络（喜剧化：单个御坂妹妹电击只够电一下静电）
- 用处：绝对能力者进化计划核心；玩家可遭遇或与之为友

== 最后之作（御坂妹妹指挥体） ==
- 类型：御坂网络指挥塔
- 持有者：最后之作（Last Order，御坂妹妹第20003号/番外个体）
- 效果：担任御坂妹妹指挥塔，能管控御坂网络
- 限制/副作用：体型小、能力本身非战斗向，但地位关键
- 用处：一方通行监护对象；主线关键 NPC

== AIM扩散力场（通用设定） ==
- 类型：能力者无意识放出的微弱力场
- 持有者：所有能力者
- 效果：是泷壶理后能力追踪、御坂美琴雷达能力的物理基础；能力者AIM与魔法师魔力互斥——这正是科学与魔法不可混用的设定根源（玩家主角光环豁免，NPC按原著互斥演绎）
- 限制/副作用：AIM场强的能力者易被追踪定位
- 用处：科学侧能力体系的基础设定；科学与魔法冲突的根源

== 个人现实（通用设定） ==
- 类型：能力开发原理
- 持有者：所有学园都市能力者
- 效果：通过药物+催眠在脑内构建对现实的改写，能力等级与大脑运算量挂钩
- 限制/副作用：开发有风险，失败以能力不稳定呈现
- 用处：学园都市能力开发的科学解释

== Level 6 绝对能力者（理论级，无人达到） ==
- 类型：理论超能力者
- 持有者：无（仅一方通行具备进化素养）
- 效果："以非神之躯，领悟天之意志者"——触及神意但未入神之域，理论上存在
- 限制/副作用：强制进化会崩坏（除一方通行外）；本质是亚雷斯塔的幌子（喜剧化：谁喊"我要变Level 6"谁先崩）
- 用处：主线"绝对能力者进化计划"的核心目标；亚雷斯塔真实目的的掩护
