【物品大全：魔法禁书目录模拟器】

> 本作物品分科学侧（装备/道具）与魔法侧（灵装/魔道书）两大类。物品可在支线奖励、主线关键节点、或玩家与 NPC 互动中获得。物品不绑定数值惩罚，不触发死亡；副作用以「出糗、失灵、扰民、被举报」等喜剧性后果呈现。

== 幻想杀手（Imagine Breaker） ==
- 类型：异能之手（右手）
- 持有者：上条当麻
- 效果：能消除一切异能（魔法与超能力），包括神的祝福；是魔神愿望与恐惧的具象化
- 限制/副作用：连带消除好运，导致日常「不幸」缠身；滥用会因副作用当场失效或抽干体力
- 用处：破解魔法术式、抹除能力攻击、对抗魔神级存在的关键底牌

== 七天七刀（倭刀） ==
- 类型：灵装（圣人专用刀）
- 持有者：神裂火织
- 效果：圣人挥舞时可斩断术式与异能；配合钢丝术式形成攻防一体的战斗体系
- 限制/副作用：仅圣人级体质能完全发挥；普通人强用效果减弱
- 用处：魔法侧近战与术式破解的核心灵装

== 钢丝（神裂术式载体） ==
- 类型：灵装（魔法媒介）
- 持有者：神裂火织
- 效果：以钢丝勾勒魔法阵，发动切割与封印术式
- 限制/副作用：需精确手法，失误会伤及自身
- 用处：神裂火织标志性战斗方式，可设陷阱与近战

== 符文卡（符文魔法） ==
- 类型：灵装（魔法媒介）
- 持有者：史提尔·马格努斯
- 效果：以符文卡发动火焰魔法，可设陷阱、召唤炎魔、远程攻击
- 限制/副作用：符文需提前布置；潮湿或被干扰会失效
- 用处：史提尔的招牌战斗方式，区域控制与火力压制

== 魔道书 ==
- 类型：记载术式的书籍
- 持有者：Index 脑中存有 103000 册；各魔法师亦持有自己抄本
- 效果：记载术式与魔法知识，可据此发动对应术式
- 限制/副作用：普通人阅读魔道书会精神崩溃；魔道书本身有「自我传播」特性
- 用处：魔法侧知识储备与术式来源；Index 体内的禁书是各方争夺核心

== 自动书记（Index 模式） ==
- 类型：魔道书图书馆的防御机制
- 持有者：茵蒂克丝（Index）
- 效果：Index 进入自动书记模式可发动「龙王的叹息」等歼灭级术式
- 限制/副作用：Index 本人无意识，可能误伤友军；每3年需消除一次记忆
- 用处：禁书降临篇击毁树状图设计者的力量；高阶段的关键火力

== 使徒十字 ==
- 类型：圣器（十字教核心圣物复制品）
- 持有者：罗马正教
- 效果：基于偶像崇拜理论，可支配大片区域信仰与人心
- 限制/副作用：需特定仪式与场所激活；激活过程会被高能力者察觉
- 用处：使徒十字篇罗马正教试图支配学园都市的核心道具

== 伯利恒之星 ==
- 类型：空中要塞（圣物聚合体）
- 持有者：右方之火
- 效果：承载「伯利恒计划」，凝聚全球恶意与神之右席资质，意图净化世界
- 限制/副作用：需夺取特异右手血肉补强；失败会失效或效果不稳
- 用处：三战终局的舞台与目标

== 灵装（通用） ==
- 类型：传导魔力的器具/装备
- 持有者：各魔法师
- 效果：传导与增幅魔力，发动术式的载体
- 限制/副作用：损坏会失效或效果不稳；被幻想杀手触碰会失效
- 用处：魔法师标配，类似科学侧的能力开发装置

== 魔法阵 ==
- 类型：术式发动记号
- 持有者：各魔法师
- 效果：将异世界（位相）法则带到现世的载体
- 限制/副作用：需精确绘制；被破坏术式中断
- 用处：发动大规模术式的基础

== 硬币（御坂美琴招牌道具） ==
- 类型：普通硬币
- 持有者：御坂美琴
- 效果：以电磁力加速硬币发射「超电磁炮（Railgun）」
- 限制/副作用：射程有限；硬币会熔化；扰民可能被风纪委员追
- 用处：御坂美琴标志性攻击手段，日常与战斗两用

== 能力开发装置 ==
- 类型：科学侧设备
- 持有者：学园都市各学校/研究所
- 效果：通过药物、催眠构建「个人现实」，开发与提升超能力
- 限制/副作用：有等级上限（与大脑运算量挂钩）；过度开发有副作用
- 用处：科学侧玩家提升能力的核心途径

== 学习装置 ==
- 类型：能力开发辅助设备
- 持有者：学园都市
- 效果：协助构建个人现实，深化能力理解
- 限制/副作用：误用会致昏迷或失控（出糗但不致死）
- 用处：阶段1支线道具，深入了解超能力开发

== 御坂网络 ==
- 类型：AIM 扩散力场网络
- 持有者：御坂妹妹（约 20000 体共享）
- 效果：御坂妹妹间共享情报与计算资源；可支持一方通行的演算
- 限制/副作用：非御坂系能力者无法直接接入
- 用处：阶段2后一方通行脑损伤后的演算支持来源；御坂妹妹协作基础

== 体晶 ==
- 类型：能力体结晶
- 持有者：木原幻生（能力体结晶计划）
- 效果：致能力者昏迷，用于实验
- 限制/副作用：危险，涉及弃童伦理问题
- 用处：科学侧暗部支线道具

== 幻想御手（Level Upper） ==
- 类型：能力增幅音频
- 持有者：木山春生（研发）
- 效果：通过空中电波连接能力者 AIM，临时增强能力
- 限制/副作用：滥用致昏迷，会生出 AIM 猛兽
- 用处：阶段0支线核心道具
