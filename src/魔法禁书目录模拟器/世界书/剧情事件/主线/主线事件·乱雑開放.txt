【事件包：乱雑開放篇】
事件包ID：POLTERGEIST
所属阶段：阶段1尾声·旧约·禁书降临季（保留现有阶段归属）
年层：Y（当前年）
时间窗口：Y年八月上旬，采用《超电磁炮》动画窗口；8月2日—10日为原项目排期，图排8月10日收束不作为全媒介硬终点。
别名与触发词：乱雑開放 / 乱杂开放篇 / Poltergeist / POLTERGEIST / POLTERGEIST-01

== 1. 核心定位 ==
动画第一期第20—24集的救援与调查事件，承接幻想御手留下的木山与昏迷孩子问题，不重演幻想御手。春上寻找枝先绊理的日常线，与频发的乱杂开放现象、MAR的介入合流。默认目标是找回孩子、取得治疗所需资料并让他们苏醒，而非镇压一群有意作乱的能力者。
玩家可由春上转学、地震现场救援或风纪委员调查进入；不因同月发生其他事件而自动切走当前锚点。

== 2. 不可丢失的核心事实 ==
- 春上衿衣搬入初春宿舍，寻找的朋友是木山春生的学生枝先绊理。检查并未证明春上是制造骚动的犯人，不能凭她在场便定罪。
- 木山曾照顾的孩子在木原幻生的能力实验后持续昏迷；木山获保释后仍试图救他们。昏迷孩子不是自愿参与新一轮实验的兵器队伍。
- 泰瑞丝缇娜·木原·莱夫莱恩是先进状况救助队MAR的负责人，以保护孩子为名接管他们；不是保育员或艺人。其木原关系与接管行为须通过调查揭露。
- Capacity Down通过声音干扰能力运算，使影响范围内的能力者难以发挥能力；不是随意切换为全城失控的开关。佐天作为无能力者破坏装置，是默认反击链的关键。
- 默认决战中美琴等夺回孩子、击败泰瑞丝缇娜，木山输入治疗程序使孩子苏醒。春上与枝先重逢；孩子为住院的木山庆生属于后日谈。

== 3. 玩家可改写的部分 ==
可改变追查顺序、救援分工、治疗资料的取得方式、装置及涉案人员的处置，也可提前识破MAR。提前救人成功便承认成功，不再制造同样绑架以凑齐节点。玩家可使用已有能力、道具或协作寻找替代解法，不强制承担原作角色的位置。

== 4. 节点推进表 ==
使用完整节点ID；每轮最多推进一个主要节点。提前解决的问题记为事实，不重复演出。

POLTERGEIST-01 暴走的传闻
进入条件：选定本篇，或八月上旬调查乱杂开放现象。
场景目标：从地震与异常震动中识别需要救援的现场。
可见角色：初春饰利、风纪委员、受影响居民。
玩家行动：疏散、记录发生地点、询问目击者或协助搜查。
结果：取得骚动时间与人员接触线索，不先判某名学生有罪。
下一节点：POLTERGEIST-02。

POLTERGEIST-02 室友与朋友
进入条件：接触初春的新室友春上。
场景目标：听取寻找枝先绊理的请求，建立失踪者线索。
可见角色：春上衿衣、初春饰利、佐天泪子。
玩家行动：陪同查找、确认旧照片、核对去向或暂缓答复。
结果：枝先与实验后昏迷孩子的关系成为调查方向。
下一节点：POLTERGEIST-03。

POLTERGEIST-03 花火与公园的骚动
进入条件：陪同活动或赶到新一次乱杂开放现场。
场景目标：先保护现场人员，再核对春上与现象的关系。
可见角色：春上衿衣、御坂美琴、白井黑子、MAR人员。
玩家行动：救援、保护证人、接受检查或独立比对记录。
结果：春上的嫌疑不等于事实；MAR的专业介入进入视野。
下一节点：POLTERGEIST-04。

POLTERGEIST-04 木山的学生
进入条件：调查枝先下落或发现木山已经获保释。
场景目标：找到持续昏迷的孩子，理解木山未完成的救治。
可见角色：木山春生、御坂美琴、昏迷的孩子。
玩家行动：查病历、听取说明、协助治疗或联系可信救援。
结果：确认孩子与旧实验的联系，不能把治疗需要误写成再次制造暴走。
下一节点：POLTERGEIST-05。

POLTERGEIST-05 MAR的保护承诺
进入条件：泰瑞丝缇娜提出接管，或玩家追踪已经转移的孩子。
场景目标：核对接管权限、去向和她与木原研究的关系。
可见角色：泰瑞丝缇娜、木山春生、春上衿衣、MAR人员。
玩家行动：质询、跟踪转移、核查资料、阻止交接或假意配合。
结果：默认发现保护承诺中的骗局；提前保住孩子则记录偏移。
下一节点：POLTERGEIST-06。

POLTERGEIST-06 孩子与治疗资料
进入条件：已确认骗局，或握有接近实验设施的线索。
场景目标：把孩子安全与木山所需治疗资料一起纳入救援。
可见角色：木山春生、春上衿衣、御坂美琴、泰瑞丝缇娜一方。
玩家行动：追踪设施、夺回资料、联络伙伴或安排转运。
结果：确定救援对象和路线；不把所谓First Sample误当整批幼童的代称。
下一节点：POLTERGEIST-07。

POLTERGEIST-07 Capacity Down
进入条件：突入遭到能力干扰，且装置尚未被排除。
场景目标：在能力运算受干扰时保护队伍并定位声源装置。
可见角色：佐天泪子、御坂美琴、白井黑子、初春饰利。
玩家行动：掩护佐天、物理破坏装置、隔离声源或执行已有替代方案。
结果：默认由佐天破坏装置，能力者恢复反击条件；不凭空扩成全城失控。
下一节点：POLTERGEIST-08。

POLTERGEIST-08 夺回孩子
进入条件：救援路线已打开，或玩家的替代救援达到终局。
场景目标：阻止泰瑞丝缇娜继续利用孩子，保障木山完成治疗。
可见角色：泰瑞丝缇娜、木山春生、春上与枝先、美琴等人。
玩家行动：阻击、转运、保护治疗过程、保存证据或谈判。
结果：默认计划失败、孩子苏醒；实际伤情与处置依本次行动记录。
下一节点：PG-END-A／PG-END-B／PG-END-C／PG-END-D。

== 5. 分支和偏离规则 ==
调查顺序改变不换锚；核心救援被提前完成则记已改写。玩家退出后只按仍成立的背景因果推进，不保证所有人必然获救，也不强行拉回。装置、治疗资料与孩子的安置不能在后篇无故重置。

== 6. 换篇条件 ==
POLTERGEIST-08完成，或玩家明确退出、另选锚点、跳时越窗，或事件因已发生的行动合理终止，才可关闭本篇。记录状态、原因与新篇首节点；不自动抢入妹妹篇或其他同期包。

== 7. 防剧透边界 ==
本篇可揭露与孩子有关的体晶实验和木原关系，不把它们当成禁说词；但不提前展开大霸星祭后续研究。美琴对妹妹实验的认识按当前经历，不能提前继承未来情报。魔法侧与小说主干不替代本动画事件的因果链。
