【事件包：乱雑開放篇】
事件包ID：POLTERGEIST
所属阶段：阶段1尾声·旧约·禁书降临季（绝对能力者进化前夜）
时间窗口：8月上旬（8月10日收束）
别名与触发词：乱雑開放 / 乱杂开放 / Poltergeist / 暴走能力 / 灵现象 / 泰瑞丝缇娜 / Capacity Down / 春上衿衣 / POLTERGEIST

== 1. 核心定位 ==
本篇是阶段1尾声的科学侧战斗事件：学园都市频发"能力者不使用能力却引发现象"的集体暴走（Poltergeist/乱雑開放现象），暗线是木原系研究者泰瑞丝缇娜·木原·莱夫莱恩以"First Sample"实验幼童为核心，借 Capacity Down 大范围能力抑制装置推进的失控兵器计划。事件主题是"被滥用的天才与被夺走的童年"——白天的日常喜剧与收束时的热血决战并行。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段1尾声因亲历暴走现象、风纪委员委托、身边能力者失灵而卷入。玩家立场自由：调查者、救援者、官方协作者、追查真相的独行侠，或与泰瑞丝缇娜周旋谈判的搅局者。

== 2. 不可丢失的核心事实 ==
- Poltergeist 现象：与能力者相关的未解释现象频发——重力异常、发火、真空爆破式现象在当事人无意识下爆发，官方以"集体性能力失控"低调处理，坊间流传"灵现象"传闻。
- 泰瑞丝缇娜·木原·莱夫莱恩：木原幻生的孙女（此事并非世界观级机密，可正常写明）；学园都市上层出身的年轻研究者，表面身份明快亲和、常以保育与艺人相关身份活动，实则以幼童实验推进木原系研究。
- "First Sample"：一批被用于能力开发实验的幼童，其中包含春上衿衣幼年分别的幼驯染；他们被泰瑞丝缇娜一方的设施控制。
- Capacity Down：大范围能力抑制装置——可让范围内能力者无法正常使用能力，也可切换为诱导失控。对玩家同样有效：被抑制期间玩家需靠体术、道具与协作战斗（这是战斗玩法特色边界，不是惩罚机制；不判死亡，不设数值代价）。
- 春上衿衣：初春饰利的新室友，柔弱怯生却共情力极强，为寻找幼年分别的幼驯染而接触相关设施，是幼童线的日常入口。
- 官方（警备员、风纪委员）在追查暴走事件；御坂美琴、白井黑子、初春饰利、佐天泪子按原著路径卷入，8月10日前后在地下设施决战泰瑞丝缇娜、救出幼童。
- 木原幻生不直接登场：泰瑞丝缇娜的计划借木原系资源，但本篇不展开木原幻生本人的深层实验。

== 3. 玩家可改写的部分 ==
- 调查顺序与方式：可以先追暴走现场、先接近春上衿衣与幼童线、先盯上泰瑞丝缇娜本人，或直接黑入官方数据网。
- 对泰瑞丝缇娜的处置：阻止、谈判、假意合作、揭发，或寻找"不牺牲任何一方"的替代方案，均合法。
- Capacity Down 的去向：摧毁、夺取、上交官方、公开其存在，或暗中留一手，都是玩家自由。
- 幼童案的结局：原著中的遗憾可由玩家改写为更好的结果（提前救人、改变收束顺序、为幼驯染争取更好安置）。
- 是否扬名：暴走事件频发的敏感期，玩家每次出手都可能被官方或坊间记录。
- 玩家能力可自由发挥（含跨体系混用，无反噬无代价）；被 Capacity Down 抑制期间的智斗是本篇特色玩法。

== 4. 节点推进表 ==
节点ID格式：POLTERGEIST-{NN}（必须使用完整ID，禁止简写如PG-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

POLTERGEIST-01 暴走的传闻
进入条件：进入本篇时间窗（开局锚点选定或阶段1推进至此）。
场景目标：玩家从新闻、同学闲谈或风纪委员渠道得知近期频发的"能力失控"事件。
可见角色：同学、路人、新闻、初春饰利（风纪线入口）。
玩家行动：追问细节、亲赴现场、忽略日常、结识知情者。
结果：玩家获得 Poltergeist 事件线索；相关 NPC 关系初始化。
下一节点：POLTERGEIST-02。

POLTERGEIST-02 室友与公园
进入条件：玩家接触初春饰利、其室友春上衿衣，或探访幼童相关设施。
场景目标：春上衿衣与"寻找幼驯染"的执念进入视野；设施里的幼童透出不对劲。
可见角色：春上衿衣、初春饰利、设施幼童、保育相关人员。
玩家行动：结伴调查、安慰春上衿衣、私下潜入、向风纪委员上报。
结果：玩家发现幼童与暴走事件存在关联的蛛丝马迹。
下一节点：POLTERGEIST-03。

POLTERGEIST-03 暴走现场
进入条件：玩家亲历一次大规模暴走现象。
场景目标：街区级暴走事故——重力异常、发火、真空爆破无差别发生，玩家面临救援与压制的抉择。
可见角色：受灾市民、警备员、御坂美琴、白井黑子。
玩家行动：救援、灭火、协助疏散、追查暴走源头、保护身边人。
结果：玩家成为事件亲历者；暴走的规律性开始显形（并非随机）。
下一节点：POLTERGEIST-04。

POLTERGEIST-04 抑制的影子
进入条件：玩家调查暴走规律或能力者失灵现象。
场景目标：Capacity Down 的存在浮出水面——有人能大范围抑制或诱发能力，暴走是被制造出来的。
可见角色：受害者能力者、调查人员、回收装置残片的可疑人。
玩家行动：追装置残片、比对失灵地点、试探被抑制、寻找设施。
结果：玩家确认"有人在操纵失控"，并把矛头指向木原系资源。
下一节点：POLTERGEIST-05。

POLTERGEIST-05 白手套的研究者
进入条件：玩家循线接近泰瑞丝缇娜本人或其活动圈。
场景目标：泰瑞丝缇娜以亲和表面接触玩家；动机疑点与其保育相关活动重叠。
可见角色：泰瑞丝缇娜、其随员、春上衿衣（可同行）。
玩家行动：虚与委蛇、当面试探、跟踪、摊牌、或与官方共享情报。
结果：玩家与其正面接触；她的真实目的开始逐层揭示（不一次性托出）。
下一节点：POLTERGEIST-06。

POLTERGEIST-06 First Sample
进入条件：玩家追查幼童线索或与泰瑞丝缇娜关系升温。
场景目标：幼童诱拐实锤——"First Sample"实验幼童被控制在设施中，春上衿衣的幼驯染在其中。
可见角色：被害幼童、春上衿衣、设施守卫、官方搜查人员。
玩家行动：救人、搜集证据、联络风纪委员与警备员、与泰瑞丝缇娜对峙。
结果：玩家掌握实锤；泰瑞丝缇娜的计划进入执行阶段，时间压力出现。
下一节点：POLTERGEIST-07。

POLTERGEIST-07 Capacity Down 启动
进入条件：计划执行或玩家行动触发提前启动。
场景目标：大范围能力抑制发动——城市内能力者纷纷失灵或失控，玩家能力亦被抑制，进入非常态战斗。
可见角色：暴走能力者、御坂美琴四人组、被困市民。
玩家行动：靠体术/道具/协作组织救援与反击、抢修或破坏装置、掩护美琴等人推进。
结果：抑制网出现缺口；决战条件成立。
下一节点：POLTERGEIST-08。

POLTERGEIST-08 地下设施决战
进入条件：抑制网突破后直捣设施。
场景目标：与泰瑞丝缇娜决战并救出幼童；春上衿衣与幼驯染的命运迎来收束。
可见角色：泰瑞丝缇娜、被害幼童、春上衿衣及其幼驯染、御坂美琴四人组、官方。
玩家行动：决战、谈判、救人优先、公开一切、或按自己的方案收尾。
结果：事件收束（见收束结果）；世界线记录与偏移事实写入。
下一节点：无（收束节点）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：玩家改变调查顺序、救人顺序或人物关系但事件主题仍在→保留当前锚点，切换到事件包内相应节点。
- 核心结果改写：玩家提前摧毁 Capacity Down、让计划流产、或公开木原系黑幕→保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 明确离开：玩家主动跳过/退出/时间跳跃→记录原因后关闭本篇，事件按背景因果自行发展（暴走事件迟早被官方压制），不强行拉回。
- 玩家对春上衿衣幼驯染的处置、Capacity Down 的去向属世界线事实，后续篇章可引用，但不构成本篇强制走向。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. POLTERGEIST-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过事件窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：御坂妹妹计划与绝对能力者进化实验、体晶计划、木原幻生的深层意图、AIM扩散力场理论深层。
- 绝对能力者进化篇不得在本篇提前启动；御坂美琴在本篇不得表现出知晓妹妹实验的存在。
- 魔法侧势力不得作为本篇推动力；禁书降临篇角色（茵蒂克丝、上条当麻）至多合理客串。
- Capacity Down 原理只到"大范围抑制/诱发失控"层，不上升为世界观级技术真相。
- 泰瑞丝缇娜是木原幻生的孙女属可正常写明的背景，但其研究细节按节点逐层揭示。

== 9. 收束结果 ==
- PG-END-A 原著近似收束：泰瑞丝缇娜计划被挫败并被官方逮捕，幼童获救，春上衿衣与幼驯染重逢（8月10日前后）。
- PG-END-B 玩家亲手终结：玩家主导决战与救援，木原系当众出丑，学园都市高层悄悄抹平痕迹。
- PG-END-C 谈判收场：玩家促成泰瑞丝缇娜交出装置换取条件，Capacity Down 移交流向存疑（后续伏笔）。
- PG-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
