【事件包：创约第十三卷·红雪与阿蒂迦利迦】
事件包ID：GENESIS-13
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第13卷；科隆尊复苏、都市失序与破坏魔术阻止战。
时间窗口：Y＋1年1月8日下午至午夜前后。15点后复苏、16点撤离、17点领事馆会议与夜间行动的分段依据社区梗概和译文章节，不冒称官方简介逐项证实；午夜后的追击由创约第十四卷承接。
别名与触发词：创约第十三卷 / 创约第十三卷红雪术式 / GENESIS-13

== 1. 核心定位 ==
科隆尊趁亚雷斯塔动摇重夺肉体，试图用大规模破坏魔术阿蒂迦利迦制造杀戮，继而挑起科学侧与魔法侧的全面战争。都市基础设施失常、英国清教介入、不同救援者互不信任，让“到现场击倒恶魔”远远不够。玩家要维系沟通、保护市民并拆解术式条件，不能把摧毁世界的威胁缩成一场无关他人的单挑。

== 2. 不可丢失的核心事实 ==
- 阿蒂迦利迦是破坏魔术名，不是人物、组织或新登场魔神。它针对由人类命名的土地，科隆尊选定意大利半岛，意图以灾难挑起各方互相毁灭。
- 科隆尊起初与魔神交战，随后在学园都市内继续准备；她控制并利用城市的异常，不代表所有市民或科学侧已经自愿与她结盟。
- 上条等人经撤离抵达第十二学区旧领事馆，与戴安、一方通行、浜面等商议。戴安解释术式与午夜期限，直接靠幻想杀手强闯并不足以解决所有问题。
- 英国清教内部并非同一意志。伊莎贝拉＝忒伊斯姆与史提尔、木原合计发生冲突，神裂帮助被限制行动的茵蒂克丝等人离开；木原合计在前卷自伤后并未永久死亡。
- 夜间行动从第二十三学区运输机出发，目标为无窗大楼遗址一带。科隆尊布置迷宫隔离援军，并召出莫伊娜＝马瑟斯阻挡戴安；莫伊娜与米娜同源，不能混成两个毫无关系的人。
- 上条、一方通行、浜面、泷壶、克里法拼图545等人的介入没有直接击败科隆尊。浜面尝试理解并回应她对世界的否定，原作谈话并未让她放弃发动术式。
- 原作阿蒂迦利迦已经发射；茵蒂克丝用强制咏唱令科隆尊改变目标，美琴提供无名土地的思路，将攻击转向大西洋中不满足命名条件的目标，使预定屠杀没有发生。不是发射后用火力击落，也不是美琴突然学会使用魔术。
- 科隆尊失去这一计划仍有力量和其他破坏手段。上条呼唤肉体内的亚雷斯塔造成新的动摇，本卷不把她宣布为已经消灭。

== 3. 玩家可改写的部分 ==
- 提前修复通讯、安排供暖与撤离，减少派系误会，让入城魔术师与本地救援者交换可信信息。
- 改变领事馆会议的合作结构、迷宫突破与空降方案，避免支援者被逐个隔离。
- 争取科隆尊停止行动，提前破坏术式条件，或协助改向而保护目标地；不强制她必定按原作发射。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；下午撤离、会议、入夜救援与午夜术式结果依次展开，跨现场行动不让所有人瞬间共处。

GENESIS-13-01 十五点后的肉体夺回
进入条件：GENESIS-12-08中科隆尊实际夺回肉体，或明确选择当日下午危机锚点。
场景目标：辨认亚雷斯塔已不再控制行动，保护复活后仍受伤的上条与附近人员。
可见角色：科隆尊、上条、爱丽丝、受伤的超绝者，介入冲突的奈芙蒂斯与娘娘。
玩家行动：组织撤离、传递肉体控制权变化、避免让伤者卷进魔神交战，记录科隆尊威胁的实际内容。
结果：原作众人暂时脱离正面冲突，科隆尊开始把自由转化为新的破坏计划；不把她与亚雷斯塔的意志混作同一阵营。
下一节点：GENESIS-13-02；若复苏条件此前被阻止，按玩家实际世界线善后。

GENESIS-13-02 十六点的撤离路线
进入条件：抵达地铁站附近，需要继续前往可商议与安置的地点。
场景目标：在通信与城市秩序变差时维持队伍联系，避免把领事馆当作已完成一切检查的安全结局。
可见角色：上条、爱丽丝及同行者，途中受影响的居民与设施人员。
玩家行动：核对路线、改用步行、帮助需要撤离的人，搜集茵蒂克丝与欧提努斯的线索。
结果：原作队伍继续前往第十二学区旧领事馆，临时安全空间与接下来需要共同处理的威胁相连。
下一节点：GENESIS-13-03。

GENESIS-13-03 十七点领事馆作战会议
进入条件：上条等人抵达旧领事馆，戴安与各方参与者开始交换情报。
场景目标：理解阿蒂迦利迦的目标条件、午夜期限及会引发战争的后果，明确分工。
可见角色：上条、爱丽丝、戴安＝福琼、浜面、泷壶、木原脑干等参与者；一方通行依其实际联络方式加入。
玩家行动：追问术式与地形依赖、确认不能只靠单人强闯的理由，安排情报、伤员、市民保障与接近核心的路线。
结果：原作形成阻止科隆尊的共同任务；幻想杀手是一种突破手段而非自动胜利，失控的电力、燃气与供水也成为必须处理的现实问题。
下一节点：GENESIS-13-04。

GENESIS-13-04 日落后的管辖冲突与解缚
进入条件：英国清教魔术师进入都市并扩大控制，茵蒂克丝等人的行动受到限制。
场景目标：阻止各方把需要合作的人继续当成敌人，让掌握术式知识者能够参与救援。
可见角色：茵蒂克丝、欧提努斯、神裂；另处的伊莎贝拉、史提尔、经医疗救回的木原合计，美琴与食蜂分别处理本地异常。
玩家行动：在所在现场核实命令与被限制者意愿、协助神裂的放行、联络美琴与食蜂，避免卷入无关的处置权争夺。
结果：原作神裂帮助茵蒂克丝等离开拘束，美琴、食蜂与她们汇合；伊莎贝拉与合计的冲突说明科学侧和魔法侧的死亡处置体系并不互认，不能自动当作统一指挥。
下一节点：GENESIS-13-05；尚未汇合的角色只通过实际通讯获得情报。

GENESIS-13-05 夜间空降与迷宫分流
进入条件：主要行动组在第二十三学区搭乘运输机，准备接近第七学区无窗大楼遗址一带。
场景目标：突破城市中的迷宫式隔离，把能阻止术式的人送到需要的位置。
可见角色：上条、浜面、泷壶、戴安、克里法拼图545等行动者；莫伊娜作为科隆尊召出的阻挡者出现。
玩家行动：检查空降与落点、保持分散小组通信、援助被迷宫困住者，帮助戴安应对莫伊娜而不放弃主目标。
结果：原作行动者分路接近，戴安与莫伊娜的交锋牵制一条支援线；爱丽丝、施普伦格尔等强者也会被迷宫阻挡，不能靠一句“全员到齐”跳过困难。
下一节点：GENESIS-13-06。

GENESIS-13-06 不能靠个人武力解决的恶魔
进入条件：克里法与数路行动者先后接触科隆尊，午夜期限继续逼近。
场景目标：避免各自底牌被逐一针对，给未到场的援军争取真正可用的机会。
可见角色：科隆尊、克里法、浜面与泷壶、上条，以及随后介入的一方通行；各人按实际抵达顺序出现。
玩家行动：汇总科隆尊对幻想杀手与反射的应对、保护倒下者、协调掩护与退路，寻找术式层面的突破而非重复正面冲撞。
结果：原作数路攻击未能终止仪式，科隆尊针对各人的能力与进攻方式拆解攻势，上条与一方通行等失去继续正面交战的能力；施术者仍在维持毁灭计划，必须改换解法。
下一节点：GENESIS-13-07；若玩家已实质破坏仪式，保留其成果并进入实际收束。

GENESIS-13-07 浜面的理解没有换来停手
进入条件：众人伤重，浜面仍试图与科隆尊说话，泷壶就在他身边。
场景目标：分清理解她遭遇的孤立与接受毁灭他人之间的界线，争取最后停手的可能。
可见角色：浜面、科隆尊、倒下的泷壶，上条在附近艰难观察与求援。
玩家行动：倾听双方对世界的不满、提出不以屠杀为代价的出口，保护泷壶并让其他救援者知道这里的真实情况。
结果：原作浜面表现出对科隆尊的同情，但没有让她放弃；她仍发动阿蒂迦利迦，上条在无力独自制止时向他人求救。玩家若成功说服，不强迫重演发射。
下一节点：GENESIS-13-08。

GENESIS-13-08 午夜边界的目标改写
进入条件：阿蒂迦利迦即将造成结果，茵蒂克丝与美琴获得接近机会。
场景目标：利用术式的命名条件阻止预定杀戮，而非要求受伤者再打一场必胜单挑。
可见角色：茵蒂克丝、美琴、欧提努斯、科隆尊、上条与浜面；爱丽丝、施普伦格尔等在外围提供通路支援。
玩家行动：协助传递无名土地的思路、为强制咏唱创造机会、保护倒下者，并阻止对现场立场的误判扩大冲突。
结果：原作茵蒂克丝干涉科隆尊咏唱，借美琴的思路把已发射术式改向大西洋中不符合命名条件的目标，预定屠杀未发生。科隆尊并未因此失去全部力量；上条呼唤亚雷斯塔，肉体内部出现新的动摇。
下一节点：本包收束；夺体尝试与午夜后的追击接GENESIS-14-01。

== 5. 分支和偏离规则 ==
- 原作最终使用改向术式，不排斥玩家提前阻止准备、解除命名条件或促成停手；成功后不补放一次屠杀来回正。
- 浜面对科隆尊的同情、茵蒂克丝与美琴的救援、英国清教的入城目的分别记录，不把所有人压成同一“讨伐阵营”。
- 破坏魔术失效与科隆尊被击败是两件事。若她还可行动，追击有因果；若玩家已使她安全停手，下一卷不凭空复原原作危机。

== 6. 换篇条件 ==
阿蒂迦利迦是否发动、是否造成伤亡以及科隆尊后续行动已有结果，或玩家主动退出、跳跃时换篇。午夜是本卷与下一卷的交界，不额外虚构一个休整日。

== 7. 防剧透边界 ==
术式条件随戴安说明与现场分析揭露，强制咏唱的改向办法不能预先变成全体NPC常识。莫伊娜与米娜的关系只由能够辨认者解释，普通市民首先知道的是断供、封锁和红雪，不是大恶魔的完整理论。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8，当前节点使用完整ID，阶段状态依撤离、会议、术式与收束更新。
- 正史锚点记录阿蒂迦利迦改向及科隆尊仍可行动的默认参照；玩家偏移保留提前停手、不同伤亡、谈判和救援结果，不强制回正。
- 已完成节点、可触发节点去重后整体replace；并行救援只有实际发生或收到可靠结果才写入，不伪造全员亲历。
- 城市保障、解缚、空降、术式阻止沿用任务追踪；同情、敌对、知情与生存状态沿用NPC关系、在场人物、势力关系、世界线记录，不创建名为阿蒂迦利迦的人物字段。

== 9. 收束结果 ==
默认意大利半岛没有遭受预定屠杀，全面战争的引线被拔掉，但都市伤员、迷宫与科隆尊本身尚未解决。上条对亚雷斯塔的呼唤为下一卷提供机会，浜面的同情也留下真实分歧；这不是一场全员无异议的胜利庆典。
