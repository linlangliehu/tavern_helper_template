【事件包：暗部大战篇】
事件包ID：DARK-BATTLE
所属阶段：阶段5·旧约·十月上旬
年层：Y
时间窗口：10月9日主战；随后治疗、组织变化与线索追查另记余波，不延长主战日
别名与触发词：十月九日暗部大战 / Battle Royale事件 / DARK-BATTLE / DARK-BATTLE-01
证据定位：O32；旧约15及官介；官方动画年表；O29、O31为前序，O36为后继

== 1. 核心定位 ==
围绕反乱、镊子与各自保护对象展开的一日多组织冲突。GROUP、SCHOOL、ITEM、MEMBER、BLOCK五组均有行动，不能把所有人合并成两个阵营，也不能把结尾写成暗部体系全灭。

== 2. 不可丢失的核心事实 ==
- SCHOOL夺取镊子，ITEM追击；GROUP被卷入阻止反乱的任务，BLOCK另有以卫星动作掩护佣兵与少年院行动的计划。
- BLOCK企图借结标抵达亚雷斯塔处，威胁她关心的少年；结标克服障碍反击，GROUP阻止该线。
- MEMBER的索绮特追杀使用海原身份的艾扎力；他继承她体内魔道书原典救下她，这一线不能因组织表缩写而消失。
- 芙兰达向垣根泄露ITEM情报，原作默认被麦野杀死；麦野仍逼迫濒临极限的泷壶，滨面选择保护泷壶并击败麦野。
- 垣根追最后之作并伤害初春，一方迎战；黄泉川受伤令一方暴走，最后之作制止他。
- 原作默认多组人员伤亡或离散，但GROUP仍继续活动；回收的镊子引出DRAGON线索，留给旧约19调查。

== 3. 玩家可改写的部分 ==
可提前警告组织、保全芙兰达、营救泷壶与少年院人员、阻止垣根伤人或公开情报。不因救活某人要求另一个人补死，选择一组也不强制敌视其他所有成员。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；多线以实际联络或事后报告衔接，均属9日主战。

DARK-BATTLE-01 反乱的警报
进入条件：10月9日GROUP接到应对反乱的任务，或玩家从其他组织接触异常调动。
场景目标：辨认五组各自目标，保护可能被当作诱饵的相关人员。
可见角色：GROUP成员；其他组织仅按所选视角出现。
玩家行动：核验委托、追查调动、提醒盟友或离开危险地点。
结果：多组行动开始交叉，镊子所在的研究设施成为关键地点。
下一节点：DARK-BATTLE-02。

DARK-BATTLE-02 被夺走的镊子
进入条件：SCHOOL抢夺设备，ITEM前往阻击。
场景目标：阻止垣根取得镊子，或追踪他突破防守后的去向。
可见角色：垣根、SCHOOL成员、麦野与ITEM；滨面按杂务身份支援。
玩家行动：护送设备、支援撤离、保存追踪线索、保护后勤人员。
结果：原作默认ITEM受挫，垣根夺得镊子；设备的用途还未完全揭晓。
下一节点：DARK-BATTLE-03；其他视角可交错处理尚未完成的DARK-BATTLE-04。

DARK-BATTLE-03 BLOCK与少年院
进入条件：GROUP识破卫星行动掩护下的入侵与胁迫。
场景目标：阻止佣兵和BLOCK利用少年院人员迫使结标协助刺杀亚雷斯塔。
可见角色：结标、GROUP、BLOCK成员、受威胁的少年与佣兵。
玩家行动：保护人质、截断入侵、支援结标、揭穿掩护行动。
结果：原作默认结标突破自身障碍，BLOCK计划被阻止，少年们获救。
下一节点：DARK-BATTLE-04；该线已完成则接DARK-BATTLE-05。

DARK-BATTLE-04 艾扎力与索绮特
进入条件：MEMBER行动，索绮特找到海原身份下的艾扎力。
场景目标：应对昔日同伴的追杀，并阻止魔道书原典继续吞噬她。
可见角色：艾扎力、索绮特；GROUP协作者按联络到场。
玩家行动：掩护、制止误伤、协助确认魔道书危机或争取停战。
结果：原作默认艾扎力承接她体内原典、救下索绮特，MEMBER线有具体结局而非凭名称消失。
下一节点：DARK-BATTLE-05；BLOCK线尚未处理则补DARK-BATTLE-03。

DARK-BATTLE-05 ITEM的崩裂
进入条件：SCHOOL由泄露情报突袭ITEM，麦野追究责任。
场景目标：阻止麦野处决芙兰达，并保护被继续逼迫使用能力的泷壶。
可见角色：麦野、芙兰达、泷壶、滨面；绢旗按行动位置出现。
玩家行动：预警、带离伤员、阻止处决、与滨面协作脱离追击。
结果：原作默认芙兰达被杀，滨面带泷壶逃离；若玩家已救人，后续不再强补原作死亡。
下一节点：DARK-BATTLE-06。

DARK-BATTLE-06 滨面的选择
进入条件：麦野追上滨面与泷壶。
场景目标：让泷壶脱离继续被当作消耗品的处境，阻止麦野杀害逃离者。
可见角色：滨面、泷壶、麦野。
玩家行动：救护、拖延、利用现场条件反击或谈判放人。
结果：原作默认滨面击败麦野，带泷壶寻找救治；这不是等级0永久获得新能力。
下一节点：DARK-BATTLE-07。

DARK-BATTLE-07 最后之作面前的暴走
进入条件：垣根寻找最后之作并袭击保护她的初春。
场景目标：救出被波及者，支援一方与垣根交战并阻止失控。
可见角色：一方、垣根、初春、黄泉川、最后之作。
玩家行动：疏散、救护黄泉川、保护最后之作、尝试提前结束对决。
结果：原作默认垣根败北；黄泉川受伤触发一方暴走，最后之作使他停手。
下一节点：DARK-BATTLE-08。

DARK-BATTLE-08 DRAGON留下的缺口
进入条件：各线已解决、明确委托结算或被玩家跳过，进入9日傍晚交接。
场景目标：确认幸存者与组织现状，检查回收的镊子带出的信息。
可见角色：土御门、GROUP；滨面、泷壶等在各自善后场景出现。
玩家行动：安排救治、交换必要情报、保存DRAGON代码线索。
结果：原作默认获得DRAGON线索；当日战斗结束，但暗部体系和GROUP均未因此消失。
下一节点：无（本篇结束，治疗与调查另记余波）。

== 5. 分支和偏离规则 ==
五组的结果分别记，不以某线获救自动抵销其他线。旧8个完整节点与完成记录保留；旧存档芙兰达等人的不同结局视为既成偏移，后继按其实际生死衔接。

== 6. 换篇条件 ==
DARK-BATTLE-08完成、玩家明确退出/跳时或反乱提前化解即可换篇。十月中旬可接ACQUA，17–18日前后接DRAGON；追查代码不是把主战持续数日，且不跳过英国王室的独立主干。

== 7. 防剧透边界 ==
本日只揭出DRAGON这一线索，不直接揭艾华斯全部真相。玩家获知范围随所选组织和消息渠道变化，未来调查不会被此边界封死。

== 8. 状态写回契约 ==
推进与交接同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留各线未完入口。组织、伤亡、镊子与情报偏移写主线进度.正史锚点.玩家偏移；治疗和DRAGON追查写任务追踪，不新增组织覆灭机制。

== 9. 收束结果 ==
- DB-END-A：近原作，各线冲突停下，幸存者进入善后，GROUP获得DRAGON线索。
- DB-END-B：玩家保护更多成员，改变组织离散与伤亡情况。
- DB-END-C：退出或分线结算，保留具体未完救护与调查。
- DB-END-D：原创调停或脱逃，既有暗部后继按实际状态继续。
