【事件包：暗部大战】
事件包ID：DARK-BATTLE
所属阶段：阶段5开头·旧约终章季（天赋梦路篇之后、第三次世界大战爆发前夜）
时间窗口：10月9日—10月12日（10月9日为学园都市"独立纪念日"，原著旧约15卷"Battle Royale"当日决战+三日余波）
别名与触发词：暗部大战 / Battle Royale / 暗部抗争 / 独立纪念日 / 垣根帝督 / SCHOOL / ITEM / BLOCK / GROUP / 镊子 / 滞空回线 / DARK-BATTLE

== 1. 核心定位 ==
本篇是学园都市暗部四大组织（SCHOOL/ITEM/BLOCK/GROUP）在独立纪念日单日爆发的全面内战：垣根帝督为取得与统括理事长亚雷斯塔"直接交涉权"掀起叛乱，夺素粒子工学研究所成果"镊子"、解析滞空回线；BLOCK勾结五千外部佣兵图谋刺杀亚雷斯塔；ITEM在追击中内部崩裂；GROUP受命镇压。这是暗部管理体制的总崩坏之日，也是"被组织当齿轮使用的人们"各自回答"为谁而战"的一天。事件主题是"齿轮的自立"——混战结束时，幸存者们拒绝再做任何人的棋子。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段5开始后因独立纪念日前的诡异召集令、暗部组织的招募、或目睹 第一波冲突而卷入。玩家立场自由：任一组织的协作者、游离的第三方雇佣战力、保护特定人物的独立者、或趁乱调查学园都市深层构造的探路人。

== 2. 不可丢失的核心事实 ==
- 独立纪念日召集令：10月9日，统括理事会向全暗部组织下达"抹杀垣根帝督"的召集令；GROUP额外受命歼灭BLOCK。这一天是全组织同台混战的制度性起点。
- SCHOOL：首领垣根帝督（Level 5第2位「未元物质/ダークマター」，生成"不存在的新物质"，天使般的六翼可飞行/防御/殺傷光線/未知向量冲击）；成员狱彩海美、誉望万化、砂皿緻密等；目标=打倒一方通行、取得亚雷斯塔直接交涉权；先夺素粒子工学研究所的"镊子"（超微粒物体干涉用吸着式操纵器，原为衣柜大小的箱，被垣根重组为手套状素粒子采集分析器），再利用滞空回线（アンダーライン，亚雷斯塔的极密通信网）解析情报。垣根曾一度打破一方通行的反射造成有效伤害，但最终败北、被打入濒死（"冷蔵库"状态）。
- ITEM：首领麦野沉利（Level 5第4位「原子崩し/Melt Downer」），成员绢旗最爱（窒素装甲）、泷壶理后（能力追踪/AIM追踪，体晶药物依赖）、弗兰达·塞维伦斯与滨面仕上（无能力者杂用组）；职能=监视统括理事会防止暴走。追击SCHOOL过程中，弗兰达被SCHOOL捕获、为活命泄露ITEM机密；麦野以"叛徒粛清"之名亲手用原子崩し将其杀害——ITEM就此崩裂，麦野精神崩坏。
- BLOCK：首领佐久辰彦，成员手盐惠未、山手、铁网；职能=监视学园都市与外部合作机构联络。当日叛变：黑客袭击第23学区卫星控制中心制造夺取"牛郎星2号"光学武器的假象，借GROUP之手（一方通行摧毁卫星通信地面天线，13时29分）让学园都市上空卫星监视全盲，再趁警备机器人换防时间差勾结约五千外部佣兵，以少管所诱出领路人结标淡希，企图从"没有窗户的大楼"内部摧毁亚雷斯塔的生命维持装置；伪装成山手的"海原光贵"（艾扎里）引来无人武装直升机"六枚羽"歼灭佣兵主力，剩余约百名佣兵在少管所内被一方通行与索绮特清除；佐久辰彦因挟持人质被手盐惠未亲手打倒，手盐惠未被结标淡希击败。
- GROUP：一方通行、土御门元春、结标淡希、海原光贵（实为艾扎里）；受亚雷斯塔管辖、处理"无法向光明表达的事"；当日识破BLOCK阴谋并镇压，战后继续追查幕后。
- 结果：ITEM/SCHOOL/BLOCK/MEMBER四大组织当日实质毁灭，暗部管理体制事实解体；幸存者（一方通行、滨面与泷壶）拒绝再做"组织的齿轮"；滨面带着泷壶逃亡，为避开追杀走上自立之路；麦野在后续与滨面的死斗和解后重组新生ITEM（详见原著重力线）。
- 弗兰达之死（双线）：原著默认=被麦野粛清（独立纪念日内）；玩家可改写=在弗兰达被杀前介入（救下/劝阻/藏匿/促成和解），改写后以玩家偏移事实记录，并联动越狱篇与暗部线后续。

== 3. 玩家可改写的部分 ==
- 弗兰达的命运：原著默认死亡；玩家可在其被杀前救下、阻止泄密、或在麦野动手前促成坦白与和解——均合法，死亡并非必然。
- 任何一个组织的结局：助SCHOOL成功接触亚雷斯塔（后果自负）、助GROUP提前粉碎BLOCK、护滨面与泷壶周全、或袖手旁观让历史按原著走，均合法。
- 垣根帝督的终局：败北濒死（原著默认）、被玩家所救、或以玩家原创方式退场，均可记录。
- 结标淡希是否被利用：玩家可截断BLOCK的诱饵计划。
- 玩家自身立场可在混战中随时翻转，暗部没有忠诚的义务。
- 是否公开暗部大战的存在（对表世界/媒体），玩家自选并承担后续。

== 4. 节点推进表 ==
节点ID格式：DARK-BATTLE-{NN}（必须使用完整ID，禁止简写如DB-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

DARK-BATTLE-01 召集令
触发：玩家进入10月上旬窗口并接触暗部圈层（被召集/被招募/目击异常调动）。
内容：独立纪念日前的紧张；"抹杀垣根帝督"召集令下达；四大组织各自备战；玩家接到组织接触或收到消息。
完成：玩家确定自己当日的立场（任一组织/独立/观望）。
下一节点：02。

DARK-BATTLE-02 镊子失窃
触发：01完成+当日晨。
内容：SCHOOL袭击素粒子工学研究所夺"镊子"；滞空回线解析开始；ITEM受命追击；城市里战端四起的传闻；玩家可卷入夺还/截击/旁观。
完成：镊子被夺的事实与垣根的目标曝光。
下一节点：03。

DARK-BATTLE-03 各自的战争
触发：02完成+当日昼。
内容：混战全面展开——SCHOOL袭亲船最中一线制造混乱、ITEM反袭SCHOOL、BLOCK暗中推动卫星计划；玩家在任一战线行动；弗兰达被SCHOOL捕获的情报浮现（可介入）。
完成：玩家完成一次明确的阵营行动或救人尝试。
下一节点：04。

DARK-BATTLE-04 弗兰达的算计（双线节点）
触发：03完成+弗兰达线激活。
内容：弗兰达为活命泄露ITEM机密；麦野知晓后的粛清抉择。【原著默认】弗兰达被原子崩し杀害，ITEM崩裂；【玩家改写】在麦野动手前介入——藏匿、劝和、制造"泄密是反间"的证据链，救下弗兰达。
完成：弗兰达结局按玩家选择落定（死亡/存活均记入世界线）。
下一节点：05。

DARK-BATTLE-05 BLOCK的野望
触发：04完成+BLOCK线激活。
内容：卫星控制中心假象、地面天线被毁、卫星监视全盲；五千佣兵集结城外；"没有窗户的大楼"与亚雷斯塔生命维持装置的威胁浮现；GROUP受命镇压。
完成：BLOCK阴谋被玩家方或GROUP识破。
下一节点：06。

DARK-BATTLE-06 GROUP的镇压
触发：05完成。
内容：结标淡希被诱出又反制；艾扎里以"六枚羽"歼灭佣兵主力；一方通行单骑扫平少管所百人；佐久辰彦众叛亲离；玩家可参与任一环节。
完成：BLOCK叛乱粉碎，亚雷斯塔危机解除。
下一节点：07。

DARK-BATTLE-07 垣根无强
触发：05完成/进行中+垣根线激活（可与06并行推进）。
内容：垣根借滞空回线情报横扫各组织；与一方通行决战——反射被打破的快举与最终败北；"想与亚雷斯塔直接交涉"的执念披露；濒死或被玩家改写救下。
完成：SCHOOL叛乱实质终结，垣根终局落定。
下一节点：08。

DARK-BATTLE-08 齿轮的自立
触发：06与07均完成（或玩家触发提前收束）。
内容：夜幕下的城市残火；四大组织实质毁灭、暗部管理体制解体；一方通行与滨面各自"不再做齿轮"的选择；麦野的后续走向埋线；玩家与幸存者的告别与交易；世界进入大战前夜。
完成：本篇收束，按第9章定收束结果。

== 5. 偏离与改写 ==
- 上述节点与结局是"原著重力线"，不是唯一路径：玩家可在任意节点改写目标、阵营、手段与结果。
- 篇章内偏离：允许玩家把本篇玩成佣兵日常/救援战/情报战混合剧，只要不覆盖核心事实（召集令、镊子失窃、BLOCK阴谋、暗部体制解体）。
- 核心结果改写：弗兰达存活、垣根被救、BLOCK部分得手、玩家截留某组织技术，均合法——以玩家偏移事实记录，不得静默回滚。
- 明确离开：玩家声明退出时按第9章DB-END-D收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：亚雷斯塔的真意与"计划"细节、滞空回线与艾华斯、爱华斯的存在、Level 6后续、第三次世界大战的交战内幕、英国清教与新约系势力。
- BLOCK与佣兵链只到"勾结外部势力"层级，不揭示更深理事会派系。
- 垣根"未元物质"只到"不存在的新物质+六翼"表现层，不揭示白甲虫/新生垣根与"进化后的未元物质"深层。
- 麦野的精神崩坏只呈现当日的粛清抉择与状态，其后续重组新生ITEM不展开（留作三战后暗线）。
- 魔法侧势力不得作为本篇推动力；艾扎里仅以"伪装海原光贵的GROUP成员"身份行动，其魔法侧背景不展开。

== 9. 收束结果 ==
- DB-END-A 原著近似收束：混战按原著收场，弗兰达死亡（或玩家未介入线），暗部解体，滨面与泷壶逃亡自立，一方通行继续追查幕后。
- DB-END-B 玩家亲手终结：玩家主导终局，四大组织按玩家方案处置，救下的人与截获的资源按玩家方案安置。
- DB-END-C 谈判收场：玩家促成组织间停战交易，暗部以"体面解体"收场，幸存者结成玩家主导的新秩序（脱离理事会或受监督）。
- DB-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
以上所有收束均不以玩家死亡或"失败判定"告终；NPC原著向死亡（如弗兰达默认线）只作为剧情事实呈现，不作为对玩家的惩罚判定。
