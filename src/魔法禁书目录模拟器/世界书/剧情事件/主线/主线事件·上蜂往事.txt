【事件包：上蜂往事】
事件包ID：MENTAL-PAST
所属阶段：阶段0·旧约·前日谭
年层：Y−1；《新约11》的当前叙事框架属于Y，不在此再发生。
时间窗口：前一年八月候选；初遇、人工湖、相处与死结的逐日落点仅为图排，不采用8月2／10／13–15／20日为确日。
别名与触发词：上蜂往事 / 上蜂人工湖往事 / 死结往事 / MENTAL-PAST / MENTAL-PAST-01

== 1. 核心定位 ==
本包独立展开《新约11》的过去层：相遇、相处、求援的约定、死结袭击与上条对食蜂的记忆障碍。后来蜜蚁相关的当前框架由MENTAL-STINGER承载，进入当前框架不让这些往事重新发生。
人工湖一幕只作图排候选场所；在该处的对白、活动与玩家介入是项目串场，不承诺原作逐日复刻。生物黑客是同一前一年夏天的另一段故事，不是本包的别名。

== 2. 不可丢失的核心事实 ==
- 食蜂在常盘台一年级时与上条相遇；上条此时仍是初三，不是遇见茵蒂克丝后的高中生。
- 相遇后的遗落手机与日常接触形成联系；幻想杀手能使针对上条的心理操作失效，不能把他写成可任意操纵的傀儡。
- 上条把求援用的哨子交给容易遇险的食蜂；它承载会来相助的关系，不是自动召唤或修改时间的道具。
- 死结因对高等级能力者的怨恨追击食蜂，上条为保护她战斗并严重受伤。
- 默认救援中，食蜂使用能力帮助上条，却留下他无法记住食蜂的障碍。这与Y年七月末的另一场失忆不是同一次事故。

== 3. 玩家可改写的部分 ==
可以帮助归还手机、安排安全见面、查找追踪者、参与救援或提出不造成同样后果的处理。改变伤势、记忆障碍及能否再会时明确记录玩家改写；没有依据的普通治疗不自动恢复默认障碍。可只听回忆，不强迫玩家扮成任何原作角色。

== 4. 节点推进表 ==
实际使用MENTAL-PAST完整节点ID；每轮最多推进一个主要节点，回忆中的一段相处不等于当前世界已经过去几天。

MENTAL-PAST-01 交错的路口
进入条件：玩家选择前一年上蜂往事，或当事人在当前场景愿意回顾。
场景目标：处理食蜂与上条初遇后的手机遗落，建立联系的起点。
可见角色：初三上条、常盘台一年级食蜂；按情境出现的警备员。
玩家行动：协助寻找或交还手机、留意对方去向、询问是否需要帮忙。
结果：联系有了由头，不把这一幕搬到Y年十一月亲历。
下一节点：MENTAL-PAST-02。

MENTAL-PAST-02 无法随意改写的记忆
进入条件：MENTAL-PAST-01完成，两人再次接触。
场景目标：在日常误会中呈现食蜂的心理操作不能随意左右上条。
可见角色：食蜂、上条。
玩家行动：解释误会、劝双方沟通、观察右手的干预；具体冲突采用项目串场，不展开隐私窥视。
结果：相处转为以真实交流处理问题；食蜂不能靠能力直接得到关系答案。
下一节点：MENTAL-PAST-03。

MENTAL-PAST-03 人工湖候选一幕
进入条件：MENTAL-PAST-02完成，玩家选择图排中的人工湖相处场景；也可明确略过。
场景目标：用一场可选的项目串场呈现平静相处，而不是给人工湖补造未经确定的原作事故。
可见角色：食蜂、上条、合理在场的玩家。
玩家行动：同行、交谈、履行日常约定，或说明不采用此候选场景。
结果：记录这次相处或明确跳过；不因湖边场所自动添加落水、救命或告白事实。
下一节点：MENTAL-PAST-04。

MENTAL-PAST-04 求援的哨声
进入条件：MENTAL-PAST-03完成或已被明确略过，双方已建立日常联系。
场景目标：落实上条交给食蜂的求援哨子及愿意相助的约定。
可见角色：上条、食蜂。
玩家行动：商量联络与安全安排、提醒追踪风险、陪同归途或尊重两人的约定。
结果：哨子成为可以使用的求援物件，不赋予它额外能力；具体交付日不强定。
下一节点：MENTAL-PAST-05。

MENTAL-PAST-05 死结的追击
进入条件：MENTAL-PAST-04完成，追击者接近或玩家先发现他们。
场景目标：保护被怨恨指向的食蜂，阻止死结利用围堵制造伤害。
可见角色：食蜂、上条、死结成员。
玩家行动：示警、打开退路、呼叫协助、与上条共同阻止追击，或提前化解袭击。
结果：默认上条击退袭击但受重伤；若玩家成功避战或分担冲突，按实际伤势继续。
下一节点：MENTAL-PAST-06。

MENTAL-PAST-06 为了救活眼前的人
进入条件：MENTAL-PAST-05完成，需要处理伤势或确认已无急救需要。
场景目标：完成救援；默认食蜂的能力介入救命过程并留下针对她的记忆障碍。
可见角色：食蜂、上条、实际抵达的救护人员。
玩家行动：保护急救环境、寻求替代方案、协助转运或处理已经减轻的伤势。
结果：默认上条获救却不能再记住食蜂；玩家若改变了关键条件，保留改写而非强行补伤。
下一节点：MENTAL-PAST-07。

MENTAL-PAST-07 被留下的一方
进入条件：MENTAL-PAST-06完成，救援结束并能确认关系后果。
场景目标：面对存活与失去共同记忆并存的结果，确定哨子、联系与知情范围。
可见角色：食蜂、康复中的上条或当前回忆听众。
玩家行动：陪伴、保守秘密、安排后续联系，或确认已经改变的记忆状态。
结果：默认食蜂保留这段经历，上条无法以共同记忆回应她；往事封存，不自动跳到新约当前框架。
