【事件包：理想送行篇】
事件包ID：NT-WORLD-REJECTER
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年12月3日前后，接僧正追击之后；不另造精确跨日时刻
别名与触发词：理想送行篇 / 柏德蔚姐妹救援 / 两只右手的初战 / NT-WORLD-REJECTER

== 1. 核心定位 ==
作品范围：新约14。奈芙蒂斯的求助引出上里翔流，与之交织的是柏德蔚姐妹互相牺牲的救援困局。两名少年的分歧必须落实到如何对待眼前的人，而不是只比较右手强弱。

== 2. 不可丢失的核心事实 ==
- 理想送行回应魔神对新天地的愿望而出现，上里可放逐具有相互矛盾愿望的对象。放逐不是已证实的普通死亡，也不是见到右手就无条件生效。
- 上里认为右手改变了自己和追随女孩们的人生，怀疑她们的心被力量扭曲，因此敌视魔神；上条不接受他替女孩们断定感情真假。
- 帕特莉夏在南极遭Sample Shoggoth寄生，身体脂肪被消耗。蕾薇妮雅在体内培育用于救妹妹的东西，却隐瞒成熟时自己会死；妹妹也不愿以姐姐生命换自己的生存。
- 上条提出利用克蕾儿的能力补充脂肪，排除寄生物，以避免姐妹只能活一个。原作手术受寄生物暴动与幻想杀手干涉，奈芙蒂斯用自己残存的身体补足救援。
- 最后上里仍要追究魔神，上条与他单独交锋。理想送行排除了幻想杀手后，上条体内的另一存在反击，上里重伤撤离；不能把本卷未知存在提前解释成已公开完整身份。

== 3. 玩家可改写的部分 ==
- 可协助核验理想送行的条件，保护欧提努斯，或与上里协商不伤害求助者的调查方式。
- 可提前揭开蕾薇妮雅隐瞒的代价，联络克蕾儿或其他有依据的救治途径，争取姐妹同时生还。
- 可让追随者自己解释选择，促成上里与魔神对话；不要求救援完成后必须再打一场右手决斗。

== 4. 节点推进表 ==
NT-WORLD-REJECTER-01 逃回来的奈芙蒂斯
进入条件：NT-HIGH-PRIEST-06之后，奈芙蒂斯报告魔神被放逐，玩家选择调查或保护她。
场景目标：确认放逐与普通击杀不同，判断欧提努斯等人的眼前安全。
可见角色：奈芙蒂斯、上条、茵蒂克丝、欧提努斯。
玩家行动：询问目击范围与逃脱方式，安排休息和联络，不因被称为魔神便否定她的求助。
结果：原作上条得知上里翔流及其右手，欧提努斯提醒危险；玩家可以先建立避险与谈判条件，不把听到名字等同已经接受决斗。
下一节点：接触上里或姐妹危机时进入NT-WORLD-REJECTER-02。

NT-WORLD-REJECTER-02 两团异形与姐妹的选择
进入条件：外出时与上里相遇，遭红黑两股力量交锋波及，或独立发现柏德蔚姐妹的异常。
场景目标：认出异形背后的求救者，弄清寄生与自我牺牲各自的危险。
可见角色：上条、欧提努斯、上里、蕾薇妮雅·柏德蔚；帕特莉夏及寄生物沿追踪线出现。
玩家行动：救回失去行动能力的蕾薇妮雅，协助茵蒂克丝分析，询问她隐瞒的身体代价与妹妹的意愿。
结果：原作得知帕特莉夏脂肪被寄生物夺走，姐姐企图以体内培育物替代；提前问出致命代价时，可避免继续把“救妹妹”误认为没有牺牲的方案。
下一节点：进入NT-WORLD-REJECTER-03；医疗准备可并行进行。

NT-WORLD-REJECTER-03 普通少年与追随者的心
进入条件：上里阵营截住上条谈判，或玩家主动促成双方会面。
场景目标：区分上里对右手的厌恶、女孩们自己的选择与需要立刻处理的医疗危机。
可见角色：上里、上条、克蕾儿、艾露莎等上里阵营成员；欧提努斯按实际陪同。
玩家行动：让追随者自己说明决定，质询上里“救一个就必须放弃另一个”的假设，协商先救姐妹再讨论魔神。
结果：原作上里与上条互不认同，阵营准备袭击住处；玩家可通过共同救援缓和冲突，不将拒绝上里理念记成必然开战。
下一节点：进入NT-WORLD-REJECTER-04；若袭击发生，先保护住处人员再推进救援。

NT-WORLD-REJECTER-04 不必二选一的补充方案
进入条件：蕾薇妮雅的致命代价已揭开，帕特莉夏仍受寄生物控制，克蕾儿或其他救治支援能够到场。
场景目标：提供替代脂肪，解除寄生物对维持身体状态的依赖，同时保住姐姐。
可见角色：柏德蔚姐妹、上条、上里、克蕾儿、茵蒂克丝、欧提努斯。
玩家行动：建立治疗空间，阻止姐妹互相牺牲，协调防护与注入过程，避免幻想杀手误碰仍在救命的异能。
结果：原作上里协助上条接近帕特莉夏，克蕾儿开始补充；寄生物暴动使上条在保护克蕾儿时干扰手术。玩家若事先安排隔离与防护，可保留治疗成功的偏移。
下一节点：治疗仍有缺口时进入NT-WORLD-REJECTER-05；已安全完成也进入该节点确认各方状态。

NT-WORLD-REJECTER-05 魔神做出的救援
进入条件：寄生物被提前排除造成生命危险，或玩家正在核对替代治疗的效果。
场景目标：补上实际医疗缺口，并让上里面对魔神也会为别人行动的事实。
可见角色：奈芙蒂斯、帕特莉夏、蕾薇妮雅、上条、上里及现场协助者。
玩家行动：接受或替代奈芙蒂斯提供的身体材料，继续救护姐妹，说明救援行为与对魔神群体的指控不能相互抹去。
结果：原作奈芙蒂斯以残存身体补足脂肪，救下帕特莉夏；这不是证明她在所有层面彻底不存在。若玩家已补足治疗，则不强制耗尽她的身体。
下一节点：进入NT-WORLD-REJECTER-06。

NT-WORLD-REJECTER-06 两只右手之后
进入条件：姐妹已安全，上里仍要求追究魔神，或双方准备讨论以后如何相处。
场景目标：处理右手与价值选择的分歧，避免刚救下的人重新成为争论筹码。
可见角色：上条、上里、茵蒂克丝、欧提努斯；双方伙伴留在实际安全距离。
玩家行动：促成停战、见证双方选择，若交锋则提供救护而非干预未掌握的右手机制，核对战后身体与关系。
结果：原作两人交锋，上条右手被排除后体内未知存在反击，上里重伤撤离，上条右臂恢复；玩家促成和解时不补演断手，也不强制让上里承认自己的全部观点错误。
下一节点：转校安排与上里再次接触出现、玩家选择参与时进入NT-SALOME-01；否则先处理姐妹与求助者善后。

== 5. 分支和偏离规则 ==
姐妹生死、寄生物状态、奈芙蒂斯残存身体与右手交锋分别记录。医疗救援不能被写成玩家失败后的惩罚场景；提前成功就取消对应牺牲。上里阵营成员保有自己的意愿，不设“右手自动洗脑”事实。

== 6. 换篇条件 ==
先稳定姐妹和现场人员，再决定是否继续上里相关调查。NT15的转校须继承NT13实际校舍状态；上里重伤与两人敌意只在确实发生时带入。

== 7. 防剧透边界 ==
不提前揭露木原唯一夺手、上里放逐或热浪来源；本卷未知存在只记可观察效果。理想送行的条件须经证言和实践核实，不默认能对任何人无条件施加。

== 9. 收束结果 ==
- 原作默认：姐妹获救，奈芙蒂斯付出残存身体，上里在右手交锋后撤离。
- 完整救援：玩家防止手术中断，保住姐妹并减少奈芙蒂斯的付出。
- 暂定停战：双方把分歧留待对话，右手决斗不发生。
- 分途调查：玩家保护求助者或追查理想送行，后续入学事件保持可选。
