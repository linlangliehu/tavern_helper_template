【事件包：ITEM第三卷·正义伙伴与白鸟侦探】
事件包ID：ITEM-03
所属阶段：阶段0·旧约·前日谭
年层：Y−1（前史图排）
时间窗口：官介确认夏末；8月29–31仅图排候选，不作为整卷连续确日。
别名与触发词：ITEM第三卷 / 夏末据点爆破事件 / ITEM-03 / ITEM-03-01

== 1. 核心定位 ==
据点被炸后，ITEM四人失去落脚处，接到的新工作又被自称“正义伙伴”的竞争者抢先。麦野随后收到来自“表面学校”友人的联络，暗部竞争与她的学校生活开始交叠。
失去据点与任务被抢的追查，依次牵出Sadistic Dolls、Frees、麦野的同学白鸟炽媚，以及风纪委员000支部的特别例外清扫队。原作默认不是找到住处便结束：白鸟死去，麦野在末场留下活口，之后又面对“暗部天敌”第六位的质问。

== 2. 不可丢失的核心事实 ==
- 默认起点是夏末据点遭爆破、四人无处落脚；若玩家此前保住据点，不为复刻开场再炸一次。
- 新工作的功劳被另一方抢走；对方自称“正义伙伴”，不代表旁白已经认定其正义或知道全部动机。
- 学校友人是白鸟炽媚（白鳥熾媚／Shiratori Okibi），她也是追查事件的侦探，想将麦野从暗部拉回光明；善意与交战并存，不是下一卷麦野本家的代称。
- 这些“正义”组织并不等于整个风纪委员系统。幕后联络者为了防备真正的第六位而聚集力量；这层动机不应提前灌给普通成员。
- 白鸟默认死于与ITEM的冲突并留下情报；冷冻仓库最后一战中，绢旗阻止麦野继续杀戮，特别例外清扫队被击败但没有被补杀。
- 后日谈第六位的形貌、名字与能力没有在此落实。其影子消失不代表麦野打倒了本人，也不能与卷一女贞木的自称合并。

== 3. 玩家可改写的部分 ==
可以保住据点、追查爆破、提前揭开竞争者的关系、救下白鸟或阻止末场杀戮。玩家的救援可以改变默认死亡；与第六位交谈也不自动查明其真名和能力。

== 4. 节点推进表 ==
使用ITEM-03完整节点ID；每轮最多推进一个主要节点。

ITEM-03-01 无处落脚的夏末
进入条件：玩家选择本卷；接续ITEM-02时须明确转入夏末的新任务。
场景目标：确认四人安全、可用物资与据点损失，先找能短暂停留的地方。
可见角色：ITEM四人、实际在场的玩家及可联络的委托方。
玩家行动：清点人员、查看安全范围内的爆破痕迹、取回物资或协助临时安置。
结果：默认四人失去据点，新工作又被抢先，必须在缺少落脚处的情况下追查；若玩家已保住据点，不补炸一次。
下一节点：ITEM-03-02。

ITEM-03-02 从农业楼追到女仆咖啡厅
进入条件：ITEM-03-01完成，四人能够处理新委托。
场景目标：从农业楼Clone Complex的任务追到犯罪计划中介“きずな屋”，定位抢功者。
可见角色：ITEM四人、中介相关人、Sadistic Dolls。
玩家行动：核对任务现场、取得中介情报、潜入女仆咖啡厅，或争取在交锋前问明对方的“正义”。
结果：调查引向Sadistic Dolls并发生交战；不把击败这一组当成全部竞争者都已消失。
下一节点：ITEM-03-03。

ITEM-03-03 Frees与学校友人的另一面
进入条件：ITEM-03-02完成，追查继续指向Frees，麦野收到学校友人联络。
场景目标：在凉亭附近的交锋中识别竞争者之间的关系，以及白鸟已深入案件的事实。
可见角色：ITEM四人、Frees相关人、白鸟炽媚。
玩家行动：交涉、支援交锋、核对雨川的去向，或要求白鸟解释她掌握的线索。
结果：默认白鸟此前杀死Frees的雨川，在对峙中透露部分身份后离开；麦野无法再把她当成与暗部完全无关的学校联系人。
下一节点：ITEM-03-04。

ITEM-03-04 冰之宫殿的侦探
进入条件：ITEM-03-03完成，双方在第十六学区冰之宫殿再度相见。
场景目标：面对想把麦野拉回光明、却以战斗和秘密逼迫她的白鸟。
可见角色：白鸟、麦野、芙兰达、泷壶、绢旗。
玩家行动：听取白鸟的情报、寻找停战条件、支援队友摆脱她的攻击，或争取救治窗口。
结果：默认白鸟败于麦野与芙兰达的交锋，留下搜集的情报和遗言后死亡；玩家救下她则保留生存与证词，不按原结局补死。
下一节点：ITEM-03-05。

ITEM-03-05 冷冻仓库留下活口
进入条件：ITEM-03-04完成，白鸟留下的线索指向风纪委员的隐秘处刑力量。
场景目标：在冷冻仓库对抗000支部特别例外清扫队，解救被控制住的队友。
可见角色：ITEM四人、Inoue Fox等特别例外清扫队成员。
玩家行动：解围、阻止致命攻击、配合绢旗制止麦野，或让双方看见彼此没有掌握的案情。
结果：默认清扫队被击败，麦野在绢旗与白鸟留下的影响下收手，没有杀死倒下的成员；普通风纪委员只知道同僚遇袭，不会自动得知整场暗部交易。
下一节点：ITEM-03-06。

ITEM-03-06 第六位的质问
进入条件：ITEM-03-05完成，暗部房产中介恢复与四人交易，麦野在后日谈另遇异常人影。
场景目标：回应第六位对麦野以恐惧维系队伍的质问，守住同伴而不把碰到影子当作获胜。
可见角色：麦野、被称为“暗部天敌”的第六位之影；其余队员没有自动看见这次接触。
玩家行动：若实际在场可介入交谈或支援；否则只能在麦野愿意透露后追问，不强开全知视角。
结果：默认第六位注意到麦野刚才选择不杀人，留下改变的可能后影子消失；麦野未击败其本人，仍决意保护ITEM。四人的住宿恢复，白鸟的死亡与这次收手都留下影响。
下一节点：无；秋初另选ITEM-04-01，不在本轮同时推进。

== 5. 分支和偏离规则 ==
可保住据点、提前交涉、救下白鸟或使清扫队停止处刑。已改变的关系与伤亡不重置；即使玩家改变末场选择，第六位的身份也不能仅凭一个称号被补全。

== 6. 换篇条件 ==
ITEM-03-06完成、局部目标提前达成，或玩家明确退出／换锚点时换篇。记录当前状态、换篇原因、玩家偏移与下一包首节点；夏末到秋初的时间跳转需要明确选择。

== 7. 防剧透边界 ==
不把Y年的暗部大战命运提前套在四人身上，不将白鸟直接认作下一卷家族关系人。电话女声与木原脑干在幕后得知的组织关系，不等于麦野或普通风纪委员已知；不在此确定第六位的真名与能力。
