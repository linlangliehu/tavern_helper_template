【事件包：创约第一卷·平安夜袭击】
事件包ID：GENESIS-01
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第1卷；新约22R之后的新事件。
时间窗口：本篇Y年12月24日。平安夜有官方卷简介支持；具体行动依卷内因果推进。
别名与触发词：创约第一卷 / 创约第一卷平安夜袭击 / GENESIS-01

== 1. 核心定位 ==
圣诞街景下，新任统括理事长一方通行的清理暗部方针招致既得利益者反击。根丘则斗利用舞殿星见夺取最后之作，企图牵制一方通行；上条当麻从节日出游被卷入人质救援，继而接触通过网络扩散魔术的R&C Occultics。玩家可从同行学生、救护协助者或调查根丘的线索接入。

== 2. 不可丢失的核心事实 ==
- 上条、茵蒂克丝、欧提努斯与御坂美琴的平安夜日常，是本卷冲突的入口，不是整卷内容。
- 舞殿星见是遭能力开发剥夺部分日常能力的念动力使用者。她能操纵巨大物体，却失去正常使用筷子的能力；这种损失不是她劫持最后之作的正当理由。
- 上条被舞殿刺伤，御坂妹为其处理伤口；救援要辨认舞殿制造的诱饵与真正运送人质的路线。
- 根丘是统括理事会成员，主张控制而非消灭暗部。他借R&C Occultics提供的魔术对抗追查，不能只按普通无能力成人处理。
- 原作中最后之作获救，舞殿被击败，根丘交由警备员处置；安娜＝施普伦格尔随后以吻将黑色药丸送入上条体内，成为次卷危机的直接原因。

== 3. 玩家可改写的部分 ==
- 提前保护最后之作、揭穿运输诱饵，或在舞殿刺伤上条前介入；伤势只继承实际发生的事实。
- 以沟通、支援或战斗让舞殿停止绑架，改变她与受害者的关系，不把挽救她等同于免除责任。
- 保存根丘与R&C的联系证据、阻止其伪装受害者；也可阻断安娜的接触，使后卷按不同暴露对象接入。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；以下完整ID是节点字段唯一写法。

GENESIS-01-01 平安夜的同行者
进入条件：选择本卷锚点，或在12月24日接近上条一行。
场景目标：从补习、购物与节日街景建立同行关系，察觉都市权力更替后的不安。
可见角色：上条当麻、茵蒂克丝、欧提努斯、御坂美琴。
玩家行动：同行、协助寻找同伴、调查街头异常；尚未获知的暗部内幕不直接告知NPC。
结果：确定玩家与现场的联系，平安夜人流成为袭击与救援的实际环境。
下一节点：GENESIS-01-02。

GENESIS-01-02 舞殿的袭击与人质
进入条件：玩家目击袭击，或接到最后之作遇险的消息。
场景目标：确认舞殿的行动目标是带走最后之作，分开处理伤员与追踪任务。
可见角色：舞殿星见、最后之作、上条当麻、御坂妹。
玩家行动：阻挡刺击、急救、保护路人、追查运送人质的设备；不因看见抛入河中的袋子就认定人质落水。
结果：原作上条负伤后接受御坂妹处理；玩家可减少伤害或先夺回人质，实际处置决定追踪条件。
下一节点：GENESIS-01-03。

GENESIS-01-03 被夺走的日常
进入条件：追上舞殿，或已保护人质而仍需制止她的破坏。
场景目标：在巨大物体造成的街区威胁中接近舞殿，听清她的损失与受制处境。
可见角色：舞殿星见、上条当麻、最后之作；美琴按所在位置支援。
玩家行动：疏散、拆解念动力攻击、劝她停止迁怒，也可展示不再依附根丘的替代出路。
结果：原作舞殿被上条击败，最后之作获救；她的联络信息把幕后指向根丘，而非宣告暗部从此不存在。
下一节点：GENESIS-01-04；若幕后已因玩家行动被合法控制，可转GENESIS-01-06核对结果。

GENESIS-01-04 根丘的受害者剧本
进入条件：获得舞殿的联络线索，调查第十五学区根丘所在高楼。
场景目标：阻止根丘以自伤与舆论倒置掩盖绑架，避免把警备员塑造成无故袭击者。
可见角色：根丘则斗、其医生与驾驶员、上条当麻、御坂美琴、茵蒂克丝。
玩家行动：保存证据、保护楼内平民、辨认医疗与转移安排，或向警备员交付可核验信息。
结果：根丘被迫暴露行动；上条一方发现其力量不遵循学园都市常见能力开发路径。
下一节点：GENESIS-01-05。

GENESIS-01-05 网络魔术的使用者
进入条件：根丘以R&C提供的魔术反击。
场景目标：结合茵蒂克丝、欧提努斯的魔术判断与现场支援，停止根丘继续伤人。
可见角色：根丘则斗、上条当麻、御坂美琴、茵蒂克丝、欧提努斯。
玩家行动：保护撤离路线、配合破除术式、揭破其以牺牲人质维持秩序的说辞，或提出能落实的拘束方案。
结果：原作根丘败北并交给警备员；R&C作为外部魔术传播渠道仍在运作，不能用抓获根丘替代处理它。
下一节点：GENESIS-01-06。

GENESIS-01-06 雪夜收场与安娜之吻
进入条件：人质与根丘事件已收束，或玩家已使这条袭击链提前终止。
场景目标：确认伤员、人质与证据去向，面对安娜＝施普伦格尔主动现身。
可见角色：上条当麻、茵蒂克丝、御坂美琴、欧提努斯、安娜＝施普伦格尔。
玩家行动：送医、询问R&C、警戒不明药丸、阻止身体接触，或按已发生的接触安排救护。
结果：原作安娜恢复成人外观并以吻投药，上条转入住院危机；若玩家阻止投药，保留该事实，不补演一次强制中招。
下一节点：本包收束；实际发生中招或同类危机且选择续接时进入GENESIS-02-01，否则保留改写后的平安夜后续。

== 5. 分支和偏离规则 ==
人质先救出不等于根丘已落网；证据与实际控制状态分别叙述。舞殿的遭遇可以成为和解线索，但不要求玩家同意她的行为。安娜的登场不能撤销玩家已经建立的隔离与保护。支线不覆盖当前主线定位，不用偏移等级决定胜负或惩罚。

== 6. 换篇条件 ==
GENESIS-01-06完成、玩家明确离开或选择新锚点、明确跳过时间窗口，或事件因玩家行动合理提前终止，才可换篇。记录已完成／已跳过／已延后／已改写、换篇原因及新包首节点。次卷主日为12月25日，不能在本包尚未收束时自动启动。

== 7. 防剧透边界 ==
舞殿与根丘的联系按调查逐步揭露；R&C的危险先呈现为本次魔术支援与安娜介入。不得让现场人物提前知道手铐行动的结局、桥架结社、CRC或次年科隆尊再战。
