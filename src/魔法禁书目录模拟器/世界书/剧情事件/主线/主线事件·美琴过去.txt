【事件包：美琴过去篇】
事件包ID：MIKOTO-PAST
所属阶段：阶段0·旧约·前日谭
时间窗口：2月20日前后（回忆性时间窗）
别名与触发词：美琴过去 / 美琴的回忆 / 超电磁炮的名号 / 常盘台往事 / 御坂美琴的起点 / MIKOTO-PAST

== 1. 核心定位 ==
本篇是阶段0的角色回忆型主线事件：围绕御坂美琴初获"超电磁炮"名号前后的往事展开。本篇的独特之处在于"回忆窗"性质——玩家可以通过时空锚点进入这段时间亲历往事，也可以在当前时间线中通过与美琴/黑子/佐天等相关者的交流、旧物、旧档案来参与这段记忆的重述。
两种进入模式都合法，且可混合：亲历模式（时间窗内目击与介入）和重述模式（当下陪伴美琴回顾）。事件主题是"名号之重"——一个称号背后稚嫩但拼命的努力。

== 2. 不可丢失的核心事实 ==
- 御坂美琴在常盘台中学就读，凭借电磁能力打出名号，最终获得"超电磁炮"（Railgun）称号。
- 初入常盘台时她曾是.Level 2 左右的中位能力者，经过大量自主训练（著名的掷硬币练射）稳步升级——名号是练出来的，不是天生的。
- 白井黑子在此时期与美琴结识并成为室友/搭档，仰慕与拌嘴并存。
- 美琴性格的底色在此时期成形：路见不平必出头、对弱者天然的守护欲、用拳头（电击）讲道理。
- 常盘台的名门氛围与"大小姐"标签是美琴日常烦恼的一部分。
- 本篇发生在幻想御手篇之前的时间窗，此时美琴只是常盘台内部小有名气的学生，尚未成为都市级知名能力者。

== 3. 玩家可改写的部分 ==
- 亲历模式：玩家可以介入美琴成名的关键场合（比试、纠纷、训练陪伴），甚至参与她获得名号的那一击。
- 重述模式：玩家可以通过提问、翻旧档、重访旧地，挖掘美琴从未对人提起的细节。
- 玩家可以成为美琴的练习对手、情报帮手、或在她第一次出手时在场的证人。
- 与黑子、佐天、初春的早期互动可由玩家改变（结识顺序、关系深度）。
- 本篇的世界线影响以"关系与细节"为主，不改变后续大事件的结构（防剧透边界约束）。

== 4. 节点推进表 ==
节点ID格式：MIKOTO-PAST-{NN}（必须使用完整ID，禁止简写如MP-01）。每轮最多推进一个主要节点。

MIKOTO-PAST-01 往事之门
进入条件：进入本篇时间窗（锚点选定）或在当下剧情中触发美琴回忆话题。
场景目标：进入回忆窗的第一场戏——常盘台的日常，美琴还是个"有点本事的新生"。
可见角色：御坂美琴、白井黑子、常盘台学生。
玩家行动：以同学/转学生/访客身份融入，或在当下开启回忆对话。
结果：回忆线开启，玩家获得美琴早期形象与人际关系基线。
下一节点：MIKOTO-PAST-02。

MIKOTO-PAST-02 硬币与靶场
进入条件：玩家接触美琴的训练日常。
场景目标：目击或参与美琴标志性的掷硬币练射与能力训练。
可见角色：御坂美琴、（可选）黑子、训练场人员。
玩家行动：陪练、递硬币、吐槽、切磋、或记录观察。
结果：玩家理解"超电磁炮是练出来的"；与美琴关系升温。
下一节点：MIKOTO-PAST-03。

MIKOTO-PAST-03 名门的烦恼
进入条件：玩家深入常盘台生活圈。
场景目标：名门校规、大小姐文化、"要强也要体面"的束缚与美琴的应对。
可见角色：黑子、舍监、常盘台学生干部。
玩家行动：帮忙解围、一起违反小规矩、旁观吐槽。
结果：玩家看到美琴稚嫩与真实的一面；信任加深。
下一节点：MIKOTO-PAST-04。

MIKOTO-PAST-04 第一次出头
进入条件：本篇时间窗推进或玩家陪美琴外出。
场景目标：街头纠纷/欺负弱小事件，美琴第一次当众出手主持公道。
可见角色：美琴、被欺负者、闹事者、（可选）佐天泪子或初春饰利的早期身影。
玩家行动：协助、观战、拦住她别把事闹大、或替她收尾。
结果："用拳头讲道理"的行事风格成形；美琴开始小有名气。
下一节点：MIKOTO-PAST-05。

MIKOTO-PAST-05 挑战者来了
进入条件：美琴名气上升。
场景目标：更高位能力者或嚣张团体向美琴发起挑战，逼她面对等级差距。
可见角色：美琴、挑战者、围观人群、黑子。
玩家行动：当参谋、当陪练、当后援，或自己也下场。
结果：美琴迎难而上；名号之战的伏笔铺开。
下一节点：MIKOTO-PAST-06。

MIKOTO-PAST-06 名号之战

场景目标：决定"超电磁炮"名号的关键一战（公开比试或标志性事件）。
可见角色：美琴、对手、观众、黑子。
玩家行动：自由介入——可以见证、助阵、甚至在她的关键一击中递上那枚硬币。
结果：美琴打出成名代表作；"超电磁炮"名号开始流传。

玩家行动：陪伴、点破、帮她保持本心，或和她一起躲开风头。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变结识顺序、介入方式或名号之战的细节时，保留当前锚点切分支推进。
- 核心结果改写：允许改变名号获得的场合与方式（如玩家代打、联合取胜、或名号提前/延后出现），保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 重述模式偏离：当下的对话可以揭出与"官方版本"不同的真相细节，作为回忆的补充层。
- 本篇为回忆型事件，允许玩家不完全参与（旁观回忆流），不强制节点逐个点亮。
