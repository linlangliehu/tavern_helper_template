【事件包：美琴过去篇·新学年续段】
事件包ID：MIKOTO-PAST
所属阶段：阶段0·旧约·前日谭
年层：Y；所回顾的一年级生活属于Y−1，不是又一次入学。
时间窗口：Y年四月起，持续时间未知；图示过去篇后半151–169话与雪紫离校为候选范围，不代表每日连续战斗或某日终章。
别名与触发词：美琴过去篇 / 新学年续段 / 雪紫离校前后 / MIKOTO-PAST / MIKOTO-PAST-01

== 1. 核心定位 ==
本包承接美琴一年级生活，处理新学年的身份变化、旧室友留下的问题及关系收束；不再以一场“名号之战”解释她获得超电磁炮称号。Y−1入学、三大派阀与琉璃学姐的相识由FIRST-YEAR承载，本包不重演。
雪紫离校及151–169话归段采用图排候选；以下探访、陪练、校内调查与对峙是项目串场，不冒称逐话复刻。离校原因、旧案幕后、发卡是否涉及能力再现及终战细节未定，不预写为事实。可亲历Y年续段，也可在后来听美琴回顾；重述不倒转当前年月。

== 2. 不可丢失的核心事实 ==
- Y−1，美琴与食蜂是常盘台一年级生；雪紫是美琴同期室友，琉璃是当时的三年级学姐。美琴入学时已是Level 5，不是从Level 2入校后靠本包一战升到Level 5。
- Y年新学年，美琴升为二年级，黑子以新生身份进入常盘台。认识、入住和形成搭档不是一个瞬间；不得把她写成Y−1已住在美琴寝室。
- 雪紫离校是图排中的关系落点，不等于死亡、被开除或某一未证幕后计划得逞；具体原因与日期不强定。
- 琉璃与三大派阀先辈在Y−1的身份只属于那一学年；Y年不得把毕业者仍当在校三年级日常点名。
- “超电磁炮”的实力与人际经历可以讨论，但没有一个由本包确定的首次称号授予日。

== 3. 玩家可改写的部分 ==
玩家可陪美琴询问旧友、核对说法、保护雪紫的隐私，或帮助新生处理实际麻烦。愿意保留旧式训练、街头解围与挑战戏时，它们明确属于项目改编，不倒推出原作的“第一次”。可改变离校安排、冲突处置与是否继续联系；已发生的玩家改写不强制回正。

== 4. 节点推进表 ==
节点ID格式：MIKOTO-PAST-{NN}；实际使用完整ID。每轮最多推进一个主要节点，必须有行动、时间流逝或事件结果支持。

MIKOTO-PAST-01 学年交界
进入条件：玩家选择Y年续段，或在当前场景明确请求回顾该段往事。
场景目标：确认美琴已升二年级、旧室友关系待交接，区分眼前的新学年与Y−1记忆。
可见角色：御坂美琴、按当前场景出现的雪紫；黑子仅以Y年新生身份出现。
玩家行动：陪同整理寝室、询问联系安排，或先听完当事人愿意讲的部分。
结果：本次调查对象与所在年层明确；没有重新授予名号或自动重置NPC关系。
下一节点：MIKOTO-PAST-02。

MIKOTO-PAST-02 硬币与旧约定
进入条件：MIKOTO-PAST-01完成，美琴愿意暂离人群。
场景目标：通过一场项目改编的陪练或旧物整理，分清她亲见的事实与转述的流言。
可见角色：御坂美琴；回忆中的琉璃或雪紫不作为同时到场者。
玩家行动：陪练、询问旧约定、把传闻逐项交给美琴核对，或尊重她暂不回答。
结果：得到一条可以当面求证的联系线索；硬币练习不被解释为超电磁炮的诞生仪式。
下一节点：MIKOTO-PAST-03。

MIKOTO-PAST-03 名门的交接
进入条件：MIKOTO-PAST-02完成，玩家选择继续了解学校安排。
场景目标：在项目串场中核对离校、寝室与联系人的说法，避免把空床位当作阴谋证据。
可见角色：御坂美琴、舍监、愿意回应的校内联系人。
玩家行动：取得本人同意后问询、核对公开通知、代交物品，或停止查问隐私。
结果：区分已确认的安排、当事人的选择与仍未知的原因。
下一节点：MIKOTO-PAST-04。

MIKOTO-PAST-04 流言中的出头
进入条件：MIKOTO-PAST-03完成，出现针对旧室友或新生的议论。
场景目标：处理一场项目改编的校内纠纷，防止传闻被拿来围堵当事人。
可见角色：美琴、涉事学生；黑子若到场仍是新生，不预设成熟搭档关系。
玩家行动：制止围堵、要求拿出依据、护送当事人离开，或让可信校方介入。
结果：眼前纠纷停止或转入正式问询；这不是美琴人生第一次保护别人。
下一节点：MIKOTO-PAST-05。

MIKOTO-PAST-05 挑战说法
进入条件：MIKOTO-PAST-04完成，双方对旧事仍有不同解释。
场景目标：安排项目改编的当面对质，检验流言与证词，而非凭旧档直接宣判幕后势力。
可见角色：美琴、提出指控者、愿意作证的相关人。
玩家行动：交换证据、保护证人、协商说明范围，或以已知事实终止无根据的追索。
结果：可信证据与推测分离；不得凭空证实武林旧案、发卡权能或常盘台歼灭计划。
下一节点：MIKOTO-PAST-06。

MIKOTO-PAST-06 为眼前的人解围
进入条件：MIKOTO-PAST-05完成，玩家提出可执行的处置方案。
场景目标：执行撤回谣言、归还物品、疏散围观或制止袭扰的项目改编方案。
可见角色：美琴、涉事学生、按方案到场的协助者。
玩家行动：谈判、公开必要证据、保护退路或协力制止冲突；允许不战斗的解法。
结果：眼前的人脱离逼迫，私人物品与信息按本人意愿处理；不虚构原作终战胜负。

可见角色：美琴、雪紫或她认可的联系人；并非所有旧同学必须在场。
玩家行动：道别、约定联系、代管物品、挽留或尊重离开。
