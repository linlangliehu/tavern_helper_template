【事件包：创约第九卷·CRC医院防卫战】
事件包ID：GENESIS-09
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第9卷；CRC攻城与保护住院安娜。
时间窗口：本篇Y＋1年1月5日，数字日期依社区译文第一章。前卷4日深夜的仪式与爱丽丝遭杀害是前情，不在本卷重新发生；尾声病房已接近午夜。
别名与触发词：创约第九卷 / 创约第九卷医院防卫战 / GENESIS-09

== 1. 核心定位 ==
CRC离开结社所在地，朝第七学区医院前进，企图杀死尚未脱险的施普伦格尔。上条拒绝放弃这个曾经的敌人，都市、超绝者与魔术师临时合力建立防线。玩家既可参与城市疏散和阻击，也可保住医生、玛丽与医疗物资，让战斗拖出的每一分钟真正转化为救人的机会。

== 2. 不可丢失的核心事实 ==
- CRC的降临、爱丽丝被杀与金斯福德迎战已经发生；他不是本卷序章才由上条召来的新敌人。
- 他的行进路线从第一二学区指向第七学区医院，威胁同时涉及安娜、其他患者与城市居民。
- 都市准备多层防线，但魔法、科学或超绝者的分类不能保证单方压制CRC。各方合作建立在共同保护目标上，不是旧恩怨全部消失。
- 冥土追魂持续治疗安娜，玛丽的救治能力必须保留；原作多名参战者死亡后获得救回，这不等于受害过程不存在，也不等于所有死者都可无条件复活。
- 上条在绝境中主动失去右臂、放出龙王之力，与亚雷斯塔合力击退CRC；原作医生救活安娜，她又为失血的上条提供输血。
- 尾声揭露自称CRC者实际是Johann Valentin Andreae。复苏的爱丽丝杀死了他，茵蒂克丝与欧提努斯发现爱丽丝本身仍处异常状态；医院胜利不是全篇危机终点。

== 3. 玩家可改写的部分 ==
- 安排不同的阻击、疏散和医疗资源分工，减少居民与防卫者伤亡，不以承受原作损失作为通关条件。
- 提前分享对CRC术式和身份的有效发现，寻找不依赖龙王的阻止方式；不把上条的右手内部力量送成玩家常驻技能。
- 干预CRC败退后的处置、保护茵蒂克丝接近爱丽丝时的安全，保留与前卷不同的爱丽丝及安娜状态。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；前线与医院通过实际传递的情报配合。

GENESIS-09-01 一月五日的行进目标
进入条件：进入1月5日并选择本卷，或获悉CRC正接近安娜所在医院。
场景目标：确认攻击目标和可用准备时间，把保护一个患者与保护整座城市接起来。
可见角色：上条、冥土追魂、住院的施普伦格尔；金斯福德、亚雷斯塔按前线位置参与。
玩家行动：核对患者转移条件、联络防卫方、安排非战斗人员撤离，不把重病安娜当成随手可搬走的物件。
结果：防卫方确定医院不能被CRC任意进入，形成医疗与阻击两条相互依赖的任务。
下一节点：GENESIS-09-02。

GENESIS-09-02 临时共同防线
进入条件：都市与能够参战的超绝者、魔术师开始拦截CRC。
场景目标：组织分层防御，确保每次阻击都为搜救与治疗争取实际时间。
可见角色：参与防守的警备员、御坂美琴、阿拉迪娅等超绝者；一方通行通过可用联络统筹都市侧。
玩家行动：疏散、救治撤下的伤员、转递术式观察，避免让不相容的攻击彼此妨碍。
结果：原作多层防线未能彻底挡住CRC，他继续逼近医院；玩家可改变损失和推进速度，不凭头衔宣告敌人必败。
下一节点：GENESIS-09-03。

GENESIS-09-03 医院不能只剩战场
进入条件：CRC突破外侧阻击，医院内外开始交战。
场景目标：保住安娜的治疗、其他患者安全与玛丽的持续救治能力。
可见角色：上条、冥土追魂、旧善玛丽、阿拉迪娅、亚雷斯塔、CRC。
玩家行动：守护病区、提供血液与设备、协助伤员复苏，选择将战斗引离治疗中的患者。
结果：原作参战者接连遭受重创，上条面对现有手段难以阻止CRC的局面；医疗线仍在工作，不因战斗激烈而停摆。
下一节点：GENESIS-09-04。

GENESIS-09-04 龙王与最后的协作
进入条件：医院关键防线失守，或玩家已找到可直接制止CRC的替代办法。
场景目标：阻止CRC抵达安娜面前，同时承认上条动用异常力量的真实危险。
可见角色：上条、CRC、亚雷斯塔；存活同伴以各自能力支援。
玩家行动：争取近身机会、维持上条的生命条件、配合合击，或执行已核实的非龙王方案。
结果：原作上条释放右臂内部的龙王之力，在失血等风险下与亚雷斯塔合力将CRC击退；这一步没有杀死CRC，也不能永久授予玩家同等力量。
下一节点：GENESIS-09-05。

GENESIS-09-05 病房中的互相救命
进入条件：CRC暂时离开医院，治疗与伤员处置能够继续。
场景目标：核对安娜及参战者的生命状态，把局部胜利落实为真实救治。
可见角色：冥土追魂、施普伦格尔、上条、旧善玛丽及接受救治的参战者。
玩家行动：协助医疗、核对失联者、传达各方安危，区分已救回、仍在抢救和未能救回的人。
结果：原作安娜被医生救活，并为上条输血；玛丽与医院条件使相关参战者得到救回。上条此时仍认为爱丽丝无法挽回，不提前知道另一现场的变化。
下一节点：GENESIS-09-06。

GENESIS-09-06 被揭穿的CRC与回来的女孩
进入条件：追查败退的CRC，或随茵蒂克丝、欧提努斯发现爱丽丝的异常。
场景目标：从CRC畏惧矮小液体等线索识别其扮演身份，并应对爱丽丝复苏后的危险。
可见角色：茵蒂克丝、欧提努斯、Johann Valentin Andreae、复苏的爱丽丝；上条仅按实际通信获知。
玩家行动：分享身份分析、保护接近者、阻止新的杀害，尝试与爱丽丝建立安全交流。
结果：原作自称CRC的约翰身份被揭穿，并被爱丽丝杀死；茵蒂克丝确认事情未结束。玩家若成功改变处置，不强制复制他的死亡或爱丽丝失控。
下一节点：本包收束；1月6日接GENESIS-10-01。

== 5. 分支和偏离规则 ==
- 不把“对手是恶人”写成伤害玩家或任意患者的免责条件；救援、拘束与追责可以并行。
- 若前卷安娜已脱险，本卷以真实仍存在的CRC目标与医院风险接入；若CRC降临已被阻止，不凭空复刻攻城。
- 玛丽的救治有条件，龙王是原作上条在特定情境下的选择；二者都不是通用数值奖励或死亡惩罚系统。

== 6. 换篇条件 ==
医院防卫与主要伤员处置有结果，CRC后续状态和爱丽丝异常已经交代，或玩家明确离开、跳跃、另选锚点时换篇。原作默认仍需处理爱丽丝，不在击退CRC时直接宣布整个超绝者事件结束。

== 7. 防剧透边界 ==
CRC的真实姓名与扮演机制留到调查或尾声揭露。病房中的上条不会自动拥有茵蒂克丝在另一地点获得的知识，必须经联络传递。

== 8. 状态写回契约 ==
- 主线进度沿用当前阶段“创约”、阶段序号8、阶段状态及完整当前节点ID。
- 正史锚点记录医院防卫、安娜获救与CRC尾声结局；玩家偏移保留防线损失、医疗结果及对敌处置。
- 已完成节点、可触发节点整体replace并去重；防卫、医疗与寻人任务沿用任务追踪，不把未获证实的伤亡一并结算。
- 各方临时合作、生命状态和爱丽丝消息沿用NPC关系、在场人物、势力关系、世界线记录，不新增龙王技能或复活计数。

== 9. 收束结果 ==
默认医院保住，安娜与上条得到救治，CRC在另一现场被复苏的爱丽丝杀死。救下曾经的敌人这一结果成立，但爱丽丝与茵蒂克丝的新危机需要下一卷接续；玩家的救治和处置分支不被抹掉。
