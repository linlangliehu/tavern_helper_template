【事件包：风斩冰华篇】
事件包ID：KAZAKIRI
所属阶段：阶段3·旧约·新学期
年层：Y
时间窗口：9月1日；官动层上午相识、下午地下街事件、傍晚告别
别名与触发词：风斩冰华事件 / 正体不明事件 / KAZAKIRI / KAZAKIRI-01
证据定位：O12；旧约6及官介；官方动画年表

== 1. 核心定位 ==
新学期里的友谊遭到地下街袭击考验。风斩发现自己不是普通人，却仍能选择保护朋友；本篇是茵蒂克丝与风斩相识，不是茵蒂克丝与上条初遇。

== 2. 不可丢失的核心事实 ==
- 9月1日姬神转学，茵蒂克丝在学校与风斩相识，随后和上条一同去地下街。
- 雪莉·克伦威尔潜入学园都市，操纵石像艾莉丝发动袭击；风纪委员组织地下街疏散。
- 风斩受伤后暴露空洞的身体，小萌的说明将其存在与AIM扩散力场联系起来。她不是普通转学生，也不因此失去情感与选择。
- 原作默认上条在地下道击败雪莉，风斩保护仍被石像追击的茵蒂克丝，上条赶到破坏石像；傍晚风斩与朋友告别。0930人工天使是后继，不在本日启动。

== 3. 玩家可改写的部分 ==
可参与交友、疏散、雪莉交涉与石像战，也可提前保护风斩不受伤。她的身份不要求以受辱或牺牲来证明，玩家可改变战斗顺序和告别方式。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口KAZAKIRI-01。

KAZAKIRI-01 新学期的朋友
进入条件：9月1日上学，或接续八月末事件。
场景目标：在姬神转学的日常中，让茵蒂克丝认识风斩。
可见角色：姬神、小萌、上条、茵蒂克丝、风斩。
玩家行动：介绍、陪同、邀请游玩，或通过事后介绍加入。
结果：风斩以具体的朋友而非未知武器进入关系网。
下一节点：KAZAKIRI-02。

KAZAKIRI-02 地下街的疏散令
进入条件：三人到地下街游玩，风纪委员开始疏散。
场景目标：确认入侵者威胁，帮助普通顾客离开。
可见角色：上条、茵蒂克丝、风斩、风纪委员；雪莉在追查线出现。
玩家行动：带路、搜寻落单者、核实封锁通道。
结果：游玩被打断，疏散路线与袭击现场发生交汇。
下一节点：KAZAKIRI-03。

KAZAKIRI-03 石像艾莉丝
进入条件：雪莉的石像追至地下街。
场景目标：保护同行者，识别操纵者与石像可分别行动的威胁。
可见角色：雪莉、艾莉丝、上条、风斩。
玩家行动：吸引石像、寻找控制者、保护茵蒂克丝退路。
结果：原作默认风斩在袭击中受伤，露出不是血肉的身体内部。
下一节点：KAZAKIRI-04。

KAZAKIRI-04 空洞不等于没有心
进入条件：发现风斩身体异常，或通过其他证据查明身份。
场景目标：从小萌的解释理解AIM集合的存在，同时安抚害怕被排斥的风斩。
可见角色：风斩、上条；小萌通过联络提供说明。
玩家行动：核对现象、表达信任、安排保护而非强行拘束。
结果：风斩知道自己与常人不同，但朋友关系不被撤销。
下一节点：KAZAKIRI-05。

KAZAKIRI-05 地下道中的雪莉
进入条件：找到雪莉，石像仍威胁其他人。
场景目标：阻止雪莉借袭击扩大科学与魔法的冲突。
可见角色：雪莉、上条；玩家按选定路线参战。
玩家行动：协助接近、破坏术式、交涉或救出阻路者。
结果：原作默认上条击败雪莉，但另一处的石像危机仍须收尾。
下一节点：KAZAKIRI-06。

KAZAKIRI-06 为朋友挡下石像
进入条件：茵蒂克丝仍受到艾莉丝攻击。
场景目标：协助风斩保护茵蒂克丝，为上条赶到争取机会。
可见角色：风斩、茵蒂克丝、艾莉丝、上条。
玩家行动：掩护、引导撤离、协同破坏石像。
结果：原作默认上条以右手击碎石像；风斩用行动确认自己能守护朋友。
下一节点：KAZAKIRI-07。

KAZAKIRI-07 傍晚的告别
进入条件：入侵与石像威胁解除。
场景目标：处理地下街伤者，保存三人的交友经历。
可见角色：风斩、茵蒂克丝、上条及救援人员。
玩家行动：道别、探伤、留下联系和未完成的游玩约定。
结果：原作默认风斩离去，友谊继续；未来再现不能被写成此次友谊失效。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
身份揭示可由其他证据完成，不强制受伤。玩家可留下风斩或改变雪莉处置，按实际偏移记录，不让0930强行抵销本篇救援。既有完成节点与关系事实保留。

== 6. 换篇条件 ==
KAZAKIRI-07完成、明确离开/跳时或袭击提前终止即可换篇。主干可接9月上旬BOOK-OF-LAW-01，科学侧独立事件按其窗口选择；ST0930到9月30日再开，不将一整月压成同一天。

== 7. 防剧透边界 ==
本篇可解释AIM集合身份，不直接预告人工天使的完整幕后。知情范围随接触形成，不能据此禁止后继风斩剧情。

== 8. 状态写回契约 ==
同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留已有项。风斩关系、疏散与雪莉处置等偏移写主线进度.正史锚点.玩家偏移，具体承诺写任务追踪。

== 9. 收束结果 ==
- KAZAKIRI-END-A：近原作，袭击终止，风斩与朋友告别。
- KAZAKIRI-END-B：玩家改变疏散、战斗或风斩去留。
- KAZAKIRI-END-C：退出或委托救援，记录场外事实。
- KAZAKIRI-END-D：原创解决，不以风斩消失或朋友失忆惩罚改写。
