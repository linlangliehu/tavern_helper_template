【事件包：上里阵营与去鸣篇】
事件包ID：NT-SALOME
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年十二月上旬；NT14之后、NT16之前，NT15—17日期冲突保留相对顺序
别名与触发词：上里阵营与去鸣篇 / 去鸣袭来 / 理想送行夺手事件 / NT-SALOME

== 1. 核心定位 ==
作品范围：新约15。学校生活把上条与上里再次放到一起，去鸣的行动使两边关系恶化，木原唯一趁乱夺走理想送行。此卷的结尾是夺手、A.A.A与反击准备，不是上里已被放逐；放逐发生在NT16末段。

== 2. 不可丢失的核心事实 ==
- 原校在僧正追击中受损，上条转入临时就读学校，上里也出现在那里。若玩家此前保住原校，须另有已经成立的会面理由，不能照抄转校。
- 去鸣是上里没有血缘关系的妹妹，早已以改造身体和魔术行动。她不盲从上里阵营，脱离其拘束后拿到上条相关者名单，进入学园都市。
- 原作上条与上里商议用影像诱出去鸣，上里却转而让阵营围攻上条；去鸣带来一方通行，打断围攻。这不是两个阵营自始至终的无间合作。
- 木原脑干被上里重创后由唯一置于冷冻保存，唯一由此追求复仇。她伪装靠近上里，切下并夺走他的右手，利用Sample Shoggoth与弱毒性圣日耳曼病毒改写识别来使用它。
- 唯一制造的魔神外形与攻击是欺骗，不是真把遭放逐的魔神全部召回。原作美琴偶然接触脑干留下的A.A.A，为救上条使用它，击退唯一；武装接触也引起亚雷斯塔关注。

== 3. 玩家可改写的部分 ==
- 可让去鸣与上里直接谈清拘束和家人关系，拒绝用不知情者作影像诱饵，避免围攻升级。
- 可识别唯一伪装、保护上里的手与脑干保存设施，或以救治脑干争取停止复仇。
- 可替美琴提供其他救援办法，不要求她必须装备A.A.A；已有接触则如实保留未知系统与身体影响。

== 4. 节点推进表 ==
NT-SALOME-01 临时学校里的旧对手
进入条件：NT14后发生实际转校，或玩家另有与上里在学校接触的原因。
场景目标：处理前次交锋留下的关系，区分正常同学与被卷入的两方伙伴。
可见角色：上条、上里、吹寄与同学；府兰等上里阵营成员。
玩家行动：核实学校安置，协商不在校园延续决斗，听取府兰关于去鸣脱离拘束的警告。
结果：原作两名少年未能单纯恢复日常，去鸣的到来成为共同警讯；玩家可先保护校内无关者，不把全部同学当作阵营成员。
下一节点：进入NT-SALOME-02。

NT-SALOME-02 妹妹不是听令的部下
进入条件：发现去鸣入城、持有上条相关者名单或接触到她的行动。
场景目标：查明她为什么针对这些人，以及她与上里阵营的矛盾。
可见角色：去鸣、上条、上里及受到威胁的相关者。
玩家行动：保护名单上的人，询问她的家人经历与自主目标，区分她的危险行为和他人将她永久拘束的正当性。
结果：原作去鸣的目标与阵营表面协作不同，她并非右手自动制造的追随者；玩家可争取她说出真实目的，但不能因亲属身份自动消除其危险性。
下一节点：进入NT-SALOME-03；已经达成停手约定仍须核实其履行。

NT-SALOME-03 被反用的诱敌影像
进入条件：上条与上里讨论共同诱出去鸣，或玩家找到可以安排公开会面的办法。
场景目标：验证合作承诺，防止诱敌变成阵营围攻与再次背叛。
可见角色：上条、上里、上里阵营、去鸣；一方通行在原作介入线上出现。
玩家行动：设置双方可核验的会面条件，保护拍摄与在场人员，识别上里的转向，向去鸣或其他援助者求助。
结果：原作上里背离合作让阵营围攻上条，去鸣带来一方通行打断局势；玩家若避免围攻，可保留较缓和关系，不为了推进而追加一次相同背叛。
下一节点：夜间学校对峙或唯一的介入出现时进入NT-SALOME-04；安全会面也可成为调查伪装的入口。

NT-SALOME-04 唯一夺走的右手
进入条件：木原唯一利用熟人伪装接近上里，或玩家已经发现她追查脑干伤势的证据。
场景目标：识别潜入者，防止右手及其能力被当成复仇工具移植。
可见角色：木原唯一、上里、去鸣、上条、上里阵营。
玩家行动：验证身份，隔离伪装与修复材料，保护上里并急救，追踪唯一对手臂识别的改写。
结果：原作唯一切下上里右手并取得理想送行，部分女孩留下照护上里，另一些支援去鸣；玩家阻止夺手或立即取回时，后续必须取消唯一凭空继续使用它的前提。
下一节点：唯一仍构成威胁则进入NT-SALOME-05；已控制现场则进入NT-SALOME-06善后。

NT-SALOME-05 假魔神与真正的放逐威胁
进入条件：唯一用夺得的右手和混合技术阻击救援者。
场景目标：区分真正的理想送行、伪装的魔神攻击与近身技术，救出受制者。
可见角色：唯一、上条、去鸣、美琴；支援去鸣的上里阵营成员。
玩家行动：揭穿魔神仿造，利用去鸣不存在相应矛盾愿望的特点安排协作，破坏材料与监视干扰工具，避免把所有攻击当成一种魔法。
结果：原作女孩们提供武器支援去鸣，上条与去鸣、美琴仍陷入苦战；玩家可以截断伪装材料或谈判，已被识破的假魔神不能继续作为真正魔神威慑。
下一节点：进入NT-SALOME-06；战斗已提前结束则带实际状态进入。

NT-SALOME-06 A.A.A与退入地下的反击
进入条件：美琴被卷入脑干武装的存放设施，或玩家已为现场建立其他反制方法。
场景目标：救下唯一攻击下的上条，明确武装接触与右手去向，不把击退误记为永久解决。
可见角色：美琴、上条、去鸣、唯一；上里与伙伴在实际安置处。
玩家行动：判断是否使用未知武装，提供替代掩护，追查唯一撤退方向，照护失去右手的上里并制定夺回方案。
结果：原作美琴使用A.A.A击退唯一，唯一仍持有右手并与亚雷斯塔接触，上里阵营转入隐蔽准备反击；上里此时尚未被放逐。玩家改变右手去向时，后继追击动机随之重写。
下一节点：唯一释放元素、城市出现异常热浪且玩家介入时进入NT-HEAT-WAVE-01；否则继续救治、追踪或校园善后。

== 5. 分支和偏离规则 ==
去鸣自愿协作不等于服从阵营，上里伤势不等于进入新天地。右手、脑干冷冻保存和A.A.A分别记真实持有者与接触情况。若唯一被控制或停止复仇，NT16的元素投放不能无因照常发生。

== 6. 换篇条件 ==
当前交锋有离场条件、上里得到救治、右手去向明确后再转入热浪篇。日期只保留NT14→NT15→NT16的顺序，不为填日历擅自挪动剧情。

== 7. 防剧透边界 ==
不在校园初见时公开唯一的伪装和移植方法；假魔神真相按观察揭开。A.A.A不作为无副作用普通机甲介绍。上里放逐、府兰真实身份与NT17救回方法均留在后续揭示。

== 8. 状态写回契约 ==
正式进入本包时，主线进度.当前阶段记“新约”，主线进度.阶段序号使用整数6；主线进度.正史锚点.当前锚点记“上里阵营与去鸣篇”，主线进度.当前节点使用NT-SALOME完整ID。已完成节点、可触发节点以op:"replace"整体替换数组；校园损毁、去鸣协议、上里伤势、右手去向、脑干与A.A.A线索写入主线进度.正史锚点.玩家偏移及世界线记录。仅用现有任务追踪、NPC关系，不造装备强制绑定字段。
玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- 原作默认：唯一夺手后被A.A.A击退，上里阵营转入隐蔽，冲突尚未根除。
- 夺手阻断：玩家保住或夺回右手，元素篇必须重新确认唯一的动机与手段。
- 停战救治：以脑干与上里的救治协商暂停复仇，保留各方真实接受程度。
- 独立撤离：玩家带走伤者与证人，尚未解决的追踪任务留存。
