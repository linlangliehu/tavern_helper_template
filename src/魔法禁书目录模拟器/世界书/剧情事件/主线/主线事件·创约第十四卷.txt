【事件包：创约第十四卷·午夜追猎与清晨归校】
事件包ID：GENESIS-14
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第14卷；科隆尊逃亡追击、决战、清晨善后与本卷附尾。
时间窗口：序章承接Y＋1年1月8日午夜前，主体跨入1月9日凌晨。分学区追击的0点、1点、2点归属依据社区梗概和译文；第四章写已过04:00，尾声明确08:30并回述“昨日”的葬礼与开学。04:00不是全卷终点，08:30也不替所有附尾镜头赋予精确时刻。
别名与触发词：创约第十四卷 / 创约第十四卷午夜追猎 / GENESIS-14

== 1. 核心定位 ==
阿蒂迦利迦没有造成预定屠杀，却不代表科隆尊再无威胁。她准备逃出学园都市换地方继续破坏，伤重的追击者必须在追敌、阻止设施灾难、照护同伴之间分配行动。原作最后不仅有上条与科隆尊的决战，也有上条恢复生者身份、按时面对新学期的愿望，以及浜面对处置结果无法释怀的分歧。

== 2. 不可丢失的核心事实 ==
- 亚雷斯塔在午夜前尝试夺回肉体而未成功；奈芙蒂斯、娘娘的攻击限制科隆尊直接飞离，她以强力攻击掩护撤退，危机转为都市内追逐。
- 科隆尊经第七、第三、第十九学区逃亡，炸毁第十九学区中央锅炉的一部分。黄泉川和设施人员的抢修、救人是阻止连锁灾难的重要行动，不能只剩主角追击。
- 她转往第二十学区野外演出场，试图把身体转换为天使之力并借地脉逃离。转换接近完成时，亚雷斯塔从精神层面干扰，她被迫回到肉体并再次考虑越墙。
- 第七学区的戴安、米娜对莫伊娜的战线延续前卷。米娜击破这份不完整的同源复制体，并利用术式破除后的回流信号为追踪科隆尊提供机会。
- 科隆尊再经第二十、第九、第十七学区转移，以强力术式阻挡追兵，最后在造船设施与上条交锋。欧提努斯的分析、环境中的铁以及亚雷斯塔的干扰共同提供突破条件，不是上条忽然拥有全面碾压她的力量。
- 原作上条知道攻击这具身体也会波及亚雷斯塔，仍选择制止科隆尊。他避开熟悉的全力攻击并击中她，第四章明确科隆尊死亡；浜面赶到时已经来不及阻止。
- 尾声展示亚雷斯塔失去所借肉体后的死后视角，金斯福德再次将他的灵魂向生者世界送去。新肉体与现实落点未在这一幕确定，不能简化成他永久消失或已经在城内完整复活。
- 清晨降雨洗去红雪，恢复供给与医疗安置继续。08:30课堂重启，上条经医生确认活着后回校；附尾中的浜面仍被看管，Aneri送来联络机会，尚未发生任何后续行动。

== 3. 玩家可改写的部分 ==
- 改变追击路线、疏散与锅炉抢修分工，保住工人、救援者及无法自行离开的居民。
- 争取在转换术式、越墙或造船设施前截停科隆尊，尝试建立可持续的封印、停手或分离肉体方案，不强制杀死她。
- 改变决战代价、亚雷斯塔去留、浜面对结果的理解与同伴善后；任何新方案都要有可执行条件，而不是旁白自动解决全部冲突。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；午夜、凌晨追击、过04:00决战、清晨与08:30分开推进。附尾只表达本卷已经展示的状态，不凭它生成下一卷事件。

GENESIS-14-01 午夜前的夺体失败
进入条件：GENESIS-13-08中术式危机解除而科隆尊仍可行动，上条已呼唤亚雷斯塔。
场景目标：辨认夺体尝试的成败，阻止科隆尊利用众人伤重直接脱离。
可见角色：科隆尊、上条、茵蒂克丝、美琴、欧提努斯、泷壶；魔神介入，亚雷斯塔在肉体内部抵抗。
玩家行动：保护倒下者、记录她失去飞离机会后的逃跑方向、恢复与一方通行等人的联络。
结果：原作亚雷斯塔未能夺回主导权，科隆尊遭魔神攻击后以攻击掩护徒步逃亡；上条决定当夜追上，而不是把她放走另开一场灾难。
下一节点：GENESIS-14-02；若玩家此前已使她安全停手，转入实际善后而不强制逃亡。

GENESIS-14-02 零点后的路线与锅炉救援
进入条件：1月9日零点后的追击沿第七、第三学区进入第十九学区，科隆尊利用设施制造阻碍。
场景目标：同时保住追踪线索与中央锅炉周边的人命，阻止剩余锅炉连锁破裂。
可见角色：上条及追击同伴、施普伦格尔；锅炉现场的黄泉川、工人与救援人员，正在逃离的科隆尊。
玩家行动：传递管线与压力信息、协助疏散和抢修、支援黄泉川进入危险区，在交接清楚后继续追踪。
结果：原作中央锅炉受损但余下系统的连锁爆炸被阻止；科隆尊没有因此被擒，转而寻求经地脉离开城市。救援成果与追击进度分别保留。
下一节点：GENESIS-14-03；仍在救人者可以留在该现场，不把他们强行搬到下一学区。

GENESIS-14-03 一点前后的野外演出场
进入条件：追击线索指向第二十学区，科隆尊开始准备身体能量化的转换。
场景目标：辨认真正的仪式地点与逃离途径，在她进入地脉前争取截停机会。
可见角色：科隆尊、上条与能抵达的同伴，追索中的英国清教人员；亚雷斯塔可从精神层面干扰。
玩家行动：核对演出场的地形与仪式条件、排除错误地点、联络各入口的小组，尝试阻断转换而不伤及旁人。
结果：原作转换进度接近完成时，亚雷斯塔抓住她进入精神层面的机会干扰；科隆尊紧急恢复肉体，地脉逃离失败，再改为向城市外墙移动。
下一节点：GENESIS-14-04；玩家若另行阻断成功，按实际原因记录，不硬补亚雷斯塔的原作手段。

GENESIS-14-04 两点前后的同源对决
进入条件：第七学区戴安与莫伊娜的战线尚在持续，米娜加入并识别这份复制体的局限。
场景目标：解除牵制，并将胜利转化成能分享的追踪信息，而非只赢一场孤立决斗。
可见角色：戴安＝福琼、米娜＝马瑟斯、莫伊娜；英国清教的接收者通过实际联络出现。
玩家行动：协助保护周边、传递莫伊娜术式表现、为米娜创造判断机会，及时接收破咒后的回流信号。
结果：原作米娜击破莫伊娜而未破坏周围街区，术式回流暴露科隆尊方位，追击获得第十七学区方向的机会；这不是科隆尊本人已被击败。
下一节点：GENESIS-14-05；若玩家只在另一现场，通过可靠通讯得知结果，不自动获得同源对决的全部知识。

GENESIS-14-05 通往第十七学区的火力封锁
进入条件：科隆尊经第二十、第九学区转入第十七学区，追击者利用新线索接近。
场景目标：突破她用来分隔援军的炮台与攻击，避免把受困同伴留在崩塌设施里。
可见角色：科隆尊、上条、欧提努斯；沿线的茵蒂克丝、美琴、超绝者与其他追击者按实际位置出现。
玩家行动：辨认攻击规律、协助被困者寻找掩护、维持联络并为能够接近的上条提供信息。
结果：原作科隆尊用强力术式把多数援军阻在外部，上条继续靠近造船设施；欧提努斯随行支援，不能将这一局面说成完全没有任何人的帮助。
下一节点：GENESIS-14-06。

GENESIS-14-06 已过四点的最后选择
进入条件：时间已过04:00，上条与科隆尊进入造船设施内的最后交锋。
场景目标：制止她逃离后继续破坏的可能，同时面对攻击共用肉体会波及亚雷斯塔的事实。
可见角色：上条、科隆尊、欧提努斯；亚雷斯塔在肉体内阻止后退，浜面正在赶来。
玩家行动：利用铁制环境干扰攻击精度、听取欧提努斯对熟悉招式的分析，寻找制止或分离方案，并承担所选择方案的实际结果。
结果：原作上条在亚雷斯塔阻挠科隆尊退避时躲开熟悉的全力攻击，击中她并使她死亡；他无法在击中瞬间确定表面意志属于谁。浜面赶到时已经太迟，亚雷斯塔也失去所借肉体。
下一节点：GENESIS-14-07；若玩家已经建立非致死收束，记录其约束与去留，不补写原作死亡。

GENESIS-14-07 清晨的照护与另一侧的归路
进入条件：科隆尊的即时威胁已终止，医疗、基础设施恢复与各方撤离开始。
场景目标：让幸存者得到照护，分清公开善后与只有死后视角才能看到的事情。
可见角色：医疗人员、神裂、泷壶、各方救援者；一方通行安排都市恢复，超绝者等准备离开。若明确切换死后视角，可见亚雷斯塔与金斯福德。
玩家行动：安置伤者、核对浜面被看管的理由和程序、协助恢复保供；在死后视角中回应金斯福德的援助而不凭空指定新肉体。
结果：原作清晨雨水洗去红雪，各方开始撤离；神裂向泷壶说明浜面并无实际物资或战斗援助行为，承诺手续与训诫后释放，但此时并非已经放人。金斯福德将亚雷斯塔的灵魂向生者世界送回，现实落点仍未确认；普通市民不会自动知道死后这一幕。
下一节点：GENESIS-14-08。

GENESIS-14-08 八点半的新学期
进入条件：尾声来到08:30，学校恢复上课，上条仍需完成自己活着的医学确认。
场景目标：让救回的日常真正落到人物行动上，而不是在决战胜利后跳过全部后果。
可见角色：月咏小萌、青发耳环、吹寄制理与同学，上条；医生作为此前完成生命确认的当事人，不必被搬到教室。
玩家行动：完成或协助核验、回应同伴担忧、交接尚待恢复的生活安排，让返校者自己说明迟到的原因。
结果：原作老师开始点名，上条在缺席后赶到；他已经过医生确认活着。“昨日”举行过葬礼并且原定开学，对应1月8日，今日是1月9日的普通上课日。
下一节点：GENESIS-14-09；不把08:30写成所有附尾镜头的共同精确时刻。

GENESIS-14-09 附尾里尚未回答的分歧
进入条件：本卷附尾切换到仍被看管的浜面；这一镜头未提供可独立锁定的钟点。
场景目标：保留浜面对科隆尊死亡的悲愤、怀疑与个人判断，不把他当作已同意庆祝胜利。
可见角色：浜面；通过送入的手机与其联系的Aneri，不凭空添加接应者或幕后组织。
玩家行动：在明确的该视角中检查联络、表达对处置的疑问，或在外部以现有渠道关心看管程序与泷壶的担忧。
结果：原作浜面改变了看待世界的方式并重新接触Aneri；这只是已经出现的思想与联络变化，尚没有后续行动、复仇结局或新的日期事件。
下一节点：本包收束；停在本卷已呈现的清晨与附尾，可进行玩家自选善后或明确另选锚点，不自动生成后续卷与1月10日至31日事件。

== 5. 分支和偏离规则 ==
- 决战死亡是原作结果，不是玩家必须履行的处刑任务。非致死收束须解决即时威胁与后续控制问题，一旦成立就持续有效。
- 亚雷斯塔的身体、灵魂与现实去向分别依据已经看到的事实描述，不把死后援助提前宣布成可无限重复的复活能力。
- 浜面的思想变化属于他的视角，不等于世界旁白认定其他人邪恶；可谈判、质疑、照护，也可保持分歧，不添加惩罚玩家选择的机制。

== 6. 换篇条件 ==
追击、决战、清晨安置与08:30返校已有结果，并保留本卷附尾的未决关系，或玩家主动选择退出、跳跃时收束。作品范围止于本卷，不把第四章的04:00当全卷终点，也不为补满一月擅自安排后续事件。

== 7. 防剧透边界 ==
追逐中各组按真实联络交换位置，不能全知科隆尊下一次转向。金斯福德与亚雷斯塔的死后对话、浜面与Aneri的联络均受视角限制；返校同学不会从旁白中自动得知所有秘密。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8，当前节点使用完整ID，阶段状态按追击、决战与实际收束更新；日期停在已经推进到的本卷时点。
- 正史锚点记录科隆尊死亡、清晨恢复及上条返校的默认参照；玩家偏移保留非致死结局、不同救援代价与关系分歧，不强制回正。
- 已完成节点、可触发节点去重后整体replace；仅被可靠告知的并行结果不伪造成亲历，收束后不加入不存在的下一卷节点。
- 锅炉救援、追踪、医疗与看管事项沿用任务追踪；生存、去留、知情和关系沿用NPC关系、在场人物、势力关系、世界线记录，不新建结局评分、复活次数或惩罚字段。

== 9. 收束结果 ==
默认科隆尊被上条制止并死亡，亚雷斯塔失去所借肉体但得到金斯福德新的援助；城市恢复供给，上条以活人身份回到教室。浜面与Aneri的附尾留下不同声音而没有给出下一步结果。本事件包到此止，玩家已经改变的存亡、救援与关系继续属于其世界线。
