【事件包：蜜蚁爱愉篇】
事件包ID：MENTAL-STINGER
所属阶段：阶段7前段·格雷姆林魔神之战后、科隆尊降临前（新约11卷·心理掌握弧）
时间窗口：12月1日—12月7日（魔神欧提努斯事件平息后、冬休前）
别名与触发词：蜜蚁爱愉篇 / 蜜蚁 / 心理穿孔 / Mental Stinger / 蜂与蚁 / 外装代脑 / Five Over OS / 食蜂操祈 / MENTAL-STINGER

== 1. 核心定位 ==
"蜂与蚁"的悲剧：蜜蚁爱愉——与食蜂操祈同系统能力、素养判定足以成为 Level 5，却因培养成本被当局从课程表上砍掉的"另一名女王候补"。她以 Level 3「心理穿孔」、外装代脑系兵器 Five_Over OS（Modelcase_"MENTAL_OUT"）与横裂体网络，在 12 月初向食蜂操祈发起复仇，将食蜂逼入精神绝境；上条当麻介入对峙，蜜蚁败北、送入少年院。本篇主题是"被系统判定为'多余'的人的求生"——没有纯粹的恶役，只有被素养格付（Parameter List）碾碎的孩子。玩家可作为调停者、守护者、调查者或见证者介入这场三人（蜜蚁/食蜂/上条）的残酷错过。
玩家进入方式：开局锚点直接选在本篇；或作为食蜂派阀侧的护卫/调查者；或主动接近蜜蚁试图阻止悲剧；或在事件余波中处理心理穿孔受害者的善后。

== 2. 不可丢失的核心事实 ==
- 蜜蚁爱愉：常盘台中学一年级（事件时已在长点上高中——本篇按"再起归来"处理），Level 3「心理穿孔（Mental Stinger）」：与食蜂同系的精神系能力，以智能手机摄像头+指尖锁定目标，可洗脑、记忆改竄/消去、读心、强制自白；本有 Level 5 素养，因"同系能力者不重复培养"的成本逻辑被砍掉课程表；外见是最初代食蜂淘汰设计（棉花糖般巧克力色卷发），食蜂也承认其"系列第一美腿"。
- 与食蜂的过去：才人工房时代蜜蚁作为"心理掌握的备份"参与外装代脑（Exterior）计划——研究者以"帮食蜂增幅能力"为名建外装代脑，实为"让任何人都能使用心理掌握"；食蜂发现完成后自己将被抹杀，遂夺走外装代脑控制权、捣毁才人工房，连带解放了蜜蚁、帆风等孩子。蜜蚁的恨意不是"食蜂抢走了什么"，而是"食蜂的存在本身就让我成了多余的备份"。
- 上条当麻的错过（悲剧核）：蜜蚁曾在某处等待"上条来救我"，上条因故迟到、错过了她的"自杀"现场；三日之后食蜂在同一地点尝试了同类行为、被（别的契机）救下——蜜蚁由此确信"被选中的是食蜂，不是我"。她恨的深处是"为什么不是我"。
- 五途 OS 兵器：Five_Over OS（Outsider）Modelcase_"MENTAL_OUT"——以食蜂能力为原型研制的兵器（多目状球体，可自由变形），蜜蚁作为驾驶者可发挥 Level 5 级战力；另有横裂体等器材辅助精神操作。她不靠能力也能用兵器精确操纵人心。
- 事件经过：11月末—12月初，蜜蚁现身向食蜂复仇；"仅 3 秒"令食蜂操祈意识沉落（精神系顶点被同系能力击破的震撼）；她以心理穿孔+兵器逐步把食蜂逼入"自己的一切记忆与人格都可能是伪造"的怀疑地狱（利用上条与食蜂的过去）。
- 上条的对峙与胜利：上条以幻想杀手无效化心理穿孔、在兵器与能力的连携攻势下逼近本体；蜜蚁暴走中罕见地以"水分抽干让物体海绵化"的物理现象攻击（精神系突破常识的例外时刻），最终被上条以连击击倒、被说服——"我不是来救食蜂的，我是来救你的"。
- 结局重力线：蜜蚁送入少年院收容；食蜂失去"心理掌握最强"的绝对自信、开始真正面对"备份"们的存在；上条的劝救话语成为蜜蚁心中未熄的火种（后日谈：她始终记着上条）。
- 与相邻篇章的时间关系：格雷姆林之战（11-12月）刚结束，学园都市暗部在暗部大战后重组中的空隙让蜜蚁的行动有机可乘；食蜂在 NT11 的心理创伤与"外装代脑"旧事由本篇正式收束。

== 3. 玩家可改写的部分 ==
- 蜜蚁复仇的成败与代价：可助她"得到想要的回答"（被看见、被承认），可促成和解，可按原著旁观败北。
- 三日之差的悲剧核：玩家可在"上条迟到"的因果节点介入（当代目击者/传信者），改写"错过"本身。
- 食蜂的 3 秒败北：可提前预警、可代为承受、可事后陪伴——食蜂的精神危机并非必然。
- Five_Over OS 的处置：破坏、夺取、上缴或玩家原创方案。
- 蜜蚁的终局：少年院（重力线）、玩家促成的治疗方案、或玩家原创的安置。
- 玩家可作为上条的协力者或独立第三方介入对峙。

== 4. 节点推进表 ==
节点ID格式：MENTAL-STINGER-{NN}。每轮最多推进一个主要节点。

MENTAL-STINGER-01 蜂之动摇
触发：玩家进入12月窗口（开局选本篇/被派阀征召/目击异常）。
内容：食蜂派阀内出现针对食蜂的流言与记忆异常；食蜂的"伪造记忆"疑心生起；暗中调查开始；玩家可参与调查或受托护卫。
完成：玩家确认"有同系能力者在背后行动"。
下一节点：02。

MENTAL-STINGER-02 蚁之现身
触发：01完成。
内容：蜜蚁爱愉现身宣战；外装代脑旧事被翻出；Five_Over OS 首次投入；食蜂派阀措手不及；玩家可目击或截击兵器。
完成：蜜蚁的存在与目的（复仇）明确。
下一节点：03。

MENTAL-STINGER-03 三秒的败北
触发：02完成。
内容：食蜂与蜜蚁正面交战——仅3秒食蜂意识沉落；"心理掌握最强"神话崩塌；派阀动摇、常盘台骚然；食蜂坠入"记忆是否为伪造"的怀疑地狱。
完成：食蜂被击倒的事实与其精神危机确立。
下一节点：04。

MENTAL-STINGER-04 错过的真相
触发：03完成。
内容：蜜蚁的过去揭开——素养格付的背叛、外装代脑、以及"三日之差"的残酷错过；玩家可在此节点介入因果（回溯调查/传信/当代目击者），尝试改写错过本身。
完成：蜜蚁的恨意根源曝光（或玩家改写线确立）。
下一节点：05。

MENTAL-STINGER-05 幻想杀手
触发：04完成。
内容：上条当麻介入对峙；幻想杀手对心理穿孔的无效化；兵器+能力的连携攻防；蜜蚁的暴走与"海绵化"物理例外；最终被击倒并被说服。
完成：蜜蚁武力线终结（或玩家改写线收束）。
下一节点：06。

MENTAL-STINGER-06 蚁的归处
触发：05完成。
内容：蜜蚁收容与安置；食蜂与"备份"们的直面与和解的第一步；上条的话留下的火种；派阀重组与常盘台日常回归；冬休将始，都市迎向年末。
完成：本篇收束，按第9章定收束结果。

== 5. 偏离与改写 ==
- 节点是"原著重力线"，玩家可任意偏离：可把本篇玩成食蜂派阀内部剧、外装代脑遗迹探索、精神系能力者保护运动，只要不覆盖核心事实（蜜蚁的存在、三秒败北或其改写、三日之差的真相）。
- 核心结果改写：蜜蚁被提前阻止、食蜂未败北、错过被修正，均合法，以玩家偏移事实记录，不得静默回滚。
- 玩家明确离开时按第9章 MS-END-D 收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：素养格付（Parameter List）的完整内容与制定者、外装代脑的最终去向、Five_Over 系列兵器全谱、食蜂与上条过去回忆的全部细节（只作动机级引用）、魔神系/科隆尊相关后续。
- 蜜蚁的能力只到"同系精神操作+海绵化例外"表现层；不揭示其 Level 上限或后续再起（创作约系内容）。
- 上条只作"介入者"行动，不展开其失忆真相、幻想杀手深层原理。
- 魔法侧势力不得作为本篇推动力（上条的右手只表现为"无效化"现象）。

== 9. 收束结果 ==
- MS-END-A 原著近似收束：复仇败北、送少年院、食蜂直面创伤的标准重力线。
- MS-END-B 玩家亲手终结：玩家主导收束，错过被修正或复仇被化解，蜜蚁按玩家方案安置。
- MS-END-C 谈判收场：玩家促成蜜蚁-食蜂-学园都市当局的三方和解（承认"备份"们的存在、素养格付受害者的救济方案）。
- MS-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
以上收束均不以玩家死亡或"失败判定"告终；蜜蚁的悲剧只作为剧情事实呈现，不作为对玩家的惩罚判定。
