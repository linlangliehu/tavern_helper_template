【事件包：蜜蚁爱愉篇】
事件包ID：MENTAL-STINGER
所属阶段：阶段6·新约11·心理掌握当前框架
时间窗口：本篇Y年十一月下旬；11月24—25日附近为图排，当前框架精确日待核
别名与触发词：蜜蚁爱愉篇 / 蜂与蚁的记忆争夺 / MENTAL-STINGER

== 1. 核心定位 ==
作品范围：新约11的当前事件。食蜂重访与上条有关的地点，却被人为改变的景观和横裂体装置诱导，开始怀疑珍贵记忆是否伪造。蜜蚁的目标不是普通派阀夺权，而是借食蜂自己的心理掌握摧毁她与上条的记忆。
前一年夏季的上蜂相遇、人工湖与死结事件引用MENTAL-PAST；本包只展开当年十一月下旬的调查、交锋和医院余波。回忆被揭开不代表事件重新发生，也不自动允许玩家倒回过去改变它。

== 2. 不可丢失的核心事实 ==
- 蜜蚁的心理穿孔与心理掌握同系。素养判定把她留作备份、发展机会受限，是她的怨恨来源之一；不能把等级较低等同于没有威胁，也不能虚构她在本框架重新入学。
- 横裂体内没有证明食蜂记忆造假的内容。骗局要制造怀疑，让食蜂自行清除记忆；云川芹亚的检查和假急救人员的露馅是调查突破口。
- FIVE Over OS以磁性显示材料改变外界感官信息，并非真正复制心理掌握；另一台未完成的FIVE Over企图把食蜂本人装进机器作为能力核心。两者不与外装代脑混为一个装置。
- 蜜蚁把过去未获救的遭遇归咎于食蜂。上条遗失手机、未及时收到求救与三日后遇见食蜂，是过去层的错过，不是上条有意挑选谁值得获救。
- 当前决战中，上条本人确实到场，制止蜜蚁失控的能力并介入救援。其到场缘由在尾声解释为云川芹亚的委托，不是食蜂召出的幻象，也不表示他恢复了关于食蜂的记忆。
- 原作尾声说明相关兵器被毁，心理掌握未被量产；蜜蚁“名义上”被送往少年院，但仍需警惕暗部，不能把收容等同于此后安全已获保证。

== 3. 玩家可改写的部分 ==
可提前揭穿景观伪装、保护证人、阻止把食蜂装入兵器、帮助蜜蚁接受援助，或提出可执行的安全安置。可查访前一年证词，但重演或改写过去必须由玩家明确选择前史锚点，并沿用已有偏移。不得为促成和解强行修复上条的记忆。

== 4. 节点推进表 ==
保留MENTAL-STINGER-01至06的完整ID；每轮最多推进一个主要节点。

MENTAL-STINGER-01 地点与记忆不相符
进入条件：十一月下旬，玩家同行或接到食蜂重访旧地后的求助。
场景目标：在人工湖相关地点核对眼前景观与食蜂记忆的矛盾，避免先认定她的记忆是假。
可见角色：食蜂操祈、派阀成员；上条只在回忆中出现。
玩家行动：查地图和现场物证、询问旧识、陪同调查，或暂时带她离开受操纵的环境。
结果：默认食蜂开始怀疑自身记忆；有独立证据时可提前保住信心，但伪装来源仍需追查。
下一节点：MENTAL-STINGER-02。

MENTAL-STINGER-02 空白横裂体与假急救
进入条件：食蜂寻求能查明精神干涉的人，或玩家发现植入装置。
场景目标：借云川芹亚的检查发现横裂体，识破以治疗为名替换装置的人。
可见角色：食蜂、云川芹亚、伪装成急救人员的行动者。
玩家行动：隔离装置、交叉询问、保护检查过程，查明装置并未保存所谓伪造记忆。
结果：默认确认这是一场诱导自我抹除的骗局；食蜂有理由反击，而不是任人定义她的人生。
下一节点：MENTAL-STINGER-03。

MENTAL-STINGER-03 磁尘之后的蜜蚁
进入条件：食蜂与派阀追踪制造假象的人。
场景目标：从FIVE Over OS制造的视觉欺骗中找出本体和观察支点，辨认宣称夺回一切的蜜蚁。
可见角色：蜜蚁爱愉、食蜂、帆风润子及派阀协力者。
玩家行动：破坏观察视点、提供不受显示材料干扰的参照，或隔离双方争取交谈。
结果：默认蜜蚁揭露备份身份与复仇动机；她抵抗同系能力不证明食蜂所有记忆都已被改写。
下一节点：MENTAL-STINGER-04。

MENTAL-STINGER-04 被引入的精神对话
进入条件：蜜蚁以同系能力间的连接诱使食蜂陷入自己的精神领域，或同意交代旧事。
场景目标：分清真实的过去错过与“食蜂故意夺走救援”的指控；理解蜜蚁不愿上条看见如今的自己。
可见角色：食蜂、蜜蚁；过去上条仅作为被叙述的对象。
玩家行动：保持外部接应、核对MENTAL-PAST已发生事实，或帮助两人表达未被听见的求救。
结果：默认食蜂决定救蜜蚁而非只求击败她；前一年事件只被揭示，不把当前日期改成夏天。
下一节点：MENTAL-STINGER-05。

MENTAL-STINGER-05 兵器、哨声与到场的人
进入条件：蜜蚁准备把食蜂作为未完成FIVE Over的核心，或玩家已逼停该步骤。
场景目标：派阀争夺OS控制权，阻止记忆被食蜂自己的能力抹去；在实体交锋后打开救援通道。
可见角色：食蜂、蜜蚁、派阀协力者；随后实际到场的上条当麻。
玩家行动：解救被固定的食蜂、切断装置、协助制止蜜蚁暴走，或在哨声之前完成谈判。
结果：默认食蜂吹哨后上条到场，幻想杀手制止能力暴走，两人均获得救援；不是把上条改成幻象，也不强制复刻每一次受伤。
下一节点：MENTAL-STINGER-06。

MENTAL-STINGER-06 医院长椅与尚需保护的人
进入条件：现场冲突结束，受伤者获救，安置消息能够核实。
场景目标：在医院核对上条因云川委托而到场的原因、兵器销毁情况及蜜蚁的名义收容安排。
可见角色：食蜂、上条；蜜蚁及相关保护者按实际安置出现。
玩家行动：核查转送去向、安排持续照护、保护隐私，或提出替代收容方案。
结果：默认上条能记住蜜蚁却仍不能留住食蜂的记忆；兵器没有量产成功，少年院并非自动安全终点。玩家安置方案如实保留。
下一节点：本篇收束；休整后可选NT-SAINT-GERMAIN-01，或继续照护、调查与自主选篇。

== 5. 分支和偏离规则 ==
玩家提前识破骗局时，不强令食蜂失去意识；蜜蚁接受帮助时，不强令她继续暴走。当前救援不抹去过去的痛苦，也不把修复过去当必须完成的任务。已经改变的安置、兵器去向与记忆状况均须沿用。
