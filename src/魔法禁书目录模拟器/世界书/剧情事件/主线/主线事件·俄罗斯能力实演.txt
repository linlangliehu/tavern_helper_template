【事件包：俄罗斯能力实演】
事件包ID：RUSSIA-DEMONSTRATION
所属阶段：阶段0·俄罗斯实演访问支路
年层：Y（当前年）
时间窗口：社区叙事以7月1日开端，图排7月1日—3日；完整三日起讫未逐章确认。不是十月第三次世界大战期间的俄罗斯事件。
原作范围：超炮SS2《能力实演旅行篇》，原为《魔法禁书目录Ⅱ》BD／DVD特典全8话，再收录《外典书库2》；不等于小说《禁书SS2》。
别名与触发词：俄罗斯能力实演 / 能力实演旅行篇 / 超炮SS2 / RUSSIA-DEMONSTRATION / RUSSIA-DEMONSTRATION-01

== 1. 核心定位 ==
美琴为能力实演访问俄罗斯的“购物中心”，一则“很有价值的橘子”传说把她带入生物炸弹与跨国阴谋。她受到保安员误拘后自行追查，与蕾莎协作，发现有人要通过袭击学园都市提升自身技术价值。玩家可作为访问随行者、现场目击者或另一端的调查协力者介入。
俄罗斯现场与学园都市调查是远程协作的两端，人物不因一通电话瞬间跨国；魔法侧新生之光参与其间，但美琴也不会因此自动掌握所有魔法知识。

== 2. 不可丢失的核心事实 ==
- “很有价值的橘子”起初是都市传说，后来与生物炸弹袭击对应。美琴阻止袭击，却被保安员Eniya怀疑、拘束；救人与被怀疑可以同时成立。
- 美琴脱出后独自调查，蕾莎提供信息，“Code EIC”成为线索。不能把蕾莎写成来参战的俄罗斯军方人员。
- 美琴曾怀疑同为Code EIC研究员的保安员Setali，询问后嫌疑解除；不能为了制造敌人把她直接定为幕后。
- 生物炸弹的实行者与“购物中心”上层的谋划要分开。后者图谋让学园都市受重创、拉低世界科学水平，抬高自己所持技术的价值。
- 美琴联系黑子，从“死亡项链”传闻追查潜入学园都市的敌人。黑子与初春查出并制服潜入者，不需要美琴回城代办这条线。
- “铀摆饰”是进一步变形的传闻，指向核攻击的可能；发现可能性不等于已知全部部署、已经发生核爆或危机已经解除。

== 3. 玩家可改写的部分 ==
玩家可救人、证明美琴的清白、避免拘束升级、核查研究者或支援学园都市端。若提前洗清嫌疑，不强制安排脱逃；如果玩家先识破上层目标，允许缩短线索链。
可选择技术防护、情报协作、谈判或撤离，不要求与每个保安员敌对。仅知道传闻不足以精确定位装置；处置重大威胁应由现场取得的证据决定。

== 4. 节点推进表 ==
每轮最多一个主要节点；远程场景只传递实际发出的信息。

RUSSIA-DEMONSTRATION-01 有价值的橘子
进入条件：玩家随能力实演访问抵达“购物中心”，或在当地接触美琴。
场景目标：确认传闻的内容和传播场所，判断是否值得追查。
可见角色：美琴、当地居民与访问相关人员。
玩家行动：询问传闻、观察异常、陪同实演准备、保留可核的时间和地点。
结果：都市传说成为调查入口，不直接等同已确认的炸弹位置。
下一节点：RUSSIA-DEMONSTRATION-02。

RUSSIA-DEMONSTRATION-02 阻止袭击却遭怀疑
进入条件：生物炸弹袭击显现，玩家或美琴已能采取现场行动。
场景目标：保护人员并说明谁在制止袭击，避免误认扩大。
可见角色：美琴、保安员Eniya及受威胁的人。
玩家行动：协助救援、保存目击证词、说明身份、拒绝把全部混乱归罪于来访者。
结果：默认美琴阻止袭击后被怀疑并拘束；玩家若成功澄清，沿用自由调查分支。
下一节点：RUSSIA-DEMONSTRATION-03。

RUSSIA-DEMONSTRATION-03 蕾莎提供的线索
进入条件：美琴脱出或获得继续调查的自由，与蕾莎取得联系。
场景目标：从单次袭击追向研究线索，而非只与保安体系纠缠。
可见角色：美琴、蕾莎。
玩家行动：核对信息、询问Code EIC、选择共享内容、寻找能够验证线索的人。
结果：默认Code EIC进入调查范围；蕾莎参与协作，不代表双方已经理解彼此全部背景。
下一节点：RUSSIA-DEMONSTRATION-04。

RUSSIA-DEMONSTRATION-04 排除Setali的嫌疑
进入条件：调查指向兼任研究员的保安员Setali。
场景目标：检验怀疑，区分研究联系与策划袭击的证据。
可见角色：美琴、Setali；蕾莎按联络情况参与。
玩家行动：询问、比对Code EIC线索、查证陈述、在证据不足时停止指控。
结果：默认Setali的嫌疑得到解除；把她当作敌人的既定判断必须修正。
下一节点：RUSSIA-DEMONSTRATION-05。

RUSSIA-DEMONSTRATION-05 技术价值的阴谋
进入条件：美琴与蕾莎能够整理袭击、研究与管理层线索。
场景目标：识别“购物中心”上层的收益逻辑与真正目标。
可见角色：美琴、蕾莎；上层人员只有实际追到或建立联系后才可见。
玩家行动：核对证据、保护知情人、区分实行者和策划层、向可信协力者预警。
结果：默认发现针对学园都市的大规模袭击图谋，其目的在于抬高自身技术价值，不是普通实演事故。
下一节点：RUSSIA-DEMONSTRATION-06。

RUSSIA-DEMONSTRATION-06 死亡项链的另一端
进入条件：美琴联系黑子，请她调查新出现的传闻。
场景目标：让学园都市端获得足够线索，又避免把俄方推测当成已证地点。
可见角色：俄罗斯端为美琴、蕾莎；学园都市端为黑子、初春，分场呈现。
玩家行动：整理传闻差异、远程通报、协助查找目击与可疑活动、维持可靠通信。
结果：默认黑子与初春开始调查潜入者；两端人员与知情范围保持独立。
下一节点：RUSSIA-DEMONSTRATION-07。

RUSSIA-DEMONSTRATION-07 潜入者落网
进入条件：黑子与初春查到学园都市内的潜入者，具备行动条件。
场景目标：制服敌人并保全继续调查所需的信息。
可见角色：黑子、初春及查获的潜入者；俄罗斯端只能经联络获知结果。
玩家行动：警戒、救护、支援控制现场、保存传闻与袭击的关联信息。
结果：默认潜入者被制服与捕获；这一成果不能自动证明跨国主谋或全部威胁已清除。
下一节点：RUSSIA-DEMONSTRATION-08。

RUSSIA-DEMONSTRATION-08 铀摆饰的警报
进入条件：调查发现变形后的“铀摆饰”传闻。
场景目标：把核攻击可能性作为新危险交接，决定防护与继续查证方向。
可见角色：两端仍在联络的美琴、蕾莎、黑子与初春，继续分场处理。
玩家行动：核查新线索、通知可信防护力量、保全已捕人员与证据、选择继续调查或退出现场。
结果：默认阶段收束到潜入者被捕、核攻击可能性浮出；不自动宣布核袭击已被完全阻止，更不制造已发生核爆。
下一节点：RD-END-A／RD-END-B／RD-END-C。

== 5. 偏离与改写 ==
玩家可改变拘束、追查和抓捕过程；不为了恢复默认顺序释放已经抓到的敌人。重大威胁的最终处置须另有行动和证据，不能只凭一则传闻直接结案。

== 6. 换篇条件 ==
完成当前安全与情报交接，或玩家主动离开即可换篇。进入七月其他事件时检查旅行与通信条件，不把本篇当作小说禁书SS2或三战俄罗斯的前置通关任务。

== 7. 防剧透边界 ==
橘子阶段不直接公布核攻击、管理层阴谋及Setali清白；按线索顺序或玩家实际突破揭露。魔法相关认识按人物已知内容处理，不因作者知道新生之光便让所有人全知。

== 9. 收束结果 ==
- RD-END-A 默认阶段收束：误拘与研究嫌疑已梳理，管理层目标被发现，学园都市潜入者被捕；核攻击可能性仍需继续处理。
- RD-END-B 玩家主导：采用实际达成的澄清、抓捕或防护结果，未解决风险不自动消失。
- RD-END-C 玩家退出：交接所知情报后离开，不判失败、不安排惩罚性袭击。
