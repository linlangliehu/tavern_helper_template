【事件包：Skill-Out篇】
事件包ID：SKILL-OUT
所属阶段：阶段5·旧约·十月开端
年层：Y
时间窗口：官动层10月3日，白天GROUP初次任务、夜间御坂美铃遇袭与收尾
别名与触发词：十月三日Skill-Out事件 / 驹场利德肃清事件 / SKILL-OUT / SKILL-OUT-01
证据定位：O29；旧约SS；官方动画年表；O28为入组前因

== 1. 核心定位 ==
一方以GROUP成员身份接受肃清任务，却从目标口中听到无能力者受害的现实；夜间再与上条分别保护美铃。不同立场的暴力不被抹平，滨面也由此走向暗部杂务生活。

== 2. 不可丢失的核心事实 ==
- 10月3日是一方加入GROUP后的首次任务，不泛写成十月上旬任意一天。
- 驹场利德向一方指出，有能力者把无害的等级0当作狩猎对象；理解这种处境不等于认可袭击无辜者。
- 原作默认一方杀死驹场，随后带着其手机处理任务之外的事。
- 家长希望带子女离开学园都市的动向构成背景，美铃遭Skill-Out追袭；一方暗中枪援，上条击倒滨面，救人由两条行动共同完成。
- 滨面之后成为ITEM杂务人员，是后续去向，不是某个正式机构对他作出的降职处分。GROUP当日并未解散。

== 3. 玩家可改写的部分 ==
可调查受害者、阻止肃清、促成驹场生还、提前保护美铃或说服滨面停手。救下无能力者不需要牺牲家长，一方的暗部身份也不强制玩家服从同一命令。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；沿用旧8个完整节点ID。

SKILL-OUT-01 GROUP的第一份工作
进入条件：10月3日，一方已在0930后与暗部达成安排。
场景目标：了解对驹场的肃清命令，识别其保护最后之作与受制于上层的处境。
可见角色：一方、GROUP联络者。
玩家行动：核对任务、准备支援、查找目标与无辜者的区别。
结果：执行命令与调查真实背景可同时选择，不默认玩家也成为杀手。
下一节点：SKILL-OUT-02。

SKILL-OUT-02 被忽视的等级0
进入条件：接触驹场及其活动地区。
场景目标：听取能力者猎杀无害无能力者的情况，核对驹场反抗的起因。
可见角色：驹场、一方、相关街区人员。
玩家行动：调查、谈判、保护受害者、寻找停止冲突的替代方案。
结果：肃清目标有具体动机与牵挂，不能只以无能力者犯罪团伙概括所有人。
下一节点：SKILL-OUT-03。

SKILL-OUT-03 驹场的抵抗
进入条件：肃清行动继续，或玩家尝试改变命令。
场景目标：处理驹场依靠武装与地形的反击，避免波及街区居民。
可见角色：一方、驹场。
玩家行动：救人、制止交战、协助夺械或争取撤离。
结果：原作默认驹场被一方杀死；成功干预则记录其生还与后续处境，不安排补偿死亡。
下一节点：SKILL-OUT-04。

SKILL-OUT-04 留下的手机
进入条件：驹场事件已有结果，一方拿到其手机或同等线索。
场景目标：追查驹场担忧的受害者与仍在继续的袭击，不把任务完成等同问题消失。
可见角色：一方；玩家可通过手机信息与街区人员联络。
玩家行动：保存线索、保护相关人、协助一方处理额外事务。
结果：原作默认一方带手机去做命令之外的行动，选择如何守护弱者。
下一节点：SKILL-OUT-05。

SKILL-OUT-05 美铃的归途
进入条件：3日夜，美铃在家长撤离动向的背景下被Skill-Out盯上。
场景目标：确认她的行踪与危险，不让普通家长成为政治命令的牺牲品。
可见角色：美铃、上条；滨面与追袭者在追查路线出现。
玩家行动：护送、交换联络、识别尾随或联系支援。
结果：日常的相遇转为实际救援，袭击者与目标均有可追踪位置。
下一节点：SKILL-OUT-06。

SKILL-OUT-06 暗处的支援
进入条件：美铃遭追击，一方也接触到现场。
场景目标：为她争取逃离通道，阻止持械者继续逼近。
可见角色：一方、美铃、Skill-Out成员。
玩家行动：掩护、引路、救护或配合不暴露全部身份的支援。
结果：原作默认一方用枪暗中帮助美铃；救援仍需应对滨面的最后阻拦。
下一节点：SKILL-OUT-07。

SKILL-OUT-07 上条与滨面
进入条件：上条赶到，美铃仍受到滨面威胁。
场景目标：制止袭击，拆开滨面对能力社会的不满与伤害无辜者的行为。
可见角色：上条、滨面、美铃。
玩家行动：协同制服、谈判停手、带走美铃或救护其他人。
结果：原作默认上条击倒滨面，美铃脱险；滨面此后的人生并非当场被永久封死。
下一节点：SKILL-OUT-08。

SKILL-OUT-08 会合之后
进入条件：当夜袭击停止，伤者与家长安全已核实。
场景目标：完成一方与GROUP会合、受害者回访及滨面去向的交接。
可见角色：一方、土御门、结标、海原；其他人物按各自现场报告出现。
玩家行动：交接证据、探望、保留联络或拒绝后续暗部委托。
结果：原作默认GROUP继续活动；滨面转入ITEM生活的后续成为10月9日可用前因。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
驹场生死、美铃安全和滨面选择分别记录，不互作代价。保留旧完整节点与完成记录；旧存档较晚发生的剧情记作偏移，不倒退时钟或把ITEM去向当成官方惩处。

== 6. 换篇条件 ==
SKILL-OUT-08完成、玩家明确退出/跳时或威胁提前解决后可换篇。正常接10月7–8日CDOC-01，再接9日DARK-BATTLE-01；不能把本案放到暗部大战之后才作为其前因补演。

== 7. 防剧透边界 ==
只揭示参与者能掌握的命令与街区事实，不预告DRAGON或麦野后续结局。后继暗部故事可正常进入，玩家不必永远留在同一组织视角。

== 8. 状态写回契约 ==
同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留旧项。驹场、美铃与滨面的实际结果写主线进度.正史锚点.玩家偏移，护送与街区回访写任务追踪。

== 9. 收束结果 ==
- SO-END-A：近原作，驹场死亡，美铃获救，GROUP继续活动。
- SO-END-B：玩家阻止肃清或改变滨面袭击，保全更多人。
- SO-END-C：留下街区救护与家长联络，不强制效忠暗部。
- SO-END-D：玩家退出，场外事件按已有因果结算。
- SO-END-E：原创多方调停，无代价转嫁或强制败局。
