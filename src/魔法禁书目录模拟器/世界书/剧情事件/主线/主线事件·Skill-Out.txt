【事件包：Skill-Out篇】
事件包ID：SKILL-OUT
所属阶段：阶段0·旧约·前日谭
时间窗口：阶段0内（无固定日期锚点）
别名与触发词：Skill-Out / 无能力者集团 / Lv0结社 / 武装无能力者 / 驹场利德 / SKILL-OUT

== 1. 核心定位 ==
本篇是阶段0的社会派主线事件：学园都市底层"无能力者（Level 0）"结成的武装自助集团 Skill-Out 的活动浮出水面。事件主题是"零与满"——在超能力至上的都市里，一无所有的人如何自处：互助、越界、还是被体制碾碎。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段0中因纠纷、委托、朋友被卷入而接触 Skill-Out。玩家可以是能力者、无能力者、调停者、追查者等任意立场，本篇对"有无能力"不预设褒贬。

== 2. 不可丢失的核心事实 ==
- Skill-Out 不是单一犯罪组织，而是多个无能力者自助团体的统称：收保护费、销赃、帮同伴讨说法，也照顾街区里的自己人。
- 其成员多为对能力开发绝望的 Level 0，普遍持有武器（刀械、电击器、改造装备），以武补能。
- 驹场利德是其中最有号召力的干部之一：讲义气、有底线、反对无谓伤人，试图把散装团伙拧成互助网络。
- 能力者与无能力者之间的日常摩擦（歧视、霸凌、资源差距）是 Skill-Out 壮大的土壤。
- 警备员对 Skill-Out 的态度是弹压为主；风纪委员视其为重点盯防对象。
- 事件的收束以"底层秩序如何重建"为核心：帮派解散、转向正业、被收编、或达成新的街区默契，都属合法结局。

== 3. 玩家可改写的部分 ==
- 立场自由：加入、合作、对抗、调停、或只是路过被卷入，全部合法。
- 驹场利德及其同伴的路线：可以被玩家劝向正业、推向极端、或保持原状。
- 具体冲突的胜负与处置：武器冲突的规模、警方介入程度、受害者结果都可由玩家改变。
- 无能力者社区的生存状态：玩家可以带去资源、工作机会、或只是尊严层面的改变。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；"以武补能"的底层逻辑也允许玩家借鉴运用。

== 4. 节点推进表 ==
节点ID格式：SKILL-OUT-{NN}（必须使用完整ID，禁止简写如SO-01）。每轮最多推进一个主要节点。

场景目标：玩家接触到底层街区的生存规则与 Skill-Out 的存在（收保护费/互助两面的初次印象）。
可见角色：Skill-Out 成员、街区商户、（可选）驹场利德。
玩家行动：观察、交涉、被勒索时应对、或主动接触。
结果：玩家了解 Skill-Out 的双面性；与至少一名成员建立联系。

玩家行动：深谈、质疑、合作、或把情报带给官方。

结果：冲突规模与伤亡程度由玩家的介入决定（本卡不使用死亡收场判定，冲突后果按剧情事实呈现）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变立场、介入方式或冲突处置时，保留当前锚点切分支推进。
- 核心结果改写：玩家改变 Skill-Out 的整体走向（提前转型、全面洗白、被彻底弹压等）时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按背景因果自行发展（冲突迟早爆发），不强制玩家参与。
- 本篇允许与暗部冲突支线交叉引用，但 Skill-Out 本篇的锚点优先。
