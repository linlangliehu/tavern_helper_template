【事件包：创约第三卷·手铐行动】
事件包ID：GENESIS-03
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第3卷；追捕与逃亡双视角。
时间窗口：本篇Y年12月25日，与创约第二卷并行。社区译文序章的15:00是场景时间，不等于已证的行动正式启动时刻；尾声另有下一晨背景，不据此迁移行动主日。
别名与触发词：创约第三卷 / 创约第三卷手铐行动 / GENESIS-03

== 1. 核心定位 ==
一方通行试图通过手铐行动终结暗部，却把没有完整情报的执法者、逃亡者和受害儿童放进同一张清剿名单。安娜引入的尼古拉斯金币进一步扭曲投降与生存选择。玩家可跟随白井黑子检查执法现场，也可随浜面仕上、泷壶理后从追捕中保护无辜者；两线由信息与救援接合，不要求玩家同时在两地。

== 2. 不可丢失的核心事实 ==
- 手铐行动属于本卷，目标是清理学园都市暗部；不是新约的格雷姆林行动，也不是创约第二卷结束后的另一天。
- 黑子与警备员乐丘丰富搭档。警备系统内部也会失控，制服与通缉名单都不能直接证明善恶。
- 花露过爱的生物攻击使黑子中毒；乐丘为她取得解药。浜面、泷壶则从被追捕者立场接触行动造成的混乱。
- Drencher Kihara Repatri保护受到暗部伤害的儿童，人工幽灵Frillsand #G与他有关；木原端数操纵的Ladybird会以人的脑组织维持自身，儿童因而成为猎物。
- 地下的“学园都市最大禁忌”涉及异常空间，不是普通逃生隧道。原作Drencher死亡，浜面阻止Ladybird；木原端数依赖金币许愿，最终因枪械走火死亡。
- 尼古拉斯金币是安娜投入的圣诞限定魔术媒介，不是可靠的好运护符。旧暗部框架遭重创，但受害者与异常空间的余波没有随行动结束而消失。

== 3. 玩家可改写的部分 ==
- 拒绝无差别清剿、保存执法记录、核实名单，改变被捕者、警备员与儿童的生存处境。
- 提前救治黑子、协助Drencher撤离儿童，或阻止Ladybird继续捕食；不把默认伤亡写成不可阻止的条件。
- 揭穿金币的介入、阻断木原端数的选择，改变其结局；不为玩家建立许愿加成或失败惩罚。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；双视角只按玩家所在地点或实际获得的消息切换。

GENESIS-03-01 清剿令下的名单
进入条件：选择本卷锚点，或12月25日接触手铐行动的部署、通缉与封锁。
场景目标：辨认一方通行的改革目标与现场执行之间的落差。
可见角色：白井黑子、乐丘丰富；逃亡侧为浜面仕上、泷壶理后。
玩家行动：加入巡查、查验抓捕依据，或帮助被追捕者观察封锁；不凭旁白读取另一线的情报。
结果：确定玩家视角与需要保护的对象，清剿带来的现实危险进入场景。
下一节点：GENESIS-03-02。

GENESIS-03-02 被颠倒的安全区
进入条件：目击失控抓捕、逃亡者求助，或接到黑子的调查信息。
场景目标：在警备员与暗部双方的暴力中建立可信的撤离路线。
可见角色：浜面仕上、泷壶理后、现场警备员；黑子按实际联络出现。
玩家行动：保护伤员、核对追捕理由、记录滥杀线索，避免把所有逃亡者送回未经核实的收容点。
结果：浜面一线转向保护实际受威胁者，黑子一线开始发现执法内部问题；双方可共享证据但不自动结盟。
下一节点：GENESIS-03-03；若已直接接触儿童藏身处，可先转GENESIS-03-04并保留未解决的救治任务。

GENESIS-03-03 生物攻击与解药
进入条件：遭遇花露过爱的攻击，或收到黑子中毒的求援。
场景目标：阻止生物威胁扩散，并找到有效救治而非继续盲目追捕。
可见角色：白井黑子、乐丘丰富、花露过爱。
玩家行动：隔离暴露区域、追索解药、协助乐丘救治；也可在攻击前控制危险源。
结果：原作黑子获得解药并存活，后续转向调查警备系统；玩家改变暴露情况时，不补写她必然中毒。
下一节点：GENESIS-03-04。

GENESIS-03-04 保护者与捕食者
进入条件：跟随逃亡线抵达儿童所在区域，或得到Drencher与Ladybird的消息。
场景目标：区分保护儿童的木原研究者与把儿童当作补给的袭击者。
可见角色：Drencher Kihara Repatri、Frillsand #G、浜面仕上、受保护的儿童、Ladybird。
玩家行动：护送儿童、协助防守、寻找Ladybird的控制线索，争取让保护者活着撤离。
结果：原作Drencher未能生还，浜面接下保护儿童的责任；玩家救下他时按实际关系继续，不另造替代死者。
下一节点：GENESIS-03-05。

GENESIS-03-05 最大禁忌的地下路线
进入条件：儿童撤离受阻，追逃双方接近地下异常空间。
场景目标：穿过无法按普通都市地图理解的区域，制止Ladybird对儿童的持续威胁。
可见角色：浜面仕上、泷壶理后、儿童、Ladybird；Frillsand #G按现场状态介入。
玩家行动：侦察出口、掩护弱者、配合浜面阻止捕食，不把未知空间当成安全传送门。
结果：原作浜面击败Ladybird，儿童获得存活机会；异常空间本身仍需后续处理。
下一节点：GENESIS-03-06。

GENESIS-03-06 金币不能保证的结局
进入条件：木原端数暴露控制者身份，或玩家发现尼古拉斯金币左右参与者的判断。
场景目标：阻止木原端数继续操纵杀戮，识别安娜对行动的外部干预。
可见角色：木原端数、浜面仕上；安娜的作用通过事后揭露确认。
玩家行动：制止持枪对峙、夺离金币、保存其来源与使用记录，也可要求端数放弃许愿并投降。
结果：原作端数企图靠金币让枪故障，却被走火击中身亡；玩家成功解除武装时采用存活处置，不强制复现走火。
下一节点：GENESIS-03-07。

GENESIS-03-07 不是干净的胜利
进入条件：主要追杀停止，幸存者能够接受救治、安置或调查。
场景目标：核对救出的人、失控执法证据与地下未解威胁。
可见角色：黑子、受伤的警备员与幸存者；Frillsand #G的变化仅在实际观察到时呈现。
玩家行动：提交调查材料、寻人、保护儿童身份，追踪Frillsand与异常空间的联系。
结果：原作旧暗部秩序遭破坏，Frillsand吸收异常空间能量而成为新危险；幸存与被捕情况逐人记录，不宣称所有人永久脱罪。
下一节点：本包收束；同日另一视角可回接GENESIS-02-01，海外事件可接GENESIS-04-01，12月29日余波可接GENESIS-05-01。

== 5. 分支和偏离规则 ==
- 未亲历的另一视角只能通过求援、报告或玩家明确换视角进入；切换不使日历自动加一天。
- 若救下Drencher、控制端数或提前稳定Frillsand，保留成果，后卷按剩余原因重组，不安排惩罚性替代伤亡。
- 最大禁忌与金币只保留本卷已知功能；不把它们升级为可无限调用的玩家系统。

== 6. 换篇条件 ==
追捕、儿童保护与现场救治已有可交代结果，或玩家明确离开、跳跃、另选锚点时换篇。创约第五卷是数日后的装甲列车事故与新救援，不把本次手铐行动重新执行一次。

== 7. 防剧透边界 ==
安娜操纵金币、木原端数的幕后身份与Frillsand后续变化，必须经调查或相应节点揭露。另一卷上条的病房战况不自动成为暗部参与者的知识。

== 8. 状态写回契约 ==
- 沿用主线进度：当前阶段写“创约”，阶段序号写整数8；当前节点只写实际到达的完整ID，阶段状态按实际推进或收束更新。
- 正史锚点的当前锚点、默认走向记录手铐行动；玩家偏移记录救人、执法分歧、金币处置与异常空间变化，不强制回正。
- 已完成节点、可触发节点去重后整体replace，保留真实历史；未亲历的双线节点不能凭卷末结算伪造完成。
- 救治、追捕、儿童安置与调查沿用任务追踪；人物位置、存活和信任沿用在场人物、NPC关系、势力关系、世界线记录，不新建字段。

== 9. 收束结果 ==
默认收束是暗部清剿付出巨大代价、黑子存活并追查内部问题、浜面保护儿童以及地下威胁遗留。玩家改变的伤亡与责任归属持续有效；与创约第二卷同日并行，与创约第五卷按幸存者及未解风险接力。
