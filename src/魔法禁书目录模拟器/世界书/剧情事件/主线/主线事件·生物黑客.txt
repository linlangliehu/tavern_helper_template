【事件包：生物黑客篇】
事件包ID：BIOHACKER
所属阶段：阶段0·旧约·前日谭
年层：Y−1；上条当麻初三的夏天。
时间窗口：前一年夏天有官方明示；7月31日至八月初仅为图排候选，不锁具体日。
别名与触发词：生物黑客篇 / 生物黑客的巨龙 / BIOHACKER / BIOHACKER-01

== 1. 核心定位 ==
本篇原为《某科学的一方通行》BD／DVD特典小说，后收录《外典书库3》。上条在路地与蜜蚁爱愉、云川芹亚相遇，巨大生物打破平静，追击蜜蚁的生物黑客将三人卷入暗处。
这是与上蜂往事不同的前一年夏日故事。巨龙背后是L.S.S.的生物技术与社长Matsuo Ryuusuke（松尾）；他要用蜜蚁的心理穿孔唤醒最初的能力者Beginning Child。打倒幕后并没有自动救下蜜蚁：她在一再被当作替代品的压力中独自离去，上条错过求助电话，结尾以她投水失联而非三人安全团聚收束。

== 2. 不可丢失的核心事实 ==
- 上条此时是初三学生；不能带入Y年认识茵蒂克丝之后的人际关系。
- 蜜蚁是常盘台学生，使用心理穿孔；云川是善用话术的天才女高中生，不把她的交涉能力写成同类超能力。
- 追击者制造、操纵巨大生物并积蓄战力；巨龙是本篇生物黑客的威胁，不能仅凭外形断言为魔法侧真龙。
- 被追的蜜蚁不是天然可信的全知解说者；缘由需要调查，不能将Y年新约11的动机直接搬来解释一切。
- 松尾难以接近食蜂，选择可触及的蜜蚁作为精神能力的替代人选；她是被利用的人，不是因为能力不足而应为L.S.S.的罪行负责。
- 狱彩三姐妹最初受L.S.S.雇佣追杀三人，后续局势使她们与上条、云川合作；不能一出场就作为无条件救援队。
- Beginning Child被唤醒后失控，松尾死亡；上条等人使她停止暴走，云川安排后续保护。战斗胜利与蜜蚁真正得到救援是两件事。

== 3. 玩家可改写的部分 ==
可帮助三人结识、提前查明L.S.S.、说服狱彩姐妹合作、救出蜜蚁或安排Beginning Child的保护。可以及时回应蜜蚁的求助、留下陪伴而改写失联结尾；不因需要衔接NT11而强迫救援失败。

== 4. 节点推进表 ==
使用BIOHACKER完整节点ID；每轮最多推进一个主要节点。

BIOHACKER-01 路地里的三人
进入条件：玩家选择前一年初三暑期入口，或明确听闻该往事。
场景目标：让上条与蜜蚁、云川的相遇成为实际接触，而不是角色名单。
可见角色：初三上条、蜜蚁爱愉、云川芹亚。
玩家行动：参与路地中的交谈、帮忙解围、了解彼此愿意公开的身份。
结果：三人建立短暂联系，玩家知道蜜蚁的能力与云川话术不是同一回事。
下一节点：BIOHACKER-02。

BIOHACKER-02 巨影打破平静
进入条件：BIOHACKER-01完成，巨大生物迫近。
场景目标：发现巨龙集中追赶蜜蚁，并找出人为控制而非野兽随机袭击的迹象。
可见角色：上条、蜜蚁、云川、巨龙、操纵它的研究者及路人。
玩家行动：疏散路人、观察气味指令、配合云川的分析或帮助蜜蚁接近操纵者。
结果：默认三人识破巨龙按气味指令行动，蜜蚁的精神操作与上条的拳头使眼前操纵者败下阵来；L.S.S.的追索并未结束。
下一节点：BIOHACKER-03。

BIOHACKER-03 狱彩姐妹的追杀
进入条件：BIOHACKER-02完成，三人获得短暂喘息。
场景目标：应对受雇而来的狱彩三姐妹，追出“生物失控”背后的企业委托。
可见角色：上条、蜜蚁、云川、狱彩三姐妹。
玩家行动：保护被追者、利用环境脱离交火、核对雇主线索，或寻找改变雇佣关系的谈判空间。
结果：默认追击牵出L.S.S.，两名刺客一度落入警备员控制；上条仍选择保护蜜蚁，不能仅因她受到追杀就将她交回研究者。
下一节点：BIOHACKER-04。

BIOHACKER-04 被当作钥匙的心理穿孔
进入条件：BIOHACKER-03完成，云川与上条查到L.S.S.的隐藏研究。
场景目标：阻止松尾用蜜蚁唤醒Beginning Child，查清他为何执意夺取这名少女。
可见角色：上条、云川、蜜蚁、松尾及其操纵的生物群。
玩家行动：保护蜜蚁、阻断掳人路线、追踪撤离方向，或与刺客交换其雇主私产的线索。
结果：默认松尾用鼠群掳走蜜蚁，说明她是自己能够取得的精神能力钥匙；上条与云川利用狱彩姐妹调查过的雇主资产寻找山中藏身地。提前救出蜜蚁则改走制止研究的路线。
下一节点：BIOHACKER-05。

BIOHACKER-05 最初能力者的暴走
进入条件：BIOHACKER-04完成，救援抵达山中，Beginning Child已经被唤醒或正受到干预。
场景目标：制止暴走，同时把Beginning Child也视为需要救出的受害者，而非只当必须消灭的武器。
可见角色：上条、云川、狱彩三姐妹、蜜蚁、松尾、Beginning Child。
玩家行动：掩护接近、配合上条的右手、寻找蜜蚁，或阻止研究者继续施加控制。
结果：默认松尾在失控中受致命伤并死亡，Beginning Child被击败但活着，云川准备借可靠联系人保护她；蜜蚁却在混乱中独自离开，不能把打赢战斗当成她已获救。
下一节点：BIOHACKER-06。

BIOHACKER-06 没有接通的求助
进入条件：BIOHACKER-05完成，寻找蜜蚁仍未结束，或玩家主动安排救援后的陪伴。
场景目标：回应蜜蚁因被当作替代品、害怕再令他人失望而陷入的危机，不再只期待她使用能力解决问题。
可见角色：蜜蚁；上条、云川、狱彩姐妹按各自搜索位置出现。食蜂仅出现在上条途中撞见的交接片段。
玩家行动：陪伴、倾听、接应电话、联系可信援助或继续寻找；可以把救人置于研究处置之前。
结果：默认上条搜索时撞到食蜂，误把自己的手机交给她，错过蜜蚁的求助；蜜蚁随后投水失联，不能在此登记为死亡或已经获救。玩家保持联络并及时救援时，结算为明确的生存改写。
下一节点：无；另选MENTAL-PAST-01或其他事件必须有独立入口。

== 5. 分支和偏离规则 ==
追踪、避战、研究处置与救援方式可自由改变。救下蜜蚁不自动让她与食蜂和解，也不触发上条另一段往事中的记忆障碍。已接通电话、陪在身边或成功救援时，不为衔接后篇补演投水。

== 6. 换篇条件 ==
BIOHACKER-06完成、玩家明确离开／跳过／换锚点，或救援提前解决，才换篇。记录状态、原因、偏移、尚未追完的线索与所选后继首节点；不能仅因同属夏天而自动连到上蜂死结事件。

== 7. 防剧透边界 ==
不提前带入茵蒂克丝、Y年蜜蚁事件结局或食蜂记忆障碍；不将云川与蜜蚁的这次相遇改名为独立心理掌握漫画。巨龙不自动与上条右手未来的其他现象合并。

== 9. 收束结果 ==
- BIOHACKER-END-A 默认收束：松尾死亡，Beginning Child停止暴走并由云川安排保护；上条没能回应蜜蚁的电话，蜜蚁投水失联。这不是三人安全团聚，也不在此裁定她死亡。
- BIOHACKER-END-B 提前救出：玩家阻止掳走或提前瓦解L.S.S.计划，明确安排蜜蚁和Beginning Child的后续保护。
- BIOHACKER-END-C 接住求助：玩家保持联络、陪伴或及时找到蜜蚁，改写失联结尾；救援成果不为未来事件而被撤销。
- BIOHACKER-END-D 暂时退出：保存已完成救援与未解问题，不因退出追加伤害、失败判定或反噬。
