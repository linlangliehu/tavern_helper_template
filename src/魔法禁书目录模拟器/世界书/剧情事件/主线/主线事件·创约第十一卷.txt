【事件包：创约第十一卷·伪地狱与回生阶梯】
事件包ID：GENESIS-11
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第11卷；死亡后的旅程与回生通道争夺。
时间窗口：序章回接Y＋1年1月6日23:58的死亡确认；死后主段按社区时间线归于1月7日。官方简介使用“寒假最后一天”等相对时间，不能据此把死亡改成7日。伪地狱的主观旅程不换算成现实世界多天。
别名与触发词：创约第十一卷 / 创约第十一卷伪地狱阶梯 / GENESIS-11

== 1. 核心定位 ==
上条在死亡后遇到金斯福德，并与已死的伪CRC同行，试图穿越地狱返回现实。眼前环境不是普适的死后世界说明书，而是约翰＝瓦伦丁＝安德烈亚借CRC之名搭建的回生装置。旅程逐渐揭露这位同行者的过去，也将“大家一起回去”的愿望推到只能供一人使用的出口前。

== 2. 不可丢失的核心事实 ==
- 上条的现实死亡时刻已经由医生确认；金斯福德主动进入死后领域，履行帮助上条的承诺，不是她创造了这座伪地狱。
- 同行的“CRC”实际是约翰＝瓦伦丁＝安德烈亚。旅途中出现的过去揭示他与蔷薇十字传说的关系，不能把他的自称等同于真实身份。
- 众人先沿层层向下的地形寻找出口，遇到牛头怪、三头犬、哈耳庇厄与渡河障碍；回生阶梯位于旅程后段，不是从入口一路向上走。
- 伪地狱混合多种地狱意象，作用是把已死灵魂的归属改造成可返回生者世界的模糊状态。它由约翰为自己准备，仅有一个回生名额，不代表世界所有死亡都可如此撤销。
- 金斯福德阻止约翰抢先登阶，仍希望救他而非只把他消灭。原作两位专家留在崩解的伪地狱下方，上条独自攀登一次性阶梯。
- 攀登中上条的力量、感官与记忆逐渐消退，他仍想回到同伴身边。本卷末没有现实复活重逢，现实侧的火葬与归来由创约第十二卷承接。

== 3. 玩家可改写的部分 ==
- 在明确选择死后视角后参与辨路、避开守卫、取得通行工具、核对同行者的说法；活人角色不因开启本包被自动杀死或传送。
- 提前识破伪地狱的构造，改变与约翰的交涉、金斯福德掩护方式和出口使用安排。
- 若玩家实际建立能改变回生限制的新条件，保留该分支；仅许愿“全部复活”不视为已经完成救助，也不因偏离原作而强行拆毁玩家方案。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；死后视角与现实同伴视角分开，不能互相自动共享记忆。

GENESIS-11-01 死亡确认后的邀请
进入条件：GENESIS-10-07实际进入死亡线，或玩家明确选择本卷死后锚点；现实时间仍回接6日23:58。
场景目标：确认上条已死、金斯福德为何前来，以及他是否仍愿意回去。
可见角色：死后视角的上条、金斯福德，入口处的伪CRC；现实医生与同伴仅在另行切换视角时出现。
玩家行动：询问回生提议、整理仍想见的人、辨别约翰的同行请求；现实侧玩家可照顾同伴而不窥知死后对话。
结果：原作上条接受旅程，三人临时同行；这不是现实复活完成，也不撤销医生的死亡确认。
下一节点：GENESIS-11-02；拒绝死后视角时留在现实善后，不补写虚构的死亡经历。

GENESIS-11-02 向下的层级与守卫
进入条件：接受金斯福德引导，开始寻找通往下一层的道路。
场景目标：理解倒置、逐层收窄的地形，避免把熟悉神话当作绝对地图。
可见角色：上条、金斯福德、约翰，牛头怪等守卫意象。
玩家行动：观察路径与异物、跟随引导绕行或协助排除守卫，记录不同地狱传统混杂的矛盾。
结果：队伍继续向下；牛头怪等现象能影响旅程，却不能据此宣称现实同伴也在同一地狱受罚。
下一节点：GENESIS-11-03。

GENESIS-11-03 泥地吊桥与鸟巢钥匙
进入条件：抵达三头犬活动的泥地与尚未放下的吊桥。
场景目标：拿到哈耳庇厄巢中的钥匙，开启通路而不是在泥地与怪物耗死。
可见角色：上条、金斯福德、约翰，三头犬与哈耳庇厄。
玩家行动：协助攀高取钥匙、看住守卫动向、操作吊桥，选择掩护与通过的顺序。
结果：原作众人利用通行工具继续深入，金斯福德的保护让上条得以通行；玩家可减少险情或改变协作方式。
下一节点：GENESIS-11-04。

GENESIS-11-04 渡河与约翰的过去
进入条件：越过前段守卫，旅程显现约翰的过往，队伍继续渡河并向更深处行进。
场景目标：把沿途记忆、蔷薇十字传说与约翰急于返回现实的企图联系起来。
可见角色：上条、金斯福德、约翰；过去片段中的克里斯托夫＝贝索尔德只是记忆所见。
玩家行动：核对约翰编造传说却又憎恨其传播的矛盾、协助筏渡、追问谁建立了这处空间。
结果：金斯福德揭明伪地狱由约翰制造，三人并非自然组成的救援队；约翰要返回现实摧毁他厌恶的传说及其影响，而装置只能送回一个灵魂。
下一节点：GENESIS-11-05。

GENESIS-11-05 冻湖前的一次性出口
进入条件：抵达最深处的冻湖区域，约翰调动伪地狱阻拦他人并争抢回生阶梯。
场景目标：阻止约翰把回生通道变成再度伤害现实世界的起点，同时寻找可行的救助安排。
可见角色：上条、金斯福德、约翰，以及受其控制的地狱现象。
玩家行动：辨认阶梯入口、避开阻拦、帮助金斯福德争取时间，向约翰提出不同于重演毁灭的选择。
结果：原作金斯福德留住约翰并让上条先走；她没有为自己抢名额，也没有放弃把约翰视作仍可救的人。伪地狱开始崩解，下方真正的地狱显露。
下一节点：GENESIS-11-06；若出口安排已被玩家实质改变，先记录实际去留再推进。

GENESIS-11-06 独自攀登仍要回去
进入条件：回生阶梯已开放，上条与留在下方的两位专家告别。
场景目标：在力量与感官逐渐淡去时维持返回同伴身边的意愿。
可见角色：攀登中的上条；金斯福德、约翰留在下方，茵蒂克丝、爱丽丝与同学只作为回忆浮现。
玩家行动：回应离别、选择支撑前进的记忆，或在现实侧保护同伴与遗体处理流程中的知情权。
结果：原作上条继续向生者世界攀登，本卷停在回生路上；不能在此节点宣布葬礼已结束、全员已经重逢或两位专家已经复活。
下一节点：本包收束；现实归来接GENESIS-12-01，具体回生发生于GENESIS-12-03。

== 5. 分支和偏离规则 ==
- 若上一卷上条存活，本包不自动发生；可留在实际世界线，或明确切换原作死后锚点而不覆盖存活记录。
- 出口的原作限制是当前装置的事实，不是给玩家新增的死亡惩罚。改变构造、说服同行者或另觅办法须有过程，成果不强制回正。
- 现实侧玩家能处理遗体与同伴悲痛，但不能凭卷名知道金斯福德的选择，更不能让所有NPC无来源地掌握伪地狱构造。

== 6. 换篇条件 ==
回生通道的使用者、留守者与旅程结果已明确，或玩家选择不再继续死后视角时换篇。1月7日是现实时间线的主段归属，不把层数、旅行感受或攀爬时长换算成现实多日。

== 7. 防剧透边界 ==
约翰的身份与装置真相随记忆和冲突揭露。阶梯能否送人回现实先保持当事人的希望与风险，不用下一卷已存在来消解当前离别，也不提前宣告现实同伴会如何接受归来。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8，当前节点使用完整ID，阶段状态依实际旅程更新；不新建死后等级或轮回次数。
- 正史锚点记录伪地狱与上条独自登阶的默认参照；玩家偏移记录不同出口安排、留守者与生存结果，不强制回正。
- 已完成节点、可触发节点去重后整体replace；没有亲历的现实或死后支线不伪造完成历史。
- 回生、掩护与现实照护沿用任务追踪；知情范围、去留、关系和世界线变化沿用NPC关系、在场人物、势力关系、世界线记录，不把主观时长写成现实日期推进。

== 9. 收束结果 ==
原作上条获得返回现实的唯一通路，金斯福德与约翰留在下方；回生希望因此有明确代价与未救之人，但本卷尚未完成现实归来。玩家改变的安排随世界线接到葬礼篇，而非被下一卷标题自动抹除。
