== 1. 核心定位 ==
天草式在伦敦准备向英国清教报告法之书事件，并参加特别编入考试。看似地下铁绘图的实地考核实为一场身份与通信被调换的骗局：真正考试是另一处小房间里的魔术桌游，假冒者正趁机骗取Free Pass。
玩家可作为天草式的临时协力者、陪同人员或伦敦现场调查者介入。默认第一话从备考走向脱困后遭追捕，并不是“考试通过、正式入教”的轻松收束。

== 2. 不可丢失的核心事实 ==
- 天草式住在伦敦廉价酒店，面对报告与考试；法之书事件是已经发生的背景，不需要再演一次争夺才允许考试开始。
- 晚上七点的酒吧会面传达前往兰贝斯站F2的安排；看似由Freedia Strikers主持的联系，后来证明存在冒名与错接。
- 假考核要求绘出地下铁半径两公里内的路径、陷阱、供电等信息，限时三小时。天草式约五十人分成两三人小组，建宫约定两小时半后集合。
- 五和与对马遭遇尸蜡齿轮、铁处女等真实危险，五和的血被取用；不能把这些都当成安全的幻象训练。
- 真实考试在兰贝斯的小房间内，以魔术桌游模拟。天草式实际被引向Soho的地下铁；“真天草对假考官、假天草对真考官”的两条通信被交叉利用。
- 尸蜡模仿五和，利用她的血形成生命力联系、预读防御。五和与对马借亚当、夏娃肋骨与婚姻的象征调整联系，摆脱攻击并使尸蜡破碎；这不是夺取永久预知能力。
- 天草式脱出后决定自行追查黑幕、洗清嫌疑。真正的Freedia已把Free Pass给了冒名者，通信又被咒返破坏，向上级提出发现天草式即杀的追捕要求；她被欺骗，不因此等于幕后主谋。

== 3. 玩家可改写的部分 ==
玩家可核对会面与路线、提前发现通信异常、保护分组成员、降低伤势或保全身份材料。若揭破骗局，不强迫所有人重新进入陷阱。
可以在追捕开始前争取澄清，也可护送同伴、从假考官或Free Pass去向查起；成功与否取决于实际证据和对方的知情状态。不能用“任务完成”凭空换取正式录用、幕后伏法或全体无罪。

== 4. 节点推进表 ==
每轮最多一个主要节点；以下为第一话起案链，后续追捕与反调查不自动结案。

NECESSARIUS-EXAM-01 伦敦备考
进入条件：法之书事件已经发生，天草式在伦敦准备报告与考试。
场景目标：确认同行身份、报告任务与考试安排，避免把传言当正式通知。
可见角色：建宫斋字、五和、对马及在酒店的天草式成员。
玩家行动：整理报告、核对集合方式、约定失联后的联络办法、选择随哪一组行动。
结果：默认天草式准备参与编入考试，尚未取得通过资格。
下一节点：NECESSARIUS-EXAM-02。

NECESSARIUS-EXAM-02 七点的会面
进入条件：按安排赴晚间酒吧会面，或玩家已经察觉通知来源需要核实。
场景目标：取得考点安排，同时留下可核对的身份与路线信息。
可见角色：天草式代表；自称Freedia一方的人或通信对象，其真伪此时尚未揭露。
玩家行动：询问兰贝斯站F2的指示、核对通知、陪同赴约、给留守成员保留线索。
结果：默认天草式收到赴地下铁考点的安排；从角色视角只知道通知内容，不提前全知冒名骗局。
下一节点：NECESSARIUS-EXAM-03。

NECESSARIUS-EXAM-03 三小时的地下铁绘图
进入条件：天草式进入被告知的考核区域，开始分组。
场景目标：完成地图任务并维持各组联络，识别任务危险程度与“考试”说法是否一致。
可见角色：建宫、五和、对马与按两三人分组的天草式成员。
玩家行动：记录路径和供电、标识陷阱、设立返程记号、遵守两小时半集合约定或提出更安全安排。
结果：默认调查展开，三小时考核与两小时半集合是两个不同时间要求；现场危险逐渐超过安全演练。
下一节点：NECESSARIUS-EXAM-04。

NECESSARIUS-EXAM-04 尸蜡与真实的血
进入条件：五和与对马一组遭遇尸蜡齿轮、铁处女等陷阱。
场景目标：保住同伴，确认伤害并非幻象，避免继续盲信假考核。
可见角色：五和、对马；玩家按已选择的小组或实际赶到的位置介入。
玩家行动：防护、止血、撤离夹击区、保存陷阱与取血的线索、通知其他小组。
结果：默认五和受伤、血被敌方利用；玩家若避免取血，后续袭击效果随之变化，不强行补伤。
下一节点：NECESSARIUS-EXAM-05。

NECESSARIUS-EXAM-05 被调换的考生与考官
进入条件：掌握足以核对实际地点、考核形式或通信对象的异常线索。
场景目标：识别Soho地下铁与兰贝斯真实考场的错位，阻止身份继续被冒用。
可见角色：天草式现场成员；真实Freedia和假考生在另一处考场，只有确已建立的视角或通信才能获知其情况。
玩家行动：对照路线、验证通知、保全身份凭据、尝试绕开被污染的联系渠道。
结果：默认真考试为小房间中的魔术桌游，真假考生和真假考官被交叉接通；假天草正在骗取Free Pass，不是天草式自导自演。
下一节点：NECESSARIUS-EXAM-06。

NECESSARIUS-EXAM-06 打破生命力联系
进入条件：尸蜡借五和的血模仿并预读她的防御，或玩家已准备好其他可行脱困办法。
场景目标：改变敌方赖以预读的联系，脱离真实陷阱。
可见角色：五和、对马与模仿五和的尸蜡。
玩家行动：掩护术式调整、利用已识别的象征关系、防止同伴误入攻击、接应撤离。
结果：默认五和与对马借肋骨和婚姻象征调整生命力联系，使尸蜡破碎并脱困；玩家有效的替代方案直接保留，不强制重复术式演出。
下一节点：NECESSARIUS-EXAM-07。

NECESSARIUS-EXAM-07 地面上的追捕令
进入条件：天草式脱出地下，或玩家已让骗局提前暴露。
场景目标：交接伤员与身份线索，决定如何应对误判和Free Pass流失。
可见角色：建宫、五和、对马及会合成员；Freedia的命令只有通过实际得到的消息进入他们的视野。
玩家行动：清点人员、保全证据、寻求可信中间人、追查冒名者或避开尚未澄清的追捕。
结果：默认天草式决定自行追查以洗清嫌疑；真实Freedia误给Free Pass后通信遭破坏，提出发现天草式即杀的要求。脱困不是通过考试，追捕与反调查由此开始。
下一节点：NE-END-A／NE-END-B／NE-END-C。

== 5. 偏离与改写 ==
优先保留玩家避免的伤势、提前查明的身份和成功送出的证据。没有发生取血或通信破坏时，后续机制相应变化；不给幕后自动补回优势，也不因玩家退避而判考试永远失败。

== 6. 换篇条件 ==
完成脱困与人员交接、形成澄清方案或玩家主动退出即可暂停。后续七话属于继续追捕与反调查的空间，本包不跳过过程直接宣布考核合格或英国清教解除全部嫌疑。

== 7. 防剧透边界 ==
入口只给当事人收到的安排；真假考官、真实桌游考点、尸蜡联系与追捕误判须按实际线索揭露。分场信息不自动共享，不能让五和在地下先知上级会议中的命令。

== 9. 收束结果 ==
- NE-END-A 第一话默认收束：天草式脱困后决定查黑幕；冒名者取得Free Pass，误判引发追捕。不是全8话完结或考试通过。
- NE-END-B 玩家主导：采用玩家真实完成的防伤、破局或澄清成果，尚未找到的幕后与证件去向继续保留。
- NE-END-C 玩家退出：完成必要交接后暂停，不追加惩罚性伤亡、不自动判定入教成败。
