事件包ID：DAIHASEISAI

别名与触发词：大霸星祭 / 祭典开幕 / 运动会对决 / 赛场风云 / DAIHASEISAI

== 1. 核心定位 ==
本篇是阶段4的舞台型主线事件：学园都市最大规模的秋季运动会"大霸星祭"开幕，全球直播下超能力者展开盛大对决，同时暗部与境外势力借祭典人潮暗流涌动。事件主题是"舞台与暗流"——聚光灯下的热血赛场，与看不见的角力同时进行。
玩家进入本篇的方式：开局锚点直接选在本篇；或随阶段4时间推进自然进入祭典。玩家可以选手身份参赛、以风纪委员/后勤/媒体身份服务祭典、或纯粹逛祭典——每条路都能撞见主线。
与支线事件包"大霸星祭（活动框架）"的关系：本篇提供主线剧情节点，支线包提供祭典活动玩法；两者可同时激活、并行推进，冲突时以本篇锚点优先。

== 2. 不可丢失的核心事实 ==
- 大霸星祭是学园都市每秋季举办的全域运动会，七大同时开幕、全球直播，是学园都市对外展示能力的最大窗口。
- 赛事规模空前：能力者同场竞技、观众与境外访客海量涌入、风纪委员与警备员全员上岗。
- 祭典是全球直播的舞台——任何赛场内的事件都会被世界看见，这既是荣耀也是风险。
- 暗部势力与境外情报机构将祭典视为行动窗口：人流、噪音、多国访客提供了天然掩护。
- 御坂美琴等 headline 级能力者的比赛是焦点话题；上条当麻以倒霉体质活跃在各个意外现场。
- 祭典期间萌发的最大暗流指向"使徒十字"阴谋（罗马正教），但该阴谋属独立事件包，本篇只埋线不启动。

== 3. 玩家可改写的部分 ==
- 参赛与名次：玩家可以自由参加任何项目，成绩由能力与发挥合理演绎（不判定失败，允许黑马奇迹）。
- 焦点对决的走向：可参与或搅动美琴、当麻等人的名场面。
- 暗部动作的处置：玩家可以提前发现、阻止、利用或加入暗流行动。
- 全球直播下的曝光度：玩家可以选择扬名、隐藏实力、或制造话题。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变参赛项目、身份路线或暗流处置时，保留当前锚点切分支推进。
- 核心结果改写：玩家高光改写焦点赛事结果、公开揭露暗部行动、或促成国际关注时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 祭典成绩与名声属跨篇事实：玩家在本篇获得的公众知名度会被后续篇章引用。
- 延后与跳过：玩家不参与主线时，赛事与暗流按背景因果自行发展，不强制玩家参与。
