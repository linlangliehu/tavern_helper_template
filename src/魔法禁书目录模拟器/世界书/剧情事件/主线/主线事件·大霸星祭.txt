【事件包：大霸星祭篇】
事件包ID：DAIHASEISAI
所属阶段：阶段4·旧约·科学侧大霸星祭
年层：Y
时间窗口：9月19日开幕、翌日事件；祭典背景19–25日，后续重逢不强填逐日日期
别名与触发词：超炮大霸星祭事件 / 外装代脑争夺 / DAIHASEISAI / DAIHASEISAI-01
证据定位：O22、O24；超炮漫画7–10卷；超炮T官方分集简介03、07、10、12–15及留存条目

== 1. 核心定位 ==
由御坂妹妹失踪追入外装代脑计划，分头阻止警策、幻生与美琴异变。它和使徒十字共享祭典，但不是同一个阴谋，也不因魔法侧仪式结束而自动结案。

== 2. 不可丢失的核心事实 ==
- 御坂妹妹因被误认成美琴参加气球猎人比赛，暗部MEMBER的巴场介入；妹妹失踪引发调查。
- 食蜂对美琴身边人的记忆作处理，遮蔽妹妹相关行动；双方经历误解后合作，不将食蜂固定成袭击主谋。
- 警策看取曾在才人工房接受能力开发并照顾多莉；她发现多莉作为复制体被实验消耗，反抗后遭关押分离。她是这段实验的受害者与复仇行动者，不是研究员。
- 木原幻生夺取外装代脑Exterior的利用权，通过御坂网络推动美琴异变，企图使其抵达等级6。
- 原作默认黑子在初春、佐天协助下制止警策；食蜂以预设的记忆与口令布局诱使幻生触发外装代脑自毁，切断网络干涉。
- 美琴仍在失控，上条与削板合力救人；上条右臂被冲断，断口出现八条龙吞噬异常力量。此为本篇现象，不能照搬为三战的左手觉醒。
- 后续食蜂与警策接触继承姐姐记忆的多莉妹妹，面对仍活着的具体人物，不是取回一个记忆体或简单复活死者。

== 3. 玩家可改写的部分 ==
可保护妹妹、提前促成食蜂与美琴互信、救出人质、阻断Exterior或说服警策。允许不经断臂便救下美琴，不因阻止异变而强迫另一个人成为实验品。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；跨场景用实际联络衔接，不让人物同时参加比赛与战斗。

DAIHASEISAI-01 开幕的城市
进入条件：9月19日进入祭典科学侧视角。
场景目标：确认比赛、观众和来访家长的日程，接触常盘台一侧的活动。
可见角色：美琴、食蜂、削板、婚后及同学；黑子以带伤观赛或联络身份出现。
玩家行动：参赛、观赛、陪同家长、加入朋友的约定。
结果：普通日程成立，之后的失踪与记忆异常有可核对的参照。
下一节点：DAIHASEISAI-02。

DAIHASEISAI-02 被误认的参赛者
进入条件：御坂妹妹被误认为美琴，参加气球猎人比赛。
场景目标：发现巴场对常盘台的针对布置，保护参赛者。
可见角色：御坂妹妹、巴场、常盘台选手。
玩家行动：支援、观察异常器材、追踪比赛后妹妹的去向。
结果：妹妹遭暗中针对并失去联络，调查不再只是胜负争执。
下一节点：DAIHASEISAI-03。

DAIHASEISAI-03 消失的联系
进入条件：翌日追查妹妹，美琴发现朋友不再正常记得自己。
场景目标：识别记忆遭处理与妹妹失踪之间的关联，不立即将食蜂所有行动定性为敌对。
可见角色：美琴、黑子、初春、佐天、食蜂派阀成员。
玩家行动：核对通讯录和既有约定、寻找独立证词、尝试联系食蜂。
结果：保留下来的物证能突破记忆遮蔽，调查有了可复核路线。
下一节点：DAIHASEISAI-04。

DAIHASEISAI-04 帮忙的人也被盯上
进入条件：婚后等协助追查，遭巴场一侧袭击。
场景目标：救护婚后，利用湾内、泡浮等取得的妹妹线索继续调查。
可见角色：婚后、湾内、泡浮、佐天、美琴；巴场在追查中出现。
玩家行动：救人、传递黑猫相关线索、追查暗部器材与撤离路线。
结果：朋友的协力没有因记忆被处理而消失，妹妹下落与敌方组织逐渐清晰。
下一节点：DAIHASEISAI-05。

DAIHASEISAI-05 警策的人质
进入条件：警策以初春、美铃等人的安全威胁美琴。
场景目标：救出人质，区分警策与食蜂的行动来源。
可见角色：警策、美琴、初春；食蜂在合作路线中出现。
玩家行动：破解遥控人形、核实人质位置、交换证据并协商联手。
结果：美琴与食蜂转向合作，真正威胁指向警策及木原幻生。
下一节点：DAIHASEISAI-06。

DAIHASEISAI-06 才人工房的旧事
进入条件：追查幻生，发现捕获目标只是替身。
场景目标：赶往Exterior相关设施，理解多莉、食蜂与警策的过去。
可见角色：食蜂、美琴；多莉旧事通过可信回忆或资料呈现。
玩家行动：追踪真身、保护设施中的人、核对过去实验而非怪罪受害者。
结果：幻生的目标不是普通控制设备，外装代脑与御坂网络的联系成为关键。
下一节点：DAIHASEISAI-07。

DAIHASEISAI-07 美琴的异变
进入条件：幻生开始借Exterior干涉御坂网络。
场景目标：救出被推向等级6的美琴，同时分派人员阻断供给与追查警策。
可见角色：异变中的美琴、上条、削板、食蜂、黑子；初春和佐天协助调查。
玩家行动：疏散、牵制、支援食蜂或加入黑子的搜寻。
结果：单次右手接触只能暂时压制，须切断持续干涉并处理残余力量。
下一节点：DAIHASEISAI-08；调查与Exterior线可按同步联络交错。

DAIHASEISAI-08 找到遥控者
进入条件：警策借金属液人形阻止黑子，初春与佐天追踪其观察手段。
场景目标：利用赛事小型摄像装置等线索定位警策本体，停止人质与遥控袭击。
可见角色：黑子、警策、初春、佐天。
玩家行动：核对监控、诱导视线、救助带伤黑子、阻断遥控路径。
结果：原作默认黑子找到并制止警策；该线的结束不等于美琴已恢复。
下一节点：DAIHASEISAI-09；已先处理Exterior则接DAIHASEISAI-10。

DAIHASEISAI-09 外装代脑自毁
进入条件：幻生追索解除限制的口令，食蜂预先的布局开始生效。
场景目标：支持食蜂利用记忆与口令陷阱切断幻生对网络的控制。
可见角色：食蜂、木原幻生。
玩家行动：掩护、保护撤离、阻止幻生识破陷阱或实行替代断联方案。
结果：原作默认Exterior自毁，幻生的干涉终止；美琴恢复意识却仍无法停止异变。
下一节点：DAIHASEISAI-10；警策线未处理则先回到DAIHASEISAI-08的未完成处。

DAIHASEISAI-10 伸向美琴的右手
进入条件：外部干涉已切断，但异常力量仍在美琴周围聚集。
场景目标：配合削板开路，把救援者送到美琴身边。
可见角色：上条、削板、美琴。
玩家行动：护送、保护周边、协助消除残余力量或执行提前准备的救援。
结果：原作默认上条右臂被冲断后八条龙显现并吞噬力量，美琴获救；具体真相不在此升级为通用能力说明。
下一节点：DAIHASEISAI-11。

DAIHASEISAI-11 仍能赴约的人
进入条件：异变解除，警策与幻生的行动均已终止或被改写。
场景目标：回访伤者，接续食蜂、警策与多莉妹妹的重逢。
可见角色：食蜂、警策、多莉妹妹；美琴等按各自善后场景出现。
玩家行动：协助会面、倾听各人意愿、恢复祭典约定或选择离开。
结果：原作默认救回美琴，旧实验留下的关系获得新的继续；重逢不是记忆物品归还，善后不必硬塞到25日。
下一节点：无（本篇结束）。
