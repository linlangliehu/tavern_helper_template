【事件包：演算战斗服篇】
事件包ID：NT-PROCESSOR-SUIT
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年十二月十一日至十二日前后图排，紧接NT18，先于赴英行动
别名与触发词：演算战斗服篇 / A.O.弗兰西斯卡事件 / 莉莉丝护送 / NT-PROCESSOR-SUIT

== 1. 核心定位 ==
作品范围：新约19。无窗大楼被送往太空只能暂时拖住科隆尊，城市里的另一化身仍在争夺系统与肉身。浜面护送莉莉丝、一方追查战斗服、上条与亚雷斯塔追踪附身者，最终在医院交汇，为离城赴英提供不可省略的桥段。
本篇不是旧约19的DRAGON事件，也不是NT20之后的英国终战。

== 2. 不可丢失的核心事实 ==
- 亚雷斯塔把无窗大楼作为载具发射，将科隆尊的主化身暂时带离城市。艾华斯在太空迎战，并通过新的魔导书维持米娜离楼后的存在。
- 地面的A.O.弗兰西斯卡是科隆尊附身府兰后的化身，目标涉及承载“书库”数据的演算战斗服。浜面被卷入诱饵安排，不应写成自愿盗取书库的恶徒。
- 艾华斯曾保住莉莉丝，并通过AIM扩散力场把她送回现世。浜面保护的是需要实际照料的婴儿形态存在；这不等于她已经具有后来接受治疗取得的稳定肉体。
- 医院交锋中，科隆尊使茵蒂克丝进入自动书记状态。米娜借新魔导书制止失控，亚雷斯塔使用灵式绊足表现的伽马刀手段分离府兰体内的科隆尊。
- 艾华斯的败退是布置的一部分：科隆尊企图驾楼返回时进入理想送行的“新天地”。这只是暂时阻断，后来她带着奈芙蒂斯和娘娘回来，不是本卷永久消灭魔神或恶魔。
- 亚雷斯塔让城市系统失去可供敌人直接接管的价值并组织疏散，又以西方之旗暂时封住科隆尊，为赴英寻找其根基争取时间。

== 3. 玩家可改写的部分 ==
- 可识破战斗服诱饵，让一方与浜面更早共享证据，优先保护婴儿与追击中的市民。
- 可预防自动书记被启动、保全府兰、改变城市封锁方式；不必为沿用正史而破坏已经保住的系统。
- 可与亚雷斯塔约定疏散、救治和行动边界，也可拒绝赴英；不把暂时同路写成全员原谅其既往行为。

== 4. 节点推进表 ==
NT-PROCESSOR-SUIT-01 飞离城市的大楼
进入条件：NT18余波中的科隆尊尚未被解决，无窗大楼被用作临时隔离载具。
场景目标：区分太空拖延与地面安全，找出仍留在城市中的敌方影响。
可见角色：地面的上条、少女形态亚雷斯塔与同伴；太空的艾华斯、科隆尊仅在独立视角或有证据的消息中出现。
玩家行动：组织撤离，确认离楼者，核对米娜的存在依托，调查残留附身与系统访问。
结果：原作艾华斯接手太空交锋，米娜借新魔导书返回地面；科隆尊并未因此失去全部行动能力。玩家若改用其他有效隔离，保留其真实作用范围。
下一节点：地面战斗服与追击线出现时进入NT-PROCESSOR-SUIT-02。

NT-PROCESSOR-SUIT-02 穿着诱饵的护送者
进入条件：浜面被卷入演算战斗服事件，莉莉丝出现在需要保护的位置。
场景目标：把“装甲承载的目标”和“穿着它的人”分开判断，避免追击伤及护送对象。
可见角色：浜面、莉莉丝、一方通行；追踪战斗服的A.O.弗兰西斯卡。
玩家行动：安排婴儿照料与安全转移，调查战斗服用途，向一方传递诱饵证据，切断敌人的追踪而非栽赃浜面。
结果：原作浜面一边遭追击一边保护莉莉丝；玩家可让双方更早协作，战斗服数据的价值与附身者的目标仍需处理。
下一节点：进入NT-PROCESSOR-SUIT-03。

NT-PROCESSOR-SUIT-03 把追逐带到可以救人的地方
进入条件：城市内多条追踪路线能够交换信息，府兰与A.O.弗兰西斯卡的关系逐渐显露。
场景目标：让护送、反附身与数据保护形成共同方案，而不是只争夺装甲。
可见角色：上条、亚雷斯塔、米娜、浜面、一方；按实际接触加入的医护与同伴。
玩家行动：核实府兰的身体状态，建立医院接应，安置莉莉丝，区分消灭恶魔与杀伤被附身者的行动。
结果：原作多方在医院的战场交汇；若玩家选择其他安全医疗点，可改写地点，但不能凭通信就宣布附身已经解除。
下一节点：面对附身者与自动书记风险时进入NT-PROCESSOR-SUIT-04。

NT-PROCESSOR-SUIT-04 医院内的两重控制
进入条件：科隆尊利用府兰与茵蒂克丝施压，队伍具备实施分离和救治的机会。
场景目标：阻断自动书记攻击，同时保护作为载体的两名少女。
可见角色：茵蒂克丝、府兰、上条、一方、亚雷斯塔、米娜；医院内需要转移的人员。
玩家行动：保护病房，拦截自动书记的攻击，协助米娜实施制止，给亚雷斯塔安全分离科隆尊的窗口，或采用已经验证的替代解除办法。
结果：原作米娜制止自动书记，亚雷斯塔以伽马刀式手段解除府兰附身；玩家若在启动前阻断控制，不补演一次医院破坏。解除结果按每名载体分别确认。
下一节点：进入NT-PROCESSOR-SUIT-05。

NT-PROCESSOR-SUIT-05 莉莉丝与暂时的封锁
进入条件：地面救援有了余裕，米娜能够传达艾华斯的信息，太空战的布置产生结果。
场景目标：说明莉莉丝被保住的事实，并判断科隆尊暂离是否足以保证长期安全。
可见角色：莉莉丝、亚雷斯塔、米娜、上条与实际在场者；艾华斯通过已经取得的信息说明。
玩家行动：安排父女相认与后续救治，验证新天地陷阱的作用，防范科隆尊返回，不把婴儿当作要挟亚雷斯塔的道具。
结果：原作莉莉丝与亚雷斯塔重逢，科隆尊短暂落入新天地后带着两名魔神返回；亚雷斯塔以西方之旗继续争取时间。玩家若让敌人无法返回，应按实际证据调整赴英的必要性。
下一节点：进入NT-PROCESSOR-SUIT-06。

NT-PROCESSOR-SUIT-06 疏散后的同路条件
进入条件：科隆尊的根基仍需追查，城市不能继续照常运作，队伍需要决定去向。
场景目标：落实平民疏散、莉莉丝安置与合作边界，再决定是否跨海行动。
可见角色：亚雷斯塔、上条、一方、浜面、泷壶、米娜；参与疏散的现有人员。
玩家行动：核对疏散路线与医疗资源，要求亚雷斯塔说明系统处置，提出保护同伴的条件，选择赴英或留城支援。
结果：原作亚雷斯塔使城市系统暂失可被夺用的价值，众人各有目的地同行赴英；一方的质问不等于当场处决亚雷斯塔，暂时合作也不抹去争议。玩家可保存更多城市功能或改变同行者。
下一节点：玩家选择赴英且敌方根基仍在时进入CORONZON-01；留城者按疏散与恢复任务继续，不自动转入阶段7。

== 5. 分支和偏离规则 ==
诱饵、附身、婴儿救治与城市撤离分别记录结果；得到战斗服不等于解决其他目标。前卷若保护了府兰或阻止大楼发射，本卷用真实残留威胁改写，不能再次强制附身。新天地与西方之旗都是有条件的拖延，不当作万能永久监狱。

== 6. 换篇条件 ==
医院危机、莉莉丝安置、城市疏散及是否赴英已明确后结束本卷。离城和合作须有玩家选择；不以十二月十二日到来强制切换。拒绝远征可保留城市恢复线，不登记已经完成英国事件。

== 7. 防剧透边界 ==
开局不公开莉莉丝的来历、府兰附身的全部机制与艾华斯故意败退。医院前不让NPC天然掌握全部解法。英国篇黄金复制体、科隆尊的最终仪式和22R身份冲突留待后续证据出现。

== 8. 状态写回契约 ==
正式进入本包时，主线进度.当前阶段记“新约”，主线进度.阶段序号使用整数6；主线进度.正史锚点.当前锚点记“演算战斗服篇”，主线进度.当前节点使用NT-PROCESSOR-SUIT完整ID。已完成节点、可触发节点以op:"replace"整体替换数组；战斗服数据、载体救援、莉莉丝安置、城市系统与疏散、合作条件写入主线进度.正史锚点.玩家偏移及世界线记录。仅使用现有任务追踪和NPC关系，不新增书库权限或疏散惩罚字段。
玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- 原作默认：医院危机解除，莉莉丝归来，城市疏散，临时同盟赴英追查科隆尊。
- 提前识破：玩家让追击者与护送者及早协作，减少医院受到的波及。
- 保全撤离：在阻止敌方接管的前提下保存更多系统与救援条件。
- 留城照料：玩家不参加远征，沿既有疏散、医疗与恢复线继续。
