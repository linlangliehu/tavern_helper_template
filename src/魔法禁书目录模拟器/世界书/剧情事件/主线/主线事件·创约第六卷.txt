【事件包：创约第六卷·涩谷跨年追杀】
事件包ID：GENESIS-06
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第6卷；涩谷与桥架结社超绝者。
时间窗口：本篇Y年12月31日，官方卷简介直接给出日期。元旦参拜与领事馆调查属于下一卷，不把本卷误归次年一月或新约。
别名与触发词：创约第六卷 / 创约第六卷涩谷追杀 / GENESIS-06

== 1. 核心定位 ==
云川芹亚邀请上条到涩谷打工，却把他带进超绝者围绕其生死展开的争执。阿拉迪娅要杀他，波罗尼亚魅魔救他；普通街头的魔女与猎巫者被卷入魔术冲突。玩家必须同时阻止追杀、保住受重伤的魅魔，并理解阿拉迪娅保护受排斥魔女的愿望与她伤害他人的手段为何冲突。

== 2. 不可丢失的核心事实 ==
- 云川的打工邀约是进入涩谷的具体起因；上条、茵蒂克丝、欧提努斯由此接触新的超绝者。
- 阿拉迪娅与波罗尼亚魅魔同属桥架结社，却对上条的处置相反，不能当成统一听令的敌军。
- 阿拉迪娅以自己认定的善行累积三倍回报，能把连续攻防纳入Triple Reload；这是她的魔术判断，不是世界书给玩家评善恶的奖励系统。
- 原作追杀中上条不止一次被杀，由旧善玛丽依其救济条件救回。救回不表示从未死亡，也不表示他或玩家从此可以无条件复活。
- 魅魔保护上条而重伤，云川负责寻找现实可用的医疗条件，旧善玛丽能提供特殊救治；救命仍需要具体准备，不是无条件复活按钮。
- 原作欧提努斯分析阿拉迪娅的术式，上条打破她的飞行与后续攻击并将其制服；阿拉迪娅存活，被约束后带回学园都市。
- 云川在魅魔衣物上留下定位发信器。安娜＝施普伦格尔企图利用阿拉迪娅的死制造更大冲突，却被安娜＝金斯福德压制并封入符咒构成的圆盘，亚雷斯塔因此获得追问结社的机会。

== 3. 玩家可改写的部分 ==
- 提前发现打工背后的风险、帮助魅魔逃离伤害范围、组织街头人群避难。
- 从阿拉迪娅保护魔女的愿望切入交涉，改变制服方式和信任形成；不要求她必然被打倒才允许活着退出。
- 改善魅魔救治条件、发现或协商定位器的使用、阻止安娜的嫁祸计划，影响次卷调查与结社态度。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；追杀线与急救线通过实际分工并行。

GENESIS-06-01 涩谷打工邀约
进入条件：选择本卷锚点，或12月31日接受云川的邀约来到涩谷。
场景目标：建立同行与工作关系，注意街头跨年人潮中的异常接触。
可见角色：云川芹亚、上条当麻、茵蒂克丝、欧提努斯。
玩家行动：询问工作内容、协助同伴、观察可用出口与联络方式；也可拒绝邀约后从街头救援切入。
结果：玩家与上条一行有了具体协作基础，阿拉迪娅的追杀打破普通打工安排。
下一节点：GENESIS-06-02。

GENESIS-06-02 同一结社的相反选择
进入条件：阿拉迪娅发起袭击，魅魔介入保护上条。
场景目标：先躲过致命攻击，再确认两名超绝者不是同一作战方。
可见角色：阿拉迪娅、波罗尼亚魅魔、上条、欧提努斯。
玩家行动：寻找掩体、掩护路人、配合魅魔转移，询问双方为何围绕上条作出不同选择。
结果：上条获得同伴保护，但原作这段追杀仍曾使他死亡并接受旧善玛丽救回；按实际发生情况记录，不强制玩家先死一次。结社内部分歧成为可以交涉的入口。
下一节点：GENESIS-06-03。

GENESIS-06-03 魔女与猎巫者的人潮
进入条件：战斗影响涩谷街头，普通人因恐惧与煽动互相针对。
场景目标：把平民从超绝者冲突中分离，阻止“保护魔女”变成继续伤人的理由。
可见角色：阿拉迪娅、魅魔、云川、上条与现场人群。
玩家行动：疏散、澄清谣言、保护被围攻者，观察阿拉迪娅如何用善行概念增幅魔术。
结果：原作魅魔为保护上条承受重伤；玩家可减轻伤势，但必须按实际生命状态安排下一步救护。
下一节点：GENESIS-06-04。

GENESIS-06-04 给魅魔争取治疗窗口
进入条件：魅魔重伤，或玩家已阻止重伤但仍需护送伤员离开封锁区域。
场景目标：让追击不再阻断救护，凑齐旧善玛丽所需的医疗条件。
可见角色：云川芹亚、旧善玛丽、波罗尼亚魅魔；上条与欧提努斯负责牵制追击。
玩家行动：寻找输液与救治场所、护送云川、传递伤情，或留在路口争取时间。
结果：原作云川借美容外科诊所条件维持魅魔生命，由玛丽继续照护；救人依赖具体分工，不以一句“超绝者不会死”略过。
下一节点：GENESIS-06-05。

GENESIS-06-05 打断三倍回报
进入条件：阿拉迪娅仍在追杀，且玩家已识别连续善行增幅的危险。
场景目标：中止她不断叠加的攻势，同时回应她想保护魔女的核心愿望。
可见角色：阿拉迪娅、上条、欧提努斯；玩家按位置支援。
玩家行动：分析地面影子与飞行术式的联系、避免给她任意延续攻击的机会，配合近身否定魔术或提出不杀人的替代方案。
结果：原作阿拉迪娅的飞行被打破，后续魔术被幻想杀手否定，最终被上条击倒；玩家通过交涉停战时采用该结果。
下一节点：GENESIS-06-06。

GENESIS-06-06 活着带回与暗处的干预
进入条件：阿拉迪娅不再主动追杀，魅魔已获得持续救护。
场景目标：落实不处死俘虏的选择，确认跨年之后可追查的线索。
可见角色：上条、阿拉迪娅、云川；安娜＝施普伦格尔、金斯福德、亚雷斯塔在实际见证或获知的另一现场呈现。
玩家行动：协商约束与护送、探望魅魔、核对发信器线索；若接触安娜的企图，可保护阿拉迪娅并阻止嫁祸。
结果：原作阿拉迪娅被带回，云川的定位器留下结社调查入口；金斯福德制住施普伦格尔，亚雷斯塔追问爱丽丝及桥架结社。未知的暗处事件不直接写成上条已知情报。
下一节点：本包收束；跨入次年1月1日可接GENESIS-07-01。

== 5. 分支和偏离规则 ==
- 阿拉迪娅的救济理念可成为关系变化的依据，不为她的每个行为背书；玩家的道德选择不换成数值奖惩。
- 若魅魔未重伤，医疗节点转为保护及确认身体状况，不补造伤口；若定位器未启用，下卷以已获得的联络线索调查，不凭空恢复它。
- 两位安娜必须全名区分。施普伦格尔被封印不等于死亡，更不等于所有NPC自动获知其位置。

== 6. 换篇条件 ==
追杀停歇、伤员有照护、阿拉迪娅处置与回城关系明确，或玩家明确离开、跳跃、另选锚点时换篇。跨年只按现实时间推进；本卷不提前完成领事馆之战。

== 7. 防剧透边界 ==
结社的最终仪式目标留待后续揭露。亚雷斯塔的审问与金斯福德的魔术只按可见范围呈现，不将暗处对话批量传给街头角色。

== 8. 状态写回契约 ==
- 主线进度当前阶段为“创约”、阶段序号8；当前节点用完整ID，阶段状态按实际推进、提前终止或收束更新。
- 正史锚点保留涩谷追杀、魅魔救治与阿拉迪娅存活的默认参照；玩家偏移记录停战、约束、定位线索与救治差异。
- 已完成节点、可触发节点整体replace并去重；救治、护送与后续调查沿用任务追踪，不把另一现场的未知事件记作亲历。
- 结社内部分歧、同伴信任、安娜的受控状态沿用NPC关系、在场人物、势力关系、世界线记录，不新增善行计分、复活次数或年层字段。

== 9. 收束结果 ==
默认上条与同伴活过跨年前夜，魅魔获救，阿拉迪娅活着进入后续关系，施普伦格尔的处境受金斯福德与亚雷斯塔干预。元旦从这些实际状态接入，不把暂时停战夸成桥架结社危机已全部解除。
