== 1. 核心定位 ==
完整承载最后之作病毒、假海原与艾扎力、闇咲逢魔救人执念三线。它们共享日期而非同一现场，不把一方的脑伤塞回妹妹实验，也不并入天使坠落。

== 2. 不可丢失的核心事实 ==
- 最后之作接触一方，31日发病；芳川告知天井亚雄植入病毒，企图利用她影响御坂网络。
- 一方在救最后之作、删除病毒时遭天井枪击，芳川赶到交火；原作默认天井死亡，一方与芳川被冥土追魂救治。一方留下脑损伤，后续康复依赖电极与御坂网络辅助，不强填装置配发日。
- 美琴请上条假扮恋人摆脱海原的追求；真海原出现，揭露冒充者是魔法师艾扎力。其任务涉及警戒上条周围聚集的势力，事件后与上条留下保护美琴的约定。
- 闇咲逢魔为救遭诅咒的女性而绑架茵蒂克丝、索求魔道书知识；上条救人并提出用右手解除诅咒的援助，不是新的清忆事件。

== 3. 玩家可改写的部分 ==
可任选或协调三线、提前删毒、保护一方免受枪击、识破冒充者、协助解咒。三线都须有结局记录，但可由玩家亲历、委托或场外结果完成；没有强制全知与三处瞬移。

== 4. 节点推进表 ==
默认入口AUGUST-31-01；31日可从AUGUST-31-05或AUGUST-31-07进入相应视角。每轮只推进一个主要节点；跨线按当前时间并行演绎或事后获悉，节点编号不意味着时钟回拨。

AUGUST-31-01 最后之作的来访
进入条件：8月30日深夜的一方视角，或31日得知这次相遇。
场景目标：接触逃离研究设施的最后之作，辨认她与普通妹妹的区别。
可见角色：一方通行、最后之作。
玩家行动：提供食宿、询问追踪者、协助联系研究人员。
结果：一方没有简单驱走她，保护关系的起点成立。
下一节点：AUGUST-31-02；也可切换尚未处理的AUGUST-31-05或AUGUST-31-07。

AUGUST-31-02 芳川说明病毒
进入条件：31日最后之作倒下，或追查其异常。
场景目标：查明天井植入病毒及其对御坂网络的危险，寻找最后之作所在位置。
可见角色：一方、芳川桔梗、最后之作；天井作为追踪目标。
玩家行动：核对脑内数据、保护芳川、追踪天井车辆或安排救护。
结果：救人需要处理具体病毒，不能仅关闭一次外部通信便算结束。
下一节点：AUGUST-31-03。

AUGUST-31-03 清除与枪击
进入条件：找到最后之作，天井试图阻止救援。
场景目标：给一方清除病毒的时间，同时防止天井开枪。
可见角色：一方、最后之作、天井；芳川随后赶到。
玩家行动：掩护演算、夺枪、转移孩子或代行已验证的清除方案。
结果：原作默认病毒被清除，一方因保护孩子遭头部枪击；芳川与天井交火，救护成为下一优先事项。
下一节点：AUGUST-31-04。

AUGUST-31-04 活下来以后
进入条件：交火结束，伤者需要急救。
场景目标：将一方与芳川交给冥土追魂，核实最后之作脱险。
可见角色：一方、芳川、最后之作、冥土追魂。
玩家行动：送医、联络、保护御坂网络，商议后续康复。
结果：原作默认天井死亡、两名伤者获救；一方的语言、运动与演算障碍及电极辅助留作后续真实状态。
下一节点：尚未处理的AUGUST-31-05或AUGUST-31-07；三线有处理结果后进入AUGUST-31-09。

AUGUST-31-05 两个海原
进入条件：31日美琴请求假扮恋人，或玩家追查海原行为异常。
场景目标：协助美琴摆脱纠缠，接触真海原提供的身份线索。
可见角色：美琴、上条、真海原、冒充海原的艾扎力。
玩家行动：配合假情侣计划、核验身份、保护真海原。
结果：冒充者被识破，普通恋爱纠纷转为针对上条关系网的潜入行动。
下一节点：AUGUST-31-06。

AUGUST-31-06 艾扎力的选择
进入条件：冒充身份暴露，艾扎力与上条对峙。
场景目标：应对其魔法攻击，弄清任务与他对美琴的个人感情之间的矛盾。
可见角色：艾扎力、上条；美琴按实际位置出现。
玩家行动：协助破术、谈判、让美琴自己决定与来访者的距离。
结果：原作默认艾扎力败退，留下保护美琴的约定；不因此强行设定玩家或美琴的恋爱关系。
下一节点：尚未处理的AUGUST-31-02或AUGUST-31-07；三线有处理结果后进入AUGUST-31-09。
