【事件包：C文书篇】
事件包ID：CDOC
所属阶段：阶段5开头·旧约·10月上旬（0930事件余波中、暗部大战前夜）

别名与触发词：C文书 / 阿维尼翁 / 反科学示威 / 康斯坦丁文书 / 法国行动 / CDOC / C Document

== 1. 核心定位 ==
本篇是旧约魔法侧线的国际章：10月起，罗马正教主导的反科学示威在全球爆发，科学侧被舆论围剿——而幕后引擎是教廷灵装「C文书」（康斯坦丁文书）：它能写出被信众视为"神的旨意"的未来蓝图，让数亿信徒按剧本行动。上条与土御门元春奉命飞赴法国阿维尼翁，与天草式的五和会合，直插文书本体。事件主题是"被写好的未来"——当信仰成为遥控器，谁有权按下按钮。
玩家进入本篇的方式：开局锚点直接选在本篇；或在10月上旬卷入示威浪潮/随上条一行赴法/受英国清教或学园都市委托截取文书情报。玩家立场自由：上条一行的同行者、示威现场的秩序维护者、教廷内部的清醒者、情报贩子、或借乱局谋利的独立势力。

== 2. 不可丢失的核心事实 ==
- 反科学示威：罗马正教信众在全球同步发起反科学游行与袭击，学园都市是头号抨击对象——0930事件的创伤让舆论战升级为世界级对立。
- C文书（康斯坦丁文书）：罗马正教最高级灵装之一，位于法国阿维尼翁教皇厅；其力量是书写"神认可的未来"，让读到/听到内容的人在不知不觉中按其行动——全球示威正是这台"意志遥控器"的输出结果。
- 阿维尼翁：法国南部教皇厅旧址，C文书所在；街区因示威陷入瘫痪，游客与市民被卷入。
- 上条+土御门：学园都市方少数能行动的战力——土御门的潜入与谍报、上条的正面突破构成双线；二人同行本身就充满喜剧与反差。
- 五和与天草式：作为英国清教协作线在法国接应，提供引导与后方支援——上条与本篇的五和互动为后续「圣人袭来篇」的护卫关系铺垫。
- 终局事实（原著重力线）：上条一行突入阿维尼翁，破坏C文书、断绝示威的"剧本源头"；全球示威随失去精神支点逐步退潮。教廷背后更深的影子（神之右席的意图）未被照亮——只是暂时的沉默。
- 战斗基调：都市游击+教皇厅攻略；玩家能力跨体系混用无反噬。

== 3. 玩家可改写的部分 ==
- 示威的退潮方式：随文书破坏自然平息（原著近似）、由玩家公开真相引爆信任危机、或被各方交易压下。
- C文书的残骸处置：销毁（原著近似）、被玩家截留为战略道具、或落入第三方（暗部组织/英国清教/情报贩子）。
- 土御门的任务边界：他带着学园都市的"另一份命令"行动——玩家可以选择揭穿、配合或互相利用。
- 与五和/天草式的关系：护送协作、结盟、或保守彼此的秘密。
- 教廷的后续反应：沉默消化（原著近似）、恼羞成怒升级对抗、或内部清洗浮出水面。
