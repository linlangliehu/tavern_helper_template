【事件包：C文书篇】
事件包ID：CDOC
所属阶段：阶段5·旧约·十月上旬
年层：Y
时间窗口：10月7–8日委托与阿维尼翁行动；日本与法国场景存在时差，不逐幕强填同一日界
别名与触发词：C文书事件 / 阿维尼翁行动 / CDOC / CDOC-01
证据定位：O31；旧约14及官介；官方动画年表；O28、O29为前序

== 1. 核心定位 ==
从全球反学园都市情绪追查正教灵装，到法国切断其作用。上条与五和同时受到魔法攻击与学园都市军事行动的威胁，不能把某一方的军队自动当成绝对安全的援军。

== 2. 不可丢失的核心事实 ==
- 亲船最中请求上条处理世界混乱，土御门带他赴法国阿维尼翁，五和在当地会合。
- C文书用于使信众认可教皇言论，借此放大正教的影响；它不是书写未来的预言本，也不表示所有抗议者都失去自主性。
- 救援者尝试切断阿维尼翁与梵蒂冈间的地脉，遭左方之地阻拦；学园都市驱动铠与空袭也威胁当地人员。
- 原作默认上条在教皇厅一带再战左方，破坏C文书；后方之水因左方牺牲普通人而将其肃清。
- 美琴从没有挂断的电话得知上条七月失忆；不是法国行动又使他失忆。

== 3. 玩家可改写的部分 ==
可提早查明文书、协调平民撤离、改变地脉切断或直接破坏方案，劝阻上层武力升级。美琴获知秘密的方式也可改变，不以失忆或平民伤亡作为固定代价。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；使用CDOC-01至CDOC-05完整ID。

CDOC-01 亲船的请求
进入条件：10月7–8日间，反学园都市动向升级，亲船接触上条。
场景目标：理解委托与文书嫌疑，在土御门协助下前往阿维尼翁。
可见角色：亲船、上条、土御门；美琴可在日本前奏出现。
玩家行动：核实目的、同行、准备联络和当地救护渠道。
结果：调查落到明确法国地点，不把十月第一周全部当作战斗日。
下一节点：CDOC-02。

CDOC-02 地脉切断受阻
进入条件：在阿维尼翁与五和会合。
场景目标：寻找切断文书效力所依赖地脉的方法，保护附近居民。
可见角色：上条、五和、左方之地。
玩家行动：协助布置、观察灵装反应、阻止左方伤及无辜者。
结果：原作默认左方现身阻止切断，任务转入正面战斗。
下一节点：CDOC-03。

CDOC-03 不安全的军事介入
进入条件：双方交战，学园都市驱动铠进入现场。
场景目标：避开对上条等人同样有敌意的攻击，抵达藏有文书的教皇厅。
可见角色：上条、五和、左方、驱动铠操作者及当地人员。
玩家行动：救护、寻找掩体、撤离、联络日本确认局势。
结果：原作默认上条联系美琴，通话未被及时切断；文书本体与空袭威胁同时逼近。
下一节点：CDOC-04。

CDOC-04 教皇厅再战
进入条件：左方携C文书再度攻击，学园都市空袭扩大破坏。
场景目标：在多方攻击中击败左方，破坏文书而非只打退持有人。
可见角色：上条、五和、左方；美琴仅经电话听到片段。
玩家行动：识别术式应对时机、配合近身破术、带离平民或阻止空袭波及。
结果：原作默认左方败北、C文书被毁；美琴由通话得知上条早已失忆，远端知情不能变成她在场参战。
下一节点：CDOC-05。

CDOC-05 文书之外的后果
进入条件：文书失效，现场可以救护与撤离。
场景目标：处理法国受害者、返程与失忆秘密，区分文书破坏和正教内部反应。
可见角色：上条、五和、当地救援者；后方之水与左方只在梵蒂冈视角出现。
玩家行动：救援、提交证据、安排返程、决定是否回应美琴的疑问。
结果：原作默认后方之水因左方牺牲无辜者将其肃清；这不是玩家不救人导致的惩罚，主角未必立即知道。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
文书、平民安危、左方去向与美琴知情分别记录。旧完整节点和完成记录继续有效；旧存档其他发生日或记忆经历转为玩家偏移，不用错误预言机制修补剧情。

== 6. 换篇条件 ==
CDOC-05完成、明确退出/跳时或灵装提前失效即可换篇。9日接DARK-BATTLE-01；后方之水正面袭击在十月中旬ACQUA，不把C文书余波延长到替代暗部大战。

== 7. 防剧透边界 ==
文书用途与左方术式通过本案查证，梵蒂冈场景不自动成为上条的知识。后继神之右席、英国和战争篇可按相应入口进入。

== 8. 状态写回契约 ==
推进、破坏与换篇同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留旧项。文书、军袭影响、左方去向与知情偏移写主线进度.正史锚点.玩家偏移，救护与返程写任务追踪。

== 9. 收束结果 ==
以下NT-END仅为旧包内标签，卷别仍是旧约14。
- NT-END-A：近原作，C文书毁坏，左方后被肃清，美琴得知七月失忆。
- NT-END-B：玩家提前破坏或隔离文书，减少战斗损害。
- NT-END-C：退出或委托善后，按实际消息范围继续。
- NT-END-D：原创解法，不追加失忆或以平民伤亡补偿改写。
