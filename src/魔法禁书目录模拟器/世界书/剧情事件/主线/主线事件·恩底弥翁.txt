【事件包：恩底弥翁的奇迹】
事件包ID：ENDEYMION
所属阶段：阶段4·旧约·大霸星祭季开幕前
年层：Y（当前年）
时间窗口：Y年9月15日—18日（剧场版本篇窗口）；9月19日祭典另篇处理。
媒介边界：《Road to Endymion》是电影前传；其与《群奏活剧》魔术表路线的对应不代表游戏所有路线都是同一正史。前传旧项目9月10日—12日、图排相关块9月10日—14日另作参考，不扩成本包起日。
别名与触发词：恩底弥翁的奇迹 / エンデュミオンの奇蹟 / ENDEYMION / ENDEYMION-01

== 1. 核心定位 ==
从街头歌手鸣护艾丽莎的出道机会，推进至宇宙电梯恩底弥翁上的大规模术式。科学都市的演出与航天设施是舞台，魔法侧人物和不死者蕾蒂丽才是不可删去的因果组成；不能改写成一场普通歌声增幅设备事故。
选本篇才进入电影事件。前传小说或游戏路线仅按玩家明确选择分层引用，不用游戏人物和结局自动填满电影时间窗。

== 2. 不可丢失的核心事实 ==
- 鸣护艾丽莎是无能力者街头歌手，缺少三年前以前的记忆。她获选参加恩底弥翁开通相关演出，歌声与奇迹相连，但不能把未明机制直接断言成已完成的能力增幅技术。
- 莎特奥拉·塞克温齐亚（Shutaura Sequenzia）率领黑鸦部队；三年前猎户座号事故与父亲死亡塑造了她对“88人的奇迹”的憎恨。她不是Browning，也不与艾丽莎简单构成雇佣杀手和目标的关系。
- 蕾蒂丽·坦格尔路德（Ladylee Tangleroad）是Orbit Portal公司的不死社长，企图利用塔、歌手与观众发动巨大术式以求死亡；不是单纯逐利的科学实验商人。
- 上条保护艾丽莎，茵蒂克丝参与理解术式；史提尔、神裂、美琴、一方通行等按各自任务介入。双方首次交战不等于魔法侧所有人都是最终敌人。
- 默认终局是阻止术式和塔撞击地面，莎特奥拉恢复记忆并与艾丽莎歌唱；艾丽莎与她重合后消失。不能宣告艾丽莎照常出道、塔如期开业而无人付出变化。

== 3. 玩家可改写的部分 ==
可提前调查公司、保护演出现场、协调魔法与科学救援，也可尝试保全艾丽莎独立存在。成功的替代结局作为玩家世界线事实保存，不伪装成电影原结局；失败也不强迫照抄电影伤亡。角色对奇迹的解释可以不同，不用全知旁白提前裁定。

== 4. 节点推进表 ==
保留ENDEYMION拼写与完整ID；每轮至多推进一个主要节点。

ENDEYMION-01 通天之塔
进入条件：选定电影锚点，当前处于9月15日前后。
场景目标：通过恩底弥翁开通宣传和街头活动认识事件舞台。
可见角色：上条当麻、茵蒂克丝、演出或城市相关人员。
玩家行动：参观、了解演出安排、接触工作人员或陪同日常活动。
结果：建立塔与庆典的公共信息，不把前传或游戏线路当成已完成经历。
下一节点：ENDEYMION-02。

ENDEYMION-02 歌声的少女
进入条件：接触鸣护艾丽莎的街头演唱。
场景目标：结识获选演出的少女，理解她的愿望与记忆空白。
可见角色：鸣护艾丽莎、上条当麻、茵蒂克丝。
玩家行动：倾听、庆祝入选、询问过去、陪同活动或保持距离。
结果：建立保护与信任关系；歌声异常不直接揭晓为某种科学能力。
下一节点：ENDEYMION-03。

ENDEYMION-03 被盯上的歌
进入条件：史提尔等对艾丽莎采取行动。
场景目标：保护少女并弄清魔法侧为何介入。
可见角色：史提尔及同行魔术师、莎特奥拉、上条、艾丽莎。
玩家行动：阻挡、护送、交涉、辨认双方目标或保留退路。
结果：默认黑鸦部队介入交战，少女的危险不止于演出纠纷。
下一节点：ENDEYMION-04。

ENDEYMION-04 塔的阴影
进入条件：少女得到暂时安置，玩家开始调查公司或事故。
场景目标：联系三年前猎户座号事故、莎特奥拉与艾丽莎的过去。
可见角色：艾丽莎、莎特奥拉、公司人员；蕾蒂丽按调查深度出现。
玩家行动：查事故资料、询问当事人、交换魔法情报、调查塔的用途。
结果：获得有待核对的记忆与动机线索，不把三年前事故重新发生在Y年。
下一节点：ENDEYMION-05。

ENDEYMION-05 出道活动
进入条件：推进至9月17日相关演出，且威胁未被提前消除。
场景目标：在演出与绑架、爆炸风险中保住艾丽莎和观众。
可见角色：艾丽莎、美琴、黑子、莎特奥拉、现场观众。
玩家行动：排查爆炸物、疏散、追踪掳人者、协助救援或取消活动。
结果：默认美琴与黑子保护现场，莎特奥拉追救艾丽莎并触及蕾蒂丽真相。
下一节点：ENDEYMION-06。

ENDEYMION-06 顶点对决
进入条件：9月18日塔上演出开始，或玩家提前接近术式核心。
场景目标：阻止蕾蒂丽利用演出完成巨大术式。
可见角色：蕾蒂丽、莎特奥拉、艾丽莎、上条与实际到达的同伴。
玩家行动：解读术式、切断设施配合、救出观众、阻止以杀艾丽莎破局。
结果：默认不死性使普通刺杀失效；救人和阻止塔崩落成为并行目标。
下一节点：ENDEYMION-07。

ENDEYMION-07 歌之奇迹
进入条件：塔面临崩坏，莎特奥拉与艾丽莎冲突进入关键点。
场景目标：争取记忆恢复与沟通，同时为排险队伍打开行动窗口。
可见角色：上条、莎特奥拉、艾丽莎、茵蒂克丝；其余救援者依所在位置行动。
玩家行动：阻止致命一击、保护歌唱、协助破坏三处爆碎螺栓或组织撤离。
结果：默认莎特奥拉恢复记忆并共同歌唱，排险条件逐一成立；不一轮自动完成全部战线。
下一节点：ENDEYMION-08。

ENDEYMION-08 篇章收束
进入条件：术式与坠落威胁被实际处理。
场景目标：确认地面安全、失踪者及各方去向。
可见角色：莎特奥拉、上条、茵蒂克丝和完成任务的救援者。
玩家行动：搜救、核实艾丽莎状态、照料伤者、保存证言或追查蕾蒂丽后续。
结果：默认塔偏离坠落路线、避免地面撞击，艾丽莎消失；其他处置按已发生事实记录。
下一节点：ED-END-A／ED-END-B／ED-END-C／ED-END-D／ED-END-E；收束后才可另选大霸星祭等篇。

== 5. 分支和偏离规则 ==
提前拆解阴谋可消除后续爆炸或坠落，不为名场面重造危险。保全歌手、改变莎特奥拉选择或取消演出均可形成自由分支，但须写明行动如何改变因果。游戏路线的既定结局不能替本篇行动产生结果。

== 6. 换篇条件 ==
ENDEYMION-08完成，或玩家明确退出、另选锚点、跳时越窗，或阴谋合理提前终止，才换篇。前传与游戏入口只作分层引用；进入新锚时记录已采用的媒介与偏移，不合并全部路线。

== 7. 防剧透边界 ==
事故与奇迹的谜底随调查揭开，区分回忆、人物推测和目睹结果。不能禁止本篇所需魔法侧登场，也不能顺势提前揭露后续魔神与新约。艾丽莎的默认消失必须延续，除非本次世界线实际改变了这一结果。

== 9. 收束结果 ==
- ED-END-A 电影默认收束：巨大术式与地面撞击被阻止，莎特奥拉恢复记忆，艾丽莎在重合后消失；不承诺宇宙电梯正常运营。
- ED-END-B 歌之守护者：玩家若改变消失结果，保存其实际依据与后续关系；否则只能守护留下的人和记忆。
- ED-END-C 提前粉碎：阴谋在发动前被阻止，实际避免的损失据实记录，不自动扩成全城零损失。
- ED-END-D 玩家退出：记录离开时尚存的危险和各方行动，不自动归入电影圆满结局。
- ED-END-E 原创收束：按玩家真正完成的解法改写人物与设施状态，明确不等同电影默认路线。
