【事件包：恩底弥翁篇】
事件包ID：ENDEYMION
所属阶段：阶段4·旧约·祭典与十字（剧场版时间带）
时间窗口：大霸星祭后-9月下旬
别名与触发词：恩底弥翁 / 宇宙电梯 / 天空城 / 恩底弥翁的奇迹 / ENDEYMION

== 1. 核心定位 ==
本篇是阶段4的科技奇观型主线事件：连接地面与太空的巨型宇宙电梯"恩底弥翁"成为学园都市的新地标，围绕这座天空城的科技阴谋与一位以歌声引发能力共鸣的少女展开。事件主题是"通天的梦想"——被寄予全人类期待的建筑，与藏在它影子里的野心。
玩家进入本篇的方式：开局锚点直接选在本篇；或在大霸星祭后因观光、任务、熟人邀约接触恩底弥翁。玩家立场自由：游客、保镖、调查者、少女的朋友、或阴谋方的对手。

== 2. 不可丢失的核心事实 ==
- "恩底弥翁"是学园都市建造的宇宙电梯，人类史上首个通天建筑，被视为科学复兴的象征；塔内观光、塔上科研区、发射平台三段结构。
- 一位以歌声影响他人能力状态的少女与恩底弥翁关系密切：她的歌声能引发能力者演算的共鸣与增幅，被部分势力视为"活体关键部件"。
- 阴谋方的目标与恩底弥翁的核心系统相关：企图利用塔与少女的能力实现一场大规模能力干预（具体口径为"科技阴谋"，不上升到世界观级真相）。
- 阴谋方具备塔内权限与武力，行动窗口设在塔的公开活动日。
- 事件的收束以"恩底弥翁的安全与少女的自由"为核心：阴谋粉碎、少女获得正常生活、塔如期运行，为合法结局。

== 3. 玩家可改写的部分 ==
- 与少女的关系：保护者、朋友、导师、或只是擦肩而过的目击者。
- 阴谋的揭露时机与方式：提前粉碎、正面决战、将计就计、或借官方力量。
- 少女能力的定位：让她摆脱"部件"命运、公开她的能力、或帮她找到不依赖阴谋方的出路。
- 高潮决战的舞台与方式：塔内任意层、塔外空中、发射平台，方式不限，含跨体系自由发挥（无反噬无代价）。
- 恩底弥翁的后续命运：如期启用、延迟检修、或带伤运行——按世界线记录处理。

== 4. 节点推进表 ==
节点ID格式：ENDEYMION-{NN}（必须使用完整ID，禁止简写如ED-01）。每轮最多推进一个主要节点。

ENDEYMION-01 通天之塔
进入条件：进入本篇（锚点选定或大霸星祭后推进）。
场景目标：玩家接触恩底弥翁——观光、任务或偶遇；天空城的震撼直观呈现。
可见角色：游客、塔内工作人员、（可选）歌声少女的远闻。
玩家行动：观光、领任务、探塔、留意异常。
结果：恩底弥翁进入玩家视野；歌声的传闻隐约可闻。
下一节点：ENDEYMION-02。

ENDEYMION-02 歌声的少女
进入条件：玩家接近歌声传闻或少女现身。
场景目标：与歌声少女相遇——她的歌声令在场能力者的能力产生共鸣波动。
可见角色：歌声少女、其监护人/经纪方、围观能力者。
玩家行动：接触、共听、试探歌声效果、关心她本人。
结果：少女与她的"被需要"处境进入玩家视野；共鸣现象确认。
下一节点：ENDEYMION-03。

ENDEYMION-03 被盯上的歌
进入条件：少女的共鸣能力公开度上升。
场景目标：多方势力围绕少女浮出——有想保护她的，有想"使用"她的；阴谋方的触手显现。
可见角色：阴谋方外围、少女身边人、（可选）当麻/美琴的同行者。
玩家行动：护卫、反侦察、警告、调查幕后。
结果：危机逼近少女；阴谋的存在与规模初现。
下一节点：ENDEYMION-04。

ENDEYMION-04 塔的阴影
进入条件：玩家深入调查阴谋。
场景目标：阴谋轮廓成形——对方瞄准恩底弥翁核心系统与少女能力的"组合"，行动窗口为公开活动日。
可见角色：阴谋方、塔内知情者。
玩家行动：收集证据、布局、通知官方、或准备正面拦截。
结果：阴谋计划为玩家所知；决战舞台锁定恩底弥翁。
下一节点：ENDEYMION-05。

ENDEYMION-05 活动日开幕
进入条件：行动窗口到来。
场景目标：塔的公开活动开始，阴谋方按计划行动——塔内接管与人质/系统控制同步发生。
可见角色：阴谋方执行队、塔内人员、游客。
玩家行动：拦截、疏散、反制、救少女、稳住系统。
结果：塔内攻防全面展开；玩家进入决战准备。
下一节点：ENDEYMION-06。

ENDEYMION-06 顶点对决
进入条件：阴谋方核心现身或玩家突入核心区。
场景目标：塔的高层决战——阴谋头目与玩家（及同伴）正面相对。
可见角色：阴谋头目、少女、（可选）当麻等协作者。
玩家行动：自由发挥（含跨体系能力、原创战术）；AI 按玩家能力与准备合理演绎，不判定失败收场。
结果：阴谋头目败退/被擒；核心系统危机解除。
下一节点：ENDEYMION-07。

ENDEYMION-07 歌之奇迹

场景目标：事件的温柔收束——少女的歌声首次只为"想唱"而唱；恩底弥翁的灯火如期亮起。
可见角色：少女、本篇主要角色。
玩家行动：陪伴、道别、安排少女后续、或公开事件真相。
结果：少女获得自由；恩底弥翁事件落幕。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变与少女的关系、揭露时机或决战方式时，保留当前锚点切分支推进。
- 核心结果改写：玩家提前粉碎阴谋、让少女能力公开化、或改变塔的命运时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按背景因果自行发展（阴谋在他人手中被粉碎），不强制玩家参与。
- 少女的能力设定以"歌声共鸣"为锚定事实，具体机制可随剧情细化，不与个人现实理论冲突。
