年层：Y（当前年）
时间窗口：社区叙事以9月3日抵达开端，图排9月3日—6日；后续“翌日”关系与图窗可作调度参考，不能冒充逐章已证的完整精确日历。
原作范围：超炮SS《学艺都市篇》，原为《魔法禁书目录》BD／DVD特典全8话，再收录《外典书库2》；与超炮SS2俄罗斯能力实演分篇。
别名与触发词：学艺都市篇 / Liberal Arts City / LIBERAL-ARTS-CITY / LIBERAL-ARTS-CITY-01

== 1. 核心定位 ==
美琴、黑子、初春与佐天参加广域社会参观，在学艺都市海滨遭遇奇怪飞行器的战斗。表面供游客欣赏的城市藏着“工作人员”、隐秘机库和灭口行动；佐天结识的少女Xochitl又把她们卷入魔法结社与城市的冲突。
玩家可随参观团、协助旅游设施或作为事件目击者进入。调查、保护佐天与游客疏散可以分工，但不能因主角们来自科学侧便删去魔法侧冲突。

== 2. 不可丢失的核心事实 ==
- 海滨活动期间，“云海之蛇”等奇怪机体引发真正的战斗，不能把一切都当成无风险表演。
- 美琴夜间调查，佐天同行潜入可疑设施，在机库遇见工作人员Olive Holiday；这次接触避免了直接交战，她们先行离开。
- 次日佐天结识Xochitl，陪她购买泳装并一同行动；城市中发生爆炸后Xochitl离去。她是“有翼者归来”相关人物，不是普通都市保安。
- 佐天夜里再访设施被Olive拘束，后来在海岸岩地险被伪装成海难灭口；Xochitl将她救出。玩家可以改变这些伤害，但默认关系不能反写成Olive救佐天、Xochitl灭口。
- 佐天说明经过后，酒店又遭武装工作人员袭击；美琴与黑子迎战，使同伴渡过这次袭击。
- 初春与佐天协助利用大型救生艇Salmon Red疏散游客；美琴与黑子迎击海上的“太阳之蛇”子机，黑子负伤后美琴以水分子翼继续行动，并与Xochitl交锋。
- 本包不自动给出全岛最终损害、全部游客撤离结果、Olive的最终处置或Xochitl此后的完整去向；这些不能从“开始疏散”直接推出。

== 3. 玩家可改写的部分 ==
玩家可改变潜入方式、拦住佐天独行、阻止灭口、保护黑子或调整疏散分工。已经避免的拘束和伤势不为补剧情重新发生。
玩家可向不同阵营求证，也可拒绝涉入秘密而专注救人。与Xochitl的合作、感谢与之后的交锋并不互相抵消，不强制把她固定成永久队友或绝对敌人。

== 4. 节点推进表 ==
每轮最多一个主要节点；同一晚和翌日按实际日期推进，不把八话挤成同一场战斗。

LIBERAL-ARTS-CITY-01 海滨的异样机体
进入条件：抵达学艺都市参加参观或海滨活动，遇上突发飞行器战斗。
场景目标：分辨表演与真实危险，先保护身边游客。
可见角色：美琴、黑子、初春、佐天及海滨游客。
玩家行动：疏散、观察机体、记录冲突来源、询问工作人员的说法。
结果：默认旅游活动被异常战斗打断，美琴开始怀疑城市表面解释。
下一节点：LIBERAL-ARTS-CITY-02。

LIBERAL-ARTS-CITY-02 夜探机库
进入条件：美琴准备调查可疑设施，佐天同行，玩家具备跟进条件。
场景目标：核对飞行器与设施关系，避免在信息不足时陷入围捕。
可见角色：美琴、佐天、Olive Holiday。
玩家行动：观察机库、掩护撤出、询问工作人员、保存亲见信息而不抢走未发现的资料。
结果：默认双方没有在此直接交战，美琴与佐天先行离开；调查仍未揭开全貌。
下一节点：LIBERAL-ARTS-CITY-03。

LIBERAL-ARTS-CITY-03 与Xochitl相遇
进入条件：次日佐天遇见Xochitl并答应陪同购物。
场景目标：建立真实接触，在日常交流与城市异常间保留判断。
可见角色：佐天、Xochitl；玩家与同伴按实际同行安排出现。
玩家行动：陪同、交流旅行经历、留意爆炸发生后的反应、保护受波及的人。
结果：默认城市多处爆炸打断同行，Xochitl离去；佐天开始想弄清她与城市秘密的关系。
下一节点：LIBERAL-ARTS-CITY-04。

LIBERAL-ARTS-CITY-04 再访设施的代价
进入条件：佐天当夜再次调查设施，或玩家已选择陪同和预警。
场景目标：阻止调查者孤立无援，确认工作人员隐藏了什么。
可见角色：佐天、Olive及相关工作人员。
玩家行动：陪同、约定联络、及时撤离、发现拘束后求援或跟踪转移。
结果：默认佐天被Olive拘束；若玩家成功阻止拘束，改为带着已知危险回报，不重复制造绑架。
下一节点：LIBERAL-ARTS-CITY-05。

LIBERAL-ARTS-CITY-05 海难伪装与救人
进入条件：Olive准备在海岸岩地灭口，或玩家已能阻断转移和加害。
场景目标：保住佐天与灭口证据，离开危险现场。
可见角色：佐天、Olive、赶来救人的Xochitl；玩家按接应位置参与。
玩家行动：报警求援、掩护救出、保护伤者、记录伪装事故的企图。
结果：默认Xochitl救下佐天；玩家提前救出则保留新成果，不要求佐天再次受害来维持相遇。
下一节点：LIBERAL-ARTS-CITY-06。

LIBERAL-ARTS-CITY-06 酒店袭击
进入条件：佐天向美琴等人讲述经过，武装工作人员前来袭击或被提前发现。
场景目标：保住同伴与住客，让调查信息不在灭口中消失。
可见角色：美琴、黑子、初春、佐天及武装工作人员。
玩家行动：组织躲避、支援防卫、抢救通信、引导非战斗人员离开交锋区。
结果：默认美琴与黑子迎战，使这次袭击未能得手；城市已不再适合继续普通参观。
下一节点：LIBERAL-ARTS-CITY-07。

LIBERAL-ARTS-CITY-07 Salmon Red疏散线
进入条件：需要让游客离开，能够组织大型救生艇的疏散。
场景目标：把游客引向可用撤离通路，并分清海上战斗与登船工作的责任。
可见角色：初春、佐天、游客；美琴与黑子转往海上应对威胁。
玩家行动：维持秩序、帮助伤者、核对通路、传递海上威胁变化。
结果：默认初春和佐天参与Salmon Red疏散行动；只记录实际已登船与已撤离人员，不一句话宣告全岛无人滞留。
下一节点：LIBERAL-ARTS-CITY-08。

LIBERAL-ARTS-CITY-08 海面上的交锋
进入条件：“太阳之蛇”子机威胁海上行动，美琴与黑子迎击。
场景目标：保护疏散时间，面对Xochitl与城市冲突带来的不同选择。
可见角色：美琴、黑子、Xochitl；陆侧的初春与佐天通过实际联络参与。
玩家行动：支援防护、接应伤者、为救生艇争取空间、尝试让交战方承认游客安全优先。
结果：默认黑子受伤后，美琴以水分子翼继续行动并与Xochitl交锋；这是疏散与战斗的阶段交接，不自动宣布全部终局。玩家已避免伤势则保留不同分工。
下一节点：LAC-END-A／LAC-END-B／LAC-END-C。

== 5. 偏离与改写 ==
合作与交锋依据当时立场，而不是角色标签。玩家可促成停火、保护人质或提前撤离；没有实际达成的协议、全岛损失与人物去向不补为默认事实。

== 6. 换篇条件 ==
完成局部救援和撤离交接，或主动选择离开即可暂停。返回学园都市须有旅行与时间衔接，不与俄罗斯能力实演或暗部大战共享一个“海外篇已完成”标记。

== 7. 防剧透边界 ==
初次旅行不公开工作人员的灭口计划、Xochitl的全部任务或之后的战斗。玩家亲见与其他同伴所知分别记录，不用远程全知替代通信。
