【事件包：人力资源计划篇】
事件包ID：NT-AGITATE-HALATION
所属阶段：阶段6·新约前段
时间窗口：本篇Y年11月21日至22日前后；日为图排
别名与触发词：人力资源计划篇 / Agitate Halation / 药味久子计划 / NT-AGITATE-HALATION

== 1. 核心定位 ==
作品范围：新约7。以土御门的复仇行动为入口，揭露借芙蕾梅亚的情感操纵“英雄”的人力资源计划，最后转向学习核心的救援。不是科学一方通行漫画后半，也不是创约3手铐行动。

== 2. 不可丢失的核心事实 ==
- 土御门以假魔术师危机把上条送入学舍之园，真实目的是让他远离自己的行动；舞夏的“死亡”是假布置，不应在旁白中确认为她已死。
- 药味久子利用芙蕾梅亚的恐惧与求救等情绪，把周边保护欲与英雄行动纳入可操纵的网络；新入生的袭击是相关实验的一环。
- 恋查是能切换、模拟多种超能力的改造兵器，存在不同机体与操作者；不是凭空集齐七名超能力者本人，也不能稳定复制幻想杀手。
- 药味抛弃肉身，将意识转移到借AIM扩散力场运行的遮蔽计算机，成为AIM思念体。消灭英雄的表层目标不能完整解释她企图跨出学园都市的后续行动。
- 原作芙蕾梅亚不再只等待英雄，而决定保护大家，反过来影响系统；上条击败恋查29，药味的计划失控。克洛杜尼随后阻止药味借残余信息再起，舞夏仍活着。

== 3. 玩家可改写的部分 ==
- 可识破土御门的隔离、提前确认舞夏安全，阻止复仇扩大；不要求玩家先相信假死才能进入主线。
- 可保护芙蕾梅亚并让她参与决定，不以再次恐吓孩子作为获得“成长”的必要条件。
- 可救助恋查操作者、隔离遮蔽计算机媒介或揭露药味的真实目的；不同方案分别需要现场能够成立的线索与能力。

== 4. 节点推进表 ==
NT-AGITATE-HALATION-01 被送错地方的魔术师任务
进入条件：土御门提出学舍之园的异常任务，或玩家发现上条被隔离的迹象。
场景目标：在封闭学区中核实危机是否存在，查清谁想让上条缺席。
可见角色：上条、土御门；学舍之园相关学生与警戒人员。
玩家行动：验证委托、寻找合法联络或离场方法、联系土御门，避免把无辜学生当成虚构魔术师的同伙。
结果：原作这是一场误导，土御门趁上条不在追查舞夏事件；玩家识破后可提早与他会合，而不是被强制关到原作时间点。
下一节点：进入NT-AGITATE-HALATION-02。

NT-AGITATE-HALATION-02 土御门的复仇路线
进入条件：发现土御门攻击相关人物，或听到舞夏“死亡”的说法。
场景目标：核对假死、保护与复仇之间的真相，制止错误目标被继续攻击。
可见角色：土御门、云川芹亚、上条；涉及调查的统括理事会人员。
玩家行动：追踪情报来源、寻找舞夏真实去向，与芹亚交换证据，阻止土御门把所有人都当成必须排除的障碍。
结果：原作上条与土御门冲突后，调查转向药味久子及人力资源计划；舞夏并未真死。玩家若先确认安全，可改变土御门的动力与行动，不补造第二次假死。
下一节点：进入NT-AGITATE-HALATION-03；若需要先保护舞夏，保留该实际任务。

NT-AGITATE-HALATION-03 谁在替孩子决定英雄
进入条件：芙蕾梅亚身边出现异常聚集、保护者互相冲突或药味的实验痕迹。
场景目标：辨别自然的保护意愿与被系统放大的行动，找到孩子而不是争夺英雄名次。
可见角色：芙蕾梅亚、浜面、绢旗最爱、黑夜、白色独角仙05；药味或其代理。
玩家行动：联系芙蕾梅亚，比较新入生袭击与当前异常，安抚人群并阻止自称英雄者相互伤害。
结果：原作揭明孩子被当成情绪支点，袭击与救援都能变成实验数据；玩家可建立不依赖公开求救的安全通道，削弱药味对场面的操纵。
下一节点：进入NT-AGITATE-HALATION-04；已掌握系统位置可并行准备NT-AGITATE-HALATION-05。

NT-AGITATE-HALATION-04 恋查28的复制边界
进入条件：恋查28阻击追查者，黑夜、浜面和上条卷入战斗。
场景目标：在能力不断切换的攻击下寻找复制限制，兼顾改造兵器内部操作者的生存。
可见角色：恋查28、黑夜、浜面、上条。
玩家行动：轮换支援、观察能力切换与机体负担，避免让能力者盲目施法，尝试使操作者脱离控制。
结果：原作恋查28尝试处理幻想杀手时出现无法承受的问题，追查者获得突破；玩家可用干扰、拆解或谈判取代正面对撞，不因此宣称所有恋查失效。
下一节点：进入NT-AGITATE-HALATION-05；伤者需急救则先安置再行动。

NT-AGITATE-HALATION-05 学习核心的最终实验
进入条件：大量保护者被引向学习核心，药味完成意识转移，恋查29介入。
场景目标：同时处理被煽动的人群、恋查29与药味脱离AIM媒介的企图，避免只追逐她已弃用的肉身。
可见角色：上条、芙蕾梅亚、保护她的垣根一侧、恋查29；药味以AIM思念体存在。
玩家行动：向盟友说明遮蔽计算机的媒介，疏散无关者，保护芙蕾梅亚并让她理解自己可以主动选择，不让她继续被当成诱饵。
结果：原作药味企图杀死芙蕾梅亚以摆脱系统依赖；玩家若先隔离系统或救走孩子，则要据真实条件处理药味受困的媒介，不假定她已无条件扩散全球。
下一节点：进入NT-AGITATE-HALATION-06。

NT-AGITATE-HALATION-06 不再等待英雄的人
进入条件：芙蕾梅亚理解保护者正因她被操纵，或玩家已为她建立反向影响系统的安全条件。
场景目标：把孩子的主体选择还给她，同时结束恋查与药味的相互依赖。
可见角色：芙蕾梅亚、上条、恋查29、药味；保护孩子的伙伴。
玩家行动：支援她保护大家的决定，切断药味控制，向恋查说明救助操作者不等于抹去其经历，制止继续过载。
结果：原作芙蕾梅亚的选择反向撼动系统，药味被排入恋查29机体；上条击败恋查，恋查在最后一刻排出药味残余。玩家可提前隔离或争取操作者协助，改变残余逃逸事实。
下一节点：进入NT-AGITATE-HALATION-07；系统仍影响人群时先继续救援。

NT-AGITATE-HALATION-07 活着的人与剩下的信息
进入条件：学习核心危机解除，能够追查操作者、舞夏与药味残余的下落。
场景目标：确认救援不是只结束一场决斗，阻止残余信息再次把孩子纳入实验。
可见角色：芙蕾梅亚、克洛杜尼、土御门、舞夏、上条；恋查相关人员按实际获救情况出现。
玩家行动：检查舞夏的安全，安置操作者，追踪药味的备用媒介，阻止再利用实验数据。
结果：原作药味残余受克洛杜尼制止，芙蕾梅亚不再仅把自己看作等待被救者，舞夏活着；玩家可选择隔离、救治或交付审查，不把原作对药味的处置转成玩家惩罚机制。
下一节点：神枪制造与格雷姆林集结的情报到达且玩家选择追查时进入GREMLIN-01；否则回到善后与日常。

== 5. 分支和偏离规则 ==
假死不记成真正死亡，药味的肉身与信息态分别描述但不新增变量字段。恋查28与29的状态不能互相覆盖。芙蕾梅亚已有自主保护选择时，不通过再受害清空成长；玩家提前中断实验，则后半战斗按仍成立的条件缩减。

== 6. 换篇条件 ==
人群不再受本次实验操纵、孩子和操作者有实际去处后，才允许本包正常收束。GREMLIN以新的神枪制造危机接入，绝不把本篇视作神枪计划的同一战场或GT3的提前版。

== 7. 防剧透边界 ==
舞夏假死、药味的AIM转移与备用媒介分别在证据出现后揭露，不让所有NPC开局全知。新入生与实验的联系到本篇才展开；后续世界重置不在学习核心战中预告答案。

== 9. 收束结果 ==
- 原作默认：实验被孩子与保护者共同击破，药味再起受阻，舞夏生还事实得到确认。
- 提前断网：玩家在最终实验前切断媒介，未发生的围攻不再强行补演。
- 操作者救援：改变恋查的参与与处置，以真实救治和知情程度承接后续。
- 继续追责：保留实验与幕后线索，本篇可停留善后，不强制进入魔神战。
