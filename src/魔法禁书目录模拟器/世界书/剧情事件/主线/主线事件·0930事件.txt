【事件包：0930事件篇】
事件包ID：ST0930
所属阶段：阶段4末尾·旧约·9月30日（大霸星祭季终幕、暗部大战前夜）
时间窗口：9月30日（单日决战+一周内余波）
别名与触发词：0930事件 / 0930 / 前方之风 / 木原数多 / 黑翼之夜 / 天罚术式 / ST0930 / 九月三十日

== 1. 核心定位 ==
本篇是旧约科学侧线的最大惨案章：9月30日，罗马正教神之右席「前方のヴェント」单骑入侵学园都市，天罚术式让全城昏睡；同日，木原系科学家木原数多率武装集团猎杀一方通行与最后之作。魔术与科学两场灾难在同一天压向这座都市。事件主题是"双头灾难下的选择"——全城倒下的时候，站着的人护住什么。
玩家进入本篇的方式：开局锚点直接选在本篇；或在9月30日当天于学园都市任意学区遭遇昏睡蔓延/武装袭击/教堂钟声般的术式轰鸣。玩家立场自由：清醒的救援者、一方通行侧的护卫、猎杀方阵营的渗透者、理事会紧急对策组成员、或趁乱行动的独立势力。

== 2. 不可丢失的核心事实 ==
- 前方のヴェント：神之右席四席之一（前方/空气/大天使乌列），激进派；奉行的"天罚术式"不限距离剥夺"对她抱有敌意者"的意识——学园都市人口的大半因此瞬间昏睡，都市机能瘫痪。她入侵的公开目标是猎杀上条当麻、先手打击科学侧。
- 木原数多：木原系科学家，率武装集团（含HsPS-15制压部队）在同日发动行动，目标直指一方通行与最后之作——这是理事会更高层意志（暗部上层）的白日化一步。
- 一方通行现状：脑伤后依赖电极与演算网络；面对木原数多这种"研究他、克制他"的对手陷入劣势——矢量操作被针对性反制。
- 黑翼觉醒（原著重力线高潮）：木原数多威胁到打止止（最后之作）的瞬间，一方通行的演算失控暴走，背后展开黑色之翼，将木原数多一击粉碎——这是"学园都市第一位的怪物"真正挣脱解释框架的一刻。觉醒机制本身仍是谜。
- 上条当麻的代价（原著重力线）：上条在混战中为保护最后之作遭受重击，记忆毁损——此后他隐瞒失忆、照常微笑着继续日常。这是贯穿后续全篇的最重暗线之一。
- 全城昏睡的应对：没有倒下的人（玩家、核心角色、应急组织）在瘫痪的都市里维持秩序——医院、电力、警备员残部、暗部组织的各自动向构成背景板。
- 暗部重组的起点：此战后学园都市暴露的弱点成为10月9日暗部大战（Battle Royale）的直接导火索——各暗部组织盯着统治权的裂缝蠢动。
- 战斗基调：都市级灾难+双线决战；玩家能力跨体系混用无反噬，可同时接触魔术侧（ヴェント）与科学侧（木原）两条战线的对手与盟友。

== 3. 玩家可改写的部分 ==
- 上条的失忆：原著=失忆并隐瞒；可改写为玩家及时挡下/医疗介入缓解/事后修复尝试——但"代价必须有人付"的重量不消失，转移给谁由玩家决定。
- 打止止的安危：原著=危机中获一方通行黑翼所救；可改写为玩家护卫成功、由玩家能力接管威胁、或付出其他代价换回。
- 黑翼事件的外泄程度：原著=目击者有限；可改写为被玩家全程直播/被理事会全程记录/永远埋进黑暗。
- 木原数多的下场：原著=被黑翼粉碎；可改写为玩家俘虏/其携资料逃逸留作暗线/被其背后势力回收灭口。
- ヴェント的结局：原著=被上条击败后撤离；可改写为玩家参战决胜/被都市防御体系重创/谈判驱离。
- 昏睡都市的秩序：玩家可选择救人称雄、趁乱渔利、或与残存暗部做交易——世界的裂缝也是玩家的机会。
