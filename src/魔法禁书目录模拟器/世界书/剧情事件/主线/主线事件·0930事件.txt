【事件包：0930事件篇】
事件包ID：ST0930
所属阶段：阶段4·旧约·九月末转折
年层：Y
时间窗口：9月30日白天日常前奏、夜间入侵与两线决战；收治和暗部交涉为随后余波
别名与触发词：0930事件 / 九月三十日入侵 / ST0930 / ST0930-01
证据定位：O28；旧约12–13及官介；官方动画年表

== 1. 核心定位 ==
前方之风入侵与木原数多率猎犬部队追捕最后之作同时发生，汇合到人工天使的显现。上条与一方分别救人，茵蒂克丝的歌唱是解除危机的关键，不能只写成一次城市防卫战。

== 2. 不可丢失的核心事实 ==
- 白天是出院、与美琴同行等日常；主袭击发生在夜间，不等于全球战争当日宣战。
- 前方之风的天罚术式使对她抱有敌意的人倒下，城市应对力量受影响；她代表神之右席进入学园都市。
- 木原数多熟悉一方的能力，以猎犬部队捕获最后之作；她被用于引出以风斩为核心的人工天使现象。
- 原作默认上条击败前方之风，茵蒂克丝通过歌唱参与救治最后之作与风斩；一方在战斗末段出现黑翼，击败木原。
- 后方之水带走前方之风；一方为保护最后之作等人，与暗部交涉并进入GROUP。上条记忆沿用七月事件后的状态，本篇不另设一次失忆。

== 3. 玩家可改写的部分 ==
可救护被天罚影响者、保护最后之作不被捕、协助歌唱解救、改变木原与前方之风结局。允许阻止人工天使形成，不为保留原作高潮重新绑架孩子或转嫁伤害。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；两线跨场景只共享实际联络，节点不要求人物瞬移。

ST0930-01 出院日的约定
进入条件：9月30日白天，接续意大利送返与一方康复。
场景目标：处理上条与美琴的同行、一方与最后之作的生活安排。
可见角色：上条、美琴；一方、最后之作、芳川、黄泉川在另一视角出现。
玩家行动：会合、探病、护送、安排夜间联络。
结果：夜间失联有了可追查的起点；白天不提前结算入侵。
下一节点：ST0930-02。

ST0930-02 前方之风的天罚
进入条件：夜间入侵发生，敌意指向前方之风的人接连倒下。
场景目标：救助失去行动能力者，识别普通包围战无法奏效的原因。
可见角色：前方之风、上条、警备员、受影响居民。
玩家行动：救护、传递术式线索、避免无谓扩大暴露或协助上条接近。
结果：上条线进入魔法对抗，另一侧对最后之作的追捕同步展开。
下一节点：ST0930-03。

ST0930-03 猎犬部队与木原数多
进入条件：一方遭木原及猎犬部队袭击，最后之作成为目标。
场景目标：保护孩子，并应对木原能突破惯常反射应对方式的近身攻击。
可见角色：一方、最后之作、木原数多、猎犬部队。
玩家行动：护送、支援、寻找失联位置或分散追兵。
结果：原作默认最后之作被捕，一方继续追击；若玩家已救出她，后续人工天使条件随之重判。
下一节点：ST0930-04。

ST0930-04 风斩再现
进入条件：最后之作被用于计划，或玩家追到相关装置和控制线索。
场景目标：辨认风斩与御坂网络异常的关联，找出救人的解除方向。
可见角色：风斩、上条、茵蒂克丝；一方线可见最后之作与木原。
玩家行动：保护风斩、转达网络异常、协助茵蒂克丝分析或提前切断控制。
结果：原作默认人工天使显现；它干扰魔法侧行动，却同时把被利用者置于险境。
下一节点：ST0930-05。

ST0930-05 上条迎战前方之风
进入条件：前方之风仍在行动，上条选择正面阻止她。
场景目标：破解她的攻击并让城市免于继续被天罚压制。
可见角色：上条、前方之风；风斩按现场状态出现。
玩家行动：掩护破术、救出波及者、谈判或执行已准备的制止方案。
结果：原作默认上条击败前方之风；这并不自动治好最后之作，另一线仍须收尾。
下一节点：ST0930-06。

ST0930-06 黑翼与救人的歌
进入条件：一方追到木原，茵蒂克丝已找到解除异常的办法。
场景目标：制止木原，同时为茵蒂克丝救治最后之作、风斩创造条件。
可见角色：一方、木原、最后之作、茵蒂克丝；风斩状态由对应现场确认。
玩家行动：支援战斗、保护歌唱、抢救伤者、阻止再次利用网络。
结果：原作默认一方黑翼显现并击败木原，歌唱使最后之作与风斩脱离危机；二者各自贡献不能互相替代。
下一节点：ST0930-07。

ST0930-07 交涉与余波
进入条件：当夜两线威胁被制止，进入收治与交接。
场景目标：确认被救者恢复、前方之风去向以及一方接受暗部工作的条件。
可见角色：上条、茵蒂克丝、一方、最后之作、医护；后方之水在回收风的场景出现。
玩家行动：探伤、协助安置、参与交涉或记录仍未查清的幕后。
结果：原作默认后方之水带走风，一方进入GROUP；记忆状态不另行重置。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前救人可直接使人工天使线缩短或不发生，不设必须转嫁的代价。旧7个完整节点与完成记录有效；旧存档不同记忆或战斗经历保留为玩家偏移，不能把其误当新的原作事实。

== 6. 换篇条件 ==
ST0930-07完成、明确退出/跳时或入侵被提前阻止后可换篇。主干先接10月3日SKILL-OUT-01，再至10月7–8日CDOC-01、9日DARK-BATTLE-01；后方之水正面来袭另属十月中旬ACQUA。

== 7. 防剧透边界 ==
本案揭示猎犬、人工天使与救援所需的联系，未核的更深计划留待后继调查；不能以此封锁GROUP、DRAGON或战争篇章。

== 8. 状态写回契约 ==
叙事与推进同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留旧项。最后之作获救、风斩状态与入组选择等偏移写主线进度.正史锚点.玩家偏移，救护与交涉记任务追踪。

== 9. 收束结果 ==
以下NT-END标签为旧包内兼容，卷别仍是旧约12–13。
- NT-END-A：近原作，风与木原败北，被利用者获救，一方进入GROUP。
- NT-END-B：玩家提前保护关键人物，改变入侵或人工天使形成条件。
- NT-END-C：退出，记录场外救援及尚存交涉。
- NT-END-D：原创协同救援，不追加失忆、补偿伤亡或强制失败。
