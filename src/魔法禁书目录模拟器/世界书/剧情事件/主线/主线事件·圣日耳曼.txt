【事件包：圣日耳曼篇】
事件包ID：NT-SAINT-GERMAIN
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年12月1日前后；项目日历按图排
别名与触发词：圣日耳曼篇 / 钻石大楼封锁事件 / Dianoid封锁 / NT-SAINT-GERMAIN

== 1. 核心定位 ==
作品范围：新约12。钻石大楼中的封锁与多人共享的圣日耳曼身份，利用加纳神华对芙兰达的思念制造复仇。承接NT11当前框架之后的日常，但不把游戏分支或前一年回忆当成必经前置。

== 2. 不可丢失的核心事实 ==
- 上条、茵蒂克丝、欧提努斯为日常采购进入钻石大楼；浜面在此工作，ITEM也在附近。加纳神华则借第六位“蓝花悦”的名字寻找失去联系的芙兰达，他不是已确认的第六位本人。
- 圣日耳曼并非真正魔神，而是多人通过药片和术式承载同一身份的集群。其成员的话术不总一致，声称可借电视无限传播也不能直接当成事实。
- 圣日耳曼用芙兰达死亡的影像、伪造的盾牌传说和成年芙兰达般的外貌诱导神华，把“上条没来救她”变成复仇理由；上条并未参与她死亡的那场冲突。
- 芙兰达的房间留下给熟人的生日礼物。给神华的留言使他重新以自己的名字作决定，拒绝继续充当圣日耳曼的工具。
- 原作茵蒂克丝与欧提努斯辨析集群术式，上条、浜面与ITEM争取时间；术式被瓦解，封锁解除，神华亲自拒绝并反击操纵者。

== 3. 玩家可改写的部分 ==
- 可提早识别伪造传说、保住影像与礼物、阻止神华使用会伤害能力者身体的魔术。
- 可救助承载圣日耳曼身份的人而非无差别消灭集群，也可协调ITEM避免误击神华。
- 芙兰达若在玩家世界线已生还，必须以她实际去向重写诱骗，不能重新制造尸体影像来保证原作复仇发生。

== 4. 节点推进表 ==
NT-SAINT-GERMAIN-01 钻石大楼停止通行
进入条件：玩家参与大楼采购、运输、寻人或接到封锁求助。
场景目标：确定出口、同伴位置与封锁性质，避免被不同面孔的同一身份分割。
可见角色：上条、茵蒂克丝、欧提努斯、浜面、加纳神华、大楼访客。
玩家行动：寻找失散者，保护运输与避难路线，核实自称蓝花悦的少年真正需要什么。
结果：原作大楼被圣日耳曼封锁，多方被迫面对共同威胁；玩家可提前救出部分访客，保留内外联络而非让封锁自动抹去所有准备。
下一节点：进入NT-SAINT-GERMAIN-02。

NT-SAINT-GERMAIN-02 盾牌与被借来的名字
进入条件：神华接受圣日耳曼接触，或玩家观察到成员服药及不同版本的说辞。
场景目标：识别伪造的血统、盾牌与魔神身份，防止少年以借来的力量走向复仇。
可见角色：加纳神华、不同外貌的圣日耳曼、上条。
玩家行动：比较服药行为与身份宣称，核查盾牌传说，询问神华寻找芙兰达的理由，给他不必假冒第六位的求助途径。
结果：原作神华被影像与话术诱向地下设施，把悲伤转为对上条的怨恨；提早揭穿时可以改变他的站位，但仍需解决封锁与设施威胁。
下一节点：进入NT-SAINT-GERMAIN-03；已拒绝诱骗者可同时协助调查NT-SAINT-GERMAIN-04。

NT-SAINT-GERMAIN-03 芙兰达房间里的礼物
进入条件：上条与浜面追查芙兰达在大楼中的遗留，或玩家找到她的房间。
场景目标：把她真实留下的信息与操纵者拼接的指控分开。
可见角色：上条、浜面；芙兰达通过已有影像与礼物出现，生还分支按实际处理。
玩家行动：保护给熟人的礼物与记录，寻找给神华的留言，讨论为什么不能把所有未能救到的人都归罪于缺席的上条。
结果：原作两人发现她为熟人准备的生日礼物，决定带给神华；玩家可保住更多证据，或在生还路线联系她本人，不凭空让其他角色共享私人留言。
下一节点：进入NT-SAINT-GERMAIN-04。

NT-SAINT-GERMAIN-04 地下设施前的真正姓名
进入条件：圣日耳曼利用重力控制设施制造威胁，神华被引到地下，救援者能接近他。
场景目标：阻止危险盾牌与复仇被一起引爆，让神华在获得真实信息后自行选择。
可见角色：神华、上条、浜面、圣日耳曼；ITEM在设施防护线上行动。
玩家行动：运送礼物，保护神华免遭双方误击，隔离重力装置，指出盾牌并不使能力者安全获得魔术。
结果：原作神华听到芙兰达留言，放弃盾牌和蓝花悦的假名，以加纳神华的身份拒绝圣日耳曼；玩家可用其他可信交流达成，不要求他一定先受伤或挥拳。
下一节点：进入NT-SAINT-GERMAIN-05；设施仍危险则保留并行处置。

NT-SAINT-GERMAIN-05 揭开服药的集群
进入条件：神华不再配合，集群展开攻击，茵蒂克丝与欧提努斯已取得分析条件。
场景目标：撑住攻击直到解除术式，同时揭穿电视传播等用来制造恐慌的谎言。
可见角色：茵蒂克丝、欧提努斯、上条、浜面、ITEM、神华、圣日耳曼集群。
玩家行动：辨认真正媒介，切断药片供给或保护术式分析，协调火力不伤被利用者，协助神华表达拒绝。
结果：原作茵蒂克丝以歌声瓦解身份术式，欧提努斯防止分析受谎言误导，神华对操纵者反击；玩家的拘束、解咒与劝退可改变具体方式，不将所有载体默认判死。
下一节点：进入NT-SAINT-GERMAIN-06。

NT-SAINT-GERMAIN-06 封锁之后仍要拆除的危险
进入条件：集群失去控制能力，大楼出口恢复或玩家已建立替代撤离线。
场景目标：完成设施处置、被困者救助与神华的安置，不把打倒一张面孔当作全楼安全。
可见角色：上条、神华、浜面、ITEM、获救访客。
玩家行动：核对重力装置是否处理，安排被利用者与伤员，保留芙兰达的真实记录，尊重神华今后的选择。
结果：原作大楼解封，浜面一侧继续处理设施威胁，神华取回自己的名字与行动权；本篇伪魔神败退不表示真格雷姆林已经消失。
下一节点：僧正的来信或相应调查出现、玩家选择介入时进入NT-HIGH-PRIEST-01；否则回到日常与善后。

== 5. 分支和偏离规则 ==
先确认芙兰达的实际生死再使用遗留证据。圣日耳曼的谎话不能提升为旁白事实；不同载体的处置分别记录。神华提前脱离操纵时，不安排第二封伪造留言强迫他复仇。

== 6. 换篇条件 ==
封锁、地下装置与主要被困者有明确处理后才能离场。NT13由新的魔神接触启动，不把圣日耳曼称为僧正本人或下一卷战斗的同一形态。

== 7. 防剧透边界 ==
不提前向神华揭示未接触的死亡影像、礼物内容或集群机制；第六位真身保持未证状态。真魔神的削弱方式与上里右手不在本包开局公开。

== 8. 状态写回契约 ==
正式进入本包时，主线进度.当前阶段记“新约”，主线进度.阶段序号使用整数6；主线进度.正史锚点.当前锚点记“圣日耳曼篇”，主线进度.当前节点使用NT-SAINT-GERMAIN完整ID。已完成节点、可触发节点以op:"replace"整体替换数组；封锁、设施、神华身份、芙兰达证据与载体处置写入主线进度.正史锚点.玩家偏移和世界线记录。仅更新已有任务追踪、NPC关系，不新增字段。
玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- 原作默认：集群术式被破，神华拒绝假名与复仇操纵，访客获救。
- 先行解救：在诱骗完成前保护神华，改由他协助识别谎言与媒介。
- 生还者路线：芙兰达的真实现状改变整段诱骗，沿用玩家世界线继续调查。
- 大楼善后：保留设施与载体救治任务，后续魔神接触仍为可选。
