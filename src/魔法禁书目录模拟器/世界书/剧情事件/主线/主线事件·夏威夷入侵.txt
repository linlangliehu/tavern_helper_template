【事件包：夏威夷入侵篇】
事件包ID：NT-HAWAII
所属阶段：阶段6·新约前段
时间窗口：本篇Y年11月10日前后；日为图排，入境与返程按实际行动记时
别名与触发词：夏威夷入侵篇 / 基拉韦厄火山计划 / 夏威夷格雷姆林行动 / NT-HAWAII

== 1. 核心定位 ==
作品范围：新约3。承接NT-FRESHMEN的海外邀约，以夏威夷的政变企图、火山行动和情报操纵为独立冲突；不是到达岛屿便直接跳到欧提努斯终战。
进入须有赴夏威夷的行动或当地调查委托。仅谈到总统、火山或同行角色，不触发整篇。

== 2. 不可丢失的核心事实 ==
- 柏德蔚带上条、美琴、一方通行、浜面等人调查格雷姆林。同行者对任务与彼此情报的掌握不相同，不视为早已互信的统一部队。
- 辛德瑞拉在机场发动袭击；格雷姆林的魔法威胁与奥蕾·布鲁莎克、Trident利用混乱改造美国权力结构的计划相互利用，并非一个指挥者掌控所有人。
- 罗伯特总统脱离常规护卫开展调查。对格雷姆林核心而言，政变能否成功不是唯一目标，基拉韦厄火山喷发及火山灰另有用途。
- 莎萝妮雅的术式依赖当地土地与幼苗的联系。原作上条找到这一依赖并破除术式，Trident最终投降；政变受挫不等于格雷姆林一无所获。
- 柏德蔚利用事件制造学园都市干涉的政治印象，二十七家协力机构与其分离。它们随后构成巴格吉城自然选择者大会的背景，上条因此更加警惕被盟友利用。

== 3. 玩家可改写的部分 ==
- 可先调查委托、与总统交换证据、阻止火山行动或把疏散排在追敌之前；不要求玩家服从柏德蔚隐瞒的目标。
- 可争取基层袭击者退出，改变政变与火山两个目标的完成情况；二者分别记录，不拿一场胜利覆盖所有后果。
- 可公开或隐匿政治操纵的证据，改变协力机构的选择；后续大会须由实际保留下来的组织与动机支撑。

== 4. 节点推进表 ==
NT-HAWAII-01 各有目的的入境
进入条件：NT-FRESHMEN-09的邀约被接受，或玩家已有独立赴岛理由。
场景目标：确定入境身份、联络点和调查权限，辨认旅游表象下的异常戒备。
可见角色：柏德蔚、上条、美琴；一方通行、浜面、番外个体与黑夜按所在小队出现。
玩家行动：核实柏德蔚的线索，分配当地联络任务，选择同行或保持独立调查。
结果：原作队伍在情报不对称下开始行动；玩家若拒绝组队，可保留自己的调查路线，不虚构已参加共同简报。
下一节点：进入NT-HAWAII-02；暂不入境则本节点悬置。

NT-HAWAII-02 机场里的童话袭击
进入条件：队伍进入机场行动区，辛德瑞拉开始袭击或其准备被发现。
场景目标：把术式攻击与平民疏散分开处理，避免把魔法袭击误认为普通枪战。
可见角色：辛德瑞拉、上条、柏德蔚、机场人员。
玩家行动：帮助乘客脱离交火范围，观察童话术式的成立条件，截断袭击或追查其接头线索。
结果：原作辛德瑞拉的攻势被制止，格雷姆林介入得到证实；提前捕获、劝退或放走她均改变可取得的情报，不抹去已发生的损害。
下一节点：进入NT-HAWAII-03；仍有被困者则先在本节点完成救援。

NT-HAWAII-03 总统离开护卫圈
进入条件：调查与罗伯特总统的独立行动相遇，或取得Trident、奥蕾方面的线索。
场景目标：辨别谁在借总统危机推动政变，建立不受被渗透指挥链控制的联络。
可见角色：罗伯特、上条、当地联络人员；奥蕾及Trident成员按调查深度出现。
玩家行动：核验总统身份，保护证人，比较政治目标与格雷姆林成员实际运输、部署的差异。
结果：原作总统与上条等人的行动指向政变网络；玩家可提前争取公开支援，但不能仅凭总统名义让各方无条件相信未经核实的指控。
下一节点：火山部署浮现后进入NT-HAWAII-04；已有莎萝妮雅位置也可与NT-HAWAII-05并行。

NT-HAWAII-04 政变之外的火山目标
进入条件：发现基拉韦厄火山被纳入行动，或喷发威胁已影响当地居民。
场景目标：阻止把自然灾害当成政治与魔术材料，同时查清两条计划并不完全重合。
可见角色：各调查小队、当地居民与执行火山计划的人员。
玩家行动：组织撤离，截断运送和术式准备，向总统报告“政变失败仍可能让格雷姆林得利”的证据。
结果：原作火山环节达成，核心格雷姆林取得所需成果；若玩家阻止，则如实取消相应材料与后续筹备条件，不以另一处无征兆喷发强行补回。
下一节点：进入NT-HAWAII-05；政治威胁已解除时可直接进入NT-HAWAII-06核对余波。

NT-HAWAII-05 莎萝妮雅的土地联系
进入条件：追踪到莎萝妮雅的控制范围，政变方仍凭她的术式维持优势。
场景目标：找出借当地土地建立的依赖点，而非只对着受控者反复攻击。
可见角色：莎萝妮雅、上条、罗伯特；受影响人员与Trident成员。
玩家行动：寻找幼苗与术式联系，保护被利用者，协助幻想杀手破除术式，或提出撤离与投降交换。
结果：原作上条破坏关键联系，莎萝妮雅的优势瓦解，Trident投降；玩家可通过提前隔离媒介、谈判或其他已具备能力达成不同收束。
下一节点：进入NT-HAWAII-06；若仅救出部分人员，保留本节点的未决目标。

NT-HAWAII-06 胜利被谁解释
进入条件：政变冲突已解决或玩家决定结束当地任务，能核对政治与火山行动各自结果。
场景目标：安置当地人员，清点仍被利用的情报，决定是否继续追踪协力机构动向。
可见角色：上条、柏德蔚、罗伯特、同行小队；机构代表通过报告出现。
玩家行动：质询柏德蔚，公开调查记录，协助善后，选择返城或追往巴格吉城。
结果：原作柏德蔚的政治操作促成二十七家机构脱离学园都市，上条不接受被当作棋子的方式；玩家成功拆穿操作时，机构分裂规模与下一篇动机按实际重写。
下一节点：有自然选择者大会线索且玩家选择追查时进入NT-NATURAL-SELECTOR-01；否则回到学园都市日常或保留海外善后。

== 5. 分支和偏离规则 ==
分别记录政变、火山、证人与政治宣传的结局。玩家救援优先并不构成任务失败，隐瞒或公开证据的影响须来自实际知情者。重要角色未赴岛时，不让其凭空参加原作会战。

== 6. 换篇条件 ==
完成可离场的救援安排并明确返程或继续调查意向，才结束本包。自然选择者由机构分裂、比赛消息或独立委托接入，不因日期到11月13日自动转场。

== 7. 防剧透边界 ==
前半只呈现袭击、政变与火山证据；柏德蔚的政治意图须经揭示才能作为角色知识。不得借本篇关键词提前讲出NT8神枪完成、NT9世界变化或NT10欧提努斯处置。

== 9. 收束结果 ==
- 原作默认：政变受挫、火山环节达成，柏德蔚的操作留下机构分裂与信任裂痕。
- 双重阻断：玩家同时瓦解政变与火山目标，后续格雷姆林筹备必须承认资源缺口。
- 政治改写：公开证据或另行协商改变机构分裂，巴格吉城仍须有成立的动机才接入。
- 暂留善后：岛上救援或调查继续，本包悬置，不强迫返回主线。
