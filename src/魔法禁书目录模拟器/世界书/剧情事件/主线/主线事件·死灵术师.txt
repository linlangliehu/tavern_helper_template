【事件包：死灵术师篇】
事件包ID：NECROMANCER
所属阶段：阶段3·旧约·九月上旬科学侧外传
年层：Y（当前年）
时间窗口：Y年九月上旬，一方通行8月31日负伤住院以后；图排约9月6日—9日，旧项目窗9月1日—8日，均不硬裁全篇精确起讫。
原载范围：《科学的一方通行》漫画1—7卷前弧（第7卷为两弧交界）；动画第1—12集为前弧改编，不含Nectar后弧。
别名与触发词：死灵术师篇 / 死霊術師編 / NECROMANCER / NECROMANCER-01

== 1. 核心定位 ==
保留既有科方前弧：住院的一方通行遇见艾丝特与DA，因妹妹们受到利用而追入菱形的实验。调查、死者尊严与救援并行，终局阻止以撒利用伪魂制造完全魔像（Golem）的企图。这里确有死灵术与科学实验交错，不把魔法部分改造成普通能力装置。
本篇解决后稍后才进入NECTAR；天使坠落不是本篇必须补演的入口，也不用其日期推算本篇持续天数。

== 2. 不可丢失的核心事实 ==
- 艾丝特·罗森塔尔是家族第23代当主；菱形蛭魅是菱形干比古的妹妹、艾丝特的朋友，不是艾丝特的妹妹。
- DA即Disciplinary Action，是使用警备员装备的过激结社；不能以其装备冒充正常警备员的集体授权。黄泉川爱穗是警备员，病院医生是冥土追魂。
- 人皮挟美已遭DA杀害；艾丝特使伪魂禍斗附于其遗体。禍斗不是黑狼，也不等于人皮原有人格复活。
- 一方通行依靠电极与御坂网络辅助受损运算；不能借脑伤任意取消其语言能力，更不能预先赋予可随意调用的未来黑翼能力。
- 菱形干比古研究Produce，企图利用妹妹们积累的公式使蛭魅达到绝对能力者层次；10046号是实际被夺走的救援对象。
- 屍食部队四人与一方通行交战后败退，不是被理事会封印后解放的组织，也不是双方不分胜负。
- 檮杌内转写了第4代以撒的魂魄，转写者为第5代内森；以撒不是家族始祖。借蛭魅身体活动不意味着死者自然复生。

== 3. 玩家可改写的部分 ==
可先救10046、先查DA或先接触艾丝特；可避免交战、改变突入分工、保护遗体与证据。阻止研究不必杀死所有关联者，救下原本将死的人也不必之后补死。已死者若没有真实发生的世界线改写，不能仅为对话方便重新变成活人。

== 4. 节点推进表 ==
使用完整ID；每轮至多推进一个主要节点，人物知情与所在位置依实际调查推进。

NECROMANCER-01 病房的不速之客
进入条件：选定本篇，或在一方通行住院期间接触艾丝特的求援。
场景目标：保护医院人员，识别持警备装备而来的DA。
可见角色：一方通行、艾丝特、DA袭击者、病院人员。
玩家行动：挡下袭击、转移病人、检查被毁兵器或询问来意。
结果：默认来袭兵器被破坏，DA与尸体利用问题进入调查。
下一节点：NECROMANCER-02。

NECROMANCER-02 DA与伪魂
进入条件：接触兵器中的遗体及艾丝特的术式。
场景目标：弄清遗体、伪魂与能力装置的区别。
可见角色：艾丝特、禍斗所附的人皮遗体、一方通行。
玩家行动：保护遗体、听取术式解释、查死因、追踪DA。
结果：获得DA实验线索；不能将禍斗的行动写成人皮获救复活。
下一节点：NECROMANCER-03。

NECROMANCER-03 屍食部队参战
进入条件：暗部势力介入DA相关冲突。
场景目标：在屍食部队的袭击中护住救援对象，分辨各方立场。
可见角色：饭栖丽塔、作乐木鸣羽、清之太郎丸、药丸医月、一方通行。
玩家行动：交涉、避战、协防、救治或利用交火追踪线索。
结果：默认屍食部队败于一方通行；其存续不等于自动与玩家结盟。
下一节点：NECROMANCER-04。

NECROMANCER-04 妹达危机
进入条件：10046号被夺走，或玩家提前发现对妹妹们的利用计划。
场景目标：定位被劫持者，阻断公式与记忆继续被实验利用。
可见角色：御坂10046号（找到后）、一方通行、艾丝特、菱形一方。
玩家行动：追踪运输、破解设施信息、突入或先行截救。
结果：确定菱形实验与妹妹们的联系，10046的处境据实际救援更新。
下一节点：NECROMANCER-05。

NECROMANCER-05 师匠与禍斗
进入条件：艾丝特开始说明她与菱形兄妹的经历。
场景目标：辨认她的责任、蛭魅的遭遇和伪魂失控的风险。
可见角色：艾丝特、一方通行、禍斗；菱形兄妹只在相应现场或回忆出现。
玩家行动：听取证词、核对实验记录、质疑师徒称呼或协助制订阻止方案。
结果：救援方向从追击DA推进至制止被利用的死灵术。
下一节点：NECROMANCER-06。

NECROMANCER-06 黄泉川的立场
进入条件：救援或追查与正规警备员发生交集。
场景目标：协调平民保护与突入，避免把DA行为归给所有警备员。
可见角色：黄泉川爱穗、警备员、一方通行、艾丝特。
玩家行动：交证、疏散、请求支援、安排伤者或继续独立行动。
结果：确认能实际到场的援助与救护，不把黄泉川写成治疗医生。
下一节点：NECROMANCER-07。

NECROMANCER-07 以撒与檮杌
进入条件：进入实验核心，伪魂真正主导者暴露。
场景目标：识别以撒借檮杌推进的计划，寻找术式核心而非盲目攻击外壳。
可见角色：以撒、艾丝特、一方通行、菱形干比古、禍斗、10046号（按救援状态）。
玩家行动：阻止吸收、掩护调查、寻找符与本体、组织撤离。
结果：完全魔像威胁进入终局，艾丝特的术式知识成为破局条件。
下一节点：NECROMANCER-08。

NECROMANCER-08 善意与终局
进入条件：找到核心路径，或玩家已准备好替代阻止方案。
场景目标：阻止完全魔像继续吞噬，保住被卷入的人。
可见角色：艾丝特、一方通行、禍斗、以撒及仍在现场的救援者。
玩家行动：开路、保护艾丝特、以舜帝之剑干涉伪魂、救出被困者或执行已证替代方案。
结果：默认以撒的企图被阻止、10046脱离利用；逐人记录伤亡与遗体处置，不宣称全员复生。
下一节点：NC-END-A／NC-END-B／NC-END-C／NC-END-D；收束后检查时间，才可另选NECTAR包。

== 5. 偏离与改写 ==
提前救人、让某场战斗失去原因或使实验停摆，都保留为有效改写；不强制重复旧节点。参与DA或与其谈判的玩家仍按实际行动产生关系变化，不自动被惩罚或强行洗回正史。

== 6. 换篇条件 ==
NECROMANCER-08完成，或玩家明确退出、换锚、跳时越窗，或实验合理提前终止，才关闭本篇。相邻关系是本篇解决后稍后接神之饮物，不从天使坠落直接绕过本篇进入NECTAR，也不自动接祭典。

== 7. 防剧透边界 ==
不提前使用0930以后的成长与知识；本篇不宣告木原研究全部结束。蛭魅、人皮与历代当主的生死及意识形式须分开，回忆不刷新当前存活状态。动画独有镜头可作改编表达，但不据此推算漫画精确日。

== 9. 收束结果 ==
- NC-END-A 默认收束：阻止以撒与完全魔像，结束对10046的利用；艾丝特面对实验与朋友的结局，不复活已死者。稍后可衔接神之饮物。
- NC-END-B 玩家主导：救援和术式处置依实际方案，不追加“DA全部被消灭”等未经发生的结果。
- NC-END-C 协商分支：监督、交接或保护条件必须落实，不能仅凭达成口头交易便宣布阴谋永远无害。
- NC-END-D 玩家退出：保留未解实验、救援和人物状态，让仍成立的因果继续发展。
