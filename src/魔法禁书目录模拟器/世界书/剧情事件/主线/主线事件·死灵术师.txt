【事件包：死灵术师篇】
事件包ID：NECROMANCER
所属阶段：阶段3开头·旧约·天使坠落季（与天使坠落篇时间带内共存，嵌套先例：学习装置之于禁书降临）
时间窗口：9月1日—9月8日（一方通行8月31日脑损伤住院后、大霸星祭前；原著一方通行外传前半"死霊術師編"置于此期）
别名与触发词：死灵术师 / 死霊術師 / 一方通行·外传 / 艾丝特 / 罗森塔尔 / DA / 禍斗 / 屍喰部隊 / 哥雷姆 / Golem / NECROMANCER

== 1. 核心定位 ==
本篇是一方通行视角的暗部守护事件：脑部受创、语言中枢受损、依赖电极维持反射的一方通行在医院静养，被卷入以"警备员之暗"面目出现的组织DA对死灵术师一脉的猎杀。罗森塔尔家第23代当主艾丝特·罗森塔尔为追查妹妹菱形蛭魅之死与"师匠"之谜闯入院内，伪魂禍斗、被封印的暗部组织屍喰部隊、DA绑架的妹达10046号依次登场；终盘揭开罗森塔尔家400年的"神之棺"阴谋。事件主题是"善意的背叛"——所有悲剧的起点都是想救人的人。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段3开始后于第10-11学区医院带探访、追查失踪妹达、或被DA/屍喰部隊任一方接触而卷入。玩家立场自由：医院访客、艾丝特的协作者、妹达的救援者、DA的说客与卧底、或一方通行一行的同行者。

== 2. 不可丢失的核心事实 ==
- 一方通行现状：8月31日为保护最后之作被天井亚雄击穿头部，语言中枢受损、 computation 依赖电极切换；不会说完整的长句（说话省字、电波腔），但思考与反射运算仍在；静养于第10-11学区间某医院（本篇舞台）。
- 艾丝特·罗森塔尔：罗森塔尔家第23代当主，金发碧眼的死灵术师（英国正统），口头禅称一方通行"师匠"；携带家传术式与禍斗；为查明妹妹蛭魅之死与家传"神之棺"真相而来，与DA的目的相撞。
- 禍斗（マグフ）：艾丝特以死灵术造出的伪魂寄宿体，外形为黑色狼形灵体；忠犬性格，可感应术式与亡魂。
- DA（"警备员之暗"）：披警备员外皮的特殊部队，成员以"为社会除害"的正义感自我催眠，进行非法人体实验与处刑；上层与统括理事会某派系相连；本篇反派组织，策划利用妹达实验体量产"人工灵魂"。
- 妹达危机：DA绑架御坂妹10046号，意图以其脑与"内部进化"系技术为原料制造灵装容器；救援妹达是本篇的明线任务之一。
- 屍喰部隊（Scavenger）：四名被理事会封印的暗部能力者小队（纸操着装的"ナル"、液体比重的"药丸"、摩擦系数的"清ケ"、指挥型的队长），奉命"清扫"DA；行事粗暴、独走，与一方通行一方冲突又时而合作，是重要的第三方战力。
- 黄泉川爱穗：一方通行的监护人、医院的医生；DA视她为"先生（センセー）"攻击目标；她的安危是一方通行行动的核心动机。
- 罗森塔尔家的秘密：家传术式"灵魂的容器"制造术传承400年，终点是"神之棺"——以菱形蛭魅遗体为宿体复活始祖以撒=罗森塔尔的Golem；真相是历代当主"想救回重要之人"的善意代代变形为偏执；艾丝特最终亲手以术式逆用排除以撒，与蛭魅遗体诀别。
- 战斗基调：一方通行强化后（黑翼未觉醒）以矢量+黑翼雏形（情绪激化时的黑翼闪现）碾压常规战力；玩家能力跨体系混用无反噬。

== 3. 玩家可改写的部分 ==
- 10046号的救援路径与结果：提前救出、交换谈判、战场截获，均合法；妹达伤亡可被玩家避免。
- 艾丝特的归宿：随一方通行同行、被官方收编、自组事务所、或按玩家原创方案安置，均合法。
- 屍喰部隊的处置：击溃、收编、策反、促其解散，玩家自由选择。
- DA上层与理事会派系的勾连深度：玩家可揭出、可截断、可留作后续暗线（记录进世界线）。
- 与一方通行的关系：雇佣、盟友、师徒式同行、互不信任的临时合作，均可建立。
- 是否介入"神之棺"决战、以何种方式介入，玩家自选；一方通行的黑翼闪现程度可被玩家的安抚/激化改写。

== 4. 节点推进表 ==
节点ID格式：NECROMANCER-{NN}（必须使用完整ID，禁止简写如NC-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

NECROMANCER-01 病房的不速之客
触发：玩家进入9月上旬窗口并接触医院带（探访/追查妹达失踪/撞见黑衣人）。
内容：一方通行静养、黄泉川照护的日常；艾丝特携禍斗闯入病房"拜师"；黑衣人（DA外围）监视迹象；妹达10046号失联的传闻浮现。
完成：玩家与艾丝特/一方通行任一方建立接触，或确认DA存在。
下一节点：02。

NECROMANCER-02 DA与伪魂
触发：01完成+玩家接近DA活动区或禍斗感应到异常术式。
内容：DA的"正义处刑"现场或人体实验据点曝光；禍斗追迹；艾丝特揭示家传术式与蛭魅之死的线索；一方通行首次出手保护艾丝特。
完成：DA作为敌对组织被玩家方确认，或玩家获取DA据点情报。
下一节点：03。

NECROMANCER-03 屍喰部隊参战
触发：02完成+理事会层下达清扫令（或玩家主动放出情报引蛇出洞）。
内容：屍喰部隊四人登场，对DA据点"清扫"；误伤/波及玩家方；一方通行与四人初次交锋（互相忌惮的平局）；"封印的组织"设定揭示。
完成：玩家与屍喰部隊建立敌对/利用/合作任一关系。
下一节点：04。

NECROMANCER-04 妹达危机
触发：03完成或玩家直接追查妹达下落。
内容：DA据点深处发现10046号；"人工灵魂容器"计划曝光；黄泉川被列为"先生"处刑目标的迹象；救援窗口倒计时。
完成：10046号位置确认，或救援行动启动。
下一节点：05。

NECROMANCER-05 师匠与祸斗
触发：04完成/进行中+艾丝特身世线推进。
内容：艾丝特自述罗森塔尔家400年传承与历代"复活死者"的执念；禍斗的诞生真相；DA真正的目标浮出——不是杀艾丝特，而是夺取"神之棺"术式。
完成：玩家掌握罗森塔尔家秘密的关键拼图。
下一节点：06。

NECROMANCER-06 黄泉川的立场
触发：05完成+DA对医院/黄泉川下手。
内容：DA袭击医院（绑架黄泉川/威胁病栋）；一方通行怒意与黑翼雏形闪现；玩家方救出行动；屍喰部隊倒戈或旁观抉择点。
完成：黄泉川脱险或危机进入高潮，玩家立场定型。
下一节点：07。

NECROMANCER-07 以撒的棺桶
触发：06完成+"神之棺"地点揭晓。
内容：蛭魅遗体所在 shrine/研究设施；DA上层与艾丝特叔父辈的合流；以撒=罗森塔尔复活仪式启动；艾丝特面临"接受400年执念"与"亲手终结"的抉择。
完成：仪式现场突入成立。
下一节点：08。

NECROMANCER-08 善意的背叛（Golem决战）
触发：07完成。
内容：以撒Golem觉醒，DA上层的野心被始祖反噬；一方通行全力+玩家能力自由发挥+艾丝特术式逆用；三方合力排除神之棺；艾丝特与蛭魅遗体诀别；DA覆灭/上层被捕；10046号获救安顿。
完成：本篇收束，按第9章定收束结果。

== 5. 偏离与改写 ==
- 上述节点与结局是"原著重力线"，不是唯一路径：玩家可在任意节点改写目标、阵营、手段与结果。
- 篇章内偏离：允许玩家把本篇玩成救援战/暗部权斗/医院日常混合剧，只要不覆盖核心事实（艾丝特身份、DA存在、妹达危机、400年阴谋）。
- 核心结果改写：救不出10046号、艾丝特黑化或离开、以撒复活被玩家阻止/利用，均合法——以玩家偏移事实记录，不得静默回滚。
- 明确离开：玩家声明退出时按第9章NC-END-D收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：一方通行黑翼的完整形态与觉醒机制、亚雷斯塔与"敌人"布局、新约系魔神与科隆尊、大霸星祭超炮线内幕、Battle Royale暗部大战、越狱篇与心理掌握线。
- 禍斗与"伪魂"技术只到罗森塔尔家术式层，不上升为AIM扩散力场或上层意图的世界观级真相。
- 妹达10046号的实验细节不得越过"DA意图制造人工灵魂容器"层级，不揭示Level 6相关后续。
- 屍喰部隊的封印内幕只到"理事会封存"层级，不揭示更深官僚链。
- 魔法侧的英国清教、罗马正教不得作为本篇推动力；死灵术仅作为罗森塔尔家秘术呈现。

== 9. 收束结果 ==
- NC-END-A 原著近似收束：Golem决战获胜，以撒排除，DA覆灭，艾丝特诀别蛭魅后自由，妹达获救。
- NC-END-B 玩家亲手终结：玩家主导终局，DA残党与"神之棺"技术按玩家方案处置，艾丝特按玩家方案安置。
- NC-END-C 交易收场：玩家促成DA上层与理事会切割、艾丝特被官方保护性收编，以撒阴谋在监督下永久封存。
- NC-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。

- 两篇的关键字互不重叠；锚点三件套只指向玩家当前所在篇章。
- 若玩家在天使坠落锚点中触发本篇关键字，仅提示"本地暗部异动的传闻"，不切换锚点；正式进入本篇须按换篇条件执行。
