【事件包：新入生与归还篇】
事件包ID：NT-FRESHMEN
所属阶段：阶段6·新约开篇
时间窗口：本篇Y年11月5日；NT1按图排，NT2官介明示同日
别名与触发词：新入生与归还篇 / 新入生袭击事件 / 战后三人归还 / NT-FRESHMEN

== 1. 核心定位 ==
作品范围：新约1—2。NT1先处理暗部“毕业生”保护芙蕾梅亚的科学侧冲突，NT2再处理上条归还、三人交换经历与魔法说明。这里的新入生是暗部组织，不是学校普通新生，也不是格雷姆林全篇的别名。
玩家可从半藏的求助、ITEM的护送或一方通行的调查进入；直接从归还聚会开局时，先确认救援已经发生的部分，不伪造玩家参与过前面的战斗。

== 2. 不可丢失的核心事实 ==
- 三战之后，一方通行与浜面试图离开暗部；上条的生还尚未向所有熟人传开。黑夜海鸟与银色十字以“新入生”身份重新把他们拖入战场。
- 芙蕾梅亚是芙兰达的妹妹。袭击她不仅是追杀一个孩子，也是诱使暗部“毕业生”出手；本卷不提前宣布NT7才揭开的完整幕后实验。
- 银色十字依靠不同驱动铠转换战斗方式；黑夜海鸟是暗黑五月计划相关的改造人，不能把她写成格雷姆林魔术师。
- 原作中芙蕾梅亚得到保护，新入生攻势被制止；柏德蔚及明色之阳从北冰洋救回的上条与一方通行、浜面汇合。
- NT2的主轴是同日的重逢与知识交接。柏德蔚在上条住处说明魔法及战后格雷姆林威胁；神裂等人在另一侧应对无线探空金城。说明会不是全员忽然精通魔法的授勋仪式。
- 无线探空金城以模仿伯利恒之星的外形掩护对幻想杀手的追踪。最后的地下信标落在学园都市：一方定位，浜面协助钻进，上条消除结晶；神裂则在空中控制下降并制止投掷之锤，两个现场缺一不可。

== 3. 玩家可改写的部分 ==
- 可提前接走芙蕾梅亚、诱离追兵、保护被当成兵器使用的人，或调查谁在要求新入生继续工作。
- 可拒绝柏德蔚的招募、要求核实情报或先处理失联者与家人的重逢；海外任务不是强制奖励。
- 旧约终局已经被玩家改写时，按实际生还与归还情况组织聚会，不重新让上条失踪。

== 4. 节点推进表 ==
节点使用完整ID；每轮最多推进一个主要节点。NT-FRESHMEN-01至05属于NT1，06至09属于NT2。

NT-FRESHMEN-01 被追赶的妹妹
进入条件：战后回城，玩家接到半藏求助或目击驱动铠追击。
场景目标：让芙蕾梅亚离开银色十字的追踪路线，弄清追击不是普通治安案件。
可见角色：芙蕾梅亚、半藏、浜面、银色十字。
玩家行动：掩护撤离、提供交通工具、误导追踪或正面阻截。
结果：默认浜面接手保护；若玩家先完成营救，后续追兵改为追查安全屋，不重复绑走她。
下一节点：NT-FRESHMEN-02。

NT-FRESHMEN-02 毕业生被拉回暗部
进入条件：追击涉及一方通行或玩家查到新入生的目标。
场景目标：识别黑夜借孩子把两名“毕业生”聚到同一战场的意图，分开护送与迎敌任务。
可见角色：黑夜海鸟、一方通行、浜面、绢旗最爱。
玩家行动：交换监控线索、安排接应，或向黑夜质问暗部解散后为何仍在作战。
结果：默认两条主角线汇合，新入生身份暴露；玩家可使她的挑衅失去人质筹码。
下一节点：NT-FRESHMEN-03。

NT-FRESHMEN-03 驱动铠追逐
进入条件：银色十字更换机体继续追踪，或仍掌握芙蕾梅亚的位置。
场景目标：针对换装与机动能力切断追击，不把保护孩子变成单纯比火力。
可见角色：银色十字、浜面、芙蕾梅亚；一方通行按分工接应。
玩家行动：夺取运输优势、破坏控制与供能、救出人质，或为负伤驾驶者安排医疗撤离。
结果：默认浜面阻止银色十字的追击并夺回保护主动；玩家成功救治时保留其实际状况。
下一节点：NT-FRESHMEN-04。

NT-FRESHMEN-04 黑夜与FIVE Over
进入条件：黑夜继续投入无人驱动铠、改造身体及FIVE Over。
场景目标：拆开重装兵器和氮气攻击的配合，保护撤离通道。
可见角色：黑夜海鸟、浜面、一方通行、绢旗最爱。
玩家行动：夺控兵器、破坏指挥链、分散攻击，或谈判终止把人当实验成果的较量。
结果：默认新入生攻势被压制，芙蕾梅亚脱险；不是凭击败黑夜就宣布整个暗部消失。
下一节点：NT-FRESHMEN-05。

NT-FRESHMEN-05 生还者归来
进入条件：救援现场稳定，上条与柏德蔚的归还得到确认。
场景目标：收拢伤者与孩子，让上条、一方通行、浜面第一次在战后真正交换立场。
可见角色：上条当麻、柏德蔚、一方通行、浜面、芙蕾梅亚。
玩家行动：核实失踪者身份、联络家人、保留新入生案的证据。
结果：默认NT1以保护成功和三人汇合结束；未解的幕后动机暂留，不在此跳到魔神决战。
下一节点：NT-FRESHMEN-06。

NT-FRESHMEN-06 迟来的平安报告
进入条件：进入NT2同日框架，众人有机会向等待的人报平安。
场景目标：分别处理上条与茵蒂克丝、美琴的重逢，ITEM见到芙蕾梅亚，以及一方通行的家人到访。
可见角色：上条、茵蒂克丝、美琴、ITEM、最后之作、番外个体。
玩家行动：陪同解释、保护私人谈话，或先去完成自己约定的会面。
结果：默认各自日常重新接上；重逢的感情与信任按实际互动发展，不自动建立新关系。
下一节点：NT-FRESHMEN-07。

NT-FRESHMEN-07 三人的魔法说明会
进入条件：三人接受柏德蔚的说明，或玩家另行核实战后异常。
场景目标：在上条住处对照科学侧经验，理解魔法的象征、术式与战后新敌的性质。
可见角色：柏德蔚、上条、一方通行、浜面。
玩家行动：提出具体疑问、记录已证情报，区分柏德蔚的判断和亲眼见到的事实。
结果：默认三人获得应对魔法的共同语言；玩家可保留疑虑，不因听课直接获得魔术或全知。
下一节点：NT-FRESHMEN-08。

NT-FRESHMEN-08 金城航路与地下信标
进入条件：柏德蔚等人发现无线探空金城正接近城市，神裂的空中处置仍未完成。
场景目标：切断对幻想杀手的追踪，同时让巨大结构安全下降，不能仅让上条逃离就放任最后信标留在市内。
可见角色：地面的上条、一方、浜面、柏德蔚；另一现场的神裂与投掷之锤，视角和联络分别交代。
玩家行动：查找第七学区中央枢纽变电站下的信标，保护钻进和结晶消除；空中协助神裂控制浮力、阻止投掷之锤强迫坠落，避免把分散拆毁误当成安全着陆。
结果：原作一方定位、浜面协助掘进、上条消除最后结晶，神裂以反飞行术式制止投掷之锤；金城失去信标后越过城市，在房总半岛外海受控降落。神裂发现格雷姆林留给上条的信息；玩家可改变协作与处置，不让任何人无依据瞬移到另一现场。
下一节点：NT-FRESHMEN-09。

NT-FRESHMEN-09 夏威夷任务的邀请
进入条件：救援与说明会完成，柏德蔚提出新的海外行动。
场景目标：决定是否调查夏威夷的格雷姆林活动，交代同行者、孩子安置与离城安排。
可见角色：柏德蔚、三位主角及实际受邀同伴。
玩家行动：接受任务、附加情报公开条件、留城照护，或另选目的地。
结果：默认海外调查准备成立；拒绝者保留本篇成果，不强制登机。
下一节点：本篇收束；接受赴夏威夷后可进入NT-HAWAII-01，否则留城或自主选篇。

== 5. 分支和偏离规则 ==
救援方式改变不等于整卷跳过。芙蕾梅亚已安全时以追兵失去目标后的反应推进；提前查清幕后只能公开玩家实际掌握的证据。拒绝说明会或出国均可收束个人路线，不制造失败惩罚。

== 6. 换篇条件 ==
收束节点完成、玩家明确离开或选新锚点、明确跨窗跳时、或事件被合理提前终止时才换篇。记录已完成、已跳过、已延后或已改写及原因；NT2同日不自动增加一天。

== 7. 防剧透边界 ==
新入生案不预告药味久子的全盘计划；柏德蔚只解释当前需要的魔法常识与格雷姆林威胁，不泄露夏威夷之后的算计、欧提努斯结局或上里与科隆尊。

== 9. 收束结果 ==
- 原作默认：芙蕾梅亚获救，新入生被阻止；上条归还，三人完成说明会并准备调查夏威夷。
- 玩家改写：提前营救、救治敌方或留城拒绝远征；按实际结果保留后继条件。
- 暂离或跳过：记录已知背景，不替玩家补做战斗与承诺，不强迫回归默认路线。
