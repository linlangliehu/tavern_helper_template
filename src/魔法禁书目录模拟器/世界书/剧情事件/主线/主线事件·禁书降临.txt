【事件包：禁书降临篇】
事件包ID：INDEX-FALL
所属阶段：阶段1·旧约·禁书降临季
年层：Y
时间窗口：官动层7月19日前奏、20日初遇、28日危机、29日住院余波
别名与触发词：禁书降临事件 / 七月记忆危机 / INDEX-FALL / INDEX-FALL-01
证据定位：O02；旧约1；官方动画年表（日期层）

== 1. 核心定位 ==
由阳台上的修女进入魔法侧，辨认追猎背后的守护，再拆穿必须每年清忆的谎言。核心是救下茵蒂克丝，而非争夺一本可供玩家任意读取的魔道书。

== 2. 不可丢失的核心事实 ==
- 茵蒂克丝记忆十万三千册魔道书，7月20日与上条相遇；史提尔与神裂是奉命追赶她的旧监护人。
- 监护人相信教会给出的说明：魔道书占用记忆，必须定期删除她的个人记忆。那是控制她的错误解释，不是医学事实。
- 上条查出危机来自术式，触碰她口中的魔法印记；自动书记随之反击。
- 原作默认7月28日龙王的叹息击毁树状图设计者，解除过程中落下的光羽损伤上条记忆；29日住院时他向茵蒂克丝隐瞒失忆。这是七月失忆事件。

== 3. 玩家可改写的部分 ==
可分担救护、协调双方、提早验证记忆说法、改变术式解除方式与光羽波及范围。救下上条记忆或保全树状图均属允许的偏移，需据此调整后续实验，不安排替代伤亡。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；7月19日前奏不能替代20日初遇。

INDEX-FALL-01 阳台上的修女
进入条件：7月20日进入事件，或接续19日的日常前奏。
场景目标：帮助饥饿的茵蒂克丝，确认她正躲避魔法师。
可见角色：茵蒂克丝、上条。
玩家行动：供餐、询问、护送或让上条接待。
结果：幻想杀手与修道服的接触让魔法的存在进入视野。
下一节点：INDEX-FALL-02。

INDEX-FALL-02 图书馆与追兵
进入条件：茵蒂克丝离开后带伤返回，或玩家追到她。
场景目标：救治伤者，并面对史提尔以符文维持的火焰魔法。
可见角色：茵蒂克丝、上条、史提尔。
玩家行动：搬离伤者、寻找符文布置、交涉或协助破术。
结果：她作为魔道书图书馆的价值与追兵的杀伤力得到确认。
下一节点：INDEX-FALL-03。

INDEX-FALL-03 小萌老师的房间
进入条件：避开追兵，但常规救护不足以应付伤情。
场景目标：协助小萌依茵蒂克丝指导进行治疗，确保仪式不被打断。
可见角色：小萌、茵蒂克丝、上条。
玩家行动：准备救护条件、守卫、转达术式说明。
结果：茵蒂克丝暂时脱险；治疗成功不等于周期性危机已解除。
下一节点：INDEX-FALL-04。

INDEX-FALL-04 神裂的解释
进入条件：神裂前来阻止上条继续介入。
场景目标：在对峙中听到监护人一次次被遗忘的经历。
可见角色：神裂、上条；史提尔可随后参与。
玩家行动：抵挡、停战谈判、追问清忆依据。
结果：追赶者的守护动机成立，但其医学解释仍须验证。
下一节点：INDEX-FALL-05。

INDEX-FALL-05 清忆说法的破绽
进入条件：7月28日期限临近，茵蒂克丝状况恶化。
场景目标：核对完全记忆能力与大脑记忆机制，寻找教会说明中的矛盾。
可见角色：上条、小萌、神裂、史提尔、茵蒂克丝。
玩家行动：联系能解释医学常识的人、检查术式迹象、争取延缓清忆。
结果：上条确认不是记忆容量耗尽，将解除目标转向施加于她的术式。
下一节点：INDEX-FALL-06。

INDEX-FALL-06 口中的印记
进入条件：停止照旧清忆，开始直接检查控制术式。
场景目标：破坏茵蒂克丝口内的魔法印记，同时保护周围人员。
可见角色：上条、茵蒂克丝、神裂、史提尔。
玩家行动：掩护接触、稳定伤者、准备应对术式反击。
结果：原作默认自动书记启动，解除行动转为正面对抗。
下一节点：INDEX-FALL-07。

INDEX-FALL-07 光束与光羽
进入条件：自动书记阻止解除。
场景目标：突破龙王的叹息，避免光束和落下的光羽伤及人员。
可见角色：上条、茵蒂克丝、神裂、史提尔。
玩家行动：配合破术、疏散、拦截光羽或改变射线方向。
结果：原作默认茵蒂克丝获救、树状图被毁，上条被光羽击中而失忆；改写则按实际结果登记。
下一节点：INDEX-FALL-08。

INDEX-FALL-08 七月二十九日的谎言
进入条件：解除结束并进入住院余波。
场景目标：确认两人的恢复状况，决定如何处理上条失忆的秘密。
可见角色：上条、茵蒂克丝、冥土追魂；监护人按探视出现。
玩家行动：探病、陪伴、保密或经本人同意解释事实。
结果：原作默认上条装作仍记得过去，茵蒂克丝保住本年度记忆；两人的生活继续。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
不得把教会的清忆说法当成不可改变的生理规则。树状图、记忆与监护关系分别记录，不捆绑成必选代价。旧完整节点及完成记录有效；旧存档不同经历转为玩家偏移，不撤销或强迫重演。

== 6. 换篇条件 ==
INDEX-FALL-08完成、明确退出/跳时或危机被提前解决后可换篇。后继可接八月上旬吸血杀手DEEP-BLOOD-01、八月妹妹事件ABSOLUTE-EVOLVE-01或日常；不得直接把8月31日或9月30日当成此处失忆的重复发生。

== 7. 防剧透边界 ==
监护人的解释、术式真相和失忆按节点揭示；角色不会仅因世界书已记载而全知。边界只约束本事件视角，不阻挡后继篇章正常进入。

== 8. 状态写回契约 ==
