【事件包：禁书降临篇】
事件包ID：INDEX-FALL
所属阶段：阶段1·旧约·禁书降临季（故事起点）
时间窗口：7月20日-7月28日
别名与触发词：禁书目录 / 茵蒂克丝 / Index / 魔道书 / 英国清教 / 禁书降临 / INDEX-FALL

== 1. 核心定位 ==
本篇是阶段1核心主线事件、科学与魔法交错的大幕：英国清教所属的魔道书图书馆茵蒂克丝（Index）降临学园都市，各方势力的追猎与守护随之而来。事件主题是"交错的起点"——玩家第一次直面魔法侧的存在，并决定自己在这场交错中的位置。
玩家进入本篇的方式：开局锚点直接选在本篇（7月20日）；或在阶段1日常中主动靠近蓝发修女、偶遇 Index 事件。玩家立场自由：守护 Index、协助追猎、两边斡旋、或纯粹旁观记录。

== 2. 不可丢失的核心事实 ==
- 7月20日，Index 从天而降（落在上条当麻的阳台或玩家面前），她体内记忆着103000册魔道书，是英国清教的"魔道书图书馆"。
- Index 受监护人神裂火织与史提尔·马格努斯"追猎/守护"——两人奉清教之命处理她，立场微妙。
- 上条当麻的右手"幻想杀手"能破除异能术式；他因救下 Index 正式卷入魔法侧。
- Index 每年需要清除记忆以容纳魔道书（"自动书记"的记忆代价），这是她与监护人关系中最沉重的一环。
- 7月28日，Index 进入"自动书记"模式，其咏唱的"龙王的叹息"击毁轨道超级计算机"树状图设计者"——科学侧失去最重要的演算核心，两大体系的冲突摆上台面。
- 萝拉·斯图亚特（清教最高主教）在幕后；亚雷斯塔·克劳利在更远处观察。

== 3. 玩家可改写的部分 ==
- 与 Index 的初遇方式与关系深度：可以替代或分担上条当麻的守护者角色。
- 对神裂/史提尔的态度：对抗、谈判、结盟、或举报给学园都市官方（科学侧介入魔法侧事务是重大偏离）。
- 7月28日"龙王的叹息"事件：可被玩家目睹、缓冲、预警、或改变波及范围——树状图设计者是否被毁、毁于何时属于可改写点（改写将深刻影响阶段2）。
- Index 的记忆处理方式：可以提出替代方案（保留记忆的尝试），按偏离记录处理。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价），允许完全原创介入。
