【事件包：亚得里亚海女王篇】
事件包ID：ADRIA
所属阶段：阶段4末尾·旧约·大霸星祭季收束（使徒十字篇后、0930事件前）
时间窗口：9月下旬（大霸星祭闭幕后一周内；上条的"幸运"北意大利之旅）
别名与触发词：亚得里亚海女王 / 意大利假期 / 威尼斯 / 基奥贾 / 雅妮丝 / La Regina / ADRIA

== 1. 核心定位 ==
本篇是旧约魔法侧线的意大利章：大霸星祭的喧嚣刚落，上条当麻抽中"北意大利七天五夜旅行"大奖，茵蒂克丝拖着他逛水都——而罗马正教的阴影正笼罩亚得里亚海。被罗马正教当作"用后即弃"工具的雅妮丝·桑提斯修女一队遭囚禁，教廷为掩盖秘密不惜让巨大陆军战舰"亚得里亚海的女王"炮击水都。事件主题是"信仰的工具人"——当组织把人当棋子，掀桌的人从何而来。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段4尾声（9月下旬）出现在意大利旅行团/威尼斯街头/基奥贾湾岸，或受英国清教·天草式委托卷入。玩家立场自由：同团游客、天草式协力者、罗马正教内部异议者、雅妮丝救援队、或追查教廷秘密的独立调查人。

== 2. 不可丢失的核心事实 ==
- 舞台：北意大利水都威尼斯与渔港小城基奥贾（Chioggia）；亚得里亚海的碧色海面下是教廷的火药味。上条的旅行是抽奖得的"幸运"，但他的霉运从不缺席。
- 雅妮丝·桑提斯：罗马正教所属修女，率领"雅妮丝部队"执行教廷密令；任务完成后被教廷翻脸定性、囚禁待处决——她与部下成了"知道太多的人"。
- 巨大霊装「亚得里亚海的女王」（La Regina del Mare Adriatico）：罗马正教的陆军旗舰级灵装，携姊妹船群组成舰队，火力足以抹平港区；是教廷"物理删除秘密"的最后手段。
- 天草式十字凄教：日本系魔法结社（建宫斋字、五和等），与英国清教协作，在意大利境内接应救援；对本篇而言是玩家最可能接触的魔法侧盟友线。
- 罗马正教的态度：本篇的教廷是把"组织秘密"看得比"信徒性命"重的官僚机器——这为后续 C文书/神之右席线的世界基调铺垫。
- 终局事实（原著重力线）：上条与天草式并肩登舰，突破女王舰防线，救出雅妮丝一队；女王核心被瘫痪，炮击解除。雅妮丝对"教廷之外的人为何要救我们"的困惑，是本篇收束的情感点。
- 战斗基调：魔法侧术式战+海战；玩家能力跨体系混用无反噬，可以科学侧身份登上魔法战舰——冲突感本身就是看点。

== 3. 玩家可改写的部分 ==
- 雅妮丝部队的命运：原著=全员获救；可改写为部分牺牲、被玩家收编、或提前由玩家策反。
- 女王的处置：瘫痪（原著近似）、夺取为玩家座舰（夸张但合法）、或逼教廷公开认错。
- 罗马正教的责任追究：把证据交给英国清教、卖给学园都市情报部门、或压下来换雅妮丝的人情。
- 与天草式的关系：临时雇佣、结为盟友、或被建宫斋字半开玩笑地拉入"编外协力者"名单。
- 玩家全程吃海景假期顺便救人，也合法——日常和主线不冲突。

完成：雅妮丝获救（或玩家改写的替代结果达成）。

ADRIA-05 女王沉默
