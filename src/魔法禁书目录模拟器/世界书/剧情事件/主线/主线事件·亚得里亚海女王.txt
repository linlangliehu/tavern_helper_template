【事件包：亚得里亚海女王篇】
事件包ID：ADRIA
所属阶段：阶段4·旧约·祭典后续
年层：Y
时间窗口：官动层9月25日中奖、27日赴意与舰队行动；重伤送返属于旅行首日收尾
别名与触发词：亚得里亚海女王事件 / 女王舰队事件 / ADRIA / ADRIA-01
证据定位：O25；旧约11及官介；官方动画年表；O16、O22为前因

== 1. 核心定位 ==
中奖旅行变成冰之舰队上的救援。上条与奥索拉重逢，接触受正教控制的雅妮丝部队，再阻止针对学园都市的灵装；不是参观普通军舰或炮击城市的军事支线。

== 2. 不可丢失的核心事实 ==
- 25日大霸星祭末日上条中奖，27日与茵蒂克丝赴北意大利；在基奥贾与奥索拉及天草式再会。
- 上条和奥索拉误入运河中的冰船，遇见雅妮丝。她以自身处境为背景，请他们救走露琪亚和安洁莲娜。
- 女王舰队承载亚得里亚海女王灵装；彼亚吉欧企图把雅妮丝用于刻限的玫瑰十字，推进针对学园都市的攻击。
- 原作默认上条联合天草式等救援、击败彼亚吉欧并阻止灵装。上条在旅行第一天重伤，被送回学园都市，旅程不是照旧继续。

== 3. 玩家可改写的部分 ==
可提前救走修女、截断舰队行动、向可协作方求助或避免上条重伤。雅妮丝在法之书篇的敌对身份不封死合作；救人后不要求补偿其他受害者。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；中奖前奏和27日行动不可混成25日同夜。

ADRIA-01 中奖后的北意大利
进入条件：25日获旅行机会，27日到达，或玩家在当地接触奥索拉。
场景目标：确认出行日程，在基奥贾与搬迁中的奥索拉、天草式会合。
可见角色：上条、茵蒂克丝、奥索拉、天草式成员。
玩家行动：同行、帮忙搬运、引路或建立本地联络。
结果：原作旅行有了实际同伴与地理位置，异常从运河方向出现。
下一节点：ADRIA-02。

ADRIA-02 运河里的冰船
进入条件：上条与奥索拉遭遇并登上冰船。
场景目标：避开舰队控制者，听取雅妮丝要求救走部下的请求。
可见角色：上条、奥索拉、雅妮丝。
玩家行动：侦察、核实修女处境、答应救援或组织外部接应。
结果：过去的敌手成为具体求助者；露琪亚与安洁莲娜的位置形成救援目标。
下一节点：ADRIA-03。

ADRIA-03 救人之后才知道的用途
进入条件：开始营救两名修女，舰队警戒升级。
场景目标：带她们脱离控制，并与天草式接应力量会合。
可见角色：露琪亚、安洁莲娜、上条、奥索拉、茵蒂克丝、天草式。
玩家行动：护送、撤离、治疗、询问雅妮丝将被用于何种术式。
结果：原作默认救援者知道刻限的玫瑰十字与女王舰队目标，决定返回救雅妮丝而非独自逃离。
下一节点：ADRIA-04。

ADRIA-04 女王舰队的核心
进入条件：掌握雅妮丝所在与灵装威胁，开始联合反攻。
场景目标：救回雅妮丝，阻止彼亚吉欧启动针对学园都市的灵装。
可见角色：上条、彼亚吉欧、雅妮丝；茵蒂克丝与天草式各自支援。
玩家行动：突破冰舰、协同解读与破术、救护被利用者或实施替代停机方案。
结果：原作默认彼亚吉欧败北、攻击被阻止，上条重伤；不是把事件伪装成器材事故就算解决。
下一节点：ADRIA-05。

ADRIA-05 被中断的旅行
进入条件：舰队行动终止，伤者与修女需要安置。
场景目标：完成上条送返与修女庇护，保留对外报告的实际内容。
可见角色：上条、茵蒂克丝、奥索拉、雅妮丝部队、医护与接应者。
玩家行动：送医、探视、安排安全落脚处或跟进正教反应。
结果：原作默认上条被送回学园都市；旧约12–13的9月30日由此承接，不在意大利无限续游。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前救雅妮丝或改变舰队处置可减少伤害，不强制重演旅行中断。旧5个完整节点与完成记录有效；已经继续旅行的旧存档保留为玩家偏移，不强行改写过去。

== 6. 换篇条件 ==
ADRIA-05完成、玩家明确退出/跳时或灵装提前被制止即可换篇。主干接9月30日ST0930-01，等待期可休整；不把9月19日使徒十字再开一次，也不把战争宣战提前到本篇。

== 7. 防剧透边界 ==
雅妮丝用途与攻击目标由救援线索揭示，不能只以保密为由抹掉动机。后续神之右席事件正常开放，人物只知道已经获悉的消息。
