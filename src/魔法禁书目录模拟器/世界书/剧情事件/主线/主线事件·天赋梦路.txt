【事件包：天赋梦路篇】
事件包ID：DREAM-RANKER
所属阶段：阶段4末尾·旧约·祭典与十字之后（三战前夜）
时间窗口：9月22日—9月29日（大霸星祭收束后、0930事件前）
别名与触发词：天赋梦路 / Dream Ranker / 印第安扑克 / Indian Poker / 梦境卡牌 / 操齿凉子 / DREAM-RANKER

== 1. 核心定位 ==
本篇是阶段4末尾的科学侧悬疑战斗事件：能让人"进入他人梦境"的卡牌「印第安扑克（Indian Poker）」在学生间悄然流行，S级梦境卡「天赋梦路」流入黑市，追查卡源的调查逐渐揭穿一个以"制造灵魂"为目标的人体改造实验。事件主题是"梦与灵魂的边界"——前期是抽卡入梦的日常喜剧玩法，后期是灵魂归属的热血决战。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段4末尾因抽到卡牌、接下风纪委员调查委托、或身边人"梦游般"行动而卷入。玩家立场自由：收藏者、调查者、食蜂的协作者、黑市的搅局者，或操齿凉子实验的干预者。

== 2. 不可丢失的核心事实 ==
- 印第安扑克（Indian Poker）：一种卡牌，使用者可通过它"查看并体验他人的梦境"，也可多人联机做梦；梦中获得的技能熟练与情感残留可能渗入现实，因而被部分学生当作"变强的捷径"交易。
- S级卡「天赋梦路」：黑市高价流通的稀有卡；卡牌经由呱太同好、食蜂派阀2号人物帆风润子之手进入御坂美琴视野，又经玩家与黑市渠道扩散。
- 操齿凉子：20学区新色见中学14岁的民间研究员；母亲因肺病接受移植后长年卧床，她为此研究人体改造与人工器官，进行"制造灵魂"的改造人实验——自愿拆分为两名改造人（本人与机械分身），机械分身在实验中获得了独立的灵魂；她故意扩散印第安扑克的制作方法，以筹集资源与筛选合适的心智。
- 食蜂操祈也在追查卡牌制造者（她的动机：卡牌的精神干涉特性威胁她的"心理掌握"领域与常盘台秩序），与玩家构成竞合关系。
- 卡牌技术溯源钩子：印第安扑克理论与才人工房系研究同源——本篇收束后，恶意定制的印第安扑克与"内部进化"遗产将引出支线「幽幻姐妹」，蜜蚁爱愉对卡牌技术的觊觎将延伸至12月的「蜜蚁爱愉篇」。
- 黑子、初春调查"能预知事故的可疑APP"传闻——该线索与梦境卡的扩散同源。
- 卡牌扩散的后果：大规模联机做梦会引发"梦境风暴"（集体梦游、技能暴走、伪魂混乱），是本篇的城市级危机。

== 3. 玩家可改写的部分 ==
- 卡牌的处置：上交官方、封存、自由流通、或由玩家垄断分发规则，均合法。
- 对操齿凉子的处置：阻止、合作、谈判、接管其研究伦理边界、或为机械分身的"灵魂"争取身份。
- 机械分身少女的命运：原著的遗憾可由玩家改写为更好的结果（灵魂的归属、与操齿凉子的和解方式）。
- 梦境风暴的应对方式：救援、切断联机、以自己的能力在梦中作战、或借梦境反向追踪。
- 是否与食蜂操祈结盟或竞争：两人的路线完全开放。
- 玩家能力可自由发挥（含跨体系混用，无反噬无代价）；在梦境中能力规则可被"梦逻辑"扭曲，是本篇特色玩法。

== 4. 节点推进表 ==
节点ID格式：DREAM-RANKER-{NN}（必须使用完整ID，禁止简写如DR-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

DREAM-RANKER-01 入梦的传闻
进入条件：进入本篇时间窗（开局锚点选定或大霸星祭篇收束后推进至此）。
场景目标：印第安扑克在学生间流行——抽卡入梦、交换梦境体验成为话题。
可见角色：同学、卡牌持有者、佐天泪子（都市传说线入口）、（可选）帆风润子。
玩家行动：试抽、观察、追问来源、拒绝参与。
结果：玩家获得卡牌或卡源线索；相关 NPC 关系初始化。
下一节点：DREAM-RANKER-02。

DREAM-RANKER-02 第一次联机
进入条件：玩家实际使用卡牌（独自入梦或联机）。
场景目标：梦境体验——他人的记忆、技能与情感以梦的形式展开；梦逻辑下能力被扭曲重演。
可见角色：梦境中的"他人"（可含原著角色）、现实中的同伴。
玩家行动：探索梦境、学习技能、寻找梦主、提前醒来。
结果：玩家确认卡牌真实有效；发现梦与现实会互相渗漏。
下一节点：DREAM-RANKER-03。

DREAM-RANKER-03 S级与黑市
进入条件：玩家追查卡源或卷入黑市交易。
场景目标：S级卡「天赋梦路」黑市流通——高价、排他、以及持有者接连出现的"梦中事故"。
可见角色：黑市掮客、受害持有者、（可选）帆风润子（卡牌经手人）。
玩家行动：竞拍/截胡、追踪流通链、求助风纪委员、或警告持有人。
结果：玩家摸到流通网络的边缘；"制造者"的存在显形。
下一节点：DREAM-RANKER-04。

DREAM-RANKER-04 预知事故的APP
进入条件：玩家接触黑子/初春的调查线或注意到越界迹象。
场景目标：能"预知事故"的可疑APP传闻与梦境卡同源——有人在用梦做预演；梦中习得开始干预现实。
可见角色：白井黑子、初春饰利、事故当事人。
玩家行动：并案调查、比对梦境与事故、追查APP后台。
结果：玩家确认有人在系统性地"操纵梦"。
下一节点：DREAM-RANKER-05。

DREAM-RANKER-05 与女王的竞合
进入条件：玩家追查深入或与食蜂操祈正面接触。
场景目标：食蜂操祈也在追查制造者——从互相试探到竞合或对抗。
可见角色：食蜂操祈、其派阀成员、帆风润子。
玩家行动：结盟、竞争、交易情报、或各查各的。
结果：两条调查线交汇；制造者的身份浮出水面。
下一节点：DREAM-RANKER-06。

DREAM-RANKER-06 灵魂的实验
进入条件：玩家锁定操齿凉子或黑市源头。
场景目标："制造灵魂"的改造人实验真相——两名改造人、获得灵魂的机械分身、扩散卡牌的真实目的逐层揭示。
可见角色：操齿凉子、机械分身少女、其研究设施相关者。
玩家行动：对峙、潜入、说服、抢救实验数据、或接触机械分身少女。
结果：玩家直面"灵魂归属"问题；大规模联机的火种已被点燃。
下一节点：DREAM-RANKER-07。

DREAM-RANKER-07 梦境风暴
进入条件：联机规模失控或玩家行动触发。
场景目标：城市级"梦境风暴"——集体梦游、技能暴走、伪魂混乱在多个学区爆发。
可见角色：梦游的学生、暴走的"梦中技能"、白井黑子/初春/食蜂等调查线同伴。
玩家行动：切断联机、逐区救援、在梦中作战、直捣发信源。
结果：风暴被压制或转移；决战条件成立。
下一节点：DREAM-RANKER-08。

DREAM-RANKER-08 灵魂的去向
进入条件：风暴平息后直抵核心。
场景目标：与操齿凉子的最终对峙与机械分身少女的灵魂抉择——本篇收束。
可见角色：操齿凉子、机械分身少女、调查线同伴、（可选）食蜂操祈。
玩家行动：决战、斡旋、给"灵魂"以出路、按自己的方案收尾。
结果：事件收束（见收束结果）；世界线记录与偏移事实写入。
下一节点：无（收束节点）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：玩家改变调查顺序、结盟对象或卡牌处置方式但事件主题仍在→保留当前锚点，切换到事件包内相应节点。
- 核心结果改写：玩家提前端掉黑市、让印第安扑克彻底公开化、或以原创方式解决"灵魂归属"→保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 明确离开：玩家主动跳过/退出/时间跳跃→记录原因后关闭本篇，事件按背景因果自行发展（卡牌热潮迟早退去），不强行拉回。
- 机械分身少女的灵魂归属、卡牌技术的最终去向属世界线事实，后续篇章可引用，但不构成本篇强制走向。

仅以下事实之一允许离开本篇：
1. DREAM-RANKER-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过事件窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：Battle Royale（暗部大乱斗）及其关联势力、学园都市最高层意图、AIM扩散力场理论深层、任何后续篇章设定。
- 本篇与木原系无关（木原幻生在大霸星祭篇超炮线已收束），不得让木原系势力在本篇登场。
- 操齿凉子母亲的病情结局与机械分身的"灵魂"细节按节点逐层揭示，不一次性托出。
- 魔法侧势力不得作为本篇推动力；第三次世界大战的前兆至多以新闻与传闻形式出现。
- 印第安扑克原理只到"联机做梦/经验渗漏"层，不上升为世界观级技术真相。

== 9. 收束结果 ==
- DR-END-A 原著近似收束：卡牌热潮平息，操齿凉子的计划在最后一步被搁置，机械分身的灵魂以原著近似方式安放。
- DR-END-B 玩家亲手终结：玩家主导收束，卡牌技术被封存或受控共享，机械分身少女获得玩家争取到的出路。
- DR-END-C 谈判收场：玩家促成操齿凉子与官方/食蜂的协议，实验在伦理边界内继续，卡牌改为受控流通。
- DR-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
