【事件包：天赋梦路篇】
事件包ID：DREAM-RANKER
所属阶段：阶段4末尾·旧约·大霸星祭后跨月事件
年层：Y（当前年）
时间窗口：Y年9月26日起跨至十月；9月22日只可作旧项目的卡牌流言预热，不能当成已证本篇起日。各支线的十月精确日不强行统一。
原载范围：《科学的超电磁炮》漫画11—13卷；动画《超电磁炮T》第16—25集为对应改编。
别名与触发词：天赋梦路篇 / 天賦夢路 / Dream Ranker / DREAM-RANKER / DREAM-RANKER-01

== 1. 核心定位 ==
大霸星祭后流行的印第安扑克是记录、体验他人梦境并可辅助学习的卡状装置，不是让全城玩家同时联网的梦境游戏。卡牌交易、预知救援、佐天与芙兰达的交往，以及操齿凉子的义体研究构成相互交错但并非同源的事件。
一条线有进展不自动结算另一条；跨0930与十月时优先维持所选锚点，保留时间流逝和人物状态。

== 2. 不可丢失的核心事实 ==
- 美山写影是利用预知照片提供线索的小学生；黑子与初春协助改变事故。预知APP不是印第安扑克的隐藏服务器或同一实验。
- 佐天因鲭鱼罐头结识芙兰达，后因所得卡牌卷入SCHOOL的行动；弓箭猎虎是其狙击手，不能把这段写成所有暗部随意集会。
- 美琴与食蜂为防止弃儿、克隆等继续被滥用于实验而合作调查，接触印第安扑克开发者操齿凉子。
- 凉子幼年事故后接受母亲的肺，母亲术后身体更差；凉子研究义体医疗以帮助母亲。不能反写成她准备把自己的肺移植给母亲才启动一切。
- Doppelganger是实验义体；“有新灵魂”“灵魂附身”属于需查明的主张。研究所所长的执念不能直接当成全知科学结论。
- 义体逃离后，美琴与屍食部队合作处置，不是一次多人联机梦境风暴。终局揭破附身说法，凉子向所长表示不能继续这项实验。

== 3. 玩家可改写的部分 ==
可试用或拒绝卡牌、追踪交易、参与预知救援、保护佐天、协助研究调查或寻找义体的其他出路。玩家不必接受预知的不可改变性，也不必为了复现终局伤害凉子。替代医疗或义体方案必须由实际行动成立，不自动给所有人治愈结果。

== 4. 节点推进表 ==
使用完整ID并保留DREAM-RANKER-09；每轮最多推进一个主要节点。预知与暗部桥段可交错，但不能无提示倒退日期。

DREAM-RANKER-01 入梦的传闻
进入条件：大霸星祭后接触印第安扑克。
场景目标：认识卡牌的用途与传播方式。
可见角色：佐天泪子、御坂美琴、帆风润子或卡牌使用者。
玩家行动：询问、交换卡牌、观察使用、拒绝尝试或调查来源。
结果：获得装置与市场线索，不生成不存在的全城联机系统。
下一节点：DREAM-RANKER-02。

DREAM-RANKER-02 第一次体验
进入条件：取得卡牌，或观察其他人使用。
场景目标：区分梦境体验、学习效果与商家的夸大宣传。
可见角色：实际同行的使用者、卡牌交易者。
玩家行动：试用、记录差异、寻找特定卡牌、检查来源或只作访谈。
结果：确认体验的边界；梦中信息不是无条件可信的现实事实。
下一节点：DREAM-RANKER-03。

DREAM-RANKER-03 稀有卡与交易
进入条件：追踪稀有或高评级卡牌。
场景目标：看清卡牌热潮的交易网络及被隐藏的数据价值。
可见角色：佐天、美琴、绢旗最爱（仅在其实际相关场景）、交易者。
玩家行动：交换、竞价、核对内容、追查持有者或退出交易。
结果：取得研究线或佐天相关危险的入口，不凭卡牌等级保证效果。
下一节点：预知事故尚可介入时到DREAM-RANKER-04；已完成或错过该段时记录背景后到DREAM-RANKER-05，不为补节点倒退日期。

DREAM-RANKER-04 预知事故的APP
进入条件：黑子与初春接到美山写影的请求，且该段尚未发生、事故仍可介入；已过对应日期只记录已发生背景。
场景目标：用照片与现场调查找到可以改变事故的行动点。
可见角色：美山写影、白井黑子、初春饰利、可能遇险者。
玩家行动：定位现场、核对预知、组织救援、安排替代路径。
结果：按实际救援改变事故；独立记录这条线，不把预知归入卡牌技术。
下一节点：DREAM-RANKER-05；该线已解决则直接承接其事实。

DREAM-RANKER-05 与女王的竞合
进入条件：美琴与食蜂开始调查义体及“灵魂”实验。
场景目标：查明实验是否继续利用弃儿或克隆，定位凉子。
可见角色：御坂美琴、食蜂操祈、操齿凉子（找到后）。
玩家行动：交换线索、访问研究者、核对受试者情况或独立调查。
结果：卡牌开发者与义体研究进入同一调查，但人物仍各有信息边界。
下一节点：DREAM-RANKER-06。

DREAM-RANKER-06 灵魂的实验
进入条件：接触凉子与研究设施。
场景目标：理解医疗动机、义体实验与所长的执念。
可见角色：操齿凉子、研究所所长、Doppelganger、实际同行者。
玩家行动：核对记录、询问义体、保护受试者、协商停止或改变实验。
结果：默认义体逃离使事态升级；提前解决则保留改写，不再强行脱逃。
下一节点：DREAM-RANKER-07；若选择佐天暗部线且时间尚合适，先DREAM-RANKER-09。

DREAM-RANKER-07 逃离的义体
进入条件：Doppelganger已脱离研究所且威胁尚存。
场景目标：追踪并处置义体扩散、巨大化造成的危险，保护凉子与市民。
可见角色：御坂美琴、屍食部队、Doppelganger、操齿凉子。
玩家行动：疏散、分工追踪、破解附身假象、阻断扩散或尝试沟通。
结果：默认美琴与屍食部队合作，调查接近飞行船上的最终对峙。
下一节点：DREAM-RANKER-08。

DREAM-RANKER-09 芙兰达与猎虎（可选桥段）
进入条件：佐天持卡被卷入SCHOOL行动，且相关人物仍符合当时存活状态。
场景目标：从佐天与芙兰达因鲭鱼罐头建立的交往，处理猎虎追击。
可见角色：佐天泪子、芙兰达·塞维伦、弓箭猎虎。
玩家行动：护送、反追踪、掩护反击、求援或提前避开袭击。
结果：默认两人应对袭击；猎虎后续死亡与本次交战分开记录，不在此强演10月9日暗部大战。
下一节点：DREAM-RANKER-07；该节点已解决则DREAM-RANKER-08，不重复终局。

DREAM-RANKER-08 灵魂的去向
进入条件：抵达飞行船对峙，或玩家已控制义体危机。
场景目标：揭清义体行动的真相，处理凉子与所长继续实验的选择。
可见角色：御坂美琴、Doppelganger、操齿凉子、研究所所长。
玩家行动：拆解附身说法、救援、制止继续实验或落实替代方案。
结果：默认义体危机得到处置，凉子决定不能继续该实验；不凭此自动治愈母亲或宣布已证新灵魂。
下一节点：DR-END-A／DR-END-B／DR-END-C／DR-END-D。
