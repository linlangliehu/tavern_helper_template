【事件包：天使坠落篇】
事件包ID：ANGEL-FALL
所属阶段：阶段3·旧约·暗面与天使
年层：Y
时间窗口：官动层8月27日海边前奏、28–29日事态、30日后日谈；不含8月31日
别名与触发词：天使坠落事件 / Angel Fall事件 / ANGEL-FALL / ANGEL-FALL-01
证据定位：O10；旧约4；官方动画年表（日期层）；O11、O12为后继

== 1. 核心定位 ==
海边度假突然出现外貌与身份认知错位。追查使天使降临人间的术式，分头保护施术源头的家人、拖住天使并破坏仪式现场；不是让整座都市清醒地寻找自己的身体。

== 2. 不可丢失的核心事实 ==
- 上条离开都市到海边，与父母会合。受术式影响的人通常不觉得眼前的错位有异常，不能预设所有人共享调查视角。
- 土御门与神裂等从魔法侧追查天使坠落；以米夏外形出现者的真实身份是降临的天使，而非普通搜查员。
- 刀夜为改善儿子不幸带回的旅游纪念品，在上条家无意构成仪式布置；刀夜不是有意伤害世界的魔法师。
- 原作默认神裂牵制天使，上条保护父亲，土御门破坏上条家解除术式。不能把解除功劳全部写成上条触碰基点。
- 解除后恢复正常，不统一赋予全世界保留互换记忆的能力；个别知情者按实际经历记忆。

== 3. 玩家可改写的部分 ==
可协助调查纪念品、保护刀夜、拖延天使或提出保住房屋的解除方法。外貌错位用于事件叙述，不新增能力随肉体等通用机制；玩家自由介入不附加反噬或代价转嫁。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；本篇的30日收尾不替代旧约5。

ANGEL-FALL-01 海边的家人
进入条件：8月27日赴海边休息，或接到上条一家附近的异常消息。
场景目标：建立旅馆、海滩与父母同行的关系，留下调查地理线索。
可见角色：上条、刀夜、诗菜、茵蒂克丝。
玩家行动：会合、住宿、陪伴家人或记录不寻常征兆。
结果：事件位于海边与上条旧家之间，不在都市全境展开寻身行动。
下一节点：ANGEL-FALL-02。

ANGEL-FALL-02 大家都觉得正常
进入条件：28日起发现熟人的外貌与身份对应异常。
场景目标：区分自己观察到的错位与他人毫无异状的认知。
可见角色：上条、家人及被错认的旅馆周边人物。
玩家行动：私下核对、避免伤害被错认者、寻找同样察觉异常的人。
结果：不能靠公开呼吁所有人自查来解释现象，需寻求术式线索。
下一节点：ANGEL-FALL-03。

ANGEL-FALL-03 魔法侧的调查者
进入条件：神裂、土御门及自称米夏的调查者到场。
场景目标：确认现象涉及天使坠落，厘清施术者与无辜受影响者的区别。
可见角色：神裂、土御门、米夏外形的天使、上条。
玩家行动：交换可核线索、分配调查路线、阻止草率杀人解咒。
结果：寻找术式源头与保护现场人员成为并行任务。
下一节点：ANGEL-FALL-04。

ANGEL-FALL-04 刀夜没有改变
进入条件：调查上条家人与错位规律。
场景目标：核实刀夜为何显得未被错位，避免把疑点直接当成恶意。
可见角色：刀夜、上条、土御门。
玩家行动：询问旅行与纪念品、核对家中布置、保护被怀疑者。
结果：刀夜长期希望儿子摆脱不幸的动机，与家中纪念品产生关联。
下一节点：ANGEL-FALL-05。

ANGEL-FALL-05 偶然组成的仪式
进入条件：土御门查到上条旧家。
场景目标：确认物品位置共同构成术式，而不是寻找某件万能诅咒物。
可见角色：土御门；海边可通过联系获知查证结果。
玩家行动：协助核对布置、提出拆除方案、协调撤离家中人员。
结果：原作默认土御门承担破坏仪式现场的任务，海边还须争取时间。
下一节点：ANGEL-FALL-06。

ANGEL-FALL-06 米夏的真身
进入条件：天使身份暴露，消灭施术者的威胁逼近。
场景目标：由神裂牵制天使，保护刀夜不被当作快捷解除手段。
可见角色：神裂、天使、上条、刀夜。
玩家行动：掩护撤离、协助牵制、维持与土御门联络。
结果：战斗与拆除必须同时推进，不能等击杀天使后才处理源头。
下一节点：ANGEL-FALL-07。

ANGEL-FALL-07 两处同时救援
进入条件：仪式位置确认，海边战斗尚在持续。
场景目标：完成破坏并让天使离开，保住上条一家。
可见角色：海边的上条、神裂、刀夜；旧家的土御门。
玩家行动：各选一路协助，或执行已经验证的替代解除方法。
结果：原作默认土御门炸毁上条家，术式解除、错位消失；上条与神裂的行动保护了人命。
下一节点：ANGEL-FALL-08。

ANGEL-FALL-08 八月三十日的余波
进入条件：术式解除，进入30日后日谈。
场景目标：处理伤者、房屋损失与家人关系，确认哪些人真正知情。
可见角色：上条一家、土御门、神裂；其他人按实际认知互动。
玩家行动：探伤、安顿、解释或保密，决定次日行程。
结果：本篇结束；最后之作、假海原与闇咲事件尚属另一天的三线。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前拆除或保全房屋可直接改变原作毁屋结局，不强加其他损失。旧完整节点与完成记录继续有效；旧存档特殊错位记忆只作为玩家已发生偏移保留，不升级为原作全世界规则。

== 6. 换篇条件 ==
ANGEL-FALL-08完成、明确退出/跳时或术式提前解除后可换篇。正常接8月30日深夜至31日的AUGUST-31，再接9月1日KAZAKIRI；若跳往其他事件须记录实际日期，不默认跳到九月或直接启动祭典。

== 7. 防剧透边界 ==
刀夜与纪念品、天使身份必须可在本篇调查揭示，不能因反剧透而虚化源头。天界更远布局不提前告知；后继篇章按其入口正常开放。

== 8. 状态写回契约 ==
本轮推进、解除及换篇同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace且保留旧记录。施术源头、解除分工、幸存情况等偏移写主线进度.正史锚点.玩家偏移；任务追踪不混入8月31日病毒救援。

== 9. 收束结果 ==
- AF-END-A：近原作，土御门破坏上条家，海边众人获救，错位解除。
- AF-END-B：玩家主导解除并保全更多人或财物。
- AF-END-C：知情者保留协作关系，不要求普通受影响者共享记忆。
- AF-END-D：玩家退出，由场外原作因果推进。
- AF-END-E：原创救援与解除方案，无强制反噬或补偿性伤亡。
