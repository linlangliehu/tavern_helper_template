【事件包：天使坠落篇】
事件包ID：ANGEL-FALL
所属阶段：阶段3·旧约·暗面与天使
时间窗口：8月31日深夜-9月中
别名与触发词：天使坠落 / 身份互换 / 世界错位 / ANGEL-FALL

== 1. 核心定位 ==
本篇是阶段3核心主线事件：一场覆盖全世界的大规模"身份互换术式"在8月31日深夜发动，所有人的灵魂与身体错位——学园都市的科学秩序与常识一夜崩坏。事件主题是"我是谁"——当记忆与肉体分离，身份、关系与信任如何重建。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段3开场直接经历"醒来即他人"的错位。本篇开局即事件，玩家的第一件事就是发现自己不在自己身体里。

== 2. 不可丢失的核心事实 ==
- 8月31日深夜，"天使坠落"术式发动：全世界范围内灵魂与肉体错位，且当事人普遍无法立刻察觉自身被互换。
- 互换是随机且全体的：亲人、恋人、陌生人互为躯壳；能力者的能力随肉体走（演算依赖肉体的脑），记忆与技能随灵魂走。
- 学园都市对外封锁消息，内部以"大规模精神系事故"名义应对；科学侧对该术式完全无解。
- 术式属魔法侧超大术式，且发动者并非蓄意毁灭——术式的真正源头与"世界真相的一角"相关，本篇只揭示表层（见防剧透边界）。
- 上条当麻因幻想杀手的特殊性成为少数"未被完全错位"的锚点人物，是追查与解除的关键。
- 解除术式的唯一途径是找到术式的术式基点并使其失效；解除后除术式发动地附近区域外，绝大多数人恢复原状，但"曾经互换过"的记忆残留成为都市传说级话题。
- 术式解除前，世界的混乱以"错位适应"为主基调：本卡不使用死亡收场判定，混乱表现为喜剧性的错位日常与悬疑性的追查双线。

== 3. 玩家可改写的部分 ==
- 玩家在错位中的处境：落在谁的 body、与谁组成互助组、是否冒用他人身份（全部合法，按剧情事实记录）。
- 追查路线：与当麻联手、独立调查、利用能力者视角、或从魔法侧痕迹切入。
- 关键人物的错位处置：重要角色的错位组合可由玩家的行动改变（救助顺序、信息共享）。
- 解除行动的角色分工：可以让当麻主导（原著锚定）、玩家主导、或联合完成。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；错位状态下能力归属规则按"能力随肉体"执行，玩家可用原 body 的能力也可能继承现 body 的能力——以玩家当前设定与剧情一致性优先。

== 4. 节点推进表 ==
节点ID格式：ANGEL-FALL-{NN}（必须使用完整ID，禁止简写如AF-01）。每轮最多推进一个主要节点。

ANGEL-FALL-01 醒来即他人
进入条件：进入本篇（8月31日深夜）。
场景目标：玩家在陌生的地方、陌生的身体里醒来；镜像里的脸不是自己。
可见角色：错位的周围人、（可选）熟悉角色的新躯壳。
玩家行动：确认现状、联系熟人、试探能力、冷静观察。
结果：错位实感确立；"只有我这样吗"的疑问产生。
下一节点：ANGEL-FALL-02。

ANGEL-FALL-02 世界都乱了
进入条件：玩家走出家门/联络外界。
场景目标：全城错位——新闻、街头、熟人全部错位；官方以精神系事故名义安抚。
可见角色：错位市民、风纪委员/警备员、新闻媒体。
玩家行动：观察秩序、帮助错位者、寻找自己身体、或直奔当麻。
结果：事件规模为"全世界"确凿；科学侧无解的现状明朗。
下一节点：ANGEL-FALL-03。

ANGEL-FALL-03 不在场的自己
进入条件：玩家追查自身下落。
场景目标：玩家的原 body 下落成谜（在都市某处/在都市外/在关键人物身边）。
可见角色：（可选）持有玩家 body 的人、互助伙伴。
玩家行动：循迹追踪、托人打听、以现 body 生活（喜剧线）。
结果：玩家 body 线索到手或确认随世界错位运转；互助网络成形。
下一节点：ANGEL-FALL-04。

ANGEL-FALL-04 术式的痕迹
进入条件：玩家或当麻开始追查源头。
场景目标：都市里出现魔法侧术式痕迹——符文残留、仪式场遗址、异常方位线。
可见角色：上条当麻、（可选）Index、神裂/史提尔的远程联络。
玩家行动：陪同勘察、独立破解、提供科学侧演算支持。
结果：术式来自魔法侧确凿；"天使坠落"之名浮出。
下一节点：ANGEL-FALL-05。

ANGEL-FALL-05 错位中的日常
进入条件：追查进入胶着期。
场景目标：错位适应期的生活切片——身份互换带来的误会、亲情与信任的重构。
可见角色：本篇互助组、错位的熟人。
玩家行动：自由发挥（修复关系/制造笑料/利用错位套情报）。
结果：事件的人物面沉淀；解术式的关键线索通过人际网络汇聚。
下一节点：ANGEL-FALL-06。

ANGEL-FALL-06 真相一角
进入条件：术式基点线索闭合。
场景目标：术式基点定位；术式的非蓄意性质与"世界真相的一角"被揭示。
可见角色：当麻、术式相关者、（可选）魔法侧接触者。
玩家行动：参与基点突入方案制定、争取各方配合。
结果：解除方案成形；发动地周边的异常确认为解除关键。
下一节点：ANGEL-FALL-07。

ANGEL-FALL-07 解除行动
进入条件：解除方案就绪。

可见角色：按方案决定。
玩家行动：可以让当麻主导（原著锚定）、自己主导、或联合执行；AI 按玩家能力与准备合理演绎，不判定失败收场。
结果：术式解除，世界复位（记忆残留保留）；玩家 body 归位。
下一节点：ANGEL-FALL-08。

ANGEL-FALL-08 篇章收束

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变互助组构成、追查路线或错位处置时，保留当前锚点切分支推进。
- 核心结果改写：玩家主导解除、提前定位基点、或解除后推动"错位真相"公开时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 错位记忆残留属跨篇事实：本篇建立的错位关系在复位后以"共同经历过的幻觉般记忆"存续，可被后续篇章引用。
- 延后与跳过：玩家长期回避时，事件按原著因果自行发展（当麻解除术式），不强制玩家参与。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. ANGEL-FALL-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过 9 月中。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇只揭示：身份互换术式的存在与解除、魔法侧超大术式的干扰能力、"世界真相的一角"（表层）。
- 不揭示：术式与天使层级/右方之火的关联、大恶魔与圣人的深层设定、亚雷斯塔布局、人工天界、右手的真相。
- 后续篇章（大霸星祭、使徒十字、三战等）不得在本篇提前启动；其角色至多合理客串。
- 术式源头人物不做具体指名与背景展开，按"已被处理的术式源头"虚化处理。
