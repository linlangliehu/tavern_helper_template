【事件包：ITEM第五卷·大霸星祭药检疑案与D子】
事件包ID：ITEM-05
所属阶段：阶段0·旧约·前日谭
年层：Y−1；不是Y年旧约9—10的同一次大霸星祭
时间窗口：民译正文明确前一年9月18日开祭、19日接案；图排9月17—21另作参照，全卷精确收束日未核，不套用Y年的19日开幕。
别名与触发词：ITEM第五卷 / 前史大霸星祭药检疑案 / ITEM-05 / ITEM-05-01

== 1. 核心定位 ==
ITEM此前处置John Doom后，NPI总部仍发生爆炸；那次行动不是祭典药检案的同一凶手线。大霸星祭期间，四人接到药检负责人Matsuba Sarina异常自杀的调查。芙兰达想看妹妹比赛，泷壶却反常积极。药检赌博、催收组织冲突和假金条将调查引向犯罪实验体系：A子、B子、C子想把泷壶强行补回她从未正式成为的第四个编号D子。
本包覆盖已核主链；序章处置和卷尾电话之声线作为独立前后继，不把全部事件说成同一幕后预谋，也不冒称逐场战斗和全部连载细节均已覆盖。

== 2. 不可丢失的核心事实 ==
- Matsuba是药剂师及志愿药检负责人。她吊死前受到增强痛感的药物影响，调查不能止于普通自杀登记；她接受贿赂篡改药检、影响赌博结果的事实也不能被美化成清白受害者遭实验室直接灭口。
- Investment Club惩罚杀害破坏客户信任的Matsuba；Army Ant催收冲突与DIY Garage假金流通把不同犯罪网络牵到一起，不代表后者预谋了所有火并。
- 第23学区敌人借质量投射器等设施伪装反射效果，不是一方通行本人参战。
- 泷壶曾试入相关研究组织，但未正式转入、未正式获得D子编号，组织便瓦解。A／B／C三人被剥夺姓名，想借重新凑齐四人恢复实验体系；D子不是第四个陌生NPC。
- 过去三人与研究者合谋以卡车撞宿舍、盗车及尸体案栽赃泷壶，麦野后来救过被冤捕的她；本次则打算利用河边烟花大会的平民伤亡调开警备、回收泷壶。过去栽赃与当前计划必须分时。
- 原作麦野、芙兰达、绢旗分别击败三人；A子所称其他ITEM成员全死是谎言。烟花没有发生预定爆炸，叙述推知芙兰达已拆弹，不把未展示的拆弹步骤当作既定表演。

== 3. 玩家可改写的部分 ==
可以更早取得药检和行车记录、保护被利用的人、阻止烟花会场受害、改变与实验体的对决及生死结果。泷壶是否讲述往事、如何选择同伴由实际交流决定，不强迫她接受D子称呼，也不让芙蕾梅亚为制造悬念自动被绑架。

== 4. 节点推进表 ==
使用ITEM-05完整节点ID；每轮最多推进一个主要节点。

ITEM-05-01 祭典中的死亡委托
进入条件：玩家选择Y−1祭典时层；9月18日开幕可作前奏，19日接药检案。
场景目标：核对异常死亡与药检职责，同时保留队员的祭典日常牵挂。
可见角色：ITEM四人、委托联系人；Matsuba通过已取得的案件资料出现，芙蕾梅亚只在实际比赛场景中出现。
玩家行动：核实现场与用药信息、安排调查和观赛时间、询问泷壶愿承担的工作。
结果：调查确认不能只按普通自杀结案；John Doom与NPI爆炸仍是此前独立案件，不自动认作本案答案。
下一节点：ITEM-05-02。

ITEM-05-02 纸箱与药检赌博
进入条件：ITEM-05-01完成，四人能够查阅补货车记录并追索相关人员。
场景目标：找出故意碰倒纸箱制造监控遮挡的人，追查药检数据怎样改变赌博结果。
可见角色：ITEM成员、外围人员Yamazaki Urika、Investment Club负责人。
玩家行动：比对人车流和行车记录、追索中介、保留供述与独立佐证，避免把外围人员直接当总主谋。
结果：负责人供述Matsuba收钱篡改药检，俱乐部因客户信任被破坏而惩罚杀害她；调查随Army Ant袭击转向债务与财物流向。
下一节点：ITEM-05-03。

ITEM-05-03 假金条背后的实验网络
进入条件：ITEM-05-02完成，催收冲突留下配送账与保险箱线索。
场景目标：沿假金流通找到DIY Garage及犯罪基础设施，识破第23学区的反射假象。
可见角色：ITEM成员、催收与制假网络中实际接触的人、设施内阻挡者。
玩家行动：核对金条和账目、绕过被操纵的设施、共享反射异常的观察，不把能力表象记成一方通行到场。
结果：调查从金融犯罪进入实验网络；借电磁场制造的反射优势被识破，各组织牵连不再被误写为单一预谋。
下一节点：ITEM-05-04。

ITEM-05-04 泷壶不是待补的编号
进入条件：ITEM-05-03完成，A子、B子、C子企图回收泷壶。
场景目标：查明旧实验与当前烟花计划的关联，支持泷壶决定自己的归属。
可见角色：泷壶、麦野及实际在场同伴、A子／B子／C子；过去研究员只通过证词或明确回忆出现。
玩家行动：听取往事、比对栽赃旧案、保护通讯、提前疏散烟花会场，拒绝以实验编号代替本人意愿。
结果：确认D子是三人企图强加的第四位置；她们要制造平民伤亡调开警备，旧栽赃不能在当前祭典再无故发生一次。
下一节点：ITEM-05-05。

ITEM-05-05 拆开谎言与会场威胁
进入条件：ITEM-05-04完成，ITEM分别面对三人的拦截与烟花会场风险。
场景目标：保护泷壶及群众，并在失联和谎报战果中保持队伍协作。
可见角色：ITEM四人、A子／B子／C子与需要撤离的人，按实际战场位置出现。
玩家行动：核实队友存活、掩护分线行动、阻止爆炸，或识破A子的高速摄影及电刺激传讯装置。
结果：原作芙兰达、绢旗获胜，B子与C子死亡；麦野回来揭穿全队阵亡谎言，以电子干扰破坏A子的反击优势并致命击败她。玩家救下或制服任何人时保留实际结果，不补做处刑。
下一节点：ITEM-05-06。

ITEM-05-06 烟花照常与归属重选
进入条件：ITEM-05-05完成，会场爆炸已被制止或玩家提前排除威胁。
场景目标：核对平民安全、泷壶去留与同伴生活，不把研究网络残余自动算作全灭。
可见角色：ITEM四人、比赛中的芙蕾梅亚；电话之声和第六位只在主动切换独立尾声视角时出现。
玩家行动：清点伤员、陪同队员回到祭典、保留未清残余线索，或在明确选择后观察上层职位冲突。
结果：原作烟花正常开始，泷壶重获同伴归属，芙兰达参加妹妹的借物赛。成年研究员失去保护是人物判断，不是全员清剿战报。独立尾声中Hanano Choubi与第六位发生冲突，“电话之声”身份开始受挑战，不自动成为ITEM四人的知识。
