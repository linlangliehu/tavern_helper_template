【事件包：绝对能力者进化篇】
事件包ID：ABSOLUTE-EVOLVE
所属阶段：阶段2·旧约·暗面浮现
年层：Y
时间窗口：八月中下旬调查；官动层8月21日决战、22日中止通知与余波
别名与触发词：绝对能力者进化计划 / 妹妹实验事件 / ABSOLUTE-EVOLVE / ABSOLUTE-EVOLVE-01
证据定位：O08；旧约3、超炮漫画4–7卷及官方动画年表；O11只作后继引用

== 1. 核心定位 ==
揭开妹妹们被当作实验消耗品的事实，使美琴的独自破坏研究所转向联合救援。胜负必须连接到实验依据失效与存活妹妹的去向，不以击倒一个敌人代替全部善后。

== 2. 不可丢失的核心事实 ==
- 树状图设计者的演算先提出一方通行在特定条件下杀死128个美琴可抵达等级6，再以两万名复制体及实验场景替代；不是因美琴难以捕获才临时选择妹妹。
- 美琴童年提供的基因被用于制造妹妹；她知道真相后袭击研究设施，仍无法阻止计划转移。
- 七月树状图已毁，使伪造新演算劝停实验的路线受阻。美琴想以自己的牺牲破坏预测，上条阻止她。
- 原作默认8月21日上条与妹妹们的协助击败一方，22日确认实验中止；存活妹妹需要治疗与安置。
- 最后之作、天井病毒和一方脑伤属于旧约5的8月31日独立事件，本篇不提前结算。

== 3. 玩家可改写的部分 ==
可公开证据、保护更多妹妹、联合破坏实验或让资助者停止计划。美琴不必被迫赴死，一方也不必按原样受伤；替代路径如实登记，不复活已发生的旧存档事件或强补原作死亡。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；ABSOLUTE-EVOLVE-07保留旧ID但不再承载8月31日战斗。

ABSOLUTE-EVOLVE-01 同一张脸
进入条件：八月调查复制人传闻，或偶遇御坂妹妹。
场景目标：区分美琴与妹妹，发现她们并非普通双胞胎。
可见角色：美琴、御坂妹妹、上条。
玩家行动：交谈、追踪研究线索、保护妹妹的隐私。
结果：妹妹的编号、装备与行为指向有组织的制造计划。
下一节点：ABSOLUTE-EVOLVE-02。

ABSOLUTE-EVOLVE-02 演算中的两万人
进入条件：取得研究资料或见到实验现场。
场景目标：确认实验目的和一方通行杀死妹妹的事实。
可见角色：美琴、一方通行、实验中的妹妹。
玩家行动：保存材料、救出在场者、调查计划的资金与设施。
结果：妹妹是有感受的人而非道具；停止实验成为明确目标。
下一节点：ABSOLUTE-EVOLVE-03。

ABSOLUTE-EVOLVE-03 研究所之外的计划
进入条件：美琴开始破坏实验设施。
场景目标：协助或替代其袭击行动，识别计划可以转移的组织网络。
可见角色：美琴、布束；科学侧调查路线可遇ITEM。
玩家行动：疏散、入侵设施、截取备份，或争取布束合作。
结果：原作默认设施受损仍未让计划停下，独自毁掉建筑并非终局。
下一节点：ABSOLUTE-EVOLVE-04。

ABSOLUTE-EVOLVE-04 铁桥上的阻止
进入条件：8月21日，美琴得知树状图已毁且实验继续。
场景目标：阻止她用自身死亡使预测落空的打算。
可见角色：美琴、上条；玩家可带已救出的妹妹作证。
玩家行动：劝说、展示替代计划、陪她确认妹妹的求生意愿。
结果：原作默认上条决定亲自挑战一方，让美琴留下寻找协助方法。
下一节点：ABSOLUTE-EVOLVE-05。

ABSOLUTE-EVOLVE-05 最强与最弱
进入条件：赶到御坂10032号将被杀死的实验场。
场景目标：救下10032号，利用右手接触能够突破反射的事实创造机会。
可见角色：上条、一方通行、御坂10032号。
玩家行动：救护、掩护、协同近身或实行已准备的替代制止方案。
结果：一方遭遇不能依靠惯常反射应付的对手，转用更大范围的攻击。
下一节点：ABSOLUTE-EVOLVE-06。

ABSOLUTE-EVOLVE-06 妹妹们的协助
进入条件：一方试图聚集空气形成大规模攻击。
场景目标：让美琴与妹妹们通过改变气流干扰聚集，支持上条结束战斗。
可见角色：美琴、御坂10032号及联网的妹妹、上条、一方。
玩家行动：保护协助者、传递请求、阻挡干扰或直接制止攻击。
结果：原作默认上条击败一方，最强在预定成长路径中的可靠性被推翻。
下一节点：ABSOLUTE-EVOLVE-07。

ABSOLUTE-EVOLVE-07 停止实验与后继桥
进入条件：决战结束，或旧存档已完成本ID。
场景目标：确认中止依据，拆开本次救援与8月31日最后之作事件。
可见角色：美琴、上条、存活妹妹与医护人员。
玩家行动：核实停令、留下医疗联系；可预约AUGUST-31的后续调查。
结果：本节点只确认本篇实验受阻，不自动发生病毒、枪击或脑伤；旧存档若已有这些事实则保留，后继从未完成处承接。
下一节点：ABSOLUTE-EVOLVE-08；到8月31日并明确换篇时另接AUGUST-31-01或其未完成节点。

ABSOLUTE-EVOLVE-08 中止通知与病房
进入条件：官动层8月22日余波；旧存档较晚日期不倒退。
场景目标：确认实验中止，安排妹妹治疗并处理美琴对她们的态度。
可见角色：上条、美琴、御坂10032号、冥土追魂。
玩家行动：探病、陪伴、追查残余计划或选择休整。
结果：原作默认计划停止，但妹妹们并未从此免于所有利用。
下一节点：无（本篇结束）。
