【事件包：绝对能力者进化篇】
事件包ID：ABSOLUTE-EVOLVE
所属阶段：阶段2·旧约·暗面浮现
时间窗口：8月中旬-8月31日
别名与触发词：绝对能力者 / 御坂妹妹 / 一方通行 / 实验场 / 最后之作 / ABSOLUTE-EVOLVE / 绝对能力者进化

== 1. 核心定位 ==
本篇是阶段2核心主线事件、学园都市暗面全面浮现：以"绝对能力者进化计划"（Level 6 Shift 实验）为中心，猎杀复制体的实验、御坂美琴的绝望反抗与一方通行的杀戮构成科学侧最沉重的篇章。事件主题是"力量的暗面"——被数据化的生命、被当作耗材的复制人，以及杀戮者与守护者的一线之隔。
玩家进入本篇的方式：开局锚点直接选在本篇（8月中旬）；或在阶段2中目击御坂妹妹被猎杀、被御坂美琴拉入阻止行动、或因实验场线索深入调查。

== 2. 不可丢失的核心事实 ==
- "绝对能力者进化计划"由树状图设计者演算：Level 5 第1位一方通行若杀死御坂美琴128次即可进化至 Level 6；因美琴难以捕捉，改为猎杀20000个御坂妹妹（军用复制体，能力为本体的约1%）逐轮实战。
- 复制体通过御坂网络共享记忆与演算，个体自称"御坂"并使用第三人称说话。
- 实验场地在第7学区铁道调车场等地，8月中旬已进行数千场。
- 上条当麻最终介入，与一方通行对决并将其击败，实验冻结。
- 8月31日，御坂网络遭病毒污染（最后之作成为病毒载体），一方通行为保护最后之作阻止天井亚雄，被其射中前额叶，失去演算与语言能力，此后依靠御坂网络辅助——这是他从"杀戮者"转向"守护者"的关键转折。
- 实验真实目的（人工天界相关）属亚雷斯塔布局，本篇不揭示。

== 3. 玩家可改写的部分 ==
- 介入时机与身份：可以作为美琴的援手、当麻的同行者、复制体的保护者、实验方的雇佣、或全程暗查。
- 御坂妹妹的获救数量与安置：原著大量复制体在实验中损失——玩家的行动可以减少损失、建立庇护网络（重大正向偏离）。
- 当麻与一方通行对决的走向：可以让当麻上场、自己抢先挑战（按玩家能力合理演绎，不判定失败）、或双方联合。
- 8月31日事件：可以提前揪出天井亚雄、瓦解病毒阴谋、或改变一方通行脑伤的结局（重大偏离机会）。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）。

== 4. 节点推进表 ==
节点ID格式：ABSOLUTE-EVOLVE-{NN}（必须使用完整ID，禁止简写如AE-01）。每轮最多推进一个主要节点。

ABSOLUTE-EVOLVE-01 妹妹的传闻
进入条件：进入本篇（8月中旬锚点或阶段2触发）。
场景目标：都市里流传"随处可见的御坂美琴"目击情报——编号各异、自称御坂的少女们。
可见角色：御坂妹妹（路人态）、传闻来源。
玩家行动：追查、偶遇、对比情报、或被美琴找到。
结果：复制体的存在进入玩家视野；异常感累积。
下一节点：ABSOLUTE-EVOLVE-02。

ABSOLUTE-EVOLVE-02 实验浮出水面
进入条件：玩家追查复制体去向。
场景目标：玩家发现复制体被批量运往"实验场"，每场实验后编号永久消失。
可见角色：运输人员、（可选）研究方外围、御坂妹妹。
玩家行动：跟踪、潜入、拦截、向美琴/当麻/官方通报。
结果：猎杀实验的真相揭开；玩家直面都市暗面。
下一节点：ABSOLUTE-EVOLVE-03。

ABSOLUTE-EVOLVE-03 美琴的战斗
进入条件：实验真相曝光。
场景目标：御坂美琴已先于所有人孤军奋战——破坏设施、追踪实验、濒临崩溃。
可见角色：御坂美琴、（可选）白井黑子。
玩家行动：加入她的战斗、劝她求助、补足情报、或各自行动。
结果：美琴的绝望与执念为玩家所见；阻止实验的战线成形。
下一节点：ABSOLUTE-EVOLVE-04。

ABSOLUTE-EVOLVE-04 第一位的身影
进入条件：玩家接近实验核心。
场景目标：一方通行登场——实验场上的绝对杀戮者，杀死复制体如同例行公事。
可见角色：一方通行、御坂妹妹（实验对象）、研究方。
玩家行动：远观、侦察其能力规则、试探、或营救当前场次的复制体。
结果：矢量操作的恐怖与"反射"规则为玩家所知（认知层记录）。
下一节点：ABSOLUTE-EVOLVE-05。

ABSOLUTE-EVOLVE-05 调车场对峙
进入条件：决定正面阻止实验。
场景目标：铁道调车场的最终实验——第10032次实验前后的正面冲突。
可见角色：一方通行、御坂妹妹、（可选）上条当麻、御坂美琴。
玩家行动：让当麻按原著上场、自己抢先挑战、与美琴联合作战、或以非战斗方式搅局——AI 按玩家能力与准备合理演绎，不判定失败收场。
结果：一方通行败退，实验冻结；对决的细节按玩家选择呈现。
下一节点：ABSOLUTE-EVOLVE-06。

ABSOLUTE-EVOLVE-06 实验冻结之后

可见角色：御坂美琴、御坂妹妹、（可选）官方代表。
玩家行动：参与安置方案（庇护、分散、移交）、安抚美琴、或建立长期支援。
结果：复制体的命运由玩家的介入程度改写（重大正向偏离机会）。
下一节点：ABSOLUTE-EVOLVE-07。

ABSOLUTE-EVOLVE-07 病毒与守护（8月31日）
进入条件：时间推进至8月31日或玩家提前触达阴谋。
场景目标：御坂网络遭病毒污染，最后之作成为载体；天井亚雄的行动与一方通行的抉择。
可见角色：一方通行、最后之作、天井亚雄、御坂网络复制体。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变介入身份、战线选择或对决细节时，保留当前锚点切分支推进。
- 核心结果改写：改变复制体获救规模、一方通行对决结果、或8月31日结局时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按原著因果自行发展（当麻独自完成 defeat），不强制玩家参与。
- 原著角色的行动随玩家偏移而变化，不强行复位；御坂网络的状态变化跨篇保留。
