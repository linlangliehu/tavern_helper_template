【事件包：创约第十二卷·葬礼后的生者证明】
事件包ID：GENESIS-12
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第12卷；葬礼、回生、离别部队追捕与史提尔冲突。
时间窗口：Y＋1年1月8日，葬礼与原定开学日的对应主要依据社区梗概及后卷回述。准备场景可承接前一日悲痛，不另造小时表；复活后的追捕与新危机仍属本卷，不能只播放葬礼就结束。
别名与触发词：创约第十二卷 / 创约第十二卷葬礼复活 / GENESIS-12

== 1. 核心定位 ==
同伴不得不为上条准备告别，而正在回生路上的他并不知道现实已走到火葬流程。归来不是所有人立刻欢呼的终点：离别部队把活动遗体视作异常风险，史提尔认定这会再次伤害茵蒂克丝，亚雷斯塔则追问为什么被救的只有上条。玩家要保护一个活着的人，也要面对他的归来给不同人带来的希望、恐惧与失落。

== 2. 不可丢失的核心事实 ==
- 葬礼建立在已经确认死亡的事实之上，同学、老师与朋友的悲痛是真实的，不是等主角登场的恶作剧。
- 上条在火葬炉中的棺木内醒来并设法逃出；不是遗体烧成灰后无条件重塑，也不是医学死亡确认从未发生。
- 离别部队Bio Secure追查异常活动遗体，木原合计是其主管。美琴与食蜂介入，但主管主动自伤退出后，部队仍能按组织流程行动，抓住一个头目不等于解除整个追捕。
- 爱丽丝与上条重逢并陪他寻找容身处；茵蒂克丝、欧提努斯已不在宿舍，找到她们和证明上条仍是活人是相连的目标。
- 史提尔把上条的回生视作对茵蒂克丝的威胁。奈芙蒂斯、娘娘与他同行另有制止其走向危险魔神化尝试的考虑，不是永久归顺英国清教。
- 两位魔神原已表示退出；史提尔以Crossroad夺取她们的力量，导致她们倒下，并让自己的身体承受风险。上条在最后正面对决中击倒他，一方通行也以远程支援介入。
- 原作上条计划利用第十二学区旧领事馆的地位安排安全检查；亚雷斯塔因金斯福德没有归来而崩溃，意志松动使科隆尊重新控制肉体。此处是下一卷危机的直接起点。

== 3. 玩家可改写的部分 ==
- 改善葬礼沟通、保护家属与同伴知情权，在回生时及时停下危险流程，避免惊慌扩大。
- 提供不以伤害本人为前提的生存与安全证据，改变离别部队、同学和医疗人员的接触方式。
- 促成史提尔与上条在战斗前交流，阻止夺取魔神力量，或帮助亚雷斯塔承受失落而改变科隆尊复苏的条件。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；准备、告别、火葬现场回生、追捕和新威胁必须保留各自的因果。

GENESIS-12-01 为同学准备告别
进入条件：上条实际处于已死待回生状态，或玩家明确选择本卷葬礼锚点。
场景目标：处理葬礼安排与同伴悲痛，不用预知复活敷衍他们的失去。
可见角色：青发耳环、吹寄制理、月咏小萌、上条的同学及参与告别的朋友；上条尚不以生者身份出现。
玩家行动：协调出席、传递已经确认的消息、陪伴沉默或失控的同伴，确认遗体后续移送安排。
结果：原作准备继续，大家带着不同情绪面对死亡；玩家可以改善照护与信息传递，不能因卷名有“复活”就把葬礼当假戏。
下一节点：GENESIS-12-02；若此前上条存活，保留存活世界线，不强制举行他的葬礼。

GENESIS-12-02 最后的献花与移送
进入条件：告别式开始，同伴面对棺木与即将结束的相处机会。
场景目标：让人物完成自己能做的告别，确保去火葬场的流程与人员安排清楚。
可见角色：上条的同学、老师、美琴、食蜂等在场者，负责葬礼和移送的人员。
玩家行动：陪伴告别者、保管物品、核对移送与联络；不替茵蒂克丝或其他人自动说出原谅、释怀。
结果：原作遗体被送往火葬场；告别没有消除悲痛，也没有提前让众人知道死后阶梯正在发挥作用。
下一节点：GENESIS-12-03。

GENESIS-12-03 火葬炉里醒来的人
进入条件：棺木已进入火葬流程，死后回生路线在现实侧产生结果。
场景目标：让已经醒来的上条脱离封闭棺木和火葬炉的危险，并制止旁人误伤。
可见角色：上条、火葬场工作人员、尚在附近的同学与朋友。
玩家行动：发现声响或求救、停止危险作业、帮助开门与疏散，确认呼吸、意识等可观察事实。
结果：原作上条逃出火葬炉并赤脚离开，现场陷入恐慌；他不是烧成灰后重生，也不因此自动获得对所有伤害的免疫。
下一节点：GENESIS-12-04。

GENESIS-12-04 离别部队的异常遗体追捕
进入条件：Bio Secure将上条归来当作异常遗体事件，火葬场与逃离路线受到控制。
场景目标：保护上条和围观者，弄清谁能停止组织流程，避免把恐惧直接变成解剖许可。
可见角色：上条、前来帮助他的爱丽丝；火葬场另一侧有美琴、食蜂、木原合计与离别部队人员。
玩家行动：在所处现场收集生命与污染检查证据、避开喷火装备、联络可信医疗者；支援同伴制止木原合计自伤或追查持续命令来源。
结果：原作美琴等介入后，木原合计通过自伤退出正面交涉，但追捕没有随之停止；上条与爱丽丝同行寻求安全落脚处。玩家能改变自伤和执法误判，不自动消除整个组织。
下一节点：GENESIS-12-05；暂未汇合时先完成当前逃离或联络，不瞬移另一现场的人物。

GENESIS-12-05 空宿舍与史提尔的拒绝
进入条件：上条与爱丽丝回到宿舍，发现茵蒂克丝、欧提努斯不在，而史提尔已经介入。
场景目标：问清两人的去向，并拆开保护茵蒂克丝与否定上条生存资格之间的冲突。
可见角色：上条、爱丽丝、史提尔，随后显露同行立场的奈芙蒂斯与娘娘。
玩家行动：尝试直接交流、保护居住者与退路、核对被带离者的位置和意愿，避免把上条当可随意处理的遗物。
结果：原作史提尔攻击上条，爱丽丝参与保护；魔神的介入使这不是简单的旧识争吵，真正动机仍需在战斗与交涉中辨明。
下一节点：GENESIS-12-06。

GENESIS-12-06 Crossroad与最后一拳
进入条件：宿舍冲突持续，上条与爱丽丝合作应对史提尔和两位魔神，一方通行提供远程支援。
场景目标：保住上条的生存与同伴的自主选择，阻止史提尔以保护之名走到自毁。
可见角色：上条、爱丽丝、史提尔、奈芙蒂斯、娘娘；一方通行通过联络与远程攻击介入。
玩家行动：创造掩护与沟通机会、辨明魔神并不准备无限作战、阻止史提尔发动Crossroad，或在其发动后避免进一步伤亡。
结果：原作魔神表示退场后反被史提尔夺取力量而倒下；史提尔的身体承受不住这股力量，上条在正面交锋中击倒他。不能误写成爱丽丝杀死两位魔神。
下一节点：GENESIS-12-07；若已和平解决，保留不同伤势与关系结果。

GENESIS-12-07 为活人安排检查与归处
进入条件：即时战斗结束，但Bio Secure追捕与茵蒂克丝、欧提努斯去向尚未解决。
场景目标：建立不会把医院再次变成战场的安全检查方案，并寻找失联同伴。
可见角色：上条、爱丽丝；冥土追魂作为拟联络的医生，未到场前不能当作已经完成检查。
玩家行动：联系医生、评估旧桥架结社领事馆残址的保护条件、整理对外说明与搜寻线索。
结果：原作两人决定前往第十二学区旧领事馆，借仍存的法理地位争取安全空间。计划形成不等于检查完成，也不等于全城已认可复活。
下一节点：GENESIS-12-08。

GENESIS-12-08 没能归来的人与松开的锁
进入条件：上条与爱丽丝离开宿舍，发现毗陀多利倒地，亚雷斯塔带着对金斯福德的失落出现。
场景目标：回应“为什么只有你回来”的质问，并防止悲痛转化为新的攻击。
可见角色：上条、爱丽丝、受伤的毗陀多利、亚雷斯塔；一方通行远程干预，科隆尊在肉体内部等待机会。
玩家行动：如实说明回生名额与金斯福德的选择、保护伤者、尝试稳定亚雷斯塔，不伪造金斯福德已经获救。
结果：原作亚雷斯塔的意志因失落动摇，科隆尊趁机夺回所借肉体，危机从上条的身份争议转成大恶魔重新自由。若玩家阻止该条件，保存实际结果，不强制复苏。
下一节点：本包收束；默认新危机接GENESIS-13-01。

== 5. 分支和偏离规则 ==
- 回生不抹除真实死亡、同伴的告别或金斯福德未归来的事实；也不禁止其他人逐渐接受上条仍然活着。
- 离别部队的风险判断需要证据，玩家可争取安全检查和撤销追捕，不必以受伤或被解剖换取推进资格。
- 史提尔的立场可以改变，魔神可以提前离场，亚雷斯塔也可得到不同支持；后续科隆尊事件只按仍成立的条件接力。

== 6. 换篇条件 ==
葬礼与回生、即时追捕、史提尔冲突及亚雷斯塔到场已有结果，或玩家主动更换锚点时换篇。不能在告别式结束时宣布本卷全部完成；领事馆检查与寻找同伴的未竟任务要带到后续。

== 7. 防剧透边界 ==
先展示上条确实呼吸、思考与求生，再让人物判断；不把“复活者一定危险”当旁白真理。魔神对史提尔的真实考虑、金斯福德留在死后的原因与科隆尊等待的机会，仅在当事人行动或说明后进入知情范围。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8，当前节点写完整ID，阶段状态按实际告别、归来与追捕更新。
- 正史锚点记录葬礼后回生与科隆尊复苏的默认参照；玩家偏移保留提前停止火葬、和平交涉、安全检查及不同复苏条件，不强制回正。
- 已完成节点、可触发节点去重后整体replace；不把尚未实施的领事馆检查或尚未找到的同伴记为已完成。
- 沿用任务追踪处理生命核验、照护和搜寻；NPC关系、在场人物、势力关系、世界线记录按实际知情与生存状态更新，不新增复活次数或死亡惩罚字段。

== 9. 收束结果 ==
默认上条确实返回现实并打赢生存资格之争的一场战斗，却还没有找齐同伴、取得全城认可或救回金斯福德。亚雷斯塔的失落使科隆尊脱困，下一卷因此从当日下午接续，而非无因生成另一名敌人。
