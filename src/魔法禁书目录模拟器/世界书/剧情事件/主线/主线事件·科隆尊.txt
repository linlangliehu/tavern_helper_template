【事件包：科隆尊英国决战篇】
事件包ID：CORONZON
所属阶段：阶段7·科隆尊与新约收尾
时间窗口：本篇Y年十二月中旬至二十日前后图排；十二日可作赴英前奏，不代表三卷终战同日
别名与触发词：科隆尊英国决战篇 / 黄金再现追击 / 不列颠女王号决战 / CORONZON

== 1. 核心定位 ==
作品范围：新约20—22。NT20是赴英寻找恶魔根基与化解入侵冲突；NT21是黄金复制体追击、查找真实遗骸与封印破裂；NT22才是不列颠女王号上的阻止仪式与救人终战。新约22 Reverse另由NT-22R承担，不包含在本包。
三个主人公的目标不同：上条救眼前的人，一方取得面对魔法与城市责任的手段，浜面拒绝把狄翁·福琼当作可以随手丢弃的复制品；玩家可穿针引线，不能用一场泛化的“世界真相对决”替代三条因果。

== 2. 不可丢失的核心事实 ==
- NT19的封锁只争取时间。亚雷斯塔一方赴英寻找科隆尊的根基，克劳利灾害的推进又被英国方面视为入侵；反对科隆尊不意味着沿路教会与骑士自动成为盟友。
- NT20中奥索拉因无法帮助前线而接受神威混淆“伊西斯—德墨忒尔”。原作上条的劝说使她拒绝继续充当宿主，上条与亚雷斯塔阻止武装另觅宿主，奥索拉最终亲自终结残留武装。
- 一方与人工恶魔克里帕拼图545建立契约。威斯敏斯特的黄金术师并非历史人物完整复活，而是有魔导书身体与供能条件的再现体，必须经过交锋和调查才能识别。
- NT21动用学园都市技术与轨道攻击帮助破解马瑟斯的防御，却也让科隆尊脱离封锁。队伍继续追向苏格兰；浜面救起福琼，她在同伴供能被切断后也还原为卡片。
- 亚雷斯塔试图利用遗骸与既有召唤关系约束科隆尊，但她此前对契约与宿主身份的说法含有骗局。原作亚雷斯塔遭反刺，不能把到达爱丁堡写成已经完成驱魔。
- NT22科隆尊夺取苏格兰王权宝物并劫持不列颠女王号，企图借英国术式系统发动Mo Athair仪式。浜面为了让福琼归来暂时帮助她，不代表他接受毁灭世界。
- 原作终战需要多线接合：一方借克里帕与御坂网络意志建立第三树，迫使科隆尊灵魂离开肉体；归来的福琼阻断仪式信号；上条才在新的条件下面对她。断臂后的异常和战后身份问题留给22R。

== 3. 玩家可改写的部分 ==
- 可提前说明来意、组织非战斗救援、使奥索拉不必依赖神威混淆，不强迫与每个英国防卫者交战。
- 可保护黄金再现体、保存福琼的记录并寻找替代供能，避免浜面只有与科隆尊交易一条路。
- 可阻止夺取王权宝物、破坏船上术式或协调多线制止；不必先让亚雷斯塔和上条重伤，才能获得可行解法。
- 若前卷已经改变科隆尊、城市系统或A.A.A的状态，本包按实际威胁和可用工具重排，不能复原敌人或装备强迫正史。

== 4. 节点推进表 ==
CORONZON-01 赴英不是取得通行许可
进入条件：NT19后科隆尊的英国根基仍构成威胁，玩家选择参与远征或已在英国接应。
场景目标：在克劳利灾害与英国防御之间建立接触渠道，区分阻止恶魔与攻击整个国家。
可见角色：上条、亚雷斯塔、一方、浜面、泷壶；分散登陆的同行者与英国守备人员。
玩家行动：核对同伴去向，护送受困修女与平民，向能交涉的人说明目的，寻找伦敦的资料与通信点。
结果：原作队伍登陆后分散，上条等与清教、骑士发生误解和冲突，浜面沿路救助雅妮丝部队；玩家可减少交战或留在护送线，不把入境视为全英国支持。
下一节点：伦敦的神威混淆危机出现时进入CORONZON-02；选择留在后方可继续本节点救援，不自动完成前线任务。

CORONZON-02 奥索拉拒绝成为武器
进入条件：奥索拉被伊西斯—德墨忒尔卷入，亚雷斯塔与英国防卫者的冲突仍在扩大。
场景目标：帮助她找回不靠毁伤他人也能救人的选择，同时阻止武装转移到新宿主。
可见角色：奥索拉、上条、亚雷斯塔；相关战场的一方、神裂与克里帕拼图545。
玩家行动：疏散交战区，听取奥索拉的无力感，提供真实可做的支援，限制神威混淆逃逸；与一方交换人工恶魔的线索。
结果：原作奥索拉拒绝武装并亲自终结其残余，一方与克里帕建立契约；玩家可提前劝止或采用其他保护方案。队伍到威斯敏斯特后面对黄金术师再现，而非就此解除全国危机。
下一节点：进入CORONZON-03；NT20在此收束，后续追击属于NT21。

CORONZON-03 魔导书身体与被打开的封锁
进入条件：黄金再现体在威斯敏斯特阻拦队伍，正面攻击难以突破马瑟斯的防御。
场景目标：识别敌方供能与自动防御，撤出包围，同时照顾并非没有自主意志的复制体。
可见角色：上条、亚雷斯塔、一方、克里帕、马瑟斯等黄金再现体；另一条路线的浜面、泷壶与受伤的福琼。
玩家行动：调查术式与魔导书载体，利用已有科技协助验证防御，救起福琼，评估重新启用城市系统是否会破坏对科隆尊的封锁。
结果：原作轨道攻击助队伍识破再现体，亚雷斯塔启用技术也使科隆尊脱封；浜面救起福琼。玩家若找到不解封的替代办法，保留封锁成果，不因卷次需要强迫恶魔逃出。
下一节点：取得苏格兰真实遗骸与王室行动的线索后进入CORONZON-04。

CORONZON-04 爱丁堡的假前提
进入条件：队伍追向苏格兰，王室护送、黄金追击与真实遗骸的调查相交。
场景目标：保护沿途人员，核验拘束科隆尊的前提，而不是只抢先抵达墓地。
可见角色：亚雷斯塔、上条、奥索拉、马瑟斯再现体；王室人员、一方、浜面与福琼，依各自到场顺序出现。
玩家行动：利用奥索拉建立的通信点与医疗支援，查验遗骸和契约说法，保存福琼的卡片记录，预留面对召唤关系骗局的防护。
结果：原作黄金供能被切断，福琼随其他再现体化为卡片；科隆尊借错误前提刺伤亚雷斯塔，焚毁被用来约束她的遗骸，浜面决定救回福琼。玩家可提前保全记录或识破骗局，不强制出现同样伤势。
下一节点：科隆尊的夺宝与仪式行动仍成立时进入CORONZON-05；NT21在此收束。

CORONZON-05 王权宝物与救人的交易
进入条件：科隆尊在苏格兰取得行动空间，福琼的记录需要保存或重新激活。
场景目标：同时应对王权宝物被夺、伤员救治与浜面的救回请求，避免把这些目标人为对立。
可见角色：科隆尊、浜面、王室守备；救治中的上条、亚雷斯塔，以及追踪者一方与相关同伴。
玩家行动：保护宝物与斯昆之石，安排上条的救治，核对科隆尊对福琼提供的办法是否可独立完成，追踪不列颠女王号的移动。
结果：原作上条初次迎战受重伤，科隆尊夺宝并与浜面交易后登船准备仪式；玩家可阻止夺宝、避免伤害或另助福琼，不把浜面简单定为应被消灭的叛徒。
下一节点：船上仪式仍在推进时进入CORONZON-06；若已阻断，则直接核验所有救援和残余威胁后转CORONZON-08。

CORONZON-06 登船后的不同目标
进入条件：队伍获得接近不列颠女王号的路线，知道单靠外部攻击难以阻止其运行。
场景目标：让登船、停船、救回福琼与驱魔彼此配合，不把所有人赶进同一决斗室。
可见角色：上条与美琴、食蜂等支援者；一方与克里帕、奈芙蒂斯；浜面、泷壶；亚雷斯塔、米娜、莉莉丝与科隆尊。
玩家行动：组织船内联络，保护婴儿与伤员，协助保存福琼记录并阻止自动修复抹去她，排除假冒安娜者对泷壶的利用；给一方验证新知识的空间。
结果：原作福琼被重新激活并救下浜面、泷壶；一方在与奈芙蒂斯的交锋中得到御坂网络意志与克里帕的协助。浜面取得救人结果后劝科隆尊停手，她仍选择继续仪式；玩家可改变这一交涉或行动顺序。
下一节点：科隆尊仍准备启动仪式时进入CORONZON-07；有效停战则转CORONZON-08清点与撤离。

CORONZON-07 三条行动共同阻断仪式
进入条件：船上多线支援已经到位，科隆尊仍有肉体保护和发动仪式的条件。
场景目标：分别解除肉体保护、阻断英国术式系统的信号、制止眼前攻击，不能用一个含糊的终极能力包办全部。
可见角色：科隆尊、上条、一方、克里帕、福琼、浜面；实际在场的亚雷斯塔、米娜、莉莉丝与支援者。
玩家行动：接合第三树产生的驱离效果，协助福琼调动黄金卡片阻断信号，封闭敌方利用A.A.A外部联络的通道，保护负责近距离制止的人。
结果：原作科隆尊灵魂被迫离开肉体，仪式信号遭福琼阻断；幻想杀手能够在改变的条件下发挥作用。科隆尊又借A.A.A通道切断上条右臂，反而破坏封印，引出的异常力量撕裂船体。玩家若堵住通道或提前停战，不补造断臂和沉船。
下一节点：进入CORONZON-08。

CORONZON-08 新约正卷的余波
进入条件：仪式被阻止或另有可信终止条件，众人能够安排救援、交接与离场。
场景目标：处理船上人员、王权宝物、城市责任和上条的异常，不把胜利误写成世界秩序已经全部解决。
可见角色：幸存的在场者、英国王室、一方与克里帕、上条及其同伴；亚雷斯塔相关幕后变化仅在取得对应见闻时呈现。
玩家行动：撤离危险区域，归还宝物，确认学园都市权限交接是否发生，追踪上条为何躲开同伴，保存尚未公开的身份与去向线索。
结果：原作米娜归还宝物，一方从亚雷斯塔处接过统括理事长权限；亚雷斯塔暗中控制科隆尊的躯体继续活动，并非两者都彻底消失。上条为避免封印异常伤及他人离开，为温莎庆功宴后的身份冲突留下原因。私人见闻不自动成为全体NPC的知识。
下一节点：玩家选择参加战后温莎活动且身份异常线仍成立时进入NT-22R-01；先做救援或另有改写时保留实际后日谈，不直接跳入创约第一卷。

== 5. 分支和偏离规则 ==
卷界依次为CORONZON-01—02、03—04、05—08，但不以翻卷重置已达成的停战和救援。封锁未破、福琼得到替代供能、宝物未失等改写，都应真实缩短或改变后续行动。原作伤害是原作默认发生的事实，不是玩家必须承受的失败惩罚或通行费用。

== 6. 换篇条件 ==
仪式威胁、关键救援和离场有明确结果后收束；玩家可明确暂离、跳时或选择不同锚点，不代替其同意任何世界改造。进入NT-22R须保留战后身份异常的因果；若已被玩家预防，转入真实的温莎后日谈，不伪称完成原作身份决战。

== 7. 防剧透边界 ==
不得因阶段7就解除所有防剧透规则。NT20不先告诉角色黄金的载体真相与福琼结局，NT21不预告第三树的具体效用；科隆尊的骗局按遗骸调查揭露。亚雷斯塔的战后躯体、真正安娜与艾华斯的接触、上条封印异常各有独立见闻边界；22R的身份答案与创约后续不提前广播。

== 8. 状态写回契约 ==
正式进入本包时，主线进度.当前阶段记“科隆尊与新约收尾”，主线进度.阶段序号使用整数7；主线进度.正史锚点.当前锚点记“科隆尊英国决战篇”，主线进度.当前节点使用CORONZON完整节点ID。已完成节点、可触发节点、玩家偏移及世界线记录等数组变化时均以op:"replace"整体替换，保留未变化的已有项。封锁、奥索拉、黄金载体、福琼、仪式、权限交接与上条异常写入主线进度.正史锚点.玩家偏移及既有世界线记录；任务追踪与NPC关系只更新实际发生的内容，不新增世界分岔、风险或强制阶段切换字段。

== 9. 收束结果 ==
- CZ-END-A 原作默认：福琼归来并阻断仪式，科隆尊终战结束，一方接过城市权限，上条的异常延续到22R。
- CZ-END-B 提前止战：玩家保住封锁或王权宝物、解决救援，使船上终战不再按原作发生。
- CZ-END-C 救援促成协作：玩家为奥索拉、福琼与被卷入者提供替代方案，减少阵营互害。
- CZ-END-D 未竟调查：玩家暂离，保留敌方条件、救援成果和未查清的身份，不自动代选结局。
- CZ-END-E 自主收束：玩家用已成立的其他方案结束仪式，所有实际改变继续影响22R与后续城市生活。
