【事件包：科隆尊篇】
事件包ID：CORONZON
所属阶段：阶段7·新约终章·本源真相（科隆尊决战实际对应新约20-23卷终盘；“创约”为新约之后的新篇章，标签已勘误）
时间窗口：12月中旬
别名与触发词：科隆尊 / 艾华斯 / 创约 / 魔法本源 / CORONZON

== 1. 核心定位 ==
本篇是阶段7的终局级主线事件：更上层的魔法存在——艾华斯与科隆尊——登场，魔法侧最本源的力量与真相被揭开；学园都市与世界的终极底牌翻出。与前七阶段不同，本篇的规则是：**玩家的选择开始决定世界的走向，可以完全偏离原著结局。**
玩家进入本篇的方式：开局锚点直接选在本篇；或随阶段7时间推进自然卷入。本篇不设标准答案——玩家与这个世界对话的每一句话，都在书写结局。

== 2. 不可丢失的核心事实 ==
- 艾华斯是亚雷斯塔·克劳利的"引导者"，以本源层级的存在姿态现身于学园都市；科隆尊是更深层魔法存在的显现。
- 魔法侧最本源的真相随科隆尊的降临揭开：魔法与科学的分野、这座都市存在的真正意义、亚雷斯塔计划的终极面目。
- 终极对决的力量层级超越此前一切篇章——但卡片不因此使用失败收场或惩罚判定，事件的张力来自选择而非数值。
- 世界的走向在这一篇真正交到玩家手里：原著结局只是众多可能之一。
- 事件的每一个收束都必须以世界线记录完整存档——这是这张卡世界线的"分岔点"。

== 3. 玩家可改写的部分 ==
- **全部。** 本篇没有锁定的原著锚定路线：玩家可以推动原著近似结局，也可以带领世界走向完全原创的未来。
- 玩家的立场：见证者、调解者、对抗者、继承者、或任何原创角色定位。
- 与艾华斯/科隆尊的对话与交易：玩家可以质疑、协商、结盟、对抗或超越阵营视角。
- 亚雷斯塔计划的处置、世界分岔的方向、魔法与科学关系的新形态——一切由玩家的选择累积决定。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；力量层级差距不构成对玩家的惩罚机制。

== 5. 分支和偏离规则 ==
- 本篇是全卡唯一"原著锚定权重最低"的事件包：玩家的原创路线与原著近似路线地位完全平等。
- 篇章内偏离：任何立场与路线变化都在当前锚点内推进，不构成跳篇理由。
- 核心结果改写：本篇的一切"改写"都按正式结局处理，必须完整写入世界线记录。
- 延后与跳过：玩家回避时，事件按背景因果缓慢推进，但**不会自动替玩家做出世界走向的核心抉择**——若玩家长期不抉择，世界保持"分岔悬置"状态而非按原著默认走完。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. CORONZON-08 完成（终局收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点（回到任意篇章或时间点重玩）。
4. 玩家明确进行时间跳跃。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态、换篇原因、关键偏移事实、新篇章首节点。回到本篇时世界分岔状态完整恢复。

== 7. 防剧透边界 ==
- 本篇本身就是"剧透终点"：艾华斯、科隆尊、亚雷斯塔计划的深层真相在本篇内按玩家探索节奏揭开，无需保留。
- 但不引入创约更后续的内容与本篇无关联的设定；艾华斯/科隆尊按本篇卡面口径呈现，不附加额外神学体系。
- 此前所有篇章的防剧透边界在本篇内自然解除——所有前篇伏笔可在本篇兑现。
- 无论世界走向如何，卡片的基础规则（无风险值/无失败收场/无反噬/能力自由混用）不变。

== 9. 收束结果 ==
- CZ-END-A 原著近似收束：玩家推动世界走向与原著近似（但不强制相同）的终局。
- CZ-END-B 玩家的世界：玩家以自己的抉择定义世界新秩序，成为新格局的奠基者之一。
- CZ-END-C 对话的终局：玩家以对话/交易/调解而非战斗解开终极事件，世界以非战斗方式转向。
- CZ-END-D 分岔悬置：玩家未做核心抉择而暂离，世界保持分岔状态，随时可续。
- CZ-END-E 完全原创收束：玩家以完全原创的方式（含跨体系能力自由发挥）终结本篇，世界线记录如实反映。
以上所有收束均不使用死亡、失败收场、风险值或反噬机制；宏大与遗憾只作为剧情事实呈现，不作为对玩家的惩罚判定。本篇收束后，玩家的故事可以任意继续——这张卡的回答始终是：世界会记住你走过的每一条世界线。
