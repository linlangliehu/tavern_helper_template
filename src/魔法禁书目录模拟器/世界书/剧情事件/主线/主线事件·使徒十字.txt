【事件包：使徒十字篇】
事件包ID：ST-CROSS
所属阶段：阶段4·旧约·祭典与十字（9月底）
时间窗口：9月下旬（大霸星祭后）
别名与触发词：使徒十字 / 罗马正教 / 灵装追缉 / 境外魔法势力 / ST-CROSS

== 1. 核心定位 ==
本篇是阶段4收束型主线事件：罗马正教将威力灵装"使徒十字"秘密运入学园都市，企图以圣器之力支配这座科学之城；魔法侧与科学侧罕见地联合追缉，一场跨国魔法暗战在都市街头展开。事件主题是"信仰与科学之城"——当教会的野心撞上无法被术式直接征服的都市。
玩家进入本篇的方式：开局锚点直接选在本篇；或承接大霸星祭篇埋下的"罗马正教影子"伏笔深入追查。玩家立场自由：联合追缉组成员、独立猎人、灵装守护者、或与各方周旋的第三势力。

== 2. 不可丢失的核心事实 ==
- "使徒十字"是罗马正教的强力灵装，拥有支配一座城市运作的恐怖权能——一旦启动，学园都市的控制权将被教会夺取。
- 运送灵装的是一位以"追迹封锁"（干扰追踪与感知的术式）闻名的女性搬运人：行踪飘忽、擅长白刃战、以打工者伪装渗透都市。
- 幕后策划者为罗马正教雅妮塞部队的修女——狂信而坚定的"支配都市"计划推动者，率雅妮塞部队随行策应。
- 魔法侧（英国清教的神裂火织、史提尔·马格努斯等）与科学侧（土御门元春等暗部要员）罕见联合，组成追缉网。
- 灵装一旦启动即难以逆转，追缉的时间压力真实存在；事件节奏紧张但不使用失败收场判定。
- 事件收束以"灵装的处置"为核心：回收、封存、摧毁、或交还教会，均属合法结局。

== 3. 玩家可改写的部分 ==
- 追缉角色：加入联合追缉网、独立行动、或与搬运人接触（说服/策反/交易均合法）。
- 搬运人的命运：被擒、逃逸、被策反、或与玩家达成秘密协议——她是本篇最重要的可改写人物。
- 雅妮塞部队的处置：正面击破、劝退、谈判、或借两方之力围堵。
- 使徒十字的最终去向：玩家参与决定（重大偏离机会：灵装流落玩家手中亦可，按世界线记录处理）。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；魔法侧对玩家能力体系的认知变化按剧情记录。

== 4. 节点推进表 ==
节点ID格式：ST-CROSS-{NN}（必须使用完整ID，禁止简写如SC-01）。每轮最多推进一个主要节点。

ST-CROSS-01 境外的影子
进入条件：进入本篇（9月下旬锚点或承接大霸星祭伏笔）。
场景目标：都市里出现罗马正教活动迹象——境外访客的异常行踪、教会痕迹、情报异动。
可见角色：（可选）土御门元春、风纪委员、可疑访客。
玩家行动：调查、上报、与熟悉角色交换情报。
结果："罗马正教有所动作"确凿；灵装传闻入耳。
下一节点：ST-CROSS-02。

ST-CROSS-02 追迹封锁
进入条件：玩家追查灵装下落。
场景目标：与搬运人首次遭遇——追迹封锁术式干扰感知，白刃战交锋后对方脱身。
可见角色：搬运人、（可选）追缉组成员。
玩家行动：追踪、交战、记住特征、或主动放线。
结果：搬运人进入玩家视野；"使徒十字在都市内"确凿。
下一节点：ST-CROSS-03。

ST-CROSS-03 联合追缉网
进入条件：灵装情报扩散。
场景目标：魔法侧与科学侧罕见联手——神裂、史提尔、土御门等组成追缉网，玩家被邀请/默许加入。
可见角色：神裂火织、史提尔·马格努斯、土御门元春。
玩家行动：加入协作、讨价还价、单独行动、或共享情报。
结果：追缉网成形；玩家的位置与话语权确立。
下一节点：ST-CROSS-04。

ST-CROSS-04 搬运人的日与夜
进入条件：玩家深入追缉或接触搬运人。
场景目标：搬运人的双重生活浮出——打工伪装、游走都市、灵装从未离身。
可见角色：搬运人、其接触的市民。
玩家行动：突袭、跟踪、搭话、攻心、或设陷阱。
结果：搬运人的形象立体化；玩家获得改变其命运的机会。
下一节点：ST-CROSS-05。

ST-CROSS-05 雅妮塞部队
进入条件：搬运人受阻或时间压力升级。
场景目标：幕后修女与雅妮塞部队浮出水面——"支配都市"的狂信计划与后备手段亮相。
可见角色：幕后修女、雅妮塞部队成员。
玩家行动：侦查部队、瓦解后备手段、谈判、或与追缉网合力。
结果：敌方全貌揭晓；启动灵装的时间压力成为共识。
下一节点：ST-CROSS-06。

ST-CROSS-06 启动倒计时

场景目标：灵装启动仪式的地点与窗口锁定——全城命运进入倒计时。
可见角色：雅妮塞部队、搬运人、追缉网全员。
玩家行动：参与决战部署、分派任务、争取搬运人倒戈（最后机会）。
结果：决战阵型就位；本篇最高潮开启。
下一节点：ST-CROSS-07。

ST-CROSS-07 十字支配战

可见角色：全部本篇角色。
玩家行动：自由发挥（含跨体系能力、原创战术）；可以让神裂/当麻线按原著承担关键一击，玩家主导亦可；AI 合理演绎，不判定失败收场。
结果：灵装启动被阻止（或按重大偏移短暂生效后被逆转）；敌方处置完成。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变追缉方式、阵营立场或处置态度时，保留当前锚点切分支推进。
- 核心结果改写：策反搬运人、提前夺取灵装、或让灵装短暂启动后被逆转时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按原著因果自行发展（联合追缉网完成阻止），不强制玩家参与。
- 搬运人与雅妮塞部队的后续状态跨篇保留（若被策反/被擒，后续篇章按世界线记录出场）。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. ST-CROSS-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过 9 月底。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：罗马正教高层的全貌与神之右席、英国清教内部博弈的深层、亚雷斯塔布局、任何后续篇章设定。
- 使徒十字的权能只按"支配城市的灵装"呈现，不展开其神学渊源。
- 幕后修女与雅妮塞部队按本篇事件呈现，不延伸其后续原著命运。
- 科学侧对魔法术式的应对以联合追缉的协作形态呈现，不引入新的世界观机制。

== 9. 收束结果 ==
- SC-END-A 原著近似收束：联合追缉成功，灵装被回收，搬运人被捕。
- SC-END-B 搬运人倒戈：玩家策反搬运人，灵装平安交接，敌方计划瓦解（重大偏移）。
- SC-END-C 灵装易手：使徒十字流入玩家或第三方手中，成为悬而未决的世界线变数。
- SC-END-D 玩家暂时退出：玩家明确离开，事件按原著因果自行发展并延后。
- SC-END-E 完全原创收束：玩家以原创方案（含跨体系能力自由发挥）改写整场事件，世界线记录如实反映。
以上所有收束均不使用死亡、失败收场、风险值或反噬机制；遗憾与代价只作为剧情事实呈现，不作为对玩家的惩罚判定。
