【事件包：使徒十字篇】
事件包ID：ST-CROSS
所属阶段：阶段4·旧约·祭典与十字（9月19日—25日，与大霸星祭同期）
时间窗口：9月19日—9月25日（大霸星祭同期进行，闭幕夜收束）
别名与触发词：使徒十字 / 罗马正教 / 灵装追缉 / 境外魔法势力 / 丽多薇雅 / 欧莉安娜 / ST-CROSS

== 1. 核心定位 ==
本篇是阶段4与大霸星祭同期并进的主线事件：罗马正教毒蔷薇·丽多薇雅·罗伦婕蒂暗中将威力灵装"使徒十字"运入学园都市，意图在大霸星祭闭幕夜借星辰定位发动，一口气把学园都市纳入罗马正教版图；搬运人欧莉安娜·汤森以"追迹封锁"术式一路穿行祭典人潮，双方就在耀眼的祭典舞台之下正面相撞。事件主题是"祭典灯火下的圣器"——当全城仰望烟火时，灵装指向星空的通道被灯光本身遮蔽。
玩家进入本篇的方式：开局锚点直接选在大霸星祭季（9月19—25日窗口即同本篇）；或承接大霸星祭篇埋下的"罗马正教影子"伏笔深入追查。玩家立场自由：联合追缉组成员、独立猎人、灵装守护者、或与各方周旋的第三势力。

== 2. 不可丢失的核心事实 ==
- "使徒十字"是罗马正教的强力灵装，借星辰之力发动，拥有支配一座城市运作的恐怖权能——一旦启动，学园都市的控制权将被教会夺取。
- 幕后主谋是罗马正教的丽多薇雅·罗伦婕蒂——人称"毒蔷薇"的圣歌队人脉核心、独行者，计划以学园都市的改制换取上级信任；她全程不落面，仅遥控与接应。
- 运送灵装的搬运人是欧莉安娜·汤森："追迹封锁"术式令追踪者感知扭曲，行踪飘忽、白刃战极强，以打工者伪装混入大霸星祭人潮。
- 使徒十字必须在闭幕夜发动：灵装需借特定星象定位，而大霸星祭闭幕夜的漫天烟火与全城灯光恰恰把星光埋掉——原著中正是这份"祭典属于自己的灯火"无意间挫败了这场战争。
- 魔法侧（英国清教的神裂火织、史提尔·马格努斯等）与科学侧（土御门元春等暗部要员）罕见联合，组成追缉网，在祭典人潮中追猎搬运人。
- 灵装一旦启动即难以逆转，追缉的时间压力真实存在；事件节奏紧张但不使用失败收场判定。
- 事件收束以"灵装的处置"为核心：回收、封存、摧毁、或交还教会，均属合法结局。
- 丽多薇雅的事后处置（被拘捕、谈判、遁走等）属于本篇收束内容；雅妮塞部队与本篇无关（她们是亚得里亚海女王篇的人物）。

== 3. 玩家可改写的部分 ==
- 追缉角色：加入联合追缉网、独立行动、或与搬运人接触（说服/策反/交易均合法）。
- 搬运人的命运：被擒、逃逸、被策反、或与玩家达成秘密协议——她是本篇最重要的可改写人物。
- 祭典窗口的利用：玩家可以选择白天赛台/人流做掩护，或故意在闭幕夜前后布置奇袭。
- 使徒十字的最终去向：玩家参与决定（重大偏离机会：灵装流落玩家手中亦可，按世界线记录处理）。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；魔法侧对玩家能力体系的认知变化按剧情记录。

== 4. 节点推进表 ==
节点ID格式：ST-CROSS-{NN}（必须使用完整ID，禁止简写如SC-01）。每轮最多推进一个主要节点。

ST-CROSS-01 祭典人潮里的影子
进入条件：进入本篇（大霸星祭开幕 9月19日 前后锚点，或承接大霸星祭篇伏笔）。
场景目标：祭典人潮中出现罗马正教活动迹象——境外访客的异常行踪、教会痕迹、情报异动；白天比赛正常进行。
可见角色：（可选）土御门元春、风纪委员、可疑访客、参赛选手。
玩家行动：调查、上报、与熟悉角色交换情报、混入观赛人流跟梢。
结果："罗马正教有所动作"确凿；灵装传闻入耳。
下一节点：ST-CROSS-02。

ST-CROSS-02 追迹封锁
进入条件：玩家追查灵装下落。
场景目标：与搬运人欧莉安娜·汤森首次遭遇——追迹封锁术式干扰感知，白刃战交锋后对方脱身，混入赛事人流。
可见角色：搬运人欧莉安娜、（可选）追缉组成员。
玩家行动：追踪、交战、记住特征、或主动放线。
结果：搬运人进入玩家视野；"使徒十字已随祭典运入都市"确凿。
下一节点：ST-CROSS-03。

ST-CROSS-03 联合追缉网
进入条件：灵装情报扩散。
场景目标：魔法侧与科学侧罕见联手——神裂、史提尔、土御门等组成追缉网，借祭典赛程间隙行动；玩家被邀请/默许加入。
可见角色：神裂火织、史提尔·马格努斯、土御门元春。
玩家行动：加入协作、讨价还价、单独行动、或共享情报。
结果：追缉网成形；玩家的位置与话语权确立。
下一节点：ST-CROSS-04。

ST-CROSS-04 搬运人的日与夜
进入条件：玩家深入追缉或接触搬运人。
场景目标：欧莉安娜的双重生活浮出——白天在祭典打工伪装、游走赛场、灵装从未离身；追迹封锁在灯火下更显诡异。
可见角色：搬运人欧莉安娜、其接触的市民/风纪委员。
玩家行动：突袭、跟踪、搭话、攻心、或设陷阱。
结果：搬运人的形象立体化；玩家获得改变其命运的机会。
下一节点：ST-CROSS-05。

ST-CROSS-05 毒蔷薇的算盘
进入条件：搬运人受阻或时间压力升级。
场景目标：幕后主谋丽多薇雅·罗伦婕蒂的轮廓浮出——"支配都市"的狂信计划、祭典闭幕夜发动的时点锁定；她的遥控与后备手段亮相。
可见角色：丽多薇雅（远距离/接应形态）、搬运人、追缉网成员。
玩家行动：侦查幕后、瓦解后备手段、谈判、或与追缉网合力。
结果：敌方全貌揭晓；"闭幕夜=发动窗口"成为共识。
下一节点：ST-CROSS-06。

ST-CROSS-06 启动倒计时
进入条件：闭幕夜临近，灵装进入启动准备。
场景目标：灵装启动仪式的地点与窗口锁定——星辰定位对夜空直视线有要求，全城灯火成了天然变数；追缉网分派拦截线。
可见角色：丽多薇雅一方、搬运人、追缉网全员。
玩家行动：参与决战部署、分派任务、争取搬运人倒戈（最后机会）、或主动操纵"灯火遮蔽"要素。
结果：决战阵型就位；本篇最高潮开启。
下一节点：ST-CROSS-07。

ST-CROSS-07 十字支配战
进入条件：ST-CROSS-06 完成（大霸星祭闭幕夜）。
场景目标：决战——阻止灵装启动或中断已开始的仪式；天空被祭典烟火与灯光点亮，灵装对星空的锁定被不断干扰；多方混战。
可见角色：全部本篇角色（含丽多薇雅的全貌）。
玩家行动：自由发挥（含跨体系能力、原创战术）；可以让神裂/当麻线按原著承担关键一击，玩家主导亦可；AI 合理演绎，不判定失败收场。
结果：灵装启动被阻止（原著轨道：烟花/灯光遮蔽星光导致发动失败；或按重大偏移短暂生效后被逆转）；敌方处置完成。
下一节点：ST-CROSS-08。

下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变追缉方式、阵营立场或处置态度时，保留当前锚点切分支推进。
- 核心结果改写：策反搬运人、提前夺取灵装、或让灵装短暂启动后被逆转时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按原著因果自行发展（联合追缉网完成阻止），不强制玩家参与。
- 搬运人欧莉安娜与主谋丽多薇雅的后续状态跨篇保留（若被策反/被擒/被拘，后续篇章按世界线记录出场）。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. ST-CROSS-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过大霸星祭闭幕（9月25日）。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==

- 使徒十字的权能只按"借星象支配城市的灵装"呈现，不展开其神学渊源。
- 丽多薇雅按本篇事件呈现（毒蔷薇的野心与败北），不延伸后续原著命运。
- 亚得里亚海女王篇（雅妮塞部队）与本篇无关，不在本篇提前铺垫。
- 科学侧对魔法术式的应对以联合追缉的协作形态呈现，不引入新的世界观机制。
