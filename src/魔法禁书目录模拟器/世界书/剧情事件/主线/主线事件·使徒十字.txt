【事件包：使徒十字篇】
事件包ID：ST-CROSS
所属阶段：阶段4·旧约·祭典与十字
年层：Y
时间窗口：9月19日追缉、当夜仪式失败；20日凌晨追捕余波。祭典背景另为19–25日
别名与触发词：使徒十字事件 / 刺突杭剑交易疑云 / ST-CROSS / ST-CROSS-01
证据定位：O22、O23；旧约9–10及官介；官方动画年表

== 1. 核心定位 ==
在开幕日人潮中追踪伪装的交易，识破把学园都市纳入正教影响的仪式。主力是上条、史提尔和土御门；不能把神裂或未证的圣歌队人脉当成本篇行动核心。

== 2. 不可丢失的核心事实 ==
- 英国清教最初得到刺突杭剑交易情报；欧莉安娜搬运的物品是伪装看板，真正目标是丽多薇雅掌握的使徒十字。
- 不能因看见搬运人就断定真正灵装已随她入城；追踪路线与仪式部署地点须分别查明。
- 吹寄在追缉中遭术式波及，姬神也被误伤；体育祭照常进行的表面下已有实际受害者。
- 原作默认19日日落前欧莉安娜被击败，丽多薇雅仍未被找到。使徒十字依赖星象，开幕日夜间烟花遮蔽星空使仪式失败，不是25日闭幕夜才阻止。
- 20日未明萝拉锁定丽多薇雅的行踪，属于追捕余波；祭典后续日程与本案主体分开。

== 3. 玩家可改写的部分 ==
可追查真灵装、保护伤者、提前破坏部署或争取欧莉安娜停手。烟花是原作默认解法，不禁止玩家主动救援；改变星象条件也不强迫仪式成功作为惩罚。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；ST-CROSS与科学侧祭典包共享背景而不共用节点。

ST-CROSS-01 危险交易的传闻
进入条件：9月19日开幕日，清教要求调查灵装交易。
场景目标：了解刺突杭剑情报，避免贸然把圣人投入可能针对她们的陷阱。
可见角色：上条、史提尔、土御门；萝拉经联络提供情报。
玩家行动：核验、分工、观察入城运输，不打断所有比赛。
结果：欧莉安娜进入追查范围，但交易物真伪尚未证明。
下一节点：ST-CROSS-02。

ST-CROSS-02 人潮中的搬运人
进入条件：找到欧莉安娜或其留下的术式痕迹。
场景目标：在人群与比赛场地之间追踪，防范她的即用型魔法反击。
可见角色：欧莉安娜、上条、史提尔、土御门。
玩家行动：接力追踪、疏散、拆除术式或试探交涉。
结果：追踪者被反侦察，保护普通参赛者成为行动限制而非玩家惩罚。
下一节点：ST-CROSS-03。

ST-CROSS-03 吹寄倒下
进入条件：追缉与比赛路线交叉。
场景目标：救治受术式波及的吹寄，防止追踪继续伤及人群。
可见角色：吹寄、上条、同学、医护；土御门与史提尔按联络加入。
玩家行动：送医、清理危险点、保留追踪线索或寻找安全替代路线。
结果：原作默认吹寄受伤退出现场；追兵不能只顾目标而忽视受害者。
下一节点：ST-CROSS-04。

ST-CROSS-04 假货与误伤
进入条件：继续接触欧莉安娜，怀疑所搬物品的用途。
场景目标：识破刺突杭剑是假情报，并救助遭误伤的姬神。
可见角色：欧莉安娜、姬神、史提尔、上条。
玩家行动：核验看板、组织治疗、追问真正委托人与目标。
结果：原作默认姬神受到救治，调查转向丽多薇雅与使徒十字，而非继续找一把不存在的交易剑。
下一节点：ST-CROSS-05。

ST-CROSS-05 星象决定的地点
进入条件：确认真正灵装的身份。
场景目标：查明使徒十字的星象发动条件，区分诱饵路线与真正部署。
可见角色：史提尔、土御门、上条；清教支援者通过联络出现。
玩家行动：比对地图、查部署位置、预警或设计遮断条件。
结果：发动时间逼近夜间，必须阻断仪式而不是等祭典闭幕。
下一节点：ST-CROSS-06。

ST-CROSS-06 日落前的对决
进入条件：追上欧莉安娜，仍未确定丽多薇雅位置。
场景目标：结束搬运人的阻挠，争取最后的调查时间。
可见角色：欧莉安娜、上条、土御门、史提尔。
玩家行动：联合破术、说服停手、夺取联络线索或转向已查到的部署点。
结果：原作默认欧莉安娜败北，但击败她不自动等于找到真灵装。
下一节点：ST-CROSS-07。

ST-CROSS-07 开幕夜的烟花
进入条件：19日夜间达到仪式所需时机。
场景目标：确认星象条件被破坏，防止仍存在的部署继续生效。
可见角色：上条与追踪组；丽多薇雅现场只在相应视角可见。
玩家行动：落实既定阻断方案、检查烟花遮蔽、救助未撤离者。
结果：原作默认祭典烟花遮蔽星空，丽多薇雅发动失败；危机当夜结束，不拖到25日。
下一节点：ST-CROSS-08。

ST-CROSS-08 二十日凌晨的追捕余波
进入条件：仪式失败，进入20日未明或事后收到报告。
场景目标：接收萝拉锁定丽多薇雅的消息，交接追捕并回访伤者。
可见角色：萝拉通过联络出现；追踪组、吹寄与姬神按所在地点出现。
玩家行动：传递证据、协助交接、探病或返回祭典活动。
结果：本案主体已结束，追捕善后有承接；19–25日祭典仍可继续。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前捕获、改变烟花或公开警报均按实际后果记录，不强迫重演原作误伤。所有旧完整节点和完成记录保留；旧存档较晚才解决的情况作为玩家偏移，不倒退日期强修经历。

== 6. 换篇条件 ==
ST-CROSS-08完成、明确退出/跳时或仪式提前失效后可换篇。20日可转DAIHASEISAI的未完成科学侧节点或FESTIVAL活动；9月25日中奖、27日意大利行动另接ADRIA，不用等闭幕才结算使徒十字。

== 7. 防剧透边界 ==
真假交易与星象条件通过线索逐步揭示。不得因本案尚未结束封死玩家选择未来锚点，也不得在本包提前执行科学侧异变或女王舰队结局。

== 8. 状态写回契约 ==
推进、仪式失败和换篇同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留记录。星象阻断、伤者与追捕偏移写主线进度.正史锚点.玩家偏移；祭典活动只写任务追踪，不抢主线锚点。

== 9. 收束结果 ==
- SC-END-A：近原作，19日夜仪式失败，20日凌晨进入追捕余波。
- SC-END-B：玩家提前破坏部署或抓获相关者。
- SC-END-C：协作与救护关系延续，祭典继续。
- SC-END-D：玩家退出，按场外因果记录已发生结果。
- SC-END-E：原创阻断方案，不强制延长到闭幕或施加补偿性损失。
