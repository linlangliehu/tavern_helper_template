【事件包：创约第四卷·洛杉矶空城】
事件包ID：GENESIS-04
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第4卷；R&C Occultics海外事件。
时间窗口：本篇Y年，洛杉矶当地12月26日起。社区译文给出当地26日03:00的计划抵达安排及跨国际日期线说明，不把计划当实测到达；图排至27日的全卷终点未获直接日期证实，回程不硬填时刻。
别名与触发词：创约第四卷 / 创约第四卷洛杉矶空城 / GENESIS-04

== 1. 核心定位 ==
英国清教与学园都市针对R&C总部展开联合行动，却面对异常寒潮与洛杉矶约三千万人口消失。上条一行从救助Helcalia Grocery开始，追查母亲Melzabeth留下的物流系统线索，识破Citrinitas的沙系魔术与嫁祸；御坂妹妹们的公开救援同时改变世界对克隆人的认识。

== 2. 不可丢失的核心事实 ==
- 联合行动名为Operation Overlord Revenge，目标是R&C；空城调查与母女救援不能缩成一次总部突击。
- Helcalia仍在寻找母亲。Melzabeth与Logistic Hornet物流技术有关，反对该系统遭滥用，并尝试切断R&C对网络的控制。
- Citrinitas用沙系魔术处理消失的人口、制造假象与假母亲，试图把灾难罪名推给Melzabeth，使她失去正常社会的庇护。
- 寒潮与巨型物流机对气压、温度的操纵相关，不是无缘无故出现的自然灾害。
- 妹妹们救援民众并公开克隆身份，美国总统Roberto Katze公开支持；她们不是只为上条提供匿名战力的背景人。
- 原作Citrinitas的计划失败，真实母亲获救，物流系统不再服从R&C命令；关联副总统Darris Hewlane被捕。母女团聚不等于安娜及其全部布局永久消失。

== 3. 玩家可改写的部分 ==
- 改变空城中的搜救顺序、与母女建立的信任、母亲技术证据的保存程度。
- 提前识破假母亲、切断物流控制，减少寒潮危害；不要求先让Helcalia受骗才允许推进。
- 协助妹妹们自主公开身份、保护她们的发声与人身安全，改变公众获得真相的过程，不替全体妹妹强制表态。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；海外当地时间与学园都市时间分开叙述。

GENESIS-04-01 联合行动遇上空城
进入条件：选择本卷锚点，或参与前往洛杉矶的R&C调查行动。
场景目标：核对异常低温、无人街道与失联情报，确立搜救优先级。
可见角色：上条当麻、茵蒂克丝、欧提努斯、可联络的联合行动人员。
玩家行动：调查人口消失范围、寻找避寒地点、建立通信，不把空城当成可任意轰炸的无人战场。
结果：总部行动转入人口失踪与环境危机调查，玩家掌握当前地点和当地日期。
下一节点：GENESIS-04-02。

GENESIS-04-02 没有放弃找妈妈的孩子
进入条件：在空城遇见Helcalia，或发现她留下的求助踪迹。
场景目标：先确保孩子安全，再核查她对母亲与灾难的记忆。
可见角色：Helcalia Grocery、上条、茵蒂克丝、欧提努斯。
玩家行动：提供保暖与食物、陪同寻人、询问熟悉的地点，避免用“母亲就是犯人”迫使她放弃求救。
结果：母女的分离成为调查主线，线索指向Melzabeth与Logistic Hornet，而非确认母亲有罪。
下一节点：GENESIS-04-03。

GENESIS-04-03 母亲留下的抵抗
进入条件：取得Melzabeth留下的影像、设备或工作相关线索。
场景目标：还原她试图摆脱R&C控制的动机，找到物流系统可被夺回的环节。
可见角色：Helcalia、上条一行；Melzabeth通过留下的信息被理解。
玩家行动：比对记录、保护程序与设备、联系技术支援，区分她的原创技术与R&C的滥用命令。
结果：调查发现母亲并非主动造成空城的幕后主谋，也获得判断后续“母亲”真伪的依据。
下一节点：GENESIS-04-04。

GENESIS-04-04 沙中的假母亲
进入条件：母亲形象突然出现，或调查触及Citrinitas制造的人偶与沙系异常。
场景目标：在保护Helcalia的同时拆穿替身与嫁祸，定位真实受害者。
可见角色：Citrinitas操纵的假象、Helcalia、上条、欧提努斯。
玩家行动：用已得线索验证身份、隔开孩子与袭击者、查找人口被藏匿的术式联系，拒绝替R&C传播未经核实的指控。
结果：Citrinitas借灾难孤立Melzabeth的计划暴露，救母与救城成为同一因果链。
下一节点：GENESIS-04-05。

GENESIS-04-05 妹妹们站到镜头前
进入条件：城市救援和信息战扩大，妹妹们实际加入行动。
场景目标：保护失踪人口的救援进程，让克隆人作为救援者与人被看见。
可见角色：参与行动的御坂妹妹、上条一行；Roberto Katze通过公开发言介入。
玩家行动：协助疏散、保存真实影像、反驳嫁祸，尊重每名妹妹对身份公开的判断。
结果：原作妹妹们公开身份并得到总统支持，R&C对舆论的控制被削弱；这为后续人权与审判议题留下真实影响。
下一节点：GENESIS-04-06。

GENESIS-04-06 夺回天空与人口
进入条件：掌握沙系术式及物流系统的控制关系，具备营救和反击条件。
场景目标：击破Citrinitas的袭击并停止物流机制造寒潮，救出真实Melzabeth与失踪者。
可见角色：上条、欧提努斯、Citrinitas、Melzabeth；妹妹们与行动人员负责各自救援区。
玩家行动：破解假象、掩护上条接近术式、协助技术人员拒绝R&C命令，同时组织灾后救护。
结果：原作沙系阴谋被阻止、母亲获救，Logistic Hornet不再执行R&C指令；十二架物流机解除威胁，关联副总统Darris Hewlane被捕。
下一节点：GENESIS-04-07。

GENESIS-04-07 汉堡餐桌与归途
进入条件：城市主要危险解除，母女能够安全重逢。
场景目标：完成母女安置、搜救交接和海外行动后的关系确认。
可见角色：Helcalia、Melzabeth、上条一行；妹妹们按实际位置参与告别或后续联络。
玩家行动：陪母女吃饭、交还证据与设备、安排回程，记录克隆人公开身份引出的社会议题。
结果：默认母女团聚，妹妹们的权利与一方通行的责任进入公众讨论；返程日期按实际叙事标明，不补造27日全篇终点。
下一节点：本包收束；回到学园都市并到达12月29日时可接GENESIS-05-01。

== 5. 分支和偏离规则 ==
- 若玩家先恢复物流控制或救出母亲，后续改为清除残余沙系危险与公开证据，不再让她被同样手段绑走。
- 若妹妹们未在玩家线公开身份，保留救援成果与不同舆论状态，不强行安排世界立即得知全部克隆内幕。
- 一处系统恢复不自动证明所有失踪者获救；按实际完成的搜救范围结算，不用无主语的“敌人撤退”代替处置。

== 6. 换篇条件 ==
母女安危、人口救援、物流危机与关键证据已有交代，或玩家明确离开、跳跃、另选锚点时换篇。回程是地点交接，不以国际日期线偷加或抹掉剧情日。

== 7. 防剧透边界 ==
Citrinitas的手法、假母亲、Darris Hewlane的关联，须随调查揭露；Helcalia起初只掌握孩子可知的经历。后续超绝者与爱丽丝的事实不提前灌入本卷。

== 8. 状态写回契约 ==
- 主线进度沿用当前阶段“创约”、阶段序号8、阶段状态与完整当前节点ID；当地日期只在既有时间叙事中保持一致，不新增时区或年层字段。
- 正史锚点记录洛杉矶空城、母女解救的默认走向；玩家偏移保留系统恢复、公开身份与责任处置的实际差异。
- 已完成节点、可触发节点整体replace并去重；任务追踪保留搜救和回程事项，不能在团聚时清空仍未完成的救援。
- 母女、妹妹们、R&C与官方的关系变化沿用NPC关系、在场人物、势力关系、世界线记录，不新建字段。

== 9. 收束结果 ==
默认是人口消失与寒潮阴谋受挫、母女重新共同生活、妹妹们公开进入社会视野。玩家改变的救援方式与社会反应继续存在；下一卷接学园都市的暗部余波，不宣称R&C幕后与安娜的一切问题已彻底解决。
