【事件包：ITEM第二卷·蜂蜜女王】
事件包ID：ITEM-02
所属阶段：阶段0·旧约·前日谭
年层：Y−1（前史图排）
时间窗口：八月候选；图排8月3–9，社区整理列4–7日若干行动，两者都不当作原文明示的整卷起讫。
别名与触发词：ITEM第二卷 / 蜂蜜女王事件 / ハニークイーン / ITEM-02 / ITEM-02-01

== 1. 核心定位 ==
正式四人组成的ITEM接到针对网络婚姻诈骗师“蜂蜜女王”的任务。能力开发机密与原子崩坏开发人员受损，基地遇袭将她们拖入被人引导的追击，前原子崩坏主任研究者浮出水面。
蜂蜜女王属于《某暗部的少女共栖》第二卷，不是独立心理掌握漫画、食蜂的称号或新约11的别名。赌场、研究所与最后反击有相对顺序；本包聚焦这条任务因果，不把卷内全部支线都算作完成。

== 2. 不可丢失的核心事实 ==
- 表层婚姻诈骗掩盖着能力开发资料争夺；麦野接下任务与原子崩坏开发人员受害有关。
- 基地遭袭并非一次孤立挑衅；ITEM感到被敌人引导，旧研究负责人又熟悉相关技术。
- 社区整理中，蜂蜜女王是以诈骗师形象活动的组织，原主任研究者鮎魚女キャロライン及协力者太刀魚メアリー参与行动；不因金发或精神系手段便认成食蜂。
- DNA资料、研究数据与Angelica计划有关；玩家只有实际取得线索才知道用途，不把名称自动解释成某个魔法术式。
- 泷壶介入太刀魚メアリー的研究所之战，与最终对原主任之战是两次行动，不能压成一次救场。
- 原主任利用念写所得的未来图像与视觉误导压制麦野；最后泷壶带来的体晶使原子崩坏失控，打乱既定预测。麦野随后亲手结束与原主任的交锋，蜂蜜女王瓦解；玩家可改变这个结局。

== 3. 玩家可改写的部分 ==
可核对受害者、保护开发资料、改变撤离路径、提早发现埋伏或阻止原主任舍弃同伴。对研究者的拘束、救治或反击结果可变；已夺回资料不必因默认顺序再次丢失，未知数据不凭空全部销毁。

== 4. 节点推进表 ==
使用ITEM-02完整节点ID；每轮最多推进一个主要节点。外围追查、两次交锋与战后照护不能同轮全数完成。

ITEM-02-01 婚姻诈骗之外
进入条件：玩家选择本卷，或四人已能共同接取新的委托。
场景目标：核对蜂蜜女王造成的损害，将普通诈骗与能力开发机密外流联系起来。
可见角色：ITEM四人、受害开发人员或委托联系人。
玩家行动：整理失窃资料范围、询问接触过程、协助设定追查目标。
结果：麦野决定应对任务，调查对象不再只是网络上的一张美人照片。
下一节点：ITEM-02-02。

ITEM-02-02 基地遇袭
进入条件：ITEM-02-01完成，敌人对基地发动袭击。
场景目标：阻止敌方连续攻击把四人赶进预设路线。
可见角色：ITEM四人、袭击者及追踪力量。
玩家行动：示警、掩护、检查撤离交通、改变路线或留证反查。
结果：四人脱离最初火力，却发现对方掌握她们的行动特征；DNA相关线索按实际损失记录。
下一节点：ITEM-02-03。

ITEM-02-03 赌场与球场外线
进入条件：ITEM-02-02完成，队伍有机会循袭击网络反查。
场景目标：从医院获取消息，追到非法赌场的外围组织，再核对球场中蜜蚁爱愉这一条线。
可见角色：ITEM四人、赌场外围人员；转到球场接触时才出现蜜蚁。
玩家行动：比对受害记录、潜入赌场、保护情报来源或询问蜜蚁掌握的信息。
结果：外围调查将目标收窄到原子崩坏研究关系；球场会面不等于蜜蚁的生物黑客或NT11整段经历在此重演。
下一节点：ITEM-02-04。

ITEM-02-04 研究所的反袭
进入条件：ITEM-02-03完成，双方在原子崩坏研究所相关地点交锋。
场景目标：在第十四学区原子崩坏研究所等待对手，应对太刀魚メアリー的压制。
可见角色：ITEM四人、太刀魚メアリー；原主任可能在另一条资料线上活动。
玩家行动：分担防御、配合泷壶寻找突破、救援倒下者或改变战场。
结果：默认泷壶介入使太刀魚メアリー败下阵来；这次异常发挥不能保证能随意再现，原主任仍在夺取余下Angelica资料。
下一节点：ITEM-02-05。

ITEM-02-05 被舍弃的同伴
进入条件：ITEM-02-04完成，原主任的资料行动与对同伴的处置显露。
场景目标：面对她为计划舍弃他人的转折，保护仍能救助的人并追上资料去向。
可见角色：原主任、倒下的协力者、能继续行动的ITEM成员。
玩家行动：救人、阻止进一步伤害、保住证词或追踪已被带走的资料。
结果：默认原主任舍弃倒下的太刀魚メアリー，并以念写相关手段使芙兰达、绢旗陷入危险；麦野必须救回队友，而非只追回资料。救助已奏效时不强制重置伤亡。
下一节点：ITEM-02-06。

ITEM-02-06 预判之外的反击
进入条件：ITEM-02-05完成，麦野与原主任正面交锋。
场景目标：识破表面的瞬移假象后，仍须面对原主任真正依靠的念写预测与视觉误导。
可见角色：麦野、鮎魚女キャロライン、强撑着支援的泷壶及玩家。
玩家行动：寻找预测未涵盖的变化、帮助泷壶接近、保护受影响的队友，或改变原主任的拘束与救治结果。
结果：默认泷壶带来的体晶令麦野失控的攻击突破预测，重创原主任；麦野没有把这当成意外了事，而是继续对决，原主任死亡。不得将这次支援与研究所对太刀魚之战合并。
下一节点：ITEM-02-07。

ITEM-02-07 蜂蜜女王瓦解之后
进入条件：ITEM-02-06完成，组织已失去本次行动的指挥与压制能力。
场景目标：确认队员照护、夺回资料与尚未追回的部分，结束蜂蜜女王任务。
可见角色：ITEM四人、负责交接的联系人及玩家保下的相关人。
玩家行动：清点人员、安排治疗、交接证据、保留对余下资料的追查。
结果：默认蜂蜜女王组织瓦解，四人接受照护、探望同伴，并在后续夏日祭恢复短暂日常；不自动宣告一切研究数据或全城同类组织清零。
下一节点：无；夏末新任务另选ITEM-03-01。

== 5. 分支和偏离规则 ==
提前保住资料、救下协力者、拘束原主任或避开原有追击路线均允许。社区相对顺序服务于默认走向，不迫使已解决的问题再次出现；改写留在本包，不把蜂蜜女王移交给独立心理掌握漫画充数。

== 6. 换篇条件 ==
ITEM-02-07完成、玩家明确离开／跳过／换锚点，或本次争夺提前解决，才换篇。记录状态、原因、偏移与后继首节点；未追回的资料可以留作线索，但不强制占据下一篇锚点。

== 7. 防剧透边界 ==
不透露Y年暗部大战中四人的命运，不把学校选举、上蜂往事与本案混为一条精神能力事件。Angelica只按当时实际发现的研究信息呈现，不能借名提前揭示后续世界观。

== 9. 收束结果 ==
- ITEM-02-END-A 默认收束：泷壶以体晶造成的变故打破预测，麦野杀死原主任；蜂蜜女王瓦解，四人治疗、探望并回到夏日祭日常，未追回资料仍按实际情况保留。
- ITEM-02-END-B 非致命改写：玩家保下关键人物，夺回或封存已实际掌握的资料，留下可追责的证词。
- ITEM-02-END-C 提前拆局：DNA或研究资料未按敌人计划流失，后半争夺依新条件收束，不强行复刻失窃。
- ITEM-02-END-D 暂时退出：保留已知损失与救援事实，不以失败惩罚或反噬强迫参战。
