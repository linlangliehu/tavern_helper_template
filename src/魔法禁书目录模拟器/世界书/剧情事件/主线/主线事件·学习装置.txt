【事件包：学习装置篇】
事件包ID：LEARNING-DEVICE
所属阶段：阶段1·旧约·禁书降临季
时间窗口：7月下旬-8月初（禁书降临篇时间带内）
别名与触发词：学习装置 / 能力开发课程 / 个人现实 / 能力开发与个人现实 / LEARNING-DEVICE

== 1. 核心定位 ==
本篇是阶段1的科学侧研究型主线事件：一台能大幅加速能力开发、甚至试探性改写"个人现实"的原型学习装置流出研究室，在学园都市地下市场与各研究势力之间引发争夺。事件主题是"捷径的代价"——能力开发的本质是什么，跳过积累直接拿到力量的人会变成什么。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段1剧情中因黑市情报、研究室委托、同学异变而接触。玩家立场自由：追缴、抢夺、保护持有者、研究剖析、或自己试用（卡面规则允许，无反噬无代价）。

== 2. 不可丢失的核心事实 ==
- 学园都市的能力开发以"个人现实"（Personal Reality）为核心：能力者在脑内建立自己的专属观测世界，并通过演算将其叠加于现实。
- "学习装置"是某研究机构的原型设备：以高密度演算辅导使用者加速建立/强化个人现实，对低等级能力者的短期增幅显著。
- 装置的副作用是"现实锚定不稳"：跳过积累建立的个人现实脆弱、易受冲击，重度使用者的能力会间歇性紊乱（表现为能力失准、感官错位，不作为惩罚判定）。
- 开发该装置的研究室因伦理审查被叫停，但设备与数据流落在外——这是事件的起点。
- 学园都市官方表面上否认该装置存在，暗地里多个势力想要回收：研究机构、暗部外围、黑市买家。
- 装置不能凭空创造能力者：对真正无能力者的效果极其有限，这一点与"原石"（天生能力）形成对照。

== 3. 玩家可改写的部分 ==
- 装置的最终归属：销毁、封存、回归官方、留在玩家手中、或流向第三方，全部合法。
- 重度使用者（被装置改速成的能力者）的命运：救治、警戒、收留、或任其漂泊。
- 研究室黑幕的公开程度：举报、交易、深挖、或按下不表。
- 玩家可试用装置——卡面规则下无反噬无代价，但装置数据会如实记录玩家的个人现实特征，成为后续剧情的伏笔素材（按世界线记录处理）。
- 玩家自身能力可自由发挥（含跨体系混用），允许以原创方式改变事件走向。

== 4. 节点推进表 ==
节点ID格式：LEARNING-DEVICE-{NN}（必须使用完整ID，禁止简写如LD-01）。每轮最多推进一个主要节点。

LEARNING-DEVICE-01 异变的同学
进入条件：进入本篇（锚点选定或阶段1剧情触发）。
场景目标：玩家身边出现能力突飞猛进又行为异常的人（同学/友人/传闻人物）。
可见角色：异变者、其身边人、（可选）研究室相关者。
玩家行动：关心、追问、调查、或忽视。
结果：玩家接触"速成能力"现象；线索指向学习装置。
下一节点：LEARNING-DEVICE-02。

LEARNING-DEVICE-02 黑市流言
进入条件：玩家追查线索。
场景目标：地下市场流出"能力速成"装置的传言与试用邀约。
可见角色：黑市掮客、试用者、竞争买家。
玩家行动：卧底接触、直接抢购、举报、或放线钓鱼。
结果：玩家获得装置的下落或实物接触机会。
下一节点：LEARNING-DEVICE-03。

LEARNING-DEVICE-03 装置在手
进入条件：玩家取得装置或锁定其位置。
场景目标：确认装置的功能与副作用；研究室背景浮出水面。
可见角色：（可选）原研究室成员、装置使用者。
玩家行动：试用、检测、拆解、转手、或寻找出处。
结果：玩家掌握装置全貌；成为多方关注的目标。
下一节点：LEARNING-DEVICE-04。

LEARNING-DEVICE-04 研究室的影子
进入条件：装置动向公开或玩家深挖出处。
场景目标：原研究室势力与暗部外围开始回收行动。
可见角色：回收执行者、研究室主管、（可选）警备员。
玩家行动：周旋、对抗、交易、借力打力。
结果：争夺升级；玩家需要选定装置的最终处置方向。
下一节点：LEARNING-DEVICE-05。

LEARNING-DEVICE-05 速成者的崩坏
进入条件：重度使用者持续使用装置。
场景目标：装置副作用大规模显现——多名速成者能力紊乱、个人现实濒临崩解。
可见角色：速成者们、医疗机构人员、装置相关者。
玩家行动：救治、稳定其个人现实（可用原创方式）、追责研究室、或收集证据。
结果：事件从争夺转向责任；装置的危害成为公开事实。
下一节点：LEARNING-DEVICE-06。

LEARNING-DEVICE-06 个人现实之问
进入条件：玩家掌握装置核心数据或与研究室正面接触。
场景目标：研究室主管摊牌——装置的真正目标是"批量复制强者"的失败尝试。
可见角色：研究室主管、（可选）官方代表。
玩家行动：辩论、揭发、合作改良、或拒绝一切合作。
结果：装置的定位由玩家的立场决定：武器、教材、还是废铁。
下一节点：LEARNING-DEVICE-07。

LEARNING-DEVICE-07 收束行动
进入条件：玩家已决定本篇的最终介入方式。
场景目标：执行玩家的收束方案（销毁/封存/上缴/保留/公开听证等）。
可见角色：按方案决定。
玩家行动：自由发挥，允许完全原创方案；AI 按玩家能力与准备合理演绎结果，不判定失败收场。
结果：装置去向与研究室处置确定。
下一节点：LEARNING-DEVICE-08。

LEARNING-DEVICE-08 篇章收束
进入条件：LEARNING-DEVICE-07 完成。
场景目标：事件结算——装置去向、速成者安置、研究室后果、世界线记录。
可见角色：本篇主要角色（余波互动）。
玩家行动：处理后续安排；选择下一走向（绝对能力者进化篇 / 日常休整 / 自主跳转）。
结果：阶段状态更新，换篇入口开启。
下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变接触方式、立场或装置处置态度时，保留当前锚点切分支推进。
- 核心结果改写：玩家提前销毁装置、让装置流向暗部、或公开研究室黑幕时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按背景因果自行发展（速成者崩坏迟早发生），不强制玩家参与。
- 玩家试用装置的记录属世界线事实，后续篇章可引用，但不构成本篇强制走向。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. LEARNING-DEVICE-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过事件窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：绝对能力者进化实验、御坂妹妹计划、AIM扩散力场理论深层、学园都市最高层意图。
- 个人现实的完整理论只按"能力开发常识层"呈现，不上升到世界观级真相。
- 学习装置与后续篇章的任何关联（如复制体技术）不得在本篇提前启动。
- 魔法侧势力不得作为本篇推动力；禁书降临篇角色至多合理客串。

== 8. 状态写回契约 ==
- 主线进度：当前锚点=学习装置篇；当前节点=LEARNING-DEVICE-{NN}；节点完成时 replace 已完成节点/可触发节点数组；偏移事实写入 正史锚点.玩家偏移。
- 任务追踪：装置追缴、救治委托等写入任务追踪（任务类型标明"主线·学习装置篇"），完成或失效时移除。
- NPC关系：速成者、研究室主管、掮客等按实际互动建立与更新；能力字段只写玩家已目睹的内容。
- 世界线记录：装置去向、玩家是否试用过装置、研究室处置改写必须写入。
- 支线任务可并行，但不覆盖本篇的当前锚点与当前节点。

== 9. 收束结果 ==
- LD-END-A 原著近似收束：装置被官方低调回收，黑幕沉入档案。
- LD-END-B 彻底销毁：玩家亲手终结装置，速成者问题遗留为后续伏笔。
- LD-END-C 公开听证：玩家推动黑幕公开，能力开发伦理成为都市话题。
- LD-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行发展并延后。
- LD-END-E 完全原创收束：玩家以原创方案（含跨体系能力自由发挥）改写整场事件，世界线记录如实反映。
以上所有收束均不使用死亡、失败收场、风险值或反噬机制；遗憾与代价只作为剧情事实呈现，不作为对玩家的惩罚判定。
