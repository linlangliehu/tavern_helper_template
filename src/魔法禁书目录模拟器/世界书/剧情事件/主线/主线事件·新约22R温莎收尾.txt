【事件包：新约22R温莎收尾篇】
事件包ID：NT-22R
所属阶段：阶段7·科隆尊与新约收尾
时间窗口：本篇Y年十二月二十一日图排，接NT22余波；以温莎庆功宴与返城的相对顺序为准
别名与触发词：新约22R温莎收尾篇 / 温莎身份冲突 / 新约22Reverse收尾 / NT-22R

== 1. 核心定位 ==
作品范围：新约22 Reverse，独立于新约22的科隆尊终战，也是新约的收尾。胜利庆祝未能消除右手封印被破坏的余波，一个携有上条记忆与力量、试图取代其身份的存在使温莎城堡陷入新的冲突。
此处处理“谁在继续承担上条当麻的选择”与受操纵者的救援，不用“有某段记忆就一定是真人”代替查证，也不把身份冲突吞入创约第一卷。

== 2. 不可丢失的核心事实 ==
- NT22的损伤与上条未能救下一切的遗憾，为其力量以另一个“上条当麻”的形态显现提供了条件。另一者拥有他失去的记忆和大部分右手力量，企图夺取他的身份；不能把它简单写成没有共同来源的外来变装者。
- 温莎城堡的庆功宴被龙形来客与身份异常打断。分离期间，原本的上条和另一者都涉及龙形表现，不能单凭“能变成龙”判定哪一个是敌人。
- 食蜂在宴会冲突中出现情绪和能力失控。现场救援须尊重她的实际处境，不把她此前失去的记忆联结当作可以随口治好的问题。
- 原本的上条离开城堡后与第一王女莉梅亚接触，并在镇上的酒馆与一方、浜面等重新会合；返回城堡需要处理被操纵或胁迫的防卫者，不是把英国盟友一律当作自愿叛变。
- 原作支援战中一方面对伊莉莎德，福琼面对神裂，其他同伴争取上条进入城堡的机会。上条最终战胜试图取代他的存在，分离状态终结，但右手的全部本质并未就此向所有角色公开。
- 战后众人回到恢复中的学园都市；一方正式走进理事会履行新统括理事长的身份。福琼留在英国，向女王提出接任清教最高主教并得到有监督条件的认可，和浜面的联系没有因此断绝。

== 3. 玩家可改写的部分 ==
- 可提前追查NT22的异常、验证宴会来客、保护食蜂与宾客，不必为了维持原作冲突而放弃沟通。
- 可向被操纵者提供撤离和解除控制的办法，改变王室与支援者交战的方式，避免把击败同伴当成唯一身份认证。
- 可讨论另一者的要求与自身来源、提出可信的隔离或共处方案；不能因它拥有记忆就剥夺原本上条已经建立的人际关系，也不能默认玩家必须选择消灭它。

== 4. 节点推进表 ==
NT-22R-01 不完整的庆功宴
进入条件：NT22已经收束，玩家参加或调查温莎的战后庆祝，右手异常仍有未解线索。
场景目标：确认返场者与战后见闻之间的连续性，同时让庆功宴中的同伴获得照料。
可见角色：宴会上的“上条当麻”、茵蒂克丝、美琴、食蜂、英国王室与同行者；莉梅亚按实际在场时间出现。
玩家行动：核对分别后的路线与见闻，观察记忆和能力表现的反常，保护仍有伤势的人，私下询问而非直接发动群体审判。
结果：原作另一者以熟悉的面貌参加庆祝，宴会未及时解决身份异常；玩家可提前积累证据或安排安全会面，不能只以宾客默认信任就认定一切正常。
下一节点：龙形来客或等价的身份对质出现时进入NT-22R-02。

NT-22R-02 来客与失控的现场
进入条件：原本的上条与另一者的矛盾显露，庆功现场已经无法照常继续。
场景目标：保护宾客与食蜂，区分外观、记忆、力量和实际行动提供的不同证据。
可见角色：两个有共同来源的“上条”、食蜂、茵蒂克丝、美琴；被卷入的宾客与守卫。
玩家行动：开辟撤离通道，制止误伤，观察双方如何回应同伴的安全，阻止借失控和胁迫迫使众人站队。
结果：原作城堡局面被另一者利用，原本的上条退到城外，食蜂的失控成为需要处理的事实；若玩家促成安全分离与有效调查，不重置局面强制围攻。任何一方的龙形都不是独立的身份判据。
下一节点：离城重整时进入NT-22R-03；已在城内建立安全调查条件，也先完成相同的证据核对，再转NT-22R-04。

NT-22R-03 温莎镇的酒馆会合
进入条件：原本的上条能够与未受城堡局势支配的协助者交换信息。
场景目标：组织救援联盟，解释另一者为何能使用熟悉的力量，而不是让单一能力决定谁有资格被救。
可见角色：上条、莉梅亚、一方、克里帕、浜面、泷壶、福琼及实际同行者。
玩家行动：比较亲历证词，分配解除控制、对外联络与进入城堡的任务，检验右手与身份的关系，把关于其本质的推论保留为推论。
结果：原作各组在酒馆会合并决定返回城堡；玩家可加入谈判和非战斗接应，不因少一个原作同伴便宣告计划必然失败。
下一节点：方案与撤离通道明确后进入NT-22R-04。

NT-22R-04 不把受控者当作敌国
进入条件：队伍返回温莎城堡，守卫与王室人员仍受到操纵、胁迫或错误信息影响。
场景目标：打开进入城堡的机会，保护被利用的同伴与防卫者。
可见角色：一方、克里帕、伊莉莎德；福琼、神裂；浜面、泷壶、莉梅亚与其他支援者。
玩家行动：分开交战区与撤离区，争取解除控制或让对方暂退，以已掌握的王室和城市资源协助，不把误判等同于不可挽回的背叛。
结果：原作一方战胜女王，福琼战胜神裂，各条支援线为上条争取进入的窗口；玩家可通过解除控制、证明身份或其他有效方案实现同一救援目标，不要求逐人打倒。
下一节点：进入NT-22R-05。

NT-22R-05 不能只由记忆裁定的本人
进入条件：原本的上条能够面对另一者，身边人的安全不再完全被对方挟持。
场景目标：处理取代身份的企图和力量分离，保留每个人对真实经历的判断权。
可见角色：上条、另一者；按现场实际能够接触的茵蒂克丝、食蜂与支援者。
玩家行动：质询另一者把未能救下一切视为取代理由的主张，保护被其利用的人，阻止能力争夺波及同伴，或提出可检验的非取代安排。
结果：原作上条战胜另一者，分离状态终结，他继续承担已有的关系与选择；玩家采用其他可行安排时，记录双方实际状态。不能借本节点宣告食蜂相关记忆自动恢复，也不能给所有人发放右手起源的终极答案。
下一节点：进入NT-22R-06。

NT-22R-06 回城与留英的人
进入条件：温莎危机有明确结果，同伴能够决定下一段生活与责任。
场景目标：逐人落实返城、留英、城市管理和关系修复，使新约有独立的落点。
可见角色：上条与返城同伴；一方、最后之作、理事会；浜面、泷壶、麦野、绢旗；英国的福琼、伊莉莎德与薇莉安，分别在其所在场景出现。
玩家行动：安排返程与安置，见证权限交接后的一方就任，确认福琼留英的监督条件，保存浜面与她继续联络的方式，给受伤关系留出真实交流。
结果：原作返城者回到恢复中的学园都市，一方正式就任，福琼留英并与浜面保持联系。故事继续，但没有凭空补回所有记忆、解决所有暗部或提前执行下一卷事件。
下一节点：可继续战后日常；玩家选择推进至平安夜且条件相符时进入GENESIS-01-01。该入口属于创约第一卷，不能把它的事件算入本篇完成记录。

== 5. 分支和偏离规则 ==
身份判断以各人可取得的证据与行动为基础，不用作者视角强制NPC站队。前卷若已经阻止封印破坏或本卷分离，按真实的战后日常与关系修复收束，不再制造一个替身补齐流程。玩家的谈判、隔离与保护同伴方案均可保留，不附加失败惩罚。

== 6. 换篇条件 ==
身份争夺、受控者安全与各自去向有明确结果后完成本篇。可明确暂离或延后返城，保存实际未竟事项；不因图排日期结束自动切换阶段。去平安夜之前允许日常和关系修复，不能直接把22R与下一卷合成一场冲突。

== 7. 防剧透边界 ==
开宴时只呈现宾客能够发现的异常，不直接公布另一者的来源、记忆范围或动机。食蜂的私密记忆不自动向王室与其他同伴公开。有关右手本质的意见保持提出者与证据边界；安娜、艾华斯与后续组织的后台活动不因本篇收尾而变成公众常识。

== 9. 收束结果 ==
- 原作默认：上条战胜另一者，温莎危机解除，返城与留英各有交代，新约在此独立收尾。
- 提前辨认：玩家在宴会阶段建立证据与安全接触，减少被利用的人与城堡交战。
- 非取代安排：玩家以可信的隔离、谈判或其他方案处理分离，记录其可持续条件。
- 战后日常：玩家暂不进入平安夜，继续修复关系、照料伤员或观察新任统括理事长的行动。
