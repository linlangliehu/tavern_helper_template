【事件包：越狱篇】
事件包ID：JAILBREAK
所属阶段：阶段5·十月中旬的科学侧事件
年层：Y（当前年）
时间窗口：十月中旬，图排另有约10月20日后续；旧项目10月10日—15日仅是精选入口，不是漫画全篇已证起讫，也不把全篇硬压在第三次世界大战之前。
原作范围：超炮漫画第14—16卷；不是超炮SS2，更不是禁书SS2。
别名与触发词：越狱篇 / 獄門開錠 / 脱狱试用赛 / JAILBREAK / JAILBREAK-01

== 1. 核心定位 ==
从巨大白蛇的都市传说进入第二少年院试用赛。初春成功脱出夺冠，却被囚犯调包与真正越狱卷入另一场危机：春暖嬉美一方绑架初春，要求她建立世界级网络、向全球公开能力开发技术。玩家可参加试用赛、保护冠军、追查院方漏洞或支援救人。
本包推进到初春假意配合、寻找逃路与同伴营救的已知冲突；后续反制、龙的最终去向及具体判罚不预写为必经事实。

== 2. 不可丢失的核心事实 ==
- 第二少年院的试用赛以防卫系统与参赛者较量为表层。美琴、黑子、初春、佐天、近江手里、屍食部队等各自行动；不能把参赛者全写成同一阵营。
- 默认初春独自脱出夺冠，后来捐出奖金。囚犯角色被调包，真正的囚犯趁势逃出；冠军不是主动帮助越狱的共犯。
- 春暖嬉美与青星铃兰有孤儿院旧事。嬉美受到能力实验伤害，书库记录为Level 0；关于黑洞或第九位的研究可能性，不等于她已经被确认是Level 5。
- 青星铃兰是第二少年院警备主任，参与把饭塚与嬉美调包；不要沿用“院长助理青星铃澜”的错误身份。
- 鳄河雷斧使用Level 4重力圆环，存在实验副作用；钓钟茶寮是使用AIM Watcher的甲贺忍者，不是收存篮球大小物件的空间能力者。
- 初春被绑后受到构建世界级网络的胁迫，表面合作而暗中找逃路。美琴迎战雷斧，黑子对付钓钟，佐天按黑子的安排潜入；嬉美持有危险的龙之力。
- 暗部大战的余波可以成为环境，但没有“暗部已经整体解体才举办试用赛”的前提。第三次世界大战也不能改写成十一月初才爆发。

== 3. 玩家可改写的部分 ==
玩家可改变比赛胜负、揭穿调包、提前防住绑架、协助初春拖延或选择技术与谈判方案。初春夺冠、绑架与营救是无人干预时的推进方向，不是强制玩家受害的任务脚本。
若玩家已阻止绑架，后续改为查明网络计划与保障证人安全，不重新制造一次绑架补剧情。救人、公开实验罪证和是否公开能力技术是不同决定，不自动捆绑。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；沿用JAILBREAK-01至JAILBREAK-06。

JAILBREAK-01 试用赛开幕
进入条件：进入十月中旬相关窗口，接到试用赛消息或调查巨大白蛇传闻。
场景目标：弄清第二少年院规则、防卫设施与参赛者分工。
可见角色：美琴、黑子、初春、佐天、近江手里及在场参赛队伍。
玩家行动：报名、观察AIM干扰设施、比较路线、以工作人员或调查者身份核对安全安排。
结果：掌握比赛入口与退出方式；玩家选择的身份决定接近权限，不凭知道篇名获知内应。
下一节点：JAILBREAK-02。

JAILBREAK-02 冠军与圈套
进入条件：比赛产生突破口或玩家正在核对囚犯角色。
场景目标：完成试用赛并发现“角色扮演”与真实收监记录的差异。
可见角色：初春、美琴一行、青星铃兰及院方人员。
玩家行动：支援脱出、争取冠军、保存调包记录、通知可信警备人员。
结果：默认初春独自脱出夺冠并捐出奖金；调包导致真正越狱，比赛成功不代表设施安全。
下一节点：JAILBREAK-03；提前揭破圈套仍追查其目标，不强制恢复绑架。

JAILBREAK-03 初春被绑
进入条件：越狱者锁定初春，或玩家已截获绑架计划。
场景目标：找出网络计划与人质位置，区分营救和技术泄露两项风险。
可见角色：初春、春暖嬉美；外线可联系黑子与其他同伴。
玩家行动：护送初春、追踪转移、维持隐蔽通信、从囚犯与研究记录核对动机。
结果：默认初春遭绑架，嬉美要她把能力开发技术送向全球；若绑架被阻止，以截获计划替代人质场面。
下一节点：JAILBREAK-04。

JAILBREAK-04 潜入与接应
进入条件：得到可行动的救援线索，或需要进入院内收集调包证据。
场景目标：为初春的逃路接上外部接应，避免各线互相暴露。
可见角色：佐天、黑子、美琴、鳄河雷斧、钓钟茶寮，按各自现场分别出现。
玩家行动：跟随佐天潜入、支援黑子与美琴、掩护撤离、传递经过核实的位置。
结果：默认形成佐天潜入、黑子对钓钟、美琴对雷斧的并行战线；不预定佐天必遭重伤。
下一节点：JAILBREAK-05。

JAILBREAK-05 假意配合与反制
进入条件：初春仍受胁迫，或玩家已取得网络计划与现场设施的线索。
场景目标：拖延危险网络的构建，在不暴露逃路的前提下保护人员。
可见角色：初春、嬉美；与外线建立联系后可接入佐天及救援同伴。
玩家行动：审查网络需求、掩护初春的假意合作、寻找脱身时机、阻断已确认的危险连接。
结果：默认初春不真心接受嬉美计划，而是寻找逃路；反制效果按实际行动落地，不凭节点标题直接赋予新能力或宣布龙被封印。
下一节点：JAILBREAK-06。

JAILBREAK-06 狱门内外的交接
进入条件：逃路、保护方案或暂停救援的决定已经形成。
场景目标：交接人质安全、实验与调包证据、尚在进行的战斗。
可见角色：已与玩家会合的初春和同伴；其他人物按当时位置处理。
玩家行动：护送、留下接应、整理证词、继续追查龙之力或明确暂时撤出。
结果：默认停在同伴实施营救、初春寻求脱身的冲突交接点；不自动宣告越狱全案结束、嬉美再收监或龙已有确定归宿。实际完成的玩家营救可成为本线收束。
下一节点：JB-END-A／JB-END-B／JB-END-C／JB-END-D。

== 5. 偏离与改写 ==
只把已发生的救援、伤势、证据与关系变化写成事实。玩家避免了冲突就沿用新局面，不安排惩罚性补战；尚未亲见的觉醒机制、最终判罚与龙的管理方式不拿旧传闻补全。

== 6. 换篇条件 ==
玩家完成阶段性交接、主动退出或另选当前时间可进入的事件即可换篇。保留未救人员与未处理风险，不以跨篇为由自动治愈或释放人物；本篇不是进入三战的硬门槛。

== 7. 防剧透边界 ==
试用赛入口不直接揭露内应和网络计划；未确认嬉美的实验记录前，不把研究假说当能力等级。龙之力只按现场表现叙述，不跨篇解释全部来历。

== 8. 状态写回契约 ==
作为当前主线时，沿用主线进度.正史锚点.当前锚点、主线进度.阶段序号、主线进度.当前阶段、主线进度.阶段状态、主线进度.当前节点；阶段序号为5。主线进度.已完成节点与主线进度.可触发节点以整数组replace更新，不写数组子路径。
将默认方向、玩家差异分别记入主线进度.正史锚点.默认走向与主线进度.正史锚点.玩家偏移；以主线进度.下一步推进提示保留接应与调查方向。任务追踪、NPC关系与世界线记录只追加实际发生的信息，不新增MVU字段；只是旁支引用时不抢主线锚点。

== 9. 收束结果 ==
- JB-END-A 默认阶段收束：比赛与调包已揭开，初春假意合作并找逃路，同伴展开营救；后续胜负与处置仍保留。
- JB-END-B 玩家主导：采用玩家实际完成的防绑架、救援或技术阻断，不伪称对应原作既定终局。
- JB-END-C 局部交接：已救人员先交接，未明的实验与龙之力继续作为任务线索，不算全案已结。
- JB-END-D 玩家退出：保留已发生事实与风险，转回所选事件；不惩罚、不强制回正。
