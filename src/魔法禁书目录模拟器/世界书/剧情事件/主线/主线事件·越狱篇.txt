【事件包：越狱篇】
事件包ID：JAILBREAK
所属阶段：阶段5前段·暗部大战之后、第三次世界大战爆发前（10月中下旬）
时间窗口：10月10日—10月15日（紧接独立纪念日的混乱余波，第二少年院"脱狱试用赛"开幕）
别名与触发词：越狱篇 / 脱狱试用赛 / 獄門開錠 / Jailbreaker / 第二少年院 / 春暖嬉美 / 青星铃澜 / 鳄河雷斧 / 钓钟茶寮 / 白绢仄火 / 天使之龙 / 龙王之颚 / JAILBREAK

== 1. 核心定位 ==
学园都市新设"第二少年院"（收容超能力犯罪者的最新锐设施）开幕即举办"脱狱试用赛"：最新锐防卫系统+AIM干扰器重重设防，突破到"囚犯室"者赏金十亿日元。美琴四人组、各路势力（风纪委员、暗部余党、忍者、屍食部队等）各怀目的参加——而这是图穷匕见的圈套：真正的囚犯春暖嬉美借试用赛脱狱，一党夺院、绑架试用赛冠军初春饰利，胁迫她建世界级网络公开学园都市最高机密"能力开发技术"。御坂美琴迎战宿着"天使之龙"的嬉美败北，佐天泪子潜入救友挡下龙翼重伤，初春在绝境中觉醒、以AIM干扰器反制龙之力——本篇是主角团三人组（美琴/佐天/初春）各自的战斗与羁绊高光。
玩家进入方式：开局锚点直接选在本篇；或以参赛者身份加入试用赛；或受风纪委员/警备员委托调查少年院异常；或在美琴线中作为援军/ independently行动。

== 2. 不可丢失的核心事实 ==
- 脱狱试用赛：第二少年院（院长京极亮太，助理青星铃澜系内应）悬赏十亿日元的公开活动；参赛者需穿过最新锐防卫系统（含AIM干扰器，使超能力者大部分失效）突破到囚犯室；美琴、黑子、初春、佐天四人组参赛，警策看取、婚后光子、屍食部队、甲贺忍者等势力同场。结局：初春黑进院方系统"释放囚人役"夺冠，但试用赛被利用——真囚人春暖嬉美一党（加原本四人成党）借机脱狱并夺院。
- 春暖嬉美：第二少年院042号室收监女囚，书库记录为Level 0；右手宿着上条当麻右臂同源"龙王之颚"的天使型龙（可无视反射与电磁，击退过美琴）；能力可产生黑洞级能量并使役龙（曾申请"第九位超能力者"），本质与整体论/超常现象系能力相关；另有暗黑五月计划受验体关联背景。一党成员：青星铃澜（院内内应、院长助理）、鳄河雷斧（白丝蛇纹样能力者，败于美琴）、钓钟茶寮（空间保存系，可保存篮球以下物体，败于黑子）、白绢仄火。
- 真正目的：以初春（试用赛冠军、天才黑客）为人质+工具，令其构筑世界规模网络，向全世界公开学园都市秘匿的"能力开发技术"——足以令世界混乱的复仇计划；背后有她们孤儿院时期的黑暗往事（与"暗黑五月计划"受验体实验相关的创伤）。
- 初春觉醒线：初春被囚后表面顺从暗中脱身，伪装看守；佐天借警备员制服潜入营救，屋上先回接应，逃亡途中佐天为庇护初春硬接龙的羽击重伤垂危；绝境中初春揭开嬉美能力与龙的关系，掌握AIM干扰器、控制自身AIM扩散力场，现场编出"打消龙之力"的反制能力——觉醒完成。
- 美琴线：追车被龙击退→击败鳄河雷斧→黑子击败钓钟茶寮→再战嬉美，以雷击+地下水道等环境战术周旋→最终与初春反制之力合流压制嬉美；龙之力失控边缘被平息。
- 结局重力线：嬉美一党再度收监，龙之力被封印管理；少年院防卫体系修复，院长拒绝对"以受验体换贷款"的收买；美琴四人组在病院重逢疗伤，日常回归。
- 与相邻篇章的时间关系：本篇在暗部大战（10/9）余波之后、三战爆发（11月初）之前；暗部解体导致的警备力真空是少年院敢于办"试用赛"的背景之一。

== 3. 玩家可改写的部分 ==
- 试用赛的胜负与冠军归属：玩家可亲自夺冠（替代初春）或协助初春。
- 初春是否被绑架：玩家可提前预警、挫败绑架，或改写绑架后的营救路线。
- 佐天的重伤：玩家可在场挡下龙翼或提供防御支援——受伤并非必然。
- 美琴vs嬉美的过程与结局：可协助美琴、独立压制嬉美、或促成不流血收场。
- 嬉美的终局：收监（重力线）、玩家促成自首换宽大、或玩家原创和解方案。
- "能力开发技术公开"危机：可被玩家以技术、政治、舆论手段提前化解。

节点ID格式：JAILBREAK-{NN}。每轮最多推进一个主要节点。

完成：玩家完成试用赛前半段（突破外围防线或建立情报网）。

内容：初春黑入系统夺冠；真囚人一党借乱脱狱夺院；院内内应青星铃澜发难；试用赛变质的迹象浮现。
完成：玩家确认"真脱狱"事实与少年院失守。
下一节点：03。

JAILBREAK-03 初春被绑
触发：02完成。
内容：初春被绑架（或玩家改写为预警成功/营救成功）；美琴追击遭龙击退；鳄河雷斧、钓钟茶寮各自被美琴、黑子击破；"能力开发技术公开"的威胁浮出水面。
完成：绑架事实与嬉美的真正目的曝光（或玩家改写线确立）。
下一节点：04。

JAILBREAK-04 潜入与重伤
触发：03完成。
内容：佐天伪装看守潜入；初春自主脱身、两人会合；逃亡中嬉美追至——佐天为庇护初春硬接龙翼重伤（玩家可在场改写）；屋上对峙。

下一节点：05。

JAILBREAK-05 觉醒
触发：04完成。
内容：初春的AIM觉醒——掌握AIM干扰器、控制自身扩散力场、编出"打消龙之力"的反制；与美琴的反击合流；嬉美的能力与龙失控边缘。
完成：嬉美压制成功（或玩家改写线收束）。
下一节点：06。

JAILBREAK-06 狱门再锁
触发：05完成。
内容：嬉美一党收监、龙封印管理；院长拒绝"受验体换贷款"收买；初春觉醒后的迷茫与成长、佐天病房、美琴的守约；少年院事件落幕，都市进入三战前夜。
完成：本篇收束，按第9章定收束结果。

== 5. 偏离与改写 ==
- 节点是"原著重力线"，玩家可任意偏离：玩成纯试用赛竞技、监狱经营、越狱教学、警备员办案剧皆可，只要不覆盖核心事实（试用赛被利用、嬉美一党脱狱、能力开发技术公开危机）。
- 核心结果改写：初春未被绑、佐天未重伤、嬉美被玩家收服、技术公开危机解除，均合法，以玩家偏移事实记录，不得静默回滚。
- 玩家明确离开时按第9章 JB-END-D 收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：龙王之颚与上条当麻幻肢/ angels 体系的深层原理、龙的个体名与完整等级、暗黑五月计划的实验细节与受验体名单、第二少年院的深层构造与"技术公开"背后的理事会派系。
- 嬉美的龙只呈现"宿着+使役+无视反射"表现层；不揭示其与幻想杀手共鸣的机制。
- 初春觉醒只到"AIM力场自控+反制龙"层级，不升级为 Level 上限变更或"第九位"认定落实。
- 魔法侧势力不得作为本篇推动力；美琴的作战限于科学侧手段。

== 9. 收束结果 ==
- JB-END-A 原著近似收束：试用赛变圈套、绑架、觉醒、压制、收监的完整重力线。
- JB-END-B 玩家亲手终结：玩家主导收束，绑架/重伤被避免或改写，嬉美按玩家方案处置。
- JB-END-C 谈判收场：玩家促成嬉美与院方/当局的交易（自首换条件/真相听证），龙封印管理+受验体创伤被正视。
- JB-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
以上收束均不以玩家死亡或"失败判定"告终；佐天重伤等NPC原著向桥段只作为剧情事实呈现，不作为对玩家的惩罚判定。
