【事件包：心理掌握漫画】
事件包ID：MENTAL-OUT
所属阶段：阶段5·常盘台学生会选举与遗产事件
年层：Y（当前年）
时间窗口：社区历表把第34话的当前进度记为十月；这不是全部连载的起讫，更不是34.5话均发生在同一天。进入本包时沿用已选择的同期日期，不为补全选举进程倒退时间。
原作范围：独立漫画《とある科学の心理掌握》第1—4卷／连载封顶34.5话；不假定34.5话全部收录于第4卷，不自动纳入第5卷或更后连载。
别名与触发词：心理掌握漫画 / 常盘台学生会选举篇 / MENTAL-OUT / MENTAL-OUT-01

== 1. 核心定位 ==
学生会长选举把食蜂操祈卷进派阀间的较量。帆风的疑云、食蜂与雅王院的行动、警策看取追查的遗产，以及先代第一位、木原与常盘台理事长的介入，使校园事务转为实质危机。玩家可参与选举事务、协助调查疑云、保护学生或支援遗产线。
这是当前常盘台事件，不是前一年建立派阀的重演。故事推进到寮监与木原唯一冲突、校舍受损与选举危机，不预设选举最终胜者或遗产终局。

== 2. 不可丢失的核心事实 ==
- 食蜂既是有力候选人，也是最大派阀的领袖；被卷入选举不等于她从一开始就主动追求会长职位，更不等于能够以能力跳过全部政治关系。
- 食蜂为洗清帆风的疑云与雅王院共同行动；“有疑云”不等于帆风已经被证明背叛。
- 警策看取另行接近“遗产（Relic）”线索。这条调查与选举交织，不应被一个投票结果自动结清。
- 第3卷引入先代第一位、木原一族的女性人物与常盘台中学理事长；这里的理事长不是学园都市统括理事长，不凭称呼混同身份。
- 第4卷的寮监与木原唯一发生冲突，常盘台校舍受到破坏，选举面临危机。寮监的武术表现不等于新增能力等级或新MVU系统。
- MENTAL-OUT不替代NT11的MENTAL-STINGER，不替代ITEM第二卷“蜂蜜女王”，也不接管幽幻姐妹。NT11当前事件层为Y十一月下旬、夏日回忆为Y−1；106项中的N11则另指游戏分支，不是NT11小说。

== 3. 玩家可改写的部分 ==
玩家可选择协助哪项调查、是否介入派阀协商、如何公开证据，以及在校舍危机中优先救人还是保全资料。帆风的清白不能靠玩家强行宣判，选票与学生意愿也不默认可被精神能力代替。
允许改写冲突或提前降低损失，但不得为凑足原作场面再次破坏已保护的校舍。选举胜负和遗产处理可成为玩家后续自由方向，未实际完成时保持未决。

== 4. 节点推进表 ==
每轮最多一个主要节点；选举、帆风与遗产是相互关联但并不共享全部情报的线。

MENTAL-OUT-01 选举将至
进入条件：玩家位于常盘台相关日常，接触学生会长选举或食蜂派阀的事务。
场景目标：弄清候选人、派阀压力与玩家能够参与的身份。
可见角色：食蜂操祈、帆风润子及在场学生。
玩家行动：协助事务、听取学生意见、询问食蜂的真实意愿、选择是否保持中立。
结果：默认食蜂因候选人与派阀领袖的身份被卷入选举；不自动承诺她必胜或愿意操纵全校。
下一节点：MENTAL-OUT-02。

MENTAL-OUT-02 帆风的疑云
进入条件：与帆风有关的疑云成为选举较量的一部分。
场景目标：把指控、目击与推测分开，避免派阀先行给当事人定罪。
可见角色：食蜂、帆风及持有相关线索的人。
玩家行动：核对证词、保护当事人的陈述机会、检查信息来路、拒绝传播未证实指控。
结果：默认食蜂要洗清帆风的疑云，调查不能直接跳成“帆风背叛已坐实”。
下一节点：MENTAL-OUT-03。

MENTAL-OUT-03 与雅王院共同行动
进入条件：食蜂为追查帆风之事，与雅王院建立共同调查的条件。
场景目标：在派阀工作与权力较量中获得可用信息，而非把合作等同永久结盟。
可见角色：食蜂、雅王院；帆风按实际安排参与。
玩家行动：分配调查方向、交叉核对情报、提出交换条件、保护不愿卷入的学生。
结果：默认两人共同面对逼近的危机；谁信任谁、共享到何种程度由实际对话与证据决定。
下一节点：MENTAL-OUT-04。

MENTAL-OUT-04 警策追查遗产
进入条件：警策看取的遗产调查与玩家的线索相交，或玩家主动寻求协助。
场景目标：确认Relic线存在的风险，区分她掌握的信息与食蜂阵营的已知内容。
可见角色：警策看取；她所接触的对象须由场景逐步确认，不预填未明身份。
玩家行动：递交可核线索、协助跟踪、保护调查者、决定哪些资料可以共享。
结果：默认警策进一步接近遗产，调查继续；“已听说遗产”不等于已取得实物、知道全部用途或解决幕后势力。
下一节点：MENTAL-OUT-05。

MENTAL-OUT-05 校园外的力量介入
进入条件：选举与调查触及先代第一位、木原一方或常盘台理事长的行动。
场景目标：分清各方权限与目的，避免把学生当作势力冲突的消耗品。
可见角色：食蜂与相关学生；先代第一位、木原相关人物、常盘台理事长按各自接触场景出现。
玩家行动：核对来意、保全已有证据、寻求可信成人协助、安排学生撤离潜在冲突区。
结果：默认外部力量使选举危机升级；不能把所有人写成同一阴谋集团或凭身份直接获知遗产真相。
下一节点：MENTAL-OUT-06。

MENTAL-OUT-06 寮监与木原唯一
进入条件：寮监与木原唯一的冲突影响常盘台，或玩家已获得能提前保护学生的预警。
场景目标：应对近距离高危交锋与校舍受损，保住学生和可用通路。
可见角色：寮监、木原唯一及受波及的在场学生。
玩家行动：疏散、救护、避免追击者闯入人群、转移资料、在能力范围内制止危险。
结果：默认冲突造成校舍破坏，选举蒙上阴影；若玩家已降低损失则沿用新结果，不强行补毁校舍。
下一节点：MENTAL-OUT-07。

MENTAL-OUT-07 危机中的交接
进入条件：冲突后的局部安全、人员去向与调查资料能够交接。
场景目标：把救援、帆风疑云、遗产调查和选举事务分别留下明确状态。
可见角色：玩家确已会合的食蜂、帆风、警策或校方人员，不默认全部齐聚。
玩家行动：清点人员、保存证据、安排后续沟通、选择继续哪条未决线。
结果：默认阶段停在校舍危机与仍受影响的选举、遗产调查；没有自动产生最终会长、幕后全败或遗产处置结论。
下一节点：MO-END-A／MO-END-B／MO-END-C。

== 5. 偏离与改写 ==
按玩家行动调整调查顺序和损失，不靠强制读心消除所有信息边界。阶段停点不是全篇完结；若玩家继续原创解决方案，单独记为本线结果，不套上未确认的原作卷话。

== 6. 换篇条件 ==
完成局部救援与资料交接、选择暂缓调查或主动换篇即可离开。与NT11、ITEM第二卷、幽幻姐妹的关联只用于人物与往事辨别，不能用同名能力自动切换包。

== 7. 防剧透边界 ==
疑云阶段不先判幕后，警策未共享的资料不自动成为全体已知；先代第一位与木原线按实际接触揭露。第5卷及更后连载不补入本包的默认走向。

== 9. 收束结果 ==
- MO-END-A 默认阶段收束：派阀疑云、遗产与外部势力已进入视野，寮监与唯一的冲突影响校舍和选举；全篇终局仍未决。
- MO-END-B 玩家主导：按实际救援、证据公开与协商结果交接，未解决的选举和遗产事项继续保留。
- MO-END-C 玩家退出：暂停当前调查，不自动选出会长，不惩罚离开。
