【事件包：创约第十卷·爱丽丝的归来与告别】
事件包ID：GENESIS-10
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第10卷；茵蒂克丝救援与爱丽丝关系收束。
时间窗口：本篇Y＋1年1月6日，社区译文第一章明确当日及22:00节点。原作死亡确认时刻为1月6日23:58，由创约第十一卷序章回接确认，不挪到7日。
别名与触发词：创约第十卷 / 创约第十卷爱丽丝归来 / GENESIS-10

== 1. 核心定位 ==
欧提努斯从复苏的爱丽丝身边逃出，带来茵蒂克丝受困的消息。上条既要救回茵蒂克丝，也不愿再把爱丽丝留在孤独与失控中。围绕“保护老师”与“拯救爱丽丝”的善意互相冲突，还有结社成员试图借爱丽丝支配局面；玩家需要先拆开利用关系，再让两人的交流成为真正的选择。

== 2. 不可丢失的核心事实 ==
- 爱丽丝在前卷尾声已经复苏并杀死伪CRC；本卷不再次把这件事当新召唤演出。
- 茵蒂克丝为让欧提努斯逃出传信而留下，上条在第七学区医院获知危机。她不是无故离队的奖励人质。
- H.T.希望救爱丽丝，施普伦格尔、金斯福德、阿拉迪娅、玛丽、魅魔等人则各以自己的方式保护上条；这两种目标未必始终对立。
- 花束的布罗戴薇兹、毗陀多利和2nd Saga利用与爱丽丝的共鸣取得优势。对抗他们需要破解支援关系，不是给所有超绝者套相同战法。
- 爱丽丝曾被绑架、改造为特殊存在；她想与老师和好，也预见老师的死亡。她能反复恢复自己，不代表她能以同样方式救所有人；玛丽也不能保证逆转爱丽丝造成的致命伤。
- 原作上条没有再用龙王把爱丽丝当作应当消灭的敌人。他坚持交流，使她重新面对他人的痛苦，却在仍站立时停止生命活动。23:58属于他的原作默认结局，不是玩家必死规则。

== 3. 玩家可改写的部分 ==
- 改变茵蒂克丝传信与脱困方式、提前保护居民、促成救老师与救爱丽丝两方合作。
- 打断三名利用者的共鸣优势，分享对爱丽丝力量与经历的分析，避免把她只当作灾害源。
- 提前减少伤害、争取新的救助条件或改变最后交流，允许上条存活分支；预言不是强迫玩家或NPC死亡的回正机制。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；22:00与23:58是现实侧节点，不能用回顾扩成另一天。

GENESIS-10-01 从医院收到求救
进入条件：1月6日选择本卷，或欧提努斯带来茵蒂克丝受困的消息。
场景目标：核对爱丽丝复苏后的状态，决定如何从医院组织救援。
可见角色：上条、欧提努斯、施普伦格尔、医疗人员；茵蒂克丝暂在另一现场。
玩家行动：询问最后目击情况、确认上条伤势、联络可用同伴，避免因急迫而让医院患者失去照护。
结果：救援目标同时包括茵蒂克丝的安全与爱丽丝的处境，而非只把后者击倒。
下一节点：GENESIS-10-02。

GENESIS-10-02 二十二点的童话侵入
进入条件：当日夜间推进至22:00前后，爱丽丝造成的异常开始影响都市秩序。
场景目标：让平民离开异常影响区，汇合不同救援立场的同伴。
可见角色：上条、H.T.、两位安娜、阿拉迪娅、玛丽、魅魔及实际在场的居民。
玩家行动：疏散、共享情报、明确“不杀爱丽丝也不放弃茵蒂克丝”的协作底线。
结果：队伍不再只争论谁更值得救，而开始分工；利用爱丽丝力量的结社成员成为实际阻碍。
下一节点：GENESIS-10-03。

GENESIS-10-03 切断利用者的优势
进入条件：布罗戴薇兹、毗陀多利与2nd Saga借爱丽丝共鸣阻挡救援。
场景目标：破解他们受到的特殊支援，让爱丽丝不再替他人的欲望承担一切。
可见角色：三名利用者、施普伦格尔、阿拉迪娅及另一名阿拉迪娅、魅魔等支援者。
玩家行动：传递共鸣分析、掩护同伴形成替代引导，针对傀儡、诅咒和花束装置分别行动，不把无效攻击反复堆叠。
结果：原作利用者的优势被打破，阿拉迪娅与魅魔等人击破其攻势，通往爱丽丝的救援得以继续；具体伤情按现场记录。
下一节点：GENESIS-10-04。

GENESIS-10-04 让茵蒂克丝重新参与
进入条件：能够接近爱丽丝所在区域，茵蒂克丝获得离开拘束或传递分析的机会。
场景目标：救回茵蒂克丝，并把她从被保护对象重新纳入有意愿的协作者。
可见角色：茵蒂克丝、欧提努斯、上条、施普伦格尔、金斯福德、爱丽丝。
玩家行动：护送脱困、共享魔术分析、了解爱丽丝被改造和孤独的经历，认真对待她关于老师死亡的警告。
结果：原作茵蒂克丝恢复行动并提供支援；救援方确认不能把玛丽的复活视作对抗爱丽丝的保险。
下一节点：GENESIS-10-05。

GENESIS-10-05 不以杀死她作为答案
进入条件：爱丽丝以不断变化的强大形态与力量对抗接近者，交流尚未成功。
场景目标：在保护旁人的前提下接近爱丽丝，分清制服、理解与消灭。
可见角色：上条、爱丽丝、施普伦格尔及实际能够支援的同伴。
玩家行动：掩护接近、争取交流时间、减轻对双方的伤害，或实施已核实的其他救援办法。
结果：原作上条拒绝再次用龙王处理一个人，承受爱丽丝的攻击仍坚持走到她面前；玩家减少伤害或提前沟通成功时保留成果。
下一节点：GENESIS-10-06。

GENESIS-10-06 老师最后想教会的事
进入条件：上条或玩家能够与爱丽丝直接交流，世界性失控仍可被阻止。
场景目标：使爱丽丝理解强大不只是保护自己，也需要看见其他人的痛苦与选择。
可见角色：爱丽丝、上条；同伴按距离提供救护与支援。
玩家行动：回应和好的愿望、解释拒绝不是抛弃、让她停止把全部世界改成单一答案，并争取救助上条。
结果：原作爱丽丝重新回到能够回应老师的小女孩状态，上条却仍站着停止生命活动；若玩家已改变致命条件，则采用存活或其他实际医疗结果。
下一节点：GENESIS-10-07。

GENESIS-10-07 一月六日二十三时五十八分
进入条件：最后交流结束，医疗人员核对上条的生命状态。
场景目标：让同伴真实面对结果，不把短暂抢救与已经确认的死亡混为一谈。
可见角色：上条、爱丽丝、茵蒂克丝、冥土追魂与赶来的同伴。
玩家行动：协助抢救、传达事实、照顾受到打击的人；不替角色自动接受或遗忘死亡。
结果：原作死亡确认是1月6日23:58；这是下一卷序章回接的时刻。存活分支不写死亡确认，也不强制开启死后篇。
下一节点：本包收束；默认死亡线接GENESIS-11-01；若存活，留在实际善后或按玩家明确选择更换锚点。

== 5. 分支和偏离规则 ==
- 预言、玛丽的能力边界与上条原作死亡都是本剧情条件，不构成玩家行动必败或禁止救人的规则。
- 若上条存活，不把他送进伪地狱补齐卷号；可继续爱丽丝照护与城市善后，后续以实际因果接力。
- 对爱丽丝的救助不能抹掉她对他人造成的伤害，也不能把她的过往受害经历当作允许同伴处刑她的自动授权。

== 6. 换篇条件 ==
茵蒂克丝安全、爱丽丝的即时失控和上条生命状态已有结果，或玩家明确离开、跳跃、另选锚点时换篇。死亡线在6日23:58衔接死后篇，不为进入下一卷把死亡改成7日。

== 7. 防剧透边界 ==
爱丽丝的经历、预言与力量边界通过调查和本人交流揭露。普通同伴不知道死后有什么，也不能因为后卷存在便把当前死亡当作没有意义。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8，当前节点用完整ID，阶段状态按实际救援与收束更新。
- 正史锚点保存爱丽丝收束与6日23:58死亡的默认参照；玩家偏移记录任何存活、提前沟通或不同医疗结局，不强制回正。
- 已完成节点、可触发节点整体replace并去重；死后入口仅在实际满足死亡线或玩家明确选锚点时加入，不把活人线自动改为已死。
- 救援、医疗与安置沿用任务追踪；生命状态及同伴反应写入NPC关系、在场人物、势力关系、世界线记录，不新建死亡惩罚或预言锁定字段。

== 9. 收束结果 ==
默认茵蒂克丝获救，爱丽丝不再以同样方式失控，上条在成功传达心意后死亡。这个结局有具体受影响的人与时间，不是只为切到下一卷的一句旁白；玩家改变的生存与关系结果持续有效。
