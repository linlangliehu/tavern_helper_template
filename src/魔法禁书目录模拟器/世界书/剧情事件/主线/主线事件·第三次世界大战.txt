【事件包：第三次世界大战篇】
事件包ID：WW3
所属阶段：阶段5·旧约→新约·世界大战
时间窗口：10月-11月
别名与触发词：第三次世界大战 / 世界大战 / 战争爆发 / 俄罗斯 / WW3

== 1. 核心定位 ==
本篇是阶段5的世界规模主线事件：科学侧（学园都市）与魔法侧（俄罗斯成教等）爆发全面冲突，战火从学园都市周边蔓延到俄罗斯大陆。上条当麻的右手（幻想杀手）与觉醒的"龙王的叹息"成为扭转战局的关键；一方通行、滨面仕上等人卷入世界规模的战斗；神之右席（右方之火）在幕后推动"拯救世界"的极端计划。
玩家进入本篇的方式：开局锚点直接选在本篇；或随阶段5时间推进自然卷入战争。玩家立场完全自由：留守都市、参战、救援、中立商人、和平斡旋者——战争是舞台，玩家的任何立场都构成一条完整的故事线。

== 2. 不可丢失的核心事实 ==
- 战争的爆发是科学侧与魔法侧长期摩擦的总体升级，主战场在俄罗斯大陆及周边空域；学园都市投入尖端兵器与能力者部队。
- 右方之火（神之右席）是战争的幕后推手：借战争达成"拯救世界"的极端计划，其手段与学园都市的反击构成双线。
- 上条当麻亲赴俄罗斯战区，其右手的力量在战争中深化，"龙王的叹息"级别的力量觉醒成为战局转折点。
- 一方通行在俄罗斯护送妹妹们（复制体群体）；滨面仕上以Skill-Out出身者的身份在战争夹缝中行动——三条角色线并行。
- 战争中魔法侧召唤的大天使级存在（加百列）参与对轰，把战争推到"世界法则被波及"的层级。
- 战争以右方之火计划被粉碎、各方停火收束；学园都市与魔法侧的对抗格局进入新阶段。

== 3. 玩家可改写的部分 ==
- 玩家的战争立场与战场：自由选择留守、参战、救援、斡旋或任何原创路线。
- 战役结果：玩家参与的具体战役按其能力与准备合理演绎（含跨体系自由发挥，无反噬无代价）。
- 三条角色线的介入深度：帮助一方通行护送、协助滨面、或与当麻并肩——玩家决定与谁同行。
- 右方之火计划的破坏方式：正面决战、釜底抽薪、外交瓦解均可。
- 战争的结束方式：原著近似（粉碎计划后停火）或玩家原创的提前/延后/替代收束。

== 4. 节点推进表 ==
节点ID格式：WW3-{NN}（必须使用完整ID，禁止简写如W3-01）。每轮最多推进一个主要节点。

WW3-01 战云密布
进入条件：进入本篇（10月锚点或时间推进）。
场景目标：战争爆发的先兆压境——学园都市动员、边境冲突升级、警报与征召。
可见角色：都市居民、军警要员、（可选）熟人角色的动员姿态。
玩家行动：确认立场、安置身边人、选择行动路线。
结果：战争开始；玩家的战争角色确立。
下一节点：WW3-02。

WW3-02 玩家的立场
进入条件：战争态势明确。
场景目标：玩家按自己的选择投入战争——留守、参战、救援、或斡旋的初始行动。
可见角色：按玩家立场决定。
玩家行动：自由发挥（任何立场均构成主线）。
结果：玩家在战争中的位置与人际关系落定。
下一节点：WW3-03。

WW3-03 俄国的战火
进入条件：玩家触及主战场或战争进程推进。
场景目标：俄罗斯大陆的战况——一方通行护送妹妹们、滨面在夹缝中求生等角色线浮出。
可见角色：一方通行、滨面仕上、（可选）当麻的战区动向。
玩家行动：介入任意角色线、独立行动、或继续留守观察。
结果：至少一条角色线与玩家交汇；战争的人的重量呈现。
下一节点：WW3-04。

WW3-04 右方的火
进入条件：战争进入相持阶段。
场景目标：幕后推手浮出——右方之火的"拯救世界"极端计划与其在战争中的真正目的被揭示。
可见角色：右方之火、（可选）其代理人。
玩家行动：收集情报、调整立场、准备应对。
结果：战争背后的大局对玩家可见；最终决战的方向确立。
下一节点：WW3-05。

WW3-05 大天使参战
进入条件：战争白热化。
场景目标：魔法侧召唤的大天使级存在（加百列）参战——战争层级突破人类常规战斗。
可见角色：加百列、交战双方高层、（可选）当麻。
玩家行动：回避、支援、正面挑战、或协助当麻线。
结果：世界法则被战争波及；行星规模的危机成形。
下一节点：WW3-06。

WW3-06 星条之城
进入条件：右方之火计划进入实施。
场景目标：星条之城（计划的载体）升空——决战舞台与世界命运绑定。
可见角色：右方之火、集结的各方。
玩家行动：参与登城决战部署、分派角色、做战前抉择。
结果：决战阵型就位；最高潮开启。
下一节点：WW3-07。

WW3-07 右手与觉醒
进入条件：WW3-06 完成。
场景目标：终局之战——当麻的右手与"龙王的叹息"觉醒，粉碎右方之火的计划；玩家作为决战亲历者或共同主体。
可见角色：当麻、右方之火、玩家方全体。
玩家行动：自由发挥（可以让当麻承担觉醒的关键时刻，玩家主导亦可；AI 合理演绎，不判定失败收场）。
结果：计划粉碎，战争走向停火。
下一节点：WW3-08。

WW3-08 篇章收束
进入条件：WW3-07 完成。
场景目标：战争结束的结算——停火格局、角色线归途、玩家的战争遗产、世界线后果记录。
可见角色：本篇主要角色（战后余波）。
玩家行动：处理战后安排；选择下一走向（格雷姆林篇 / 日常休整 / 自主跳转）。
结果：阶段状态更新，换篇入口开启。
下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变立场、战场或介入角色线时，保留当前锚点切分支推进。
- 核心结果改写：玩家提前粉碎计划、改变停火条件、或以原创方式终结战争时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家回避战争时，战争按原著因果自行进行与结束，不强制玩家参与。
- 玩家的战争行为（救助、战斗、斡旋）按剧情事实记录，不使用道德评分或失败判定。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. WW3-08 完成（战争收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过 10月-11月。
5. 战争因玩家行动或世界线变化合理提前结束。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：魔神与位相的存在（属格雷姆林篇）、人工天界、科隆尊与艾华斯、亚雷斯塔的深层布局。
- 右方之火按"神之右席的极端计划推动者"呈现，不展开神之右席全貌与更多成员。
- 加百列按"被召唤参战的大天使级存在"呈现，不展开天使层级体系。
- 停火后的世界格局只推进到"对抗进入新阶段"，不预设新约篇的具体事件。

== 8. 状态写回契约 ==

- 任务追踪：参战任务、护送任务、斡旋承诺等写入任务追踪（任务类型标明"主线·世界大战篇"），完成或失效时移除。
- NPC关系：一方通行、滨面、当麻线及玩家战争结识者按实际互动建立与更新；能力字段只写玩家已目睹的内容。
- 世界线记录：玩家战争立场、战役结果、停火方式等改写必须写入。
- 支线任务可并行，但不覆盖本篇的当前锚点与当前节点。

== 9. 收束结果 ==
- WW3-END-A 原著近似收束：计划粉碎，战争停火，玩家作为战争亲历者归来。
- WW3-END-B 玩家的战争：玩家以自己的方式（含原创手段）终结战争，成为停火格局的关键一方（重大偏移）。
- WW3-END-C 同行者：玩家与一方通行/滨面/当麻中至少一条角色线结成长期羁绊，跨篇延续。
- WW3-END-D 玩家暂时退出：玩家明确离开，战争按原著因果自行进行并延后。
- WW3-END-E 完全原创收束：玩家以原创方案（含跨体系能力自由发挥）改写整场战争，世界线记录如实反映。
以上所有收束均不使用死亡、失败收场、风险值或反噬机制；战争的残酷只作为剧情事实呈现，不作为对玩家的惩罚判定。
