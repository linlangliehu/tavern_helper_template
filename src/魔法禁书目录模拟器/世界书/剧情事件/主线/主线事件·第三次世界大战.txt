【事件包：第三次世界大战篇】
事件包ID：WW3
所属阶段：阶段5·旧约20–22·俄罗斯战争
年层：Y
时间窗口：10月18日宣战（旧约20官介／官动）；19日起战事块（图排）；10月30日终战（官动层，旧约21官介明确当日战事）
别名与触发词：第三次世界大战 / 俄罗斯战争篇 / 伯利恒之星 / 克里姆林报告 / WW3-01
证据定位：O37；旧约20–22官介与官方动画年表；O35英国、O36 DRAGON为独立前置

== 1. 核心定位 ==
三名少年为各自要救的人来到俄罗斯，个人救援与右方之火借战争实施的计划交汇。英国政变属于旧约17–18，都市DRAGON属于旧约19；本包从宣战交接到旧约终战，不用一场俄国大战替代前面三卷，也不把十一月新约算作仍在打仗。
18日宣战与19日起战事分层记录；官动把俄国主角高潮集中在30日，不能据此新造19–29日的逐日任务。晚于宣战日入场只补获消息，不倒拨当前日期。

== 2. 不可丢失的核心事实 ==
- 俄罗斯向学园都市宣战，右方之火在背后推动；上条为取回被夺的茵蒂克丝遥控灵装，一方为救最后之作，滨面为治疗体晶损害下的泷壶而赴俄，不是三人领取同一参战命令。
- 上条在独立国同盟接触艾莉莎莉娜，右方之火袭击并夺走萨莎；随后以伯利恒之星承载计划，通过萨莎召出加百列。旧称“星条之城”不沿用为原作设施名。
- 番外个体刺激一方失控；一方与上条交战后重新确认亲手保护最后之作的目标，转而与番外个体合作寻找救法。他护送的是最后之作，不是带全体妹妹横穿战区。
- 滨面获得村落救助、回身保护村民，并得到后方之水相助；治疗泷壶后又阻止克里姆林报告，遭遇麦野并达成和解。
- 加百列出击，后方之水吸收天使之力使其削弱，一方与风斩合力退敌；一方随后依据羊皮纸唱出魔术，救下最后之作。
- 上条的右臂被右方之火斩下；他压住断口涌出的“某物”，恢复右手后击败右方之火。不得改称左手龙王或本篇“龙王的叹息觉醒”，也不把超炮祭典的八龙场面移到这里。
- 原作默认上条留下处理失控天使的余患，向茵蒂克丝说明旧有失忆后坠海失踪；10月30日终战，搜救、幸存消息与十一月新约是后继，不是战争延续到十一月。

== 3. 玩家可改写的部分 ==
玩家可留守都市、救治难民、接应任一少年、保护萨莎、阻止要塞升空或改变最终救援。可避免伤害、提前停火或救回上条；按行动得到的事实写偏移，不要求断臂、失踪或同伴受伤作为剧情通行费。未亲历的异地线只通过可取得的报告推进。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口WW3-01。WW3-03与WW3-06为一方／滨面视角，按已有事实交错；节点编号不代表各地事件必然逐一发生。旧WW3-01至WW3-08全部保留，旧存档已发生的玩家事实不撤销、不强制重演。

WW3-01 宣战与三种出发理由
进入条件：18日宣战消息抵达，或玩家从英国／DRAGON后继进入战时；较晚入场不回拨时间。
场景目标：区分政治宣战与19日起战事，确认茵蒂克丝、最后之作和泷壶各自等待的救援。
可见角色：可联络的英国清教人员、都市留守者、三条赴俄线的同行者。
玩家行动：安置同伴、核实消息、选择留守或赴俄、安排救治与接应，不必加入军队。
结果：18日宣战记为既有事实；三条救援目标分别立项，进入者不被迫重演英国或DRAGON。
下一节点：WW3-02。

WW3-02 独立国同盟的避难处
进入条件：上条追查遥控灵装与萨莎下落；一方和滨面也在寻找救治渠道。
场景目标：在艾莉莎莉娜的支援点安置伤者，应对右方之火袭击，保护前来援助的萨莎。
可见角色：上条、艾莉莎莉娜、蕾莎、萨莎、右方之火；其他视角为村落医生与求助者。
玩家行动：守住撤离通道、联系救治、阻止绑架、追查袭击去向或承担留守救援。
结果：原作默认萨莎被夺，上条转向阻止右方之火；滨面获得村落救助，一方取得魔术羊皮纸线索。
下一节点：WW3-03；滨面视角也可先处理WW3-06的村落救援，再回到尚未完成节点。

WW3-03 番外个体与守护的答案
进入条件：番外个体接触一方，以敌意与妹妹相关记忆刺激他；最后之作仍病重。
场景目标：制止失控与追击，面对一方和上条的冲突，找出救人而非自毁的行动方向。
可见角色：一方、番外个体、上条、最后之作及救护者。
玩家行动：阻止误伤、转移患者、提供已知魔术线索、让双方说明目的；不必照演决斗。
结果：原作默认上条击倒一方，一方重新选择保护最后之作，并与番外个体合作；羊皮纸和禁书目录成为救法线索。
下一节点：WW3-04。

WW3-04 伯利恒之星升空
进入条件：右方之火取得萨莎并启动计划，上条继续追索遥控灵装。
场景目标：识别空中要塞与天使召唤的关联，寻找登上要塞、救萨莎和切断遥控的路径。
可见角色：上条、右方之火、萨莎；英国线可经联络得知史提尔应对茵蒂克丝自动书记的消息。
玩家行动：救出被利用者、破坏仪式条件、协助登上要塞、将确认的情报传给地面救援者。
结果：原作默认伯利恒之星升空，加百列被召出并出击；夺回遥控灵装与处理战场天使成为不同但相连的目标。
下一节点：WW3-05。

WW3-05 被削弱的天使
进入条件：加百列投入战场，羊皮纸与各处交战者遭到威胁。
场景目标：为撤离和解析羊皮纸争取空间，支援风斩与一方，避免把天使之力当作一般兵器硬拼。
可见角色：加百列、风斩、一方、后方之水；英国方面的交战只由现场或可靠报告呈现。
玩家行动：护住伤者和资料、协调迎击、协助后方之水吸收天使之力，或用已成立的替代方案拆解召唤。
结果：原作默认后方之水吸收力量使天使削弱，一方与风斩将其击退；这不等于右方之火的计划和天使余患已全部消失。
下一节点：WW3-06；滨面线已完成则转WW3-07。

WW3-06 村落、克里姆林报告与和解
进入条件：滨面得到村民救助并回身保护村落；后续泷壶接受治疗，新的袭击计划威胁居民。
场景目标：与村民、后方之水一起抵御攻击，阻止克里姆林报告，并面对追来的麦野。
可见角色：滨面、泷壶、村民、后方之水、麦野及袭击部队。
玩家行动：协助诊疗与撤离、侦察袭击设施、阻止报复、促成滨面与麦野对话；村落救援可早于空中战处理。
结果：原作默认泷壶得到治疗，滨面再救村落并与麦野和解；获救者的回援使他有机会带着交涉筹码回城，而非被安排成战争炮灰。
下一节点：WW3-07；若WW3-03至WW3-05尚未推进，先返回对应未完节点，不重复村落事件。

WW3-07 右手、羊皮纸与各自的救援
进入条件：上条与右方之火在要塞对峙，一方得到解析羊皮纸的契机；两线可分视角推进。
场景目标：阻止借“拯救”之名实施的大灾害，同时完成最后之作的救治，不把两件事混成一次能力觉醒。
可见角色：上条、右方之火；另一线为一方、最后之作、番外个体及救援者。
玩家行动：破坏计划、保护遥控灵装、协助羊皮纸解析与救治，或在已建立的条件下改变断臂和决战过程。
结果：原作默认上条右臂被斩后压住“某物”、恢复右手并击败右方之火；一方唱出魔术救下最后之作，两条救援分别记录，不新增左手龙王设定。
下一节点：WW3-08。

WW3-08 十月三十日终战
进入条件：右方之火败北，要塞下坠，失控的天使仍留下必须处理的危机。
场景目标：安排要塞与战场撤离，回应美琴的接应，处理最后的天使余患及各线归途。
可见角色：上条、美琴、通过遥控灵装联系的茵蒂克丝、当地救援者；其他线按联络条件出现。
玩家行动：协助解除余患、实施救援或搜索、安置伤者、记录停火和失踪；可救回上条而不受强制纠偏。
结果：原作默认上条留下善后，说明自己此前的记忆缺失后坠海失踪；俄罗斯教会宣布终战。日期收束于30日，滨面与一方各自处理回城，十一月新约另起。
下一节点：无；按玩家选择进入战后搜索、休整或后续新约包。

== 5. 分支和偏离规则 ==
- 三线救援目标分开记录；玩家不在场时只结算已到时间且有依据的结果，不瞬间获知所有秘密。
- 玩家提前救人、取消召唤、促成停火或改变上条去向，标记已改写并保留本包兼容ID，不补造灾害“偿还正史”。
- 留守、避战和中立路线同样成立；战事可场外推进，不设置道德分数、反噬、降级或强制伤亡惩罚。

== 6. 换篇条件 ==
WW3-08收束、玩家明确离开／跳过／换锚点、跨过10月30日的主动时间跳跃，或战争因玩家行动合理提前结束时换篇。记录实际终战方式、三线救援状态、当前日期与未兑现承诺；原作默认30日之后是战后，不把战事拖到十一月。英国与DRAGON未亲历的部分可作为既有前因记录，不能默认强制回档补打。

== 7. 防剧透边界 ==
当前视角可获知本篇已揭示的遥控灵装、羊皮纸、艾华斯造成的前因及伯利恒之星计划；不提前给出十一月的新约敌人与救援后的秘密。不把此边界变成后续篇章禁入令，也不抹去玩家在DRAGON已知的艾华斯信息；断口“某物”不在此强行定名或解释最终来源。

== 8. 状态写回契约 ==
同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace，保留旧ID、其他已完成项与未完分线。宣战、救治、绑架、断臂、失踪、停火的实际偏移写主线进度.正史锚点.玩家偏移；护送、救援、搜索用任务追踪分开，能力和关系只依亲历更新。阶段5、年层Y，不新增API、变量机制或强制代价。

== 9. 收束结果 ==
- WW3-END-A 原作近似：右方之火败北、最后之作与泷壶获救、上条失踪，30日终战。
- WW3-END-B 玩家的战争：玩家改变救援或停火条件，记下真实存活状态与战后格局。
- WW3-END-C 同行者：与任一救援线继续同行，保留其他线经证实的场外结果。
- WW3-END-D 玩家暂时退出：只结算当前可知事实，战事与后续按时间及玩家选择衔接。
- WW3-END-E 完全原创收束：玩家以已成立的原创方案结束战争，不以反噬或强制失踪否定成果。
