【事件包：自然选择者篇】
事件包ID：NT-NATURAL-SELECTOR
所属阶段：阶段6·新约前段
时间窗口：本篇Y年11月13日大会开幕；不把全部冲突拖排至11月18日
别名与触发词：自然选择者篇 / 巴格吉城大会 / 天择者混战 / NT-NATURAL-SELECTOR

== 1. 核心定位 ==
作品范围：新约4。巴格吉城的异种格斗大会是脱离学园都市的机构展示替代技术的舞台，也是木原与格雷姆林相撞的战场。重点是城市中被当成实验对象的人、木原加群的复仇与救援，而不是正常赛制下逐轮夺冠。

== 2. 不可丢失的核心事实 ==
- 二十七家反学园都市机构以科学守护者为背景举办大会，试图证明学园都市超能力并非唯一力量。11月13日是大会开始的日期，不是所有后续转场均已完成的证明。
- 云川鞠亚与近江手里卷入城内混战；贝尔西是木原加群在格雷姆林中的身份。鞠亚寻找的老师与战场上的参与者是同一人，不在初遇时向不知情者直接公开。
- 木原加群与木原病理之间有复仇因果。原作两人的交锋以死亡收束，鞠亚被迫面对老师的选择；不能把这件事写成玩家必须满足的献祭条件。
- 玛莉安是贝尔西的同伴，她的术式与金属加工手段使周围的人面临被改造的危险。上条在后段介入阻止她；欧提努斯现身展示压倒性力量，欧雷尔斯和右方之火随后介入。
- 原作格雷姆林带走玛莉安，学园都市一侧迫使科学守护者归顺。上条醒来仍要求救助城内居民；比赛胜负不是城市危机的终点。

== 3. 玩家可改写的部分 ==
- 可从参赛者、救护者、寻找鞠亚或追查机构的身份入城，提前疏散实验受害者。
- 可揭开贝尔西身份、阻止复仇同归于尽、救下玛莉安所控制的人；改变死亡事实后，后续英灵状态也必须同步改写。
- 可拒绝学园都市强迫归顺的做法并尝试保留独立救济渠道，但不得凭一份声明让所有木原和机构自动停手。

== 4. 节点推进表 ==
NT-NATURAL-SELECTOR-01 替代超能力的大会
进入条件：夏威夷之后取得大会线索，或玩家主动进入巴格吉城。
场景目标：查明大会宣称与实际安保、试验安排之间的落差，建立离场路线。
可见角色：大会工作人员、参赛者、云川鞠亚、近江手里。
玩家行动：报名或调查，查看被展示的技术，核实谁在赞助比赛，为非战斗人员寻找避难地。
结果：原作大会背后的对抗很快压过赛制；玩家可提前发现机构与魔术侧的交易，使后续围城不再完全出其不意。
下一节点：进入NT-NATURAL-SELECTOR-02；选择先撤离则保留调查线索，不计作输掉大会。

NT-NATURAL-SELECTOR-02 鞠亚寻找的老师
进入条件：与鞠亚或近江接触，城内开始出现超出正常比赛的袭击。
场景目标：将寻人线索和救援路线连接起来，辨认贝尔西为何身在格雷姆林。
可见角色：云川鞠亚、近江手里、贝尔西；玛莉安在其活动地点出现。
玩家行动：保护寻找老师的鞠亚，核对身份与旧事，询问贝尔西是否愿意离开复仇安排。
结果：原作鞠亚最终确认贝尔西就是木原加群；若玩家提早揭示，可以改变她赶到交锋现场的时机，但不能代替当事人决定原谅或赴死。
下一节点：进入NT-NATURAL-SELECTOR-03；已找到加群与病理的交锋地点可直达NT-NATURAL-SELECTOR-04。

NT-NATURAL-SELECTOR-03 木原与格雷姆林的猎场
进入条件：木原方面的镇压与格雷姆林行动扩大，比赛设施成为战场。
场景目标：分辨不同袭击者的技术与目的，防止平民成为双方试验材料。
可见角色：木原方面人员、玛莉安、鞠亚、近江、被困参赛者。
玩家行动：拆分交火区，救出遭改造或追杀者，追踪木原病理，利用双方目标冲突争取撤离时间。
结果：原作城内秩序崩坏，胜负已无法按比赛规则结算；玩家可保住局部医院、通路或证人，形成后续可用的具体支点。
下一节点：进入NT-NATURAL-SELECTOR-04；救援未完成的地点记为可返回目标。

NT-NATURAL-SELECTOR-04 加群与病理的复仇
进入条件：找到加群与病理的决斗，或已在此前改变其中一方的行动。
场景目标：在复仇即将吞没当事人与旁观者时，决定阻断、救治还是见证。
可见角色：木原加群、木原病理、云川鞠亚；玛莉安按其到场过程出现。
玩家行动：隔开两人、争取治疗时间、把鞠亚带离杀伤范围，或用已掌握证据动摇加群的求死选择。
结果：原作加群与病理均死于这段冲突，鞠亚失去老师；救援成功则保留生还偏移，不在下一节点补写必死。玛莉安的反应取决于她实际见到的结局。
下一节点：进入NT-NATURAL-SELECTOR-05；需要急救时先继续本节点。

NT-NATURAL-SELECTOR-05 不完整的魔神现身
进入条件：玛莉安继续危及城内人员，上条介入，或玩家已先行抵达核心冲突。
场景目标：制止玛莉安的改造与杀伤，同时给被困者保留逃离压倒性力量的机会。
可见角色：上条、玛莉安、欧提努斯；欧雷尔斯、右方之火随后介入。
玩家行动：破除眼前术式，带走受害者，阻断玛莉安退路或争取停火，不把未知魔神力量当成已可随意对消的普通能力。
结果：原作上条阻止玛莉安后遭欧提努斯重创右臂，欧雷尔斯与右方之火介入，欧提努斯带玛莉安撤走；玩家的阻截、谈判或先行撤离均可改写，不要求复现伤势。
下一节点：进入NT-NATURAL-SELECTOR-06；成功拘留相关人员时带着实际状态进入善后。

NT-NATURAL-SELECTOR-06 不是冠军的归程
进入条件：核心交锋结束，能够进入城市救济与机构处置阶段。
场景目标：区分机构归顺和居民获救，确认鞠亚、伤者与实验受害者的去处。
可见角色：上条、鞠亚、近江、救护人员；木原唯一与机构代表在政治处置线出现。
玩家行动：继续救助居民，保存实验记录，反对灭证，调查格雷姆林下一步需要的人与材料。
结果：原作科学守护者被迫归顺，上条坚持救人；加群被欧提努斯作为英灵复活并非普通获救。若他本已生还则取消该前提。下一轮争夺转向学园都市中的芙罗兰·克洛杜尼。
下一节点：玩家选择返城追查时进入NT-ICHIHANARAN-01；也可继续巴格吉城救济或暂离。

== 5. 分支和偏离规则 ==
将加群生死、鞠亚是否知情、玛莉安是否撤离与居民救援分别存档。死亡与英灵化只属原作默认事实，不是玩家失败惩罚；若加群被救，不用魔神远程夺走他来恢复原作。政治归顺也不等同所有受害者得到补偿。

== 6. 换篇条件 ==
有离城安排、未决救援的接手者和继续调查意向，才进入一端览祭。新约5的节庆地点与核心对象必须重新说明，不把11月13日大会延长成一端览祭的前半。

== 7. 防剧透边界 ==
贝尔西身份、复仇目的及欧提努斯登场按调查逐层揭示。初入大会者不自动知道魔神完整性、神枪制造或后来世界变化。学园都市中的不死少女只在卷末情报出现时接入。

== 8. 状态写回契约 ==

玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- 原作默认：复仇以两人死亡告终，格雷姆林撤离，机构归顺，居民救援继续。
- 复仇中断：玩家救下加群或病理，后续依照真实生还、拘留与关系处理，不补演死亡。
- 城市优先：保住撤离通道、医院或证据，暂不追击格雷姆林。
- 独立善后：玩家留城推动救济与政治处置，下一篇待玩家选择再接入。
