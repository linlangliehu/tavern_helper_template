【事件包：夺回上里篇】
事件包ID：NT-KAMISATO-RESCUE
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年十二月上旬，接NT16放逐之后、NT18之前；保留NT15—17排期冲突
别名与触发词：夺回上里篇 / 新天地归还作战 / 理想送行救回行动 / NT-KAMISATO-RESCUE

== 1. 核心定位 ==
作品范围：新约17。灾害结束后的学园都市开始恢复秩序，唯一却以右手为筹码操纵上里阵营。上条与府兰寻找不受她控制的救回办法，证明“可能是最后希望”并不等于对方说的就是事实。
上里若在NT16未被放逐，本包不强制造成失踪；可只引用灾后恢复与府兰处境，不记作完成整段救回行动。

== 2. 不可丢失的核心事实 ==
- 唯一保管理想送行，威胁若失去右手便可能永远救不回上里，多数女孩因恐惧而追杀上条。府兰拒绝服从，独自帮助他寻找替代方案。
- 元素自毁、热浪消退后，Useful Spider展开原作所称的“秩序恢复四十八小时”。避难所自定规则与救援管制彼此冲突，恢复工程不是已瞬间完成的安全背景。
- 府兰与上条说服幽灵少女卢卡加入。观察原型A.A.A时，美琴遭亚雷斯塔施加的诅咒；原作她坚持让卢卡先完成分析，再由幻想杀手解除，随后接受救治。
- 府兰的原石与外星人身份是掩饰，她实际来自英国清教；这不等于她想救上里的意愿虚假。卢卡在身份曝光后仍继续协助。
- 卢卡的救回术式需要两边保有同一对象的部分以建立联系。原作最终利用帕特莉夏体内奈芙蒂斯的部分，与新天地中的奈芙蒂斯联系；娘娘和奈芙蒂斯也在另一侧保护上里。
- 上里归来后，唯一失去胁迫筹码，女孩们夺回右手。府兰的教会身份又使她成为亚雷斯塔的目标，土御门介入，为NT18的逃离与反击留下原因。

== 3. 玩家可改写的部分 ==
- 可在追杀前提供可信替代证据，争取更多女孩加入，不必让所有人一直服从唯一。
- 可优先救治美琴或设计安全观察办法，不能把忍受诅咒规定为玩家必须付出的通行费用。
- 可保护帕特莉夏并征得救援配合，使用其他已经验证符合条件的连接物；不凭口号跨越放逐区域。

== 4. 节点推进表 ==
NT-KAMISATO-RESCUE-01 被希望挟持的追兵
进入条件：上里确已被放逐，唯一持有右手并命令上里阵营杀上条。
场景目标：从追杀中脱离，同时保留说明替代救援可能性的机会。
可见角色：上条、府兰、去鸣等追击者；唯一通过命令与威胁施压。
玩家行动：掩护撤离，询问唯一能提供什么确证，保护不同意命令的成员，避免把受胁迫者一律当成必须杀死的敌人。
结果：原作只有府兰先站到上条一侧；玩家若能争取其他成员，保留实际同盟，不让她们在下一幕无故回到追兵位置。
下一节点：进入NT-KAMISATO-RESCUE-02。

NT-KAMISATO-RESCUE-02 说服幽灵少女卢卡
进入条件：得知卢卡有相关魔术知识，能够在追踪与交涉中接触她。
场景目标：让真正想救上里的人比较方案，而不是争夺谁更忠诚。
可见角色：卢卡、府兰、上条；附近避难者与追兵。
玩家行动：指出右手垄断说缺乏证明，说明跨越两边所需的信息，提供安全交流地点，避免以伤害卢卡强迫合作。
结果：原作卢卡被说服参与研究，救援不再只能等待唯一；玩家可改变会面方式与加入时机，但术式仍需实物与知识支撑。
下一节点：进入NT-KAMISATO-RESCUE-03。

NT-KAMISATO-RESCUE-03 恢复秩序中的医院路线
进入条件：城市恢复工程展开，队伍需要避难所的通信、医疗与调查条件。
场景目标：协调避难所和Useful Spider的管制，阻止灾后报复扩大。
可见角色：上条、府兰、卢卡、美琴、避难者、Useful Spider人员。
玩家行动：建立可靠联络，保护被洗劫后受伤的学生，劝阻美琴对人群的报复，把常盘台人员与医院安全接合。
结果：原作上条制止愤怒的美琴，她带队伍取得医院避难点的协助；若NT16已保住学校，则不伪造洗劫与失控，改由实际需要建立合作。
下一节点：原型A.A.A位置得到确认后进入NT-KAMISATO-RESCUE-04。

NT-KAMISATO-RESCUE-04 原型武装上的诅咒
进入条件：队伍能够观察原型A.A.A核心，亚雷斯塔对美琴的干预发生或被预先察觉。
场景目标：理解武装与另一侧的关联，同时阻止调查吞没被诅咒者的安全。
可见角色：美琴、上条、府兰、卢卡；亚雷斯塔仅通过实际显现的术式影响现场。
玩家行动：建立隔离和急救，分析诅咒来源，讨论立即解除与保留观察窗口的取舍，寻找替代样本。
结果：原作美琴自愿坚持至卢卡完成分析，上条随后解除诅咒，她被送医；玩家可以更早救人并另寻线索，不以无法取得本次全部数据惩罚其选择。
下一节点：完成救治与必要调查后进入NT-KAMISATO-RESCUE-05；缺少连接线索时继续调查而不编造成功。

NT-KAMISATO-RESCUE-05 府兰的身份与另一条联系
进入条件：府兰的清教身份暴露，或原型武装的方案受阻，队伍需要改用其他联系物。
场景目标：区分情报隐瞒和救援意愿，找到两侧同时存在的奈芙蒂斯部分。
可见角色：府兰、卢卡、上条、帕特莉夏；柏德蔚姐妹按救护需要会合。
玩家行动：质询府兰而不自动否定所有合作，核对NT14留下的救治材料，征求帕特莉夏配合并确保其身体安全。
结果：原作卢卡继续帮助府兰，发现帕特莉夏体内的奈芙蒂斯部分可成为连接；若玩家此前改变NT14治疗，须寻找真实存在的替代，不凭空在她体内补放材料。
下一节点：连接物和术式条件成立后进入NT-KAMISATO-RESCUE-06；否则保留研究与谈判分支。

NT-KAMISATO-RESCUE-06 新天地那一侧的接应
进入条件：连接媒介、施术者和安全位置具备，能够尝试救回上里。
场景目标：建立稳定联系，并给遭魔神围攻的上里留下回程。
可见角色：府兰、卢卡、上条；另一侧的上里、奈芙蒂斯、娘娘只在已经建立的叙述与联络范围出现。
玩家行动：保护施术，阻止追兵打断，争取其他女孩信任；联系另一侧时允许上里表达是否回来的意愿。
结果：原作首次尝试受阻后，府兰与卢卡最终成功救回上里，奈芙蒂斯与娘娘为他争取时间；玩家可提前成功或改变接应者，不要求补演首次受阻。
下一节点：返回成功则进入NT-KAMISATO-RESCUE-07；联系尚不稳时继续本节点，不宣布上里已归来。

NT-KAMISATO-RESCUE-07 唯一失去筹码之后
进入条件：上里已回到现实，或玩家达成能解除唯一胁迫的替代协议。
场景目标：结束追杀，取回右手，核对城市恢复与府兰的新危险。
可见角色：上里、去鸣、上里阵营、唯一、府兰、上条；土御门按其介入出现。
玩家行动：传递归还证据，制止不必要的报复，救治伤者，保护府兰并确认土御门为何对亚雷斯塔采取行动。
结果：原作女孩们转向唯一并夺回右手，城市恢复工程告一段落；亚雷斯塔追究府兰身份，土御门开枪介入但未杀死他。玩家可用撤离或交涉改写，不要求复现枪击。
下一节点：府兰与土御门携舞夏求助、玩家选择介入时进入NT-ALEISTER-01；否则留在上里归还与灾后善后。

== 5. 分支和偏离规则 ==
每次连接与归还都要有实物条件，不能把“放逐非死亡”推导成随时自由往返。前卷改变奈芙蒂斯身体、A.A.A或常盘台状态时，本卷同步改写。原作四十八小时是救援行动名称与背景，不自动给玩家结算倒计时失败。

== 6. 换篇条件 ==
上里、右手与唯一的控制关系有明确结果后，才结束救回链。府兰的英国清教身份和土御门的保护承诺，才是进入NT18的线索；不因跨过某个日历日自动开启亚雷斯塔战。

== 7. 防剧透边界 ==
不得在追杀开局直接公开卢卡最终公式、帕特莉夏媒介或府兰间谍身份。美琴遭咒前不让所有角色掌握幕后全貌。新天地的视角不能变成现实NPC天然共享的见闻。

== 8. 状态写回契约 ==
正式进入本包时，主线进度.当前阶段记“新约”，主线进度.阶段序号使用整数6；主线进度.正史锚点.当前锚点记“夺回上里篇”，主线进度.当前节点使用NT-KAMISATO-RESCUE完整ID。已完成节点、可触发节点以op:"replace"整体替换数组；阵营选择、美琴救治、连接物、上里归还、右手与府兰处境写入主线进度.正史锚点.玩家偏移及世界线记录。仅更新现有任务追踪、NPC关系，不新增维度坐标或倒计时惩罚字段。
玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- 原作默认：上里归来，唯一失去胁迫筹码，府兰与土御门面临新的追踪。
- 提前协作：更多女孩接受替代方案，减少追杀与反复阻挠。
- 安全取证：玩家保护美琴与帕特莉夏，利用已成立的其他联系完成救援。
- 继续寻找：尚未满足连接条件时保留真实进展，不把未归还者登记为完成。
