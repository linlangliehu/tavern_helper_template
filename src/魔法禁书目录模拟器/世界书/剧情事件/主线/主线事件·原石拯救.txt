【事件包：原石拯救篇】
事件包ID：GEMSTONE
所属阶段：阶段0·旧约·前日谭
时间窗口：1月18日前后
别名与触发词：原石 / 原石拯救 / 天生能力者 / 自然能力者 / 未开发能力 / GEMSTONE

== 1. 核心定位 ==
本篇是阶段0的科学侧支线级主线事件：一名从未在学园都市接受过能力开发课程、却天生拥有强大力量的"原石"能力者出现在学园都市，引发统括理事会、研究机构与多方势力的关注与争夺。事件主题是"天赋与体制"——被体制外的天赋打破规则的人，在学园都市的秩序下会遭遇什么。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段0中主动接近传闻、受人之托、或偶然目击原石能力者暴露力量。玩家立场自由：可以保护原石、协助研究、代管理事会追查、或纯粹旁观。

== 2. 不可丢失的核心事实 ==
- "原石"指未经学园都市能力开发课程、天生觉醒能力的人，极其稀有；其能力等级可媲美高位能力者，且不受常规能力测定体系完整评估。
- 学园都市的官方叙事是"能力全部来自开发课程"，原石的存在与这套叙事冲突，因此理事会倾向低调处理：接触、评估、必要时收容或送出都市。
- 事件中的原石能力者对自身力量的来历知之甚少，且对学园都市的体制缺乏了解，容易同时被善意与恶意利用。
- 研究机构对原石的样本价值极高，存在越界采集的动机；警备员与风纪委员的官方立场是维持秩序而非保护原石本人。
- 原石能力者事件的收束以"该原石的去向"为核心：留在都市、安全离城、获得庇护或被机构收容，都属合法结局。
- 本篇以学园都市内部势力为主，无魔法侧势力推动；玩家跨体系能力属卡面自由规则，不代表外部势力介入。

== 3. 玩家可改写的部分 ==
- 是否接触原石能力者、以何种身份接近（朋友、保护者、劝离者、追查者）。
- 原石能力者暴露力量的程度与范围：可以被玩家压制、掩护、或引导其控制。
- 对研究机构越界行为的态度：举报、阻止、交易、或视而不见。
- 原石能力者的最终去向：这是本篇最大的可改写点，玩家的准备与选择直接决定结局。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价），允许以原创方式改变事件走向。

== 4. 节点推进表 ==
节点ID格式：GEMSTONE-{NN}（必须使用完整ID，禁止简写如GS-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

GEMSTONE-01 传闻初现
进入条件：进入本篇时间窗（开局锚点选定或阶段0推进至此）。
场景目标：都市里出现关于"没上过能力开发课却拥有强大能力的人"的零散传闻。
可见角色：传闻来源、路人、（可选）原石能力者的模糊身影。
玩家行动：追问传闻、忽略、检索网络、留意异常新闻。
结果：玩家获得原石传闻；传闻真假混杂，需自行判断。
下一节点：GEMSTONE-02。

GEMSTONE-02 目击力量
进入条件：玩家接近传闻源头或原石活动区域。
场景目标：玩家亲眼目击原石能力者在不受控状态下展露力量（或其后果）。
可见角色：原石能力者、受波及的路人、可能到场的风纪委员或警备员。
玩家行动：接触、救助、掩护其离开、或记录上报。
结果：玩家与原石能力者建立初步接触；其能力引起了有心人注意。
下一节点：GEMSTONE-03。

GEMSTONE-03 多方注意
进入条件：力量暴露或玩家上报。
场景目标：研究机构、理事会外围人员、风纪委员等多方开始锁定原石能力者。
可见角色：机构人员、官方调查者、（可选）动机不明的接触者。
玩家行动：为原石传递信息、对抗追踪、与官方合作或周旋。
结果：原石能力者处境公开化，争夺开始；玩家选定立场。
下一节点：GEMSTONE-04。

GEMSTONE-04 温柔的牢笼
进入条件：玩家与原石建立信任或官方接触原石。
场景目标：以"保护/研究/安置"名义提出的收容方案出现，原石面临选择。
可见角色：原石能力者、方案提出方、玩家信任的其他角色。
玩家行动：陪原石分析利弊、寻找第三条路、拖延、或促成方案。
结果：收容压力升级；原石的去向问题摆上台面。
下一节点：GEMSTONE-05。

GEMSTONE-05 越界之手
进入条件：收容谈判僵持或原石拒绝配合。
场景目标：研究机构的越界采集行动展开（诱拐、强制样本、威胁家人朋友等）。
可见角色：越界执行者、被波及者、原石能力者。
玩家行动：阻止、揭发、反追踪、保护被波及者。
结果：事件从"安置"转向"对抗"；玩家掌握机构越界的证据或实锤。
下一节点：GEMSTONE-06。

GEMSTONE-06 原石觉醒
进入条件：原石承受的压力达到临界（恐惧、愤怒或被逼入绝境）。
场景目标：原石能力者力量大规模失控暴露，波及范围扩大。
可见角色：原石能力者、各方势力、可能到场的防御部队。
玩家行动：压制、安抚、疏散、掩护，或借势对抗越界方。
结果：事件进入最紧张阶段；原石的去向在此轮后基本注定。
下一节点：GEMSTONE-07。

GEMSTONE-07 收束行动
进入条件：玩家已决定本篇的最终介入方式。
场景目标：执行玩家的收束方案（护送离城、达成协议、公开揭露、战斗压制等均可）。
可见角色：按方案决定。
玩家行动：自由发挥，允许完全原创方案；AI 按玩家能力与准备合理演绎结果，不判定失败收场。
结果：原石的去向确定；越界行为得到玩家选择范围内的处置。
下一节点：GEMSTONE-08。

GEMSTONE-08 篇章收束
进入条件：GEMSTONE-07 完成。
场景目标：事件结算——原石去向落实、与机构/官方的关系结算、世界线后果记录。
可见角色：本篇主要角色（余波互动）。
玩家行动：处理后续安排；选择下一走向（日常休整 / 幻想御手篇 / 自主跳转）。
结果：阶段状态更新，换篇入口开启。
下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变接触方式、立场或保护对象时，保留当前锚点，在节点表内切分支推进。
- 核心结果改写：玩家提前送走原石、公开机构黑幕、或促成官民联合保护时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家长期回避时，事件按背景因果自行发展（原石被找到、冲突爆发），不强制玩家参与。
- 原著角色的行动随玩家偏移而变化，不强行复位。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. GEMSTONE-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过 1 月窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：统括理事会的全貌、学园都市最高层真实意图、能力开发的终极秘密、AIM扩散力场理论深层。
- 原石能力者的天赋成因只按"未解之谜"处理，不得提前给出学园都市世界观级别的解释。
- 后续篇章（幻想御手、禁书降临等）不得在本篇提前启动；其角色至多合理客串。
- 魔法侧组织不得作为本篇推动力；玩家跨体系使用能力属卡面自由规则。

== 9. 收束结果 ==
- GS-END-A 原著近似收束：原石被体制以低调方式安置，玩家身份有限知情。
- GS-END-B 玩家送离：玩家帮助原石安全离开学园都市，体制未获取样本。
- GS-END-C 联合庇护：玩家促成风纪委员/可信机构与民间的联合保护方案。
- GS-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行发展并延后。
- GS-END-E 完全原创收束：玩家以原创方案（含跨体系能力自由发挥）改写整场事件，世界线记录如实反映。
