【事件包：ITEM第六卷·银行救人与情报商勒索】
事件包ID：ITEM-06
所属阶段：阶段0·旧约·前日谭
年层：Y−1前史
时间窗口：秋日休息日；民译第二至三章有十月明文，不能再称月份仅图排。银行当天及全卷精确起讫未核，不自动填十月首日。
别名与触发词：ITEM第六卷 / 秋日银行劫案 / ITEM-06 / ITEM-06-01

== 1. 核心定位 ==
麦野手机与支付账户的问题让四人来到第15学区银行，却遇到受胁迫的少女Sudori Sayu抢劫。绢旗阻止开枪，泷壶用灭火器制造遮蔽，带绢旗和少女撤出。银行案随后与另一委托相接，被胁迫者获释，但救人秘密落入售卖犯罪方案的情报商Norsitro Chatellenie手中；她要求绢旗杀掉麦野、接管ITEM。
本包覆盖银行、勒索、队内坦白及终局善后的已核主干，不把救出少女当全卷结束。战斗细部及电话之声完整置换机制仍不擅自补写。

== 2. 不可丢失的核心事实 ==
- Sayu因父母安全受到胁迫，是需要保护的人，不是终敌或隐藏能力者。银行开场不是ITEM预先接到的救援委托。
- 绢旗挡住芙兰达开枪，泷壶制造遮蔽并带两人离开；不能把救援写成绢旗单独完成。
- 第一层操盘者Kamigi Ryouichi被称为“第13人／看不见的理事”，是其外号和影响力描述，不擅增一名正式理事。他受麦野与芙兰达威慑退出非法生意，公开销毁黑料，被胁迫者才得以获释。
- Norsitro的犯罪方案客户受损后，她用隐瞒救人的秘密勒索绢旗杀麦野。三名队员试图制造麦野误伤绢旗的亏欠来抵销所谓背叛，但这个骗局不是最终和解原因。
- 绢旗真实重伤后向麦野坦白救人和撒谎，主动使秘密失去勒索价值；麦野因此重新确认她是应被保护的队员。
- Norsitro是Level0，气象攻击来自Superb Starling无人机群，不是天候超能力。通信漏洞、犯罪者救援组织Dark Rescue Squad与无人机设施是不同层次的支援。
- 绢旗接受手术与输血、住院；通信漏洞修补后，残党仍不明，ITEM搬离据点。卷尾Hanano Choubi夺回“电话之声”职位，不意味着此前每通电话都是她。

== 3. 玩家可改写的部分 ==
可以提前劝止开枪、改变撤离办法、保护被胁迫者、主动坦白或识破情报商，从而避免重伤与骗局。玩家获得的信任持续有效，不为了复现原作让麦野突然忘记解释，也不要求伤害同伴才能取得宽恕。

== 4. 节点推进表 ==
使用ITEM-06完整节点ID；每轮最多推进一个主要节点。

ITEM-06-01 休息日银行里的被迫劫犯
进入条件：玩家选择Y−1秋日银行锚点；不要求具体某一天。
场景目标：辨认少女受胁迫的处境，在麦野愤怒、芙兰达准备开枪时保护普通人。
可见角色：ITEM四人、Sudori Sayu、银行工作人员及顾客。
玩家行动：提醒队友、阻止误伤、配合泷壶的遮蔽与撤离，或尝试有依据的现场交涉。
结果：原作绢旗阻枪，泷壶利用灭火器带她与Sayu撤出；救援仍瞒着麦野，尚未解除对少女父母的威胁。
下一节点：ITEM-06-02。

ITEM-06-02 同一网络的两条委托
进入条件：ITEM-06-01完成，追赃发现收货与店铺等中间环节也被胁迫。
场景目标：沿网络找到操盘者，并分清绢旗私下救援与麦野另一委托各自掌握的信息。
可见角色：绢旗、麦野、芙兰达、Kamigi Ryouichi；泷壶与Sayu在另一现场按实际联络参与。
玩家行动：保护中间受害者、核实黑料与委托目标、传递已取得的关联信息，争取安全解除胁迫。
结果：原作绢旗随队行动到末尾才发现目标相连；Kamigi受威慑退出非法生意并公开视频毁掉黑料，泷壶护送Sayu与父母团聚。银行案得到阶段收束，队内隐瞒没有自动解除。
下一节点：ITEM-06-03。

ITEM-06-03 被出售的秘密
进入条件：ITEM-06-02完成，犯罪方案客户受损，Norsitro接触绢旗。
场景目标：核对勒索者的筹码与要求，寻找不杀队友、不把无辜者交回去的脱身办法。
可见角色：绢旗、Norsitro；泷壶与芙兰达通过实际商议参与。
玩家行动：记录威胁、追索情报交易、争取坦白或独立求援，不将敌人的杀人命令当作玩家必须完成的任务。
结果：确认情报商要求绢旗杀麦野并取代其位置；原作三人误以为让麦野误伤绢旗能形成亏欠，这是一项危险且可能失败的自设方案。
下一节点：ITEM-06-04。

ITEM-06-04 追踪情报商与失控骗局
进入条件：ITEM-06-03完成，队伍开始追查携带多台手机的人及其真实登记信息。
场景目标：定位Norsitro，识破免检通信与犯罪救援支援，阻止计划伤及队友。
可见角色：ITEM四人、Norsitro及实际到场的支援者。
玩家行动：核对可得的通讯信息、保护目标区域平民、提醒队友计划风险，或用提前建立的信任取代制造误伤。
结果：原作骗局失控，绢旗真正重伤；通信漏洞与Dark Rescue Squad说明敌人有持续支援，不是几个银行劫匪被打倒就结束。玩家已阻止重伤时直接沿实际局面进入摊牌。
下一节点：ITEM-06-05。

ITEM-06-05 坦白而非亏欠
进入条件：ITEM-06-04完成，绢旗能够对麦野说明真相或玩家已创造安全沟通条件。
场景目标：让勒索筹码失效，合力拆解敌方无人机攻击而不互相残害。
可见角色：绢旗、麦野、泷壶、芙兰达、Norsitro。
玩家行动：支持坦白、护住伤员、分享泷壶对Level0与无人机的识破，利用已观察到的设备共同弱点支援。
结果：原作麦野接纳冒死坦白的绢旗并保护她；Norsitro的天候表象被揭为无人机群。麦野应对雷击对电子束的干扰并逼至最后通牒，镜头切走处不另造尸体处置。
下一节点：ITEM-06-06。

ITEM-06-06 住院、搬家与电话之声
进入条件：ITEM-06-05完成，追击受控，伤员可以接受治疗。
场景目标：落实医疗、据点风险和队内关系，不把接纳绢旗误写成所有隐瞒都已毫无芥蒂。
可见角色：ITEM四人、实际参与治疗的黑医；Hanano Choubi与职位顶替者仅在明确切换尾声视角时出现。
玩家行动：协助就医、确认通信漏洞修补、安排搬离与后续联络，或选择观察独立的上层尾声。
结果：原作绢旗经手术及输血后住院，漏洞已补但残党不明，四人搬离据点。独立尾声中Hanano杀死职位顶替者、夺回电话之声身份，怒意指向第六位；顶替者不是Norsitro，四人不自动知晓该场面。
下一节点：无；同年冬季散点查前史与SS2节点索引，跨入Y年须明确换年，不自动开启暗部大战。
