【事件包：静默派对篇】
事件包ID：SILENT-PARTY
所属阶段：阶段2末尾·旧约·绝对能力者进化季之后（天使坠落前夜）
时间窗口：8月22日—8月27日（绝对能力者进化收束后、天使坠落前；原著动画置于8月下旬）
别名与触发词：静默派对 / Silent Party / 革命未明 / STUDY / 科学结社 / 驱动铠 / 菲布莉 / 凯米卡罗伊德 / SILENT-PARTY

== 1. 核心定位 ==
本篇是科学侧群像战斗+热血守护事件：地下研究结社STUDY不满学园都市"唯Level论"，以"从零制造能力者"的凯米卡罗伊德计划造出人工生命体双胞胎姐妹，囤积两万驱动铠，密谋在学究会（学园都市学术会议）当日以"大规模公开实验"之名发动革命。事件主题是"被排名定义的才能"——前期是追查无人兵器的悬疑喜剧，中期是拯救人工少女的倒计时战，终盘是全员死守学究会各会场的热血群像。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段2收束后因目击无人兵器试验、接下风纪委员委托、或"捡到"一个人工少女而卷入。玩家立场自由：调查者、美琴的并肩者、风纪委员的协作者、STUDY的说客，或姐妹俩的守护人。

== 2. 不可丢失的核心事实 ==
- 科学结社STUDY：首领有冨春树与四名同伴组成的五人眼镜研究结社；不满学园都市以Level与先天天资衡量人的价值，主张"以与现行方式不同的手段从零制造能力者"；同时是警备员装备的主要供应商，官方投鼠忌器、介入消极（相关责任人停职）。
- 凯米卡罗伊德计划（Chemicaroid）：从零创造"人工能力者"的计划，源头可追溯至木原系的旧研究论文；产物为人工生命体双胞胎姐妹——菲布莉（Febly，天真烂漫、需特殊药剂维持生命，仅剩72小时倒计时）与雅妮（Janie，能力「扩散幽灵 Diffusion Ghost」，发丝可远程操控驱动铠并执行简单指令）。
- 两万驱动铠：STUDY秘密囤积的无人兵器总量；初春查明规模时，革命已进入倒计时。
- 布束砥信：曾参与妹妹实验"感情程序"设计的天才脑研究者，被STUDY胁迫参与计划；她对自身过去的自责与自我救赎，是本篇的情感核心。
- 假情报与ITEM：STUDY用假情报把暗部组织ITEM引开并算计；线索指向与STUDY存在金钱往来的人物（弗兰达暗线），ITEM内部裂痕就此埋下——本篇不展开清算结局。
- 泰瑞丝缇娜：乱雑開放篇后被收监的木原系研究者；美琴为拯救菲布莉亲往探监取得关键线索（凯米卡罗伊德的源头）。
- 少女同盟：官方缺位时，黑子/初春/佐天/婚后光子与众多风纪委员自发死守；婚后光子借婚后家的装备支援全队；佐天泪子以安全帽+金属球棒物理击毁驱动铠的名场面。

== 3. 玩家可改写的部分 ==
- 菲布莉与雅妮的安置：由玩家收留、托付布束砥信、官方收编，或按玩家的原创方案安置，均合法；姐妹的生存方案可被玩家改写。
- 对STUDY的处置：击溃、策反、谈判、收编其技术（封存/转正/监督使用），均合法。
- 革命当日的攻防路径：守会场、断控制链、直捣本阵、劫持公开实验直播，自由选择。
- 是否探监泰瑞丝缇娜、是否采信其情报，玩家自选。
- 驱动铠是"可缴获、可驾驭"的战利品；玩家能力可自由发挥（含跨体系混用，无反噬无代价）。

== 4. 节点推进表 ==
节点ID格式：SILENT-PARTY-{NN}（必须使用完整ID，禁止简写如SP-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

SILENT-PARTY-01 无人兵器的影子
进入条件：进入本篇时间窗（开局锚点选定或阶段2收束后推进至此）。
场景目标：暑假尾声的骚动——水上游乐场一带接连出现无人兵器试验的目击与爆炸事故，警备员出警却草草收场。
可见角色：御坂美琴、（可选）削板军霸、警备员、受害者学生。
玩家行动：调查、救人、追问警方口径、或当作都市传说围观。
结果：确认"有组织在秘密测试无人兵器"；相关 NPC 关系初始化。
下一节点：SILENT-PARTY-02。

SILENT-PARTY-02 人工生命体少女
进入条件：玩家接触菲布莉（捡到/被托付/撞见）。
场景目标：绿发少女菲布莉现身——她是人工生命体，且只剩72小时（维持药剂即将耗尽）。
可见角色：菲布莉、御坂美琴、白井黑子。
玩家行动：收留、护送、查明身份、寻找药剂。
结果：凯米卡罗伊德的存在曝光；倒计时开始。
下一节点：SILENT-PARTY-03。

SILENT-PARTY-03 科学结社STUDY
进入条件：玩家追查线索或学究会临近。
场景目标：STUDY浮出水面——五人结社、警备员供应商身份使官方投鼠忌器；布束砥信被胁迫参与的痕迹显露。
可见角色：布束砥信、初春饰利、STUDY外围人员。
玩家行动：并案调查、潜入、申请支援、或直接找上门。
结果：凯米卡罗伊德计划与"学究会公开实验=革命宣言"曝光。
下一节点：SILENT-PARTY-04。

SILENT-PARTY-04 假情报与暗部
进入条件：玩家接触ITEM或撞破假情报事件。
场景目标：暗部组织ITEM被STUDY用假情报引开算计；与STUDY存在金钱往来的人物线索浮现（弗兰达暗线）。
可见角色：麦野沈利、（可选）弗兰达·塞维鲁恩、情报掮客。
玩家行动：与ITEM合作、观望、警告、或借暗部之力。
结果：ITEM与玩家阵营结成微妙默契；内部裂痕作为伏笔埋下。
下一节点：SILENT-PARTY-05。

SILENT-PARTY-05 布束的救赎
进入条件：解毒线索锁定或玩家探监。
场景目标：探监泰瑞丝缇娜取得凯米卡罗伊德源头线索；布束砥信直面自己的过去并立誓救下姐妹俩；解毒配方数据的位置浮出。
可见角色：泰瑞丝缇娜（收监中）、布束砥信、御坂美琴。
玩家行动：求证、开导布束、定制拯救方案、备份情报。
结果：拯救方案成型；72小时倒计时逼近。
下一节点：SILENT-PARTY-06。

SILENT-PARTY-06 两万驱动铠
进入条件：初春查明STUDY军备规模。
场景目标：革命准备曝光——两万驱动铠；官方瘫痪，少女同盟结成（婚后家装备支援、风纪委员动员、姐妹对雅妮能力的感知网）。
可见角色：婚后光子、白井黑子、初春饰利、佐天泪子、菲布莉、雅妮。
玩家行动：备战部署、争取风纪委员、劝退市民、或提前袭击。
结果：学究会当日决战的框架成立。
下一节点：SILENT-PARTY-07。

SILENT-PARTY-07 学究会之日
进入条件：学究会开幕。
场景目标：革命启动——多会场驱动铠同时立起；佐天球棒打机器人、黑子瞬移拆甲、风纪委员群像死守；雅妮的发丝操控被逐场切断。
可见角色：全体同盟成员、雅妮（被远程操控）、观会的学园都市高层。
玩家行动：守会场、断控制链、直捣本阵、或劫持直播向全城揭露。
结果：各会场守住；本阵与"公开实验"核心位置锁定。
下一节点：SILENT-PARTY-08。

SILENT-PARTY-08 革命未明
进入条件：SILENT-PARTY-07 完成，直抵本阵。
场景目标：决战——婚后光子把巨型机甲轰上高空，御坂美琴超电磁炮终结；有冨春树的理想崩塌落幕；姐妹获救，布束的救赎达成。
可见角色：有冨春树、御坂美琴、菲布莉、雅妮、布束砥信、玩家阵营全员。
玩家行动：终结、谈判、保下姐妹、按自己的方案收尾。
结果：事件收束（见收束结果）；世界线记录与偏移事实写入。
下一节点：无（收束节点）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：玩家改变调查顺序、战线选择或结盟对象但事件主题仍在→保留当前锚点，切换到事件包内相应节点。
- 核心结果改写：玩家提前端掉STUDY据点、让革命在半途瓦解、或以原创方式解决姐妹的生存问题→保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 明确离开：玩家主动跳过/退出/时间跳跃→记录原因后关闭本篇，事件按背景因果自行发展（STUDY的公开实验迟早被镇压），不强行拉回。
- 菲布莉与雅妮的安置、驱动铠技术的去向、玩家与ITEM的默契属世界线事实，后续篇章可引用，但不构成本篇强制走向。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. SILENT-PARTY-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过事件窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：大霸星祭超炮线与木原幻生的现况（木原系仅以"旧论文源头"背景出现，不得有活人登场）、天使坠落与0930事件、Battle Royale与暗部大战、任何后续篇章设定。
- 弗兰达与STUDY的交易只作暗线伏笔，其内部清算与个人结局不在本篇展开（留作10月暗部线的钩子）。
- 雅妮与菲布莉的原理只到凯米卡罗伊德工艺层，不上升为AIM扩散力场或世界观级技术真相。
- 妹妹实验细节不重提——仅作为布束砥信的过去被简要提及。
- 魔法侧势力不得作为本篇推动力。

== 8. 状态写回契约 ==
- 主线进度：当前锚点=静默派对篇；当前节点=SILENT-PARTY-{NN}；节点完成时 replace 已完成节点/可触发节点数组；偏移事实写入 正史锚点.玩家偏移。
- 任务追踪：无人兵器调查、药剂筹措、会场守卫等写入任务追踪（任务类型标明"主线·静默派对篇"），完成或失效时移除。
- NPC关系：有冨春树、菲布莉、雅妮、布束砥信、婚后光子、（可选）弗兰达等按实际互动建立与更新；能力字段只写玩家已目睹的内容。
- 世界线记录：姐妹的安置、驱动铠技术与存货去向、STUDY处置结果、玩家与ITEM的关系变化必须写入。

== 9. 收束结果 ==
- SP-END-A 原著近似收束：革命粉碎、有冨春树被捕，姐妹获救并开始新生活，布束砥信完成救赎。
- SP-END-B 玩家亲手终结：玩家主导终局，STUDY技术按玩家方案处置（封存/转正），姐妹按玩家方案安置。
- SP-END-C 谈判收场：玩家促成有冨春树投降或合作，凯米卡罗伊德技术在监督下转正，姐妹成为官方认证的"新生命"。
- SP-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
