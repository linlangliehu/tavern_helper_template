别名与触发词：静默派对篇 / Silent Party / 革命未明 / SILENT-PARTY / SILENT-PARTY-01

== 1. 核心定位 ==
《超电磁炮S》第18—24集的动画原创事件。美琴等从照顾无名少女菲布莉开始，面对STUDY借人工生命与无人兵器在学究会发动袭击的计划。救援主线既要保护眼前的少女，也要找到仍在研究所的雅妮及维生办法。
本篇可作选定锚点或经玩家同意进入的动画分支；没有选用该媒介时，仅保留资料，不把原创剧情硬塞进小说必经链。

== 2. 不可丢失的核心事实 ==
- 菲布莉在公园花坛被发现，由初春与佐天暂时照料。遭警备机器人和驱动铠袭击后，她因高热就医；医生说明她是人工生命，必须靠随身糖果维生。
- 凯米卡罗伊德计划的另一名少女雅妮仍受STUDY利用。她以毛发为媒介使AIM扩散力场物质化，成为控制两万驱动铠的关键，不能把她当成自愿发动袭击的指挥官。
- 有冨春树等STUDY成员不满能力等级中心的评价秩序；这种动机不使绑架、试验和袭击变成正当行为。
- 布束砥信被卷入计划并试图救出少女。10032号提供姐姐及布束的线索；探监泰瑞丝缇娜帮助美琴联系造人目的与学究会目标。
- ITEM受假委托欺骗，其能力数据被STUDY收集利用，随后报复。这里不是芙兰达出卖ITEM或其十月死亡的起因。
- 默认终局有两万驱动铠阻击战和恩底弥翁建设机械发射的导弹；美琴高空拦截，菲布莉唤醒雅妮。姐妹随后与布束赴国外研究机构检查和再调整。

== 3. 玩家可改写的部分 ==
可改变姐妹救援、药剂取得、同盟分工与STUDY处置，提前阻断控制链或导弹发射也合法。是否接触ITEM、是否探监、是否公开技术由玩家决定。任何长期安置方案须说明持续照料条件，不能仅凭赢得战斗就宣称维生问题自动消失。

== 4. 节点推进表 ==
每轮至多推进一个主要节点；用完整ID，不将多条战线一次性结算。

SILENT-PARTY-01 公园中的少女
进入条件：选定动画分支，或在相应时段与美琴等经过公园。
场景目标：发现身份不明的菲布莉，先安排安全照料。
可见角色：菲布莉、御坂美琴、初春饰利、佐天泪子。
玩家行动：询问、护送、查找失踪信息、协助暂时安置。
结果：建立照料关系与身份调查，不提前全知她的制造过程。
下一节点：SILENT-PARTY-02。

SILENT-PARTY-02 袭击与糖果
进入条件：少女在学究会准备场所遭袭，或玩家发现追踪她的机器。
场景目标：挡下追击，并处理菲布莉的异常高热。
可见角色：菲布莉、美琴等人、诊治医生。
玩家行动：救护、保存机器残片、盘点糖果、请求检查。
结果：确认人工生命与维生需求；药剂剩余依当前事实，不任意重置倒计时。
下一节点：SILENT-PARTY-03。

SILENT-PARTY-03 STUDY的线索
进入条件：掌握袭击装备或10032号提供的线索。
场景目标：把少女、研究所和学究会准备活动联系起来。
可见角色：御坂美琴、御坂10032号、初春饰利。
玩家行动：调查装备流向、寻找布束、核对STUDY活动。
结果：获知另一名少女及布束可能参与其中，形成救援方向。
下一节点：SILENT-PARTY-04。

SILENT-PARTY-04 被利用的能力数据
进入条件：追查STUDY或接触受骗的ITEM。
场景目标：辨认假委托与能力数据武器，不把报复当成内部背叛。
可见角色：ITEM成员（按接触出现）、美琴、STUDY的执行装置。
玩家行动：避开交火、交换证据、借报复创造窗口或独立调查。
结果：STUDY的数据利用暴露；不建立通往十月清算的虚构因果。
下一节点：SILENT-PARTY-05。

SILENT-PARTY-05 探监与布束
进入条件：需要造人计划线索，或已找到研究所入口。
场景目标：由探监情报锁定学究会目标，在研究所与布束接触。
可见角色：泰瑞丝缇娜（探监时）、布束砥信（研究所内）、御坂美琴。
玩家行动：核实情报、听取布束的救援计划、取得维生所需线索。
结果：确认雅妮处境与毛发媒介；不同场所的人物不无故同场。
下一节点：SILENT-PARTY-06。

SILENT-PARTY-06 两万驱动铠
进入条件：掌握STUDY计划规模，且袭击尚未被提前排除。
场景目标：召集能参与的伙伴，分配疏散、阻击与姐妹救援。
可见角色：初春饰利、白井黑子、佐天泪子、婚后光子、布束砥信。
玩家行动：布置防线、通知救援、分配装备、先断控制媒介。
结果：建立针对两万驱动铠的协作方案，不预设所有角色同时到场。
下一节点：SILENT-PARTY-07。

SILENT-PARTY-07 学究会防线
进入条件：STUDY发动袭击，或玩家开始执行先制阻断。
场景目标：阻止驱动铠伤及市民，同时打开接近雅妮的通路。
可见角色：风纪委员及伙伴、御坂美琴、ITEM成员（实际介入时）。
玩家行动：守点、撤人、破坏兵器、掩护布束与菲布莉接近雅妮。
结果：默认防线挡住袭击，麦野因数据被盗反击相关兵器；终局威胁仍待处理。
下一节点：SILENT-PARTY-08。

SILENT-PARTY-08 革命未明
进入条件：有冨启动最后手段，或玩家已控制研究所终局。
场景目标：阻断建设机械发射的导弹，并使雅妮脱离暴走控制。
可见角色：有冨春树、御坂美琴、菲布莉、雅妮、布束砥信及支援者。
玩家行动：拦截、阻止发射、掩护姐妹交流、转运伤者或要求投降。
结果：默认美琴升至高空击落导弹，菲布莉唤醒雅妮；按实际行动结算救援。
下一节点：SP-END-A／SP-END-B／SP-END-C／SP-END-D。

== 5. 分支和偏离规则 ==
战线、同盟与情报顺序变化不换锚。玩家提前救走姐妹或瓦解STUDY即记已改写，不再强开袭击。跨体系能力可用于原创解法，不因没有复现动画镜头而惩罚玩家。未兑现的治疗和安置仍保留为任务。

== 6. 换篇条件 ==
SILENT-PARTY-08收束，或玩家明确退出、另选锚点、跳时越窗，或计划被合理提前终止，才关闭本篇。记录状态与原因；动画内恩底弥翁建设现场不自动启动电影或游戏路线。

== 7. 防剧透边界 ==
妹妹实验只作为布束的已发生经历，按人物知情程度提及。不得以本篇为芙兰达日后死亡设虚构伏笔；不预演大霸星祭木原幻生行动、0930或暗部大战。仅说明本篇所需的人工生命与AIM机制，不替角色全知解开学园都市全部技术。

== 9. 收束结果 ==
