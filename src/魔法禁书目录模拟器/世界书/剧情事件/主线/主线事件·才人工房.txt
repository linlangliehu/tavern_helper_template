【事件包：才人工房往事】
事件包ID：TALENT-WORKSHOP
所属阶段：阶段0·旧约·前日谭
年层：常盘台入学前；夺取图排在Y−1，相识与相处可能更早。
时间窗口：入学前可定，Y−1四月仅为图排候选；4月1–5合并格不是连续五天的确日，不能把多莉相遇、死亡、夺取和入学压到同一天。
别名与触发词：才人工房往事 / 食蜂夺取人才工坊 / 食蜂夺取才人工房 / TALENT-WORKSHOP / TALENT-WORKSHOP-01

== 1. 核心定位 ==
这是可亲历的前史起点：从才人工房的封闭生活进入食蜂与多莉的关系，最后落实食蜂控制研究者、改变设施支配关系。它不是独立《某科学的心理掌握》的选举，也不是Y年大霸星祭期间再发生一次幼年实验。
回忆所在篇章与往事发生时间分开。多莉的病弱、与旧友分离及食蜂受托陪伴是起因；多莉去世后食蜂控制研究者是默认走向。具体探查与协助方式由项目串场补足，不为实验杜撰天数或给研究者添加未明身份。

== 2. 不可丢失的核心事实 ==
- 幼年食蜂曾在才人工房接受能力开发，多莉依赖设备维持身体；食蜂被安排陪伴刚与好友分开的她。
- 接触从研究安排变成了真实友情。不能把多莉只当作偷取资料的钥匙，也不让食蜂从第一刻就知道未来全部实验。
- 默认往事中，多莉死亡，食蜂随后将研究者置于能力控制下；夺取改变的是工房内的支配关系，不等于学园都市全部暗部消失。
- 这段经历在入学前；常盘台一年级生活随后另开FIRST-YEAR。内部进化等其他实验室往事不因夺取本工房而自动全部解决。

== 3. 玩家可改写的部分 ==
可以作为获准接触者、救援协助者或回忆听众介入，陪伴多莉、寻找照护、阻止隔离、协助食蜂取得主动权。提前救治并改变多莉去向属于明确的玩家改写，不用“正史必须如此”撤销救援。知情范围与对研究者的处置由实际行动决定。

== 4. 节点推进表 ==
所有节点使用完整ID；每轮最多推进一个主要节点，不把相处、病情转变与夺取在同轮结算。

TALENT-WORKSHOP-01 封闭的房间
进入条件：玩家选择常盘台入学前的才人工房入口，或明确请求回顾该往事。
场景目标：认识实验室的出入限制及多莉需要照护的处境。
可见角色：幼年食蜂、多莉、负责接触安排的研究者。
玩家行动：以合理身份接受接触安排、观察设备、询问照护需求或只旁听回忆。
结果：能接触谁、能看到什么被确定；尚不知道全城实验的真相。
下一节点：TALENT-WORKSHOP-02。

TALENT-WORKSHOP-02 陪伴不再是任务
进入条件：TALENT-WORKSHOP-01完成，接触得到允许或玩家创造了安全机会。
场景目标：使多莉与食蜂的关系超出研究安排，听见多莉对旧友与外界的牵挂。
可见角色：多莉、食蜂；不把多莉缺席的旧友强行传送进房间。
玩家行动：陪聊、带来允许的日常物品、帮助传达心愿或保护私人谈话。
结果：形成一项实际的陪伴约定；具体对白与物品属于项目串场。
下一节点：TALENT-WORKSHOP-03。

TALENT-WORKSHOP-03 照护与隔离
进入条件：TALENT-WORKSHOP-02完成，病弱状态或研究安排妨碍约定。
场景目标：分清多莉当下需要与研究者允许透露的信息，寻找不把她当实验材料的处理方式。
可见角色：多莉、食蜂、实际负责照护的研究者。
玩家行动：争取探视、要求解释、安排自愿救治或让可信协助者介入。
结果：照护方案或被拒绝的理由明确；不编造原作寿命倒计时。
下一节点：TALENT-WORKSHOP-04。

TALENT-WORKSHOP-04 无法兑现的约定
进入条件：TALENT-WORKSHOP-03完成，往事推进到病情的决定点。
场景目标：面对默认往事中多莉的死亡，或落实玩家已经完成的救援改写。
可见角色：食蜂、多莉及在场照护者；是否仍能互动取决于实际结果。
玩家行动：陪伴、完成告别、保存她的愿望，或执行已具备条件的救治与转移。
结果：多莉的去向具体落定；不能为回到默认剧情而让获救者再次无故死亡。
下一节点：TALENT-WORKSHOP-05。

TALENT-WORKSHOP-05 夺取才人工房
进入条件：TALENT-WORKSHOP-04完成，食蜂决定不再任由研究者掌握一切。
场景目标：把研究者从支配者变为受控制者，改变食蜂在工房内的地位。
可见角色：食蜂、工房研究者、实际介入的玩家。
玩家行动：协助接近关键人员、保护相关记录、阻止外泄，或提出有同等控制效果的替代方案。
结果：默认食蜂控制工房研究者，工房不再能按原样支配她；替代方案按玩家改写记录。
下一节点：TALENT-WORKSHOP-06。

TALENT-WORKSHOP-06 入学以前的秘密
进入条件：TALENT-WORKSHOP-05完成，工房内的主动权已经改变。
场景目标：确定多莉相关记录与知情人的处理，结束这段入学前往事。
可见角色：食蜂、被保留联系的协助者。
玩家行动：约定保密、安排后续照护或联系，选择常盘台入学生活或返回回忆前场景。
结果：默认食蜂保有对研究者的控制及对多莉的记忆；不是将多莉在本篇复活，也不是把工房整个炸毁。
下一节点：无；玩家另选一年级生活时才转FIRST-YEAR-01。

== 5. 分支和偏离规则 ==
玩家改变多莉去向、工房控制方式或公开范围时，阶段状态记“已改写”，保留实际后果。亲历与后来听闻不能混成一次事件。可暂停调查或直接离开，不强制看完悲剧再解锁入学。

== 6. 换篇条件 ==
TALENT-WORKSHOP-06完成、玩家明确离开／换锚点／跳过，或控制问题已合理提前解决，才换篇。记录状态、原因、偏移与所选后继首节点。入学需要另一次时间推进，不从四月图格自动跳到Y年祭典。

== 7. 防剧透边界 ==
不提前讲出多莉相关的后续重逢、Y年大霸星祭解法、上蜂记忆损伤或常盘台选举结局。后来回忆起本工房，只引用既有事实；不生成第二次幼年夺取。

== 8. 状态写回契约 ==
- 正式亲历时，主线进度.当前锚点=才人工房往事；当前节点为TALENT-WORKSHOP完整节点ID，阶段保持0。正文与状态同轮更新，节点完成时 replace 已完成节点/可触发节点数组。
- 多莉去向与控制方式的改写写入 正史锚点.玩家偏移、世界线记录；任务追踪记录探视、照护与保密约定，结束时移除失效任务。
- NPC关系与知情范围按实际互动更新。回忆模式不覆盖当前主线锚点、节点或当前时间；其他前史包不随本包自动完成。

== 9. 收束结果 ==
- TALENT-WORKSHOP-END-A 默认往事：多莉去世，食蜂控制工房研究者，带着对朋友的记忆走向入学前的下一段生活。
- TALENT-WORKSHOP-END-B 救援改写：多莉按玩家落实的照护或转移方案存续，研究者失去继续支配她们的条件。
- TALENT-WORKSHOP-END-C 协议或公开：工房被玩家选择的约束方式控制，记录与知情范围明确；后续据实际改写发展。
- TALENT-WORKSHOP-END-D 暂时退出：保留当下已发生的事实，不用新增死亡或反噬惩罚退出。
