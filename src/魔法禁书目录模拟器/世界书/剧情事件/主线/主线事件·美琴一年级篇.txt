【事件包：美琴一年级篇】
事件包ID：FIRST-YEAR
所属阶段：阶段0·旧约·前日谭（回忆窗2，与美琴过去篇同属回忆层，可并行互认）
时间窗口：美琴一年级学年（入学～次年新学期黑子入学；回忆性时间窗，相对时序，不与主时间轴日历强制对齐）
别名与触发词：美琴一年级 / 一年级篇 / 常盘台派阀抗争 / 三大派阀 / 永代姬君 / 沙淡扇 / 水镜凪纱 / 支仓冷理 / 琉璃学姐 / 洁斋雪紫 / FIRST-YEAR

== 1. 核心定位 ==
本篇是阶段0的第二个回忆型主线事件（回忆窗2）：原著超炮漫画最终章「御坂美琴一年级编」（第17～21卷）的完整改编。围绕美琴入学常盘台第一年爆发的"三大派阀抗争"与企业黑手展开——沙派阀、水镜派阀、支仓派阀为"永代姬君"之位明争暗斗，Mongolfiere社与安提基特拉社在幕后搅动，而最大派阀首领沙淡扇的真实目的，是为被常盘台抹杀的养姐武林夜宵复仇。终盘黑子入学、常盘台歼灭计划发动，美琴与沙淡扇决战收束。
本篇与美琴过去篇共同回答"超电磁炮是怎样炼成的"：美琴过去篇讲"名号之重"，本篇讲"名门之暗"——王冠背后派阀、企业、家族三代黑手如何把一群大小姐逼成战士。美琴的习惯（安全裤、泡泡袜、踢自动贩卖机、反手提包）全部源自本篇的琉璃学姐。
玩家进入本篇的方式：开局锚点直选"美琴一年级篇"；或阶段0日常中以转学生/插班生/访客身份进入常盘台；或在当下时间线与美琴聊起"一年级往事""派阀传闻"触发重述模式。两种模式（亲历/重述）与美琴过去篇同规则，可混合。

== 2. 不可丢失的核心事实 ==
- 美琴的Level 5认定：入学当月（4月）能力测定即认定Level 5，但当时被讥为"超能力者最弱""与Level 4擦线"；名号与实力都是此后一年打出来的。同期入学的食蜂操祈入学前就已是Level 5，此时点两人尚无派阀、无恩怨。
- 派阀制度：常盘台的学生派阀是半公认团体，有派阀栋；将最大派阀首领之位维持一年以上并保持到毕业者获称「永代姬君（Majesty）」，毕业后保证统括理事会席位等出世路线——这是三大派阀倾轧的制度根源。
- 三大派阀（美琴入学时点）：①沙派阀——首领沙淡扇（2年级），占全校23%，以「有力者与天赋者之责务」为理念行慈善，人望最高；沙淡扇人称「保健室的女帝」，病弱易碎、携熊猫玩偶腹语代言。②水镜派阀——首领水镜凪纱（3年级），19%；能力「油性操作（Oil Direction）」可操持油脂与身体脂肪（丰胸瘦腰的民生妙用），宝石商五姐妹末女，本性胆小只想安稳却意外成为首领，只对派阀有贡献者使用能力。③支仓派阀——首领支仓冷理（3年级），17%，建派最古；能力「氢键合（Hydrogen Station）」Level 4；京都茶道世家、学年主席级才媛，两任Level 5出现前的"常盘台最强"；无执行部全员平等，战力却是三阀之首。
- 抗争爆线：支仓派阀学生炎乘与水镜派阀学生花山院口角后，花山院被疑似炎乘能力者袭击 → 水镜派阀袭击支仓派阀 → 支仓好战成员安赌蜴吹禾报复袭击水镜凪纱，抗争全面爆发。
- 美琴首秀：新科Level 5的美琴在派阀混战中以一敌四介入，超电磁炮初度校内扬名；食蜂操祈同为主力介入——本篇是"常盘台两大Level 5"的首次同框。
- 企业黑手：Mongolfiere社在幕后搅动派阀抗争，被美琴、食蜂与三大派阀联合揭发挫败；其背后真黑手是安提基特拉社（Antikira社，即"安提基特拉"之名），同样被三大派阀共同作战打垮——但支仓冷理与琉璃学姐总觉得事件流程有违和感（伏笔）。
- 食蜂派阀的起点：Mongolfiere事件平息后，食蜂操祈决意结成自己的派阀——日后常盘台最大派阀的起点在本篇。
- 武林夜宵悲剧：前代最大派阀（武林派阀）首领、几乎确定的永代姬君候补武林夜宵，因企业鍛嶺化学拉致派阀成员，为救人造成重大损害被逮捕；常盘台抹消其入学记录、永代姬君资格随之消灭，夜宵最终在少年院自尽。她是沙淡扇与洁斋雪紫在武林家的养姐。
- 沙淡扇的真面目：夜宵的养妹。表面是病弱慈善家，实际短气粗暴、腹语玩偶只是敬语人设道具；视派阀成员为"温室大小姐"棋子，唯独把雪紫当亲妹疼爱。其复仇目标：见死不救并抹杀夜宵的常盘台中学——常盘台歼灭计划。
- 能力再现权能：沙淡扇就任永代姬君后，获得"从他人持有物再现其能力"的权能（常盘台暗制度级设定）；御坂美琴的发卡是再现其能力的必要媒介。
- 雪紫的挣扎：双面间谍（明面受支仓派阀指示监视美琴，实际效命沙淡扇），却真心待美琴如友（说教、护发卡、拌嘴中提醒上课）；最终在"不得伤害美琴"为条件的心痛下，交出了美琴的发卡。
- 终盘：次年新学期白井黑子等新入生入学；常盘台相关要人与企业连续遭"能力再现"袭击，全校被疑，美琴食蜂遭监视拘束；黑子以风纪委员身份从177支部遗留讯息逼近真相（琉璃学姐留下的情报）；最终美琴与沙淡扇决战，雪紫的说得与以身涉险成为扭转关键。
- 琉璃学姐（神苑小路瑠璃悬巢）：三年级无派阀实力者，三大派阀都忌惮；实为风纪委员（低年级无人知晓）；太妹装扮+呱太眼双马尾；是美琴几乎所有标志习惯的源头（安全裤、泡泡袜、踢自动贩卖机、反手提包），魔之自贩机吞万日元是两人结识的喜剧开端。
- 战斗基调：派阀学生战以Level 3-4能力混战为主，美琴的超电磁炮是"格"的压制；企业线涉及武装集团与能力再现的诡计战；玩家能力跨体系混用无反噬。

== 3. 玩家可改写的部分 ==
- 派阀站位：玩家可加入任一派阀、自立小派阀、或当无派阀的"琉璃学姐二号"；三大派阀的势力消长可改写。
- 抗争走向：花山院遇袭案可被玩家提前侦破（企业黑手提前暴露）、安赌蜴吹禾的报复可被阻止、水镜凪纱可被玩家护住。
- 企业线：Mongolfiere社与安提基特拉社的败露方式、是否连根拔起、鍛嶺化学旧案是否翻出，玩家自由。
- 武林夜宵悲剧：玩家可改写夜宵被捕后的走向（洗冤、越狱式救援、迟来的正名），或在终盘改写沙淡扇的结局（拯救、救赎、放逐、自立门户均可）。
- 发卡危机：玩家可阻止雪紫交出发卡、夺回发卡、或以自己的持有物顶替美琴卷入权能——代价与后果如实记录。
- 黑子的开局：黑子入学与首功可由玩家协助、抢功或改写；雪紫与黑子的碰撞可缓和可激化。
- 与美琴/食蜂的关系：陪练、军师、共犯、损友皆可；本篇建立的关系按重述模式规则同步到当下时间线。
- 本篇为回忆窗：允许玩家不完全参与（旁观回忆流），不强制节点逐个点亮。

== 5. 偏离与改写 ==
- 上述节点与结局是"原著重力线"，不是唯一路径：玩家可在任意节点改写站位、阵营、手段与结果。
- 篇章内偏离：允许把本篇玩成校园政治剧/侦探剧/热血格斗/吐槽日常的任意混合，只要不覆盖核心事实（三大派阀格局、永代姬君制度、武林夜宵悲剧、沙淡扇的复仇）。
- 核心结果改写：派阀抗争被玩家提前平息、夜宵获救、沙淡扇被救赎或彻底黑化、美琴未能在校内扬名等，均合法——以玩家偏移事实记录，不得静默回滚。
- 重述模式偏离：当下的对话可揭出与"官方版本"不同的真相细节，作为回忆的补充层。
- 明确离开：玩家声明退出时按第9章 FY-END-D 收束，事件转为背景自行推进。
