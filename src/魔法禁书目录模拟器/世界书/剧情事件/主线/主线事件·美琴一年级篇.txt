【事件包：美琴一年级篇】
事件包ID：FIRST-YEAR
所属阶段：阶段0·旧约·前日谭
年层：Y−1学年为主体，至Y年春交接；Y是旧约1所在的本篇年。
时间窗口：Y−1入学后的春季起，跨学年衔接到Y年春；五月、六月、十月等图排仅为候选，不作逐日行程。
别名与触发词：美琴一年级篇 / 常盘台三派阀往事 / 一年级学年交接 / FIRST-YEAR / FIRST-YEAR-01

== 1. 核心定位 ==
本篇以美琴入学、结识雪紫与琉璃、接触三大派阀及跨学年交接为主干。漫画一年级篇从17卷起；本次叙事边界按20卷与连载169话分别理解，不能宣称“17–21卷完整终章”，也不把卷数与话数互相推算。
已知人物关系与派阀格局作为底色；校内风波的调查、协商与过渡场景采用项目串场。五月生日礼物与支仓指导、六月风波、十月建派阀等日期是图排候选。武林旧案、剧院失火、绝对等速和未确定的终战细节只留线索，不编成已确认的整条因果。
亲历从Y−1开始；后来重述只是在当前场景回顾。Y年详细续段可另选MIKOTO-PAST，不用两个包重演同一次学年交接。

== 2. 不可丢失的核心事实 ==
- 入学时美琴已是Level 5；食蜂是同期生。她们的实力、名号、人际关系不能被压缩为某天突然升级的同一事件。
- 雪紫是Y−1美琴的同期室友，属于支仓派阀，并受派阀指示留意美琴。雪紫真实的关心与派阀任务可以并存。
- 琉璃学姐是Y−1三年级的无派阀学生，受三大派阀重视；美琴被自动贩卖机吞钱后与她结识。不能把她的全部日常习惯都断言为唯一传承来源。
- 当时三大派阀分别由沙淡扇、水镜凪纱、支仓冷理率领；慈善、人际中的能力需求、向上心形成不同吸引力。美琴并非必须加入其中之一。
- Y年春美琴成为二年级生，黑子才以常盘台新生身份进入；黑子的入住与后续搭档关系另有过程。
- 三年级学姐的毕业、雪紫离校与新生入学不是同一个日期。Y年过去篇后半持续时间未知，不能拿回忆叙述顺序替代故事年月。

== 3. 玩家可改写的部分 ==
可以选择派阀站位、与雪紫坦诚沟通、和琉璃同行、接受或婉拒指导，调查流言而非直接参与报复。玩家可提前缓和冲突、组织无派阀互助、改变去留与毕业前约定；不会被强制送回某场终战。礼物内容、对话、调查手段与可协商结果属于项目改编，不能反称为原作台词或情节证据。

== 4. 节点推进表 ==
节点ID格式：FIRST-YEAR-{NN}，禁止简写。每轮最多推进一个主要节点；跨月、跨年必须先说明时间流逝并取得相应剧情依据。

FIRST-YEAR-01 魔之自贩机
进入条件：玩家选择Y−1入学后生活，或明确请求回顾这一学年。
场景目标：从美琴被自贩机吞钱、结识琉璃的日常认识常盘台，而非重新授予Level 5。
可见角色：一年级美琴、同期室友雪紫、三年级琉璃学姐。
玩家行动：帮忙交涉、陪同取回物品、认识学姐，或在听闻后询问雪紫。
结果：三人的日常关系形成入口；黑子、初春与佐天不自动成为此时的同校伙伴。
下一节点：FIRST-YEAR-02。

FIRST-YEAR-02 派阀地图与课余约定
进入条件：FIRST-YEAR-01完成，玩家愿意了解室友的活动。
场景目标：从雪紫介绍认识三派阀；可在图排五月候选中选一次生日礼物或支仓指导的课余场景。
可见角色：美琴、雪紫、支仓冷理；其他派阀人员按会面出现。
玩家行动：询问派阀规则、准备礼物、请求指导或坚持不入派阀；具体礼物与课程为项目串场。
结果：站位与一次约定明确；5月24–28的图格不被写成连续五天授课。
下一节点：FIRST-YEAR-03。

FIRST-YEAR-03 派阀风波
进入条件：FIRST-YEAR-02完成；按六月候选进入校内摩擦，或由玩家行为引出冲突。
场景目标：调查互相指控与报复风险，不先把每一次袭击、凶手及后台公司判成事实。
可见角色：美琴、雪紫、沙／水镜／支仓派阀相关学生。
玩家行动：询问当事人、比对证词、保护被针对者、向学姐求助或维持中立。
结果：确认一条可行动的线索，或指出指控证据不足；调查过程为项目串场。
下一节点：FIRST-YEAR-04。

FIRST-YEAR-04 电光介入
进入条件：FIRST-YEAR-03完成，纠纷已有可处理的对象。
场景目标：制止眼前冲突，给当事人提供脱离群体报复的机会。
可见角色：美琴、食蜂、相关派阀学生；到场需要各自理由。
玩家行动：协助救援、劝停、分开人群或提出证据；不要求两位Level 5每次都联手作战。
结果：本次摩擦被制止或转入协商，不把这次介入命名为原作唯一“名号首战”。
下一节点：FIRST-YEAR-05。

FIRST-YEAR-05 风波后的选择
进入条件：FIRST-YEAR-04完成，参与者有机会重新选择关系与立场。
场景目标：核对外部干预的线索，讨论是否建立新的互助关系；食蜂决定建派阀的十月落点仅为候选。
可见角色：美琴、食蜂、雪紫、愿意回应的派阀代表。
玩家行动：继续取证、促成互助、拒绝利用学生的委托，或离开派阀竞争。
结果：一次具体委托停止或有了保护措施；不自动宣告Mongolfiere及安提基特拉等公司均已被歼灭。
下一节点：FIRST-YEAR-06。

FIRST-YEAR-06 留待求证的旧案
进入条件：FIRST-YEAR-05完成；玩家继续本学年，或明确同意略过中间日常。
场景目标：整理可带入新学年的约定与疑问，区分事实、图排与传闻。
可见角色：雪紫、琉璃、玩家实际接触的学姐；沙淡扇的隐情不因提问自动公开。
玩家行动：请求当事人说明、保留未答问题、告别毕业生，或把武林／剧院／绝对等速线索留在资料索引。
结果：本学年关系得到记录；不凭旧案名编造死亡、家族身份、发卡权能或十二月决战。
下一节点：FIRST-YEAR-07；进入前须明确跨至Y年新学年，不能同轮跨完一年。

FIRST-YEAR-07 新学年的发卡与室友
进入条件：FIRST-YEAR-06完成且故事已明确来到Y年春；若仅回顾Y−1，可直接请求收束。
场景目标：确认学年变化，处理旧室友的物品和联系安排；发卡只是私人物品，不预定为某种能力媒介。
可见角色：二年级美琴、雪紫、以新生身份出现的黑子；毕业学姐只能以探访或回忆出现。
玩家行动：协助交接、见新生、与雪紫沟通；想详细调查时明确改选MIKOTO-PAST-01。
结果：新旧身份不混同；只采用雪紫离校的候选落点，不预定其理由或黑子立即入住。
下一节点：FIRST-YEAR-08；另选详细续段时按换篇规则转MIKOTO-PAST-01，不并推两包。

FIRST-YEAR-08 学年交接收束
进入条件：FIRST-YEAR-07完成，或玩家选择结束一年级回顾。
场景目标：结算派阀委托、未完成约定与去留，结束这一学年的叙事。
可见角色：实际参与交接者；回顾模式下仅有当前叙述者与听众。
玩家行动：确认联系、保留待问问题、选择新学年日常或其他事件。
结果：默认本次风波已停止，约定归档，美琴转入二年级生活；采用离校候选时雪紫不再担任旧室友，不补写未经确认的终战。
下一节点：无；本包收束。

== 5. 分支和偏离规则 ==
改变派阀站位、提前平息冲突、挽留室友或改写毕业前安排均合法，以“已改写”和实际结果保留。中间月份可以留白，资料索引中的候选不是必须清完的任务。重述只更新当前听闻；不能因包名为“一年级”便抹去Y年已发生的关系。

== 6. 换篇条件 ==
FIRST-YEAR-08完成、玩家明确离开／跳过／换锚点，或故事合理提前收束，才换篇。转入MIKOTO-PAST时记录已发生的学年交接，详细续段不再次完成同一事实。记录本篇状态、原因、偏移事实与所选后继首节点；回顾结束回原场景。

不提前启动妹妹实验、幻想御手、Y年大霸星祭或独立心理掌握选举。才人工房夺取是常盘台入学前的另一事件，不在校内派阀冲突中重新发生。食蜂的派阀规模随时点变化；黑子不得提前作为Y−1室友。武林夜宮／夜宵名称对应、剧院失火、绝对等速话页及过去篇终局未定，只允许询问或明确的项目改编。
