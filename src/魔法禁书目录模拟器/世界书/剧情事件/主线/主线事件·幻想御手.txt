【事件包：幻想御手篇】
事件包ID：FANTASY-HAND
所属阶段：阶段0·旧约·前日谭
时间窗口：5月-6月
别名与触发词：幻想御手 / Level Upper / 能力增幅 / 水平线之诗 / 木山春生线 / 佐天泪子线

== 1. 核心定位 ==
本篇是阶段0的科学侧主线事件：学园都市内流传一种名为"Level Upper（幻想御手）"的神秘音频文件，使用者声称能力获得提升，随后陆续出现使用者昏睡、能力失控等异常。事件以都市传闻开始，以网络层面的异常爆发收束。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段0日常中主动追查传闻、结识相关人员。玩家可以是学生、风纪委员协助者、研究者、自由行动者等任意身份，不预设立场。

== 2. 不可丢失的核心事实 ==
- Level Upper 是在网络间私下传播的音频文件，宣称能提升能力等级；传闻先于真相存在，早期信息真假混杂。
- 使用 Level Upper 后确实出现能力短期增强的现象，但代价是使用者逐渐陷入昏睡、精神状态恶化；大量使用者陆续病倒。
- 事件牵涉一系列儿童失踪案的暗线；木山春生（一位年轻的女性研究者）与失踪儿童、Level Upper 的真正来源直接相关。
- 学园都市官方（警备员、风纪委员）会介入调查；初春饰利作为风纪委员成员参与数据与网络分析；佐天泪子作为 Level Upper 使用者之一被卷入。
- 事件收束于 Level Upper 网络的异常扩大与最终平息；木山春生的真实动机在事件后期才完整揭示。
- 本篇全部发生在学园都市内部，属科学侧事件；魔法侧组织不作为本篇的推动力登场。

== 3. 玩家可改写的部分 ==
- 何时接触 Level Upper：玩家可以拒绝接触、只做观察者、亲自试听、协助调查或阻止他人使用。
- 帮助对象与顺序：可以先救佐天、先协助初春分析数据、先追查失踪儿童、或直接追查木山春生。
- 调查方式：正面调查、私下收集情报、接近官方调查网、或利用自己的能力与关系网另辟蹊径。
- 对木山春生的处理：阻止、合作、谈判、寻找不牺牲任何一方的替代方案，均合法。
- 儿童失踪案的结局：原著中的遗憾可以由玩家改写为更好的结果（如提前救人、改变收束顺序）。
- 玩家能力可自由发挥（含跨体系混用，无反噬无代价），允许以原创方式改变事件走向。

== 4. 节点推进表 ==
节点ID格式：FANTASY-HAND-{NN}（必须使用完整ID，禁止简写如FH-01）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

FANTASY-HAND-01 传闻浮现
进入条件：进入本篇时间窗（开局锚点选定或阶段0推进至此）。
场景目标：玩家从同学、网络论坛或街头闲谈中得知 Level Upper 的存在与"用了就能变强"的说法。
可见角色：同学、路人、网络信息；佐天泪子/初春饰利可作为登场入口。
玩家行动：追问传闻、忽略、上网检索、结识知情者。
结果：玩家获得 Level Upper 传闻；相关 NPC 关系初始化。
下一节点：FANTASY-HAND-02。

FANTASY-HAND-02 首次接触
进入条件：玩家主动接触传闻（获取音频、目击他人使用、或认识使用者）。
场景目标：玩家近距离看到 Level Upper 的实际使用与效果（短期增强）。
可见角色：使用者若干；佐天泪子（若走佐天线）；初春饰利（若走风纪线）。
玩家行动：试听或拒绝；劝阻或旁观；向官方或民间渠道报告。
结果：玩家掌握第一手证据；"使用即变强"与"似乎有代价"的矛盾信息并存。
下一节点：FANTASY-HAND-03。

FANTASY-HAND-03 使用者异变
进入条件：本篇时间推进或玩家接触足够多的使用者。
场景目标：出现首批昏睡/异常倒下的使用者；流言开始转向恐慌。
可见角色：昏睡使用者、风纪委员或警备员、初春饰利。
玩家行动：救助、调查昏睡原因、保护身边人、隐瞒自己接触过的事实。
结果：事件从"都市传闻"升级为"公共异常事件"；玩家掌握异常的第一手线索。
下一节点：FANTASY-HAND-04。

FANTASY-HAND-04 调查网络铺开
进入条件：异常事件引起官方介入。
场景目标：风纪委员/警备员展开正式调查；玩家以协助者、平行调查者或被调查者身份卷入。
可见角色：初春饰利（数据分析）、官方调查人员、佐天泪子（若已被卷入）。
玩家行动：配合或规避官方；分享或保留线索；锁定"音频来源"与"儿童失踪案"两条线索方向。
结果：玩家与官方调查网建立联系（或对立）；儿童失踪案与 Level Upper 的关联开始显形。
下一节点：FANTASY-HAND-05。

FANTASY-HAND-05 幕后浮现
进入条件：玩家追查线索至一定深度（来源、失踪案、或异常使用者的共同点）。
场景目标：木山春生与她的研究进入玩家视野；失踪儿童的线索指向她。
可见角色：木山春生、其身边的人、失踪儿童相关者。
玩家行动：接近、试探、对峙、或尝试理解她的动机；玩家可以此时就选择改写儿童案走向。
结果：玩家得知 Level Upper 的真正来源与木山春生的目的（动机细节在此节点逐层揭示，不一次性托出）。
下一节点：FANTASY-HAND-06。

FANTASY-HAND-06 网络风暴
进入条件：Level Upper 网络规模扩大或玩家/官方的行动触动网络本体。
场景目标：网络异常扩大，大量使用者同时出现危险状态；事件进入最紧张阶段。
可见角色：木山春生、初春饰利、佐天泪子（状态视玩家此前选择而定）、官方力量。
玩家行动：进入网络层面解决问题、保护昏迷者、追击或谈判、联合各方力量。
结果：危机到达顶点；玩家的选择直接决定收束方式。
下一节点：FANTASY-HAND-07。

FANTASY-HAND-07 收束行动
进入条件：玩家已决定本篇的最终介入方式。
场景目标：执行玩家的收束方案（战斗压制、谈判化解、救援优先、技术性平息均可）。
可见角色：按方案决定（木山春生、官方、被保护者等）。
玩家行动：自由发挥，允许完全原创方案；AI 按玩家能力与准备合理演绎结果，不判定失败收场。
结果：网络异常平息或被引导收束；儿童案得到玩家选择范围内的最好结局。
下一节点：FANTASY-HAND-08。

FANTASY-HAND-08 篇章收束
进入条件：FANTASY-HAND-07 完成。
场景目标：事件结算——涉案人员安置、关系结算、玩家行为的世界线后果记录。
可见角色：本篇主要角色（余波互动）。
玩家行动：处理人际关系与后续安排；选择下一走向（日常休整 / 进入阶段1 / 自主跳转）。
结果：阶段状态更新，换篇入口开启。
下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：玩家改变行动顺序、帮助对象或调查方式时，保留当前锚点，在节点表内切分支推进；未走到的节点按因果顺延或合并。
- 核心结果改写：玩家提前解决儿童案、改变网络爆发规模、或以原创方式收束整场事件时，保留当前锚点，将阶段状态记为"已改写"，并写入世界线记录。
- 延后与跳过：玩家长期回避主线时，事件按背景因果缓慢自行推进（传闻扩散、官方介入），但不强制玩家参与；回到主线时以当时的世界状态续演。
- 原著角色的行动也随玩家偏移而变化，不强行复位到原著剧本。

== 6. 换篇条件 ==
仅以下事实之一允许离开本篇：
1. FANTASY-HAND-08 完成（本篇收束）。
2. 玩家明确要求跳过或离开本篇。
3. 玩家明确选择新的时空锚点。
4. 玩家明确进行时间跳跃并跨过 5-6 月窗口。
5. 事件因玩家行动或世界线变化合理提前终止。
换篇时记录：本篇状态（已完成/已跳过/已延后/已改写）、换篇原因、关键偏移事实、新篇章首节点。

== 7. 防剧透边界 ==
- 本篇不揭示：统括理事会的深层运作、学园都市最高层的真实意图、能力开发的终极秘密、以及任何后续篇章的世界真相。
- 木山春生的完整动机只在 FANTASY-HAND-05 之后按剧情逐层揭示，不得在早期节点和盘托出。
- 后续篇章（禁书降临、绝对能力者进化等）的核心事件与角色不得在本篇提前启动；其角色至多合理客串。
- 魔法侧组织不得作为本篇事件的幕后推动力；玩家自己跨体系使用能力属卡面自由规则，不代表魔法侧势力介入本篇。

- 主线进度：当前锚点=幻想御手篇；当前节点=FANTASY-HAND-{NN}；节点完成时 replace 已完成节点/可触发节点数组；偏移事实写入 正史锚点.玩家偏移。
- 任务追踪：玩家接受的调查任务、守护承诺、协作请求写入任务追踪（任务类型标明"主线·幻想御手篇"），完成或失效时移除。
- NPC关系：佐天泪子、初春饰利、木山春生等按实际互动建立与更新；能力字段只写玩家已目睹的内容。
- 世界线记录：玩家改写儿童案结局、改变网络爆发规模、改变关键人物命运时必须写入。
- 支线任务（校园日常、委托等）可并行，但不覆盖本篇的当前锚点与当前节点。

== 9. 收束结果 ==
- FH-END-A 原著近似收束：网络平息、木山春生的行动被终止、儿童案以原著近似方式落幕。
- FH-END-B 玩家提前解决：玩家在前期节点就切断来源或救出关键人物，事件小规模收束。
- FH-END-C 联合收束：玩家促成官方、风纪委员与涉事者的联合方案，事件以更低代价平息。
- FH-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行发展并延后。
- FH-END-E 完全原创收束：玩家以原创方案（含跨体系能力自由发挥）改写整场事件，世界线记录如实反映。
以上所有收束均不使用死亡、失败收场、风险值或反噬机制；遗憾与代价只作为剧情事实呈现，不作为对玩家的惩罚判定。
