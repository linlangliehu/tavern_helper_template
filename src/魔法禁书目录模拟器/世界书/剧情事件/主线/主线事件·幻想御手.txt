【事件包：幻想御手篇】
事件包ID：FANTASY-HAND
所属阶段：阶段0·旧约·科学侧前奏
年层：Y
时间窗口：七月中下旬；官动层为七月中旬异常前奏、下旬主体，不强填漫画逐日日期
别名与触发词：幻想御手事件 / Level Upper事件 / FANTASY-HAND / FANTASY-HAND-01
证据定位：O01；超炮漫画1–3卷；官方动画年表（含一期前奏）

== 1. 核心定位 ==
从能力异常的案件追到共享脑网络，救治使用者并阻止幻想猛兽。木山春生救学生的动机与她伤害其他学生的手段必须同时呈现；不是泛称失踪儿童的寻人案。

== 2. 不可丢失的核心事实 ==
- 提升能力的音频在学生间传播，使用者随后昏迷；佐天也是使用者之一。
- 木山借音频使众人脑波同步，将他们的脑组成演算网络，自己得以使用多种能力。
- 她教过的置弃儿童在实验中陷入昏迷；申请树状图设计者计算救治方法屡遭拒绝，是她建立替代网络的动机。
- 木山败北后网络失控形成幻想猛兽；治疗程序与美琴的战斗共同阻止灾害。原作默认使用者苏醒，木山被拘捕；其教过的儿童此时并未全部获救，后续另接乱杂开放。

== 3. 玩家可改写的部分 ==
可追查音频来源、劝阻使用、协助医院比对脑波、提前取得治疗程序，或为木山寻找不伤害学生的计算资源。救援对象、公开程度和木山处置均可改变；不以补偿性伤亡惩罚成功。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；完整ID继续用于存档。

FANTASY-HAND-01 超出等级的案件
进入条件：七月中旬接触虚空爆破等能力异常案件，或下旬追查其余波。
场景目标：确认实际威力与登记等级不符，救出被爆炸波及的学生。
可见角色：美琴、黑子、初春；爆炸现场可见上条。
玩家行动：疏散、调查案卷、询问嫌疑人取得能力的途径。
结果：案件指向能提升能力的流传物，而非自然升级。
下一节点：FANTASY-HAND-02。

FANTASY-HAND-02 音频与诱惑
进入条件：获得幻想御手传闻。
场景目标：追踪传播链，并面对佐天等低等级学生对能力的渴望。
可见角色：佐天、初春、使用者及传播者。
玩家行动：收集样本、劝阻、陪同就医；使用与否由玩家决定。
结果：原作默认佐天与同学使用音频，短暂获得能力后出现异常。
下一节点：FANTASY-HAND-03。

FANTASY-HAND-03 同一种脑波
进入条件：使用者相继倒下。
场景目标：把群体昏迷与音频关联，比较患者脑波。
可见角色：初春、佐天、木山、医护人员。
玩家行动：送医、共享调查资料、核对专家解释。
结果：患者出现同一人的脑波模式，控制者线索落到木山身上。
下一节点：FANTASY-HAND-04。

FANTASY-HAND-04 初春与治疗程序
进入条件：木山身份暴露，初春落入其控制。
场景目标：救出初春并保护可让使用者恢复的治疗程序。
可见角色：木山、初春、美琴、警备员。
玩家行动：追踪车辆、谈判、保护程序载体、联系广播渠道。
结果：救人和解除脑网络成为两项明确任务，不必先把所有患者唤醒才能行动。
下一节点：FANTASY-HAND-05。

FANTASY-HAND-05 多才能力背后的教室
进入条件：追上木山，警备员的阻拦遭多种能力突破。
场景目标：阻止她继续利用学生，并查明昏迷儿童实验与计算申请被拒的经过。
可见角色：木山、美琴；实验回忆中的儿童仅作为过去证据。
玩家行动：协助美琴、隔离战场、质询实验责任或提出替代救治路线。
结果：原作默认木山被击败；同情其动机不等于把本次伤害合理化。
下一节点：FANTASY-HAND-06。

FANTASY-HAND-06 幻想猛兽诞生
进入条件：脑网络脱离控制。
场景目标：阻止聚合的AIM扩散力场形成的幻想猛兽继续破坏市区。
可见角色：美琴、木山、附近警备员与学生。
玩家行动：疏散、牵制再生个体、保护治疗程序播放设施。
结果：只击退外形不足以解决问题，必须同时解除支撑它的网络。
下一节点：FANTASY-HAND-07。

FANTASY-HAND-07 播放与击破
进入条件：治疗程序可播放，战场仍需有人支撑。
场景目标：让程序覆盖使用者，并为美琴击破核心创造时机。
可见角色：美琴、初春、佐天、木山。
玩家行动：组织播放、抢修传输、救助昏迷者或共同攻击核心。
结果：原作默认程序生效、幻想猛兽被消灭，使用者逐渐苏醒。
下一节点：FANTASY-HAND-08。

FANTASY-HAND-08 苏醒与未完成的救治
进入条件：网络灾害终止。
场景目标：核实患者恢复，处理木山去向并留下其学生的救治线索。
可见角色：佐天、初春、美琴、木山及医护人员。
玩家行动：探病、整理实验材料、选择继续追查或恢复日常。
结果：本案收束；昏迷儿童的后续不在此自动完成。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前救治、保全木山或改用其他演算资源均记为玩家偏移，不强制重新制造幻想猛兽。旧完整节点ID与完成记录保留；旧存档已发生的不同结果保留为偏移，不清空或强迫重演。

== 6. 换篇条件 ==
FANTASY-HAND-08完成、玩家明确离开/跳时或事件被合理提前解决即可换篇。包头、节点和换篇均以七月为当前时间，不能跳回五月至六月；禁书降临可在七月并行，乱杂开放按其独立窗口衔接，不把两者当本篇必然下一日。

== 7. 防剧透边界 ==
线索按调查揭示木山和实验，不预告未来实验的全部幕后。只限制本篇人物知情范围；后续篇章到达相应日期或由玩家选定时正常开放。

== 9. 收束结果 ==
- FH-END-A：近原作，使用者苏醒，木山被拘捕，儿童实验救治待续。
- FH-END-B：玩家提前切断网络或以替代方案完成救援。
- FH-END-C：保留与木山、患者及调查者的后续协作。
- FH-END-D：玩家退出，按已知原作因果记录场外结果。
- FH-END-E：原创解法；具体获救者和未竟事项如实记录，不附加惩罚。
