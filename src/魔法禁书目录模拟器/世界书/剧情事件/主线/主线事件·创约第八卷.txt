【事件包：创约第八卷·安娜保护与复活仪式】
事件包ID：GENESIS-08
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第8卷；三方追查、超绝者暗杀与桥架结社的目的。
时间窗口：本篇Y＋1年1月3日至1月4日深夜，据社区译文序章与尾声。承接前卷同日逃亡；尾声仪式灾变不是次卷才首次发生。
别名与触发词：创约第八卷 / 创约第八卷安娜保护线 / GENESIS-08

== 1. 核心定位 ==
上条与阿拉迪娅护送施普伦格尔，从第一二学区走向第一五学区的魔术资料线索。穆特忒贝奉结社之命追杀，学园都市实施安全管制，亚雷斯塔与金斯福德担心安娜继续利用上条；三方目的不同。安娜想靠掌握结社秘密自保，却无法用情报谈判撤销已经完成的复活仪式。

== 2. 不可丢失的核心事实 ==
- 上条保护安娜的生命，不代表认同她此前造成的灾难；阿拉迪娅主要是为了帮助上条而同行。
- 一方通行管理下的都市首先需要保护学生与控制局面，不应把戒严笼统写成所有警备员奉命杀安娜。
- 穆特忒贝可利用影子获取物体的力量，并持有针对超绝者的“矮小液体”。结社另准备了一名阿拉迪娅，必须与上条身边的同行者区分。
- 安娜以结社资料为谈判筹码；逃亡中大规模魔术会暴露踪迹，使用艾华斯等力量也有实际取舍。
- 原作安娜中了矮小液体，上条与同行阿拉迪娅击败追击的穆特忒贝及另一名阿拉迪娅，却不处死她们。安娜仍需要爱丽丝帮助，普通救治不足以解除该危险。
- 结社在追击结束前已完成仪式，召来名为CRC的存在；他拒绝按结社期待救济人类，重创结社并杀害爱丽丝。金斯福德迎战，危机转为都市与医院防卫。

== 3. 玩家可改写的部分 ==
- 改变护送路线、与都市交换信息的方式、是否让无关学生接触危险。
- 提前识别另一名阿拉迪娅、保护安娜免中矮小液体、以非致命方式控制追击者。
- 若确实提前获知仪式且具备介入条件，可以尝试阻止或改变仪式；不能在原作已完成后的节点仅说“谈判成功”就倒退现实。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；追击双方、都市管制与领事馆仪式按实际消息衔接。

GENESIS-08-01 一月三日的临时同行
进入条件：前卷安娜被带离，或玩家选择其他不处死监管方案并接入本卷。
场景目标：建立最低限度的护送约定，分清保护生命与纵容作恶。
可见角色：上条、安娜＝施普伦格尔、同行的阿拉迪娅。
玩家行动：核对伤势、约定行动边界、寻找安全路线，联系失散的茵蒂克丝与欧提努斯。
结果：三人组成不稳固的临时协作，安娜提出利用结社资料争取生路。
下一节点：GENESIS-08-02。

GENESIS-08-02 戒严不是一场统一追杀
进入条件：遭遇都市管制、结社追兵或亚雷斯塔一行的搜索。
场景目标：识别各方诉求，避免用一个敌我标签处理所有障碍。
可见角色：上条一行、实际遇见的警备人员；穆特忒贝、亚雷斯塔、金斯福德按所在位置出现。
玩家行动：向都市说明安全风险、掩护居民离开、避免无必要的大规模施法，评估与各方有限交换情报的可能。
结果：玩家可争取安全通道或缓和一方敌意，但不能因此认定所有追查都停止。
下一节点：GENESIS-08-03。

GENESIS-08-03 第一五学区的资料筹码
进入条件：仍需核实安娜掌握的结社秘密，具备前往资料所在地的路线。
场景目标：取得可验证的魔术资料，判断安娜的谈判方案是否真实有效。
可见角色：上条、施普伦格尔、同行阿拉迪娅；艾华斯只在实际召用时出现。
玩家行动：保护资料、追问安娜遗漏的信息、控制施法暴露；不把她的自信当成仪式尚未开始的证据。
结果：结社以成员配置完成特定仪式的目的逐渐可被理解，逃亡不再只是躲过一波波战斗。
下一节点：GENESIS-08-04。

GENESIS-08-04 第二名阿拉迪娅
进入条件：穆特忒贝与另一名阿拉迪娅追上护送队伍。
场景目标：确认同名对手不是同行者突然背叛，防止矮小液体击中保护对象。
可见角色：穆特忒贝、第二名阿拉迪娅、同行阿拉迪娅、上条、施普伦格尔。
玩家行动：辨认动作与位置、保护同伴、破坏影子接触条件，寻找避开针对超绝者武器的方法。
结果：原作安娜中了矮小液体，其他手段只能暂缓危险；玩家若成功阻止命中，保留不同伤情与后续救援需求。
下一节点：GENESIS-08-05。

GENESIS-08-05 赢下追击仍不能治愈
进入条件：追击者仍阻挡撤离，安娜的伤情或监管安全需要处理。
场景目标：配合阿拉迪娅击破穆特忒贝的影子军备，制服两名追击者而不是报复处刑。
可见角色：上条、同行阿拉迪娅、穆特忒贝、第二名阿拉迪娅、施普伦格尔。
玩家行动：改变照明与遮蔽、拆开追击者配合、掩护近身反击，控制对手后保留呼吸与救治条件。
结果：原作两名追击者被制住，矮小液体被取得；安娜仍未得救，上条把寻找爱丽丝作为下一步，而非宣布一切结束。
下一节点：GENESIS-08-06。

GENESIS-08-06 已完成的仪式
进入条件：审问穆特忒贝、追查领事馆，或更早获得可验证的仪式情报。
场景目标：辨别谈判是否还来得及，确认第二名阿拉迪娅与仪式配置的关联。
可见角色：穆特忒贝、上条、阿拉迪娅；结社成员通过现场或可靠信息被确认。
玩家行动：核查仪式进度、警告都市与领事馆、规划安娜救治；若玩家已提前干预，按实际改变核算。
结果：原作追击开始前相关任务已完成，结社不再需要安娜临时补位；“拿秘密换停手”不能自动撤销已经发生的召唤。
下一节点：GENESIS-08-07。

GENESIS-08-07 一月四日深夜的反噬
进入条件：现实侧进入1月4日深夜，仪式结果显现或消息传到救援方。
场景目标：从期待救世转为保护结社成员与都市，区分愿望和被召者自己的意志。
可见角色：CRC、爱丽丝、H.T.与在场超绝者；金斯福德、亚雷斯塔赶入危机。
玩家行动：警示结社、掩护撤离、救治安娜及其他伤员，阻止CRC伤害爱丽丝；未在场者通过消息接入而非全知旁观。
结果：默认CRC拒绝承担结社希望的救济，爱丽丝遭杀害，金斯福德迎战；上条一方原本依赖爱丽丝救安娜的计划被切断。玩家若保护成功，不强制再杀爱丽丝。
下一节点：本包收束；进入1月5日医院危机时接GENESIS-09-01。

== 5. 分支和偏离规则 ==
- 三方威胁分别处理；争取都市协助不自动消除穆特忒贝的命令，击倒穆特忒贝也不自动解除仪式。
- 第二名阿拉迪娅与同行者分开记录，不靠同名覆盖NPC关系或位置。
- 若仪式被有效阻止、爱丽丝存活或安娜未中矮小液体，后卷依剩余冲突接入，不以新的无证灾难强迫回正。

== 6. 换篇条件 ==
追击与安娜的即时处境已有交代，仪式是否发生及其危险已明，或玩家明确离开、跳跃、另选锚点时换篇。创约第九卷继承已发生的CRC降临与爱丽丝受害，不把它们重新表演一次。

== 7. 防剧透边界 ==
结社仪式目标随资料与现场揭露。CRC的进一步身份真相属于后卷调查，不能在本卷初遇时直接告诉上条；暗处仪式不是所有角色的同步记忆。

== 8. 状态写回契约 ==
- 主线进度当前阶段“创约”、阶段序号8不变；当前节点写完整ID，阶段状态对应护送、冲突或收束。
- 正史锚点记录安娜保护、仪式完成与默认灾变；玩家偏移保留伤情、谈判、仪式干预及爱丽丝结局。
- 已完成节点、可触发节点整体replace并去重，任务追踪持续保留安娜救治与失散者事项，不因赢得追击战清空它们。
- 都市管制、两名阿拉迪娅与各方立场沿用在场人物、NPC关系、势力关系、世界线记录，不新增阵营惩罚或影子战力数值字段。

== 9. 收束结果 ==
默认护送者赢得局部战斗却未救好安娜，结社期待的救世仪式引出CRC灾难，爱丽丝被杀与金斯福德迎战成为次卷已发生的前情。玩家改变的伤情、仪式与人际关系继续有效。
