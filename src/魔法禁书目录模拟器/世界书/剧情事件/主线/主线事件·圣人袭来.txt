【事件包：圣人袭来篇】
事件包ID：ACQUA
所属阶段：阶段5·旧约·10月中旬（暗部大战余波中、三战前夜；欢迎页锚点"暗部脱逃·后方之水篇"对应的完整事件包）
时间窗口：10月11日-10月17日（战书送达→踏浪而来→决战收束）
别名与触发词：圣人袭来 / 后方之水 / 阿克亚 / Acqua / 威廉·奥威尔 / 阿斯卡隆 / ACQUA / 暗部脱逃

== 1. 核心定位 ==
本篇是旧约科学侧线的圣人战章：暗部大战的硝烟未散，罗马正教神之右席「後方のアックア」——兼具体质与圣人资质的佣兵威廉·奥威尔——向英国清教送达战书（随信附上左方之地的遗骸），随后只身踏浪突入学园都市，目标直指上条当麻的右手。天草式全员护卫、五和贴身随行，上条被逼入瀕死；救场的是另一位圣人——神裂火织。事件主题是"何为真正的强"——在压倒性的圣人面前，凡人的规则一文不值，但守护的意志不是。
玩家进入本篇的方式：开局锚点直接选在本篇（对应欢迎页"暗部脱逃·后方之水篇"时点）；或以战书送达/圣人登陆的都市异变卷入。玩家立场自由：护卫战的协力者、疏散与救护的中枢、天草式的临时战友、理事会观战记录员、或想会一会"圣人"的挑战者。

== 2. 不可丢失的核心事实 ==
- 后方之水（威廉·奥威尔）：神之右席「後方」之席，兼具神之右席的神性（大天使加百列系）与圣人资质的双重身份，可发挥两倍实力；佣兵出身、刚直重信义；持灵装圣剑「阿斯卡隆」；用「圣母的慈悲」吸收夜气强化武器。他是四人中最接近「武人」的存在——战斗堂堂正正。
- 战书的仪式感：10月11日，英国清教收到战书与左方之地的遗骸——神之右席的内斗与意图第一次摆在台面上（对应欢迎页锚点卡）。
- 压倒性的强度差：圣人=物理法则级的怪物；常规战力（警备员、多数能力者）无法构成威胁；上条在正面交战中被打至瀕死——幻想杀手的"无效"需要接触，而圣人不给机会。
- 五和与天草式：护卫作战的主力；五和的贴身护卫与"不撤退"的觉悟是本篇的情感线之一（承C文书篇建立的护卫关系）。
- 神裂火织的参战：同为圣人的神裂火织第一时间驰援，圣人对圣人的决战展开（钢线与北欧术式 vs 圣剑与圣母之力）——本篇最高潮。
- 终局事实（原著重力线）：神裂与上条、天草式合力击破后方之水；他的败因里藏着"自己也没打算全力以赴"的余白——他的真实目的（与右方之火路线的对立）沉在水面之下。上条重伤得救，都市再次带伤运转。
- 暗部背景：战书事件同时暴露了神之右席与教廷高层的路线裂痕——右方之火的"计划"在这个背景里第一次被隐约提及（仅提名，不展开）。
- 战斗基调：单点圣人碾压+圣人对决；玩家能力跨体系混用无反噬，但面对圣人级战力的正确玩法是"智取、辅助、护卫、换位"，而非正面对轰——把这份强度差玩出策略感。

== 3. 玩家可改写的部分 ==
- 上条的瀕死：原著=重伤倒地等救场；可改写为玩家医疗介入/能力防护/提前转移战场——代价转给谁由玩家决定。
- 决战胜负：神裂参战（原著近似）、玩家成为决胜的最后一块拼图、或说服后方之水罢手（他重信义，讲理的通道存在）。
- 后方之水的去向：败退（原著近似）、被玩家俘虏/收留、或阵亡（改写线，需玩家承担教廷报复的后果）。
- 情报的流向：战书与右席内斗的情报交给谁——英国清教、学园都市、理事会、还是玩家自己攥着。
- 五和的位置：护卫成功后的关系走向——恩情、战友、或玩家阵营的常驻协力者。

完成：上条瀕死与护卫战成立的事实确认（或玩家改写战局）。

触发：03完成。

完成：后方之水被击破（或玩家改写的替代结果达成）。
下一节点：05。

ACQUA-05 水面下的目的
触发：04完成。
内容：后方之水的败因里留着"未尽全力"的余白；他的真实目的（与右方之火路线的对立）不揭示、只留轮廓；上条得救、都市善后、五和的觉悟得到回应；三战的阴影在地平线上逼近（10月18日不列颠万圣节政变的消息开始传入）——按第9章定收束结果。

== 5. 偏离与改写 ==
- 上述节点与结局是"原著重力线"，不是唯一路径：玩家可在任意节点改写目标、阵营、手段与结果。
- 篇章内偏离：允许把本篇玩成都市疏散剧/圣人讨伐战/天草式视角群像/谈判剧，只要不覆盖核心事实（后方之水入侵、上条瀕死、圣人级强度差）。
- 核心结果改写：上条战死级重伤、神裂未参战、后方之水倒戈、圣人战以谈判终局，均合法——以玩家偏移事实记录，不得静默回滚。
- 明确离开：玩家声明退出时按第9章NT-END-D收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：右方之火的计划与伯利恒、三战的全面展开（只到"阴影逼近"层级）、新约系一切、后方之水的真实目的全貌。
- 后方之水的双重身份只到「神性与圣人资质并存、可发挥两倍实力」层级；「圣母的慈悲」的深层原理不展开。
- 神之右席的内斗只到"路线裂痕浮出"层级，四人各自的完整计划不展开。
- 上条的失忆暗线（若存在）只保持"细微违和"层级。
