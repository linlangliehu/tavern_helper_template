【事件包：圣人袭来·后方之水篇】
事件包ID：ACQUA
所属阶段：阶段5·旧约·十月中旬
年层：Y
时间窗口：十月中旬；暗部大战之后、英国王室之前，现有官动只证相对窗，不强填起讫日
别名与触发词：后方之水袭来 / 圣人袭来事件 / ACQUA / ACQUA-01
证据定位：O34；旧约16及官介；官方动画年表；O31、O32为前序

== 1. 核心定位 ==
一场交出右臂便放过性命的威胁，迫使上条、五和与神裂从各自逞强转向合作。胜机来自破解两种力量的配合，不是某个圣人突然忘记自身能力。

== 2. 不可丢失的核心事实 ==
- 五和在学园都市护卫上条，后方之水来袭将其重伤，要求期限前交出右臂。
- 天草式先代上条迎战，圣人崩被防住；神裂单独对战也受挫。后方之水同时具圣人与神之右席一侧的力量，不能硬写成准确两倍战力。
- 原作默认上条赶回战场，消除神之右席术式；神裂限制其圣人动作，五和再次发动圣人崩，三方配合成功。
- 这不是OT16中手持阿斯卡隆的英国大战，也不引入吸收夜气等无据招式。败退后的威廉将在英国线再登场，非永久退场。

== 3. 玩家可改写的部分 ==
可提前设置护卫、阻止上条重伤、协调天草式与神裂、谈判终止威胁或使用替代破术方案。没有交出右臂才能继续故事的硬门槛，不安排原作伤害的补偿对象。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；沿用ACQUA-01至ACQUA-05。

ACQUA-01 护卫与战书
进入条件：十月中旬，五和为应对后方之水到上条身边护卫。
场景目标：处理共同生活与护卫安排，在袭击中保护上条及周围人员。
可见角色：五和、上条、茵蒂克丝、后方之水。
玩家行动：警戒、撤离、协助迎战或提出谈判。
结果：原作默认上条重伤，被要求限期交出右臂；伤情与威胁分别进入后续任务。
下一节点：ACQUA-02。

ACQUA-02 天草式的第一次尝试
进入条件：上条住院，天草式选择替他应战。
场景目标：协同发动圣人崩，查明为何既定对圣人手段无法奏效。
可见角色：五和、建宫、天草式成员、后方之水。
玩家行动：支援阵型、救护、分析圣母之慈悲等防御作用。
结果：原作默认首次攻击被防下，单靠同样方式重复冲锋不能改变局势。
下一节点：ACQUA-03。

ACQUA-03 神裂不是一个人
进入条件：神裂独自迎战，天草式仍有伤员需要保护。
场景目标：支援神裂，促使她接受伙伴协力，而非独自承担一切。
可见角色：神裂、后方之水、五和、天草式成员。
玩家行动：救援、提供观察结果、协调重新入场时机。
结果：原作默认神裂单挑受挫；天草式与她共同辨认两类力量的配合漏洞。
下一节点：ACQUA-04。

ACQUA-04 三方合击
进入条件：上条赶回战场，协作方案形成；玩家可用其他已成立方案替代。
场景目标：消除神之右席术式、限制圣人动作，让圣人崩命中。
可见角色：上条、神裂、五和、天草式、后方之水；美琴只在出院途中实际相遇时出现。
玩家行动：护送、配合破术与牵制、保护五和完成攻击。
结果：原作默认上条、神裂、五和各自完成一环，再次圣人崩击败后方之水；美琴对七月失忆的知情可在途中交流。
下一节点：ACQUA-05。

ACQUA-05 来袭之后
进入条件：威胁解除，伤者可以收治。
场景目标：确认上条右臂与同伴安全，处理五和、神裂及天草式的后续联系。
可见角色：上条、五和、神裂、茵蒂克丝及医护人员。
玩家行动：探病、确认承诺、安排休养或了解英国方面的召集。
结果：原作默认后方之水败退；罗马侧右方之火对教皇动手并转向茵蒂克丝，是后继信号，不自动成为主角全知情报。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
可提前合作或谈判，减少既定失败回合；不因玩家跳过受伤便强制神裂或五和代为承受。旧完整节点和完成记录保留，既成不同战果作为玩家偏移继续。

== 6. 换篇条件 ==
ACQUA-05完成、明确退出/跳时或战书威胁提前终止后可换篇。主干接十月中旬后段BRITISH-ROYAL-01，都市暗线另接DRAGON；不能将旧约17–19直接压缩成三战开场一句背景。

== 7. 防剧透边界 ==
本篇可以揭示合击所需的力量差异，不用反剧透屏蔽解法；英国王室和右方之火后继按各自时间窗正常开放。

== 8. 状态写回契约 ==
推进、合击与换篇同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留旧项。右臂、伤情、协作与威廉去向偏移写主线进度.正史锚点.玩家偏移；护卫和休养记任务追踪。

== 9. 收束结果 ==
以下NT-END为旧包内兼容，卷别仍是旧约16。
- NT-END-A：近原作，三方合作击败后方之水，上条保住右臂。
- NT-END-B：玩家提早协作、劝退或另法破术，减少伤害。
- NT-END-C：退出或委托收尾，保留护卫与休养承诺。
- NT-END-D：原创制止方案，不转嫁代价，不强制毁臂。
