【事件包：树状图残骸篇】
事件包ID：TREE-DIAGRAM-REMNANT
所属阶段：阶段4·旧约·祭典前夕
年层：Y
时间窗口：9月14日前后；官动层14日傍晚调查、夜间争夺与营救
别名与触发词：树状图残骸事件 / 残骸争夺战 / TREE-DIAGRAM-REMNANT / TREE-DIAGRAM-REMNANT-01
证据定位：O20；旧约8及官介；官方动画年表；O02、O08为前因

== 1. 核心定位 ==
一个被劫走的手提箱把黑子的风纪委员调查与妹妹实验的后患相连。阻止树状图复原与救出黑子同样重要，不能只让美琴或一方在场外替玩家解决一切。

== 2. 不可丢失的核心事实 ==
- 树状图在七月被毁，回收残骸可能支持复原，重新威胁已经中止的妹妹实验。
- 黑子调查手提箱被夺案，与能移动远处物体的结标淡希交战负伤；美琴也在追踪残骸。
- 结标试图招揽黑子，被拒后冲突升级。原作默认重伤的黑子由上条救出，一方摧毁残骸阻止实验重启。
- 此次受伤延续到祭典期间，不能随后把黑子默认写成不受限制的正常参赛者；玩家治愈则另记偏移。

== 3. 玩家可改写的部分 ==
可护送手提箱、截断外运、保护黑子、说服结标或选择能防止再利用的封存办法。保全残骸不自动等于允许重启实验，需要写清控制与去向，而非惩罚性安排其失窃。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口TREE-DIAGRAM-REMNANT-01。

TREE-DIAGRAM-REMNANT-01 被夺走的手提箱
进入条件：14日傍晚风纪委员收到劫案线索。
场景目标：查明运输路线与袭击者，保护受到波及的人员。
可见角色：黑子、初春、运输人员。
玩家行动：追踪、调取可用资料、救护、封锁离开路线。
结果：普通抢夺案露出与研究物资有关的异常。
下一节点：TREE-DIAGRAM-REMNANT-02。

TREE-DIAGRAM-REMNANT-02 空间移动的差异
进入条件：黑子追上结标。
场景目标：应对结标不需直接接触目标的移动攻击。
可见角色：黑子、结标；初春可远程支援。
玩家行动：掩护、观察定位方式、带离伤者或阻断转运。
结果：原作默认黑子负伤，但得知箱中物品与美琴有关。
下一节点：TREE-DIAGRAM-REMNANT-03。

TREE-DIAGRAM-REMNANT-03 不能复原的演算机
进入条件：美琴追查残骸，与风纪委员线索交汇。
场景目标：确认箱中是树状图残骸，说明它可能重新支撑妹妹实验。
可见角色：美琴、黑子；初春按收到的信息协助。
玩家行动：核对前案、协调拦截、限定敏感信息的知情范围。
结果：阻止复原成为明确目标，原作默认结标从美琴追阻中逃走。
下一节点：TREE-DIAGRAM-REMNANT-04。

TREE-DIAGRAM-REMNANT-04 被拒绝的招揽
进入条件：黑子再次接触结标。
场景目标：面对她以相似能力与处境提出的招揽，守住黑子自主判断。
可见角色：黑子、结标。
玩家行动：交涉、援护、策动放下残骸或中断战斗。
结果：原作默认黑子拒绝，结标激怒并加重攻击；伤势不能被下一幕无故抹除。
下一节点：TREE-DIAGRAM-REMNANT-05。

TREE-DIAGRAM-REMNANT-05 从险境中救人
进入条件：黑子重伤受困，或玩家提前执行营救。
场景目标：在攻击和现场危险中把黑子带到安全处。
可见角色：黑子、上条、美琴；结标按逃离情况出现。
玩家行动：通知上条、开辟接近路线、救护或独立救出黑子。
结果：原作默认上条救出黑子；残骸尚须另行截断，救人不等于自动夺回箱子。
下一节点：TREE-DIAGRAM-REMNANT-06。

TREE-DIAGRAM-REMNANT-06 一方的拦截
进入条件：结标携残骸继续行动，或玩家已控制残骸。
场景目标：阻止其用于复原树状图、重启妹妹实验。
可见角色：一方通行、结标；玩家按追踪路线到场。
玩家行动：协助拦截、拆毁、提出可靠封存方案或争取结标配合。
结果：原作默认一方击败结标并摧毁残骸，复原路线受挫。
下一节点：TREE-DIAGRAM-REMNANT-07。

TREE-DIAGRAM-REMNANT-07 伤员与残骸去向
进入条件：残骸争夺终止。
场景目标：核实黑子治疗与残骸处置，确认妹妹实验没有因此恢复。
可见角色：黑子、美琴、初春、上条及医护人员。
玩家行动：探病、整理物证、通知必要协作者，选择祭典前安排。
结果：黑子伤情、结标去向与残骸状态分别保留，不能用一句结案全部清零。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
若七月树状图未被毁，本案条件须按已存偏移重判，不能凭本包强造残骸；可改为阻止既有演算资料被利用，或合理跳过。其他既有节点完成记录不撤销，不强迫黑子再次受伤。

== 6. 换篇条件 ==
TREE-DIAGRAM-REMNANT-07完成、玩家退出/跳时或转运提前终止即可换篇。接15–18日其他独立事件或19日起祭典；ST-CROSS与DAIHASEISAI择一为当前主线，不覆盖黑子伤情。

== 7. 防剧透边界 ==
只揭示本案所需的妹妹实验后患，不预告结标未来入GROUP后的全部任务。后继暗部事件正常开放，不把本案败退写成角色从此消失。

== 8. 状态写回契约 ==
同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留旧项。伤情、残骸与实验条件偏移写主线进度.正史锚点.玩家偏移，护送和治疗写任务追踪。

- TREE-DIAGRAM-REMNANT-END-C：退出或因前置已改写而合理跳过。
