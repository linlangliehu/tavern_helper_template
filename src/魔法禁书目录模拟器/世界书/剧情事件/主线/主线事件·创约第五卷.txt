【事件包：创约第五卷·装甲列车与不思议之国】
事件包ID：GENESIS-05
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第5卷；手铐行动之后的独立余波。
时间窗口：本篇Y年12月29日，数字日期据社区译文序章。爱丽丝改写的体验不另算现实过去数日。
别名与触发词：创约第五卷 / 创约第五卷装甲列车 / GENESIS-05

== 1. 核心定位 ==
上条醒来时身边多了把他叫作老师的爱丽丝，随后卷入押送暗部囚犯的装甲列车事故。爱丽丝能把危险整理成老师可以获胜的冒险，但上条选择撤去这种照顾，回到真正复杂的现场。玩家要和黑子、花露妖宴、浜面等人重新确认事实，最终救出被地下木原端数控制的儿童，结束最大禁忌的扩张。

== 2. 不可丢失的核心事实 ==
- 押送事故发生在手铐行动数日之后；部分囚犯逃脱，警备员与暗部幸存者再次相遇，不代表12月25日行动被重跑。
- 爱丽丝的Live Adventures in Wonderland会调整冒险的因果与参与者。看似顺利的世界不等于真实世界已有同样结果。
- 上条拒绝依靠爱丽丝替他安排所有答案；恢复未被她调整的现场后，列车事故的嫌疑关系也需要重新调查，不能沿用虚假版本的凶手结论。
- 木原端数在原作12月25日肉体死亡后，以人工幽灵形式延续自己并控制地下最大禁忌；这是新的状态，不是把死亡记录悄悄删去。
- 端数利用Risako牵制Frillsand #G，企图通过异常空间与更大能量体系取得自由。Frillsand的危险与救回孩子的愿望相连，不是单纯为了毁城。
- 原作上条与浜面保护儿童，克里法＝拼图545帮助救出Risako，风斩冰华最终消除端数的人工幽灵威胁；Frillsand收回最大禁忌并停止扩张。爱丽丝随后随安娜离开。

== 3. 玩家可改写的部分 ==
- 改变事故救援、逃亡者是否合作以及黑子对现场证据的掌握，不以暗部标签取消救治。
- 选择何时识别爱丽丝的安排，与她谈清“帮忙”和替人决定的区别；也可保留部分帮助，但必须标明何者仍被她影响。
- 救出儿童、阻止端数控制异常空间，争取Frillsand停止伤害；若前卷已改变端数结局，不强制复制其死亡后复出。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；爱丽丝调整前后的信息、实际世界的结果必须分开。

GENESIS-05-01 醒来时的陌生学生
进入条件：选择本卷锚点，或12月29日在上条周围遇见爱丽丝。
场景目标：确认孩子的安全和她把上条视为老师的关系，不急于定义她为敌人。
可见角色：上条当麻、爱丽丝＝安娜扎拜布尔、茵蒂克丝、欧提努斯。
玩家行动：交谈、寻找照护线索、陪她外出，观察她对常识与危险的不同理解。
结果：玩家获得参与这场异常冒险的关系基础，随后接触装甲列车事故。
下一节点：GENESIS-05-02。

GENESIS-05-02 脱轨后的临时同伴
进入条件：押送装甲列车出事，现场伤员、囚犯和执法人员混杂。
场景目标：优先救助受困者，辨认花露妖宴与黑子的处境。
可见角色：上条、爱丽丝、花露妖宴、白井黑子，以及实际遇见的押送人员与逃亡者。
玩家行动：救人、疏散、核对押送信息，尝试与有危险能力的幸存者建立有限合作。
结果：原作上条救下妖宴；爱丽丝的力量让事件逐渐呈现过于顺畅的冒险结构，玩家可发现不合常理的便利。
下一节点：GENESIS-05-03。

GENESIS-05-03 拒绝被安排好的胜利
进入条件：察觉爱丽丝调整了局面，或获知当前冒险不是未受影响的现实。
场景目标：让上条与爱丽丝就救人方式作出明确选择，区分被安排的结局与实际救援。
可见角色：上条、爱丽丝；其他人的知识受其实际经历限制。
玩家行动：询问变化范围、要求恢复真实现场、安抚爱丽丝，或明确接受某项帮助并记录影响。
结果：原作上条回到不再由爱丽丝保证胜利的现场；此前的嫌疑、盟友与便利不能直接充作真实证据，但可成为待验证线索。
下一节点：GENESIS-05-04。

GENESIS-05-04 重新调查铁轨与人心
进入条件：回到真实事故现场，或玩家选择核查仍受爱丽丝影响的关键事实。
场景目标：处理轨道破坏、袭击与人质威胁，重新取得合作而非复制先前的顺利答案。
可见角色：上条、黑子、妖宴、乐丘丰富及其妹妹；爱丽丝按实际同行情况出现。
玩家行动：检查铁路设备、保护受胁迫者、救治重伤者，与妖宴等人交换地下区域线索。
结果：真实调查不再把Frillsand当作包办全部事故的唯一凶手；花露姐妹提供的信息将余波指向第十学区地下最大禁忌。
下一节点：GENESIS-05-05。

GENESIS-05-05 死者留下的人工幽灵
进入条件：找到通向地下异常空间的路线，或儿童受困的信息得到核实。
场景目标：辨认木原端数的新状态及他对Risako的控制，阻止异常空间继续扩张。
可见角色：木原端数的人工幽灵、Risako、浜面仕上、Sodate、上条；Ladybird按所在位置参与保护或冲突。
玩家行动：寻找孩子位置、汇合浜面、辨认端数与Frillsand争夺控制权的原因，不把异常空间当作普通地铁出口。
结果：端数借人质限制Frillsand、谋求脱离地下束缚的计划暴露，救孩子成为解除结构性威胁的关键。
下一节点：GENESIS-05-06。

GENESIS-05-06 让孩子选择温柔的力量
进入条件：能够接近Risako与Sodate，端数的控制尚未解除。
场景目标：救出儿童并使他们摆脱以伤害他人换取安全的诱导。
可见角色：上条、浜面、Risako、Sodate、克里法＝拼图545、Frillsand #G；风斩冰华在相应战场介入。
玩家行动：掩护救援、与孩子沟通、破坏人质控制，协助把端数与受害者分离。
结果：原作克里法协助Risako脱困，Frillsand得以夺回控制；风斩冰华消除端数的幽灵威胁，地下扩张失去推动者。玩家已有更早解决方案时保留它，不强制追加战斗。
下一节点：GENESIS-05-07。

GENESIS-05-07 回到地面的人
进入条件：儿童获救、最大禁忌停止扩张，幸存者能够返回地面。
场景目标：安置伤员与孩子，确认Frillsand的存在边界，并处理爱丽丝的离开。
可见角色：上条、浜面、泷壶、Ladybird、Risako、Sodate；爱丽丝、安娜＝施普伦格尔随后出现。
玩家行动：安排后续照护、替Frillsand与孩子保留联系，询问爱丽丝意愿并记录安娜的介入。
结果：原作幸存者重聚，Frillsand因自身危险没有直接与孩子团聚；爱丽丝随安娜离开，上条没有把两人一概归作不可救的恶人。
下一节点：本包收束；12月31日可接GENESIS-06-01。

== 5. 分支和偏离规则 ==
- 爱丽丝的世界不是通用存档读档机制；若玩家拒绝撤去影响，保留异常范围与未知事实，不宣称已验证现实同样安全。
- 前卷救活的人继续存活；现实中已死的Drencher等人不因本次圆满救援自动复活，也不把幻象版本记作真实复活。
- 救援与责任处置分别记录；接受妖宴、Ladybird的帮助不等于替她们取消全部既往行为。

== 6. 换篇条件 ==
事故救援、儿童安置及最大禁忌的即时危险已有结果，或玩家明确离开、跳跃、另选锚点时换篇。爱丽丝与安娜离开是超绝者线索，不把下一卷跨年追杀提前发生在29日。

== 7. 防剧透边界 ==
端数的人工幽灵、Frillsand真实动机与风斩的介入只在调查及终局揭露；爱丽丝的力量不授予玩家或NPC对桥架结社全貌的知识。

== 8. 状态写回契约 ==
- 主线进度当前阶段写“创约”、阶段序号8，当前节点使用完整ID，阶段状态依实际事件更新。
- 正史锚点记录装甲列车与最大禁忌的默认走向；玩家偏移记录爱丽丝的影响、前卷幸存变化与真实救援结果。
- 已完成节点、可触发节点整体replace并去重，区分未受影响的现实与仅体验过的安排，不凭幻象添加现实完成项。
- 伤员、儿童照护与残余空间观察沿用任务追踪；人物与势力变化写入NPC关系、在场人物、势力关系、世界线记录，不新增读档或复活字段。

== 9. 收束结果 ==
默认是幸存者以真实行动完成救援、端数的人工幽灵威胁解除、Frillsand停止扩张，手铐行动遗留的这条危险得到终结。已经发生的损失仍存在，爱丽丝与安娜的关系则接向跨年前后的桥架结社事件。
