【事件包：僧正追击篇】
事件包ID：NT-HIGH-PRIEST
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年12月3日前后；承接钻石大楼之后
别名与触发词：僧正追击篇 / 魔神评分者邀约 / 箭头彗星危机 / NT-HIGH-PRIEST

== 1. 核心定位 ==
作品范围：新约13。真格雷姆林中的僧正要求上条成为魔神的“评分者”，被拒绝后以破坏追逐施压。核心是拒绝把世界变成受魔神任意安排的舞台，以及追击中的平民救援；不是NT8—10的欧提努斯战争重演。

== 2. 不可丢失的核心事实 ==
- 僧正用储物柜里的信约上条到校舍天台。上条拒绝评分者地位，不愿让人的生活成为魔神讨好他的表演。
- 僧正对学校与城市造成破坏，上条与美琴乘Acrobike逃离并救人，向第二十三学区转移以减少波及。
- 僧正能借与大地的联系追踪。两人在船上短暂摆脱追踪并补充电力，遇见奈芙蒂斯与娘娘，接受情报但没有让她们直接代打。
- 原作两人利用质量加速器把僧正送入太空，他却夺取箭头彗星准备撞向城市。把他发射出去不是最终获胜。
- 木原脑干使用与亚雷斯塔相连的A.A.A消灭僧正并阻止彗星。尾声奈芙蒂斯求助，带来魔神遭理想送行放逐的新危机。

== 3. 玩家可改写的部分 ==
- 可支持拒绝评分者，也可询问条件并尝试限制干涉，不能替玩家默认接受凌驾普通人生活的地位。
- 可提前疏散、改变追击路线、寻找切断大地联系的方法或争取停战，不必重演全部校舍与街区损毁。
- 可尝试非致命阻止僧正、改变脑干的介入；相应后果必须继承，不能为下一卷便利而补写必死。

== 4. 节点推进表 ==
NT-HIGH-PRIEST-01 天台上不是情书的邀约
进入条件：上条发现僧正来信，或玩家主动调查真格雷姆林的接触。
场景目标：弄清评分者到底能决定什么，以及普通人的生活会被怎样改变。
可见角色：僧正、上条；玩家与校内人员依实际位置出现。
玩家行动：追问魔神目的、指出未经他人同意的改变，保护学生，争取在校外继续谈判。
结果：原作上条拒绝，僧正以破坏来迫使他改变想法；玩家若取得真正停手承诺，可改走协商，不让袭击无条件照常发生。
下一节点：追击发生则进入NT-HIGH-PRIEST-02；已停战则进入NT-HIGH-PRIEST-06核对后续。

NT-HIGH-PRIEST-02 不能只顾逃走的双人车
进入条件：僧正破坏学校并追来，上条取得Acrobike，美琴被卷入同行。
场景目标：把追击引离人口密集区，同时救助沿途被波及者。
可见角色：上条、美琴、僧正；沿途居民、右方之火按其介入出现。
玩家行动：开辟疏散线、维持车与通讯、支援沿途救援，警惕对僧正重复使用未验证有效的削弱方案。
结果：原作常规阻拦与右方之火的妖精化尝试未能结束追击，两人转向第二十三学区；玩家的疏散和路线改变会留下不同损毁与伤者记录。
下一节点：进入NT-HIGH-PRIEST-03。

NT-HIGH-PRIEST-03 水面上的短暂停顿
进入条件：车辆电力不足，或发现僧正的追踪依赖与大地接触。
场景目标：利用追踪断点争取恢复与情报，判断是否接受其他魔神直接干涉。
可见角色：上条、美琴、奈芙蒂斯、娘娘；僧正在追踪线外施压。
玩家行动：选择脱离地面的路线、补充电力，询问力量机制，协商协助范围，不把暂时脱离误认成对手消失。
结果：原作两人从奈芙蒂斯与娘娘取得信息而拒绝直接代打；玩家可以提出不同协作，但须让其意愿与可能影响在对话中成立。
下一节点：进入NT-HIGH-PRIEST-04；有可靠停战路径可转NT-HIGH-PRIEST-06。

NT-HIGH-PRIEST-04 第二十三学区的发射井
进入条件：队伍抵达第二十三学区，僧正再次追上并威胁城市地基。
场景目标：配合居民避险，利用质量加速器将破坏源移离城市。
可见角色：上条、美琴、僧正；联络到的居民与设施人员。
玩家行动：确认井内与周围人员撤离、牵制目标、协调发射，或提出已验证可行的拘束方案。
结果：原作僧正被送入太空，但仍有行动能力；玩家若提前改变发射或达成拘束，则后续彗星危机只在确有条件时发生。
下一节点：僧正仍能控制太空目标时进入NT-HIGH-PRIEST-05；威胁已稳定则进入NT-HIGH-PRIEST-06。

NT-HIGH-PRIEST-05 回到天空的箭头
进入条件：僧正控制箭头彗星并将其指向学园都市。
场景目标：阻止撞击，维持疏散与联络，辨认远程反制来自何方。
可见角色：上条、美琴；僧正与木原脑干通过各自战场呈现。
玩家行动：提供定位与疏散支援、联络反制力量，或执行自身已具备的拦截方法，不凭现场人物视野宣称知道A.A.A全部原理。
结果：原作木原脑干用A.A.A消灭僧正，彗星危机终止；若玩家使僧正生还或改变反制，记录实际处置，不把原作死亡变成必须领取的通关结果。
下一节点：进入NT-HIGH-PRIEST-06。

NT-HIGH-PRIEST-06 归来后的另一名求助者
进入条件：追击结束，伤者、校舍与城市有基本善后安排，上条能返回住处。
场景目标：区分已解决的僧正危机与正在发生的魔神放逐，决定是否接纳新的求助。
可见角色：上条、茵蒂克丝、欧提努斯、衰弱的奈芙蒂斯；美琴按实际告别或同行。
玩家行动：安置伤员和受损学校相关人员，听取奈芙蒂斯证言，核对欧提努斯是否也在被追击范围内。
结果：原作奈芙蒂斯带来上里翔流与理想送行的消息，原校损毁留下后续转校原因；玩家若保住学校，则NT15不能仍无理由写全校转移。
下一节点：玩家选择调查上里或保护求助者时进入NT-WORLD-REJECTER-01；否则保留警示并回到善后。

== 5. 分支和偏离规则 ==
逐次记录疏散、道路与校舍损毁，玩家抢先救助的成果不能在转场时被清空。僧正是否被发射、是否生还、脑干是否介入是不同事实。旁观者不自动知道亚雷斯塔的个人动机或魔神削弱的全部机制。

== 6. 换篇条件 ==
追击与彗星威胁须先有明确处理，再由奈芙蒂斯的消息接入NT14。NT15转校仅继承实际损毁，不用日历或阶段数强制制造。

== 7. 防剧透边界 ==
来信时不泄露彗星、脑干杀招或上里全貌。A.A.A的观察与机理知识分开；NT14的姐妹危机与后续夺手不在本篇提前解答。

== 9. 收束结果 ==
- 原作默认：僧正被脑干消灭，城市免于彗星撞击，受损学校与魔神求助留下后续。
- 追击提前结束：停战、拘束或其他方法奏效，未发生的损毁不补演。
- 非致命分支：僧正生还，后续按其实际立场与约束继续，不默认为盟友。
- 城市善后：玩家留在救援线，理想送行线索暂存而不强制开启。
