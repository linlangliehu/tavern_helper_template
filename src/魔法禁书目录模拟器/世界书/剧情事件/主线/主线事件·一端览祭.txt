【事件包：一端览祭篇】
事件包ID：NT-ICHIHANARAN
所属阶段：阶段6·新约前段
时间窗口：本篇Y年11月14日至15日前后；按图排区分前夜与祭典当日，不强行分配所有战斗时刻
别名与触发词：一端览祭篇 / 芙罗兰克洛杜尼争夺 / 不死少女解放 / NT-ICHIHANARAN

== 1. 核心定位 ==
作品范围：新约5—6。NT5对应祭典前夜、索尔的邀约与不死少女出逃；NT6对应祭典当日的追逐、多战场牵制与替代脑救援。被格雷姆林与欧雷尔斯一方争夺的核心是芙罗兰·克洛杜尼，不应以“芙蕾梅亚争夺”代替她的身份。
芙蕾梅亚和最后之作在此是与她建立友谊的孩子；芙蕾梅亚成为人力资源计划核心是另一篇的因果。

== 2. 不可丢失的核心事实 ==
- 索尔借美琴的外表接近上条，提出先救出克洛杜尼、打乱双方利用她的安排。他追求战斗与成长，不等于已经退出格雷姆林成为无条件忠诚的伙伴。
- 上条与索尔破坏无窗大楼外壁时，克洛杜尼自行冲破拘束、离开大楼；不能把他们写成已经征服亚雷斯塔全部防线。
- 克洛杜尼在城市里与芙蕾梅亚、最后之作交朋友，却面临吞食最后之作大脑的功能性需求。她不愿伤害朋友，不是普通饥饿或主动猎食取乐。
- 复起的垣根帝督与多名强者加入争夺；白色独角仙05在接触孩子后选择保护她们，不再只执行原有杀戮目标。
- 原作上条组织的方案由辛德瑞拉制作糖果脑替代品，浜面与泷壶运送，以此骗过克洛杜尼的吞食需求。她缩小后仍被孩子们接纳；索尔与上条的单独决斗发生在救援之后。

== 3. 玩家可改写的部分 ==
- 可不接受索尔的全部安排，却与他在救人目标上临时合作；也可提前联系楼内外人员或寻找其他脱困办法。
- 可在需求发作前建立通讯、护送与替代物方案，避免孩子被当作引诱少女的诱饵。
- 可说服追杀方暂停、帮助独角仙05建立自主立场、替代原作决斗；救援成功不要求玩家再打赢所有参战者。

== 4. 节点推进表 ==
NT-ICHIHANARAN-01 索尔递出的第三种选择
进入条件：巴格吉城后已返城，祭典准备中接触索尔或不死少女的情报。
场景目标：分清索尔伪装、格雷姆林目标与欧雷尔斯一方的安排，判断是否先救被争夺者。
可见角色：上条、索尔；欧雷尔斯按其会面线索出现。
玩家行动：识别冒用美琴外表的来者，要求说明救援对象与地点，提出互不信任情况下仍可验证的合作条件。
结果：原作上条接受共同救人的方向而不承诺服从格雷姆林；玩家可另行调查，不把接受一次协作记成阵营效忠。
下一节点：进入NT-ICHIHANARAN-02；未获得位置时留在本节点补足线索。

NT-ICHIHANARAN-02 无窗大楼的裂口
进入条件：选择接近无窗大楼，或已经取得能接触克洛杜尼的替代通路。
场景目标：打开被拘束者的离场机会，并应对守备与建筑异常。
可见角色：上条、索尔、芙罗兰·克洛杜尼；附近守备单位。
玩家行动：协助牵制、准备撤退通道，观察她自身造成的变化，不把突破外壁误判为可以任意深入大楼。
结果：原作克洛杜尼冲破墙面与守备后进入城市，上条和索尔也被她的力量波及；玩家若协助平稳出逃，则保留她对救援者的实际印象。
下一节点：进入NT-ICHIHANARAN-03；她仍被拘束则继续本节点的救援。

NT-ICHIHANARAN-03 她获得的第一个联络点
进入条件：克洛杜尼进入城市，遇见芙蕾梅亚与最后之作，或玩家先找到她。
场景目标：在各方搜索抵达前，以交流而非归属标签理解她的行为。
可见角色：克洛杜尼、芙蕾梅亚、最后之作；上条与索尔沿追踪线到场。
玩家行动：帮助她理解城市与通讯，保留孩子们建立的联络，询问本人意愿，隐蔽或公开保护地点。
结果：原作少女与两个孩子建立友谊，这使后来吞食需求成为她最不愿接受的矛盾；玩家可提前建立警示与求助约定，避免只把她看成材料。
下一节点：进入NT-ICHIHANARAN-04。

NT-ICHIHANARAN-04 前夜留下的相反目标
进入条件：各方得知少女出逃，围绕“夺取、消灭或救援”发生分歧。
场景目标：在NT5前夜收束时确认保护对象、伤员状态与敌我目标，为次日行动准备实际方案。
可见角色：负伤的上条、索尔、柏德蔚；玛莉安及欧雷尔斯一方按接触出现。
玩家行动：治疗与转移伤员，阻止把少女死亡当成唯一保险，收集她的身体需求与追踪方式，不伪装已知完整救法。
结果：原作没有在前夜解决争夺，NT6以负伤上条继续追赶她展开；若玩家已争取停火或庇护，则次日只保留仍有动机的追兵。
下一节点：祭典当日危机继续时进入NT-ICHIHANARAN-05；已安全解决则进入NT-ICHIHANARAN-09核对善后。

NT-ICHIHANARAN-05 垣根重返争夺
进入条件：祭典当日，克洛杜尼与孩子的踪迹暴露，垣根的未元物质介入。
场景目标：把追杀者与节庆人群隔开，防止保护者在地下与街面的不同战场失去联系。
可见角色：垣根帝督、一方通行、麦野沈利、浜面、泷壶、两名孩子。
玩家行动：疏散人群，维护通讯，支援被追赶者，区分未元物质的分体与本人意志，而非见白色构造就一律摧毁。
结果：原作一方通行与麦野牵制垣根，孩子们另寻生路；玩家可改变交锋地点与分工，不需要让每名原作战斗者同时在场。
下一节点：进入NT-ICHIHANARAN-06；可并行调查NT-ICHIHANARAN-07所需的替代方案。

NT-ICHIHANARAN-06 独角仙05不再照命令行事
进入条件：白色独角仙05与最后之作、芙蕾梅亚同行，原来的攻击目标与保护选择冲突。
场景目标：确认它是否能自主选择，保护孩子时不否认它来自垣根的事实。
可见角色：白色独角仙05、最后之作、芙蕾梅亚；垣根的控制与分体形成压力。
玩家行动：询问与验证它的承诺，帮助它切断不愿执行的命令，给孩子保留离开任何“保护者”的选择。
结果：原作独角仙05站到保护孩子的一方，未元物质内部不再只有原来的杀戮意志；玩家可建立其他可靠护送者，但不能直接删掉它自主选择的资格。
下一节点：进入NT-ICHIHANARAN-07；护送尚未完成时保留本节点。

NT-ICHIHANARAN-07 为替代脑争取时间
进入条件：确认克洛杜尼的吞食需求，辛德瑞拉等人的方案能取得材料与运输条件。
场景目标：让制作与运送替代脑的方案赶在杀人或处决之前完成。
可见角色：上条、辛德瑞拉、浜面、泷壶；柏德蔚、布伦希德、席尔薇娅、索尔、美琴分处相应战场。
玩家行动：协助制作与护送，向追杀方证明替代方案，牵制柏德蔚的消灭行动，或谈判暂停攻击。
结果：原作美琴、索尔等人牵制强敌，上条击败掌握关键术式的柏德蔚，使追杀行动失去继续基础；玩家若说服她接受方案，可免去决斗，不能因此取消仍在进行的运送。
下一节点：替代品与护送者到位后进入NT-ICHIHANARAN-08；尚缺条件则继续本节点。

NT-ICHIHANARAN-08 不必吃掉朋友的办法
进入条件：克洛杜尼与孩子们会合，糖果脑替代品或玩家验证过的救援方法抵达。
场景目标：满足危险的功能性需求，同时让保护者及时知道孩子们仍然安全。
可见角色：克洛杜尼、最后之作、芙蕾梅亚、白色独角仙05、浜面、泷壶；一方通行随后确认情况。
玩家行动：完成交付，防止不知情援军误判，检查替代方案效果，支持孩子们向她表达接纳。
结果：原作糖果脑骗过吞食需求，克洛杜尼缩小；最后之作及时阻止一方通行的误击，她仍被朋友接纳。玩家方案不同则记实际身体与关系状态，不硬套缩小结果。
下一节点：进入NT-ICHIHANARAN-09。

NT-ICHIHANARAN-09 救援之后的索尔
进入条件：少女与孩子已安全，主要战斗停止或玩家达成了替代收束。
场景目标：安置获救者，处理盟友之间仍未解决的战斗欲望与信任。
可见角色：上条、索尔、获救者；其他参战者按善后到场。
玩家行动：接受、拒绝或改换索尔的私下挑战，安排克洛杜尼的生活，复盘各方为什么要争夺她。
结果：原作索尔仍向上条挑战，这不表示救援失败；玩家可协商止战。孩子们的关系与白色独角仙05的保护选择延续到后续人力资源事件。
下一节点：人力资源实验的异常求助出现且玩家选择调查时进入NT-AGITATE-HALATION-01；否则返回祭典善后或日常。

== 5. 分支和偏离规则 ==
NT5的伤势、通讯与庇护安排必须带入NT6，不能跨卷清空。克洛杜尼、芙蕾梅亚与最后之作是不同的人，任何一人的身体状态不能替另一人写回。玩家救下少女后不以“为了原作”恢复吞食或追杀；后继只继承真实留下的关系与计划线索。

== 6. 换篇条件 ==
先明确克洛杜尼、两名孩子及追杀方的处理，再讨论索尔邀战或日常。NT7须由新的求助、土御门异常或人力资源计划迹象接入，不以祭典落幕强迫开启下一篇。

== 7. 防剧透边界 ==
开局不向玩家和全部NPC公开糖果脑解法、独角仙05的选择或垣根后续状态。索尔的临时协作不等于玩家知道NT8潜入者的身份；本篇也不提前揭露NT7药味久子的完整实验。

== 9. 收束结果 ==
- 原作默认：少女不再需要吞食朋友，独角仙05成为保护者，各方结束围猎，索尔另行邀战。
- 早期庇护：玩家在前夜阻断争夺，次日不再强行复演追杀。
- 协商救援：追杀方接受经验证的替代方案，多战场冲突提前停止。
- 暂留照护：玩家继续处理身体状态与生活安排，下一篇保持可选。
