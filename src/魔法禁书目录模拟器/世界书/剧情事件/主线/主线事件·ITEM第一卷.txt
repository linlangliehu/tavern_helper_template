【事件包：ITEM第一卷·保单竞技场与第五名少女】
事件包ID：ITEM-01
所属阶段：阶段0·旧约·前日谭
年层：Y−1（前史图排）
时间窗口：前一年夏季，七月主链；组队先导更早。调查、救援、对决与后日谈有相对先后，不把社区日序强锁成确日。
别名与触发词：ITEM第一卷 / 少女共栖第一卷 / ITEM保单竞技场 / ITEM第五名少女 / ITEM-01 / ITEM-01-01

== 1. 核心定位 ==
《某暗部的少女共栖》小说第一卷的主线是追查利用死亡保险与能力者竞技场敛财的另一支“ITEM”。绢旗加入后的四人接触候补华野超美，委托从保险公司延伸到地下比赛、人质救援与女贞木小路枫的逃亡。
本包保留已知原作因果和玩家介入机会，不用另一件原创委托替代本卷。葬礼及汇报只展开已知后果；悼念对象与完整幕后交代不凭猜想补齐。

== 2. 不可丢失的核心事实 ==
- 麦野是拥有强大火力的Level 5；泷壶负责追踪能力者发出的微弱力量，芙兰达擅长爆炸物与陷阱，绢旗承担氮气防御。
- 四人的合作发生在不能公开的暗部任务中；她们的日常相处与暴力工作并存，不是普通风纪委员小队。
- 后继小说第二卷的ITEM已正式由四人构成；不能用第一卷尚未明确的葬礼标签随意删去其中一人。
- 敌对ITEM由女贞木小路枫、鳄口锯刃、花山过蜜、井上拉斯佩齐娅构成；“敌对”是麦野一方的区分，不是另一队的正式冠名。
- 敌方用高额奖金吸引投保者参加允许杀人的能力者比赛，并从保险、转播和赌博获利；麦野一队的账户冻结与追查这件事有关。
- 华野不是仅有动画才出现的人物。电话女声使用过“华野超美”这一伪装；她的柔弱候补形象与幕后身份不可混成队员已知事实，也不能直接登记为确认死亡。

== 3. 玩家可改写的部分 ==
玩家可作为外围协助者、参赛者、被波及者或回忆听众，追查保单、识破候补的伪装、救援被俘者或截住逃亡者。可改变成员伤亡和敌方去向；这些互动方案是项目扩展，不能自动让所有角色共享幕后真相。

== 4. 节点推进表 ==
使用ITEM-01完整节点ID；每轮最多推进一个主要节点。调查、比赛突入、基地救援、终战和后日谈分轮处理。

ITEM-01-01 第四人与第五名候补
进入条件：玩家选择本卷前史；绢旗进入麦野一队，电话女声介绍华野超美。
场景目标：接下调查保险公司与能力者死亡的委托，同时判断候补能否随队。
可见角色：麦野、泷壶、芙兰达、绢旗、华野；电话女声通过通信接触。
玩家行动：核对委托对象、观察华野、约定外围协助或陪同取得保险公司高层的情报。
结果：四人与华野进入同一行动，账户冻结使任务资金也成为压力；华野的真实身份尚未向队伍揭示。
下一节点：ITEM-01-02。

ITEM-01-02 保单指向地下竞技场
进入条件：ITEM-01-01完成，保险公司线索可供追查。
场景目标：从高层人员与公司内部记录追到流动的地下比赛会场。
可见角色：ITEM四人、华野、保险公司相关人、参赛能力者。
玩家行动：协助潜入、比对投保与死亡记录、追踪资金或警告被奖金诱入比赛的人。
结果：查明保单、致死竞技与转播获利相连，并定位这次设在第七学区图书馆的会场；不是普通合法比赛。
下一节点：ITEM-01-03。

ITEM-01-03 同名ITEM的碰撞
进入条件：ITEM-01-02完成，敌方发现麦野一队潜入会场。
场景目标：在追赶携款者与保护留在会场的人之间分配战力。
可见角色：双方ITEM、华野及尚未撤离的参赛者。
玩家行动：支援麦野追击花山的高速载具、掩护芙兰达与绢旗，或协助华野带泷壶脱离。
结果：默认麦野击败并杀死花山；女贞木与鳄口压制芙兰达、绢旗，华野被俘。玩家救出她则按改写路线继续追踪基地，不强制补绑架。
下一节点：ITEM-01-04。

ITEM-01-04 人质在敌方基地反击
进入条件：ITEM-01-03完成，华野被关押，或改写后队伍找到敌方基地。
场景目标：救出人质并辨认华野并非毫无准备，不能把她只当等待救援的名单。
可见角色：华野、鳄口、井上、女贞木；麦野一队与玩家按实际抵达位置出场。
玩家行动：侦察关押处、配合脱离、阻止杀人或辨认华野的反制安排。
结果：默认鳄口与井上死于华野的反击，女贞木抛下现场逃离。基地失守不等于华野的全部经历已经向队伍公开。
下一节点：ITEM-01-05。

ITEM-01-05 巴士总站截住女贞木
进入条件：ITEM-01-04完成，女贞木准备经青森方向离开，再设法逃往海外。
场景目标：在巴士总站阻止竞技场主谋脱身，避免无关旅客卷入能力交锋。
可见角色：麦野、女贞木小路枫、旅客；其他队员依支援安排出现。
玩家行动：疏散、追踪出口、支援破解杀伤压击，或提出能改变敌人去向的谈判。
结果：默认麦野在一对一交战中杀死女贞木，敌对ITEM四人的行动链被打断；她自称第六位不等于官方排名获证。
下一节点：ITEM-01-06。

ITEM-01-06 葬礼与汇报后的另一张脸
进入条件：ITEM-01-05完成，进入葬礼、汇报与真相片段构成的后日谈。
场景目标：清点竞技场事件的损失，区分四人掌握的经过和电话女声的幕后身份。
可见角色：ITEM四人及实际参与后日谈者；华野的伪装真相只在有揭露条件的视角出现。
玩家行动：核对已知死伤、参与善后、追问华野去向或继续查电话联络链；未明确的葬礼对象不自行指定。
结果：默认敌对ITEM败亡、竞技场敛财行动被阻断，麦野四人继续接受暗部委托；华野这一面孔属于电话女声的伪装，不能结算成普通第五队员永久入队或确认死亡。完整葬礼与汇报细节留白。
下一节点：无；时间与委托条件具备且玩家选择后，另转ITEM-02-01。
