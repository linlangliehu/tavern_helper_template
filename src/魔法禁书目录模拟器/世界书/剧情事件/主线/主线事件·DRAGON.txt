【事件包：DRAGON篇】
事件包ID：DRAGON
所属阶段：阶段5·旧约·战争交接段
年层：Y
时间窗口：官动层10月17–18日都市主体；尾段仅写夜后未明与离境顺序，不强填下一日日期
别名与触发词：DRAGON事件 / 迎电部队人质事件 / 潮岸追杀事件 / DRAGON-01
证据定位：O36；旧约19及官介；官方动画年表；O32为镊子线索前因，O37为后继

== 1. 核心定位 ==
暗部大战取得的代码成为迎电部队与GROUP追查的目标，潮岸开始灭口；另一线是滨面救泷壶并从都市追杀中逃离。两线相遇后分别通向俄罗斯，不是三战已经开打的都市战场。

== 2. 不可丢失的核心事实 ==
- 迎电部队占据个人沙龙，以人质事件索取DRAGON情报。滨面为泷壶进入现场，与同在现场的一方相遇。
- 潮岸将追查DRAGON的GROUP列为目标；一方向亲船求助，获得与潮岸交涉的筹码，冲突仍升级。
- 艾扎力面对特库帕托与遭改造的托琪托莉；绢旗面对为砂皿复仇的史蒂芬妮，两条侧战不能只用暗部追杀四字带过。
- 杉谷压制结标并远程停用一方电极；一方利用杖中只针对远程控制的干扰反制，不等于主动切断御坂网络。
- 原作默认DRAGON的线索落到艾华斯现身，最后之作的负荷恶化；一方循禁书目录线索带她赴俄。
- 滨面再战麦野，带泷壶奔向机场；封锁被原子崩坏突破后离城。他们赴俄为了泷壶治疗，不是接受同一军方参战命令。

== 3. 玩家可改写的部分 ==
可救人质、保护GROUP、提前查出电极控制、援助绢旗与艾扎力、说服麦野或选择其他离境方式。救援与情报分别推进，不强制每个角色都再次受伤才允许战争篇开启。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口DRAGON-01。滨面与GROUP两视角可按未完成节点交错，异地线索用真实联络和报告传递，不倒拨时钟。

DRAGON-01 以人质索取答案
进入条件：17日夜迎电部队向统括理事会索取DRAGON情报。
场景目标：确认被占据的沙龙与人质安全，查明事件与镊子线索的联系。
可见角色：迎电部队、人质、GROUP联络者。
玩家行动：侦察、安排撤离、核实要求、向涉事者传递消息。
结果：DRAGON不再只是代码，掌握情报的一方开始反向清理调查者。
下一节点：DRAGON-02。

DRAGON-02 沙龙中的两个人
进入条件：18日夜滨面进入沙龙营救泷壶，一方也在现场。
场景目标：救出泷壶与人质，确认双方并非迎电部队同伙。
可见角色：滨面、泷壶、一方、迎电部队成员。
玩家行动：协同救援、澄清冲突、护送伤者、开辟离开通道。
结果：原作默认滨面与一方相遇；脱出沙龙不代表统括理事会的追杀结束。
下一节点：DRAGON-03；滨面视角可交错处理DRAGON-05。

DRAGON-03 潮岸的封口令
进入条件：GROUP成为潮岸清理目标。
场景目标：向亲船寻求交涉筹码，尝试逼止追杀而非继续无方向逃跑。
可见角色：一方、亲船、潮岸、GROUP成员。
玩家行动：护送会面、验证筹码、传递条件或保护其他调查者。
结果：原作默认交涉破裂，潮岸的武力与各成员旧敌分别逼近。
下一节点：DRAGON-04。

DRAGON-04 艾扎力的昔日同伴
进入条件：特库帕托与托琪托莉出现在艾扎力面前。
场景目标：识别托琪托莉遭改造的事实，阻止继续利用同伴与魔道书。
可见角色：艾扎力、特库帕托、托琪托莉；索绮特按已有关系和所在位置衔接。
玩家行动：救援、支援破术、截断操控或寻找保全受害者的办法。
结果：原作默认艾扎力苦战击败特库帕托，旧组织的追杀线获得实际处理。
下一节点：DRAGON-05；绢旗线已完成则接DRAGON-06。

DRAGON-05 绢旗面对复仇者
进入条件：绢旗脱离暗部新安排后遭追击，史蒂芬妮为砂皿复仇。
场景目标：支援绢旗抵挡袭击，同时查清六枚羽等追踪行动的真正目标。
可见角色：绢旗、史蒂芬妮；滨面、泷壶按联络加入。
玩家行动：救护、掩护反击、分析跟踪路线、转移受追杀者。
结果：原作默认绢旗击败史蒂芬妮，特殊部队真正盯上的是滨面，泷壶须与他继续逃离。
下一节点：DRAGON-06；艾扎力线未处理则先补DRAGON-04。

DRAGON-06 被停用的电极
进入条件：杉谷阻止GROUP接近潮岸，并压制结标。
场景目标：救出被压制者，反制电极被远程停用的威胁。
可见角色：一方、杉谷、结标、潮岸。
玩家行动：掩护、识别远程控制、保护一方启用已准备的干扰手段。
结果：原作默认一方用杖中的定向干扰摆脱遥控并击败杉谷，御坂网络支援没有被一并主动切断。
下一节点：DRAGON-07。

DRAGON-07 艾华斯的出现
进入条件：追查逼近DRAGON真实指向。
场景目标：面对艾华斯，辨认最后之作恶化与亚雷斯塔计划的联系。
可见角色：一方、艾华斯、最后之作。
玩家行动：保护孩子、核对现象、提取禁书目录与俄国方向的线索，或撤离危险显现场。
结果：原作默认艾华斯现身，最后之作陷入新危机；一方的目标转为寻找救治，而非已经获得所有计划答案。
下一节点：DRAGON-08；若滨面逃离线已完成则接DRAGON-09。

DRAGON-08 机场前的麦野
进入条件：夜后未明，滨面与泷壶逃向机场，麦野为复仇追来。
场景目标：保护泷壶，突破麦野与特殊部队造成的阻拦。
可见角色：滨面、泷壶、麦野、机场附近特殊部队。
玩家行动：救护、拖延、制止麦野、另找出境路线或尝试谈判。
结果：原作默认滨面再次击败麦野；登机道路上的封锁后被原子崩坏扫清，两人得以离城。
下一节点：DRAGON-09；GROUP线未处理则从DRAGON-03的未完成处承接。

DRAGON-09 两条赴俄道路
进入条件：主要救援与对抗均已有亲历、委托或场外结果，亦可记录明确跳过部分。
场景目标：分别确认一方与最后之作、滨面与泷壶的治疗目标及离境状况。
可见角色：两组人物各在自己的路线，不要求同时到同一机场。
玩家行动：护送、提供医疗联络、告别或选择继续其中一组视角。
结果：原作默认两组以不同理由赴俄；宣战可能已经作为外部消息发生，不为进WW3重演18日。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
早救最后之作或保住城市内治疗路线，可改变赴俄原因；不强迫再制造病情。旧约15的人物生死与伤情按既有偏移承接，各线完成记录保留，不以新包覆盖旧暗部节点。

== 6. 换篇条件 ==
DRAGON-09完成、明确退出/跳时或追杀与治疗危机提前解决即可换篇。主干接WW3-01或当前日期对应的未完成节点；英国BRITISH-ROYAL属并行独立包，必要时只接已核消息，不能自动标其全部完成。

== 7. 防剧透边界 ==
本案可揭艾华斯是DRAGON线索指向及救治方向，不预告战争终局、白翼或后世计划。后继战争照常开放，选择滨面视角不自动获得艾华斯会谈全部内容。

== 8. 状态写回契约 ==
同轮更新主线进度.正史锚点.当前锚点、主线进度.当前节点；主线进度.已完成节点/可触发节点整数组replace并保留未完入口和旧项。人质、追杀、电极、伤情与赴俄偏移写主线进度.正史锚点.玩家偏移，治疗与护送用任务追踪区分，不新增API。

== 9. 收束结果 ==
- DRAGON-END-A：近原作，GROUP冲破追杀，两组因各自救治目标赴俄。
- DRAGON-END-B：玩家保全人质和同伴，改变治疗或离境路线。
- DRAGON-END-C：部分亲历、其他场外结算，留下未核情报与具体承诺。
- DRAGON-END-D：原创救援或交涉，无强制复发、断援或伤害补偿。
