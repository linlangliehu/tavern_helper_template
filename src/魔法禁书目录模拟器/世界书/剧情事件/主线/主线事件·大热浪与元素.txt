【事件包：大热浪与元素篇】
事件包ID：NT-HEAT-WAVE
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年十二月上旬，介于NT15与NT17；保留冲突排期，不把项目12月9—10日窗当定论
别名与触发词：大热浪与元素篇 / 元素侵袭危机 / 常盘台水晶塔远征 / NT-HEAT-WAVE

== 1. 核心定位 ==
作品范围：新约16。冬季热浪与元素怪物使学园都市基础设施停摆，学校与避难点成为生存协作现场，最后才转向无窗大楼下的战斗及上里放逐。下一卷“夺回上里”单独承接，不把两卷压成同一个归还入口。

== 2. 不可丢失的核心事实 ==
- 唯一为逼出躲藏的上里阵营释放元素。府兰发现高温能压低元素活动，利用空间站微波制造热浪；元素与高温由不同直接行动造成，不能把一切统称为唯一的气候魔法。
- 超过五十摄氏度的热浪破坏供水、供电与通信，元素又潜伏在较凉的区域。寻找阴凉不等于安全，避难者必须权衡实际环境。
- 常盘台依靠美琴的A.A.A、食蜂的组织与学生协作建立庇护。水晶塔被当作控制目标，却是唯一识别并引出威胁的诱饵；远征期间后方遭袭。
- 上里阵营并未消失到新天地，而是藏身并准备反击。得知热浪真相后，上条随他们攻向无窗大楼下方，唯一使用吞并元素形成的A.A.A迎战。
- 原作唯一落败后利用大楼火箭推进器制造最后危机，上里为保护众人使用理想送行时抱有矛盾愿望，自己也被放逐；唯一再获右手，借“最后救援希望”胁迫女孩们追杀上条。

== 3. 玩家可改写的部分 ==
- 可改善水、遮蔽、通信与医疗，不以缺水或高温设置额外惩罚数值；困难通过具体场景呈现。
- 可提前识破水晶塔诱饵、保留常盘台后卫，揭露热浪来源并寻找不伤城市的抑制方法。
- 可中断推进器危机、提出替代保护方式，使上里不必自我放逐；成功就不强制开启NT17救回链。

== 4. 节点推进表 ==
NT-HEAT-WAVE-01 冬天失去电力的城市
进入条件：NT15之后，元素投放与异常高温真实发生，玩家位于城内或进入救援。
场景目标：确认水、电、通信与可移动范围，建立不依赖失效设备的联络。
可见角色：上条、临时学校师生、附近居民；元素以现场遭遇出现。
玩家行动：寻找安全水源、遮蔽与伤员，试验怪物对温度和光照环境的反应，避免让居民在无情报情况下进入阴暗区。
结果：原作学校转入求生协作，上条开始外出寻找突破；玩家可保住局部基础设施，后续不能为了表现末日把有效准备全部抹去。
下一节点：进入NT-HEAT-WAVE-02。

NT-HEAT-WAVE-02 学校之间的避难通路
进入条件：本地资源不足或收到常盘台仍维持防御的消息。
场景目标：在元素活动区连接不同避难者，争取补给而非让学校相互掠夺。
可见角色：上条、沿途学生、美琴、常盘台接应者。
玩家行动：侦察阴影与废弃道路，护送脆弱人员，协商物资交换，确认美琴的武装状态。
结果：原作上条接触常盘台的庇护体系；玩家可建立多点互助，不把常盘台视作无限供给且永不受袭的安全区。
下一节点：进入NT-HEAT-WAVE-03；未能安全转移者保留待救位置。

NT-HEAT-WAVE-03 常盘台与水晶塔远征
进入条件：进入常盘台组织的防御与调查，发现疑似元素控制点的水晶塔。
场景目标：判断远征价值、留守力量与通信条件，避免全部防线同时外出。
可见角色：美琴、食蜂、上条、常盘台学生。
玩家行动：核验控制点假设，安排侦察与预备队，协商是否让A.A.A出击，保护不能随队的学生。
结果：原作远征摧毁水晶塔，却暴露己方威胁并落入诱导；玩家识破诱饵时可改变远征和留守比例，不能被日期自动拉去同一战场。
下一节点：进入NT-HEAT-WAVE-04；放弃远征也须处理唯一仍在进行的追踪。

NT-HEAT-WAVE-04 后方不是永远安全
进入条件：唯一率元素攻击学舍之园，或玩家侦察到其对常盘台与A.A.A机库的部署。
场景目标：救出疲惫学生与伤员，阻止追击者利用返回队伍和后方防线的间隙。
可见角色：唯一、美琴、上条、常盘台守备学生；去鸣等上里阵营成员随后介入。
玩家行动：回援、转移伤员、保住机库资料，质询援助者为何等待，防止只救走少数主角就宣布学校全员安全。
结果：原作常盘台重创，上条被上里阵营带离并质问其迟援；玩家成功保护后方时，NT17不再默认学校被洗劫与美琴因此失控。
下一节点：进入NT-HEAT-WAVE-05；仍有伤员时保留学校救援任务。

NT-HEAT-WAVE-05 热浪背后的空间站
进入条件：接触藏身的上里阵营，能够向府兰追问高温与元素的关系。
场景目标：核实高温是抑制元素的应急办法，而非元素的单一来源，决定共同反击或先改善城市状态。
可见角色：上里、府兰、去鸣、上条、上里阵营。
玩家行动：核对空间站微波、温度阈值与唯一的部署，要求向受影响避难者提供可执行的说明，安排反击时的后方照护。
结果：原作上条得知阵营藏身与热浪来源，参与向无窗大楼进军；玩家可提出降温与拘束元素同步进行的方案，不让贸然停热把避难者送到怪物面前。
下一节点：选择对付唯一时进入NT-HEAT-WAVE-06；协作尚未成立则本节点继续。

NT-HEAT-WAVE-06 大楼下的元素武装
进入条件：队伍抵达无窗大楼下方，唯一已用元素构成自己的A.A.A。
场景目标：拆开武装、右手与建筑设施的多重威胁，给伤者留下撤离空间。
可见角色：唯一、上里、去鸣、府兰、上条及参与进攻者。
玩家行动：协作破坏元素核心，救出被封路线的人，争取取回右手，检查唯一败退时还能操作哪些设施。
结果：原作众人击败唯一的主要攻势，但她仍能利用大楼推进器制造绝境；玩家若控制设施并阻断最后手段，就保留有效成果，不凭空再造同样危机。
下一节点：进入NT-HEAT-WAVE-07；危机已被完全控制也在该节点核对人员与右手去向。

NT-HEAT-WAVE-07 被自己的右手送走的人
进入条件：推进器仍威胁众人，上里必须决定怎样保护他们，或玩家已提供替代脱困方法。
场景目标：在保护大家与上里自己想留下的愿望之间，寻找不必放逐本人的办法。
可见角色：上里、唯一、去鸣、府兰、上条、上里阵营。
玩家行动：制止推进器、护送撤退、帮助上里辨认矛盾愿望；若放逐已发生，则保住证据和右手线索，不接受唯一未经证明的垄断宣称。
结果：原作上里被自己使用的理想送行放逐，唯一重新取得右手，以救回可能性控制女孩们并下令杀上条；若玩家避免放逐，则只处理夺手与城市善后，不生成一个并不存在的待救上里。
下一节点：上里确被放逐且玩家选择救援时进入NT-KAMISATO-RESCUE-01；未放逐则返回救治与灾后恢复，可保留唯一追责线。

== 5. 分支和偏离规则 ==
热浪、元素、常盘台受损、右手归属与上里放逐分别存档。保护成功的学校与被救者不在下一卷重新受害。上里阵营受胁迫不是被唯一精神控制，可通过证据与替代希望改变立场。

== 6. 换篇条件 ==
先确认上里是否真的被放逐以及城市灾害是否仍持续，再决定NT17是否成立。卷序为15→16→17；各卷内部日历有冲突，不用固定“12月9—10日自动归还”覆盖行动。

== 7. 防剧透边界 ==
热浪来源与水晶塔诱饵应通过调查揭露；普通避难者不在开局知道府兰的空间站或教会身份。未到末战不宣布上里必然放逐，也不提前提供NT17连接新天地的解法。

== 9. 收束结果 ==
- 原作默认：元素战结束，上里被放逐，唯一用右手胁迫阵营，救回线开启条件成立。
- 上里留下：玩家解决最后设施危机，取消自我放逐，不强迫进入失踪救援。
- 庇护保全：常盘台或其他避难点得以保住，灾后人际关系按实际发展。
- 城市优先：玩家留在恢复与安置线，是否追查新天地由玩家决定。
