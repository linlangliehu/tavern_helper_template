【事件包：吸血杀手篇】
事件包ID：DEEP-BLOOD
所属阶段：阶段2·旧约·八月前段
年层：Y
时间窗口：八月上旬；官动层8月8日三泽塾事件、9日治疗余波
别名与触发词：吸血杀手事件 / 三泽塾事件 / DEEP-BLOOD / DEEP-BLOOD-01
证据定位：O06；旧约2及官介；官方动画年表（行动次序与日期层）

== 1. 核心定位 ==
从餐厅里的巫女到被炼金术控制的补习学校，救出被用作诱饵的姬神与再次被夺走的茵蒂克丝。奥雷欧斯的救人执念建立在过时的情报上，是对抗的关键而非新的正确清忆方法。

== 2. 不可丢失的核心事实 ==
- 姬神秋沙拥有吸引并杀死吸血鬼的吸血杀手，奥雷欧斯·伊萨德利用她寻找吸血鬼。
- 奥雷欧斯曾与茵蒂克丝同行；他试图借吸血鬼解决她的困境，却不知道七月的控制术式已经被解除。
- 三泽塾被其炼金术控制，入侵者会受记忆操作影响；黄金炼成使其确信的想象成为现实，不能只靠当作普通枪战通关。
- 原作默认上条证明茵蒂克丝已经获救后，奥雷欧斯动摇并攻击他；上条右臂被斩，断口出现龙头，恐惧使炼金术师失去对局面的掌控。事件后上条接受治疗，姬神脱离被利用的处境。

== 3. 玩家可改写的部分 ==
可提早告知救援事实、保护校内学生、协助姬神离开，或选择谈判终止炼成。右臂受伤和龙头显现不是必须表演的通关仪式；玩家救援成功不需要补上原作损伤。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口DEEP-BLOOD-01。

DEEP-BLOOD-01 餐厅里的巫女
进入条件：八月上旬遇见姬神，或收到三泽塾有关的求助。
场景目标：了解她正受某方控制，而非把吸血杀手当作传闻猎奇。
可见角色：姬神、上条、茵蒂克丝。
玩家行动：交谈、提供帮助、记下她离去方向。
结果：姬神与三泽塾之间的联系成为可追踪线索。
下一节点：DEEP-BLOOD-02。

DEEP-BLOOD-02 史提尔的委托
进入条件：史提尔要求处理三泽塾的魔法事件。
场景目标：确认救援目标、奥雷欧斯的身份及学校被控制的风险。
可见角色：史提尔、上条；玩家可安排茵蒂克丝的安全联络。
玩家行动：接受协作、核对情报、制定学生撤离路线。
结果：救姬神与查明炼金术据点成为行动目的，不预设所有在校者都是敌人。
下一节点：DEEP-BLOOD-03。

DEEP-BLOOD-03 被改写的入侵记忆
进入条件：进入三泽塾接触炼金术支配范围。
场景目标：发现校内异常并应对奥雷欧斯让入侵者忘记目的的处置。
可见角色：上条、史提尔、姬神、奥雷欧斯及受影响学生。
玩家行动：核查外部记录、相互提醒、救助学生或寻找再次进入的方法。
结果：原作默认两人被清除入侵相关记忆后离开；右手与预备措施使追查得以恢复。
下一节点：DEEP-BLOOD-04。

DEEP-BLOOD-04 茵蒂克丝被带走
进入条件：救援者恢复行动，茵蒂克丝也被卷入学校。
场景目标：追上奥雷欧斯，避免他继续把姬神当作吸血鬼诱饵。
可见角色：茵蒂克丝、姬神、上条、史提尔、奥雷欧斯。
玩家行动：营救、阻止伤害姬神、说明茵蒂克丝现状。
结果：炼金术师的真正目标从夺取据点转为他自认的救人计划。
下一节点：DEEP-BLOOD-05。

DEEP-BLOOD-05 已经不需要的救法
进入条件：能直接与奥雷欧斯对话或对峙。
场景目标：让他面对七月已成功救下茵蒂克丝的事实，识别黄金炼成对确信的依赖。
可见角色：奥雷欧斯、上条、茵蒂克丝、史提尔、姬神。
玩家行动：出示事实、劝他停手、抵抗其以命令塑造的攻击。
结果：原作默认他无法接受自己的努力已失去目标，转而敌视上条，确信开始动摇。
下一节点：DEEP-BLOOD-06。

DEEP-BLOOD-06 右臂断口的龙头
进入条件：谈判未能止战，或玩家正在执行替代制止方案。
场景目标：救下人质，破坏炼金术师对绝对支配的信念。
可见角色：上条、奥雷欧斯、史提尔、姬神、茵蒂克丝。
玩家行动：协同破术、保护伤者、解除束缚；可直接阻止断臂。
结果：原作默认右臂被斩后龙头显现，奥雷欧斯崩溃，控制解除；不在此解释龙头的终极本质。
下一节点：DEEP-BLOOD-07。

DEEP-BLOOD-07 三泽塾之外
进入条件：人质救出，进入官动8月9日治疗余波。
场景目标：治疗上条、确认姬神安置与学生安全。
可见角色：姬神、茵蒂克丝、上条、史提尔、医护人员。
玩家行动：探病、安排庇护、记录仍需处理的校内善后。
结果：原作默认上条右臂恢复，姬神获得脱离原处境的机会；她九月转学属后继。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
动机可以被说服，不强制炼金术师走向同一败局。未亲历部分通过事后报告补足；不同媒介的支线场景不混装成同一天的额外硬节点。既有已完成记录保留，偏移不自动回正。
