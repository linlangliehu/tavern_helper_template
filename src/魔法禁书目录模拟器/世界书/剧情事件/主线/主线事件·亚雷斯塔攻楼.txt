【事件包：亚雷斯塔攻楼篇】
事件包ID：NT-ALEISTER
所属阶段：阶段6·新约十二月
时间窗口：本篇Y年十二月十一日前后图排，接NT17、先于NT19；楼内经历不另换算日期
别名与触发词：亚雷斯塔攻楼篇 / 无窗大楼攻入 / 读取托特78引路 / NT-ALEISTER

== 1. 核心定位 ==
作品范围：新约18。府兰暴露的教会身份引发追踪，逃离学园都市的尝试又被舞夏身上的诅咒截断。上条一行只能反过来寻找无窗大楼的主人，调查城市为何围绕他的右手不断制造悲剧。
这是现时的攻楼与救援，不是把过去当作可以随意穿越的地图；亚雷斯塔的回忆只按当前调查已经取得的内容呈现。

== 2. 不可丢失的核心事实 ==
- 土御门与府兰求助，上条、茵蒂克丝、欧提努斯、舞夏等参与离城。城墙处舞夏被影剑诅咒刺中，草率消除术式会危及她的身体，不能将幻想杀手写成无需判断的万能急救。
- 业之链兽持续追踪，队伍利用无窗大楼推进器留下的入口反向进入。建筑内部并非普通楼层结构，队伍被分开后各自取得的信息不同。
- 引路的米娜·马瑟斯是“读取托特78”形成的存在，不是历史本人复活。她让上条接触亚雷斯塔的过去与其对相位火花的认识。
- 亚雷斯塔把女儿莉莉丝的失去与魔法的偶发悲剧联系起来，并把城市围绕上条配置的事件反过来归责于上条。动机、观察记录与他的责任转嫁必须区分；不能预先断言莉莉丝的灵魂也已消灭。
- 攀登过程被利用为召唤艾华斯的仪式。原作同伴的干预使显现难以维持，米娜协助破坏爆破杖优势，上条才得以打倒亚雷斯塔。
- 亚雷斯塔倒下不等于科隆尊被解决。原作随后出现的袭击和坠落救援把队伍带入NT19，攻楼不应提前结算英国终战。

== 3. 玩家可改写的部分 ==
- 可提前保护舞夏、阻止诅咒附着或寻找安全解除方式，不以她必须受伤作为进入本篇的费用。
- 可改变队伍分工、保存调查记录、拒绝接受亚雷斯塔的归责说法，另行要求停止追踪与救治承诺。
- 可拆解仪式或谈判停战，避免原作坠落；若改变美琴的A.A.A状态，后续按真实装备与救援条件演绎。

== 4. 节点推进表 ==
NT-ALEISTER-01 被截断的离城路线
进入条件：府兰受到追踪，土御门等人提出保护她与舞夏离开学园都市。
场景目标：确认追兵和边界防御为何针对同行者，优先维护舞夏的安全。
可见角色：上条、土御门、府兰、舞夏、茵蒂克丝、欧提努斯；显现的追踪术式。
玩家行动：侦察城墙，护送非战斗成员，检测影剑与身体的联系，阻止未经确认就强行消除术式。
结果：原作离城失败，舞夏身上的诅咒迫使队伍寻求施术者；若玩家安全脱离或避免附咒，保留成果，以追踪未解除或主动问责作为可选后续，不重新制造同一伤害。
下一节点：选择进入大楼寻求解法时进入NT-ALEISTER-02；安全离城且不再追查则按实际偏移收束。

NT-ALEISTER-02 从推进器入口进入
进入条件：决定接触亚雷斯塔，掌握无窗大楼下方可利用的入口。
场景目标：在追击与异常内部空间之间建立可靠的救援和联络路线。
可见角色：上条与同行队伍；分离后出现的读取托特78所化米娜。
玩家行动：留下路径标记，安排伤员保护，检查空间变化，询问米娜能够提供什么与她为何帮助来者。
结果：原作队伍被分开，上条接受米娜引导；玩家可维持更多联络，但不能让未取得的楼内情报自动传到每名同伴手中。
下一节点：取得通向记录与上层的路径后进入NT-ALEISTER-03。

NT-ALEISTER-03 不可代替现人的过去
进入条件：米娜能够展示与亚雷斯塔计划相关的过去记录。
场景目标：理解黄金结社、女儿与相位火花如何塑造计划，同时分辨记录和当事人的解释。
可见角色：上条、米娜；记录中的亚雷斯塔与相关人物，不视为现在可以召来的角色。
玩家行动：询问记录来源，比较失去女儿与消灭魔法的因果主张，保存有用线索，拒绝把所有偶然伤害归罪给受害者。
结果：原作上条理解亚雷斯塔的动机，却未接受城市悲剧因此合理；玩家可表达不同评价，不能只因观看影像就改写前一年或更早的现实历史。
下一节点：准备回应现时计划时进入NT-ALEISTER-04。

NT-ALEISTER-04 谁应承担城市的选择
进入条件：上条抵达能与亚雷斯塔直接交涉的位置，舞夏救治和追踪问题仍需处理。
场景目标：把“城市为上条而设计”的说法与设计者的具体决定区分开来。
可见角色：上条、亚雷斯塔、米娜；按实际联络接入的同伴，美琴与食蜂可从楼外支援。
玩家行动：要求解除追踪和诅咒，指出同伴不是试验材料，讨论停止计划的条件，观察其灵式绊足与爆破杖造成的威胁。
结果：原作上条拒绝退缩，冲突继续；玩家可以达成局部承诺或停战，不能因同情亚雷斯塔而替所有受害者表示同意。
下一节点：仪式或武力对抗继续时进入NT-ALEISTER-05；谈判已经解除危险则先确认履约，再进入NT-ALEISTER-06处理余波。

NT-ALEISTER-05 被攀登完成的召唤
进入条件：亚雷斯塔利用此前行动推进艾华斯显现，队伍能够干预仪式或爆破杖。
场景目标：解除复合优势，使救援不再取决于承受无止境的强攻。
可见角色：上条、亚雷斯塔、米娜、显现中的艾华斯；实际取得支援位置的同伴。
玩家行动：识别攀登与召唤的关联，协调楼内外干预，保护米娜，切断术式条件或夺下爆破杖。
结果：原作同伴干预使艾华斯消失，米娜打落爆破杖，上条击倒亚雷斯塔；若玩家提前瓦解仪式或得到有效停战，不补演必输再反击的固定流程。
下一节点：进入NT-ALEISTER-06。

NT-ALEISTER-06 胜负之后的袭击
进入条件：攻楼主要冲突已有结果，队伍开始救治与撤离。
场景目标：应对科隆尊的突袭，确认坠落者、伤员和分散的亚雷斯塔的实际处境。
可见角色：现场同伴、亚雷斯塔、科隆尊；具备救援条件时的美琴。
玩家行动：保护倒下者，建立接应路线，核对谁仍留在楼内，追踪大楼被用作载具的迹象。
结果：原作科隆尊袭击亚雷斯塔，其他同伴由美琴的A.A.A接住，上条由少女形态的亚雷斯塔救下；玩家若改变坠落或装备，使用已成立的替代救援。科隆尊的行动尚未终结。
下一节点：科隆尊与城市后续仍成立时进入NT-PROCESSOR-SUIT-01；否则按已经改变的追踪、救治与撤离结果收束，不强造第二次袭击。

== 5. 分支和偏离规则 ==
保护舞夏、解除追踪、阻止仪式是可分别完成的目标。玩家不必同意亚雷斯塔的宏观立场才能救人，也不必把所有冲突压成一次拳击。回忆展示不创建历史穿越权限；提前改写的事实向NT19连续继承。

== 6. 换篇条件 ==
攻楼的对抗、受保护者处境及撤离有明确结果后收束。NT19以科隆尊的后续行动和城市危机进入，不由日期到点或自动阶段切换触发。玩家可明确暂离、跳时或终止追查，保留未解决事项。

== 7. 防剧透边界 ==
进入楼前不直接公开米娜的引导内容、攀登仪式与科隆尊突袭。NT19对莉莉丝的揭示不提前转成众人常识；英国篇的魔导书复制体和终战仪式不在这里说明。

== 9. 收束结果 ==
- 原作默认：上条击倒亚雷斯塔，科隆尊随后突袭，救援与反制延续到NT19。
- 救援先行：玩家先解救舞夏、减少队伍分离，再与计划制定者交涉。
- 仪式止息：玩家提前切断召唤或达成可信停战，不强制重演原作交锋。
- 暂离问责：已有安全出口但计划尚未解决，保存证据与未履行的承诺。
