【事件包：未元物质】
事件包ID：DARK-MATTER
所属阶段：阶段3·九月科学侧外传
年层：Y（当前年）
时间窗口：九月候选窗口；图排9月7日—9日，社区历表仅将第4话定位为约9月8日，不能据此把全篇压成一天或确定全部起讫。
原作范围：独立漫画《とある科学の未元物質》1卷4话；不是10月9日暗部大战的替代包。
别名与触发词：未元物质外传 / 杠林檎事件 / DARK-MATTER / DARK-MATTER-01

== 1. 核心定位 ==
垣根帝督接触暗黑五月计划的幸存者杠林檎，想从她身上取得一方通行演算模式的数据。少女也受到DA、黑夜海鸟和木原一方的觊觎。玩家可作为目击者、临时保护者、资料调查者或与垣根利益部分一致的协力者介入。
本包围绕接触、数据目的、争夺与少女自身状态展开。以下调查顺序是可选择的推进路径，不宣称官介已经证明各追逐者依次登场的逐话顺序；少女与数据的最终去向不作自动结案。

== 2. 不可丢失的核心事实 ==
- 垣根是第二位，他的起始目的包括取得第一位演算模式。不能开场便把他改写成无条件的监护人，也不能因他的功利动机抹去后来可能产生的选择。
- “暗黑五月计划”是研究计划名称，不是本篇必定发生在五月的日期证据；实验背景不能与当前追逐折叠。
- 林檎是计划幸存者，有记忆逐渐脱落的表现；流乡知果与她的实验创伤有关，只能通过往事与证言呈现，不能当作当前等待集合的活人队友。
- 林檎通常表现为低等级念动力，强烈压力下出现的异常输出不能被泛化为完整复制一方通行或随时使用全部矢量操作。
- DA、黑夜海鸟、木原一方均觊觎少女的力量；“也在争夺”不等于他们彼此结盟，更不保证与死灵术师事件中的DA行动是同一天、同一队伍。
- 取得演算模式信息不等于垣根已经击败第一位；本篇与后续暗部大战、其他时期的未元物质个体必须分开。

== 3. 玩家可改写的部分 ==
玩家可优先保护林檎、协商资料用途、拒绝以压力诱发能力、追查实验责任或选择不与垣根合作。允许保护与情报交易达成不同结果，不以“必须走向暗部大战”强迫牺牲少女。
垣根的态度、资料取得程度和少女愿否接触他人分别由行动推动。未经建立的医疗方案不能一句话治好记忆问题，也不能凭知道原作篇名直接获知追逐者位置。

== 4. 节点推进表 ==
每轮最多一个主要节点。DARK-MATTER-03与DARK-MATTER-04可按取得的线索互换；已经处理的节点不重复结算。

DARK-MATTER-01 少女与第二位
进入条件：玩家进入候选九月窗口，目击林檎与垣根接触，或受托寻找这位计划幸存者。
场景目标：确认少女的处境与垣根的来意，而非直接加入某一暗部阵营。
可见角色：杠林檎、垣根帝督。
玩家行动：询问需求、观察双方关系、提出临时陪同或保持距离、确认是否有人追踪。
结果：默认垣根与林檎建立接触，数据目的成为双方行动中的张力；玩家获得保护或调查的入口。
下一节点：DARK-MATTER-02。

DARK-MATTER-02 演算模式的代价
进入条件：能与垣根或林檎谈及计划，或取得与实验有关的可信资料。
场景目标：弄清为什么少女会被当作通向第一位的数据渠道。
可见角色：垣根、林檎；研究信息须经记录或当事人陈述进入视野。
玩家行动：核对实验名称、询问数据用途、限定交换内容、提出不刺激林檎的保护条件。
结果：默认垣根求取演算模式的动机明确；计划受试者身份并不等于林檎能够安全且随意交出完整数据。
下一节点：DARK-MATTER-03；先得到黑夜或木原线索也可进入DARK-MATTER-04。

DARK-MATTER-03 DA的争夺线
进入条件：确认DA在追索林檎，或玩家正在核实追踪者身份。
场景目标：避免少女被当作可交接的研究物品，并识别这条争夺线的行动范围。
可见角色：林檎、垣根；DA人员仅在实际追踪或接触后出现。
玩家行动：警戒、改变会面地点、核对来者身份、记录追索理由、拒绝无依据的交人要求。
结果：DA是争夺者之一的风险得到处理或保留；不自动宣告所有DA成员被消灭，也不套用死灵术师篇的战斗成果。
下一节点：DARK-MATTER-04；该线已处理则到DARK-MATTER-05。

DARK-MATTER-04 黑夜与木原的目的
进入条件：获得黑夜海鸟或木原一方的线索，能继续调查另一组争夺者。
场景目标：分辨不同追逐者对少女力量的需求，防止把他们误认成同一支救援队。
可见角色：垣根、林檎；黑夜海鸟或木原相关人物按实际接触分场出现，不默认齐聚一室。
玩家行动：跟踪线索、比较实验诉求、与其中一方谈判、拒绝危险演示、给少女保留撤离选择。
结果：争夺不止DA一条线；各方知道什么、控制什么分别记录，不能由姓氏推断完整研究方案与终局胜负。
下一节点：尚未处理DA线时可回DARK-MATTER-03，否则到DARK-MATTER-05。

DARK-MATTER-05 断落的记忆
进入条件：林檎的记忆问题影响行动，或她愿意谈及实验中的朋友。
场景目标：在追逐压力下保护她的判断空间，分开当前能力现象与旧日创伤。
可见角色：林檎、垣根；流乡知果仅在回忆或记录中出现。
玩家行动：倾听、记录她愿意保留的线索、避免逼迫回忆、寻求可信帮助、阻止以恐惧反复诱发力量。
结果：林檎不再只是数据线索；玩家可以改变对待她的方法，但不自动消除创伤或宣告完整复制矢量操作成功。
下一节点：DARK-MATTER-06。

DARK-MATTER-06 保护与数据的选择
进入条件：已了解主要争夺风险，并形成继续保护、交涉或退出的方案。
场景目标：明确接下来由谁保护少女、如何处理资料与尚未摆脱的追逐。
可见角色：仍与玩家同行的林檎、垣根及确已建立联系的人。
玩家行动：执行撤离或交涉、限制数据使用、安排实际可行的接应、保留研究责任线索。
结果：默认收束到“垣根与少女的关系、数据目标和多方追逐已经显明”的阶段；不自动宣告林檎获救、死亡、失踪或垣根已经得到全部数据。玩家实际完成的保护可作为本线局部结果。
下一节点：DM-END-A／DM-END-B／DM-END-C。

== 5. 偏离与改写 ==
支持保护、交易、追责或退出，不补演被玩家避免的伤害。未证的交战顺序与人物终局保持开放；只有实际发生的行动才进入世界线记录，不能把某一自由方案称为漫画默认结局。

== 6. 换篇条件 ==
阶段性保护与风险交接完成，或玩家主动换篇即可退出。死灵术师、神之饮物及暗部大战均须检查自身窗口另行选择；本篇没有强制通向暗部大战的死亡门槛。

== 7. 防剧透边界 ==
初见只呈现少女的状态与垣根的可见行为；实验创伤、其他追逐者与数据用途分层揭露。不能把未来人物形态或后来的胜负当作当前全知情报。

== 9. 收束结果 ==
- DM-END-A 默认阶段收束：垣根的数据目的与多方争夺已显明，少女的处境尚待后续解决；不等于1卷4话全部结案。
- DM-END-B 玩家主导：按实际完成的保护、撤离或资料方案交接，未处理的风险继续存在。
- DM-END-C 玩家退出：记录已知事实和未决事项，不强制少女遭难、不惩罚退出。
