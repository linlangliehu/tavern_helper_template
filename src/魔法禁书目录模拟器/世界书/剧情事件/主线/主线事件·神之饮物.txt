【事件包：神之饮物篇】
事件包ID：NECTAR
所属阶段：阶段3尾部·旧约·九月科学侧外传
年层：Y（当前年）
时间窗口：死灵术师事件解决后稍后；图排约Y年9月13日—14日，旧项目窗9月9日—14日，不把两种排期合并成已证精确日。
原载范围：《科学的一方通行》漫画7—12卷后弧，第7卷与前弧交界；不是科方动画已经改编的内容。
别名与触发词：神之饮物篇 / 神の飲み物 / Nectar / NECTAR / NECTAR-01

== 1. 核心定位 ==
保留既有科方后弧：姬戏茉离从天而降，使一方通行接触以治疗为名、以暴走能力者为原料的体晶供应体系。少女被掳后，调查从医院延伸至制药公司、Full Course和豪华客船上的食之宴。
前置是NECROMANCER已解决或玩家明确建立的等价世界线；不能只接在天使坠落后就把两弧倒序。后弧末尾与树状图设计者残骸的关联属于旧约8的相邻事件，不是大霸星祭本体。

== 2. 不可丢失的核心事实 ==
- 茉离体内有采集体晶的器械；一方通行自身伤势恶化倒下期间，她遭Full Course带走。器械不能无证改写为必定限时摘除的机械心脏。
- 亡本里藏（亡本裏蔵）是掌管学园都市食粮事务的统括理事会成员。Full Course受其指使，以料理相关称谓组织成员，并非不明来源的吸血宗教。
- スクナビコナ製薬以假部门RSPK第二研究所接触慢性能力暴走患者，用开发特效药的临床试验名义招揽，再利用其体晶或使其参与暗部行动。
- 飞雄ゆみ是风纪委员第105支部成员、静菜高中二年级学生；飞雄まみ是她的双胞胎妹妹，也是Full Course的“食前酒”，失去左眼并受慢性能力暴走困扰。二人关系不能交给临场随意编造。
- Full Course的Chef与Sous-chef等成员阻挡救援；敌方也有人被疾病和供应关系束缚，不能因暗部身份便自动判全部死亡。
- 对决舞台是豪华客船埃斯科菲耶号与食之宴。打败护卫、救出患者、医疗脱险和追究亡本责任是不同结果，不能一次战斗自动打包完成。

== 3. 玩家可改写的部分 ==
可提前保护茉离、追踪掳人路线、协调飞雄姐妹、破坏体晶供应或潜入宴会。玩家可以谈判、截获证据、选择救援优先或追责优先；不强制代替一方通行杀敌，也不强制接受以弱者作原料的交易。

== 4. 节点推进表 ==
每轮至多推进一个主要节点；完整保留NECTAR节点，不用同月祭典替代本弧。

NECTAR-01 从天而降的“公主”
进入条件：死灵术师事件已收束，一方通行外出时接触茉离。
场景目标：处理少女坠落后的异常，找出体内器械与病情线索。
可见角色：姬戏茉离、一方通行、打止或病院人员（依现场）。
玩家行动：救护、询问来历、安排检查、保护她免受跟踪。
结果：体晶采集器与身体异常进入调查，不能把少女当成未知型号机器人。
下一节点：NECTAR-02。

NECTAR-02 公主失窃
进入条件：Full Course趁一方通行伤势恶化夺走茉离，或其掳人行动被玩家发现。
场景目标：查清带走者并保住追踪机会。
可见角色：一方通行、病院人员、Full Course行动者；茉离视追踪进度出现。
玩家行动：截救、追车、记录接触者、保护伤者或联系风纪委员。
结果：默认茉离被带走；若截救成功，以追查供应体系替代重复绑架。
下一节点：NECTAR-03。

NECTAR-03 饮物的原料
进入条件：获得采集器、药品或患者招募线索。
场景目标：追查临床试验与体晶供应的联系。
可见角色：一方通行、接触到的患者、制药或研究所相关人员。
玩家行动：核对招募记录、查假部门、访问患者、保存器械证据。
结果：确认Nectar并非无害饮品，暴走能力者才是被剥削的来源。
下一节点：NECTAR-04。

NECTAR-04 同翼相争
进入条件：调查接触飞雄姐妹或“食前酒”的行动。
场景目标：区分ゆみ的风纪委员身份与まみ的暗部、患者处境。
可见角色：飞雄ゆみ、飞雄まみ、一方通行（按实际相遇）。
玩家行动：辨认身份、询问病情、交涉、阻止冲突或安排保护。
结果：双胞胎关系与供应控制成为可利用的事实，不能把二人当同一人切换身份。
下一节点：NECTAR-05。

NECTAR-05 受试者与供应链
进入条件：查明假临床试验或姐妹的受控处境。
场景目标：寻找其他患者，避免只救眼前一人却保留同样的剥削。
可见角色：实际找到的受试者、飞雄姐妹、Full Course相关者。
玩家行动：安排撤离、寻找医疗替代、备份证据、追查资助者。
结果：亡本与体晶体系的联系浮出；尚未获救者逐一保留为救援目标。
下一节点：NECTAR-06。

NECTAR-06 食之宴请柬
进入条件：掌握埃斯科菲耶号与食之宴的位置或进入线索。
场景目标：选择接近敌方本部的方式，先划定患者保护与撤离路线。
可见角色：一方通行、船上工作人员、Full Course守卫。
玩家行动：潜入、正面突破、利用接触关系或配合场外救援。
结果：进入客船行动阶段；掌握会场不等于已救出所有患者。
下一节点：NECTAR-07。

NECTAR-07 恶党上桌
进入条件：抵达食之宴，或Full Course开始阻止救援。
场景目标：对抗Chef、Sous-chef等阻力，打断以患者为原料的宴会。
可见角色：一方通行、Full Course成员、船上宾客与被控制者。
玩家行动：作战、切断供应、疏散、掩护救人或要求交人。
结果：对决进入决着；每名敌人和患者的结果按实战分别记录。
下一节点：NECTAR-08。

NECTAR-08 以恶制恶的收账
进入条件：宴会防线被突破，仍有少女或患者未脱离控制。
场景目标：继续救援并追查责任，不把护卫战胜利误作全部医疗结局。
可见角色：一方通行、仍待救出的少女、实际可接触的亡本一方与医护。
玩家行动：追索控制者、交接患者、封存材料、落实后续治疗或协商条件。
结果：已发生的救援与阻断可收束；未确认的手术、亡本处置和个体去向保留，不自动宣告全灭或自首。
下一节点：NT-END-A／NT-END-B／NT-END-C／NT-END-D；未结医疗或追责保留为任务。

== 5. 偏离与改写 ==
提前救走茉离、策反某成员或让宴会失去原料，均按真实因果改写后续节点。允许玩家选择非杀伤与原创解法，不以“恶党”主题强迫其施暴；也不能凭一份协议自动抹去患者的危险。

== 6. 换篇条件 ==
NECTAR-08达成本次救援收束，或玩家明确退出、换锚、跳时越窗，或供应体系合理提前瓦解，才关闭本篇。先保留死灵术师的结果，再按玩家选择进入残骸等相邻篇，不自动跳往祭典。

== 7. 防剧透边界 ==
不将Nectar归入科方动画，不借动画前弧替本弧补结局。后续残骸关联只在其时间与条件成立时引用，不提前演出旧约8或0930。一方通行未来成长、未发生的医疗结果及人员生死不得预先结算。

== 9. 收束结果 ==
- NT-END-A 默认推进方向：在食之宴与Full Course决战后，继续以一方通行的方式救出仍受都市黑暗控制的少女。只结算已落实的救援，不附加全员死亡、亡本必然自首或特定手术必定成功。
- NT-END-B 玩家主导：以实际突破和救护结果结束本次行动，后续照料与追责可以继续。
- NT-END-C 交易收束：释放、治疗与停止采集须逐项兑现；供应体系没有被改变时不假称永久解决。
- NT-END-D 玩家退出：保留已救与未救名单、器械状态和剩余线索，不默认一切已由背景角色完成。
