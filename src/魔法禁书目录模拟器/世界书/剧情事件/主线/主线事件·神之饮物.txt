【事件包：神之饮物篇】
事件包ID：NECTAR
所属阶段：阶段3尾部·旧约·天使坠落季（与天使坠落篇时间带内共存，嵌套先例：死灵术师篇之于天使坠落篇）
时间窗口：9月9日—9月14日（死灵术师篇收束后、恩底弥翁/大霸星祭前；原著一方通行外传后半"神の飲み物編"置于此期）
别名与触发词：神之饮物 / 神の飲み物 / Nectar / 姬戏茉离 / 体晶 / Full Course / 食之宴 / 亡本里藏 / 埃斯科菲耶号 / NECTAR

== 1. 核心定位 ==
本篇是一方通行视角的暗部守护事件第二幕：死灵术师篇的风波刚过，一方通行从医院溜号透气，撞上从天而降的超任性少女姬戏茉离；她体内埋着采集"体晶"的器械——暗部组织Full Course正以"神之饮物（Nectar）"为名，把暴走能力者当活体原料榨取。事件主题是"恶党的正义"——自认最凶的恶，用恶的方式兜住被都市黑暗吞掉的人。
玩家进入本篇的方式：开局锚点直接选在本篇；或在阶段3尾声（9月上中旬）于医院区活动、街头偶遇坠落的"公主"、或追查暴走能力者失踪传闻时卷入。玩家立场自由：吃瓜路人被茉离缠上、一方通行一行的同行者、Full Course的渗透者、暴走能力者救援队、或理事会暗线调查员。

== 2. 不可丢失的核心事实 ==
- 一方通行现状：仍处静养期（电极+妹达网络演算支援），乱来就会晕倒；刚经历死灵术师篇，伤势未愈却按捺不住。自称恶党，但把保护打止止当绝对行动准则。
- 姬戏茉离：低能力者少女，自封"公主"、偏好"高贵"服饰、说话像发布敕令；极端任性（硬赖一方通行"碰了本公主"要他当奴隶），却把"救助困境之人"列为自己的绝对规则；长期被囚禁、路痴；与打止止意外投缘。真相：她是能产出A级高纯度Nectar的暴走能力者，被亡本里藏当作"食材"登记管理。
- 体晶：暴走能力者体内被植入采集器械、定期榨取的结晶物质——Nectar的原料；采集过程无异于把人当果树轮伐。
- 神之饮物（Nectar）：暗部黑市流通的"奇迹饮品"，服用者能力数值被短暂拔高，上流圈以天价竞逐；其"原料真相"是本篇最大的黑暗。
- Full Course：以"食"为业的暗部组织，话术里把人当食材分级；在豪华客船"埃斯科菲耶号"上举办秘密"食之宴"。
- 亡本里藏：本篇幕后黑手，从死灵术师篇起就以"食"系权力者身份潜伏的理事会关联人物；表面绅士，实际把人命当食材账本管理。
- 空力使双子姐妹：两名持有同系空气操作能力的少女，本篇中段的宿命对决；败者坠入"学园都市救不回的黑暗"——Nectar产业黑暗面的缩影（姐妹姓名与恩怨细节按玩家遭遇即兴补全，不与主线冲突即可）。
- 机械心脏少女：被Full Course榨取至深的暴走能力者，心脏已被换成拟似心脏；一方通行住院期曾与她有交集（本卡暗部传闻线既有人物）。
- 终局事实（原著重力线）：一方通行杀入埃斯科菲耶号，全灭Full Course、砸毁宴会会场，胁迫亡本向警备员自首（失脚）；随后与冥土归し合作数小时，为受害暴走能力者摘除拟似心脏。打止止对归来的"英雄"说的话，是本篇的温柔收束点。
- 战斗基调：一方通行电极态（黑翼未觉醒），矢量碾压常规战力但持续时间受限；玩家能力跨体系混用无反噬。

== 3. 玩家可改写的部分 ==
- 茉离的结局：提前救出、宴会上截胡、或由玩家收留安置，均合法。
- 双子姐妹的宿命对决：可以阻止、可以干预结果、可以让两人都活——姐妹的去向由玩家改写。
- Full Course的覆灭方式：全灭、招安、交理事会清洗、或留作玩家的情报渠道，自选。
- 亡本里藏的下场：胁迫自首（原著近似）、玩家亲手料理、风纪委员+警备员联合曝光、或谈成污点证人，均合法。
- Nectar流通网络：揭穿曝光、控制货源、销毁配方、或留作日后筹码（记录进世界线）。
- 拟似心脏摘除手术的参与度：旁观、帮忙、或由玩家的能力/人脉改变手术结果。
- 与一方通行的关系：临时队友、被茉离强行编入的"仆从"、暗部同行、或互相看不顺眼的合作，均可。

== 4. 节点推进表 ==
节点ID格式：NECTAR-{NN}（必须使用完整ID，禁止简写）。每轮最多推进一个主要节点；推进必须有玩家行动、时间流逝、事件结果或势力介入支持。

NECTAR-01 从天而降的"公主"
触发：玩家进入9月9日-14日窗口并接近第10-11学区医院带（探望/路过/追查传闻）。
内容：一方通行溜出医院透气；茉离从天而降砸进现场，蛮横宣布"本公主与你结缘"；打止止与她火速投缘；茉离突然倒地——检查发现体内埋着体晶采集器械；一方通行伤势恶化晕倒。
完成：玩家与茉离/一方通行任一方建立接触，或确认"体晶"的存在。
下一节点：02。

NECTAR-02 公主失窃
触发：01完成+一方通行倒地休养期间。
内容：茉离在混乱中被Full Course掳走；线索指向"食"系流通网络；机械心脏少女的传闻与"食材失踪"传闻合流；一方通行醒来——这场恩怨从"麻烦"升级成了"恶党的私人恩怨"。
完成：确认掳走茉离的是Full Course，或玩家拿到宴会/流通线情报。
下一节点：03。

NECTAR-03 饮物的原料
触发：02完成或玩家主动追查Nectar黑市。
内容：Nectar流通链曝光——"奇迹饮品"以暴走能力者的体晶为原料；亡本把既有暗部研究理论转用量产的内幕浮出；可联动乱雑開放事件余波（同为暴走能力者受害链）。
完成：玩家掌握"原料=人"的核心黑暗事实。
下一节点：04。

NECTAR-04 同翼相争
触发：03完成+玩家追查受害暴走能力者下落。
内容：空力使双子姐妹登场；同能力者的遭遇战打响；玩家可在场、劝架、下注或介入姐妹恩怨；"败者会被都市黑暗吞掉"的规则显现。
完成：玩家与双子姐妹任一方建立接触，或目击宿命对决。
下一节点：05。

NECTAR-05 救不回的黑暗
触发：04完成/进行中。
内容：姐妹对决的结果揭晓（原著重力线：败者坠入黑暗，一方通行目睹后怒而行动）；Full Course的"食材分级"制度曝光；救援名单确定——茉离、其同伴、以及被榨取的暴走能力者群体。
完成：玩家明确救援目标与突入路线。
下一节点：06。

NECTAR-06 食之宴请柬
触发：05完成+宴会情报到位。
内容：豪华客船埃斯科菲耶号的"食之宴"入场情报（请柬/内应/武装突入方案）；自称料理人的少女出现在宴会后勤线（可作内应或线索人）；玩家选择潜入方式。
完成：突入埃斯科菲耶号的计划成立。
下一节点：07。

NECTAR-07 恶党上桌
触发：06完成。
内容：宴会开始，"禁忌食材"被端上桌；一方通行掀桌——矢量操作对Full Course能力者群的无差别碾压；玩家按自身立场同步行动（救人/控场/断后/揭发）。
完成：宴会会场被摧毁，或玩家达成自己设定的行动目标。
下一节点：08。

NECTAR-08 以恶制恶的收账
触发：07完成。
内容：亡本出逃被截；原著重力线=一方通行胁迫其向警备员自首、当众失脚；冥土归し主刀的拟似心脏摘除手术（数小时鏖战）；打止止对归来的"英雄"说出温柔收束台词；按第9章定收束结果。
完成：本篇收束。

== 5. 偏离与改写 ==
- 上述节点与结局是"原著重力线"，不是唯一路径：玩家可在任意节点改写目标、阵营、手段与结果。
- 篇章内偏离：允许把本篇玩成美食街日常/客船潜入战/暗部权斗/救援行动混合剧，只要不覆盖核心事实（茉离身份、体晶、Full Course、亡本）。
- 核心结果改写：茉离救不回、亡本逃脱或被玩家私刑、Nectar配方外流，均合法——以玩家偏移事实记录，不得静默回滚。
- 明确离开：玩家声明退出时按第9章NT-END-D收束，事件转为背景自行推进。

== 7. 防剧透边界 ==
- 本篇不揭示：一方通行黑翼的完整形态与觉醒机制、暗部大战（10月9日）之后的一切、Battle Royale各组织动向、恩底弥翁/大霸星祭内幕、新约系魔神与科隆尊。
- 亡本里藏只到"理事会关联的'食'系权力者"层级，不揭示其与理事会更深层的勾连网络。
- 相关暗部研究理论只到"既有成果被转用于量产"层级，不展开木原系后续与新约线。
- 茉离的过去只到"长期被囚禁、被当食材"层级，更深的背景不主动展开（玩家追问可即兴补全，但不得触及上述禁项）。
- 魔法侧势力（英国清教/罗马正教）不得作为本篇推动力；本篇是纯科学侧暗部事件。

== 9. 收束结果 ==
- NT-END-A 原著近似收束：Full Course全灭、会场砸毁、亡本向警备员自首失脚、茉离与同伴获救、拟似心脏摘除成功、暴走能力者转入保护。
- NT-END-B 玩家亲手终结：玩家主导终局，Full Course残部与Nectar配方按玩家方案处置，茉离按玩家方案安置。
- NT-END-C 交易收场：玩家促成亡本与理事会切割、Nectar产业在监督下永久封存、受害者在玩家安排的渠道获救。
- NT-END-D 玩家暂时退出：玩家明确离开，事件按背景因果自行收束并延后。
