【事件包：ITEM第四卷·新宿追责与麦野家族】
事件包ID：ITEM-04
所属阶段：阶段0·旧约·前日谭
年层：Y−1（前史图排）
时间窗口：秋初新学期；民译正文第一章明示9月10日，与图排9月1–2冲突，暂不锁定全卷起讫，更不把图排当确日。
别名与触发词：ITEM第四卷 / 新宿站芙兰达追责事件 / 麦野家族继承冲突 / ITEM-04 / ITEM-04-01

== 1. 核心定位 ==
芙兰达在新宿站站台醒来，自制炸弹等武器不见了，也不明白自己为何在这里。未经许可越过学园都市围墙会招致处罚，熟知暗部的她尤其无法轻易脱身；承担处罚任务的麦野等人反而成为威胁。
这不是一场与麦野本家无关的失物调查。追索绑架车辆和仿制炸弹后，芙兰达发现麦野家族的Mugino Sakuya正利用她制造对学园都市的威胁、打击麦野的继承地位；逃亡由此转入横滨与山区的家族内斗。默认最终不是处刑芙兰达，而是同伴与家族人员共同制止失控的麦野，四人活着回城。

== 2. 不可丢失的核心事实 ==
- 醒来的地点是新宿站站台，不是学园都市里的同名设施；武器失踪和行程不明都是开场问题。
- 芙兰达开场不知道经过。身在墙外不等于自愿叛逃；家族陷害必须沿车辆、炸弹与文件逐步发现，不在站台直接全知揭晓。
- ITEM接到的处罚任务使同伴关系与暗部规则冲突，麦野等人的威胁不能被一段开场介绍略去。
- Sakuya企图借芙兰达的罪名连带削弱麦野，并以城外学生家长的安全威胁学园都市；找到这份计划，不等于已经取得她谋杀现任家主的完整证据。
- 老执事Mujinayama曾照顾麦野，却站在Sakuya一方。Sakuya开枪击倒他引发麦野暴怒；他并未当场死亡，后来的出声是制止麦野的关键。
- 家主以粮食及研究原料供应的影响力阻止学园都市扩大清除；Sakuya被带走处置，受伤执事送医，ITEM四人返回学园都市。不能另编麦野父亲或入城原因。

== 3. 玩家可改写的部分 ==
玩家可在墙外协助芙兰达，也可留在城内核验她的求援；位置与知情范围必须一致。可以找回物品、核实许可与行程、争取停战、掩护脱离或拒绝处刑，不强迫玩家加入任何一方的伤害行动。

== 4. 节点推进表 ==
使用ITEM-04完整节点ID；每轮最多推进一个主要节点。

ITEM-04-01 陌生站台上的醒来
进入条件：玩家选择本卷；接续夏末事件时须明确来到秋初新学期。
场景目标：帮助芙兰达确认地点、随身物品与眼前风险，建立可靠的联络方式。
可见角色：芙兰达、站台上实际在场的人；城内玩家仅通过通讯获知情况。
玩家行动：询问身体状况、核对失物、查看可合法取得的行程信息或先离开拥挤站台。
结果：确认她身在新宿且武器失踪；缺失的经过仍是未知，不凭旁白直接补全。
下一节点：ITEM-04-02。

ITEM-04-02 绑架车辆与灭口爆炸
进入条件：ITEM-04-01完成，芙兰达已获知处罚命令，并找到追踪被带离路线的机会。
场景目标：在ITEM与城外追捕压力下，沿车辆痕迹查出是谁借用了她的武器。
可见角色：芙兰达、运输她的卡车司机；麦野等人按实际追踪位置出现。
玩家行动：协助追索车辆、问出运输经过、保护司机或辨认爆炸残留，不向无关人员扩散战斗。
结果：默认司机遭爆炸灭口，芙兰达活下来，从仿制其装备的手法辨认出麦野家族的线索；若玩家救下司机，保留证词与生还，不补演灭口。
下一节点：ITEM-04-03。

ITEM-04-03 横滨文件与继承权
进入条件：ITEM-04-02完成，线索将追逃引向横滨的家族据点。
场景目标：突破Hanagai等人的阻截，取得能够说明陷害目的的文件，让追捕自己的同伴看见另一层冲突。
可见角色：芙兰达、Hanagai、Mugino Sakuya、Mujinayama；随后抵达的麦野、泷壶、绢旗。
玩家行动：潜入取证、掩护芙兰达脱离、传递文件、协调遭遇战，或阻止双方被同一陷阱利用。
结果：文件说明用芙兰达制造城外犯罪、借连带责任打击麦野继承地位并威胁学园都市的计划；麦野与Sakuya公开对峙，冲突不再只是执行越墙处罚。
下一节点：ITEM-04-04。

ITEM-04-04 追到山区的旧执事
进入条件：ITEM-04-03完成，队伍在交锋后重新找到Sakuya一方的动向。
场景目标：利用泷壶发现的监听线索及芙兰达取得的藏身地情报，追到山区并应对Mujinayama。
可见角色：ITEM四人、Mujinayama、Sakuya及实际参战的家族人员。
玩家行动：协调追踪、掩护同伴、争取执事说明立场，或在胜负已定时阻止再伤害。
结果：默认麦野压倒Mujinayama，却无法轻易杀死这位教养过自己的老人；Sakuya从背后开枪击倒执事，麦野暴怒失控。若玩家已挡下枪击，依实际结果改写后续，不强制暴走。
下一节点：ITEM-04-05。

ITEM-04-05 同伴与家族共同止战
进入条件：ITEM-04-04完成，麦野的攻击威胁在场人员，学园都市也准备扩大清除。
场景目标：在泷壶指引下避开原子崩坏、救护执事，并与原来的敌人合作制止麦野。
可见角色：ITEM四人、Hanagai、仍活着的Mujinayama及家族人员；家主的交涉仅向实际旁听者可见。
玩家行动：掩护救护、接应队友、寻找不致命的阻止机会，或协助将执事尚存的消息传给麦野。
结果：默认Mujinayama出声使麦野短暂停顿，芙兰达与Hanagai把握机会将她击昏；家主以供应链影响力阻止学园都市的扩大打击，战场没有被连同众人一起抹除。
下一节点：ITEM-04-06。

ITEM-04-06 四人一同回城
进入条件：ITEM-04-05完成，麦野已被制止或玩家提前避免了失控，伤员可以撤离。
场景目标：落实伤员去向、家族处置与四人的返城，不把暂时停火当作永久和解。
可见角色：ITEM四人、家主、被带离的Sakuya和接受救护的Mujinayama。
玩家行动：救护与清点、保留已取得的证据、安排返程，或确认尚未解除的家族矛盾。
结果：默认家主带走Sakuya按家规处置，要求Mujinayama送医；ITEM四人从南门回到学园都市，赶在大霸星祭前恢复日常。不编造Sakuya处刑或麦野父亲的答案。
下一节点：无；同年前史大霸星祭另选ITEM-05-01。
