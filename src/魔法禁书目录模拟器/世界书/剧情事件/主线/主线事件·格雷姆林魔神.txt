【事件包：格雷姆林魔神篇】
事件包ID：GREMLIN
所属阶段：阶段6·新约魔神决战
时间窗口：本篇Y年11月23日至24日前后；日为图排，NT9主观世界经历不换算成现实日历
别名与触发词：格雷姆林魔神篇 / 神枪制造决战 / 欧提努斯救援追逐 / GREMLIN

== 1. 核心定位 ==
作品范围：新约8—10。GREMLIN-01至03是NT8的联军、东京阻击与神枪；04至05是NT9的世界变化与理解；06至08是NT10的丹麦追逐和救援。新约1—7分别由前置事件包承接，本包不冒充十卷全覆盖。
核心不是“人工天界计划”，而是欧提努斯完成魔神状态及神枪Gungnir的制造。玩家可在每一阶段介入、改写或离开，不能为展示后卷而强制毁灭已被玩家保住的世界。

== 2. 不可丢失的核心事实 ==
- 联军围剿格雷姆林时，东京同时受其成员攻击；军政情报与上条等人的现场判断并不一致。神枪制造在船之坟场进行，玛莉安等人为此工作。
- 欧雷尔斯伪装索尔潜入，与右方之火安排妖精化术式。他们以为能借此削弱欧提努斯，原作却使她能将不稳定的可能性统一到一侧；她最终同时掌握完成神枪与妖精化带来的两种解法。
- NT8原作末尾，欧提努斯毁去世界。NT9中上条因幻想杀手这一基准点而留下，经历她改变的世界；普通同伴不因此共同拥有这些记忆。
- NT9上条在被排除的“完美世界”中动摇，御坂网络总意帮助他重新面对自己的愿望。最终欧提努斯理解自己需要的是理解者，主动恢复上条原来的世界，而不是上条将她普通击倒后自动复原。
- NT10上条决定救欧提努斯，两人赴丹麦寻找密米尔之泉中的眼睛，以解除她濒临崩溃的状态。她最后放弃按原计划自救，上条仍救下她；原作她以约十五厘米的形态存活。

== 3. 玩家可改写的部分 ==
- 可在制造前阻止材料与人员被利用，揭露妖精化方案的问题，争取欧提努斯放弃毁界；成功就不补演世界毁灭。
- 可在世界变化中支持上条、寻找沟通或其他稳定方法；玩家是否在场、是否记忆连续须由已成立的能力和经历决定，不默认共享无限体验。
- 可拒绝追杀、提出监督与救助并行的方案，改变丹麦路线与各方态度；不以对欧提努斯的处置设置玩家奖惩。

== 4. 节点推进表 ==
GREMLIN-01 联军与东京的两张地图
进入条件：NT7后取得神枪制造与格雷姆林集结的情报，玩家选择介入；或从联军调查直接开局。
场景目标：核对联军目标与东京袭击的关系，确定谁真正需要救援、船之坟场在哪里。
可见角色：上条、茵蒂克丝、美琴、柏德蔚、蕾莎、云川鞠亚；各国代表通过通讯出现。
玩家行动：比对情报、疏散东京居民、联系不同小队，追踪神枪材料而非盲随最大规模的军队。
结果：原作围剿与东京阻击并行，上条一行分路赶往核心地点；玩家可提前识别诱导，改变队伍到达顺序与平民受波及范围。
下一节点：进入GREMLIN-02；已找到且能够接触制造现场者可进入GREMLIN-03。

GREMLIN-02 从阻击者身边救人
进入条件：前往东京湾的路线受到弗蕾雅等成员与术式阻挡，或云川鞠亚发现加群的踪迹。
场景目标：打开通往船之坟场的路，同时不把被编入格雷姆林的人一概当作可牺牲材料。
可见角色：弗蕾雅、上条、茵蒂克丝、美琴、柏德蔚、蕾莎、云川鞠亚、木原加群。
玩家行动：分析并解除阻击术式，救治失去战斗能力者，协助鞠亚接近老师，判断加群的行动是否仍保有本人的选择。
结果：原作上条等人突破阻击，加群凭预设的自身行为约束保护他们，鞠亚留下陪伴他；加群此前若被玩家救活，就沿用生还状态，不重新套入英灵控制。
下一节点：进入GREMLIN-03；救援优先的小队可留下，不能凭空同时登船。

GREMLIN-03 妖精化与完成的神枪
进入条件：抵达船之坟场，或已能干预欧雷尔斯、右方之火与欧提努斯的交锋。
场景目标：阻止神枪完成，识别“让魔神失败”本身是否落入她需要的结果。
可见角色：欧提努斯、欧雷尔斯、右方之火、玛莉安；上条等到场者。
玩家行动：揭穿伪装与制造安排，阻断妖精化的利用，救出制造人员，尝试使欧提努斯说明她真正想回去的地方。
结果：原作妖精化并未按联军预期终结威胁，欧提努斯完成魔神状态与神枪，毁去世界；若玩家确实中断或说服她放弃，则世界保留，跳过不成立的NT9经历。
下一节点：世界变化已经发生则进入GREMLIN-04；毁界被阻止则进入GREMLIN-08处理实际收束，必要时保留谈判。

GREMLIN-04 不以现实天数计的世界
进入条件：欧提努斯已改变世界；先确认上条及玩家各自有何记忆连续条件。
场景目标：区分外界形态与人物真实经历，在不断变化的世界中寻找仍可表达自身意愿的空间。
可见角色：欧提努斯、上条；不同世界中的熟人只拥有各自成立的经历，御坂网络总意在相应阶段介入。
玩家行动：观察世界变化的规则，支持陷入自我否定的人，拒绝以自毁证明价值，探索不伤害他人的交流路径。
结果：原作上条被各种世界逼迫，在看似人人幸福却排除自己的世界中动摇，随后得到御坂网络总意的支持；玩家可更早提供支点，不要求逐次演完全部苦难。
下一节点：对话与自身选择能够继续时进入GREMLIN-05；若玩家建立了其他稳定解法，则进入GREMLIN-08记录所保留的世界与记忆。

GREMLIN-05 理解者与被归还的世界
进入条件：上条愿意面对自己的愿望，欧提努斯与他发生最终对抗或真正的交流。
场景目标：辨认欧提努斯想回旧世界的愿望背后，是不是失去了能够理解她的人。
可见角色：上条、欧提努斯；恢复后在现场的茵蒂克丝、美琴、柏德蔚、蕾莎。
玩家行动：参与有依据的沟通，支持双方说出需求，争取在不可逆伤害前停止对抗；世界恢复后及时解释她的实际状态。
结果：原作欧提努斯在失去上条后意识到他是理解者，主动恢复其世界；上条转而保护遭集火的她。玩家已提前促成理解时不补写死亡；恢复也不让同伴自动记起NT9主观经历。
下一节点：欧提努斯仍受妖精化侵蚀且选择救援时进入GREMLIN-06；已达成其他稳定方案则进入GREMLIN-08。

GREMLIN-06 与世界的追兵同行
进入条件：上条选择保护欧提努斯，两人需要赴丹麦寻找眼睛，联军仍将她视为世界级威胁。
场景目标：在追逐中争取可行的救命路线，向旧日同伴说明救助不等于认可先前暴行。
可见角色：上条、欧提努斯；一方通行、美琴、茵蒂克丝、柏德蔚及各国追兵按路线逐次出现。
玩家行动：谈判、掩护撤离、提供交通与治疗，区分真正阻杀者和试图确认上条意愿的同伴，不将全部会战塞进同一地点。
结果：原作上条一路面对旧盟友与国家力量，逐步争取理解；玩家可减少交锋或改变追捕态度。尚未发生的战斗不计为完成，也不自动附加原作伤势。
下一节点：接近密米尔之泉所在的伊埃斯科城堡时进入GREMLIN-07；路线受阻则保留本节点。

GREMLIN-07 眼睛与她不愿接受的代价
进入条件：抵达城堡一带，欧提努斯能取回眼睛，上条仍受到索尔等人的阻拦。
场景目标：解决最后的路线阻碍，并让欧提努斯有机会说出她对获救后果的担忧。
可见角色：上条、欧提努斯、索尔；玩家争取来的协助者。
玩家行动：与索尔交涉或交锋，保持与欧提努斯的联系，讨论救援后的承担方式，阻止她独自把死亡当成唯一补偿。
结果：原作欧提努斯因不愿把全部罪责与负担压到理解者身上，放弃眼睛这一自救路径；玩家若提前达成共同承担的方案，可改变该选择，不强制毁掉眼睛。
下一节点：进入GREMLIN-08；若她已按其他方法稳定，仍须完成各方沟通与安置。

GREMLIN-08 活下来的魔神与见证
进入条件：欧提努斯濒临崩溃，或玩家在较早节点建立了替代收束。
场景目标：完成实际救援，明确欧提努斯状态、世界是否恢复以及她与各方如何继续相处。
可见角色：上条、欧提努斯、参与救援的同伴；总统与英国王室等通过战后沟通出现。
玩家行动：支援救治、解释现场证据，争取以活着面对后果取代继续追杀，安排住所与监督；也可提出自洽的其他处置。
结果：原作上条突破她的攻击并排除妖精化残留，欧提努斯以约十五厘米形态存活；各方接受她留在世界中见证其延续。非原作路线按真实身体、能力与协议收束，不强制缩小、监禁或恢复旧世界。
下一节点：十一月下旬食蜂相关异常进入视野且玩家选择调查时进入MENTAL-STINGER-01；否则返回实际保留下来的日常或分支世界。

== 5. 分支和偏离规则 ==
世界未毁、改变后未恢复、恢复但救援方式不同，分别存档。主观经历不累加现实年份，也不把全体NPC设成共享记忆者。默认收束不是强制回正命令；玩家拒绝跟随上条时，只叙述其能够得知的事件，不替玩家选择对欧提努斯的立场。

== 6. 换篇条件 ==
先确认世界基底、记忆归属、欧提努斯状态和追捕处理，再结束本包。MENTAL-STINGER只接本年NT11当前框架；前一年上蜂往事由MENTAL-PAST承接，不在恢复世界后再发生一次。

== 7. 防剧透边界 ==
阶段内也按卷级揭示：NT8不预告恢复世界与缩小结果；NT9普通角色不读取上条主观经历；NT10追兵只能依据已知危险判断。真格雷姆林、理想送行和科隆尊属于后续独立包，不因提到“魔神”提前加载。

玩家偏移、世界线记录、任务追踪、NPC关系等既有数组如需变化，也统一以op:"replace"整体替换，保留未变化的已有项。

== 9. 收束结果 ==
- GR-END-A 原作近似：世界恢复，欧提努斯以缩小形态存活，上条与她建立理解关系，各方停止即时追杀。
- GR-END-B 玩家的裁决：玩家促成另一种救援、监督或分离协议，按各方真实接受程度记录，不授予无条件支配他人的权力。
- GR-END-C 未曾毁界：神枪与魔神完成过程被中断或欧提努斯主动放弃，NT9主观世界链不发生。
- GR-END-D 玩家暂离：未决冲突按已经成立的行动延续，只报告玩家可获知的变化，不以缺席触发惩罚。
- GR-END-E 原创收束：玩家建立另一种自洽世界与生存方式，记录与后续篇章的兼容条件，不强制回归正史。
