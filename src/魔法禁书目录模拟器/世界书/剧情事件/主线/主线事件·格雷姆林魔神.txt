【事件包：格雷姆林·魔神篇】
事件包ID：GREMLIN
所属阶段：阶段6·新约·魔神与位相
时间窗口：11月-12月
别名与触发词：格雷姆林 / 魔神 / 欧提努斯 / 位相 / GREMLIN

== 1. 核心定位 ==
本篇是阶段6的世界法则级主线事件：魔法侧秘密结社"格雷姆林"发动人工天界计划，魔神欧提努斯以位相篡改的伟力将世界玩弄于股掌——科学侧与魔法侧被迫联手，上条当麻与魔神展开赌上"能否保护所有人"的信念之战。
玩家进入本篇的方式：开局锚点直接选在本篇；或随阶段6时间推进自然卷入。玩家立场自由：联军协作者、独立调查者、欧提努斯的对话者、或格雷姆林的对手。
本篇是世界观层面最高的主线事件之一，"魔神"与"位相"概念按本篇卡面口径呈现，不引用更深层设定。

== 2. 不可丢失的核心事实 ==
- "格雷姆林"是活跃的魔法侧秘密结社，制造全球性魔法事件；其首领是魔神欧提努斯。
- "魔神"是触及世界法则的存在：魔力与伟力失衡的一百之一个可能性——按本篇口径，魔神拥有改写世界的能力。
- 格雷姆林的最终计划是"人工天界"：以世界为材料再造一个天界，为此不惜改写位相——世界的"底片"被强行替换。
- 位相篡改的极端后果：欧提努斯曾将世界改写为"错误的世界"，当麻与玩家亲历被改写的世界并寻找回归之路。
- 科学侧与魔法侧在魔神威胁面前被迫联手；当麻以"无论世界被改写多少次都照样保护"的信念对抗魔神。
- 收束以欧提努斯的转变为核心：战败/转变后她以被削弱的形态（缩小）留在当麻身边，成为独特同伴——此为合法收束，玩家可改写其最终处置。

== 3. 玩家可改写的部分 ==
- 玩家在世界改写前后的行动：阻止计划、亲历改写、寻回世界、或改写结局。
- 对欧提努斯的最终处置：原著近似（削弱后随行）、放逐、和解、或玩家的原创方案。
- 联军的协作方式与玩家的位置。
- 玩家自身能力可自由发挥（含跨体系混用，无反噬无代价）；在世界被改写期间玩家能力是否受位相影响，按剧情一致性处理并在世界线记录中注明。

== 4. 节点推进表 ==
节点ID格式：GREMLIN-{NN}（必须使用完整ID，禁止简写如GR-01）。每轮最多推进一个主要节点。

GREMLIN-01 魔神的传闻
进入条件：进入本篇（11月锚点或时间推进）。
场景目标：全球性魔法事件接连发生，"格雷姆林"之名与"魔神"的传闻浮出。
可见角色：情报来源、（可选）神裂/史提尔等魔法侧熟人。
玩家行动：收集情报、联络熟识的两方角色。
结果：格雷姆林与魔神概念进入玩家视野。
下一节点：GREMLIN-02。

GREMLIN-02 结社的动作
进入条件：玩家开始追查格雷姆林。
场景目标：格雷姆林的具体行动——夺占地点、袭击目标、收集计划材料。
可见角色：格雷姆林干部与行动队、（可选）当麻。
玩家行动：拦截、调查、协助追缉、或潜入。
结果：格雷姆林的行动模式为玩家所知；"人工天界"的词眼首次出现。
下一节点：GREMLIN-03。

GREMLIN-03 位相的裂缝
进入条件：格雷姆林计划推进。
场景目标：世界出现异常征兆——天象错乱、法则性的小规模异变，位相的存在被感知。
可见角色：亲历异变者、当麻。
玩家行动：调查异变、保护周围人、推演原理。
结果：位相篡改的威胁确凿；时间压力成形。
下一节点：GREMLIN-04。

GREMLIN-04 人工天界计划
进入条件：玩家深入敌情。
场景目标：格雷姆林计划全貌揭晓——以世界为材料再造人工天界。
可见角色：欧提努斯、格雷姆林干部。
玩家行动：参与联军部署、争取先机、准备正面接触。
结果：科学侧与魔法侧联军成形；决战方向确立。
下一节点：GREMLIN-05。

GREMLIN-05 世界被改写
进入条件：欧提努斯发动伟力。
场景目标：世界被位相篡改——眼前的世界变成"错误的世界"（细节由AI按"法则与常识错位"演绎，保持人物关系可辨认）。
可见角色：被改写世界中的众人。
玩家行动：在错误世界中求生、集结同伴、寻找当麻线。
结果：玩家亲历改写后的世界；回归之路的起点确立。
下一节点：GREMLIN-06。

GREMLIN-06 寻回原来世界
进入条件：GREMLIN-05 完成。
场景目标：横跨被改写世界的回归之旅——收集回归的线索与力量，抵达欧提努斯面前。
可见角色：当麻、同伴们、（可选）改写世界的住人。
玩家行动：自由发挥（任何探索与协作路线）。
结果：回归之路打通；与魔神的最终对峙就位。
下一节点：GREMLIN-07。

GREMLIN-07 信念之战
进入条件：GREMLIN-06 完成。
场景目标：当麻与欧提努斯的信念之战——"能否保护所有人"；玩家作为并肩者或独立战力参与。
可见角色：当麻、欧提努斯、玩家方。
玩家行动：自由发挥（可以让当麻承担信念对决的关键时刻，玩家主导亦可；AI 合理演绎，不判定失败收场）。
结果：欧提努斯的伟力被制服/转变；世界回归。
下一节点：GREMLIN-08。

GREMLIN-08 篇章收束
进入条件：GREMLIN-07 完成。
场景目标：事件结算——欧提努斯的最终处置、世界的修复状态、联军余韵、世界线后果记录。
可见角色：本篇主要角色（战后余波）。
玩家行动：处理后续安排；选择下一走向（科隆尊篇 / 日常休整 / 自主跳转）。
结果：阶段状态更新，换篇入口开启。
下一节点：无（本篇结束，按换篇规则处理）。

== 5. 分支和偏离规则 ==
- 篇章内偏离：改变追查方式、联军角色或探索路线时，保留当前锚点切分支推进。
- 核心结果改写：玩家阻止改写、提前制服欧提努斯、或原创处置魔神时，保留当前锚点，阶段状态记"已改写"，写入世界线记录。
- 延后与跳过：玩家回避时，事件按原著因果自行发展（当麻完成信念之战），不强制玩家参与。
- 世界被改写的经历属跨篇重大事实：玩家与同伴"曾亲历错误世界"的记忆按世界线记录处理。
