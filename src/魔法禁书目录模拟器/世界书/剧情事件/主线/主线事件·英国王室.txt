【事件包：英国王室篇】
事件包ID：BRITISH-ROYAL
所属阶段：阶段5·旧约·英国政变
年层：Y
时间窗口：十月中旬后段；官动层10月16日隧道消息、17日赴英、18日前后政变与收束
别名与触发词：英国王室事件 / 不列颠万圣节 / 卡提纳政变 / BRITISH-ROYAL / BRITISH-ROYAL-01
证据定位：O35；旧约17–18及官介；官方动画年表；O34为前序，O37为后继

== 1. 核心定位 ==
隧道爆破调查逐渐转为英国王室与骑士派的政变。上条要在国内权力冲突中保护茵蒂克丝和普通人；威廉从前一篇对手变成救援者，不能因后方之水败退而将他删去。

== 2. 不可丢失的核心事实 ==
- 英法海底隧道爆破引发紧张，英国召集茵蒂克丝，上条陪同赴英，航班途中遭遇恐怖活动与航路干扰。
- 新生之光运输相关物品，上条追踪蕾莎；其运输联系使卡提纳·正统到达第二王女凯莉莎手中。
- 凯莉莎依托卡提纳与骑士派发动政变，神裂败于骑士团长；威廉救下第三王女薇莉安并与骑士团长交战。
- 原作默认各方联合反抗，白金汉宫决战中女王伊莉莎德以联合旗帜凝聚力量，上条破坏卡提纳·正统，凯莉莎败北。
- 右方之火随后企图处置凯莉莎，被上条阻止，却夺走茵蒂克丝的远隔控制灵装。由此衔接赴俄救人，不把OT17–18算作三战正文。

== 3. 玩家可改写的部分 ==
可破解航班危机、阻止卡提纳转运、保护王女与平民、调停政变或保住遥控灵装。政治选择不强制效忠任何派别；提前成功不必补演政变和夺取控制器。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口BRITISH-ROYAL-01。英国与都市DRAGON线并行，不要求同一人物跨国瞬移。

BRITISH-ROYAL-01 海底隧道的新闻
进入条件：10月16日前后收到爆破消息与赴英召集。
场景目标：确认茵蒂克丝受召原因，安排出行与日本方面联络。
可见角色：上条、茵蒂克丝；美琴可在离境前实际相遇时出现。
玩家行动：查证消息、同行、留守联络或帮助保护出行者。
结果：上条随茵蒂克丝赴英，调查以隧道事件为表面入口。
下一节点：BRITISH-ROYAL-02。

BRITISH-ROYAL-02 飞往英国的航班
进入条件：17日早晨的赴英航班遭恐怖活动，外部亦有干扰。
场景目标：保护机内人员，协助识别袭击者并让飞机安全抵达。
可见角色：上条、茵蒂克丝、机组与乘客、袭击者。
玩家行动：协助排查、疏散危险区域、联络机组或制止暴力。
结果：原作默认航班危机得到处理，英国境内的矛盾却未随降落结束。
下一节点：BRITISH-ROYAL-03。

BRITISH-ROYAL-03 王室委托与运输包
进入条件：到达伦敦，王室要求协助调查。
场景目标：追踪新生之光及蕾莎携带的包，核查其与卡提纳的关联。
可见角色：上条、茵蒂克丝、伊莉莎德、王女、蕾莎及新生之光成员。
玩家行动：追踪、盘问、保护运输途中的旁人、截断中转。
结果：原作默认运输联系将卡提纳·正统送到凯莉莎处，表面调查暴露国内计划。
下一节点：BRITISH-ROYAL-04。

BRITISH-ROYAL-04 凯莉莎发动政变
进入条件：18日前后凯莉莎取得卡提纳并动员骑士派。
场景目标：保护被控制的茵蒂克丝与王室成员，辨认军政权力已经转移。
可见角色：凯莉莎、骑士团长、茵蒂克丝、上条、王女与骑士。
玩家行动：撤离、传递实情、协助反抗或争取停战。
结果：原作默认政变爆发，神裂与骑士团长对峙；王室委托不能再按原计划机械执行。
下一节点：BRITISH-ROYAL-05。

BRITISH-ROYAL-05 威廉与第三王女
进入条件：神裂受挫，凯莉莎命令处决薇莉安。
场景目标：保护第三王女，支持威廉阻止处刑并迎战骑士团长。
可见角色：薇莉安、威廉·奥威尔、骑士团长、神裂；上条按所处路线出现。
玩家行动：救护神裂、护送薇莉安、牵制骑士或组织撤离。
结果：原作默认威廉救下薇莉安并击败骑士团长；昔日敌手的救援行为成为新的合作依据。
下一节点：BRITISH-ROYAL-06。

BRITISH-ROYAL-06 救回茵蒂克丝
进入条件：各方开始重新集合，茵蒂克丝仍受凯莉莎控制。
场景目标：借威廉等人的协助救回茵蒂克丝，联络可共同反抗的力量。
可见角色：上条、茵蒂克丝、威廉、清教与王室协作者。
玩家行动：营救、建立安全联络、保护伤员和撤离群众。
结果：原作默认茵蒂克丝获救，反抗行动转向白金汉宫的最终对决。
下一节点：BRITISH-ROYAL-07。

BRITISH-ROYAL-07 白金汉宫联合反击
进入条件：能够共同阻止凯莉莎继续掌控卡提纳。
场景目标：在伊莉莎德凝聚各方力量的支持下，突破凯莉莎防御并破坏灵装。
可见角色：伊莉莎德、凯莉莎、上条、各方反抗者。
玩家行动：救护、牵制、护送上条接近或用已验证方案令灵装失效。
结果：原作默认卡提纳·正统被破坏、凯莉莎败北，国内政变告终。
下一节点：BRITISH-ROYAL-08。

BRITISH-ROYAL-08 被夺走的安全装置
进入条件：政变结束，右方之火现身干预。
场景目标：阻止他杀害凯莉莎，保护与茵蒂克丝相连的远隔控制灵装。
可见角色：上条、右方之火、凯莉莎；英国清教人员按所在地点出现。
玩家行动：护人、拦截夺取、追踪离去方向、确认茵蒂克丝状态。
结果：原作默认上条阻止杀人却未保住灵装，右方之火离去，赴俄夺回或破坏控制器成为明确目标。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
政变与控制器分别登记，提前阻止其一不强行重造同一危机。前案威廉伤情按已有存档承接；玩家救援、王女选择与政治协作保留为偏移，不以王室权威否定玩家自由。

== 6. 换篇条件 ==
BRITISH-ROYAL-08完成、明确退出/跳时或政变及后续威胁提前解决即可换篇。世界层接10月18日宣战、19日起战事、30日终战的WW3；已在18日之后的视角只获知宣战，不倒退。都市并行线DRAGON可另选，不能以本篇完成代替OT19全部节点。

== 7. 防剧透边界 ==
卡提纳运输与政变逐步揭示，不预告俄罗斯决战的结果。后继战争或DRAGON调查到达各自入口即可开放，时间跳转由玩家决定。

== 8. 状态写回契约 ==

== 9. 收束结果 ==
- BRITISH-ROYAL-END-A：近原作，政变被制止，右方之火夺走远隔控制灵装。
- BRITISH-ROYAL-END-B：玩家提前阻止转运、政变或灵装被夺，后续动机随之调整。
- BRITISH-ROYAL-END-C：退出或委托部分救援，记录场外结果。
- BRITISH-ROYAL-END-D：原创联合或谈判结局，不追加王女死亡与控制器失窃。
