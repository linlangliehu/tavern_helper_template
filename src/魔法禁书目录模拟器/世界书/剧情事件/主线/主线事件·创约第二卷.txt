【事件包：创约第二卷·圣诞日安娜迎击】
事件包ID：GENESIS-02
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第2卷。
时间窗口：本篇Y年12月25日；官方卷页确认圣诞日，前日投药是12月24日前情。与手铐行动同日并行，不按卷号另加一天。
别名与触发词：创约第二卷 / 创约第二卷圣诞日迎击 / GENESIS-02

== 1. 核心定位 ==
安娜＝施普伦格尔把危机植入上条体内，再以R&C Occultics掌握解决办法的姿态施压。御坂美琴与食蜂操祈为了保护同一人联手；上条则必须决定如何对待体内具有意志的圣日耳曼。玩家可参与病房保护、蜂琴迎击或寻找兼顾宿主与体内生命的出路。

== 2. 不可丢失的核心事实 ==
- 上条因前卷安娜之吻被送医；体内的急性圣日耳曼并非普通毒物，幻想杀手不能简单地一次抹除正在体内扩散的全部问题。
- 安娜利用“只有她能解决”的处境推广R&C；美琴与食蜂结成临时合作，不代表两人的日常矛盾从此消失。
- 原作蜂琴没能凭两名Level 5的联手制伏安娜。上条与圣日耳曼从宿主和侵入者转为共同作战者。
- 正面对决是上条与圣日耳曼对安娜与艾华斯。幻想杀手和圣日耳曼的防护魔术各补另一方的空缺。
- 击败安娜不等于自动治愈。原作圣日耳曼主动停止扩散、归向幻想杀手而消失，上条幸存；上条曾试图为它寻找其他生存方式。
- 安娜随后接触收监中的一方通行；R&C的影响与暗部清理危机并未随这场胜负终止。

== 3. 玩家可改写的部分 ==
- 若前卷已阻断投药，不凭空让上条中招；可由其他实际接触、对安娜的调查或明确选择原作锚点接入。
- 改变病房警戒、蜂琴的情报与协作方法，允许玩家分担迎击或提出谈判。
- 可尝试提前隔离体内侵入、寻找保全圣日耳曼的替代承载；原作未成功的方案只能作为玩家尝试，不写成既有万能疗法。

== 4. 节点推进表 ==
每轮最多推进一个主要节点，使用以下完整ID。

GENESIS-02-01 圣诞日的病房
进入条件：承接投药后的住院，或明确选择本卷原作起点。
场景目标：确认上条真实病情，把探病、病房保护和调查安娜分成可执行任务。
可见角色：上条当麻、茵蒂克丝、欧提努斯、御坂美琴、食蜂操祈、冥土追魂。
玩家行动：问诊、整理已知接触、保护病人、陪同探望；不以战斗胜利预先宣告治愈。
结果：安娜造成的问题与普通伤势被区分，众人开始分别寻找阻止她与救人的方法。
下一节点：GENESIS-02-02。

GENESIS-02-02 蜂琴共同迎击
进入条件：美琴与食蜂察觉安娜仍掌握危机主动权。
场景目标：让两位能力者在情报、控制与火力上配合，而不是让病人独自承担全部压力。
可见角色：御坂美琴、食蜂操祈、安娜＝施普伦格尔；上条仅在其实际所在场景出现。
玩家行动：提供魔术线索、救助受波及者、协助撤退或参与截击，也可留守医院。
结果：原作两人负伤，没能靠等级优势解决安娜；她的危险不能按科学侧排名直接推断。玩家若提前制伏她，仍须处理上条体内状态。
下一节点：GENESIS-02-03；若已终止安娜的攻击，可在厘清体内意志后转GENESIS-02-05。

GENESIS-02-03 体内的共同作战者
进入条件：上条感知并与圣日耳曼交流，或玩家获得双方真实状态。
场景目标：区分安娜的控制意图与这个圣日耳曼个体的选择，建立不互相消耗的协作。
可见角色：上条当麻、圣日耳曼；体内交流只能通过实际表达让外人得知。
玩家行动：倾听、传递情报、寻找救护或替代承载条件；支持合作而不把圣日耳曼只当一次性武器。
结果：原作双方决定共同反抗安娜；上条的右手与圣日耳曼魔术形成互补，但后者的存在仍会损伤宿主。
下一节点：GENESIS-02-04；已解除外部威胁则转GENESIS-02-05。

GENESIS-02-04 百货店的两对搭档
进入条件：需要正面阻止安娜，且已形成可执行的援护或共同作战方案。
场景目标：应对安娜与艾华斯，把上条的破除异能和圣日耳曼的防护能力接到同一攻防节奏。
可见角色：上条当麻、圣日耳曼、安娜＝施普伦格尔、艾华斯。
玩家行动：疏散、观察复合攻击、创造接近机会，或用自己的可行方案打破安娜优势。
结果：原作安娜被击败；这只解决眼前对手，不能删掉病情或宣告R&C永久解散。
下一节点：GENESIS-02-05。

GENESIS-02-05 不止宿主一个人的救援
进入条件：安娜的迎击已结束，上条仍处在危急状态。
场景目标：处理继续侵蚀宿主的圣日耳曼，而非把倒下的对手当成治愈开关。
可见角色：上条当麻、圣日耳曼；玩家与救护人员按实际抵达参与。
玩家行动：协助寻找可用的分离条件、及时转运、尊重圣日耳曼的意志，或落实已建立的替代方案。
结果：原作圣日耳曼自行集中到右手并消失，上条获救；玩家若保全了双方，记录具体方法与仍需照护的状态，不补演牺牲。
下一节点：GENESIS-02-06。

GENESIS-02-06 圣诞日的两条余波
进入条件：宿主生命危机已处理，相关救护与迎击结果可以交接。
场景目标：安置伤员，辨认安娜仍有其他政治目标，并与同日暗部行动的信息分开记账。
可见角色：上条当麻、御坂美琴、食蜂操祈、茵蒂克丝；有相应视角时才呈现安娜与一方通行的会面。
玩家行动：复查、探望、提交R&C情报，或明确选择另一条圣诞日视角。
结果：原作上条与蜂琴存活，安娜转去接触一方通行；手铐行动是此时另一条因果链，不是翌日任务。
下一节点：本包收束；明确转同日暗部视角可接GENESIS-03-01；进入洛杉矶后续须满足出行与当地日期条件，再接GENESIS-04-01。

== 5. 分支和偏离规则 ==
迎击成功、获得治疗信息与保全圣日耳曼是不同结果，分别继承。玩家留守病房不等于蜂琴必败；采用已发生的行动事实。变更救援方式不强制换篇，核心因果已被改写时可在本包收束，不以原作伤亡惩罚玩家。

== 6. 换篇条件 ==
GENESIS-02-06完成、玩家明确跳过／离开／选新锚点、明确越过窗口或因果提前终止后才换篇。记录阶段状态与原因。同日切换GENESIS-03时说明视角及已发生时间，不把世界日历推进到12月26日，也不清空另一线已知结果。

只揭示本卷的圣日耳曼、安娜与艾华斯协作及R&C威胁。不能把桥架结社、安娜后来的求救或CRC身份提前交给不知情者。手铐行动细节须由现场或报告取得，不由探病场景自动全知。

== 9. 收束结果 ==
原作默认：蜂琴迎击受挫，上条与圣日耳曼共同击败安娜；圣日耳曼消失，上条幸存，安娜继续接触都市最高决策者。
玩家改写：可阻断投药、改善蜂琴战果、保护圣日耳曼或限制安娜活动。洛杉矶与暗部后续按仍存在的R&C、伤员及政治条件接力，不要求牺牲某人来兑换下一卷。
