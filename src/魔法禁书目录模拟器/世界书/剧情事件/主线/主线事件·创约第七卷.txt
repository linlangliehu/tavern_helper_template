【事件包：创约第七卷·跨年领事馆】
事件包ID：GENESIS-07
所属阶段：阶段8·创约（阶段序号8）
作品范围：小说《创约 魔法禁书目录》第7卷；元旦日常、领事馆接触与救济分歧。
时间窗口：本篇Y＋1年1月1日→1月2日→1月3日。1月1日有官方卷简介支持，2日与3日依社区译文章节明确日期；不能把三日压成一个元旦日，也不因异常空间体验额外加日。
别名与触发词：创约第七卷 / 创约第七卷跨年领事馆 / GENESIS-07

== 1. 核心定位 ==
上条带着被制服的阿拉迪娅迎接新年，却发现桥架结社已把领事馆设在学园都市内部。他尝试说服超绝者放弃处死安娜＝施普伦格尔。阿拉迪娅在理解上条符合自己保护受迫害魔女的条件后，才于1月3日主动协作，并进一步尝试为安娜争取生路；H.T.特莉丝玫姬丝忒丝却将这种变化视为威胁。救人与维护组织的冲突最终伤到爱丽丝，使她与老师的关系破裂。

== 2. 不可丢失的核心事实 ==
- 初诣在第一二学区展开，上条与美琴、食蜂等人相遇；阿拉迪娅仍承接12月31日的约束与关系变化。
- 云川留下的发信器是调查结社的线索，但爱丽丝已主动来到学园都市。领事馆不是远在海外的普通据点。
- 结社准备以“矮小液体”处决施普伦格尔，穆特忒贝是负责执行的超绝者。魅魔与玛丽曾救上条，不代表她们无条件反对处决安娜。
- 各超绝者有各自的救济条件。1月2日尚无成员因这些条件站出来救安娜；3日欧提努斯解释上条遭教会利用、12月25日主动借圣日耳曼施法的经历，阿拉迪娅才认定上条也是应受自己保护的魔女，主动提出通过结社议事阻止处决。她进一步为安娜争取生路时，被H.T.以防止她脱离常识为由袭击；他刻意利用她仍受约束的弱点。
- 原作玛丽救回受害者并与H.T.交战，爱丽丝随后惩罚双方：她既责怪伤害老师的人，也责怪没及时阻止伤害的人。
- 上条阻止爱丽丝继续处罚，自己受重伤；爱丽丝见众人都来保护老师，感到被排除而离开。尾声上条解除施普伦格尔的圆盘封印，带她与阿拉迪娅逃走。

== 3. 玩家可改写的部分 ==
- 从参拜、照护阿拉迪娅或调查发信器进入，与结社建立不同程度的信任。
- 提前解除不再合理的束缚、阻止H.T.袭击，以可验证的安全方案争取撤销处决。提前入馆或提前向阿拉迪娅说明上条经历并争取其协作，必须有实际介入和认知变化，记为玩家偏移，不替代原作分日日程。
- 听清爱丽丝的恐惧，改变她与老师的沟通结果；保护施普伦格尔不等于替她取消责任。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；每次跨日明确现实侧日期，不跳过同日尚在处理的事件。

GENESIS-07-01 一月一日的初诣
进入条件：跨入次年元旦并选择本卷，或与上条一行来到第一二学区。
场景目标：在参拜与摊位日常中确认同伴状态，面对阿拉迪娅由追杀者变为同行者的尴尬。
可见角色：上条、茵蒂克丝、欧提努斯、阿拉迪娅、御坂美琴、食蜂操祈及实际同行者。
玩家行动：同行参拜、协助维持秩序、讨论约束条件，核对云川留下的发信器是否仍可用。
结果：元旦日常建立关系与调查意图；原作当晚仍回上条宿舍过夜。爱丽丝已经来到都市，不能假定她还在等待被追踪，也不能据此把入馆提前到元旦。
下一节点：默认到1月2日早餐后进入GENESIS-07-02；玩家主动提前接触时保留实际日期并记录偏移。

GENESIS-07-02 城市里的结社领事馆
进入条件：默认1月2日早餐后，接受爱丽丝前往第一二学区领事馆的邀请；玩家循有效线索提前到访仅作为实际介入产生的偏移。
场景目标：进入结社的生活与规则之中，了解其为何敢在都市内设立据点。
可见角色：爱丽丝、H.T.特莉丝玫姬丝忒丝、魅魔、旧善玛丽、阿拉迪娅。
玩家行动：接受招待、询问留宿与安全边界，观察成员的分工；也可留在外侧联络都市方面。
结果：玩家从外部追踪转为具体接触，看到结社既有生活秩序，也有围绕爱丽丝的恐惧。
下一节点：同日进入GENESIS-07-03，不在入馆后另加一天。

GENESIS-07-03 一月二日的处决议题
进入条件：默认1月2日入馆后接触结社，或收到同日可靠的会谈消息；提前接触分支沿用已记录的实际日期。
场景目标：确认施普伦格尔面临处决，弄清赞成者的理由与执行方式。
可见角色：上条、阿拉迪娅、穆特忒贝、魅魔、玛丽、欧提努斯。
玩家行动：询问“矮小液体”的用途、核对安娜造成的危害，提出拘束、监督或审理等替代路径。
结果：救过上条的成员仍可能支持处决安娜；玩家必须处理具体分歧，不能凭恩情直接要求全体服从。
下一节点：GENESIS-07-04。

GENESIS-07-04 救济条件不是同一颗心
进入条件：玩家或上条决定争取结社改变处决意见，默认仍处1月2日的交流阶段。
场景目标：逐一理解魅魔、玛丽与阿拉迪娅愿意救人的条件，寻找可合作的交集。
可见角色：阿拉迪娅、上条、欧提努斯、魅魔、玛丽。
玩家行动：核实安娜是否符合可救助条件、听取反对者顾虑、避免伪造她无辜的证据，准备次日继续游说。
结果：原作此日只摸清各人的救济条件，没有成员据此站出来救安娜，阿拉迪娅的主动协作尚未取得；保留分歧与待补的认知，继续到次日。玩家若已实际说明上条的经历并取得不同回应，单独记录提前转向的偏移，不视为默认结果。
下一节点：到达1月3日后进入GENESIS-07-05。

GENESIS-07-05 一月三日的花园斩击
进入条件：默认1月3日，欧提努斯向阿拉迪娅解释上条遭教会利用，以及12月25日主动借圣日耳曼施法救人的经历；此前玩家造成的认知变化按实际继承。
场景目标：让阿拉迪娅正视上条符合保护受迫害魔女的条件，再共同争取改变处决决定，阻止组织秩序的维护者以暴力压制同伴变化。
可见角色：H.T.特莉丝玫姬丝忒丝、阿拉迪娅、上条、欧提努斯。
玩家行动：补足阿拉迪娅对上条经历的认识，听取她通过结社议事阻止处决的提议，再向花园中的H.T.游说；观察拔剑征兆、保护仍受约束的阿拉迪娅，或撤离谈判现场。
结果：原作阿拉迪娅在上述认知转折后才主动帮助上条，并进一步为不符合自身救济条件的安娜争取生路；H.T.在同日花园会谈中袭击阿拉迪娅并追杀上条，谈判转为救命。提前说服或阻止袭击属于玩家偏移，不补造不可避免的死亡。
下一节点：GENESIS-07-06。

GENESIS-07-06 医疗者对上常识守门人
进入条件：H.T.继续进攻，或玛丽介入处理已发生的伤害。
场景目标：协助救治，阻止H.T.以常识为由限定谁配得到奇迹。
可见角色：旧善玛丽、H.T.、上条、阿拉迪娅。
玩家行动：护送伤者、提供救治条件、配合玛丽防守，或利用已争取的其他成员促成停手。
结果：原作玛丽施救并与H.T.正面交战；爱丽丝发现老师的血与同伴相残，转而亲自干预。
下一节点：GENESIS-07-07。

GENESIS-07-07 不要替老师处罚所有人
进入条件：爱丽丝要处罚H.T.与未能及时保护老师的玛丽。
场景目标：制止过度惩罚，同时回应她因害怕失去老师产生的失控。
可见角色：爱丽丝、上条、受伤的H.T.与玛丽；茵蒂克丝、欧提努斯及援助者按位置赶来。
玩家行动：护住失去反抗能力者、解释救人与原谅、阻止增援把爱丽丝单纯当作必须消灭的对象。
结果：原作上条重伤仍反对处罚，爱丽丝因被拒绝与众人围护老师而失落离开；这不是上条以武力完全击败了她。玩家成功沟通时保留不同关系。
下一节点：GENESIS-07-08。

GENESIS-07-08 解除圆盘封印的选择
进入条件：离开领事馆冲突现场后，阿拉迪娅接触亚雷斯塔一行，上条追随而至。
场景目标：面对眼前受控的施普伦格尔，决定是否允许她被杀以及如何限制其继续伤害别人。
可见角色：上条、阿拉迪娅、安娜＝施普伦格尔、亚雷斯塔、金斯福德、木原脑干。
玩家行动：询问拘禁理由、提出非处死方案、阻止即时杀害；也可协助上条解除封印后护送她离开。
结果：原作上条以右手解除圆盘封印，拉着安娜逃走，阿拉迪娅同行；爱丽丝关系破裂与三方追查成为同日后续，不自动加一天。
下一节点：本包收束；1月3日接GENESIS-08-01。

== 5. 分支和偏离规则 ==
- 玛丽的特殊救治按既有条件呈现，不给玩家建立无限复活权；未发生死亡时不补写一次死亡履历。
- 爱丽丝若被成功安抚，后卷仪式与关系状态必须调整，不强迫她重新崩溃以对齐原作。
- 不愿带安娜逃走时，可以保留非处死监管分支；后续威胁按实际监管、结社与都市立场形成。

== 6. 换篇条件 ==
领事馆的即时冲突和安娜处置形成结果，或玩家明确离开、跳跃、另选锚点时换篇。默认接创约第八卷时仍是1月3日，不因卷号更换自动进入4日。

== 7. 防剧透边界 ==
H.T.的袭击、爱丽丝的反应须从会谈与冲突中发生。结社仪式的最终对象及其结果留待后卷，不能让元旦参拜者预知。

== 8. 状态写回契约 ==
- 主线进度仍为当前阶段“创约”、阶段序号8，跨年不另建阶段；当前节点写完整ID，阶段状态据实际结果更新。
- 正史锚点记录分日接触、领事馆冲突与保护安娜的默认走向；玩家偏移保留救济协商、伤亡与爱丽丝信任的变化。
- 已完成节点、可触发节点整体replace并去重，明确三个现实日期的先后；不能一次换篇把三日节点全记完成。
- 伤员救治、安娜监管和失散同伴沿用任务追踪；关系、位置和跨日事实写入NPC关系、在场人物、势力关系、世界线记录，不新增年层字段。

== 9. 收束结果 ==
默认领事馆没有成为消除分歧的避风港，爱丽丝与上条关系破裂，上条仍选择保护施普伦格尔。玩家若改变沟通或监管方案，带着不同结果接同日的安娜保护线，而不是强制回到逃亡。
