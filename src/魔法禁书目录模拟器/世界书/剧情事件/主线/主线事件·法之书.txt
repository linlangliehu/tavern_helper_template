【事件包：法之书篇】
事件包ID：BOOK-OF-LAW
所属阶段：阶段3·旧约·九月上旬
年层：Y
时间窗口：九月上旬；官动层9月8日委托与救援、9日凌晨反救及白天余波
别名与触发词：法之书事件 / 奥索拉营救事件 / BOOK-OF-LAW / BOOK-OF-LAW-01
证据定位：O16；旧约7及官介；官方动画年表；O17只作相对后继

== 1. 核心定位 ==
先以为在帮助正教营救被天草式绑架的修女，随后发现所谓保护是秘密处决。行动必须从追捕天草式转为救回奥索拉，而非固定哪一教派永远代表正义。

== 2. 不可丢失的核心事实 ==
- 法之书及被认为能够解读它的奥索拉卷入争夺；史提尔带茵蒂克丝参与，上条也被拉入搜救。
- 雅妮丝部队以营救名义行动，天草式实际试图保护逃离正教的奥索拉；混乱与缺乏信任导致她再落入正教手中。
- 建宫被拘束后向上条说明隐情，救援者须重新选择立场。争端中的解读主张不能直接当成已经掌握法之书力量。
- 原作默认上条联合史提尔、茵蒂克丝与天草式救出奥索拉，击败雅妮丝；奥索拉与天草式转入英国清教庇护。

== 3. 玩家可改写的部分 ==
可提前核实奥索拉意愿、拒绝交人、促成互信或直接阻止处决。教派命令不高于玩家自主选择；可救助交战双方，不强制以原作伤亡为结局价格。

== 4. 节点推进表 ==
每轮最多推进一个主要节点；默认入口BOOK-OF-LAW-01。

BOOK-OF-LAW-01 失踪者与带走的专家
进入条件：9月8日史提尔带走茵蒂克丝参与行动。
场景目标：核实委托所称的法之书失窃与奥索拉被绑架事件。
可见角色：上条、史提尔、茵蒂克丝；途中可遇迷路的奥索拉。
玩家行动：追问任务来源、帮助迷路者、要求确认当事人意愿。
结果：救援队以正教提供的版本出发，但该说法尚未证实。
下一节点：BOOK-OF-LAW-02。

BOOK-OF-LAW-02 雅妮丝部队与天草式
进入条件：奥索拉被带走，正教请求联合夺回。
场景目标：追踪天草式潜伏地点，辨认其利用日常物品布置的术式。
可见角色：雅妮丝、露琪亚、安洁莲娜、史提尔、建宫及天草式成员。
玩家行动：侦察、协助营救、尝试接触天草式而非盲信情报。
结果：双方进入冲突，上条一方获得接近奥索拉的机会。
下一节点：BOOK-OF-LAW-03。

BOOK-OF-LAW-03 交还之后的疑问
进入条件：夜间夺回奥索拉、拘束建宫。
场景目标：处理奥索拉交给雅妮丝部队的安排及她表现出的不安。
可见角色：奥索拉、上条、雅妮丝、史提尔、建宫。
玩家行动：陪同交接、询问十字架与归属、拒绝不透明带离。
结果：原作默认奥索拉被交还，建宫留下说明真相的机会；玩家可提前阻止交人。
下一节点：BOOK-OF-LAW-04。

BOOK-OF-LAW-04 被称作保护的处决
进入条件：建宫获得解释机会，或玩家查到正教真正行动。
场景目标：确认奥索拉因被视为危险解读者而遭追杀，天草式原在救她。
可见角色：建宫、上条、史提尔、茵蒂克丝。
玩家行动：核验证词、释放协作者、联系奥索拉并制定反救方案。
结果：任务从追捕天草式转为阻止正教秘密处决，不再继续执行错误委托。
下一节点：BOOK-OF-LAW-05。

BOOK-OF-LAW-05 重回教堂
进入条件：9日凌晨反救开始，或玩家提前截住处决路线。
场景目标：突破雅妮丝部队的防线，保护被围攻的奥索拉。
可见角色：上条、史提尔、茵蒂克丝、建宫、天草式、雅妮丝部队。
玩家行动：协同破术、护送、救助受伤修女或促使部队停手。
结果：盟友各自承担牵制与解读，给上条或玩家接近奥索拉创造窗口。
下一节点：BOOK-OF-LAW-06。

BOOK-OF-LAW-06 不能以解读为罪
进入条件：进入雅妮丝控制奥索拉的核心现场。
场景目标：制止处决，分开解读真伪与奥索拉应否获救两个问题。
可见角色：奥索拉、雅妮丝、上条、茵蒂克丝及赶来的盟友。
玩家行动：破坏攻击术式、夺回伤者、接受投降或追索命令证据。
结果：原作默认雅妮丝被击败、奥索拉获救；救人不以她先交出真实魔道书力量为条件。
下一节点：BOOK-OF-LAW-07。

BOOK-OF-LAW-07 新的庇护
进入条件：救援成功，进入9日白天善后。
场景目标：确认奥索拉和天草式今后的安全归属。
可见角色：奥索拉、建宫、上条、史提尔；神裂可联系致谢。
玩家行动：协助交接、确认本人意愿、保留与修女及天草式的联络。
结果：原作默认双方获英国清教庇护；雅妮丝部队后续处境另接亚得里亚海女王。
下一节点：无（本篇结束）。

== 5. 分支和偏离规则 ==
提前识破、改变交接或促成和解均直接改变后续，不为凑反转重新绑架已救出的人。已发生的存档事实保留为偏移；原作默认与玩家选择分别登记。

== 6. 换篇条件 ==
BOOK-OF-LAW-07完成、玩家明确退出/跳时或处决被提前阻止即可换篇。必要之恶教会特别编入考试只标法之书事件后、九月上旬，不强填某一天；主干可接9月14日TREE-DIAGRAM-REMNANT-01，意大利事件另按9月下旬进入。

== 7. 防剧透边界 ==
保护与追杀的反转在本篇必须可查明；不提前让人物知道女王舰队或神之右席后续。边界不封锁后继篇章与自愿时间跳跃。

- BOOK-OF-LAW-END-B：玩家提前识破或协商救援，省去被交还的危机。

- BOOK-OF-LAW-END-D：原创处置，不以立场选择惩罚玩家。
