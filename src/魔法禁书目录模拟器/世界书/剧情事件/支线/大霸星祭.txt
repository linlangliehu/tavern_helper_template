【事件包：大霸星祭·活动框架（支线）】
事件包ID：FESTIVAL
类型：支线·祭典活动，不承担两条主线的结算
所属阶段：阶段4·旧约·大霸星祭季
年层：Y
时间窗口：9月19–25日七日背景；19日开幕夜与25日闭幕分开
别名与触发词：大霸星祭活动 / 大霸星祭观赛 / FESTIVAL / FESTIVAL-01
证据定位：O22、O23、O24；祭典官网、官方动画年表；旧约9–10、超炮7–10卷

== 1. 核心定位 ==
提供参赛、观赛、探访与日常结交路线。魔法侧事件走ST-CROSS，科学侧调查与美琴异变走DAIHASEISAI；本包不夺取两者的主线锚点，也不靠一句祭典结束结掉主线。

== 2. 不可丢失的核心事实 ==
- 祭典持续19–25日，学生比赛与家长、校外观众活动并行；并非所有重要角色都是参赛选手。
- 黑子原作此时带伤，适合观赛、联络及能力范围内的活动；一方不是默认参赛者。美琴、食蜂、削板也须按具体场景出现，不能统一排成每场选手名单。
- 使徒十字原作19日夜被烟花阻断，20日凌晨是追捕余波；科学侧事件另有翌日调查与异变，不延长魔法侧仪式到25日。

== 3. 玩家可改写的部分 ==
玩家自行选择参赛或观赛、社交对象、项目与成绩；访客和工作人员路线同样可玩。不强制参赛、不以比赛输赢扣机制资源，也不为日常活动制造暗部追杀。

== 4. 节点推进表 ==
支线节点只供任务追踪引用；可按祭典实际日程重复日常活动，不重算主线完成度。

FESTIVAL-01 入场与身份
进入条件：19–25日进入祭典活动。
场景目标：确认今天以学生、观众或协助者身份参加，以及实际能进入的场所。
可见角色：同学、工作人员、来访家长。
玩家行动：查询日程、报名、购票或与同伴会合。
结果：得到当日可参与的项目，不自动接到全部角色邀约。
下一节点：FESTIVAL-02或FESTIVAL-03。

FESTIVAL-02 一场具体的比赛
进入条件：已选定当日项目，或在观众席等待开赛。
场景目标：完成比赛、应援或现场协助，保留学生各自的实际出场身份。
可见角色：当场参赛者、裁判、同学；黑子可在观赛或联络位置出现。
玩家行动：配合队友、制定战术、应援、照顾受伤同伴。
结果：记录具体成绩和互动，不把比赛失利写成全剧情失败。
下一节点：FESTIVAL-03；继续活动可再选FESTIVAL-02。

FESTIVAL-03 场边与家长来访
进入条件：比赛间歇或选择非参赛路线。
场景目标：用餐、引路、探访伤员，处理同伴被主线行动临时叫走的安排。
可见角色：实际在场的同学、朋友、家长；不强行召集一方或暗部成员。
玩家行动：交谈、分享见闻、帮忙联络，或明确选择介入主线。
结果：日常关系有具体进展；涉及主线的线索移交对应事件包。
下一节点：19日夜可接FESTIVAL-04；其他日期接FESTIVAL-05或返回FESTIVAL-02。

FESTIVAL-04 开幕夜的烟花
进入条件：19日夜选择观赏烟花；较晚入场不倒退日期补演。
场景目标：与同伴观赏、疏导人群或回访当日伤员。
可见角色：观众、同伴、工作人员；主线角色只按已有行踪相遇。
玩家行动：观赏、照顾走散者、约定翌日活动。
结果：此为开幕日夜间活动，不是闭幕；ST-CROSS的仪式结果仍由主线记录。
下一节点：FESTIVAL-05。

FESTIVAL-05 余下几日与告别
进入条件：20–25日继续活动，或玩家准备离开祭典。
场景目标：安排后续项目、回访因事件缺席的朋友，处理25日闭幕后的约定。
可见角色：按当前日期与伤情能到场的伙伴。
玩家行动：补约、参赛、告别或整理照片与联络方式。
结果：日常活动收束；若主线仍有未完成事项，明确保留而不顺带结案。
下一节点：可返回FESTIVAL-02或FESTIVAL-03；选择结束则无。

== 5. 分支和偏离规则 ==
主线需要人员离场时让位，不把人同时放在比赛与战场。玩家可改变活动日程和伤者恢复情况，按已有世界线解释，不强制与原作成绩或邀约一致。

== 6. 换篇条件 ==
完成活动、主动离开或超过25日即可结束支线；回到原有主线的未完成节点。只有玩家明确选择换主线才由主线协议更新锚点，本包不自动跳转意大利或十月。

== 7. 防剧透边界 ==
普通观众只知道实际目击或获告知的消息；不因烟花发生便知晓使徒十字真相。之后选择主线调查不受本活动视角限制。

== 8. 状态写回契约 ==
活动与承诺同轮写任务追踪，关系按实际互动更新；本包不改主线进度.正史锚点.当前锚点、主线进度.当前节点，也不以支线ID覆盖主线进度.已完成节点/可触发节点。影响正史的既成偏移按现有契约同轮记主线进度.正史锚点.玩家偏移，无新增API或字段。

== 9. 收束结果 ==
- FESTIVAL-END-A：完成所选活动，留下比赛与社交记录。
- FESTIVAL-END-B：中途支援主线，日常约定保留待续。
- FESTIVAL-END-C：自主离场或跳过，无参赛惩罚和强制人情债。
