【事件包：大霸星祭·活动框架（支线）】
事件包ID：FESTIVAL
类型：支线（大型祭典玩法框架，科学侧为主但魔法侧可卷入）
与主线包的关系：主线剧情走「主线事件·大霸星祭」（DAIHASEISAI）；本包只提供祭典活动玩法框架，两者可同时激活，冲突时以主线锚点优先。

== 1. 核心定位 ==
大霸星祭是学园都市历时七天、180 万人参加的超大规模体育祭，超能力者公开对决的盛大舞台。表面是青春热血的运动会，暗地里暗部势力暗流涌动——统括理事会借机观察能力者、暗部借机行动。本包是玩家高调亮相、结交 Level 5、享受祭典氛围的玩法框架。

== 2. 玩法事实 ==
- 祭典设定：历时七天、每日不同项目、全球直播；参赛者与观众身份自由切换。
- 可见角色：御坂美琴、一方通行、白井黑子、食蜂操祈、削板军霸（祭典参赛者）；暗部成员。
- 活动内容：报名参赛/观赛应援/街头小吃/团体赛/祭典限定活动。
- 祭典期间的剧情爆发（使徒十字、Level-6 相关）属对应主线事件包的领域，本包只做氛围与钩子。
- 比赛失利、被暗部盯上等作为剧情事实呈现，不构成惩罚判定。
- 魔法侧玩家可伪装潜伏或受英国清教派遣观察。

== 3. 玩家可改写的部分 ==
- 参赛项目与成绩、观赛与社交的全部安排。
- 是否借祭典接触主线角色、建立长期关系。
- 玩家能力自由发挥（含跨体系混用，无反噬无代价）。

== 4. 状态写回契约 ==
- **锚点让位规则**：本包永不改变 主线进度.当前锚点/当前节点/阶段状态。
- 主线包 DAIHASEISAI 激活时，本包只承担活动玩法层，主线节点由主线包驱动。
- 物品：祭典限定奖励、奖金正常入账。
- NPC关系：Level 5 与参赛者的好感度/声望正常推进。
- 玩家的祭典表现写入世界线记录（若后续主线包未激活，声望事实仍被保留）。

== 5. 收束方式 ==
祭典结束即随日常回归，无篇章收束。
