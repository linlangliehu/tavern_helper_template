【事件包：暗部冲突（支线）】
事件包ID：DARKSIDE
类型：支线（高危暗部线，科学侧为主，魔法侧可被卷入，可重复）

== 1. 核心定位 ==
学园都市光鲜表面下藏着「暗部」——替统括理事会干见不得光任务的地下组织（Group、Item、Block、Member 等）。一方通行、土御门元春、结标淡希、麦野沈利都是暗部成员。暗部处理「能力者失控、实验泄密、外部势力渗透、内部清洗」等脏活，手段不择。玩家若牵扯进都市机密，会被拉拢、利用或清除——清除以剧情危机呈现，不构成失败收场判定。本包是科学侧最高危、最高回报的支线，也是通往阶段5三战（WW3）的伏笔线。

== 2. 玩法事实 ==
- 进入方式：玩家卷入机密/被招募/成为清除目标；原创角色需有相应背景铺垫。
- 任务类型阶梯：能力者失控镇压→实验泄密追查→外部势力渗透清剿→内部清洗。
- 可见角色：一方通行（Group）、土御门元春、结标淡希、麦野沈利（Item）、垣根帝督（暗面对手）；统括理事会指令；偶尔出现的上条当麻（介入方）。
- 关键钩子：暗部间内斗、与统括理事会博弈、可能撞见亚雷斯塔真目的线索（通向后续主线包）。
- 转折点锚定：0930 事件（一方通行加入 Group）是本线的核心时间锚。
- 进入条件：科学侧玩家需先卷入机密事件（如绝对能力者进化计划）；魔法侧玩家若与科学结社勾结也可卷入。

== 3. 玩家可改写的部分 ==
- 站队与立场：加入某暗部、多方周旋、当双面间谍、或拒绝并被追猎。
- 与暗部成员的个人关系（他们是本包最重要的人际资产）。
- 是否揭露真相、把线引向更高阶段。
- 玩家能力自由发挥（含跨体系混用，无反噬无代价）。

== 4. 状态写回契约 ==
- **锚点让位规则**：本包永不改变 主线进度.当前锚点/当前节点/阶段状态；暗部线与主线交汇时（如 0930），主线事件包优先驱动剧情，本包提供组织背景与人物关系。
- 任务追踪：暗部任务作为任务记录（任务类型标明「支线·暗部」），完成或失效时移除。
- NPC关系：暗部成员的好感度/敌对状态/知情层级正常推进；「对方知道玩家多少秘密」用 NPC关系.认知 字段承载。
- 物品：机密情报、报酬、特殊装备正常入账。
- 挖出的亚雷斯塔线索/机密写入世界线记录，供后续主线包引用。

== 5. 收束方式 ==
单个任务即接即结；暗部身份与恩怨作为长期状态跨篇保留（写入世界线记录）。玩家可随时暂离回日常，但暗部的记忆不会消失。
