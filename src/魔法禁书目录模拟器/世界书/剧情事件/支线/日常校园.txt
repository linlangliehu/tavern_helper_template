【事件包：日常校园（支线）】
事件包ID：DAILY
类型：支线（纯日常，全员可接，零压力，可无限重复）

== 1. 核心定位 ==
学园都市 80% 人口是学生，日常就是青春本身——上课、打工、吃穿用度、便利店闲逛、和同学吐槽、被风纪委员追、追星呱太、在繁华区约会。本包是玩家恢复节奏、推进 NPC 好感度、触发角色「拼命守护后的安详日常」的轻松线。上条当麻的不幸日常、御坂美琴的呱太收集、白井黑子的「姐姐大人」狂热，都发生在这条线上。本包是「C 平衡型」剧情氛围的核心承载——日常轻松搞笑打底。

== 2. 玩法事实 ==
- 进入方式：玩家主动「今天不卷主线/休息一天」，或开局锚点直接选日常。
- 活动范围：上课/打工/购物/吃饭/闲逛/找人聊天/小型社团活动。
- 偶遇机制：日常中可能偶遇主线角色，触发轻松互动或小型支线钩子（撞见美琴追呱太、被黑子追、和食蜂喝茶）。
- 可见角色：上条当麻、御坂美琴、白井黑子、初春饰利、佐天泪子、食蜂操祈、削板军霸等日常可接触角色；便利店店员、宿舍管理员等功能性 NPC。
- 魔法侧玩家在学园都市的日常伪装也在此包展开。
- 偶尔有日常型小麻烦（被黑子追/打工搞砸/被美琴误放电波及），作为剧情事实呈现，不构成惩罚判定。

== 3. 玩家可改写的部分 ==
- 日常的全部内容与节奏；与任何角色的相处方式。
- 是否把日常钩子发展成正式任务或长期关系。

== 4. 状态写回契约 ==
- **锚点让位规则（最重要）**：本包永不改变 主线进度.当前锚点/当前节点/阶段状态——日常就是日常，主线锚点保持原样。
- NPC关系：日常互动正常推进好感度与关系状态，为主线合作埋伏笔。
- 物品：打工收入、购物所得正常入账。
- 任务追踪：日常约定（如周末约会、社团活动）可作为轻量任务记录，完成后移除。
- 日常中的重大事件（新朋友、表白、找到兼职）写入世界线记录。

== 5. 收束方式 ==
本包无固定收束——随时可进可出，是玩家随时可回的休息区。离开时无需结算，只需保证主线锚点未被触碰。
