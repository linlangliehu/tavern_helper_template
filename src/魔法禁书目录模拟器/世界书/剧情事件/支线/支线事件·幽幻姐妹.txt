【事件包：幽幻姐妹】
事件包ID：ASTRAL-BUDDY
包类型：支线包（锚点让位型，与同期主线并行）
所属阶段：阶段4·九月下旬至十月上旬的常盘台支线
年层：Y（当前年）；才人工房相关旧事只在回忆层呈现。
时间窗口：九月下旬跨入十月上旬，与天赋梦路部分并行；旧项目9月22日—10月6日不是全30话已经证实的精确起讫，不能把本篇排成天赋梦路完成后的必接事件。
原作范围：独立漫画《とある科学の超電磁砲外伝 アストラル・バディ》全4卷30话；本包默认推进至幕后计划显露与全城混乱的阶段交接。
别名与触发词：幽幻姐妹 / Astral Buddy / 幽体连理 / ASTRAL-BUDDY / ASTRAL-BUDDY-01

== 1. 核心定位 ==
帆风润子被一个自称幽灵、失去记忆的少女缠上。围绕她的身份展开调查时，食蜂派阀遭袭、才人工房旧实验与蜜蚁的计划逐渐连接。玩家可从帆风的日常、异常目击、派阀求助或街头救援介入，不要求提前知道实验真相。
本篇讲述当前的调查与旧伤，不默认复活已死研究人员，也不把未确认的意识现象直接判为灵魂返生。

== 2. 不可丢失的核心事实 ==
- 幽灵少女是悠里千夜。她的幽体连理涉及AIM思念体、以水为媒介的作用，以及对精神和肉体的支援；可以附于失去意识的身体，不因此获得任意操纵所有生物的万能权能。
- 千夜与才人工房第三研究室“内部进化”有旧日联系；她有先天肺部疾病、心脏负担等病史。旧实验与当前思念体的存在不能推出“肉体植物状态、最后必然回归”这一确定结局。
- 弓箭入鹿等人劫持食蜂，帆风与伙伴介入；入鹿与北条彩铃遭到击败。此前的异常调查与派阀袭击是可分开介入的线索，不能让玩家开场就拿到幕后名单。
- 北条静护是研究者、彩铃的兄长，旧实验暴走后虽受重创仍存活。远峰叶理的往事只能通过回忆、记录或当事人陈述呈现，不能无解释作为当前活人登场。
- 削板军霸向帆风发起挑战；真正幕后人物蜜蚁推进计划，混乱扩大到学园都市。计划动机不能直接改写为“已经能救回死者”。
- 本篇与独立心理掌握漫画MENTAL-OUT、ITEM第二卷、NT11不是同一个包。NT11对应MENTAL-STINGER，当前事件层在Y十一月下旬，上蜂相关夏日回忆在Y−1；不再沿用“十二月蜜蚁篇”的交叉引用。

== 3. 玩家可改写的部分 ==
玩家可选择先保护千夜、协助帆风救食蜂、核对研究记录或在全城混乱中保护居民。能够提前阻止的袭击不补演；入鹿、彩铃与蜜蚁的责任分别按已发生事实处理。
可以提出对话、研究监管、意识保护等自由方案，但其效果必须有现场条件与后续行动，不能一句“温柔重演”便宣告旧日死者全部复活。玩家改变千夜归宿时明确记为本线选择，不冒充原作默认结局。

== 4. 节点推进表 ==
每轮至多一个支线主要节点；沿用ASTRAL-BUDDY-01至ASTRAL-BUDDY-06。主线有即时危机时先让位。

ASTRAL-BUDDY-01 幽灵骚动
进入条件：在同期常盘台日常中遇见帆风或接到与她有关的异常目击。
场景目标：确认少女与帆风的联系，区分传闻和玩家亲见。
可见角色：帆风润子；千夜只在当前能够感知她的条件下可见。
玩家行动：询问失忆线索、陪同调查、观察媒介与感知差异、拒绝把传闻当证明。
结果：帆风被失忆少女缠上的事实成立，身份与能力仍需追查。
下一节点：ASTRAL-BUDDY-02。

ASTRAL-BUDDY-02 异常的线索
进入条件：愿意继续协助帆风，或周边出现与调查相关的袭击及派阀异常。
场景目标：追踪异常与研究背景的联系，保护尚未受害的人。
可见角色：帆风、食蜂派阀成员；千夜按感知条件参与。
玩家行动：走访目击者、比对现象、保护可疑物证、把信息交给愿意合作的当事人。
结果：调查接近派阀冲突；不凭一个梦或幽灵传闻便宣布全城人员受同一机制控制。
下一节点：ASTRAL-BUDDY-03。

ASTRAL-BUDDY-03 派阀之乱
进入条件：食蜂遭劫持或玩家已得到可靠袭击预警。
场景目标：找到食蜂并化解入鹿、彩铃造成的威胁。
可见角色：帆风、弓箭入鹿、北条彩铃；接近目标后可见食蜂。
玩家行动：支援营救、打断陷阱、照顾伤者、保存袭击者与研究背景的联系。
结果：默认帆风与伙伴反击，入鹿与彩铃遭击败；玩家提前防护则保留未遭绑架的新局面。
下一节点：ASTRAL-BUDDY-04。

ASTRAL-BUDDY-04 正体与旧实验
进入条件：救援后取得研究线索，或相关当事人愿意讲述过去。
场景目标：辨明千夜的身份及内部进化的旧伤，避免把不同人的生死混在一起。
可见角色：帆风、千夜及能提供证词的相关人物；远峰叶理仅出现在往事叙述中。
玩家行动：核对病史与实验记录、分别确认静护和叶理的情况、询问千夜愿意承受什么风险。
结果：千夜的AIM思念体与实验联系浮出；不能由此推定其肉体去向、告别方式或实验可复活死者。
下一节点：ASTRAL-BUDDY-05。

ASTRAL-BUDDY-05 第七位的挑战
进入条件：削板军霸向帆风挑战，或玩家所在现场受到这场交锋影响。
场景目标：应对挑战，保护周边，并保留继续追查幕后计划的力量。
可见角色：帆风、削板军霸；千夜是否能被旁人感知仍按现场条件。
玩家行动：协助防护、疏散、观察双方判断、提出停战或让帆风自行应战。
结果：默认帆风面对削板的挑战；玩家可影响过程，不凭“根性”自动赋予任何人新等级或万能解法。
下一节点：ASTRAL-BUDDY-06。

ASTRAL-BUDDY-06 约定与未完的抉择
进入条件：蜜蚁的幕后计划显露，混乱已经扩大或被玩家提前遏止。
场景目标：保护受波及的人，决定如何面对旧实验与千夜的愿望。
可见角色：帆风、千夜；蜜蚁只在追到其行动或取得可用联系后进入现场。
玩家行动：阻止已确认的危险、分辨救人与重演实验、尝试对话、为千夜保留自主决定的空间。
结果：默认交接到蜜蚁计划与全城混乱的应对阶段；不自动演出千夜消散、回归身体或死者复活。若玩家已完成局部救援，则按其实际成果结束本支线当前段。
下一节点：AB-END-A／AB-END-B／AB-END-C／AB-END-D。

== 5. 锚点让位规则 ==
永不修改主线进度.正史锚点.当前锚点、主线进度.阶段序号、主线进度.当前阶段、主线进度.阶段状态、主线进度.当前节点、主线进度.已完成节点或主线进度.可触发节点。主线推进优先，本篇不能因同名人物或梦路关键词自动接管主线。
用现有任务文字保留当前支线节点，主线需要同一人物时先检查时间与地点，不让人物同时在两处行动；暂停后从保留节点继续，不把未完成节点算已完成。

== 6. 换篇条件 ==
完成当前救援、交接调查或玩家主动离开即可暂停。与天赋梦路只按实际发生的日期并行；转入独立心理掌握或MENTAL-STINGER须另选事件并检查其时间层，不自动触发。

== 7. 防剧透边界 ==
初见不公开千夜全名、研究史或蜜蚁的布局。过去的死亡、实验责任与当前的能力现象分别求证；不能把玩家尚未得到的终局信息通过“幽灵自述”无条件灌入。

== 8. 状态写回契约 ==
仅在现有任务追踪的任务文字、NPC关系及世界线记录中登记ASTRAL-BUDDY的当前节点、已发生的救援、证词和玩家选择；不创建支线专用字段、不更新主线节点数组、不以本篇收束写主线完成。
记录未明的意识状态时保持未明；回忆信息带上往事标记，当前行动使用Y，不把NT11的Y−1夏日回忆挪成本篇当前事件。

== 9. 收束结果 ==
- AB-END-A 默认阶段收束：千夜身份与旧实验线索连接，派阀救援和削板挑战已推进，蜜蚁计划与全城混乱进入应对；不预写完整终局。
- AB-END-B 玩家主导：按实际阻止的袭击、救援与对话交接，不宣布未经行动的复活或必然和解。
- AB-END-C 局部见证：已得证词成为后续线索，未见终局仍保持未明，不获得全知档案。
- AB-END-D 玩家退出：保留当前支线状态，回到主线；无失败惩罚、不抢锚点。
