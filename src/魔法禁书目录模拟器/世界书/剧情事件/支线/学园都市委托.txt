【事件包：学园都市委托（支线）】
事件包ID：COMMISSION
类型：支线（日常+轻战斗，科学侧为主但全员可接，可重复）

== 1. 核心定位 ==
学园都市 230 万人口日常运转，少不了各种「小麻烦」——从街头能力者纠纷、走失儿童、违规能力使用，到仓库盗窃、研究设施小事故。风纪委员（Judgement）与警备员（Anti-Skill）人手不足，常向学生放出委托；暗部也偶尔借「委托」名义干脏活。本包是玩家积累资金、声望、人脉的最佳日常入口。

== 2. 玩法事实 ==
- 进入方式：玩家主动接委托，或被风纪委员/警备员/普通市民求助。
- 接单渠道：风纪委员 177 支部、街头公告板（日常型/战斗型/调查型）。
- 委托类型阶梯：街头调停→能力者纠纷→小型潜入→仓库盗窃→研究设施小事故。
- 可见角色：白井黑子、初春饰利、固法美伟（风纪委员 177 支部）；黄泉川爱穗（警备员）；佐天泪子（路人吐槽担当）；偶尔客串的上条当麻。
- 关键钩子：可能撞见暗部借「委托」名义干脏活，或发现委托背后藏着更大的线（可通向暗部冲突包或对应主线事件包）。
- 委托搞砸（被投诉/被黑子训/被要求赔偿）作为剧情事实呈现，不构成惩罚判定，可继续。

== 3. 玩家可改写的部分 ==
- 接什么委托、怎么处理、是否追查到底或收手。
- 与委托方/风纪委员/警备员的长期关系经营。
- 玩家能力自由发挥（含跨体系混用，无反噬无代价）。

== 4. 状态写回契约 ==
- **锚点让位规则**：本包永不改变 主线进度.当前锚点/当前节点/阶段状态；委托中发现主线级线索时，只做记录与钩子，不推动主线节点。
- 任务追踪：每个委托作为任务记录（任务类型标明「支线·委托」），完成或失效时移除。
- 物品：报酬、缴获品正常入账。
- NPC关系：风纪委员/警备员/市民的好感度与声望正常推进。
- 挖出的暗部/科学结社线索写入世界线记录，供对应主线包引用。

== 5. 收束方式 ==
单个委托即接即结，无篇章收束。玩家可随时暂离去主线。
