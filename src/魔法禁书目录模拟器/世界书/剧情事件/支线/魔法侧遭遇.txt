【事件包：魔法侧遭遇（支线）】
事件包ID：MAGIC-CONTACT
类型：支线（魔法侧为主，科学侧玩家可被卷入，可重复）

== 1. 核心定位 ==
学园都市表面是科学之地，暗地里却是魔法侧各方角力的战场。英国清教、罗马正教、天草式、格雷姆林残党都在都市内有各自的行动；魔法师伪装成普通市民潜伏，偶尔因任务暴露。魔法侧玩家可受雇于英国清教处理异端，或作为天草式成员行动；科学侧玩家可能在街头意外撞破魔法师术式，被卷入科学与魔法的交错冲突。

== 2. 玩法事实 ==
- 进入方式：魔法侧玩家从英国清教/天草式据点接「异端处理/灵装回收/情报刺探」类任务；科学侧玩家在街头撞破术式后被卷入。
- 任务类型阶梯：伪装潜入→术式对峙→灵装回收→情报刺探。
- 可见角色：神裂火织、史提尔·马格努斯、五和（天草式）；偶尔出场的萝拉·斯图亚特指令；罗马正教/格雷姆林残党作为对手。
- 关键钩子：可能撞见罗马正教或格雷姆林残党的行动，发现科学侧暗部与魔法侧勾结的线索（可通向对应主线事件包或暗部冲突包）。
- 任务搞砸（术式失灵闹乌龙/被反将一军/被监护人训）作为剧情事实呈现，不构成惩罚判定。
- 科学侧玩家需先卷入一次魔法事件（如禁书降临篇）后才会被纳入魔法侧任务体系。

== 3. 玩家可改写的部分 ==
- 接什么任务、对魔法侧各方的关系立场（可同时与多方便周旋）。
- 是否追查到底或收手；撞破事件后走科学侧程序还是私下处理。
- 玩家能力自由发挥（含跨体系混用，无反噬无代价）。

== 4. 状态写回契约 ==
- **锚点让位规则**：本包永不改变 主线进度.当前锚点/当前节点/阶段状态；发现主线级线索时只做记录与钩子。
- 任务追踪：每个魔法侧任务作为任务记录（任务类型标明「支线·魔法侧」），完成或失效时移除。
- 物品：魔道书抄本、灵装、魔法侧道具正常入账。
- NPC关系：神裂/史提尔/五和等魔法侧人脉的好感度与认知正常推进。
- 挖出的暗部勾结/世界级线索写入世界线记录，供对应主线包引用。

== 5. 收束方式 ==
单个任务即接即结，无篇章收束。玩家可随时暂离去主线。
