【势力：魔法侧势力总览】

== 英国清教（Anglican Church / 必要之恶教会）==
- 定位：英国国教的核心魔法组织，「必要之恶教会」是其行动部门，负责处理魔法侧的异端与威胁
- 成员/代表人物：最高主教萝拉·斯图亚特；神裂火织、史提尔·马格努斯（Index 监护人）
- 目标理念：守护英国与十字教世界的秩序，管理魔道书与异端术式，制衡罗马正教与学园都市
- 与玩家的关系：魔法侧玩家最常打交道的组织；可能是你的上司、雇主或约束者
- 与其它势力关系：与罗马正教同源却暗中博弈；与学园都市有限合作；与格雷姆林对立
- 在主线中的角色：Index 的归属组织，禁书降临篇的引导者，贯穿全线的魔法侧后台

== 罗马正教（Roman Catholic Church）==
- 定位：故事世界观中最大的宗教势力，信众遍布全球，魔法底蕴深厚
- 成员/代表人物：教皇及众多神职魔法师；暗部「神之右席」（右方之火等四人）
- 目标理念：维护罗马正教对世界的绝对影响力，视学园都市的科学为异端与威胁
- 与玩家的关系：若玩家卷入世界级事件，罗马正教可能是施压方、对手或幕后推手
- 与其它势力关系：与英国清教长期对立；与俄罗斯成教同属十字教却各怀心思；与学园都市正面冲突
- 在主线中的角色：使徒十字篇、第三次世界大战的主要发动方之一

== 俄罗斯成教（Russian Orthodox Church）==
- 定位：十字教三大分支之一，三战期间的关键魔法势力
- 成员/代表人物：多位主教与魔法师，与罗马正教有复杂同盟关系
- 目标理念：维护俄罗斯教廷利益，在三战中选择站在罗马正教一侧
- 与玩家的关系：通常远观；若玩家深入三战主线，会正面遭遇
- 与其它势力关系：与罗马正教同盟对抗学园都市；与英国清教貌合神离
- 在主线中的角色：第三次世界大战的魔法侧主战场承载者

== 天草式十字凄教 ==
- 定位：日本地下的基督教派系，融合神道与十字教术式，行动隐秘
- 成员/代表人物：神裂火织（出身于此）、五和等
- 目标理念：以日本独有的方式守护信仰，依附英国清教行动
- 与玩家的关系：可能成为魔法侧玩家的同行者或情报来源
- 与其它势力关系：隶属英国清教体系，与罗马正教对立
- 在主线中的角色：神裂火织的根，日常与主线间隙的灰色地带组织

== 神之右席（God's Right Seat）==
- 定位：罗马正教最隐秘的暗部组织，四人对应十字教四大元素与天使
- 成员/代表人物：右方之火（右手/红色/大天使米迦勒）、后方之水（威廉·奥威尔，圣人）、前方之风、左方之地
- 目标理念：表面效忠罗马正教，实则各自怀揣「超越神」的极端计划
- 与玩家的关系：高阶段主线的强敌或幕后黑手；低阶段几乎不露面
- 与其它势力关系：游离于罗马正教常规体系之外，自成一方
- 在主线中的角色：使徒十字篇与三战的核心反派集团

== 格雷姆林（Gremlin）==
- 定位：新约登场的魔法结社，融合科学与魔法的灰色组织
- 成员/代表人物：玛丽安·斯琳格奈亚、雷维尼亚·巴德温等
- 目标理念：以魔神为后盾颠覆现有秩序，制造世界级混乱
- 与玩家的关系：新约阶段主线对手；可能以合作者面目接近玩家
- 与其它势力关系：与真·格雷姆林有渊源，与学园都市、英国清教均对立
- 在主线中的角色：新约·格雷姆林/魔神篇的主要威胁来源

== 真·格雷姆林（True Gremlin）==
- 定位：隐世的魔神和平组织，成员皆超越人智的「魔神」
- 成员/代表人物：欧提努斯（北欧魔神）、奈芙蒂斯（埃及）、特兹卡特利波卡（阿兹特克）、娘娘（中国尸解仙）、僧正（佛教）等
- 目标理念：魔神间维持微妙平衡，各自试探世界与彼此
- 与玩家的关系：极高阶段的存在；玩家若选魔神开局，本身就是其中一员
- 与其它势力关系：凌驾于普通势力之上，彼此制衡
- 在主线中的角色：新约·魔神篇的核心，世界法则的真正操弄者

== 黄金黎明（Golden Dawn）==
- 定位：1887 年创立的近代魔法结社，西方近代魔法体系的奠基者
- 成员/代表人物：马瑟斯、维斯考特；亚雷斯塔·克劳利曾加入
- 目标理念：系统化研究与精制魔法，追求魔法至高境界
- 与玩家的关系：历史背景组织，通常作为往事被提及；偶有遗物或残党卷入
- 与其它势力关系：1900 年因亚雷斯塔挑拨内斗解体；其遗产影响后世众多魔法师
- 在主线中的角色：魔法侧历史纵深，理解亚雷斯塔与魔法起源的关键线索

== 科学结社 ==
- 定位：学园都市外部的敌对科学组织，与都市内研究员勾结
- 成员/代表人物：与天井亚雄、结标淡希等有过关联
- 目标理念：窃取并滥用学园都市科技，谋取私利
- 与玩家的关系：若玩家卷入科技泄密或地下实验，会成为对手
- 与其它势力关系：与学园都市暗面勾结，被风纪委员/警备员追查
- 在主线中的角色：科学侧支线与暗部事件的常见幕后之一
