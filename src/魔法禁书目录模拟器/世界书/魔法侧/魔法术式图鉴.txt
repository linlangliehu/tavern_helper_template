【魔法术式图鉴：魔法禁书目录模拟器】

> 本作魔法侧术式归档。按体系分列原著标志性术式与效果，供魔法侧玩家与 NPC 战斗演绎参考。
> 本作无风险值、无反噬、无解密——术式失败以「失灵/出糗/扰民/被举报」等喜剧性后果呈现，不致死不收场。

== 符文魔法（史提尔·马格努斯·英国清教） ==
- 类型：符文系魔法
- 持有者：史提尔·马格努斯
- 效果：刻/贴在周围的"带有力量的文字"，写"火焰Kenaz"即冒火；符文消失则魔法消失，施术者被打倒魔法亦消失
- 限制/副作用：符文需提前布置；潮湿或被干扰会失效（喜剧化：遇暴雨符文泡汤，史提尔当场变落汤鸡）
- 用处：史提尔的招牌体系，区域控制与火力压制的基础

== 猎杀魔女之王（Innocentius / 异端审问官） ==
- 类型：符文召唤术式
- 持有者：史提尔·马格努斯
- 效果：召唤超3000℃火焰巨人，符文范围内无限复活，融化一切攻击与障碍，自动追踪敌人直至歼灭；可一次召唤三个（三位一体构造）
- 限制/副作用：仅存在于符文空间，离开符文范围即消散
- 用处：禁书降临篇对上条当麻的主力术式；魔法侧歼灭级火力

== 炎剑（Flame Sword） ==
- 类型：符文炎术
- 持有者：史提尔·马格努斯
- 效果：超3000℃火焰形成的剑，咒文"TIAFIMH/IHTSOTS/AIHTR"；可变化外形；衍生招"赐与巨人痛苦的赠礼"（大爆炸+高速袭击）、"吸血猎杀红十字"（左右手蓝红双剑，威力为大投射炎剑一倍）
- 限制/副作用：维持高温极耗体力，长时间使用会虚脱
- 用处：近战与中距离的火力爆发手段

== 闲人驱散（Opila） ==
- 类型：符文区域术式
- 持有者：史提尔·马格努斯
- 效果：使附近人产生"不知为何不想靠近这里"的心情，取得一定区域所有权防外人干涉
- 限制/副作用：对意志强者或无心者无效
- 用处：开战前清场，避免波及路人

== 海市蜃楼 ==
- 类型：符文幻术
- 持有者：史提尔·马格努斯
- 效果：利用空气受热膨胀改变光折射率，身影如溶于空气般消失，或投射到空无一物之处
- 限制/副作用：遇强风或温度骤变会穿帮
- 用处：潜行、佯攻、脱战

== 拘束卡 ==
- 类型：符文束缚术式
- 持有者：史提尔·马格努斯
- 效果：带有心理功效的身心拘束，影响思考与行动能力
- 限制/副作用：对圣人级体质效果减弱
- 用处：控制与捕捉敌人

== 钢丝术式（神裂火织·圣人专用） ==
- 类型：灵装术式载体
- 持有者：神裂火织
- 效果：以钢丝勾勒魔法阵，发动切割与封印术式；可设陷阱与近战
- 限制/副作用：需精确手法，失误会伤及自身
- 用处：神裂标志性战斗方式，攻防一体

== 七闪（七千日元） ==
- 类型：钢丝斩击术式
- 持有者：神裂火织
- 效果：操纵七条钢丝施展斩击，看不见的速度撕裂对手，一瞬间杀人七次故称"瞬杀"；拔刀动作掩饰操纵钢丝之手（实际未真正拔刀）；钢丝最大限度展开可割裂空气高空减速
- 限制/副作用：仅圣人级体质能完美驾驭其速度
- 用处：神裂招牌瞬杀技，近战与突围

== 唯闪 ==
- 类型：圣人拔刀术式
- 持有者：神裂火织
- 效果：用"七天七刀"的拔刀术，在不同宗教术式（十字教/佛教/神道）间互补弱点，发挥完全破坏力的一发决胜负招式——对特定宗教迂回使出其他教义的术式攻击，连天使也能切断；瞬间引出"神之子"的力量
- 限制/副作用：超肉体极限，长时间使用身体濒临崩溃，淬炼成一发决胜负；失败以搞笑呈现（闪到腰、刀卡鞘）
- 用处：神裂的决胜王牌，对天使/神之右席级存在的杀手锏

== 七天七刀（倭刀） ==
- 类型：灵装（圣人专用刀）
- 持有者：神裂火织
- 效果：圣人挥舞时可斩断术式与异能；配合钢丝术式形成攻防一体的战斗体系
- 限制/副作用：仅圣人级体质能完全发挥；普通人强用效果减弱
- 用处：魔法侧近战与术式破解的核心灵装

== 阴阳道（土御门元春·东洋术式大流派） ==
- 类型：东洋术式体系
- 持有者：土御门元春（最高阶阴阳博士）
- 效果：综合道教与日本文化的东洋术式大流派，含风水、占术、炼丹、咒术、祈祷、历术、漏刻等
- 限制/副作用：需描绘纸片魔法阵发动；兼能力者身份强行施法会伤身（本作改为搞笑抽搐）
- 用处：土御门的根基体系，多场景通用

== 风水 ==
- 类型：阴阳道·地脉术式
- 持有者：土御门元春
- 效果：利用地脉与龙脉能量流向，通过山川位置或房屋隔间配置创造回路（魔法阵），以大地"气"作能量
- 限制/副作用：受地形影响，在钢筋水泥密林地带效果减弱
- 用处：地形控制与陷阱布置

== 赤术式 ==
- 类型：阴阳道·远距离炎魔法
- 持有者：土御门元春（不熟练）
- 效果：远距离攻击用炎魔法，曾从远处精准轰掉上条当麻的家
- 限制/副作用：土御门不擅长，准头偶尔翻车（轰错房子）
- 用处：远程爆破

== 黑术式 ==
- 类型：阴阳道·水路攻击术式
- 持有者：土御门元春（最擅长）
- 效果："制造水路"，通过水流安排巨大魔法阵，借以保护城堡或都市
- 限制/副作用：需水源，沙漠地带无效
- 用处：土御门招牌，大范围防御与攻击

== 理派四阵 ==
- 类型：阴阳道·探索术式
- 持有者：土御门元春
- 效果：以使用者为中心半径约三公里搜索；需事先配置蓝、白、红、黑四张色纸及探索目标的"灵装"，发动后四张色纸转动逼近灵装，最终在地面画出精密地图
- 限制/副作用：下次准备需十五分钟左右
- 用处：找人、追踪、定位

== 占术圆阵 ==
- 类型：阴阳道·逆探知魔法阵
- 持有者：土御门元春
- 效果：反应对方传来的术式魔力，逆运算出魔力源头的方向与距离；外观为直径两米左右的红色魔法阵
- 限制/副作用：需对方先发动术式才能逆推
- 用处：反追踪、定位敌方施术者

== 折纸魔法 ==
- 类型：阴阳道·折纸术式
- 持有者：土御门元春
- 效果：复杂折成正方形的折纸发动魔法，不同颜色不同效果——橙色=火焰子弹，蓝色=前方掩体弹开子弹，黑色=1m水球猛撞目标
- 限制/副作用：折纸被水泡烂或被风吹走会失效
- 用处：便携多属性攻击与防御

== 丑时参拜 ==
- 类型：阴阳道·咒术
- 持有者：土御门元春
- 效果：以特殊步骤破坏目标的一部分，借以从远处攻击目标肉体；利用对象毛发、指甲等物，将传统"丑时参拜"重新建构（重点由人偶改为毛发）
- 限制/副作用：只对"不知道的人"有用，专业魔法师会在前兆出现时采取对策
- 用处：远程暗算

== 神圣之右（Holy Right） ==
- 类型：神之右席至高术式
- 持有者：右方之火
- 效果：能让行星粉碎消散、重现所有十字教神话中的庞大力量
- 限制/副作用：受各种制约无法完全发挥，需上条当麻的"幻想杀手"作媒介才能完全输出
- 用处：三战终局级力量，右方之火的核心底牌

== 第三只手 ==
- 类型：神之右席术式
- 持有者：右方之火
- 效果：右肩出现巨人手臂般扭曲的光块作为攻击手段——挥手即中无需速度，拍下即灭无需更大威力；力量随"必须打倒的敌人强度"自动调整（来源为人们的恶意）；可挥3-40公里橘色长剑劈开山脉
- 限制/副作用：非常不安定，无法长时间维持会空中分解
- 用处：右方之火的主力攻击形态

== 妖精化 ==
- 类型：神之右席术后习得术式
- 持有者：右方之火（失右臂后接触欧莱鲁斯习得）
- 效果：将目标妖精化的法术，曾对欧提努斯使用并打中
- 限制/副作用：对僧正的"变异型妖精化"改良版失败
- 用处：对付魔神级的手段之一

== 天罚术式 / 天谴术式 ==
- 类型：神之右席·天使术式
- 持有者：前方之风
- 效果："二十亿中的最终兵器"，不限距离剥夺所有对自己抱有敌意者的意识；会故意诱导他人产生敌意以触发；三种症状——睡着般昏迷、石头般僵硬、缺氧人工假死；灵装（舌头上连接的锁链与十字架装饰）被幻想杀手粉碎后失效
- 限制/副作用：只能针对"抱有敌意者"，对无恶意的对手无效
- 用处：前方之风的招牌术式，团灭级控制

== 空气钝器 ==
- 类型：神之右席·风术式
- 持有者：前方之风
- 效果：从虚空取出缠绕带刺铁丝的巨大槌子产生空气"钝器"，配合舌头上垂十字架的锁链做轨道修正进行攻击
- 限制/副作用：需保持锁链连接，被切断会失准
- 用处：前方之风的常规牵制与攻击手段

== 女王舰队 ==
- 类型：神之右席·海战术式
- 持有者：前方之风
- 效果：借十字教"镇压海上风暴、保护船只安全"的传说部分影响水，操纵"亚得里亚海女王"舰队的冰制帆船，发射巨大冰船锚作为攻击
- 限制/副作用：海上风暴是"风"与"水"混合属性，部分影响而非完全
- 用处：海战场景的大范围攻击

== 圣母的慈悲 ==
- 类型：神之右席·圣母术式
- 持有者：后方之水（威廉·奥威尔）
- 效果：圣母崇拜的秘密仪式，吸收夜气增强武器威力，即使是虚假的月光（如天象仪投影）也可强行获得加护
- 限制/副作用：需圣母体质加护
- 用处：后方之水的强化术式

== 阿斯卡隆（灵装） ==
- 类型：神之右席·灵装圣剑
- 持有者：后方之水（威廉·奥威尔）
- 效果：基于《圣乔治传说》圣剑效果重新创造的灵装，长3.5m重200kg，理论可斩50英尺恶龙；攻击时实时调整集中供魔力，各部位产生不同颜色；内部可隐藏一把细剑突袭
- 限制/副作用：对圣人的"圣人崩坏"术式对其加倍有效，需构筑分散力量的管道防自爆（力量跌落到普通圣人水平）
- 用处：后方之水的主力武器，斩龙级灵装

== 光之处刑 ==
- 类型：神之右席·优先度术式
- 持有者：左方之地
- 效果：根据耶稣死于十字架构建的术式，以"XX为上，XX为下"格式发动；用小麦粉（代"神之肉"）发动前大量饮酒；改变事物间优先顺序，上位对下位抵挡破坏，可把面粉刀当武器且不受单一攻击伤害
- 限制/副作用：无法同时控制多个事物的优先顺序，需一直调换事物；尚未调整完毕，准头有偏差
- 用处：左方之地的招牌术式，攻防转换

== 龙王的叹息（Dragon Breath / 龙的吐息） ==
- 类型：禁书目录·自动书记术式
- 持有者：茵蒂克丝（自动书记模式）
- 效果：发动"圣乔治领域"产生空间裂缝，发出直径1m光柱，威力相当于圣乔治之龙一击；生成极快，幻想杀手也无法完全消除；被偏移后仍贯穿大气层击毁外太空"树形图设计者"卫星；射程内一切被破坏并转化为"光之羽"
- 限制/副作用：Index 本人无意识，可能误伤友军；每3年需消除一次记忆
- 用处：禁书降临篇的主力歼灭术，高阶段关键火力

== 圣乔治领域第二阶段「Eli, Eli, Lema Sabachthani」 ==
- 类型：禁书目录·对十字教术式
- 持有者：茵蒂克丝（自动书记模式）
- 效果：咒名"神啊，你为何离弃我"，对十字教用术式，以此破解史提尔的猎杀魔女之王
- 限制/副作用：需自动书记模式才能发动
- 用处：禁书目录的反制十字教术式手段

== 圣书解读能力 ==
- 类型：禁书目录·解读能力
- 持有者：奥索拉·阿奎纳
- 效果：原罗马正教情报分析专家，擅长魔法相关暗号解读；自行研究出《法之书》解读方法
- 限制/副作用：《法之书》解读方法实为陷阱，只会把解读者引入歧途
- 用处：情报分析与魔道书解读

== 伊西丝-德墨忒尔（灵装） ==
- 类型：英国清教"神威混淆"系列灵装
- 持有者：奥索拉·阿奎纳
- 效果：穿上后操纵植物——召唤巨大猪笼草、捕蝇草、葡萄藤作为攻击手段，用植物藤蔓控制整个伦敦的地下网络
- 限制/副作用：需灵装加持，脱下后能力消失
- 用处：大范围植物控制

== 主神之枪 艮古尼尔（Gungnir） ==
- 类型：魔神权能·必中之枪
- 持有者：欧提努斯
- 效果：百发百中（必中无必杀）；枪发光后世界就会改变，相当于"对世界的控制杆"
- 限制/副作用：欧提努斯因放弃过力量成为不完整魔神，有"无限可能性"（成功与失败几率各半）
- 用处：魔神级世界改写手段

== 欧提努斯之弩 ==
- 类型：魔神权能·投射术式
- 持有者：欧提努斯
- 效果：从皮袋拿出后前段立刻伸长，同时发射十支粗大箭矢，贯穿金属铠甲，几乎不会错失目标，一举歼灭眼前敌人
- 限制/副作用：发射后需很长时间准备下一发
- 用处：魔神级歼灭手段

== 操纵相位 / 操纵时间（魔神权能） ==
- 类型：魔神权能
- 持有者：欧提努斯等真·格雷姆林魔神
- 效果：随意改变世界模样（让1+1=3、万有引力反转等）；操纵自身以外的时间流动，让时间放慢或倒流；不会衰老，腰斩斩首也能自动恢复
- 限制/副作用：完全魔神才有；欧提努斯为不完整魔神，权能受"50%成功概率"制约
- 用处：魔神级世界观战力，新约核心

== 魔神成员（真·格雷姆林） ==
- 类型：魔神集体
- 持有者：欧提努斯、欧莱鲁斯（准魔神）、僧正、奈芙蒂斯、娘娘、奇美拉、努阿达、特斯卡特利波卡、普洛塞庇娜
- 效果：完全踏入神之领域的特殊魔法师，掌握魔法侧所有知识，无限力量，颠覆一切法则，世界对他们一触即碎
- 限制/副作用：魔神间互相制衡，不会轻易全力出手
- 用处：新约·魔神篇的核心存在群

== 黄金炼成（Ars Magna） ==
- 类型：炼金术式
- 持有者：奥雷乌斯（炼金术师）
- 效果：将脑中所想转变为现实
- 限制/副作用：易受精神状态影响而变得不稳定
- 用处：将意念具现化

== 天使坠落（Angel Fall） ==
- 类型：世界级术式
- 持有者：右方之火（经由天使媒介莎夏）
- 效果：将一名天使和一名凡人交换身份；0930事件中世界范围的身份互换术式
- 限制/副作用：发动条件苛刻，需特定仪式
- 用处：世界级事件型术式

== 瞬间炼金 ==
- 类型：炼金术式
- 持有者：奥雷乌斯
- 效果：被伤到的人会被强制转换为纯金，无法防御避免
- 限制/副作用：接触类术式，需近身
- 用处：近身歼灭

== 项圈 ==
- 类型：教会防御灵装
- 持有者：茵蒂克丝
