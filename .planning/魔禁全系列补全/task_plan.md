## 各包内容骨架（均已完成联网核实，见 findings.md）

### 批1-A 死灵术师编（NECROMANCER）
- 核心事实：一方通行脑损伤住院期；死灵术师**艾丝特·罗森塔尔**（罗森塔尔家 23 代当主，称一方通行"师匠"）被"DA"（警备员之暗，与统括理事会相连）追杀；禍斗（伪魂）；DA 利用"妹达"（10046 号被绑）；**屍喰部隊**（Scavenger，4 人被封锁的暗部能力者，纸操着装'ナル'/液体比重'药丸'/摩擦系数'清ケ'/指挥型 leader）； climax：以撒=罗森塔尔 400 年 Golem 阴谋（宿于菱形蛭魅遗体）；"善意的背叛"主题。
- 节点草案：01 病房的不速之客 → 02 DA 与伪魂 → 03 屍喰部隊参战 → 04 妹达危机 → 05 师匠与祸斗 → 06 黄泉川的立场 → 07 以撒的棺桶 → 08 善意的背叛（Golem 决战）。
- 嵌套共存条款：与天使坠落包互写——天使坠落=全球身份互换事件（背景辐射），死灵术师编=本地暗部事件；两包锚点互不覆盖，关键字互不重叠。
- 原著向收束：Golem 粉碎、艾丝特决别蛭魅、DA 覆灭、一方通行护 Last Order 离场；玩家可改写艾丝特归宿/屍喰处置。

### 批1-B 暗部大战（DARK-BATTLE）
- 核心事实：10月9日单日混战；**SCHOOL**（垣根帝督）叛乱夺"镊子"（超微粒物体干涉吸着式操纵器）+滞空回线解析+袭亲船最中；**ITEM** 追击中内部崩裂→**弗兰达被麦野杀害**（原著默认+玩家可改写双线）；**BLOCK** 引外部势力袭亚雷斯塔→被 Group 镇压；**Group**（一方通行/土御门元春/结标淡希/海原光贵·艾扎里）；结局=暗部管理体制事实解体，幸存者（一方通行/滨面）拒绝做"组织之驹"。
- 节点草案：01 镊子失窃 → 02 SCHOOL 宣战 → 03 ITEM 出击 → 04 弗兰达的算计（双线节点）→ 05 BLOCK 的野望 → 06 GROUP 介入 → 07 大混战 → 08 暗部解体。
- 联动：承接静默派对包弗兰达暗线钩子；铺垫三战（滨面线）；三战包进入条件追加"暗部大战收束后"。
- 防剧透：不揭示亚雷斯塔布局深层、艾华斯、Level 6 计划后续。

### 批2-D1 幽幻姐妹（ASTRAL-BUDDY，支线）
- 核心事实：**正史窗口 10/3-10/6**（联网核实：9/26 美琴从帆风处得印第安扑克→10/4 美山写影公园火事→10/6 弓箭猟虎死亡→10/9 暗部抗争）；主线=**蜜蚁爱愉**联合才人工房第三研究室旧案，借印第安扑克+幽灵**悠里千夜**重做"内部进化/理想（アイディアル）"实验以拯救实验事故死去孩子的灵魂；帆风润子为主线主角；反派北条静護（"造神"论）。
- 性质：锚点让位型支线（同"大霸星祭活动框架"先例），永不改变主线锚点；与主线包冲突时主线优先。
- 联动：承接天赋梦路"卡牌技术去向"世界线记录；为批2-C 蜜蚁篇提供前史。

### 批2-D2 越狱篇（JAILBREAKER）
- 核心事实：第二少年院"脱狱试用赛"（越狱トライアル，AIM 干扰器防守）被真犯人利用脱狱；**春暖嬉美**（Level 0/整体论能力者=黑洞级巨观形变；右腕宿上条"龙王之颚"一体天使型竜：洗脑羽+盐化+黑雷；留精弃粗/黑暗五月计划受试者，化名白绢仄火）；同伙鳄河雷斧（重力円環）、钓钟茶寮（AIM 追踪忍者）、青星铃兰（救过她/给初春 U 盘）；目的=胁迫初春建全球网络公开能力开发技术； climax=美琴 vs 天使龙（初春解析龙以黑洞能量为食→AIM 反制）、佐天重伤获蛙医救治；结局=春暖败北再收监。
- 节点草案：01 脱狱试用赛 → 02 真犯人脱狱 → 03 初春被绑 → 04 追踪战（美琴vs鳄河/黑子vs钓钟双线）→ 05 佐天潜入 → 06 第二少年院攻防 → 07 初春的反制（AIM 觉醒）→ 08 天使龙决战。
- 与暗部大战相接（10/10 起）；三战爆发前收束。

### 批2-C 蜜蚁爱愉篇（MENTAL-OUT）
- 核心事实：蜜蚁=Level 3「心理穿孔」(Mental Stinger，手机镜头+指尖定位，同系精神系相互弹开)；树状图设计者判定其与食蜂均有 Level 5 素养，因**资质排行（Parameter List）**为集中培养食蜂被砍课程→"变成蜂的蚂蚁"；五途 OS（Five_Over Out_Sider）"MENTAL_OUT"兵器（由外而内操控人心/磁性制御显示器伪造存在）；10月末-12月初借一端览祭与食蜂对决：短暂击倒食蜂（3 秒），最终败于上条，**送少年院**；食蜂内心承认她。
- 节点草案：01 记忆的裂痕（食蜂线开启）→ 02 素养排行的真相 → 03 一端览祭开幕 → 04 蚁之女王宣战 → 05 五途 OS 出击 → 06 三秒的女王 → 07 上条的抵达 → 08 蜂与蚁的和解（收束）。
- 窗口 12 月上旬（欧提努斯战后原史时点）；防剧透：不揭示心理掌握外传深层/雲川芹亚设定细节。
- 联动：蜜蚁配角档案已有；Astral Buddy 支线为前史；"上条拯救失败"悲剧主题与操齿凉子线同构。
