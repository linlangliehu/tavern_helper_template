# 超炮剧情补全 · 实施计划

> 计划 ID：railgun-story-fill
> 状态：🚀 实施中（决策点已全部确认，2026-08-31）
> 创建：2026-08-31
> 目标：把《某科学的超电磁炮》系列已核实但卡内缺失的剧情内容补入世界书，重点填补两个时间窗真空（8月上旬 / 9月底-10月初），并强化现有大霸星祭包的超炮线。
> 铁律继承：项目记忆 #10 全部决策继续生效——无风险机制、不做解密、无反噬、剧情C平衡型、不过度参考其他卡。

## 一、补全内容清单（按优先级）

### P0-A · Poltergeist 篇（乱雑開放）——新主线事件包
- **ID**：POLTERGEIST（节点 POLTERGEIST-{NN}）
- **时间窗**：8月上旬（8/1-8/10）——填补「禁书降临收束(7/28)」与「绝对能力者进化(8月中旬)」之间的真空
- **所属阶段**：阶段1与阶段2之间的过渡（沿用原著锚点总览的旧约窗口；在总览中插一行）
- **核心事实**（已核实）：能力者集体暴走/灵现象化（Poltergeist）；反派泰蕾兹缇娜·木原·莱夫莱恩（木原幻生的孙女，档案已有木原幻生=现成接口）；Capacity Down 大规模能力抑制装置；"First Sample" 幼童诱拐线；8月10日美琴四人组击败泰蕾兹缇娜收束
- **类型**：战斗+日常兼备（暴走事件+治安混乱）
- **防剧透边界**：不提前启动绝对能力者进化；木原幻生深层实验不展开；Capacity Down 原理只到"大范围能力抑制"层
- **锚点联动**：绝对能力者进化篇防剧透段需补"Poltergeist 篇核心事件不得在本篇提前启动"（反向同理）

### P0-B · 天赋梦路（Dream Ranker）篇 ——新主线事件包
- **ID**：DREAM-RANKER（节点 DREAM-RANKER-{NN}）
- **时间窗**：9月底-10月初（使徒十字之后、三战之前）——填补第二个真空
- **所属阶段**：阶段4末尾（旧约·祭典与十字之后）
- **核心事实**（已核实）：卡牌「Indian Poker（印第安扑克）」——他人梦境可被抽卡者体验、可联机做梦；S级梦境「天赋梦路」黑市交易；操齿凉子（20学区新色见中学、民间研究员、"制造灵魂"改造人实验：自愿拆分两名改造人、机械分身获得灵魂）；食蜂操祈追查卡牌制造者；仿生人少女
- **玩法契合**：抽卡体验他人技能与卡的能力体系/都市传说规则天然契合；"制造灵魂"悲剧线符合C平衡型
- **防剧透边界**：Battle Royale（本传）联动不启动；操齿凉子母亲线细节逐层揭示

### P0-C · 大霸星祭主线包「超炮化」增强——改现有文件
- **ID**：DAIHASEISAI（现有包内补超炮线分支节点+核心事实增补）
- **补充内容**（已核实）：美琴因 Sisters 篇亲历被学园都市暗部标记/追杀的压力线；蜜蚁爱愉（美琴的记者同伴线）；食蜂操祈的暗中攻防与协同；暗部追杀作为"暗流"分支不改变现有节点结构
- **原则**：只增不改既有 8 节点骨架；新增内容以"超炮线分支"小节挂入

## 二、明确不做

- Silent Party 篇（STUDY 结社）：时间窗拥挤+战斗系可玩性中等，若用户要可后补
- 越狱篇/超炮过去篇/漫画最终回：动画未播出，等第四季
- Astral Buddy 番外（帆风润子主线）：内容过深，仅以配角身份存在
- 任何解密化/风险化改造（铁律 #11/#10）

- 阶段0：用户确认决策点（见下）
- 阶段1：P0-A Poltergeist 包 + P2 对应行 + P1 相关配角
- 阶段2：P0-B 天赋梦路包 + P2 对应行 + P1 相关配角
- 阶段3：P0-C 大霸星祭增强 + P1 相关配角
- 阶段4：index.yaml 注册 + check-mjr-yaml 校验 + 旧机制残留扫描（grep 反噬/失控/风险值/解密词表）
- 阶段5：构建发布链（webpack→push→等bot→锁sha→tavern_sync bundle→tEXt 校验→git checkout -- dist）

## 四、决策点（2026-08-31 用户已确认）

1. **Silent Party 篇**：不做（已向用户解释其内容；保持排除）
2. **泰蕾兹缇娜与木原幻生关系**：开局即写明"木原幻生孙女"
3. **范围**：P0-A + P0-B + P0-C 三项全做
4. **发布节奏**：全部写完后一次性发布（阶段5 只跑一次）
5. 【执行中新发现】新主线包必须补开局欢迎页篇章组+场景卡（否则开局表单选不到新篇），纳入阶段4

## 五、验收标准

- 新包节点推进表完整（8节点规格、完整ID格式、每轮最多推进1节点）
- index.yaml 注册后 check-mjr-yaml 通过（或豁免说明）
- 旧机制残留扫描零命中（否定式守卫条款除外）
- CDP 实机：绿灯关键词激活、开局锚点可选新篇、软锁定生效、原 20 包无回归
- PNG tEXt 载荷校验：新包ID在卡、loader sha 正确
