# 魔禁 MVU 协议 insert 重放不幂等 — 修复方案 v2

> 日期：2026-09-11 ｜ 卡：魔法禁书目录模拟器 ｜ 当前基线：1.1.2（6 loader @ `ba1ff77c`）
> 状态：开始实施。用户负责最终角色卡导入与聊天验证；本轮负责源码、自动化门禁、构建、打包及交付检查。

## 一、背景与根因

`src/魔法禁书目录模拟器/脚本/mvu-protocol-applier/raw-status-writer.ts` 的 `insert` 分支把去重字段硬编码为 `角色名`。因此 `NPC关系` 能进入合并分支，而使用 `任务名称` 的 `任务追踪` 会直接执行 `splice()`，在协议重放时产生重复记录。

八条恢复、扫描和重试路径最终汇入同一个 `applyPatch()` 写入边界。本轮只修复共同写入边界，不重构这些调度入口。

## 二、行为契约

### 2.1 本次保证

1. 同一普通 JSON 对象的 `insert` 协议重放时，不新增完全相同的记录。
2. 已登记稳定主键的对象数组允许借 `insert` 更新已有记录。
3. 同主键更新保留已有未知字段，且不改变原数组位置。
4. 不同主键对象正常插入。
5. 无稳定主键的对象数组只阻止完全相同对象重放。
6. 字符串、数字、布尔值、`null` 和数组类型的 `patch.value` 保持现有 `insert` 语义，不参与本轮通用去重。
7. 不修改 `patch.value` 或测试输入对象。
8. 不改变 `replace`、`delta`、`remove`、`move` 等其他操作。

### 2.2 本次不保证

1. 不主动删除历史聊天中已经存在的重复记录。
2. 存量重复是否因运行时重建而恢复为单份，只作为用户真机验证项，不作为源码静态保证。
3. 不修改 `extractReplacePaths`、`isFalselyAppliedStat` 或假性已应用判定。
4. 不修改 Schema 业务结构。
5. 不修改神秘复苏模拟器。
6. 不扩展为跨角色卡公共框架。

## 三、对象分类与处理顺序

### 3.1 已登记主键的普通对象

1. 校验插入索引。
2. 从完整操作路径移除末尾 `-` 或数字索引，得到数组容器路径。
3. 根据容器路径查询主键配置。
4. 提取并标准化待插入对象的主键。
5. 找到相同主键记录时，用克隆后的新值执行 `Object.assign` 合并并返回成功。
6. 找不到相同主键记录时，按原逻辑插入。

### 3.2 未登记主键的普通对象

1. 对目标数组中的普通 JSON 对象执行 JSON 语义深比对。
2. 已存在完全相同对象时，视为已成功应用，不再插入。
3. 不存在完全相同对象时，按原逻辑插入。

### 3.3 标量和数组值

字符串、数字、布尔值、`null` 和数组保持原有 `insert` 行为，允许重复插入。

## 四、主键映射

```text
/任务追踪      -> 任务名称
/NPC关系       -> 角色名；空白时回退姓名
/物品/持有物   -> 名称
/能力档案      -> 能力名称
```

映射查询使用数组容器路径：

```text
/任务追踪/-      -> /任务追踪
/任务追踪/0      -> /任务追踪
/物品/持有物/-   -> /物品/持有物
/NPC关系/2       -> /NPC关系
```

有效主键必须是 `trim()` 后非空的字符串。`undefined`、`null`、空字符串和纯空白字符串均视为无效主键。`NPC关系` 的 `角色名` 无效时回退 `姓名`；两者均无效时走普通对象深比对。

## 五、JSON 深比对规则

采用递归 `deepEqual`，仅支持 JSON 数据语义：

- 对象键顺序不同，视为相同。
- 数组元素顺序不同，视为不同。
- `1` 与 `"1"` 不同。
- `null` 与 `{}` 不同。
- 缺少字段与字段值为 `null` 不同。
- 比较过程不修改输入。
- 不支持循环引用、`Date`、`Map`、`Set`、函数、类实例和 `Symbol`。

## 七、自动化测试矩阵

### 7.1 任务追踪

- 首次插入长度为 1。
- 同协议重放 4 次后长度仍为 1。
- 不同 `任务名称` 保留为两条。
- 同 `任务名称`、不同 `当前进度` 更新原对象。
- 更新后数组位置不变。
- 更新后未知字段仍保留。

### 7.2 NPC关系

- 同一 `角色名` 重放不翻倍。
- `角色名` 为空、纯空白或 `null` 时回退 `姓名`。
- 不同角色分别保留。
- `角色名` 与 `姓名` 均无效时不发生错误主键合并。

### 7.3 物品与能力档案

- `/物品/持有物/-` 和数字索引路径均正确识别容器路径。
- 同名物品重放不翻倍；数量变化时更新原记录。
- 不同物品名称分别保留。
- 同一 `能力名称` 重放不翻倍；字段变化时更新原记录。
- 不同能力名称分别保留。

### 7.4 世界线记录

- 完全相同对象重放不重复。
- 对象字段顺序不同但内容相同，仍判定相同。
- `事件`、`时间点`或嵌套内容不同时正常追加。
- 数组属性顺序不同时判定为不同。

### 7.5 标量数组与边界

- `在场人物` 连续插入相同字符串两次，按原语义长度增加两次。
- `/-` 与合法数字索引均可工作。
- 非法索引继续返回失败，去重逻辑不得绕过索引校验。
- `1` 与 `"1"` 不判定相同。
- `patch.value` 和 fixture 输入对象均不被修改。

### 7.6 回归杀伤力

临时将主键逻辑退回只识别 `角色名` 时，`任务追踪` 幂等测试必须失败，证明门禁能够捕获原始缺陷。
