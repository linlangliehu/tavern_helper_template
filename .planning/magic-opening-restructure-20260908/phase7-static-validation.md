## 层级与排序

- 数据层：`时间层 → 作品线 → 剧情阶段／篇章 → 具体开场白`
- 显示层：`时间层 → 作品线｜剧情阶段／篇章 → 具体开场白`
- 分组排序：时间层 → 组内最早日期 → 作品线顺序 → 阶段顺序。
- 组内排序：先槽位，再日期；连续精确日期不得倒序。
- 未定日只出现在 `TL-UNDATED`，不参与伪日期排序。
