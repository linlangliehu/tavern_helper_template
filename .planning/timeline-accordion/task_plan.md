# 开场白时间线手风琴重构计划

## 目标
将当前开局界面「选择开场白」步骤中**平铺的 58 个开场白卡片**，重构为**按时间线篇章分组的手风琴折叠结构**：先按篇章分组并按时间线排序，点击篇章标题下拉展开该篇章的开场白卡片。

## 触发条件
用户要求：「先将事件按时间线排序，点击事件下拉出现关于该事件的开场白」

## 约束（来自项目记忆）
- 只改欢迎页.txt + index.yaml 内嵌副本 + 打包，不动脚本/MVU/世界书
- 视觉对齐深蓝科幻青蓝霓虹（#66ccff/#00ffaa）
- 风格对齐现有面板替换式交互流（goToStep + 返回按钮）
- 改欢迎页.txt 后必须同步 index.yaml 内嵌副本（gen-mjr-welcome-regex.cjs）
- 失败用搞笑呈现，无风险数值

## 技术可行性结论：可行
- 现有 `#secOpening` step（646行）含平铺58个 `.mw-scene` 卡片
- 已有 step 切换机制 `goToStep()` 和 `.mw-step` CSS 可复用
- 现有 `.mw-scene` 卡片含 `data-date`/`data-tag`/`data-desc` 结构化数据，可由 JS 动态分组
- 手风琴是纯前端 HTML/CSS/JS 增强，不涉及 MVU/打包协议/世界书
