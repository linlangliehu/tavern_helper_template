# 魔禁全内容补全至新约结束：执行计划

First Playable：批次01（神之饮物篇）收口期。S1-S5 已完成；S6 部分通过（导入/触发/嵌套传闻/状态栏已验证，节点写回与换篇互斥待补证）；S7 提交授权未请求、未授权。

临时问题支线：hotfix-01（能力卡占位符）契约草案已落盘待批准，未改任何脚本，走独立提交门。

## 目标

在保留当前已实机验证的 MVU、脚本、loader、欢迎页交互和角色卡运行协议的前提下，分批补全《魔法禁书目录》旧约至新约结束的主线与日常内容，并纳入《某科学的超电磁炮》《某科学的一方通行》《心理掌握》《幽幻姐妹》《未元物质》《暗部少女共栖》等正式外传。特典、SS、广播剧、附录和动画原创全部进入开发侧索引，动画原创与小说、漫画平等登记，但保留媒介来源与兼容性标记。

## 固定范围

- 本传：旧约、旧约 SS 与正式补充、新约、新约 Reverse，终点为新约结束。
- 暂不纳入：创约。创约完结后另行立项。
- 外传：超电磁炮、一方通行、心理掌握、幽幻姐妹、未元物质、暗部少女共栖，以及经正式来源核实的其他相关外传。
- 日常完整度：C 档。特典、SS、广播剧、BD/DVD 内容、漫画附录、动画原创和其他正式附加叙事全部登记。
- 欢迎页：只展示时代和主要篇章，子篇章与日期节点留在篇章内部。

## 不可突破的红线

- 不做数据库或外部 SQL 服务。
- 不增加风险值、失败收场、异常事件、线索推理或解密体系。
- 不增加跨体系反噬或使用惩罚。
- 不照搬《神秘复苏模拟器》的恐怖、风险或解密结构。
- 原著结果只是默认世界线，玩家可以介入、偏离和改写。
- 不复制受版权保护的原作正文或台词，只记录事实摘要、来源定位和玩法所需信息。
- 未经证据和单独授权，不修改 MVU、变量协议、脚本、loader 或运行依赖。
- 不混入 `src/神秘复苏模拟器/schema.json` 等其他项目的现存改动。

## 内容分层

1. 开发侧作品注册表：登记所有正式发行物，不注入模型上下文。
2. 开发侧内容与证据账本：登记内容单元、来源、时间锚点、冲突与兼容性，不直接装入角色卡。
3. 运行侧主线事件包：仅承载玩家需要进入和推进的主要篇章。
4. 运行侧日常素材单元：按角色、地点、节日、关系和时间窗口条件激活。
5. 运行侧索引摘要：只保留必要的篇章定位，不把全量书目和研究资料发送给模型。

## 执行阶段

### 阶段 0：基线冻结

- 创建本规划目录及 `findings.md`、`progress.md`。
- 记录旧计划 `.planning/魔禁全系列补全/` 为已完成的历史阶段，不覆盖或删除。
- 冻结当前源文件、世界书、欢迎页、PNG、脚本依赖和 Git 状态基线。
- 建立性能基线和组件依赖图。

退出条件：当前正式产物身份、文件数量、大小、条目数量、剧情包数量、依赖和工作区现存改动均有记录。

### 阶段 1：作品全集与覆盖账本

- 建立作品注册表、内容单元表、证据表、事件表、冲突兼容性表和项目覆盖映射表。
- 先核验正式发行物，再研究剧情，不从百科摘要直接补写。
- 使用官方出版目录、版权页、正式作品、制作委员会资料和可靠书目交叉核验。
- 社区资料只用于发现候选，不单独作为完成依据。

退出条件（2026-09-02 修订）：骨架核验完成即视为阶段 1 主体达成——本传/外传/C档发行骨架、六类账本（ledger-01~05）与缺口矩阵均已落盘。原「登记完整度 100% + 一级来源核验率 ≥95%」转为长期目标，中间卷日期、外典書庫4细节、广播剧逐集等待核验细目，随对应内容批次逐项核验，不再作为阶段 1 的阻塞门。

### 阶段 2：最小可玩试点

### 阶段 7：静态与安全门禁

- 文件结构、编码、条目注册、关键词和顺序校验。

- 世界书、提示词、最大单条目、正则、脚本和整卡体积预算检查。
- 只有欢迎页或正则变化时才执行正则管线。

- 发布前执行只读安全审计。

### 阶段 8：真实 SillyTavern 验收

### 阶段 9：发布与交接

- 每一批必须先通过门禁和实机验收。
- 提交前重新检查 Git 状态，排除其他项目改动。
- 未经用户明确授权，不提交、不推送、不更新 CDN、不覆盖正式 PNG。
- 获得发布授权后，创建可回滚提交、更新不可变 loader SHA（仅在脚本确实修改时）并更新交接文档。

## 覆盖状态

每个作品或内容单元只能处于以下状态之一：

- 未研究
- 待核验
- 仅索引
- 摘要覆盖
- 日常素材覆盖
- 可玩事件覆盖
- 完整覆盖
- 有意排除
- 延期至创约工程

“名称出现在世界书中”不得算作完整覆盖。

## 媒介兼容标签

- M0：该媒介的原始叙事。
- M1：直接改编。
- M2：扩写且兼容。
- M3：替代演绎。
- M4：连续性冲突。
- M5：时间位置尚未可靠确定。

动画原创与小说、漫画平等登记，不使用低一等的默认地位；存在冲突时保留双方并记录项目采用路线。

## 性能原则

- 全量书目、证据和研究记录只留在开发侧。
- 每个运行侧世界书条目只承担一种职责。
- 大型剧情包按当前篇章条件激活，不常驻。
- 日常素材按角色、地点、时间和关系条件激活。
- 优先消除重复说明，不擅自删除剧情。
- 候选产物必须与同一基线、同一测量表面和同一脚本版本比较。
