## 二、统一记录口径：先分层，再定日期

每个事件至少说明以下信息，可写在现有文本包头／节点说明中，**不要求本轮新增MVU字段或改schema**：

1. 事件身份：作品、卷／话、媒介、共视角或原创改编；有同名设定不等于有同名原作篇章。
2. 原著锚点：原作明示、官方动画日期或图推日期分别标注，缺章页则明写待核。
3. 事件范围：前奏→主体→结局→后日谈；不能让某个决战日代替全篇，也不能把余波写成主战仍持续。
4. 可玩窗口：欢迎页的提前调查、精选入口、回忆触发与原创续玩，单列为项目安排。
5. 年层／时间层：上一学年、当前学年、跨年后；回忆讲述日与回忆内容发生日分开。
6. 冲突：记录来源、同／异媒介、两种排期及未决理由；不能因为网页较新就自动覆盖原作／官方证据。

使徒十字的目标口径示例：主体为9/19、术式当夜失败；9/20凌晨为追捕后续；9/19–25是祭典背景，不是使徒十字持续七天。这个示例以官方动画年表为日历证据，小说章页尚未独立取证。
