# MJR 1.2.0 发布记录

版本：1.2.0。发布日期：2026-11-05。正式标签：`mjr-v1.2.0`。

## 变更

- 新增悬浮变量编辑器，分类查看和修改玩家、能力、任务、地点、关系等 MVU 消息楼层变量，支持删除数组项和全部 JSON 编辑。
- 修复手动值被旧 AI 协议覆盖：消息面板和协议写入器共用 swipe + 协议指纹保护，写入前及异步提交前检查；新协议和新 swipe 仍正常更新。
- 修复输入后需要点击两次“应用”：输入时暂存，保存状态局部刷新，一次点击即可提交。
- 按 schema 类型生成编辑控件，允许纠正异常布尔、数字和枚举；空数字阻止应用。
- 保留 1.1.9 的图鉴 token 优化，以及后续关键字约束、关系条目角色名显示和生成状态修复。

## 验证与依赖

- 开发卡实机已验证三项修复、旧协议保护、新楼层协议更新及重新进入聊天后的持久化，详见 `魔禁/MJR_变量编辑器修复_20261105.md`。
- 角色卡类型：MVU Zod；PNG 内嵌世界书、7 条正则、单一启用的脚本加载器；加载器串行加载 MVU、变量结构、协议应用、界面美化、固定状态栏、消息内面板、变量编辑器共 7 个模块。
- 宿主需要 SillyTavern、Tavern Helper 与 ST-Prompt-Template（世界书 EJS）；MVU 和变量结构由卡内加载器加载，无须另装本地 Zod。验收环境为 ST 1.18.0 / Tavern Helper 4.11.3 / MVU 0.171.0。
- 正式脚本使用固定 Git commit 的 testingcf CDN，沿用单节点重试加载器；fastly 用于独立字节验证，未增加自动节点切换。BGM 固定 `bgm/7f1be030f9f59d8c6d2dbc3333ffa77dff8b9a26`。
- 不携带本地 5510 地址、watch 或开发模式标记；PNG `chara`/`ccv3` 各一份，所有 chunk CRC 有效，两个载荷的 data 完全一致。
