## 修复

1. 手动值不再被旧协议覆盖。新增共用 `_manual_variable_edit.ts`，写入前设置消息级 swipe + 协议指纹标记；面板和协议写入器共享判断。补写入口、假性已应用扫描及异步提交前均检查保护；写入失败撤回暂存标记，变量与标记一起保存。兼容历史 swipe 标记；新写入使用更严格指纹。新协议/新 swipe 不继承旧保护，同一 swipe 的新协议在正文清理后保存最新快照。
2. 一次点击应用。文本输入使用 input 事件暂存，只更新按钮状态、错误及改动标记，不销毁正在输入的控件。保存中禁止重复提交；应用前核对消息对象和协议身份。
3. 异常类型可表单纠正。控件读取自动生成的 schema.json，布尔字符串通过带原值提示的下拉框显式纠正，数字字符串按数字编辑，空数字阻止保存。保留“未修改的历史错误不阻塞其他字段”的校验策略。
