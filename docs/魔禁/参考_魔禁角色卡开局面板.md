## 二、页面结构（两大 Tab）

### 顶部导航 `.main-nav`（sticky）
- 左：标题"魔法禁书目录"
- 右：两个 nav-link：**角色生成**（active）/ **角色介绍**

### Tab A：角色生成 `#home-page`

**1. 玩家信息表单 `.form-container`（2列网格，移动端1列）**
| 字段 | 类型 | 备注 |
|------|------|------|
| 姓名 | text | placeholder"请输入姓名" |
| 性别 | select | 男/女/其他 |
| 年龄 | number | min12 max30 |
| 性格 | text | |
| 外貌 | text | |
| 补充 | text | placeholder"可在此输入其他补充信息，如背景故事、特殊设定等" |

> 注意：参考卡比我们的计划多了一个"性格"字段，且"补充"是 input 而非 textarea。我们可按需调整。

**2. 阵营选择 `.side-section`**
两列卡片网格 `.side-options`：
- **科学侧** `.side-option[data-side="science"]`：图标 `fa-atom`，描述"学园都市的超能力者，开发个人现实，通过科学手段获得超凡能力"
- **魔法侧** `.side-option[data-side="magic"]`：图标 `fa-hat-wizard`，描述"使用魔法力量的魔法师，掌握神秘术式，与科学侧对立的神秘世界"

选择后进入对应分支。

**3a. 科学侧分支**
- `.school-section` 选学校：某高中 / 常盘台中学 / 栅川中学 / 长点上机学园 / 雾丘女子学院 / 自定义输入
- `.ability-section` 选超能力：幻想杀手(锁定Level0) / 矢量操作 / 未元物质 / 超电磁炮 / 原子崩坏 / 心理掌握 / 念动炮弹 / 自定义能力
- `.level-section` 选等级（药丸式 6个）：Level 0-5 + Level 6(绝对能力者)
  - 特殊：选"幻想杀手"自动锁定 Level 0，其余等级禁用

**3b. 魔法侧分支**
- `.organization-section` 选魔法组织：英国清教 / 罗马正教 / 俄罗斯成教 / 黄金魔法结社 / 自定义输入
- `.magic-section` 选魔法境界（药丸式）：魔神 / 圣人 / 魔法师 + 自由输入"你的魔法描述"

**4. 开场白选择 `.opening-section`**（共用）
- 50 个预设开场白（见第三节）+ 1 个"自定义开场白"
- 每个开场白卡片显示：加粗日期/篇名 + 截断的剧情描述
- 选自定义 → 展开 textarea

**5. 提交 `.generate-button`**
→ 弹出预览模态框 `.preview-modal` 展示配置 → "确认复制" `copyFinalConfig` 复制文本到剪贴板。

### Tab B：角色介绍 `#characters-page`

角色卡片网格 `.characters-container`（auto-fill minmax(200px,1fr)），点击卡片弹出 `.character-modal` 显示大图 + 详细信息列表（性别/年龄/外貌/能力/性格/背景）。

## 六、对我们魔禁角色卡设计的启发与差异

### 可借鉴
1. **深蓝科幻 + 青绿选中** 的视觉语言契合魔禁（学园都市科技感 + 魔法神秘感）
2. **阵营分支**：科学侧走 学校→能力→等级；魔法侧走 组织→境界→魔法。分支清晰
3. **开场白作为时空锚点**：50个剧情节点直接可用，比三级手风琴更扁平（但量太大需分组）
4. **预览模态框**：提交前先预览配置，体验好

### 需改进/适配本项目
1. **提交方式**：参考卡用"复制到剪贴板"手动粘贴；本项目应**直接写入 `send_textarea` 并触发发送**（参考神秘复苏 fillWelcomeStart）
2. **时空锚点**：50个开场白太长，应改为**三级手风琴**（阶段0-7 → 篇章 → 具体日期节点），而非平铺50项
3. **角色介绍 Tab**：参考卡只有5个原著角色且无原创原型；按我们计划应加原创原型
4. **性格字段**：参考卡有"性格"字段，我们计划未列——可补上
5. **魔法侧"魔法境界"药丸**（魔神/圣人/魔法师）：开局就给"魔神"过强，建议默认只开"魔法师/圣人"，魔神设为隐藏或高风险标注
6. **幻想杀手锁定Level0**：好设计，应保留（选幻想杀手自动锁Level 0）
7. **图片**：不可复用第三方图床；角色介绍图需自备或用纯 CSS 立绘
8. **音乐**：参考卡有BGM（GitHub raw mp3），本项目可选用不加
